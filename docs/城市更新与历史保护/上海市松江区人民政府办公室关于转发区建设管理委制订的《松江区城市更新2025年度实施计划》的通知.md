# 上海市松江区人民政府办公室关于转发区建设管理委制订的《松江区城市更新2025年度实施计划》的通知

各镇人民政府、街道办事处，区政府各部门：

经区政府第97次常务会议通过，现将《松江区城市更新2025年度实施计划》转发给你们，请遵照执行。

2025年7月15日

松江区城市更新2025年度实施计划

为深入贯彻党的二十大、二十届三中全会精神，落实市委市政府、区委区政府总体工作部署，坚决、稳妥、有序推进城市更新，我区城市更新工作坚持以总规为引领，深入践行人民城市重要理念，聚焦市委对松江“四个区”的功能定位，统筹民生改善和高质量发展，优化空间布局，补齐短板弱项，探索可持续城市更新模式。现就松江区城市更新2025年度实施计划分解如下：

一、行动任务

围绕城市更新“六大行动”，分类梳理包括区域更新、民生改善、设施优化、风貌保护、产业转型、商业再造等方面共22项任务。在综合区域整体焕新方面，强调先行先试，加强全要素统筹协调；在人居环境品质提升方面，强调筑梦安居，不断增进民生福祉；在公共空间设施优化方面，强调功能提升，系统提高城市应对风险能力；在历史风貌魅力重塑方面，强调保护传承，合理引导空间载体活化利用；在产业园区提质增效方面，强调产业升级，培育新兴产业发展优势；在商业商务活力再造方面，强调盘活存量，营造功能多元的新业态环境。

（一）综合区域整体焕新行动

1.加力推进经开区中部SJC1-0013单元松东路以西区域、九里亭秀浜城市更新项目。（牵头单位：经济技术开发区、九里亭街道，支撑单位：区规划资源局、区建设管理委、区经委）

2.持续推进永丰仓城、泗泾下塘历史文化风貌区城市更新项目，探索可持续城市更新模式。（牵头单位：永丰街道、泗泾镇，支撑单位：区文化旅游局、区规划资源局、区建设管理委）

（二）人居环境品质提升行动

3.认定启动3个“城中村”整体改造类项目，同步推进规划拔点类、整治提升类项目，发挥稳增长、扩内需、促转型的积极作用。（牵头单位：区住房保障房屋管理局、相关街镇）

4.完成旧住房修缮更新60万平方米。（牵头单位：区住房保障房屋管理局、相关街镇）

5.完成既有多层住宅加装电梯开工和完工25台。（牵头单位：区住房保障房屋管理局、相关街镇）

（三）公共空间设施优化行动

6.推进144个“15分钟”社区生活圈建设项目。（牵头单位：区规划资源局、相关街镇）

7.推进5个“美丽街区”建设。（牵头单位：区绿化市容局，支撑单位：相关街镇）

8.实施7公里燃气老化管道改造。（牵头单位：区建设管理委）

9.实施24公里老旧供水管道改造。（牵头单位：区水务局）

10.开展雨污水分流改造，积极推动重点区域及其他区域涉及住宅小区、企事业单位、市政管网的雨污混接整治工作。（牵头单位：区水务局）

11.推进海绵城市达标评估，落实海绵城市达标区面积占建成区50%的目标要求。（牵头单位：区建设管理委）

12.实施38个区管桥梁桥下空间整治。（牵头单位：区交通委）

13.推进印象城慢行交通示范区创建。（牵头单位：区交通委）

14.完成晨星口袋公园建设。（牵头单位：区绿化市容局，支撑单位：经开区）

15.完成3万平方米节能率不低于15%的既有公共建筑节能改造。（牵头单位：区建设管理委）

（四）历史风貌魅力重塑行动

16.启动长桥南街王槐亭宅、中山西路沈氏宅、泗泾镇张逸盛宅等修缮工程。（牵头单位：岳阳街道、永丰街道、泗泾镇，支撑单位：区文化旅游局）

17.实施袜子弄文化滨水绿道更新、中山西路架空弱电管线改造、泗泾镇开江路、文化路路面铺装等工程。（牵头单位：中山街道、永丰街道、泗泾镇）

（五）产业园区提质增效行动

18.推进“两评估、一清单、一盘活”专项行动，完成3.44平方公里低效产业用地处置任务。（牵头单位：区规划资源局、区经委、区国资委）

19.推进佘山高新科技园、车墩工业园南部产业园区转型升级。（牵头单位：区经委、佘山镇、车墩镇）

20.推进大洋集团老旧厂房改造。（牵头单位：九亭镇）

（六）商业商务活力再造行动

21.通过推动早餐工程和菜篮子工程建设进一步完善“一刻钟便民生活圈”建设。（牵头单位：区经委）

22.推进荣乐中路8号（原卜蜂莲花）大橘邻里传统商圈改造升级。（牵头单位：区经委、岳阳街道）

二、工作保障

（一）坚持规划总体引领

建立完善规划实施体系，在空间布局上进行整体统筹、系统谋划，加强规划对更新区域资源优化配置的引导，强调提升城市功能、促进职住平衡、推动均衡发展、增进民生福祉。

（二）坚持城市体检先行

坚持“先体检、后更新，无体检、不更新”，创新城市体检与城市更新联动的体制机制，深入开展区级城市体检和专项体检，滚动开展街镇和社区体检，强化体检成果应用。

（三）健全项目生成机制

优化完善松江区城市更新项目库管理办法，结合“2025年度城市更新规划实施报告”推进项目生成，在规划引领下推动项目实施。

（四）用好“三师”联创工作机制

加快推进建筑师负责制，充分发挥专业力量在城市更新中的技术统筹和引领作用，强化城市设计引导，精准实施城市更新项目。

（五）强化先进理念应用

推广绿色低碳建筑，提升建筑能效水平，把城市更新与海绵城市、韧性城市、智慧城市、公园城市建设有机结合起来，注重无障碍环境建设。

（六）坚持党建引领

通过党建联建等加强跨部门联动协同，充分发挥基层党组织的工作优势，结合基层治理推动解决重点难点问题，让人民群众全过程、全方位参与城市更新。
