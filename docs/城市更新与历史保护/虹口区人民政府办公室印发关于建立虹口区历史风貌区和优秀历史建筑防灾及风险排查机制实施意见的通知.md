# 虹口区人民政府办公室印发关于建立虹口区历史风貌区和优秀历史建筑防灾及风险排查机制实施意见的通知

区政府各部门、各街道办事处、有关单位：

《关于建立虹口区历史风貌区和优秀历史建筑防灾及风险排查机制的实施意见》已经区政府同意，现印发给你们，请按照执行。

虹口区人民政府办公室

关于建立虹口区历史风貌区和优秀历史建筑

防灾及风险排查机制的实施意见

为确保虹口区历史风貌区和优秀历史建筑安全，建立日常防灾及风险排查机制，根据住建部办公厅《关于做好历史文化名城名镇名村防灾工作的紧急通知》（建办规电〔2014〕3号）及市规土局、区政府有关工作要求，特制定本意见。

一、历史风貌区和优秀历史建筑是虹口区重要的历史遗存，具有不可再生性，须加强保护。要高度关注、逐步改善历史风貌区和优秀历史建筑居住者的生活条件，加强基础设施建设，消除安全隐患。

二、各单位要牢固树立综合减灾和风险管理理念，认真总结历史风貌区和优秀历史建筑防灾减灾工作的经验教训，建立部门联动工作机制，根据实际情况建立防控制度，完善应急处理制度，落实责任，共同做好防灾工作。

三、本意见所称虹口区历史风貌区和优秀历史建筑的范围是：提篮桥历史文化风貌区、山阴路历史文化风貌区、外滩历史文化风貌区（苏州河以北部分）内的建筑及本市1－4批公布的位于虹口区范围内的共计58处优秀历史建筑。今后如新增历史风貌区和优秀历史建筑一并纳入。

四、各单位按以下职能分工牵头定期组织开展防灾及风险排查工作，原则上每年不少于2次：

（一）区房管局。负责定期牵头召开全区历史风貌区和优秀历史建筑防灾及风险排查工作例会，安排全年防灾及风险排查工作；负责督促和指导优秀历史建筑物业管理单位、产权人对相关优秀历史建筑进行全面排查，汇总、梳理、分析和上报排查情况，并协调、督促物业管理单位和产权人落实整改。

（二）公安消防支队。负责对区内优秀历史建筑的消防隐患及其周边的城市市政消火栓等公共消防基础设施进行总体排查，针对排查中发现的火灾隐患，督促指导相关单位落实消防主体责任，制定整改计划，落实整改措施；负责适时开展消防宣传教育工作，增强相关单位的消防安全意识和防范能力，提升&ldquo;四个能力&rdquo;（检查消除火灾隐患能力、组织扑救初起火灾能力、组织人员安全疏散逃生能力和消防宣传教育培训能力）建设水平。

（三）区建交委。负责组织、协调、落实因各类工程建设影响而产生的房屋安全问题的整改；负责配合公安消防支队对市政道路上的消防设施进行排查，并落实整改。

（四）区安监局。负责加强安全生产监管，配合指导各相关部门、单位制定整改方案；负责组织、协调相关事故的调查处理工作，并监督事故查处的落实情况。

（五）各街道办事处。负责结合消防防火检查开展风险及防灾排查工作；负责组织对辖区内非物业管理范围内相关建筑的安全排查工作；负责通知物业管理范围内售后房及商品房各产权人自行或委托物业管理单位开展房屋安全排查工作，并予以监督。具体分工为：

1.提篮桥街道办事处负责提篮桥历史文化风貌区、外滩历史文化风貌区（本街道内部分）建筑的防灾和风险排查工作。

2.四川北路街道办事处负责山阴路历史文化风貌区（本街道内部分）、外滩历史文化风貌区（本街道内部分）建筑的防灾和风险排查工作。

3.欧阳路街道办事处负责山阴路历史文化风貌区（本街道内部分）建筑的防灾风险和排查工作。

（六）虹房集团。负责组织对受托经营管理的各类公房进行安全排查,并落实整改。

（七）区房屋急修中心。负责对受理的房屋报修急修事件进行分类梳理，经现场查看，确认存在严重安全隐患的要及时报区房管局、虹房集团、房屋产权人（单位）。

五、对于未按照有关法律和本意见履行防灾和风险排查工作职责，造成后果和严重影响的，将依法依纪追究责任。
