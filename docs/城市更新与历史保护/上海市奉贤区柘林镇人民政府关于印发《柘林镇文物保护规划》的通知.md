# 上海市奉贤区柘林镇人民政府关于印发《柘林镇文物保护规划》的通知

各相关单位、部门：

为深入贯彻习近平总书记关于文物工作的重要论述和指示批示精神，聚力推进柘林镇“十四五”时期文物保护利用工作，现将《柘林镇文物保护规划》印发给你们，请结合实际，认真抓好落实。

特此通知

柘林镇文物保护规划

党的十八大以来，以习近平同志为核心的党中央高度重视文物工作，习近平总书记站在传承中华文明、增强文化自信、建设文化强国的战略高度，深刻论述了文物工作的重要意义，系统阐明了做好文物工作的方向性、根本性、全局性问题。为深入贯彻习近平总书记关于文物工作的重要论述和指示批示精神，聚力推进柘林镇“十四五”时期文物保护利用工作，以文物承载灿烂文明，传承历史文化，维系民族精神，根据镇政府决策部署，编制本规划。

一、总体要求

(一)指导思想

坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十大和二十届历次全会精神，贯彻落实习近平总书记关于文物工作重要论述和指示批示精神，立足新发展阶段，贯彻新发展理念，构建新发展格局，以推动文物保护利用高质量发展为主题，以深化改革创新为主线，坚持把保护放在首要位置，强化系统性保护，加强文物保护、管理、研究、利用，持续提升文物保护领域治理体系和治理能力现代化水平，使文物保护成果更多惠及人民群众，推动柘林历史文化名镇的发展建设。

(二)基本原则

——坚持党的全面领导。坚持马克思主义的指导作用，坚持和完善党领导文物工作的体制机制，深刻认识“两个确立”的决定性意义，增强“四个意识”，坚定“四个自信”，坚决做到“两个维护”，树立正确的历史观、国家观、民族观、文化观，深入挖掘阐释文物蕴含的思想理念、传统美德、人文精神。

——坚持以人民为中心。自觉践行“人民城市”重要理念，尊重人民群众主体地位，保障人民群众文化权益，广泛动员社会力量参与文物保护利用，推动文物保护利用融入人民群众生产生活，做到文物保护为了人民、依靠人民，成果由人民共享，不断增强人民群众的认同感、参与感、获得感。

——坚持依法科学保护。始终把保护放在第一位，健全文物保护工作体制，落实文物保护的主体责任，明确文物保护的各方责任，构建文物保护全社会参与新格局。

——坚持创新驱动发展。牢固树立文物保护利用要依靠创新的发展理念，完善科技创新体制机制，增强创新能力，推动文物领域的创造性转化和创新性发展。发挥创新引领作用，创新文物保护、利用和管理方式，着力推动让文物“活起来”，激发文物的创新创造力和生命力。

(三)主要目标

在“十四五”时期，基本建设成为与柘林镇历史文化底蕴相匹配的文物事业发展新格局。文物保护管理体系逐渐健全，古人类文化、海塘文化、非遗文化等的文化底蕴充分挖掘，文物在提升乡镇软实力中作用显著增强。柘林镇特有的文物资源得进一步系统梳理，保护传承力度不断加大，乡镇历史风貌和历史文脉的延续性持续强化，乡镇发展与文物保护利用相融合的新格局初步形成，文物在建设中的创新活化有效提升。文物保护利用效率逐步提升，推动具有柘林特质的历史文化传承进入民众生活，文物保护惠及全民的格局逐步推进。文物保护科技创新能力不断提高，科技创新对文物工作的支撑作用显著增强。社会力量参与文物保护的体制机制逐步健全，文物保护领域社会参与活力不断焕发，社会力量广泛参与文物保护利用格局逐步形成。

二、主要任务

(一)健全文物治理体系

1.完善文物保护管理体系。探索建立不可移动文物保护与土地空间规划管理的协调机制，统筹划定文物保护单位保护范围和建设控制地带、地下文物埋藏区等，并纳入土地空间规划“一张图”。强化规划引领，做好全国重点文物保护单位、重要市级文物保护单位保护规划及相关专项规划的编制、公布和实施工作。进一步完善镇文物行政管理部门机构设置，在镇文物行政管理部门的基础上，推动增设文物所在村居负责文物保护管理的基层机构。优化各类保护对象实施保护、修缮、改造、迁移的审批管理，探索实施审批简易程序，完善文物领域事中事后监管。

2.健全文物资源管理体系。完善文物登录制度，保障文物资源资产安全完整、有效保护和合理利用。完善不可移动文物资源管理机制，推动各村居持续加强历史文化资源梳理，申报一批区级文物保护单位和文物保护点。加强新中国成立以来现当代文物、农业遗产、工业遗产等资源梳理，推进镇文物数据库建设，系统整合全镇不可移动文物、可移动文物及历史文化档案数据。

3.深化构建文物安全体系。将文物安全纳入各村居年度绩效考核体系，进一步落实文物安全各村居主体责任。推行网格化管理模式，实施文物安全责任人公示公告和全镇不可移动文物保护联系人制度，构建完善的镇、村居巡查检查机制，适时探索“文物长制”。严格落实文物消防法律法规，持续开展全市文物火灾隐患整治和消防能力提升行动，针对市级以上文物保护单位和重点博物馆开展消防安全风险评估，有效化解重大文物火灾风险隐患。建立文物安全风险形势研判、风险评估和预警长效机制，开展文物安全风险等级评估，加强面对极端天气和自然灾害的预案制定和预警演练，提升防灾减灾能力。实施文物平安工程，加大文物保护单位、博物馆、考古遗址等安全技术防范设施设备改造提升力度，提高文物安全监管能力。

(二)提升不可移动文物保护能力

1.强化系统性保护。开展不可移动文物现状调查，摸清不可移动保护保存状况，加大文物保护单位险情排查，推进文物保护单位修缮项目。补充、更新不可移动文物分类保护导则，明确保护要求，提高文物保护管理针对性、实效性。实施重要不可移动文物保护性修缮，完成杨家老宅、王藕英老宅等的修缮项目。

2.推动预防性保护。加强预防性保护研究和技术推广，推动实现全国重点文物保护单位从抢救性保护到预防性保护转变。围绕日常维护保养、监测、影响评估、风险预控等文物预防性保护重点领域，坚持文物保护多学科深度融合，推动文物预防性保护基础理论研究。

3.加强乡镇更新中的文物保护。深入贯彻国家、上海市相关法律法规，坚持保留保护为主的理念，在实施乡镇有机更新中进一步加强文物保护工作。强化文物本体保护和周边风貌管控，坚持文物本体保护与周边环境整体保护提升并重。加强全国和市级重点文物保护单位保护，重点做好文物保护单位的规划编制、保护修缮、安全防范和展示利用。

(三)推进和配合考古工作

1.加强考古研究和价值阐释。从构建柘林镇历史文化脉络出发，重点推进柘林良渚遗址、华亭古海塘的考古发掘和研究，并强化考古成果的整理和价值阐释，配合上海文明探源工程，积极探源柘林历史，助力打造“柘林之根”考古成果转化的文旅融合项目，用实证的方式勾勒展示柘林地方历史文化脉络。加强文化交流，强化柘林在上海考古发掘、研究和成果展示的话语权，以更广阔的视野形成柘林考古研究的学术之地。

2.形成文物考古“小阵地”。积极推动柘林建设成为上海重要的考古文化资源的汇聚地和展示平台。围绕“何以”系列考古文化品牌建设，梳理柘林考古和文物资源，通过展览、文创、出版物等多种形式，诠释“何以柘林”考古主题，联合高校、考古机构、博物馆等，打造“何以柘林”系列考古展，制作推出“何以柘林”考古纪录片。

3.探索乡镇建设工程中考古机制创新。完善配合基本建设考古工作体制机制，在“三区两镇”的发展空间格局中，统筹推进相关考古工作，试点推行建设工程考古区域评估机制。划定一批地下文物埋藏区，积极探索在政府土地储备及建设中推行“先考古、后出让”制度，将考古调查、勘探、发掘作为前置程序，最大限度减少基本建设对地下文物的影响。重点做好道路建设、公园修建、水系航道整治等基础设施工程项目建设前期涉及范围内的考古工作。

(四)推动非国有博物馆和村史馆深化发展

1.推出柘林镇非遗陈列馆“非国有博物馆计划”。通过丰富和增加馆内展示陈设内容，更新完善馆内服务设备，引进数字化技术，加强队伍建设，力争在“十四五”期间建成在上海领衔的真正的非国有博物馆，赋能柘林乡镇发展和上海城市软实力的提升，在新时代、新征程为服务国家战略和城市发展做出更大贡献 。

2.加强规划村史馆建设。在现有村史馆建设布局基础上，挖掘文物丰富、文化厚重的重点村居，规划建设村史馆，形成新型文化地标和文化集群，加强文博集聚区的科学规划和周围基础服务设施建设，保障村史馆公共文化服务的便捷性和人群覆盖面。

3.实施双类展馆青少年教育实践。建立广泛的馆校合作机制，构建校内外育人共同体，建立健全非国有博物馆、村史馆与教育部门和学校的联动机制，鼓励学校组织学生到非国有博物馆和村史馆开展学习实践。

三、保障措施

(一)加强组织领导

坚持党对文物工作的领导，进一步发挥镇党委在文物工作中总揽全局、协调各方的领导作用。严格落实地方政府文物保护主体责任，建立规划实施保障机制，强化重大任务、重大工程、重大项目的实施保障。加强镇文物行政管理部门和专业机构力量，强化人员配置，保障文物事业发展。

(二)强化联动协同

加强镇级部门协同，增强文物部门与宣传、发展改革、公安、消防、教育、财政、人力资源社会保障、市场监管等部门之间的沟通协调，形成工作合力，研究、解决文物工作中遇到的困难和问题。加强镇、区联动，区级层面要把握好全市文物工作的主导方向，加强宏观资源配置、空间规划布局、政策环境优化和基础条件配备。镇级层面要按照全区战略目标和总体规划部署，结合本镇实际，推动本镇文物事业健康有序发展。

(三)强化人才支撑

适应新时代文物事业发展需求，树立与时俱进、兼容并蓄的人才观。结合奉贤区和镇重点人才项目，培育聚集一批专业文物人才，加强考古、文物修复、文物展览等急需领域人才培养，加快形成人才高峰效应。
