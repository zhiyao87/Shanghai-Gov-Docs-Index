# 闵行区人民政府关于印发《闵行区城市更新“十五五”规划》的通知

闵府发〔2026〕26号

各镇人民政府、街道办事处，区政府各委、办、局,各区属公司，有关单位：
《闵行区城市更新“十五五”规划》已经区政府同意，现印发给你们，请认真按照执行。

2026年7月28日

闵行区城市更新“十五五”规划

“十五五”时期，闵行区紧扣打造现代化主城区和新质生产力主阵地的发展定位，依据国家和上海关于城市更新的部署要求，结合本区建设用地规模趋紧、空间品质和功能配套亟待提升等实际需求，聚焦“聚新质转动能，优空间提品质”发展主线，高质量开展本区城市更新行动。
一、发展目标
坚持以习近平新时代中国特色社会主义思想为指导，深入领会习近平总书记考察上海讲话精神和对上海工作重要指示要求，完整、准确、全面贯彻新发展理念，学习贯彻中央城市工作会议精神，转变超大城市发展方式，以城市更新助力“五个中心”建设，探索完善可持续的城市更新模式。
坚持以重点区域更新为牵引、以零星微更新为网络协同，分类分区系统推进全域更新任务，统筹推进好房子、好小区、好社区、好城区“四好”建设，实现人居环境品质持续改善、城市动力活力明显增强、风貌特色更加彰显、安全发展基础更加牢固、城市更新体制机制更加健全，着力将闵行打造成为功能承载区、创新实践区、宜居样板区，助推闵行高质量建设创新开放、生态人文、宜居安居现代化主城区和新质生产力主阵地。

二、重点任务
（一）建设全龄友好宜居城区
1.加强既有居住建筑改造
聚焦住房安全与居住品质提升，稳妥推进危险住房改造，依法拆除D级危险住房，有序推进国有土地上C级危险住房处置。分批推进老旧公房成套改造居民入户工作，做好权属登记与产证办理，“十五五”期间完成电四小区、鲁汇一村共计约1.4万平方米成套改造。同步实施既有居住建筑节能与安全改造，加强既有建筑及市属保障房外墙外保温维护监管。
2.推进老旧小区整治改造
以2000年前建成的公房、动迁房及混合小区为重点，实施“美丽家园”综合修缮。对未纳入“美丽家园”但存在渗漏、开裂等隐患的老旧小区，专项开展屋面、外墙修缮，消除安全隐患。常态化开展从前期意愿征询到后续使用管理的全流程工作，有序推进既有多层住宅加装电梯；借力国补政策，继续推进符合更新条件的住宅老旧电梯有序更新，持续提升更新覆盖率；利用闲置空间打造绿地与健身设施；有序开展二次供水设施改造接管工作，切实保障居民饮用水质持续稳定。
3.开展完整社区建设
聚焦“一老一小”核心需求，建设综合为老服务圈与托幼一体化设施，在公共空间融入适老适幼设计，完善无障碍与儿童活动场地。统筹教育、医疗、养老、文体等设施布局，盘活存量空间增设社区食堂、助餐点等便民配套。健全体育服务体系，推动场地错时开放与线上预约。在古美、新虹、虹桥、吴泾等街镇新增特色类、基础类完整社区，力争2030年完整社区覆盖率达到60%。
4.加快推进城中村改造
重点聚焦颛桥中心村、浦江召稼楼、浦江杜行老街、华漕诸翟村、浦锦恒星村郁宋村、七宝七宝村、吴泾共和村星火村、梅陇永联村曹中村等8个城中村整体改造项目，坚持区域更新、整体改造，加快推进项目建设，拓展城市发展空间，提升城乡统筹能级。2026年全面启动8个整体改造项目动迁腾地，完成三幅安置房地块出让工作，2027年全面完成项目前期改造，持续推进土地出让和项目建设，优先安排村民动迁安置房、配套基础设施和公共服务设施建设项目，到2030年基本完成项目开发建设。持续推进剩余城中村规划拔点、整治提升点位相关工作，到2026年底全面完成城中村整治提升，同步推进实施规划拔点。
（二）打造创新人文活力城区
1.推进老旧街区更新改造
推动街区活力提升。依托七宝“两路一园”入选“全国城市更新美丽城镇建设标准化试点”经验，在有条件街镇推进街区更新。推进吴宝路、七宝生态商务区“无障碍街区”建设，实施七宝老街、莘庄老街、虹泉路、永平路、江川路等更新提升。推进剑川路科创街区建设，盘活低效用地，优化路网和公共空间节点。深化古美城市家具建设，形成示范并逐步推广。到2030年，完成5个以上老旧街区改造。
推进美丽街区建设。围绕大零号湾、虹桥国际中央商务区、莘庄副中心等重点区域，打造科创街区、时尚街区、公园街区，融入文化、艺术、历史元素，完善公共服务和休憩设施，提升空间品质与使用体验。重点推进申长路、科创水岸等美丽街区建设，打造富有生活烟火和艺术时尚的闵行江川新地标。
2.推进商务楼宇和商业设施更新提升
分类推进商务楼宇更新。重点推进虹桥国际中央商务区核心区、漕河泾开发区（闵行部分）等商务单元更新，完善监测与需求评估。推进甲级及以上楼宇以“提升品质”为主；乙级及以下楼宇以优化功能为主；园区型楼宇以集聚产业为主，有序推进转型或退出。适时出台区级商务楼宇配套支持政策，动态更新区级商务楼宇政策服务包。到2030年，推动10个以上商务楼宇更新。
推进传统商圈改造升级。加速虹桥国际中央商务区商业迭代，推动虹桥新天地演绎中心等多元消费场景创新升级。聚力提升吴中路、莘庄两大市级商业中心，推动首尔夜市、老外街焕新，推进仲盛世界商城等向年轻化、品质化转型。提升七宝、南方、颛桥、大零号湾等区级商业中心品质。七宝区域推动星钻城、嘉寰广场改造，力争将九星城打造成一站式超级生活城；梅陇区域以锦江乐园哈利·波特项目为核心引擎，联动南方商务区，打造商旅文娱融合区；颛桥区域加快启动砂之船奥特莱斯项目，打造区域特色消费地标；大零号湾区域聚焦科创消费配套升级，推动虹梅南路—永德路商圈提质更新，打造开放式休闲商业街区。力争到2030年，累计完成50万平方米以上商业设施更新。
3.推进产业空间提质增效
推进存量工业用地更新。滚动推进“两评估、一清单、一盘活”专项行动，排摸潜力地块和园区，运用回购、回租、置换、合作开发等方式盘活资源。推进常青工业园、闵行经济技术开发区、闵行老工业基地等提质增效，稳定产业规模，保障重大项目用地。到2030年，累计盘活低效产业用地5000亩。
推动老旧厂区更新转型。优化零星工业用地管理，支持向文创、研发、保障性住房等功能转型，推动工业遗产活化利用。鼓励老旧厂区通过提高用地容积率、实施新改扩建工程实现提质增效，高效保障优质存量工业项目改扩建需求。推动吴泾镇与梅陇镇的战略留白区深度融合，打造闵行民用无人机试飞运行基地和双溪低空基地。积极开展战略预留区内优质项目认定和“零增地”技改评估工作，鼓励相关优质企业改扩建。大力推进莘庄工业区低效工业空间的盘活提升和重点厂区的迭代更新，系统推进商业航天“火箭星城”建设，构建全链条产业生态。到2030年，完成20个以上老旧厂区改造。
4.保护传承城市历史文化
开展历史文化资源评估调查。在既有普查基础上，按“古建筑、近现代重要史迹、古遗址”等分类建档，明确地址、年代、保护范围等信息，实施分级管控；文保单位严格按范围保护，文保点加强日常维护，并在城中村改造、街区更新中优先保护文保资源。
推进历史风貌区保护与活化。统筹七宝古镇、召稼楼老街整体保护与利用，优化业态，培育文化消费；将江川路沿线国营重型装备大厂“四大金刚”等工业遗存纳入保护，推动转型为工业博物馆、科创空间和文创园区；落实“修旧如旧”，推动历史建筑功能置换与公共服务导入。
推进城中村改造与文脉传承协同实施。开展杜行老街风貌重塑、诸翟村“文脉长廊”建设，推进召稼楼“一房一档”工作，保留水乡格局，打造“国风水乡”和耕学社区。
（三）构筑安全韧性生态城区
1.加强城市基础设施建设改造
提升交通设施服务水平。完善“三纵七横一射”高快速路体系，配合推进外环西段抬升、S4奉浦东桥等重大工程建设。织密多层次公交网络，配合推进示范区线、嘉闵线等7条轨交线路建设。加强步行道、自行车道、立体慢行设施建设，推动紫竹地区慢行精品区建设。至2030年，力争路网密度达4.15公里/平方公里。
推进各类市政基础设施改造。在虹桥国际中央商务区、锦江乐园、大零号湾、莘庄枢纽周边开展架空线入地和杆箱整治，推进九星地区、浦业路地下综合管廊项目，推进吴泾发电基地转型配套电网建设。全面推进雨污混接普查整治，持续推进供水、排水系统提标改造，针对性推进以10年为一周期的老龄市政排水管道结构性检测和修复工作。至2027年，完成不少于421公里燃气老化管道改造阶段性目标。
提升环卫市容景观品质。持续推进闵行景观照明建设，加快完善重点区域亮化。推进建设绿色“无废城市”，持续开展垃圾分类提档升级、分类投放设施智能化、友好化改造。
推进韧性安全城市建设。配合黄浦江二期防洪能力提升工程，对32座一线水闸进行防洪能力达标建设。推动市政设施、老旧社区等重点领域物联感知设备全覆盖，优化建立闵行区安全风险地图，将城市韧性安全理念和举措有机融入网格化管理、十五分钟社区生活圈建设和城市更新实践。至2030年，全区应急避难人均避难面积大于1.7平方米。
2.修复城市生态系统
落实市级“一江一河一带”战略。优化生态空间建设运维和功能拓展机制，在黄浦江、大治河、金汇港三水交汇湾区打造“三水八岸、十字水系”格局；在苏州河（吴淞江）区域策应十字象限重要节点建设要求，推动生态空间综合性功能节点跃升。衔接上位规划及周边区域发展需求，统筹吴泾地区污染地块治理修复与项目开发建设一体谋划，助推区域空间科学布局。
加强高品质水岸统筹空间建设。推进浦江郊野公园滨江段和紫竹滨江浦江第一湾岸线贯通；推进科创水街二期、虹桥商务区北横泾环线等滨水空间贯通；建成召稼楼古镇沪派江南村落水环境提升试点。至2030年，美丽幸福河湖建成率达到50%。
打造绿色生态魅力城区。落实“环城生态公园带”建设要求，围绕全市外环绿道主脉贯通工程，适时逐步打通漕宝路等绿道断点，配合推进市级吴淞江凤栖湿地规划建设。至2030年，全区人均公园绿地面积达到11.5平方米，各类公园二十四小时开放比例力争达到90%。
推进海绵城市建设。依托城市更新，在土地出让、项目审批、竣工验收和设施运维全过程落实海绵城市理念，加快推进虹桥前湾、七宝九星地区海绵城市建设。至2030年，全区建成区80%以上面积达到海绵城市建设目标要求。
3.完善城市功能
拓展城市公共空间。争取市级文化设施落地，织密基层文化设施网络，提升公共文化服务效能。实施公共空间文化“微更新”，推进城市家具公园、江川红色文化街区建设，完善黄浦江、北横泾、吴淞江沿线公共服务设施，提升休闲与文化功能。
营造创新创业环境。深化校区、园区、城区“三区联动”，支持上海交通大学扩校发展，通过更新改造打开校园边界，推动企业与科研院所共建科创街区和国际研发社区，形成“5分钟产创生活圈”。
完善公共服务网络。利用闲置用房和空置楼宇补充嵌入式服务设施与保障性住房，优先补齐民生短板；推进适老化、适儿化及无障碍改造，增加普惠托育与养老服务供给；利用桥下、滨水、街旁绿地建设健身设施，推进应急避难场所和医疗应急体系建设。
三、重点片区
（一）虹桥国际中央商务区核心区
强化核心功能，优化业态布局。以研发经济为产业核心定位，依托虹桥国际中央商务区（闵行部分）区位、人才、政策、服务等多维优势，优选虹桥绿谷、富力环球中心、虹桥阿里、虹桥九星商务中心等作为长三角制造业研发集聚区首批建设载体，实现“制造在长三角、研发在大虹桥”的协同联动发展新格局，构建梯度化、系统性产业空间供给体系。聚焦市级土地储备项目收储工作。到2030年，累计完成9个市级土地储备项目收储工作。
加强设施支撑，推进品质提升。推动诺亚财富中心、虹桥丽宝广场、虹桥阿里中心等楼宇功能转型，植入商业酒店、租赁住房等多元混合功能。优化改造西交通平台，植入全球服务、交流展示、科创社区等功能，营造“虹场绿丘”枢纽门户街区。构建三层立体慢行交通系统，推动国家会展中心东侧停车场区域功能焕新，打造“高线飞虹、活力青洲”特色节点。落实区域公园体系建设，加快推进新家弄水系景观工程，统筹布局健康运动、休闲游憩等多元功能，系统构建滨水景观带与林间慢行步道体系。依托北横泾滨水空间打造“水岸秀场”，不断提高公共空间品质。
（二）大零号湾
推动存量空间转型提升。以上海交大、华东师大两所“双一流”高校为核心，加快推进交大闵行北校区未来产业创新区和产教融合攻关区建设。加快推进T轴核心区骄成总部基地项目建设、推动轴承厂地块出让及开工建设。有序推进常青工业园“规储供用”工作，打造常青科创核心、滨江活力核心和江川、沧源等多个科创功能节点，形成多点布局、多类型的科创载体空间。
提升关键节点空间品质。加快“大零号湾”科技创新策源功能区建设，打造生态美丽街区，通过实施北横泾科创水岸一期及沧源科技园区宜良路、宁洱路、罗平路修复养护项目，提升大零号湾核心区域滨水空间品质，打通区域交通微循环，成为宜居、宜业、宜人的开放式园区。
（三）莘庄副中心
打造功能更加集聚的活力副中心。围绕莘庄枢纽，加快天荟TODTOWN项目的建设完成，稳步推进仲盛商圈改造落地，完善北广场交通功能布局，形成高效联动的商业与交通体系。持续推动莘庄商务区的建设与招商工作，打造集多功能现代服务业及企业总部基地于一体的集聚区。友东路片区立足规划实施方案发展目标，保障产业载体，完善配套服务设施，优先启动南马、莘吴地块项目实施，积极开展产业招商等工作。
塑造品质更具特色的宜居副中心。有序推进莘庄老街和莘庄公园等更新改造工作，优化整体空间布局，完善公共服务配套，深入挖掘历史文脉，致力于建设宜居、宜业、宜游的城市环境。推动七莘路沿线更新改造工作，统筹推进沿线重点区域功能置换与品质提升，充分发挥蓝绿生态资源优势，打造业态复合多元、空间品质彰显的城市功能集聚带。
（四）闵行经济开发区产业基地
强化产业引领，打造先进能源装备产业高地。将闵行老工业基地作为产业基地进行长期锁定，重点集聚核电、机电电气为主导的先进制造业。充分发挥上海电气等链主企业的龙头带动作用，加快推进上海电气全链智能化、上重铸锻能级提升等重大项目，推进上重机器厂地块整体转型。
推动空间焕新，加快存量用地转型提效。以“提容增效、腾笼换鸟”为指导思路，加快低效产业用地分类处置与存量载体更新改造。产业基地内产业用地占比保持70%左右，引导低效产业用地减量化和功能置换，优先保障先进能源装备及绿色低碳产业空间需求，推动园区从单一生产功能向生产、研发、服务等多功能复合转型。
（五）黄浦江两岸片区
融入区域格局打造滨江秀带。全力推进黄浦江滨江岸线贯通，构筑“点上成景、线上成廊、网上成荫、面上成林、空间一体”的滨江岸线。持续推进第一湾滨江绿地建设及岸线贯通，加快滨水空间品质提升改造，推进西延伸公园等重点项目建设，结合“大吴泾”专项规划，推动紫竹半岛沿线高品质贯通，强化科创、文化功能。
立足滨水岸带筑牢生态基底。聚焦浦江镇黄浦江中游湾岛片区及大治河生态廊道，推进“山水工程”项目报批和后续建设，统筹推进河湖水网治理、林地效能提升、农田生态整治、岸带韧性提升等工程，增强生态系统韧性，改善地区环境品质。依托郊野公园滨江岸线，规划打造5条精品文旅线路，助力世界级滨江活力带建设。推进吴泾工业区污染土地治理，融合地形营造与植绿造景，系统构建区域生态本底，为长远发展做好空间衔接与生态价值储备。
（六）七宝老街
加强文化传承，推动老街焕新。系统推进七宝老街区域更新，凸显“文化+”特色，打造具有国际范、上海味、时尚潮的国际文旅精品小镇。落实历史文化风貌保护要求，重点保护南北大街、蒲汇塘两侧核心历史肌理，向南延展古镇空间脉络，将四面厅、斗姆阁等文物保护单位纳入一体化保护利用格局。加快实施柳岸街邻城中村改造、镇企路旧改等历史文化风貌区内重点更新项目，充分挖掘历史文化内涵，确保区域风貌协调统一。统筹研究交大置换地块功能定位和空间布局，强化区域产业联动。深入谋划策划老街功能业态提升，联动周边文化公园等文旅资源，推动文商旅展深度融合，激发区域发展新动能。
坚持规划引领，分期有序推进。加快形成1平方公里规划实施方案，重点推进七宝“城中村”项目实施。有序开展柳岸街邻、王家场以及七宝教寺南侧局部地块等3个重点地块土地出让工作，并同步启动南侧交大置换地块控规调整相关研究。推动七宝老街城市更新由“规划蓝图”向“项目落地”转变。
（七）召稼楼古镇
焕新古镇风貌，重塑江南神韵。通过整体改造、文化唤醒、自然融合、商业焕新等策略，形成晓烟湖轻度假、古镇核心、耕学生活三大功能区，打造召楼新天地，形成“产城融合、文旅联动、生态宜居”的现代江南水乡典范。充分依托“国家AAAA级旅游景区”“上海首批历史文化风貌区”的基础，全力推进召稼楼城中村改造项目。全力攻坚动迁清零任务，稳步推进道路、河道等配套建设，加快住宅、商业等经营性地块出让。加强风貌保护研究及文保单位活化利用，加强与革新村和镇域重点区域的功能链接。力争2029年基本建成，进一步提升召稼楼古镇历史文化内涵和整体能级。
（八）锦江乐园及周边区域
加快设施升级，塑造潮流文化新地标。以打造融合影视文化、科技体验、创新研学与多元休闲功能的国际文化体验标杆为目标，推动锦江乐园主题全面升级。重点推进哈利·波特制片厂之旅等项目建设，有序开展文化设施及相关配套工程，充分发挥其世界级文旅IP辐射效应，联动周边院校与产业园区，积极培育影视制作、文化创意等新兴业态，带动周边餐饮、住宿、娱乐及交通等服务功能全面升级，推动区域文商旅协同发展。
