# 关于印发《临港新片区城市体检实施方案（试行）》的通知

关于印发《临港新片区城市体检实施方案（试行）》的通知

沪自贸临管委〔2024〕53号

管委会各部门、各直属单位，临港新片区各镇、各有关单位:

为深入贯彻习近平总书记关于城市体检工作的重要指示批示精神，落实中共中央办公厅、国务院办公厅印发的《关于推动城乡建设绿色发展的意见》要求，按照住房和城乡建设部《关于全面开展城市体检工作的指导意见》（建科〔2023〕75号）及市住建委《关于印发<2024年上海城市体检工作方案>的函》（沪建综规〔2024〕108号）文件精神，临港管委会制定了《临港新片区城市体检实施方案（试行）》，现印发给你们，请认真贯彻执行。

中国（上海）自由贸易试验区临港新片区管理委员会

2024年5月18日

临港新片区城市体检实施方案（试行）

为深入贯彻习近平总书记关于城市体检工作的重要指示批示精神，落实中共中央办公厅、国务院办公厅印发的《关于推动城乡建设绿色发展的意见》要求，按照住房和城乡建设部《关于全面开展城市体检工作的指导意见》（建科〔2023〕75号）及市住建委《关于印发<2024年上海城市体检工作方案>的函》（沪建综规〔2024〕108号）文件精神，临港管委会制定了《临港新片区城市体检实施方案（试行）》，结合临港新片区实际，现制定临港新片区城市体检实施方案（试行）。

一、总体要求

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的二十大精神，完整、准确、全面贯彻新发展理念，扎实推进城市体检工作。深刻认识城市体检工作的重要意义，坚持人民城市人民建、人民城市为人民，坚持问题导向、目标导向、结果导向，把城市体检作为统筹城市规划、建设、管理工作的重要抓手，建立健全“发现问题—解决问题—巩固提升”的城市体检工作机制，整体推动城市结构优化、功能完善、品质提升，打造宜居、韧性、智慧城市。

二、体检范围

按照市住建委提出的“市区持续深化、街镇全面覆盖、社区扩大试点”的原则，聚焦城市建设领域，划细体检单元，覆盖住房、小区（社区）、街区、城区（城市）空间范围，建立新片区、镇、社区三级体检体系，并结合新片区特点开展若干专项体检。

（一）新片区城市体检

以“产城融合区”为体检总范围，并根据管委会承接事权的实际情况划定各项体检范围，把新片区作为“有机生命体”，以“产城融合、功能完备、职住平衡、生态宜居、交通便利、治理高效”为目标，查找影响新城竞争力、承载力和可持续发展的短板弱项。

（二）镇城市体检

结合新片区实际，管委会会同浦东新区和奉贤区每年在浦东新区南汇新城镇（滴水湖核心片区）、书院镇、万祥镇、泥城镇和奉贤区四团镇范围内选取4个试点镇开展城市体检，以镇城市化地区为体检范围，查找群众、企业反映强烈的难点、堵点、痛点问题。

（三）社区城市体检

每个试点镇各选取1-2个社区开展体检试点。试点社区居住人口规模宜为5000-12000人，以居民委员会管辖和服务范围为基础，综合考虑城市道路网、自然地形地貌和现状居住小区等边界，优先选取现状问题短板突出的社区，并兼顾商品房、动迁安置房、公共租赁房等不同住宅类型。

（四）专项体检

结合新片区特色，聚焦重点工作，逐步对城市建设转运营精细化管理、新城产业配套、创新创业之城、数字化城市治理等方面开展专项体检，与城市体检工作做好衔接。

三、工作内容

（一）构建指标体系

按照“可量化、可感知、可评价”的原则，围绕宜居共建、安全韧性、品质更新、绿色低碳、交通便捷、多元共享、精细共治、智慧高效八大维度，形成“新片区—镇—社区”三级体检指标体系。

新片区城市体检结合新片区特色和所处发展阶段，在市级、区级城市体检指标基础上新增体现新片区发展需求和目标的特色指标。

各镇城市体检聚焦百姓关注热点和生活需求，衔接筑巢引凤、产教融合，查找公共服务设施缺口、街镇环境、精细化管理等方面的问题。南汇新城镇（滴水湖核心片区）城市体检突出规划、建设和管理衔接的问题，并在镇级城市体检指标基础上新增体现“最现代、最生态、最便利、最具活力、最具特色”总体导向的特色指标，体现核心区域的综合服务功能。

试点社区城市体检依托社区级城市体检指标，结合完整社区建设、美丽家园建设、活力街区打造、区域化物业管理等，统筹开展住房、小区、社区体检，摸清住房及附属设施存在的安全隐患，找准社区公共服务及配套设施缺口以及环境、管理方面的问题。

专项体检根据体检内容构建特色指标体系，体现新片区发展需求和特色，聚焦近期重点工作等。

（二）采集填报数据

数据采集采用“新片区—镇—社区”三级联动，社区、居民、物业、企业、专业单位等共同参与的方式。新片区、镇、社区可通过部门统计填报、座谈访谈、现场走访踏勘、遥感影像识别、互联网大数据、居民问卷调查和意见征集等方式采集数据。数据主要采用上一年度数据，充分使用上海市公共数据开放平台、房屋建筑和市政设施调查、城市信息模型（CIM）基础平台等已有数据资源。

（三）开展社会问卷调查

新片区、各镇采用市级社会调查问卷，分别组织开展社会满意度调查，组织引导公众积极参与，社区体检应结合现场调研开展居民抽样问卷调查。全面收集整理分析调查数据，常态化引进人民建议征集和市民服务热线数据，编制社会调查报告，为问题病症识别与诊治提供充足的民意支撑。

（四）开展评估分析

对标国际先进城市经验和国家、地方标准规范，结合管委会工作要求、国土空间规划、专项规划，科学确定指标参考值，建立评估参考体系。落实各项指标评估方法，按照定性与定量、主观与客观相结合原则，结合社会调查问卷，对指标开展系统性分类评估。

（五）编制体检报告

新片区管委会、各镇应根据指标评估与问卷调查结果，按照轻重缓急的原则对体检发现的问题进行系统梳理、诊断分析，将问题分为限时解决、尽力解决和长期谋划三类。其中，限时解决类主要是涉及安全、健康以及群众反映强烈的突出问题；尽力解决类主要是涉及难点、堵点，需要跨部门跨层级协同、落实保障措施的问题；长期谋划类主要是实施条件暂不成熟、需进行前瞻性论证研究的问题。针对不同问题分类制定限时整改、持续提升、研究策划等对策措施，形成工程类、管理类、规划研究类项目建议，编制一表三清单（优势清单、问题清单和整治建议清单），形成各级年度城市体检报告。社区城市体检汇总形成体检指标调查表，以社区为单位汇交至镇政府，纳入镇城市体检报告。城市体检报告主要内容包括上一年问题整改情况、本年度体检工作组织与主要成效、数据指标分析、总体评价、对策和行动建议等。新片区、各镇分别汇总本辖区镇和社区体检指标调查表、问题清单、工作特色等，建立问题台账，并选取可空间落图的指标和问题进行可视化表达，形成体检问题地图，台账、图纸等作为城市体检报告的附件。

（六）强化成果应用

新片区管委会、镇政府积极推动城市体检成果应用实践。对限时解决类问题，形成《风险隐患告知书》，明确问题情况、风险等级、可能造成的后果以及整治建议，督促相关责任主体制定整改方案，做到立行立改、限时解决。对尽力解决类问题开展深入研究，坚持尽力而为、量力而行，尽力补齐短板弱项。对长期谋划类问题，开展专项课题研究，衔接相关规划和计划的编制工作。将解决上一年度体检发现问题的情况纳入到本年度的城市体检工作环节中，持续推进问题解决。管委会依据体检报告，聚焦民生短板突出或发展潜力较大的区域，形成重点领域行动建议，制定项目年度实施计划，形成项目储备库，统筹推进城市规划、建设和管理工作。镇及社区层面生成城市更新项目，区分项目轻重缓急，明确具体项目的实施路径和时间安排，针对性实施更新改造。最终体检报告可作为项目立项、资金安排、项目实施的重要依据。

（七）健全信息系统

依托新片区管委会、各镇既有的信息平台，持续完善城市体检数字化应用场景。以临港新片区数字孪生基础平台为底座，推进“新片区—镇—社区”三级体检指标数据汇聚共享。完善数据智能分析模块，实现数据的自动整理计算、生成台账清单及空间落位，探索绘制“城市体检问题地图”。强化与城市管理信息系统和城市体征指标的联动，构建“动态监测—定期体检、评估—查找问题—整治措施—跟踪落实”的在线闭环管理功能。

四、工作保障

（一）加强组织领导

临港新片区按照“管委会统筹、部门协作、属地负责、多元参与”的工作模式，建立新片区、镇、社区三级联动，第三方参与的工作机制。管委会依托城市管理精细化工作领导小组，充分发挥专项联席会议推进机制优势，由各成员部门协同配合，专题推进各领域的城市体检工作。临港新片区管委会协同浦东新区和奉贤区统筹推进镇和社区体检工作，属地镇政府是责任主体，相关工作成果纳入管委会年度考核。

（二）加强资金保障

管委会、各镇按照预算管理有关规定，统筹安排资金，列入年度预算，购买第三方服务，保障城市体检工作质量。管委会负责新片区城市体检和专项体检第三方服务费用，列入建设和交通管理处年度部门预算，其余各镇负责镇、社区城市体检第三方服务费用，列入镇年度预算。加强城市体检与城市更新、生态城区建设、城市精细化管理等专项工作统筹，合理安排各类资金，提高资金使用效益。

（三）加强技术支撑

第三方专业团队全过程参与城市体检工作，包括指标体系构建、数据采集、社会问卷调查、分析诊断、编制城市体检报告等，对报告质量负责。管委会、各镇遴选第三方专业团队承担城市体检工作，依托第三方专业团队定期开展工作宣讲交流，不断提升城市体检工作质量和水平。

（四）加强社会宣传

做好政策解读和舆论引导，畅通公众参与城市规划、建设、管理的渠道，引导公众积极参与。广泛宣传城市体检评估和更新实践中的典型经验、特色亮点、工作成效，提高群众的知晓度、参与度、满意度。

本实施方案自发布之日起试行，有效期三年。
