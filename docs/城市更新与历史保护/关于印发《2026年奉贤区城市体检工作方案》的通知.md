# 关于印发《2026年奉贤区城市体检工作方案》的通知

各相关委办局、各街镇:

为深入贯彻习近平总书记关于城市体检工作的重要指示批示精神，落实住房城乡建设部和上海市住建委对城市体检的工作部署，根据《2026年上海市城市体检工作方案》(沪建综规〔2026〕132号)要求，我委结合本区实际，制定了《2026年奉贤区城市体检工作方案》，现印发给你们，请抓好贯彻落实。

奉贤区建设和管理委委员会

2026年4月27日

2026年奉贤区城市体检工作方案

为深入贯彻习近平总书记关于城市体检工作的重要指示精神，落实中共中央国务院《关于推动城市高质量发展的意见》和上海市《关于高质量建设现代化人民城市的实施意见》要求，根据上海市住房和城乡建设管理委员会《关于开展2026年上海城市体检工作的通知》(沪建综规〔2026〕132号)文件要求，结合本区实际，制定如下方案。

一、工作任务

城市体检分为综合体检和专项体检。综合体检按照市、区、街镇、社区四级体系，深入查找群众急难愁盼问题和影响城市竞争力、承载力、可持续发展的短板弱项。专项体检是对城市建设发展中的有关行业领域和重点区域进行专项分析评价，与年度综合体检统筹部署开展，相关指标数据统一采集、共同使用，避免重复调查，成果纳入综合体检报告。

(一)综合体检

1.区级体检。奉贤区建设和管理委员会统筹开展2026年奉贤区城市体检工作，以奉贤区辖区为体检范围，按照本方案要求负责牵头组织开展区、街镇、社区城市体检和专项体检，力争到2027年实现全覆盖。衔接片区更新、城市管理精细化等工作因地制宜建立特色指标，完善指标体系，开展数据采集、社会调查和分析评价。充分整合专项体检成果，提出问题清单和整治建议清单(含项目建议库)，编制区级综合体检报告，形成本区体检三张地图、指标分析空间图集和矢量数据库。

2.街镇级城市体检。以街道或建制镇建成区范围为基本单元，以街镇为主体开展街镇级体检工作。今年计划在南桥镇、庄行镇、奉城镇、金汇镇开展街镇级体检。聚焦群众关注和实际工作需求，衔接片区更新、城市管理精细化、“15分钟社区生活圈”等工作建立特色指标，开展数据采集和社会调查，排摸存量资源，查找问题短板，建立街镇问题清单和整治建议清单，编制街镇综合体检报告，形成指标分析空间图集和矢量数据库。

3.社区级体检。衔接完整社区建设目标，严格以综合网格为社区体检单元，各街镇本年度体检的社区数量不少于1个。重点选择网格内2000年底前建成的老旧小区和住房作为体检对象，通过现场调研、访谈交流等方式采集数据，形成住房、小区和社区体检调研台账、问题需求清单、整治建议清单。拟开展完整社区建设的社区应将社区体检作为前置条件，深入查找问题短板，充分调研社区未来发展方向和居民实际需求，为完整社区建设提供有力支撑。

(二)专项体检

结合奉贤区2026年重点工作部署，本年度计划开展城市更新和完整社区建设专项体检，并按需组织开展重点更新片区专项体检。

1.城市更新专项体检。根据更新专项体检指标体系，结合本区城市更新专项规划编制需求，开展区级城市更新专项体检，调查排摸全区范围内更新对象和潜力空间资源，分析其总量、分布及基础特征，形成本区更新资源清单、存量资源分布地图及矢量数据库，结合三张地图提出城市更新潜力片区分布图和更新项目建议库，编制区级城市更新专项体检报告。

2.完整社区专项体检。结合本区城市体检工作统一部署，将拟开展完整社区建设的社区纳入社区体检目录，深入查找社区设施、环境、服务、治理等方面短板，充分调研社区未来发展方向和居民实际需求，精准查找问题短板、风险隐患，提出问题清单和整治建议清单，编制完整社区专项体检报告，更好指导后续完整社区建设方案编制。

3.重点更新片区体检。为支撑城市更新片区策划，根据实际需求，组织片区所在街镇或相关统筹主体开展重点更新片区体检，形成重点片区体检报告，推动形成一批可实施性强的更新项目并纳入更新项目库。

二、工作要求

区建设管理委发挥好统筹作用，加强全过程跟踪指导，做好成果质量评价，推动问题整改落实。相关部门和街镇依据职责分工，完成信息采集、数据核查和分报告编制，组织开展相关领域专项体检。

应加强城市更新专项体检与专项规划编制工作统筹，优选第三方技术团队，加强体检培训，推进体检成果应用，推动问题整改与成效监测。

各级城市体检团队应与更新专项规划编制团队建立常态化沟通机制，强化数据共享与校核，协同开展指标体系研究、数据采集调研与分析评价。综合体检团队负责识别问题短板和民生需求，开展上一年度问题整治动态监测，依据城市更新专项体检团队提供的存量资源清单，统筹编制三张地图。城市更新专项体检团队负责梳理存量资源的底图底数，为综合体检及更新专项规划提供基础支撑。与市级专项规划编制和综合体检团队做好相关成果衔接。

三、成果应用和时间安排

(一)成果应用

对于本年度体检发现涉及安全、健康以及群众反映强烈的突出问题，应及时向市、区相关部门报告，并向相关责任主体发送《风险隐患告知书》，做到立行立改、限时解决。综合体检应充分整合城市更新专项体检和重点更新片区体检成果，提出更新潜力片区和项目建议库，作为城市更新专项规划编制、片区策划和城市更新项目储备库入库依据，引导资金、政策等要素精准投放。积极推动体检成果在规划征询、更新项目库管理、城市管理精细化、城市维护项目等领域的拓展应用。

(二)进度安排

各相关单位要加强组织领导，细化工作方案，明确工作重点和任务要求，做好工作经费和技术保障，按时间节点保质保量完成年度城市体检工作。

2026年4月，印发区级体检工作方案，完成工作部署，明确本年度街镇、社区体检范围。

5月31日前，完成各级城市体检，汇交体检报告初稿、数据库与图集，配合校核三张地图、更新潜力片区和更新项目建议等体检成果。

6月30日前，各级城市体检报告经各级人民政府同意并加盖公章后，报送至市住房城乡建设管理委，同步将体检成果转发相关部门和街镇。
