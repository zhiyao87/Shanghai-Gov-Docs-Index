# 上海市住房和城乡建设管理委员会关于公布首届上海市工程勘察设计大师名单的通知

上海市住房和城乡建设管理委员会关于公布首届上海市工程勘察设计大师名单的通知

沪建建管〔2024〕95号

各有关单位：

根据《上海市工程勘察设计大师培育选树管理办法（试行）》（沪建建管〔2022〕579号）和《上海市住房和城乡建设管理委员会关于开展首届上海市工程勘察设计大师培育选树活动的通知》（沪建建管〔2023〕130号），市住建委组织开展了首届上海市工程勘察设计大师培育选树活动。经审定，确定王挥等30名同志进入首届上海市工程勘察设计大师名单，现予公布。

希望本市工程勘察设计行业技术人员深入贯彻落实新发展理念，勇于创新，敢于实践，不断提升本市工程勘察设计水平，为推动行业高质量发展做出更大贡献。
