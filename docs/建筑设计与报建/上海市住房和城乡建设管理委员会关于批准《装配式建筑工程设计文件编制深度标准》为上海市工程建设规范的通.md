# 上海市住房和城乡建设管理委员会关于批准《装配式建筑工程设计文件编制深度标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《装配式建筑工程设计文件编制深度标准》为上海市工程建设规范的通知

沪建标定〔2022〕86号

各有关单位：

由上海市建设工程勘察设计管理事务中心、上海市建工设计研究总院有限公司、上海中森建筑与工程设计顾问有限公司主编的《装配式建筑工程设计文件编制深度标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2349-2022，自2022年7月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市建设工程勘察设计管理事务中心负责解释。

特此通知。

2022年1月29日
