# 上海市住房和城乡建设管理委员会关于公布2025年上海市工程勘察设计大师培育名单的通知

上海市住房和城乡建设管理委员会关于公布2025年上海市工程勘察设计大师培育名单的通知

沪建建管〔2026〕85号

各有关单位：

根据《关于开展2025年上海市工程勘察设计大师培育行动的通知》（沪建建管〔2025〕242号），市住房城乡建设管理委组织开展了2025年上海市工程勘察设计大师培育行动。经审定，石长礼等10名同志入选2025年上海市工程勘察设计大师培育名单，现予公布。

希望本市工程勘察设计行业技术人员深入贯彻落实新发展理念，勇于创新，敢于实践，不断提升本市工程勘察设计水平，为推动行业高质量发展做出更大贡献。
