# 上海市住房和城乡建设管理委员会关于批准《装配式混凝土居住建筑设计标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《装配式混凝土居住建筑设计标准》为上海市工程建设规范的通知

沪建标定〔2025〕613号

各有关单位：

由同济大学主编的《装配式混凝土居住建筑设计标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2071-2025，自2026年6月1日起实施。原《装配整体式混凝土居住建筑设计规程》(DG/TJ08-2071-2016)同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，同济大学负责解释。

特此通知。

2025年12月12日
