# 上海市住房和城乡建设管理委员会关于批准《超低能耗建筑设计标准（公共建筑）》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《超低能耗建筑设计标准（公共建筑）》为上海市工程建设规范的通知

沪建标定〔2025〕227号

各有关单位：

由华东建筑集团股份有限公司、上海建筑设计研究院有限公司主编的《超低能耗建筑设计标准（公共建筑）》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ 08-2466-2025，自2025年10月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，华东建筑集团股份有限公司负责解释。

特此通知。

2025年4月23日
