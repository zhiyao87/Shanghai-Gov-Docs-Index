# 关于印发临港新片区施工许可告知承诺制实施方案（试行）的通知

关于印发《临港新片区施工许可告知承诺制实施方案(试行)》的通知

沪自贸临管委〔2020〕574号

管委会各部门、各直属单位，临港新片区各镇、各开发公司、各有关单位：

为进一步优化临港新片区营商环境，加快推进重大项目建设，根据《国务院办公厅关于全面开展工程建设项目审批制度改革的实施意见》（国办发〔2019〕11号）、《上海市行政审批告知承诺管理办法》（沪府令4号）和《临港新片区工程建设项目审批制度深化改革实施意见（试行）》（沪自贸临管委〔2020〕481号）等文件精神，管委会组织制定了《临港新片区施工许可告知承诺制实施方案（试行）》，现印发给你们，请遵照执行。

中国（上海）自由贸易试验区临港新片区管理委员会

2020年7月30日
