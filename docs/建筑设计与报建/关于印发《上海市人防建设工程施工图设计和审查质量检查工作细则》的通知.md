# 关于印发《上海市人防建设工程施工图设计和审查质量检查工作细则》的通知

关于印发《上海市人防建设工程施工图设计和审查质量检查工作细则》的通知

沪国动规〔2023〕3号

各区国防动员办公室，上海市民防监督管理事务中心，临港新片区管委会民防管理部门，有关单位：

经上海市国防动员办公室2023年第9次主任办公会议审议通过，现将《上海市人防建设工程施工图设计和审查质量检查工作细则》印发你们，请遵照执行。

上海市国防动员办公室

2023年11月29日

上海市人防建设工程施工图设计和审查质量检查工作细则

为贯彻落实《关于做好市人防办“双随机、一公开”工作有关事宜的通知》（沪审改办发〔2016〕125号）工作要求，结合本市建设工程审批改革、“多图联审”等工作，切实履行人防建设工程设计和审查质量事中事后监管责任，依据相关法规和人防建设工程设计、审查质量检查工作的有关要求，制定以下工作细则。

一、检查依据

（一）《国家人民防空办公室印发〈关于建立人民防空行业市场责任主体失信惩戒制度的实施意见（试行）〉的通知》（国人防〔2018〕117号）

（二）《上海市人民政府关于印发〈上海市分类监管管理办法〉的通知》(沪府规〔2018〕13号)

（三）《关于印发〈上海市工程建设项目施工图设计文件“多图联审”管理办法〉的通知》（沪住建规范联〔2018〕9号）（以下简称《“多图联审”管理办法》）等相关文件

（四）《上海市民防行业市场主体信用监管规定（试行）》（沪民防规〔2021〕4号）

（五）《住房和城乡建设部关于修改〈房屋建筑和市政基础设施工程施工图设计文件审查管理办法〉的决定》（中华人民共和国住房和城乡建设部令 第46号）（以下简称《审查管理办法》）

（六）《建设工程勘察设计资质管理规定》（建设部令第160号）（以下简称《资质管理规定》）

二、检查单位

上海市国防动员办公室。

三、具体实施单位

上海市民防监督管理事务中心、经委托授权的管委会。

四、检查对象

人防建设工程施工图设计文件的设计单位和审图机构。

五、检查分类

设计单位和审图机构分别列为A、B、C、D四个类别，实行分类监管。

分类标准：

A类：合格率=100%；

B类：100%>合格率≧60%；

C类：60%>合格率≧30%；责任主体受到检查单位约谈、通告、官网公开；提供虚假材料、隐瞒真实情况；

D类：合格率＜30%；责任主体受到检查单位行政处罚；提供虚假材料、隐瞒真实情况，侵害人防管理秩序和社会公共利益；无审查数据情况。

合格率计算方法见附件（1）

六、检查周期及合格率有效期

（一）以15个自然日为一个检查周期.

（二）每个检查周期的合格率有效期为1个月。

七、检查方式

（一）日常抽查

按一定比例从已经出具《联合审查合格书》的工程中，随机抽取一定数量的工程进行施工图设计文件质量检查。对A、B、C、D类设计单位和审图机构的日常监督检查抽查比例分别为不少于30%、50%、70%和100%。同一个设计单位多个项目抽查顺序根据审图机构合格率由低到高选取。抽查个数计算四舍五入取整。一个检查周期内人防工程项目总数为1的，全数抽查。

（二）重点检查

100%检查市区国动办审批的重要经济目标人防工程、人防骨干工程、执行《上海市二等人员掩蔽所人防工程技术要求规定（试行）》的人防工程、兼顾设防工程、改建、扩建人防工程。

（三）联合检查

与市建设工程勘察设计管理事务中心（以下简称“市勘察设计管理中心”）开展多图联审的联合检查。

与人防安全质量监督部门联动开展设计质量联合检查，每年联动不少于2次。

（四）专项检查

在日常工作中发现的较普遍设计和审查问题，开展针对性、阶段性专项检查。

八、检查内容

（一）日常抽查和重点检查

对设计单位落实人防工程的配建要求，执行国家和上海市人防工程建设相关设计规范、规定等情况进行检查；对审图机构执行人防审查标准和管理规定等情况进行检查。

（二）联合检查

1．与市勘察设计管理中心开展多图联审的联合检查，人防检查内容同上。

2．与人防安全质量监督部门联合检查内容如下：

（1）对日常抽查过程中发现的突出问题对现场施工图进行检查。

（2）对现场施工图出现的重大设计质量问题进行检查。

（3）对现场施工图落实抽查意见的情况进行检查。

（4）对现场施工图内容是否有重大设计变更、重大设计变更是否符合审查流程、重大设计变更内容是否执行国家和上海市人防工程建设相关设计规范、规定等情况进行检查。

（三）专项检查

对人防建设项目施工图设计是否存在影响人防工程防护效能的突出问题进行检查。

九、分类标准与抽查比例调整

（一）当设计单位或审图机构按分类标准连续2个检查周期被评为A类，则后续2个检查周期抽查比例下调为0；后续第三个检查周期按无审查数据情形抽查。

（二）受到检查单位或建设行政管理部门行政执法的设计单位或审图机构，分类标准调整为D类，抽查比例调高至100%，执行简易程序的责任主体连续调高2个检查周期，执行普通程序的责任主体连续调高至失信行为信息修复。

（三）对于在通知日常抽查后超过5个工作日未在联审平台补正资料的设计单位，分类标准调整为D类，抽查比例调高至100%，连续调高有2个检查周期。

以上检查周期均指被调整对象有审查项目的检查周期。

十、检查程序

由检查单位根据所要检查工程的特点，从《上海市人防建设工程设计技术专家库》中抽取专家，与检查工作人员组成检查组。

（一）检查组依据有关规范、标准及文件规定对被抽查的施工图设计文件进行检查或工程实地检查，并形成书面意见，经审核后将检查意见书反馈给相对人，要求其限期整改。

（二）被检查单位应限期整改并回复整改报告，检查单位对其整改情况进行复核，直至整改完成。

（三）专家与被检查单位有利害关系的，应遵循回避原则。

十一、检查处理

（一）检查对象有下列情形之一的，检查单位对其采取约谈等行政措施：

1．1个自然年内2次及以上被执行第九条第三款的。

2．未在规定时间内落实整改并回复检查意见的。

3．检查过程中存在问题较多的。

4．1个自然年内累计漏报2项人防建设工程审查项目信息的（每月3日、18日为上报日期，节假日顺延至上班第一天，超过该上报日期视为漏报）。

5.1个自然年内累计2次漏报人防建设工程重大设计变更信息的（每次人防重大设计变更审查合格后3个工作日内为上报时限）。

（二）设计单位有下列情形之一的，移送市住房城乡建设管理委依法处理：

1．确认有情节较严重的失信行为，且一个自然年内受到检查单位普通程序执法3次及以上的，依法将产生的信用信息纳入本市建筑市场信用评价。

2．违反《资质管理规定》第十七条有关情形之一的。

（三）审图机构审查完毕后，人防工程施工图仍存在影响重大安全隐患的，检查单位将视情节轻重暂停或取消委托该施工图审查机构的审查资格。

十二、信息公开

（一）分类结果和抽查比例按照上一检查周期的合格率确定，并通过市国动办网站每月（季度）向社会发布，公告样式见附件（2）。

（二）联合检查、专项检查结果不定期通过市国动办网站向社会发布。

十三、检查档案管理

日常抽查、重点检查、联合检查和专项检查记录应形成书面材料，及时装订成册归档。

十四、施行时间

本细则自2024年1月1日起施行，有效期至2028年12月31日。自施行之日起，《上海市人防建设工程施工图设计和审查质量检查工作细则（试行）》（沪民防〔2020〕117号）同时废止。
