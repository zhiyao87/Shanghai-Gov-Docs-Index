# 关于印发修订后的《临港新片区工程渣土处置实施办法》的通知

关于印发修订后的《临港新片区工程渣土处置实施办法》的通知

沪自贸临管委〔2022〕101号

管委会各部门、各直属单位，临港新片区各镇、各开发公司、各有关单位:

根据《上海市市容环境卫生管理条例》、《上海市建筑垃圾处理管理规定》、《临港新片区建筑垃圾处置管理办法（试行）》，为进一步规范临港新片区工程渣土收集、运输、消纳等处置活动，以建设“无废城市”为新起点，围绕法制化、标准化、智能化、社会化的要求，持续提高工程渣土综合利用水平，临港新片区管委会对《临港新片区工程渣土处置实施办法》进行了修订，现印发给你们，请遵照执行。

2020年 10月 27日印发的《临港新片区工程渣土处置实施办法》（沪自贸临管委〔2020〕869号）同时废止。

特此通知。

中国（上海）自由贸易试验区临港新片区管理委员会

2022年9月14日

临港新片区工程渣土处置实施办法

为切实加强临港新片区工程渣土处置管理，围绕法制化、标准化、智能化、社会化的要求，提升城市市容和环境卫生，改善人居环境，根据《上海市市容环境卫生管理条例》、《上海市建筑垃圾处理管理规定》、《临港新片区建筑垃圾处置管理办法（试行）》等有关规定，修订本实施办法。

第一条  加强组织领导

建立临港新片区工程渣土处置工作领导小组，由临港新片区管委会分管副主任任组长。领导小组下设办公室（设在生态处），发挥统筹协调作用，牵头规资处、建交处、应急处、综合执法大队、规土中心、公安处等相关职能部门及各相关镇落实各项职责要求。

第二条  适用范围

本办法适用于临港新片区（431KM2）行政区域内工程渣土处置活动。

工程渣土是指建设工程的新建、改建、扩建、修缮或者拆除等过程中，产生的弃土、弃料和其他废弃物。

第三条  处置原则

（一）各镇辖区范围内产生的工程渣土处置应遵循规划布点先行，生态绿地优先，环境质量注重，内部自行平衡的原则，除优质绿化土外，工程渣土只出不进。

（二）生态建设空间通过完善建设规划标高、堆坡造景、低洼填平等就地利用方式，对工程渣土进行科学合理的综合利用。由生态处牵头，规资处、规土中心、各镇协同配合，以规划引领，做好生态空间的开发建设。

（三）规划建设用地应结合城市建设的区域定位，做有利于建设的标高抬升。规资处、建交处、生态处应系统考虑区域开发、市政配套、防汛排涝等因素，进一步提高工程渣土的减量化、资源化水平。

第四条  管理部门和职责

（一）生态处：履行工程渣土主管部门职责，加强与市绿容局的业务对接，组织协调相关部门开展联合检查和执法。

具体负责工程渣土排放、运输、中转和消纳的日常监管工作。切实落实建设单位的主体责任，优化政务服务，创新和加强事中事后综合监管能力，促进临港新片区工程建设项目的高质量发展。

牵头构建工程渣土综合管理平台，围绕法制化、标准化、智能化、社会化的要求，为临港工程渣土全覆盖、全过程、全天候监管提供数据和信息支撑。

负责对新开河道、水体等水域开挖项目加强施工组织设计的审核力度，明确渣土外运和回填方案，避免长距离土方运输，做好进出渣土计划和时间节点安排。

（二）建交处：牵头协调工程渣土相关工作，做有利于城市建设的标高抬升，核发施工许可证时加强施工组织设计的审核力度。负责建筑工地的监督管理，监督施工现场工程渣土的规范装运；督促建设单位、施工单位委托规范运输单位和运输车辆处置建筑渣土，督促施工单位加强工地现场工程渣土处置管理；参加工程渣土运输专项执法检查。

（三）规资处：负责指导各镇开展渣土处置临时消纳场所的规划布局，协同生态处做好消纳场所空间规划比对工作。

（四）应急处：负责渣土综合管理平台的运行，充分发挥“一网统管”城市运行平台作用，协同执法部门做好渣土收、运、处全覆盖，全过程、全天候的“一网管、一网防”。

（五）规土中心：负责加强未开发利用土地的日常监管。工程渣土处置消纳过程中，协同生态处及各镇做好生态建设空间土地的临时移交与接管工作；结合土地收储管理，做好收储规划与建设用地土地平整计划方案的制定和实施。

（六）综合执法大队：负责对违反《上海市建筑垃圾和工程渣土处置管理规定》的建设单位、运输单位和消纳场所管理单位进行处罚；严防偷倒、乱倒行为，对擅自倾倒、堆放、处置工程渣土的行为进行处罚；对无证运输、未按路线运输、未密闭运输、车容不洁、造成道路污染的工程渣土车辆进行处罚。

（七）公安处（交警）：负责审核工程渣土运输车辆运输时间、线路，对道路交通秩序实施管理，对车辆超速、超载、牌照污损等进行处罚；协同生态处和综合执法大队开展调查取证，对伪造、变造国家机关公文、证件、印章的行为，依据相关法律法规进行处罚。

（八）属地镇：属地镇是镇域内工程渣土排放处置和综合利用管理的责任主体，应根据郊野单元规划，因地制宜，通过全域土地整理，高标准农田建设，乡村振兴建设，实现镇域渣土处置平衡；属地镇应通过工程渣土综合管理平台的信息推送，结合日常巡查，加强未开发利用土地的管理力度，实现工程渣土全覆盖、全过程、全天候监管。

第五条  建设单位责任

（一）建设单位在编制建设工程概算、预算时，应当专门列支建设工程渣土的运输费和处置费；

（二）建设单位应当在取得工程渣土运输许可证的运输单位中，选择具体的承运单位；

（三）建设工程渣土的运输费、处置费由建设单位分别与运输单位和消纳场所管理单位协商确定，并在运输合同、处置合同中予以明确；

（四）建设单位在申报工程渣土行政许可证时，必须正确预估出土的数量。根据《上海市建筑垃圾处理管理规定》的要求，确保实际开挖后的工程渣土外运总量不超过申报核定数量的15%；

（五）建设单位应当按照建交处、生态处的相关规定，加强工地文明施工管理。建设工程施工现场堆放工程渣土的，堆放高度应当低于围挡高度，并应对其进行覆盖，且不得影响基坑、周边建筑物、构筑物和各类管线、设施的安全，不得长期堆放。涉及渣土外运的施工现场，应在工地大门内设置车辆过水池、冲水及电子三联单系统，若未落实即停运整改；

（六）建设单位应当在工程渣土处置前，请第三方机构出具相应的检测报告，确保工程渣土符合相关指标参数；

（七）建设单位应该建立工程渣土处置的台账。

第六条  运输单位责任

（一）建设工程渣土的运输单位必须依法取得本市绿化市容行政管理部门核发的建筑垃圾运输许可证；

（二）运输车辆须取得行政审批部门核发的建筑垃圾处置证；

（三）运输单位应当安排管理人员对施工现场运输车辆作业进行监督管理，并按照渣土运输的规范要求，做好车辆密闭启运、装卸点清洗、按线路运输、车容车貌整洁;保证运输车辆安装的电子信息装置等设备正常、规范使用,对违规摘除电子信息装置进行违法作业的,将根据黑名单管理制度予以警告或纳入黑名单。

第七条  消纳场所管理单位责任

（一）负责提供消纳场所的土壤检测报告，确保消纳场所符合相关控制指标及参数要求；

（二）有符合消纳、资源化利用和分拣需要的机械设备和照明、消防等设施；

（三）有符合规定的围挡和经过硬化处理的出入口道路；

（四）有与消纳、资源化利用和分拣规模相适应的堆放、作业场地；

（五）在出口处设置车辆冲洗的专用场地，配备运输车辆冲洗保洁设施，落实单子三联单系统。

（六）应该建立工程渣土处置的台账。

（七）消纳点管理单位如违规吸纳外来工程渣土，即取消管理资格。

第八条  强化日常管理

（一）强化企业主体责任。建立建设单位、运输单位、消纳场所管理单位工程渣土管理考核制度，建设单位考核结果交由建交处管理使用；运输单位、消纳场所管理单位考核结果交由生态处管理使用。建立企业诚信档案系统，各相关部门要共同完善、充分应用诚信档案系统，将记分结果与企业评优评级、招投标等挂钩，通过工程渣土领导小组办公室联席会议制度落实市场退出机制和黑名单制度。

（二）落实政府监管责任。监察部门要加强监督，对于懒政怠政、滥用职权、玩忽职守、徇私舞弊的行业管理部门的直接责任人员和其他责任人员依法给予行政处分，构成犯罪的，依法追究刑事责任。

（三）完善市场运行机制。生态处负责建立工程渣土供需对接机制。将施工方案评审和建设工程申报的进出土时间、数量、种类等信息与消纳场所、储运能力等信息一并纳入信息综合管理平台，充分发挥信息系统对出土、运土及填土等市场资源的整合作用，促进产生和消纳的有效衔接，提高综合利用水平。

（四）建立信息通报制度。各部门和各镇落实分管领导和联络员，对管理上碰到的问题及时进行沟通。建立通报机制，对在申报数量、施工、运输、处置等过程中存在的问题进行及时通报。建立例会制度，每月召开一次管理部门工作例会和运输企业工作例会。
