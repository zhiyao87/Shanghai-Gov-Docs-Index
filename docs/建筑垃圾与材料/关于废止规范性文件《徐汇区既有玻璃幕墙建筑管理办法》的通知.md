# 关于废止规范性文件《徐汇区既有玻璃幕墙建筑管理办法》的通知

根据《上海市行政规范性文件管理规定》相关要求，经研究，现决定对《徐汇区既有玻璃幕墙建筑管理办法》(徐建规〔2021〕1号)予以废止，废止文件自本通知印发之日起停止执行。

上海市徐汇区建设和管理委员会

2025年2月7日
