# 关于进一步规范吴泾镇建筑垃圾治理的通知

闵吴府发〔2021〕3号

关于进一步规范吴泾镇建筑垃圾治理的通知

为进一步规范吴泾镇建筑垃圾的收集、运输和处置管理，打击违法违规处置行为，深化我镇建筑垃圾从源头到末端的全程管控，提高城市管理精细化水平，根据《中华人民共和国固体废物污染环境防治法》《上海市建筑垃圾处理管理规定》（政府令第57号）《关于进一步规范本市拆房（拆违）垃圾和装修垃圾收运处置工作的通知》（沪建城管联〔2017〕420号）《关于进一步规范住宅小区装修垃圾清运相关行为的通知》（沪绿容规〔2018〕5号）《关于进一步加强建筑垃圾全程管理严厉打击违法违规处置行为的通知》（沪绿容〔2020〕372号）等法律法规和文件规定，结合我镇实际，现将建筑垃圾全程管理相关事项，通知如下：

一、工作目标

着力完善建筑垃圾全程分类处置体系，进一步规范建筑垃圾收集、运输、中转、分拣、消纳等处置活动，实现建筑垃圾资源化利用和无害化处置。不断提高建筑垃圾精细化管理水平，坚持依法管理、闭环管理、协同治理，依托城市运行“一网统管”，强化源头管控、强化过程控制、强化常态管理。严厉打击建筑垃圾违法违规处置行为，综合运用多种手段，坚决遏制违法违规行为，形成联合监管、严管重罚的高压态势，实现我镇的建筑垃圾收集与处置全量申报和全程监管，不断优化城市环境，提升城市品质。

二、职责分工

（一）城运中心：负责建筑垃圾处理的监督管理，加强与上级行业主管部门的业务对接，做好建筑垃圾源头的申报备案工作，对辖区内的中转分拣场所加强日常监管，强化建筑垃圾治理工作的宣传告知。同时将违规运输、处置建筑垃圾纳入网格巡查范围，加强对擅自倾倒堆放建筑垃圾的行为，堆积建筑垃圾的现象进行排查，发现后及时进行平台流转处置。督促街区物业公司加强店铺装修、装潢垃圾及门责零星工程施工垃圾的监管，督促施工单位主动向城运中心申报，并与吴泾镇主体运输企业签订清运协议。

（二）规建办：负责督促工程建设单位积极履行建设工程垃圾处置申报主体责任；督促工程建设单位委托获得建筑垃圾运输许可的运输单位进行运输；督促工程建设单位在办理工程施工许可或工程备案手续前，向镇城运中心同步备案并向区绿化市容行政管理部门提交建设工程垃圾处置计划、运输合同、处置合同和运输费、处置费列支信息，申请核发处置证。

（三）社区办：负责协调各居委会、业委会等参与建筑垃圾治理工作。做好小区建筑垃圾规范管理的宣传告知，加强对小区建筑垃圾的检查和监管，并纳入对小区综合考评。要求每个小区设置建筑垃圾临时堆放点，建筑垃圾与生活垃圾必须分开堆放，不混装。

（四）房管办：负责协调各小区和规模租赁场所的物业公司参与建筑垃圾治理工作。加强对物业公司关于装修垃圾规范管理的宣传告知，督促物业服务企业履行装修垃圾投放管理责任人义务，与镇装修垃圾主体运输企业签订合同，并就物业公司的履职情况进行考核。督促小区物业公司负责设置居住区内建筑垃圾及大件垃圾临时堆放点，使建筑装修垃圾、大件垃圾与生活垃圾分开堆放、不混装;及时向居民发放建筑装修垃圾处置告知书,并做好居民装修申报备案工作，同时和吴泾镇主体运输企业签订委托协议，做好小区装修垃圾清运处置费用的代收工作。

（五）动迁办：负责对拆房垃圾的监管，规范拆房垃圾堆放；督促拆房公司积极履行拆房工程垃圾处置申报主体责任；督促拆房公司委托获得建筑垃圾运输许可的运输单位进行运输；督促拆房公司在办理拆除工程备案手续时同步向镇城运中心备案并向区绿化市容行政管理部门提交建设工程垃圾处置计划、运输合同、处置合同和运输费、处置费列支信息，申请核发处置证。

（六）拆违办：负责对拆违垃圾的监管，规范拆违垃圾堆放，督促施工单位主动申报拆违垃圾，并委托经核准具有从事建筑垃圾运输资质的单位进行清运并规范消纳。

（七）环卫公司：负责居住区及街面无主垃圾的规范收运工作，并做好清运台账;同时配合做好对建筑装修垃圾和无主垃圾收集、中转和消纳的全过程监管工作。

（八）城管执法中队：负责依法对建筑垃圾产生者委托未取得建筑垃圾运输许可证的单位运输；运输单位承运未取得处置证的单位产生的建筑垃圾，以及擅自倾倒、堆放、处置建筑垃圾等违法行为实施行政处罚。

（九）吴泾、塘湾派出所：负责建筑垃圾运输车辆行驶路线的核定，以及涉及交通方面的违规运输行为的查处，积极开展货运车辆超限运输整治工作，从严处罚超限自卸货运车辆。

（十）各村：负责在镇政府及行业管理部门的指导下，做好村辖区内建筑垃圾及无主垃圾处理的源头管理、规范运输处置等，以及协同配合工作，将建筑装修垃圾、无主垃圾处理管理工作所需经费，纳入村内预算。同时，各村在村域范围内不得设置经营性垃圾中转或分拣场所。

三、主要任务

（一）强化源头管控

健全事前申报制度，凡在吴泾镇辖区内产生建筑装修垃圾的单位和个人均应按照规定申报建筑垃圾处置计划，并办理相关登记备案手续。

1.居住区建筑装修垃圾申报单位为物业公司，清运单位为吴泾镇主体清运单位，由居委、物业公司落实前端管理，具体工作如下：

（1）物业公司要及时对小区内装修户主发送建筑装修垃圾处置告知书，要求居民在装修前至物业办理相关登记手续，装饰装修等产生的建筑装修垃圾做到袋装化。

（2）居委、物业公司要加强小区内环境卫生巡查，物业公司对每天产生的建筑装潢垃圾做好临时围挡或收集至建筑垃圾临时堆放点，并及时将建筑装修垃圾的数量、临时堆放地点申报至吴泾镇清运主体单位。

（3）督促主体清运单位做到及时清运、日产日清，并落实专人负责统计清运的建筑装修垃圾数量，并签字确认，确保台账清晰完整。

2.沿街商铺、商业综合体的建筑垃圾申报单位为经营户、商业综合体管理方，由街面网格负责前端管理，具体工作如下：

（1）由街面网格对街面开展巡查，对出现装饰装修的店家及时发送建筑装修垃圾处置告知书，督促业主及时到镇城运中心备案并与清运主体企业签订协议，同时将产生的装修垃圾有序堆放至临时堆放点，及时通知清运公司清运建筑装修垃圾，保持街面干净整洁。

（2）督促主体清运单位做到及时清运、日产日清，督促业主做好清运的建筑装修垃圾数量统计，并签字确认，保留相关台账。

3.各类建设工程、拆房工程、单位装修工程所产生建设工程垃圾的申报单位为建设单位，相关行业职能部门负责告知，具体工作如下：

（1）各业主单位在办理工程施工许可证或者拆除工程备案手续前，应当向区绿容局提交建设工程垃圾处置计划、运输合同、处置合同和运输费、处置费列支信息，申请核发处置证并至镇城运中心备案。

（2）建设单位应当在取得建筑垃圾运输许可证的运输单位中选择承运单位。

（3）镇内各机关、企事业单位、社会团体等单位的办公和经营场所产生的装修垃圾应当由装修垃圾投放管理责任人交由吴泾镇装修垃圾清运主体企业进行清运，并至镇城运中心备案。

（二）规范收运处置

我镇将从全区范围内有资质的清运企业内，通过比选，择优确定二家清运企业作为建筑垃圾主体清运单位，清运单位必须统一车辆颜色、标示、编队等明显特征，人员应着统一工作服。清运车辆应当加装GPS装置，并与城运中心平台进行信息数据对接。清运车辆的增加或减少报镇城运中心备案。

吴泾镇辖区范围内产生的建筑装修垃圾及无主垃圾由主体清运单位统一进行收运，不得交给个人或者其他无资质运输单位清运。主体清运单位必须与申请人签订建筑垃圾清运协议，并严格按照规定和上级要求，做好建筑装修垃圾末端处置渠道流量流向的申报并提供有效的消纳证明，无主垃圾须运输至吴泾镇建筑垃圾临时中转站进行分拣处置。分拣残渣，运至市、区绿化市容部门规定的处置设施进行资源化利用或无害化处置，进入市属处置设施消纳的残渣处置费用纳入生活垃圾处置费结算渠道。

镇城运中心会同规建办、动迁办、房管办等行业主管部门监督、指导建筑垃圾产生单位落实分类处理规定，对工程渣土、泥浆、建筑废弃混凝土实施分类收集、运输，将其它建设工程垃圾、装修垃圾按照砖石类、木质类、金属类、玻璃类和残渣五个类别进行分类收集、运输。

镇城运中心、环卫公司须加强对建筑垃圾中转分拣站的监督管理，进站的建筑垃圾及无主垃圾落实称重计量、消纳结算，对进入中转站的运输车辆以及收纳数量等情况进行记录，按照消纳数量结算处置费，确保建筑垃圾和无主垃圾流量流向清晰。

（三）公开收费信息

吴泾镇装修垃圾清运收费参照《上海市闵行区装修垃圾清运处置费成本分析报告》计价方式及标准，零星建筑垃圾及无主垃圾清运收费标准参照装修垃圾清运收费标准执行。

规建办须督促实施施工许可（备案）管理的各项目工地建立建设工程垃圾排放公示制度，在施工现场显著位置公示建设工程垃圾排放种类及数量，充分发挥社会监督作用。

房管办须督促物业服务企业在物业管理区域公布装修垃圾清运收费价格信息、投放规范、投放时间、监督投诉方式等事项。

（四）严格监督执法

镇城运中心、规建办、动迁办、房管办、城管执法中队、派出所等相关部门应当各尽其责，加大对建筑垃圾违法违规处置行为的监督执法力度，实施联合惩戒，将涉嫌污染环境犯罪的案件或线索移送公安部门立案查处。

四、工作保障

（一）加强组织领导，抓好责任落实。要充分认识建筑垃圾处理对于确保城市稳定运行、改善人居环境的重要意义， 严厉打击建筑垃圾偷乱倒行为，坚决预防建筑垃圾违法跨省处置案件发生。要努力践行“人民城市人民建，人民城市为人民”重要理念，深入贯彻落实《固废法》等相关法律、法规、规章，落实各有关部门工作职责，规建办、动迁办、城运中心、城管中队、房管办、派出所等部门要建立信息共享、联合检查、联合执法等工作机制，建立顺畅的信息沟通机制，形成工作合力，确保建筑装修垃圾及无主垃圾收运处置工作的各项管理措施落实到位。

（二）加强社区宣传，强化物业责任。社区办、房管办、各居委、村委要充分利用多种载体、采取多种形式，加大宣传工作力度，引导单位和个人自觉配合建筑装潢垃圾申报和有偿收运工作。

（三）严格收费标准，实施托底保障。按照“谁产生，谁付费”的原则，严格执行核定的收费标准。

（四）完善监督机制，推行考核问责。加强行政效能督察，对建筑垃圾、无主垃圾管理中相互推诿、工作落实不力的单位和个人，予以问责。
