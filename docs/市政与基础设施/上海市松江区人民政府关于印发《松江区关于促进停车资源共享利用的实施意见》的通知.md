# 上海市松江区人民政府关于印发《松江区关于促进停车资源共享利用的实施意见》的通知

各镇人民政府、街道办事处，区政府各部门：

经区政府研究，现将《松江区关于促进停车资源共享利用的实施意见》印发给你们，请遵照执行。

2017年7月26日

松江区关于促进停车资源

共享利用的实施意见

为贯彻落实《上海市人民政府办公厅关于印发2017年市政府要完成的与人民生活密切相关的实事的通知》有关要求和工作部署，确保及时、较好地完成“创建50个停车资源共享利用示范项目”的工作目标，根据《上海市停车场（库）管理办法》（沪府令第85号）、市交通委等七部门《关于促进本市停车资源共享利用的指导意见》（沪交财〔2016〕1059号）、市静态交通管理领导小组办公室《关于做好2017年停车资源共享利用示范项目创建工作的通知》（沪静交领办〔2017〕1号）等相关规定及要求，特制定本实施意见：

一、总体要求

（一）指导思想

以“创新、协调、绿色、共享、开放”为理念，以提升停车资源集约利用效率、实现停车规范有序为目标，以本市公共停车信息平台为技术支撑，以加强本区住宅小区综合治理、道路交通违法行为大整治以及停车综合治理为契机，努力构建政府引导、市场运作、社会参与、个人自律四位一体和良性互动的停车共享工作格局。

（二）基本原则

一是加强领导、合力推进。充分发挥政府部门在停车共享工作中的领导作用，建立“条块结合、以块为主”“政府部门指导部署、街镇具体实施”的工作推进模式，组织和引导停车供需双方及社会第三方停车经营服务企业（以下简称“第三方企业”）等社会各方积极参与共治，按照“统一指导、属地推动、因地制宜、协商确定”的工作原则，建立多方协同推进机制。

二是市场运作、专业服务。鼓励由街镇会同有关第三方企业作为实施主体，统筹停车资源供需关系，搭建停车供需平台，组织签署合作协议，具体由第三方企业开展停车共享经营服务，并做好跟踪协调服务工作。

三是规范有序、信息支撑。支持有关第三方企业利用本市公共停车信息平台开展停车共享经营服务，统计对接停车供需双方服务和使用信息，鼓励供需双方按照有关协议约定规范服务和有序停车。

四是自愿为主、政府鼓励。鼓励停车资源供给方在能够保障自身生产经营秩序和安全的前提下对外开放停车资源，鼓励停车资源需求方通过街镇及第三方企业对接使用周边停车资源。

二、工作目标

坚持以人为本理念，在最大限度挖潜利用住宅小区、医院、学校等内部停车资源的前提下，充分挖掘周边公共、专用、道路等各类停车资源，形成“内外联动、错时共享”的停车资源共享利用格局，切实优化停车资源配置，有效缓解重点区域停车供需矛盾，实现停车规范有序。

三、工作内容

（一）主要任务

1．重点针对住宅小区、医院、学校等停车需求，优先考虑挖掘利用在周边步行距离300-500米范围内的公共、专用、道路等各类停车资源，引导居民、患者、学生家长等将所乘车辆错时或临时停放。

2．鼓励进一步挖掘利用距离目的地较远、换乘公共交通便利的大型停车设施集中停车，并探索在集中停车点和目的地之间开行接驳巴士。

（二）管理要求

1．在住宅小区、医院、学校等停车矛盾突出的区域，周边经营性公共停车场（库）原则上应全天开放。

2．有关政府机关、医院和普通高等学校等事业单位、国有企业等在保障内部安全和秩序的前提下，应将内部停车设施错时对外开放，率先落实停车共享责任。

3．鼓励商业、办公等建筑配建的停车设施办理经营备案手续，对外提供错时或临时停车服务，其中按照规划要求配套增建的公共停车泊位，应按照有关要求全部对外开放，不得自行占用。

4．停车矛盾突出的住宅小区周边道路具备夜间停车条件的，由街镇牵头协调公安、交通、居委会、小区业主委员会以及物业服务企业、道路停车管理单位等有关部门和单位，落实停放管理制度，编制初步方案，并履行本市道路停车场设置、审核程序申报批准后，可以按照本市道路停车场包月停放管理的相关规定实施。

5．根据业主大会决议，全体业主共有的住宅小区内部停车设施可向周边错时开放，提供临时停车服务。

四、职责分工

（一）区交通委

1．制定有关具体操作流程，建立区域停车资源共享利用协调制度，建立定期沟通会商机制。

2．制定年度目标，负责对停车资源共享利用工作的协调推进和监督指导，对各街镇停车设施共享利用工作进行年度考核。

3．调研公共、专用、道路等各类停车资源供给状况。

4．根据政府采购的相关规定和要求，确定有关第三方企业，配合街镇建立停车共享协商机制，对接停车共享供需双方。

5．全面梳理本区矛盾突出区域，协调周边停车资源，按照“一点一方案”的要求，指导街镇制定停车资源共享实施计划，明确总体任务和时间节点。

（二）区公安分局

调研道路停车资源供给状况，结合停车矛盾突出区域实际，指导制定周边道路停车设定方案。

（三）区卫计委

全面梳理矛盾突出的医院停车需求状况，协调推动医院在保障内部安全和秩序的前提下错时对外开放内部停车设施，率先落实停车共享责任。

（四）区住房保障和房屋管理局

全面梳理矛盾突出的住宅小区停车需求状况，协调推动住宅小区在保障内部安全和秩序的前提下错时对外开放内部停车设施，率先落实停车共享责任。

（五）区教育局

全面梳理矛盾突出的学校停车需求状况，协调推动高等学校在保障内部安全和秩序的前提下错时对外开放内部停车设施，率先落实停车共享责任。

（六）区机管局

协调推动有关政府机关及相关事业单位在保障内部安全和秩序的前提下，应将内部停车设施错时对外开放，率先落实停车共享责任。

（七）区国资委

协调推动有关国有企业等在保障内部安全和秩序的前提下，应将内部停车设施错时对外开放，率先落实停车共享责任。

（八）区财政局

指导开展本区停车共享工作第三方企业的政府采购工作，配合制订相关的支持政策，切实加强资金保障和使用监管。

（九）相关街镇

负责具体开展本区域停车共享实施工作，会同有关第三方企业和相关住宅小区居民委员会、业主委员会、物业服务企业以及周边相关停车资源供给方，联合制定本区域停车资源共享方案，组织第三方企业与相关停车资源供给方和居民签署停车共享三方协议，监督相关工作落实。

五、保障措施

（一）加强组织领导

成立我区停车共享专项工作领导小组，负责组织、指导、研究、协调、管理、推进、监督全区停车共享工作。由区委常委、副区长于宁同志担任组长，区府办、交通委、财政局、公安分局、卫计委、房管局、教育局、机管局、国资委以及各相关街镇行政主要负责同志为成员，区政府相关部门、相关街镇要落实工作部门，定人定责，确保停车共享工作任务落实执行到位。

（二）开展监督检查

领导小组下设推进办公室，设在区交通委，区交通委行政主要领导为办公室主任，分管领导为副主任，区各相关部门及、相关街镇分管领导、实施单位相关负责人为办公室成员。领导小组办公室负责建立健全专项监督检查制度，开展对停车共享具体开展情况，采取多种检查方式，全面进行督促检查，确保停车共享工作任务落实执行到位。

（三）强化社会监督

建立全方位多渠道投诉处理机制，充分发挥人大、政协、新闻媒体和群众监督的作用，组织开展社会评议，确保停车共享工作真正发挥效果，有效缓解停车矛盾。
