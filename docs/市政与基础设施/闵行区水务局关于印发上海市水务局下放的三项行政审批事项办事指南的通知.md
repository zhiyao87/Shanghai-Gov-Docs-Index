# 闵行区水务局关于印发上海市水务局下放的三项行政审批事项办事指南的通知

闵水务〔2022〕39号

签发人：陆彬文

局机关各科室、相关直属单位：
根据《上海市人民政府关于下放一批行政审批事项的决定》（沪府规〔2022〕1号），“市管河道管理范围内建设项目施工方案的审核”、“市管河道管理范围内树木迁移的审批”和“区管国家基本水文测站上下游建设影响水文监测工程的审批”这3项事项，上海市水务局将行政审批权限下放至各区水务部门。根据《上海市推进政府职能转变和行政审批制度改革领导小组办公室关于进一步做好沪府规〔2022〕1号文件贯彻落实工作的通知》（沪审改办发〔2022〕3号）精神，我局对扩大权限的“河道管理范围内建设项目施工方案的审核”、“河道管理范围内树木迁移的审批”2项行政审批事项修订了办事指南，对新增的“国家基本水文测站上下游建设影响水文监测工程的审批”事项编制了办事指南，并经局办公会议审议通过。现予印发，自2022年8月6日起施行，请各相关科室、单位遵照执行。
特此通知。

附件：1.“河道管理范围内建设项目施工方案的审核办事指南
2.“河道管理范围内树木迁移的审批”办事指南
3.“国家基本水文测站上下游建设影响水文监测工程的审批”办事指南

上海市闵行区水务局
2022年8月5日
