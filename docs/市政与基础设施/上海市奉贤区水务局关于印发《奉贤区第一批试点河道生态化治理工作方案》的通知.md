# 上海市奉贤区水务局关于印发《奉贤区第一批试点河道生态化治理工作方案》的通知

各镇人民政府、街道办事处、旅游区管委会：

为深入贯彻落实河长制，加快提升全区水生态环境品质，持续构建河湖健康生态体系，2024年度，我区聚焦老百姓居住区域周边的河道开展生态化治理试点工作。经踏勘选点现已形成第一批试点河道清单，其中，由区级试点实施25条段，各街镇、开发区实施407条段(详见工作方案附表)。为规范推进试点工作，区财政局、区水务局制定《奉贤区第一批试点河道生态化治理工作方案》，经区政府常务会议审议通过并印发，请认真组织实施。

上海市奉贤区水务局               上海市奉贤区财政局

2024年6月14日
