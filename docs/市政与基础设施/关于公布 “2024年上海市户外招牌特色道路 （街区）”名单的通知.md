# 关于公布 “2024年上海市户外招牌特色道路 （街区）”名单的通知

各区绿化和市容管理局：

为贯彻落实《上海市生态空间建设和市容环境优化“十四五”规划》《上海市城市管理精细化三年行动计划（2024-2026）》（沪委办发〔2024〕49号），通过打造户外招牌特色道（街区），树立示范典型，推进户外招牌多样化、个性化、艺术化设置，助力提升街区品质、焕发街区活力、培育特色商圈。经各区绿化市容部门上报、专家推荐、网上公示，现将2024年20条（个）市级户外招牌特色道路（街区）名单公布如下：

浦东新区  南汇新城镇  城市书香街区

花木街道   碧云里街区

黄浦区   瑞金二路街道 南昌路

小东门街道  董家渡路

静安区   曹家渡街道  延平路

江宁路街道  陕西北路

江宁路街道  昌平路

徐汇区   徐家汇街道  蒲汇塘路

长宁区   新华路街道  上生新所

普陀区   桃浦镇    景泰路

虹口区   广中路街道  广灵一路

杨浦区   新江湾城街道 江湾里广场

宝山区   高境镇    三邻桥

闵行区   古美路街道  龙茗路

马桥镇    银春路

金山区   山阳镇    金山嘴老街

松江区   洞泾镇    云堡未来市文创区

青浦区   徐泾镇    首位奥特莱斯

奉贤区   奉浦街道   八字桥路

希望各区局依据条例、规章、指导意见指导设置人规范设置户外招牌，充分发挥特色道路的溢出示范效应，引领本市户外招牌设置更好地融入建筑、文化、环境、业态，体现户外招牌设置的多样化、个性化、艺术化。
