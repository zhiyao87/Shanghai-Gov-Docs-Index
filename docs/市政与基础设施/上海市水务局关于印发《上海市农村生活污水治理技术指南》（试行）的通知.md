# 上海市水务局关于印发《上海市农村生活污水治理技术指南》（试行）的通知

上海市水务局关于印发《上海市农村生活污水治理技术指南》（试行）的通知

沪水务〔2021〕597号

各有关单位：

经2021年8月19日局长办公会议审议通过，《上海市农村生活污水治理技术指南》（试行）批准为上海市地方标准化指导性技术文件，统一编号为DB31 SW/Z 012-2021，自发布之日起施行。2013年3月19日印发的《上海市农村生活污水处理技术管理要求（暂行）》（沪水务〔2013〕207号）同时废止。

特此通知。

上海市水务局

2021年9月2日
