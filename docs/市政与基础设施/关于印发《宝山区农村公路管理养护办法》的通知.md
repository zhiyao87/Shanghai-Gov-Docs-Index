# 关于印发《宝山区农村公路管理养护办法》的通知

为贯彻落实乡村振兴战略和促进城乡一体化发展，切实加强本区农村公路管理养护，提升农村公路精细化管理水平，全面推进我区农村公路高质量发展，根据上海市宝山区人民政府办公室《关于转发区交通委制订的〈宝山区深化农村公路管理养护体制改革实施方案〉的通知》（宝府办〔2021〕42号）的任务分工，制定了《宝山区农村公路管理养护办法》，现印发给你们，请参照执行。

特此通知。

上海市宝山区交通委员会会

2021年8月17日
