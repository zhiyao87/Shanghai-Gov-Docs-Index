# 关于进一步加强道路检查井盖病害整治工作的通知

市道运中心、各区交通委（建交委）、各井盖权属单位:

为切实提升本市道路交通设施精细化管理水平，压实道路检查井盖权属单位的管理责任，重点围绕“快速发现、快速派单、快速处置”的要求，持续巩固扩大道路检查井盖整治工作成果，现就进一步加强本市道路检查井盖病害整治工作通知如下：

一、明晰工作职责，压实管理责任

井盖是地下管线的末梢，各相关管线单位是道路检查井盖病害整治的责任主体。根据“谁所有、谁使用、谁负责”的原则，从所有者、使用者、管理者三个方面，进一步压实井盖管理的责任。对于影响道路安全使用的井盖病害即知即改，对于需采取工程性措施解决的井盖病害及时制定计划，并在规定时限内完成。对于井盖标识不清的，根据井内管线落实权属单位。对于废弃检查井，由原管线权属单位限时填埋，并恢复路面。对于无主井盖，由属地道路管理单位进行填埋。

二、完善井盖标识，快速追踪溯源

通过近年井盖整治工作的持续推进，大部分道路检查井盖有其行业专属型式及标识，道路检查井盖病害发生后的溯源时限已大幅缩短，但仍存在少量标识不清或混盖的检查井盖。为提升道路安全水平，确保每个井盖能迅速落实整治单位，要求各权属单位在2023年6月底前，结合日常养护管理，对所有道路检查井盖进行一次彻底的检查排摸，彻底消除标识不清的井盖，并积极对接属地道路管理机构，做好道路检查井盖位置的交底工作。对于共用井，一般由管道建设单位承担井盖管理责任，也可由属地交通主管部门牵头协调明确，由管道共用单位分别承担。

三、建立两级平台，优化处置链路

鼓励各区建立井盖整治区级平台，进一步缩短井盖派单链路，提升井盖病害精准派单效率。同时市级“既有道路检查井盖病害监管系统”进一步纳入路灯、公安、水务等井盖主管部门，不断丰富数据，完善功能；对于疑难井盖病害，提级协调，快速落实处置部门，逐步成为“一网统管”的成熟应用场景。

四、规范抢修围封，杜绝次生灾害

根据《上海市管线检查井盖管理和应急处置试行办法》，道路检查井盖出现缺失或损坏的,管线权属单位应在市区２小时、郊区４小时时限内妥善处置，道路管理部门应积极配合。井盖病害处置需临时围封的，除按照道路养护相关安全管理规定外，还应根据市交警总队下发的《关于加强临时占路作业活动安全管理的通知》的要求严格执行，杜绝次生灾害。

五、量化考核标准，形成监管合力

通过在线监管系统，对井盖权属单位的响应度、井盖病害整治的及时率和完成率进行统计分析，对各区及管线权属单位发布井盖病害处置红黑榜，提升权属单位整治道路检查井盖病害的主观能动性。道路井盖病害治理纳入精细化管理重点工作落实。

六、加强源头治理，优化井盖设置

努力践行道路设施全生命周期管理理念，从源头上，从规划指标上减少道路检查井盖数量。在道路新改扩工程前期，积极提出行业意见，引入控制指标，对管线选线、井位选址、井位数量指标进行系统性研究，做到道路检查井盖减量化设置。对于必须设置的检查井，调整井盖位置以避开车辆轮迹线和车道线，减少井盖受车轮碾压冲击频次，也便于日后最小化封道养护维修。抓住道路新建、架空线入地、道路大中修、精品示范路创建、人行道整治等机会同步改造调换路上各类井盖为防沉降井盖。

井盖整治是贯穿整年的工作，今年9月由市道运中心牵头，继续开展“井盖整治月”集中活动，将每年的整治月打造成井盖整治的常态化工作和对外展示窗口。对优秀整治成果案例进行展示，鼓励各检查井盖权属单位和各区组织井盖整治现场观摩及经验交流，并进行全媒体集中宣传，提升市民对井盖整治的感受度。
