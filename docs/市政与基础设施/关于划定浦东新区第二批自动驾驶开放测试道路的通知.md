# 关于划定浦东新区第二批自动驾驶开放测试道路的通知

关于划定浦东新区第二批自动驾驶开放测试道路的通知

沪交科〔2024〕19号

浦东新区人民政府：

为加快推进上海市建设“全球领先的高级别自动驾驶引领区”，规范自动驾驶开放测试道路的建设管理，本市分阶段、分批次开放自动驾驶典型测试道路，形成“全车型、全出行链、全风险类别、全测试环节和融合新基建基础设施”的“四全一融合”自动驾驶测试场景布局。根据《浦东新区人民政府关于商请扩大浦东新区智能网联汽车测试道路区域的函》（浦府〔2023〕181号），经认真研究，遵循“一次许可、分步实施、动态管理”原则，决定将以下道路作为浦东新区第二批自动驾驶开放测试道路：

三、请按照城市道路及公路有关技术标准、开放测试道路风险改善建议，尽快完善开放测试道路相关标识、标线和路侧设施，抓紧建设开放测试道路视频监测系统及测试数据记录系统，为智能网联汽车上路测试及交通影响评估提供技术支持。常态落实好开放测试道路养护巡查机制，并强化相关路段运维保障。

四、请做好上述开放测试道路社会宣传工作，并加强开放测试区域道路管理，做好测试期间交通组织工作，加强风险防控，确保智能网联汽车开放道路测试工作安全有序开展。
