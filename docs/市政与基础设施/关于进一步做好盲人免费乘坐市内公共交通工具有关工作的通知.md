# 关于进一步做好盲人免费乘坐市内公共交通工具有关工作的通知

各区残联、交通委、民政局：

根据《上海市实施〈中华人民共和国残疾人保障法〉办法》第四十五条关于“盲人持有效证件免费乘坐市内公共汽车、电车、地铁、渡船等公共交通工具”，以及《上海市残疾人事业发展“十四五”规划》“盲人凭有效证件免费乘坐市内公共交通政策”的规定，为进一步保障盲人的合法权益，规范有效证件管理，就有关事项通知如下：

一、发证对象

（一）本市户籍，持有有效《中华人民共和国残疾人证》的一、二级视力残疾人。

（二）非本市户籍，持有有效《上海市居住证》《中华人民共和国残疾人证》的一、二级视力残疾人。

上述一、二级视力残疾人统称为“盲人”。

二、新证、补证、注销流程

（一）本市户籍盲人新证发放

1.免申即享

（1）发证要求

符合条件的发证对象免于申请即可领用《上海市盲人公共交通证》。

本通知生效之日前，符合条件但未申请《上海市盲人公共交通证》的，自本通知生效之日起免申即享。

发证对象可在“一网通办”政务服务平台查询《上海市盲人公共交通证》领用情况以及个人信息。

（2）条件确认

符合免申即享条件的发证对象，其个人关键信息：本人近期一寸免冠照片（不配戴深色眼镜）、收件地址、联系方式等，由户籍所在区残联确认后，报市残联制证。

信息不全的，由户籍所在地街镇残联通知发证对象补充信息材料，并对补充完整的信息材料完成初审后录入系统提交区残联，区残联在收到申请材料后5个工作日内对修改、补充材料进行确认，确认通过的报市残联制证；确认不通过的，在5个工作日内由户籍所在地街镇残联通知发证对象，并告知其可根据申请条件重新提交材料。

2.新证申请

（1）申请

符合条件的发证对象可通过互联网渠道或至就近街道、镇（乡）社区事务受理服务中心（以下简称“受理服务中心”）申请《上海市盲人公共交通证》，并提供以下材料:

本人居民身份证、本人有效《中华人民共和国残疾人证》、本人近期一寸免冠照片（不配戴深色眼镜）、《〈上海市盲人公共交通证〉申请审核表》（附件1）。

《上海市盲人公共交通证》允许代办，代办须提供代办人居民身份证和委托书。

以上材料能通过调用电子证照等信息共享交换途径获得的，免于提交实体证件。

（2）审核

通过互联网渠道申请或受理服务中心受理的，由区残联审核通过后报市残联制证；审核不通过的，由区残联反馈申请人信息。

（二）非本市户籍盲人新证申请

1.申请

符合条件的发证对象可通过互联网渠道或至就近受理服务中心申请《上海市盲人公共交通证》，并提供以下材料:

本人居民身份证、本人有效《中华人民共和国残疾人证》、本人近期一寸免冠照片（不配戴深色眼镜）、《〈上海市盲人公共交通证〉申请审核表》（附件1）、《上海市居住证》。

《上海市盲人公共交通证》允许代办，代办须提供代办人身份证和委托书。

以上材料能通过调用电子证照等信息共享交换途径获得的，免于提交实体证件。

2.审核

通过互联网渠道申请的，由居住证所在街镇残联（或通过受理服务中心申请的，由申请地所在街镇残联）补充完整的信息材料并完成初审后提交区残联，区残联在收到申请材料后5个工作日内对申请材料进行审核，审核通过的报市残联制证；审核不通过的，在5个工作日内由进行审核的区残联反馈申请人。

（三)补证申请

《上海市盲人公共交通证》遗失、损坏等需补证的可通过互联网渠道或至就近受理服务中心申请《上海市盲人公共交通证》补证，申请材料及审核流程按照“新证申请”。

（四）注销

符合下列情形之一的，应予以注销。

1.自愿放弃的发证对象填写并提交《自愿放弃〈上海市盲人公共交通证〉承诺书》（附件2），由街镇残联审核后报区残联注销，于次月生效。

2.迁出本市并注销本市户籍的，残疾类别、等级不符合的，残疾人证注销或过期的，区残联每月根据系统生成的注销名单进行审核及注销，于次月生效。

3.被人民法院判处有期徒刑以上刑罚，且在监狱服刑的，经街镇残联核实情况属实后，区残联依职权予以注销，于次月生效。

三、制发

市残联制作《上海市盲人公共交通证》送达发证对象指定地址。

四、资金保障

制证及物流资金由市级残疾人就业保障金列支。

五、组织管理

市残联负责政策的修订、宣传、实施，由市残疾人就业服务中心负责数据收集、统计、交付制证、发证等日常管理工作。市交通委负责监督管理公交、电车、轮渡、地铁等公共交通企业服务情况，督促各公共交通企业严格执行政策。市民政局负责协调落实受理服务下沉受理服务中心。各区残联负责辖区内人员新增、退出的审核，反馈及违规使用情况的核实，支持、指导本区受理服务中心做好材料收取、受理等工作。

六、其他事项

（一）《上海市盲人公共交通证》仅供持证人本人乘坐上海市内公共汽车、电车、地铁、渡船等公共交通工具时使用。搭乘公共交通工具时，应配合工作人员指引、核实证件，遵守相关规定。

（二）《上海市盲人公共交通证》禁止转借他人使用，如公共交通企业在日常管理中发现相关情况并收集到证据，应及时提供给市残联，由所属区残联核实情况，情况属实的，注销其所持《上海市盲人公共交通证》，且自注销之日起一年内不得再次申领。

（三）《关于进一步做好盲人免费乘坐市内公共交通工具有关工作的通知》（沪残联〔2021〕137号），自本通知实施之日起废止。

（四）本通知自印发之日起实施，有效期5年。
