# 关于切实做好综合业务平台道路货运数据清理工作的通知

市道运中心、各区交通行政主管部门、临港新片区管委会：

根据上海市交通委员会有关综合业务平台数据清理工作要求以及《关于印发<上海市道路运输行业行政许可事项依职权注销制度>的通知》（沪道运办﹝2023﹞11号）相关规定，结合道路货运行业实际，请各有关单位及时完成道路货运行业依职权注销工作，切实做好综合业务平台道路货运数据清理工作。具体工作通知如下：

一、清理范围

（一）道路运输经营许可证（含道路危险货物运输许可证）有效期届满未延续的道路货运企业及其名下的所有道路货运车辆。

（二）超报废年限的道路货运车辆。

二、清理方式

对上述范围应清理的相关道路货运企业（单位）和车辆，应及时纳入待注销列表，要严格按照《关于印发<上海市道路运输行业行政许可事项依职权注销制度>的通知》（沪道运办﹝2023﹞11号）规定的依职权注销程序进行清理。

三、清理时限

按照“动态清零”的工作要求，各相关单位应每个月进行一次依职权注销工作，及时完成综合业务平台数据清理工作。

本通知自2023年5月1日开始实施，请各相关单位遵照执行。

特此通知。

上海市道路运输管理局
