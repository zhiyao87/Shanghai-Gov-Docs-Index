# 关于命名瑞金南路等16条道路为上海市绿化特色道路的通知

各区绿化和市容管理局：

对照《上海市绿化特色道路评定办法》,通过各区绿化主管部门进行自评和推荐，经相关专家现场评定，瑞金南路等16条道路（详见附件）符合上海市绿化特色道路评定标准。经公示无异议，现决定命名中山南路等16条道路为2022年度上海市绿化特色道路。

希望各区按照上海市园林绿化“十四五”规划要求，进一步落实本市绿化“四化”和精细化管理要求，不断提升本市道路绿化品质和景观特色化水平。

特此通知。
