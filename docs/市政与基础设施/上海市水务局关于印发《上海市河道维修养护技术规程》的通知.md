# 上海市水务局关于印发《上海市河道维修养护技术规程》的通知

上海市水务局关于印发《上海市河道维修养护技术规程》的通知

沪水务〔2022〕901号

各有关单位：

经2022年10月31日局长办公会议审议通过，《上海市河道维修养护技术规程》批准为上海市地方标准化指导性技术文件，统一编号为DB31 SW/Z 027-2022，自发布之日起施行。原《上海市河道维修养护技术规程》(沪水务〔2015〕114号)同时废止。

特此通知。
