# 关于修订印发《上海市公共停车场（库）经营备案告知承诺实施细则（2023版）》的通知

各区交通行政主管部门、临港新片区管委会、市道运中心、委行政服务中心：

根据本市公共停车场（库）经营备案制度改革工作要求，我局决定进一步拓展告知承诺实施范围，明确将“公共停车场（库）开业备案”、“公共停车场（库）（含临时停车场）基本信息变更备案”两项业务情形纳入“告知承诺”办理方式的适用范围，将“智慧停车场（库）核验报告”、“停车场（库）充电设施联网监测报告”等两项备案材料调整为承诺件材料，修订形成了《上海市公共停车场（库）经营备案告知承诺实施细则（2023版）》，并经市道路运输局2022年第13次局长办公会审议通过，现予以印发，自2023年3月1日起施行。

特此通知。

上海市道路运输管理局

2023年1月20日

上海市公共停车场（库）经营备案

告知承诺实施细则（2023版）

第一章总则

第一条（目的和依据）

为进一步优化行政备案程序，完善管理方式，提高行政效率，根据《上海市道路运输管理条例》《上海市停车场（库）管理办法》《上海市行政审批告知承诺管理办法》等规定，制定本实施细则。

第二条（定义）

本实施细则所称的告知承诺，是指申请人提出公共停车场（库）经营备案申请，交通行政主管部门一次告知其备案条件和需要提交的材料，申请人以书面形式承诺其符合备案条件，由交通行政主管部门予以登记备案的方式。

第三条（适用范围）

在本市行政区域内通过告知承诺方式办理公共停车场（库）经营备案的申请、审批、监管适用本细则。临时停车场开业经营不适用告知承诺的备案方式。

申请人有下列情形的，不适用告知承诺：

（一）上一年度公共停车行业质量信誉考核结果为B级的；

（二）曾有在规定期限内未提交材料，或者提交的材料不符合要求，或者作出不实承诺或者违反承诺的。

第四条（职责分工）

上海市道路运输管理局（以下简称“市道路运输局”）负责本市公共停车场（库）经营备案告知承诺工作的总体组织和协调推进；负责本辖区内机场、火车站等市级对外交通枢纽等附属的公共停车场（库）以及其他市管公共停车场（库）经营备案告知承诺方式申请的备案。

临港新片区管委会、各区交通行政主管部门负责本辖区内公共停车场（库）经营备案告知承诺工作的组织和推进；并按照分工职责具体负责本辖区内公共停车场（库）经营备案告知承诺方式申请的备案。

第二章 经营备案相关规定

第五条（备案依据）

交通行政主管部门应当依据《上海市道路运输管理条例》《上海市停车场（库）管理办法》规定的从事公共停车场（库）应当具备的条件实施行政备案，并制定相关办事指南。

第六条（申请材料）

申请人采用告知承诺方式申请公共停车场（库）经营备案的，应当按照本细则附件的要求提交相关申请材料。

第七条（法律效力）

申请人采用告知承诺方式取得公共停车场（库）经营备案的，在具备法律法规规定的从事公共停车场（库）经营必备条件后，方可从事公共停车场（库）经营活动。

第三章 备案程序和后续监管

第八条（申请与受理）

上海市交通委员会行政服务中心统一受理向上海市道路运输管理局提交的申请。临港新片区管委会、各区交通行政主管部门确定的对外服务窗口统一受理向本辖区交通行政主管部门提交的申请。

申请人选择采取告知承诺方式申请公共停车场（库）经营备案的，须现场提交经申请人签章的《行政审批告知承诺书》和第六条规定的材料。

申请人不愿意采取告知承诺方式的，可以按照《公共停车场（库）经营备案办事指南》的一般程序申请办理相关事项。

第九条（申请人的承诺）

提出从事公共停车场（库）经营活动的申请人在办理经营备案时，愿意作出承诺的，应当在填写申请人基本信息时对下列内容作出确认和承诺：

（一）所填写的基本信息真实、准确；

（二）已经知晓交通行政主管部门告知的全部内容；

（三）自身能够满足交通行政主管部门告知的条件、标准和技术要求；

（四）能够在约定期限内，提交交通行政主管部门告知的相关材料；

（五）愿意承担不实承诺、违反承诺的法律责任；

（六）符合法定条件前，不开展相关经营活动；

（七）所作承诺是申请人真实意思的表示。

第十条（审核与决定）

申请人采取告知承诺方式的，《行政审批告知承诺书》经交通行政主管部门和申请人双方签章后生效，由交通行政主管部门和申请人各保存一份。交通行政主管部门对申请人符合适用告知承诺的情形、承诺符合备案条件并提交约定材料的，作出行政备案决定。

第十一条（文书和证件的送达）

交通行政主管部门应当在作出行政备案决定后10个工作日内依法送达行政备案证明。

第十二条（后续监管）

交通行政主管部门应当在作出准予备案决定后2个月内，对申请人的相关材料进行核查。

第十三条（备案决定的撤销）

交通行政主管部门核查发现申请人未提交材料或者提交的材料不符合要求且无法补正的，或者实际情况与承诺内容不符的，交通行政主管部门应当要求其限期整改；逾期拒不整改或者整改后仍不符合条件的，依法撤销行政备案决定。申请人在整改期限内不得经营，擅自经营的，行政审批机关按照有关法律规定依法予以处理。

第十四条（诚信档案）

交通行政主管部门在审查、后续监管中发现申请人、备案人作出不实承诺或者违反承诺的，记入本市交通行政管理部门诚信档案，并对该申请人、备案人不再适用告知承诺的备案方式。

第十五条（施行日期）

本细则自2023 年3月1日起施行。

一、交通行政主管部门的告知

按照《上海市行政审批告知承诺管理办法》，就行政备案事项告知如下：

（一）适用条件

信用情况良好的公民、法人和其他组织均可采用告知承诺方式提出行政备案申请。但有以下情况之一的不适用：
