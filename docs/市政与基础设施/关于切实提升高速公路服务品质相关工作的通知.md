# 关于切实提升高速公路服务品质相关工作的通知

局相关部门、市道运中心、各高速公路项目公司：

为贯彻落实交通运输部公路“十四五”发展规划和本市道路精细化管理要求，提高广大驾乘人员的行车舒适性，结合前期已制定的高速公路设施整治和养护质量提升、服务区专项提升、ETC服务提升等工作方案和要求，切实提升本市高速公路整体服务品质，现将具体事项通知如下：

一、工作目标

认真践行“人民城市人民建，人民城市为人民”重要理念，明确2022-2024年为高速公路服务品质提升年，力争到2024年底，总体实现高速公路各类设施规范统一、功能完好；路域环境舒适整洁、常亮常净；安全设施合理布设、防护到位；服务设施彰显特色、突出功能；运维体系协同高效、智能可靠；服务品质以人为本、精细多维的工作目标。

二、工作任务

（一）交通安全设施提质增效

全面排查前期开展的高速公路交通安全设施提质增效工作完成情况，梳理问题，查缺补漏，细化整改工作清单；开展后评估工作并建立长效管理机制，做好后续交通安全设施的维护工作。（2023年6月底完成）

（二）高速公路设施整治提升

对照《高速公路设施整治提升标准》仔细排查各类问题，对既有老旧设施开展检测和评估，结合改建、养护工程、养护专项等实施，实现高速公路设施的整治提升。（2024年12月底完成）

（三）高速公路养护质量提升

对照《高速公路养护质量提升标准》仔细排查各类问题，通过设施维修、整形、保洁、冲洗等措施，重点聚焦高速公路附属设施、路面、匝道、绿化带等设施和区域，提升高速公路的养护质量，并形成长效机制。（2023年5月底完成）

（四）安全设施和交通秩序精细化提升

围绕《公路安全设施和交通秩序管理精细化提升行动方案》中“精细提升安全防护能力、科学规范信息指引、加强疏堵保畅、强化恶劣天气动态管控、改进完善通行管理措施”五大任务，联合公安部门对事故易发多发点段进行评估，开展高速公路安全设施隐患排查；结合“交通安全设施提质增效、高速公路设施整治提升、高速公路养护质量提升”三项工作，对标薄弱事项，细化整治措施；实行 “一点一方案”、“一路一设计”，打造“高速公路安全精品路”。（2024年12月底完成）

（五）服务区品质提升

各高速公路服务区按照“一区一策、分类实施”的原则，按照标杆、特色、功能服务区分类提升，实现“综合楼品质明显提升、停车需求得以保障、环境卫生明显改观、公共秩序更加规范、服务品质显著改善、探索联合经营模式”等目标。（2024年12月底完成）

（六）ETC服务提升

根据部路网中心下发的《高速公路联网收费系统优化升级工程方案》完成本市高速公路联网收费系统优化升级，提升计费精准性和业务规范化程度；开展收费预交易、智能收费发卡等科技创新工作试点，推进收费站轻量化、集约化以及车道标准化等方案研究及试点；各试点工作成熟后逐步推广，改善道口通行能力，提升收费服务水平。（2024年12月底完成）

三、工作措施

（一）构建组织保障体系

市道路运输局组建高速公路服务品质提升工作组，由分管领导任组长，局养护处总体牵头会同运行处、计财处全面负责各项工作的指导、统筹和整体协调推进。

市道运中心组建高速公路服务品质提升工作专班，市道运中心主要领导为负责人，中心相关部门和高速公路质量评价小组人员组成，明确专人专岗，负责工作任务中各专项提升工作的具体指导、协调、推进实施。

各项目公司组建高速公路服务品质提升工作领导小组，由项目公司负责人牵头，统筹各方资源力量、协调推进各专项提升工作落地落实。

（二）推进落实全过程管理

1.组织标准宣贯培训。市道路运输局各部门针对交通安全设施提质增效、高速公路设施整治提升、高速公路养护质量提升等工作明确标准，市道运中心据此开展反复的、多层次的宣贯培训和答疑。（牵头部门：市道路运输局养护处、运行处，具体实施：市道运中心）

2.制定路段实施方案。各项目公司根据工作标准以及本路段的实际情况，针对每一项工作任务分别编制实施方案，明确主要任务、具体要求和推进机制，市道运中心负责监督推进并进行行业审查。（牵头单位：市道运中心，具体实施：各项目公司）

3.梳理任务清单。各项目公司根据审批后的路段实施方案和总体时间节点安排，梳理、排列本路段具体的工作任务清单，明确各阶段任务时间节点，形成细化的季度和年度任务分解表，并报送市道运中心备案。（牵头单位：市道运中心，具体实施：各项目公司）

4.重视专项设计与审查。对于整体性和技术性较强的工作任务，如高速公路设施整治提升、服务区专项提升等，由各项目公司委托专业设计单位编制专项提升设计方案，由市道路运输局各部门组织，市道运中心落实行业专家评审并反馈修改内容，各项目公司按修改意见按时完善设计方案并报送市道运中心二次审批。（牵头部门：市道路运输局养护处、运行处，具体实施：各项目公司，市道运中心）

5.跟踪推进过程。建立工作组季度例会和专班月度例会制度。由工作专班定期梳理各专项工作完成情况、取得成效、先进经验、存在问题以及相关措施，并形成工作简报。开展日常巡查，注重检查各专项工作的实施情况（进度和质量），对存在问题及时反馈，并加强后续整改复核，形成闭环管理；针对工程类项目，落实项目验收制度。各项目公司积极推进各专项工作实施方案，并及时向市道运中心报告。（牵头单位：市道运中心，具体实施：各项目公司）

6.开展行业评价通报。市道运中心对各专项工作的实施情况及时总结、评估，将进展和完成情况进行反馈。市道路运输局将对成果突出的项目公司进行行业表扬，对于工作不到位甚至影响行业形象的项目公司予以行业通报。（牵头部门：市道路运输局养护处、运行处，具体实施：市道运中心）

（三）落实资金预算和审查监管

1.落实资金保障。市道运中心督促、指导各项目公司根据审批后的专项工作实施方案排列资金预算，各项目公司在此基础上落实资金来源和金额，并报送市道运中心进行行业备案。（牵头单位：市道运中心，具体实施：各项目公司）

2.加强预算审查。市道路运输局计财处牵头市道运中心对各项目公司的年度预算计划开展行业审查，过程中加强计划执行情况监管，及时提出反馈调整意见、督促项目公司进行调整并在行业通报中反应资金使用和计划执行情况。（牵头部门：市道路运输局计财处，具体实施：市道运中心）

3.试点养护合同资金监管。市道运中心开展市管和政府还贷高速养护资金监管试点工作，动态监测养护资金的支出用途及资金流向，从而掌握实际养护资金使用情况并做到专款专用。在进行资金监管的同时对资金监管情况进行中期评估和后评估，为后续养护资金合理科学的投入积累基础数据。（牵头部门：市道运中心）

（四）开展综合评价

市道路运输局各部门牵头组织市道运中心每季度编制收费高速公路运营养护服务质量评价报告，针对公路技术检测、人工巡视、重点工作、资金预算执行情况进行综合评价，报告内容包含客观量化数据、具体评价评估内容、行业工作建议和表扬批评等。（牵头部门：市道路运输局养护处、运行处、计财处，具体实施：市道运中心）

四、工作要求

（一）加强组织保障

构建市道路运输局、市道运中心、各高速项目公司三位一体、层次分明、责任清晰的组织保障体系，分解细化工作目标，专岗专责推进落实。

（二）强化全过程管理

各专项工作要从标准宣贯、方案制定、清单梳理、专项设计与审查、过程管理、评价通报六个环节，做到按时推进、环环落实。通过强化全过程管理，精准把脉各专项工作开展质量，最终达到提升高速公路服务品质目标。

（三）规范资金使用

依据高速公路服务品质提升工作目标和各项标准、实施方案，分年度、分项目落实资金预算，高标准、严要求实施预算审查；对部分高速路段试点养护合同资金监管，逐步在高速公路服务品质提升过程中形成资金管理长效机制。

（四）全面评价监督

通过阶段性、全方位综合评价各专项工作完成情况，全行业通报评价结果，鼓励各项目公司相互交流学习，监督各项目公司积极提高质量，促进形成“比、学、赶、超”工作氛围，进一步推动实现高速公路服务高质量发展。
