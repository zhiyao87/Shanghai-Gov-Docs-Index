# 关于印发《上海市金山区超标排放加价污水处理费征收实施细则》的通知

各相关单位:

根据《上海市排水与污水处理条例》《关于印发<上海市污水处理费征收使用管理实施办法>的通知》等有关规定，为切实加强对排水户的监管，参照《上海市超标排放加价污水处理费征收实施细则》相关要求并结合金山区实际，现制定《上海市金山区超标排放加价污水处理费征收实施细则》，请遵照执行。

特此通知。

上海市金山区水务局

上海市金山区发展和改革委员会

上海市金山区财政局

2023年11月22日

上海市金山区超标排放加价污水处理费征收实施细则

第一条（目的和依据）

为切实加强对排水户的监管，保障城镇排水与污水处理设施稳定运行，贯彻落实污水处理费加价征收制度要求，按照《上海市排水与污水处理条例》《关于印发<上海市污水处理费征收使用管理实施办法>的通知》《关于完善长江经济带污水处理收费机制有关政策的指导意见》《关于印发<上海市超标排放加价污水处理征收实施细则>的通知》等规定，结合金山区实际，制定本细则。

第二条（征收对象）

经上海市金山区水务行政执法机构监测，向本区城镇排水和污水处理设施排放污水不符合国家和本市污水排放的相关标准的排水户（即《关于印发<上海市污水处理费征收使用管理实施办法>的通知》中的重点污染用户），应当缴纳超标排放加价污水处理费。

第三条（排放标准）

排水户应当按照国家和本市有关规定，建设相应的污水预处理设施，确保排放污水水质达到《污水综合排放标准》（DB31/199-2018）排放限值相关要求。相关行业排放标准另有强制性规定的，从其规定。如国家或本市发布新的污水排放标准，则按新标准执行。

第四条（管理职责）

本区区域污水处理设施服务范围超标排放加价污水处理费的征收工作由上海市金山区水务局负责，具体实施由上海市金山区排水管理所承担。

超标排放加价污水处理费的征收、使用和管理应当接受本区财政、价格等部门的监督检查。

第五条（监测方式）

上海市金山区水务行政执法机构负责本区行政区域内排水水质专项监测。

上海市金山区排水管理所可以委托具有相应资质的第三方检测机构对本区区域的重点监测对象进行水质监测，频次不低于每年一次，并将监测超标的排水户信息报送至上海市金山区水行政执法机构，列入排水水质专项监测计划。

第六条（重点监测对象）

本细则所称的重点监测对象是指本区行政区域内已依法申领污水排入排水管网许可证（以下简称排水许可证）的排水户，且符合以下条件之一的：

（一）纳入本区重点排污单位名录管理；

（二）申领的排水许可证排水量超过100m3/d；

（三）近三年被水务行政执法机构认定超标排放。

上海市金山区水行政主管部门负责每年根据当年的重点排污单位名录、排水许可证的变更情况以及超标排放情况，确定本区域的重点监测对象，并由上海市金山区水行政主管部门于每年年初进行公示。

第七条（检测指标）

排水户水质检测的常规指标为9项,包括pH值、CODCr、悬浮物、氨氮、硫化物、总磷、动植物油、石油类和阴离子表面活性剂。

其他特征性指标由上海市金山区水行政主管部门根据排水许可证许可内容，并结合行业排放污水的污染特性来确定。

第八条（征收标准）

区属污水处理设施服务范围内的超标排放加价污水处理费征收标准在污水处理费征收标准基础上，每立方米加收0.8元。今后调整加价污水处理费征收标准时按新标准执行。

第九条（征收水量）

超标排放加价污水处理费的征收水量为排水户被执法监测水质超标的近三个月（含取样当月以及后二个月）的水费账单中应缴纳污水处理费的征收水量，包含使用公共供水和自备水应缴纳污水处理费的征收水量。如执法监测水质再次超标，相同月份不重复加价征收。应收超标排放加价污水处理费=征收水量×征收标准。

第十条（征收入库）

上海市金山区排水管理所审核相关情况后向超标排放的排水户开具非税收入缴款书，超标排放的排水户收到缴款书后按要求缴入国库，纳入污水处理费统一管理和使用。

第十一条（施行日期）

本细则自2024年1月1日起施行，有效期至2028年2月29日。
