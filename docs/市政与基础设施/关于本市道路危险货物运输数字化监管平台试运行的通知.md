# 关于本市道路危险货物运输数字化监管平台试运行的通知

各有关单位：

为探索数字化治理，推动本市道路危险货物运输行业数字化管理转型，不断加强本市道路危险货运车辆动态监督管理，切实提高行业安全管理水平，现将本市道路危险货物运输数字化监管平台（以下简称“数字化监管平台”）试运行有关工作通知如下：

一、市道路运输管理局负责统筹推进本市道路危险货物运输数字化监管平台试运行工作，跟踪数字化监管平台运转情况，不断优化数字化监管平台功能，并逐步建立相关管理制度。

二、各道路危险货物运输企业应通过企业监控平台，对数字化监管平台下发的动态监管报警信息，在15分钟内予以响应，2小时内完成处置并把处置结果反馈数字化监管平台，对政府监管考核信息有异议的应当于2天申诉期内进行申诉并上传相关申诉材料。

三、市道路运输事业发展中心负责对数字化监管平台产生的许可类报警信息进行处置，必要时及时锁停不符合安全生产条件的道路危险货物运输企业、车辆、人员的电子运单填报功能；负责综合应用数字化监管平台采集的企业安全运营信息开展考核。

四、市交通委执法总队可登陆数字化监管平台，下载企业违规报警明细表作为行政检查或处罚的线索；根据违规报警统计分析情况具有针对性的安排勤务。

上海市道路运输管理局

2021年11月17日
