# 上海市水务局关于印发《上海市城镇污水处理设施运行监督管理办法》的通知

上海市水务局关于印发《上海市城镇污水处理设施运行监督管理办法》的通知

沪水务〔2021〕903号

各相关区水务局、城投集团、各城镇污水污泥处理管理和运行单位：

随着修订后《中华人民共和国固体废物污染环境防治法》和《中华人民共和国长江保护法》的颁布执行与国家《水污染防治行动计划》的落地实施，以及本市城镇污水处理厂提标改造工程全面完成，城镇污水处理设施运营与绩效考核工作需要提出更高的要求。为此，上海市水务局组织各行业单位修订形成了《上海市城镇污水处理设施运行监督管理办法》，现印发给你们，请遵照执行。原《上海市城镇污水处理设施运行监督管理办法（试行）》（沪水务〔2019〕434号）同时废止。

特此通知。

上海市水务局

2021年12月23日
