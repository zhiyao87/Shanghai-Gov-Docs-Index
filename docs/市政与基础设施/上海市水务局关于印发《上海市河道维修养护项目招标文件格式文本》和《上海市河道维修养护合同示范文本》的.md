# 上海市水务局关于印发《上海市河道维修养护项目招标文件格式文本》和《上海市河道维修养护合同示范文本》的通知

上海市水务局关于印发《上海市河道维修养护项目招标文件格式文本》和《上海市河道维修养护合同示范文本》的通知

沪水务〔2022〕1045号

各区水务局，各有关单位：

《上海市河道维修养护项目招标文件格式文本》和《上海市河道维修养护合同示范文本》已经2022年11月11日局长办公会议审议通过，现印发给你们，请参照执行。原《上海市河道维修养护项目招标文件格式文本》和《上海市河道维修养护合同示范文本》（沪水务〔2016〕995号）同时废止。

特此通知。

上海市水务局

2022年12月8日
