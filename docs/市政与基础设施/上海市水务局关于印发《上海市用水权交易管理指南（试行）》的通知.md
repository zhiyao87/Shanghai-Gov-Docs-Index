# 上海市水务局关于印发《上海市用水权交易管理指南（试行）》的通知

上海市水务局关于印发《上海市用水权交易管理指南（试行）》的通知

沪水务〔2024〕372号

各区水务局、临港新片区管委会、上海交易集团有限公司、上海环境能源交易所股份有限公司：

为贯彻落实《水利部 国家发展改革委 财政部关于推进用水权改革的指导意见》，确保本市用水权交易工作安全、有序、高效开展，我局制定了《上海市用水权交易管理指南（试行）》，现予印发，请遵照执行。

特此通知。

上海市水务局

2024年9月4日
