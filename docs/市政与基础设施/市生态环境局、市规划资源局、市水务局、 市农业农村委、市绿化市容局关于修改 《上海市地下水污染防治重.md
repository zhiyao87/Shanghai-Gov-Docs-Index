# 市生态环境局、市规划资源局、市水务局、 市农业农村委、市绿化市容局关于修改 《上海市地下水污染防治重点区划定及管控方案》的通知

各有关单位：

现决定对《上海市地下水污染防治重点区划定及管控方案》作如下修改：

将第四条第（一）项中的“《中华人民共和国水污染防治法》”

修改为“《中华人民共和国生态环境法典》”。

本通知自2026年8月17日起施行，有效期至2030年2月28日。《上海市地下水污染防治重点区划定及管控方案》根据本通知作相应文字调整后，重新发布。
