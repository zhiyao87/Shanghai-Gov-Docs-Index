# 关于发布《市道路运输局路政行业依申请行政权力事项实施清单（2023版）》的通知

市道路运输事业发展中心：

根据国务院办公厅、市政府办公厅关于行政许可事项清单管理工作部署，结合市交通委不断深化“放管服”改革、持续提升“一网通办”政务服务事项办理能级、促进道路运输行业营商环境持续改善的具体要求，我局编制了《市道路运输局路政行业依申请行政权力事项实施清单（2023版）》，并经2023年第15次局长办公会审议通过。现予印发，即日起施行。

特此通知。
