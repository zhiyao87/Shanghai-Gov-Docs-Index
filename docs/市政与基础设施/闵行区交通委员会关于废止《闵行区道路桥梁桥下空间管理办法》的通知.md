# 闵行区交通委员会关于废止《闵行区道路桥梁桥下空间管理办法》的通知

各镇人民政府、街镇办事处、莘庄工业区管委会：
根据市人大常委会法制委、市政府办公厅、市司法局《关于落实〈全面评估清理地方性法规政府规章和行政规范性文件工作方案〉相关具体工作安排的通知》，结合区政府全面评估清理行政规范性文件相关工作要求，经研究决定，废止2021年1月8日印发的《闵行区道路桥梁桥下空间管理办法》（闵交规〔2021〕1号）,自2025年9月1日生效。
特此通知。
