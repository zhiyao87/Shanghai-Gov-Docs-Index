# 上海市静安区人民政府办公室关于转发区应急办《静安区落实轨道交通车站应对大客流“四长联动”应急处置工作的实施方案》的通知

区政府各委、办、局，各街道办事处、彭浦镇政府：

区应急办《静安区落实轨道交通车站应对大客流“四长联动”应急处置工作的实施方案》已经区政府第53次常务会议通过，现转发给你们，请认真按照执行。

静安区落实轨道交通车站

应对大客流“四长联动”应急处置工作的

实施方案

为贯彻落实市政府关于《本市建立轨道交通车站应对大客流“四长联动”应急处置机制方案》（沪府办〔2017〕2号）文件精神和工作要求，加强我区轨道交通突发事件大客流疏散应急处置能力，保障轨道交通和地面交通安全、有序和有效的衔接，现就本区建立轨道交通车站地铁站长、轨交公安警长、属地派出所长和属地街镇长联动（以下简称“四长联动”）应对大客流应急处置机制，制定本方案。

一、工作目的

静安区地处中心城区，是上海火车站站区所在地，商业商务区域密集。目前辖区内共有轨道交通线路9条（分别是1、2、3、4、7、8、10、12、13号线），站点共计18个，分别是：共康路站、彭浦新村站、汶水路站、上海马戏城站、延长路站、天潼路站、中山北路站、上海火车站站、汉中路站、西藏北路站、中兴路站、曲阜路站、宝山路站、自然博物馆站、南京西路站、昌平路站、静安寺站、武宁路站。本区轨道交通站点具有分布密集、枢纽站点多、客流量大的特点，将来还将有一定数量的新建轨道交通线路和站点。

按照轨道交通突发事件应对工作体系，通过“四长联动”应急处置机制明确相关机构职责程序，建立统一、规范、分级、高效的应急处置指挥系统，切实发挥属地的支援保障作用，进一步深化轨道交通车站内外在大客流应急疏散中的有序联动，合力提升风险管控和应急处置能力，最大程度地预防和减少因轨道交通突发事件造成的人员伤害。按照“以人为本、安全至上、各司其职、协同应对、信息共享、紧密联动”的工作原则，建立“四长联动”机制，有利于积极探索条块合作模式，实现属地各种应急资源快速有效整合，有利于轨道交通应急处置更直接、更快速，对保障轨道交通安全运营和防范重大人员伤害具有重要作用。

二、主要职责

（一）各方职责

区应急办负责对轨道交通车站“四长联动”应急处置机制的协调指导。区建管委负责发生轨道交通突发事件时沟通联系市交通委启动公交保障等措施。区公安分局负责指导各属地派出所做好轨道交通车站外秩序维护、开辟“绿色通道”等工作。区市场监管局做好轨道交通车站内电梯及自动扶梯的日常监督管理工作。区城管执法局与街镇共同做好轨道交通车站出入口地面周边环境秩序的日常管理工作。各属地派出所和街镇负责协助轨道交通方面具体实施“四长联动”应急处置机制工作。

各相关单位要做好突发事件信息报送工作，一旦发生轨道交通突发事件，根据突发事件信息报送工作要求，及时报区总值班室，相关职能部门针对突发事件开展应急处置工作。

（二）“四长”职责

1．轨道交通站长职责

（1）负责牵头组织落实。牵头建立和落实“四长联动”各项机制；修订车站“四长联动”工作预案，并定期组织开展联合演练，确保联络方式、应急力量位置、物资装备配置、导向标识设置等处置物资、措施落实到位，处置人员职责明晰；突发事件情况下，负责根据实际情况启动“四长联动”机制，将现场情况通知轨交警长、属地街镇长，牵头组织现场应急处置、人员岗位部署以及信息传递。

（2）负责日常联络工作。建立“四长联动”机制联系人通讯录，制定“四长联动”应急处置机制备案表，主动与轨交公安、属地派出所、属地街镇沟通，定期组织召开“四长联动”工作例会，强化日常沟通协调。

（3）负责牵头开展联合整治。牵头组织轨交公安、属地派出所以及属地街镇，定期对车站周边秩序开展联合整治，并建立长效机制，保障车站出入口周边环境与秩序。

2．轨道交通警长职责

（1）积极配合机制落实。配合做好“四长联动”各项机制建立和落实工作；定期参加“四长联动”工作例会，主动与轨交车站沟通联系，强化信息沟通和工作协调；积极参与“四长联动”联合演练，配合落实各项处置措施。

（2）积极配合联合整治。配合轨交车站、属地派出所以及属地街镇，定期对车站周边秩序开展联合整治，保障车站出入口周边环境与秩序。

（3）积极参与应急处置。突发事件情况下，根据预案调配增援警力，配合轨交车站将站内乘客疏散至地面，并与地面属地派出所做好工作衔接。

3．属地派出所长职责

（1）积极配合机制落实。配合做好“四长联动”各项机制建立和落实工作；定期参加“四长联动”工作例会，主动与轨交车站沟通联系，强化信息沟通和工作协调；积极参与“四长联动”联合演练，配合落实各项处置措施。

（2）积极配合联合整治。配合轨交车站、轨交公安以及属地街镇，定期对车站周边秩序开展联合整治，保障车站出入口周边环境与秩序。

（3）积极参与应急处置。突发事件情况下，根据预案调配警力，迅速赶赴现场，维护站外地面秩序，疏散人群、开辟绿色通道、疏导交通。

4．属地街镇长职责

（1）积极配合机制落实。配合做好“四长联动”各项机制建立和落实工作；定期参加“四长联动”工作例会，主动与轨交车站沟通联系，强化信息沟通和工作协调；积极参与“四长联动”联合演练，配合落实各项处置措施。

（2）积极配合联合整治。负责组织运用辖区组织资源、人力资源、设施资源，维护轨交车站出入口的环境秩序。配合轨交车站、轨交公安及属地派出所，定期对车站周边秩序开展联合整治，保障车站出入口周边环境与秩序。

（3）积极参与应急处置。做好相关志愿者招募和培训工作。突发事件情况下，根据预案组织各方力量增援车站，配合做好人群疏散等工作。

三、工作要求

（一）定期会商。属地派出所和街道要积极配合落实“四长联动”机制，定期参加“四长联动”工作例会，听取各责任单位的工作开展情况汇报，了解地铁各车站设置疏散引导标志标牌情况、相关单位的大客流应急疏散具体应急预案编制情况、志愿者队伍招募培训情况、轨道交通地铁站长承担“四长联动”应急处置机制联络工作进展情况等，协调解决“四长联动”工作推进中发生的问题，确保“四长联动”工作方案按时完成。

（二）预案编制。轨道交通车站、轨交公安、属地派出所和属地街镇要根据工作职责和应对流程，编制本单位大客流应急疏散的具体应急预案，明确联络方式、力量编成、人员位置、处置措施等。做好各长应急预案的相互衔接，根据车站的疏散条件研讨编制符合各自轨道交通车站的“四长联动”工作方案，解决应急联动处置中可能遇到的问题和突发状况，提高“四长联动”应急处置工作效率，确保事发后的应急保障流程和客流疏散措施落到实处。

（三）强化联动。针对轨道交通运营突发故障等应急状况，轨道交通车站内外发生大客流密集积压需要疏散的情况，各轨道交通车站、轨交公安、属地派出所和属地街镇要快速反应、紧密合作、有序联动，形成实施有效的应急联动处置机制，各长单位要依托轨道交通车站主动对接，并以路网各车站站长与轨交站点警长为“四长联动”机制双负责人为主开展工作。

（四）联动演练。由轨道交通车站牵头，每年组织一至二次应对大客流疏散的拉动演练，重点检验联络方式、应急力量位置、物资装备配置、导向标识设置等情况，确保应急处置措施落实到位、处置人员职责明晰。对于演练中发现的问题，相关单位要及时商讨和改进。

（五）措施保障。轨道交通车站、轨交公安、属地派出所和属地街镇要根据大客流安全疏散需要及各自具体应急预案明确的工作要求，落实人员力量、配备相关应急设施、应急装备、通讯设备和应急物资，为应对突发事件启动“四长联动”工作做好必要的保障。

四、工作安排

（一）第二季度： 2017年6月30日前，全区各轨道交通车站与属地街镇、派出所要全面完成“四长联动”应急处置工作的对接，成立四长联合工作小组。各轨道交通车站按“四长联动”应急处置组织机构备案表要求上报联系人，并组织实施“四长联动”应急处置方案的建立。

（二）第三季度：全面落实建立“四长联动”应急处置工作机制。2017年9月30日前，在全区已开通的轨道交通车站全面落实建立“四长联动”应急处置工作机制，建立例会制度、完成预案编制、人员培训演练和应急装备配置工作，确保机制有效运转。对于后续新开通站点必须在开通运营前实现“四长联动”应急处置机制同步落实。

（三）第四季度：检查“四长联动”应急处置机制建立落实情况。2017年10月起，区相关部门与各街镇重点开展督查。检查“四长联动”应急处置机制建立落实情况，并采取不提前预告方式进行拉练，检验各站点四长机制工作情况。
