# 上海市道路运输管理局关于公布2022年度机动车维修、机动车驾驶员培训、清障施救牵引行业AAA级质量信誉企业的通知

各有关单位：

经综合考核评定，上海南汇祝桥汽车销售服务有限公司、上海小昆山机动车驾驶技术学校、上海浦江桥隧运营管理有限公司等150家企业分别被评为2022年度上海市机动车维修（一、二类维修企业）、机动车驾驶员培训、道路清障牵引行业AAA级质量信誉企业，现予公布。

附件:1.2022年度上海市机动车维修行业（一、二类维修企业）AAA级质量信誉企业

2.2022年度上海市机动车驾驶员培训行业

AAA级质量信誉企业

3.2022年度上海市道路清障施救牵引行业

AAA级质量信誉企业

（备注：其余AA、A、B级企业的质量信誉考核等级情况可以在上海市道路运输管理局官网https://dlysj.sh.gov.cn/上进行查询）

上海市道路运输管理局

2023年5月8日
