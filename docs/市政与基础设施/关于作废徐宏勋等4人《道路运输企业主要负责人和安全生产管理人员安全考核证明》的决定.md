# 关于作废徐宏勋等4人《道路运输企业主要负责人和安全生产管理人员安全考核证明》的决定

上海新大都客运有限公司：

2021年8月16日，江苏省人民政府对《沈连高速盐城段"4-4"重大道路交通事故调查报告》进行了批复（苏政复[2021]48号），该调查报告认为，你公司存在未履行法定安全生产管理职责导致发生沈连高速盐城段"4-4"重大道路交通事故，造成11人死亡、19人受伤，直接经济损失1500余万元。

根据交通运输部《道路运输企业主要负责人和安全生产管理人员安全考核管理办法》第十七条规定，决定作废你公司以下4人《道路运输企业主要负责人和安全生产管理人员安全考核证明》：

1.姓名：徐宏勋；身份证号：31010**********212

2.姓名：王本强；身份证号：31010**********416

3.姓名：宗蒋娜；身份证号：32052**********523

4.姓名：冯智伟；身份证号：31010**********016

本决定自发布之日起生效，相关人员可在作废后参加安全考核考试合格后，持新《道路运输企业主要负责人和安全生产管理人员安全考核证明》到相关管理部门备案。

上海市道路运输管理局
