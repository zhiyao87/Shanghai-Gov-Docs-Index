# 上海市水务局关于印发《上海市供水可靠性管制计划（试行）》的通知

上海市水务局关于印发《上海市供水可靠性管制计划（试行）》的通知

沪水务〔2023〕723号

上海城投水务（集团）有限公司：

根据《上海市人民政府办公厅关于印发<上海市加强集成创新持续优化营商环境行动方案>的通知》（沪府办规〔2023〕1号）的要求，进一步提高上海供水可靠性，提升上海供水服务水平，经组织有关单位研究，并结合本市供水行业实际，制订了《上海市供水可靠性管制计划（试行）》，现予印发，请按照执行。各郊区供水企业参照执行。

特此通知。

上海市水务局

2023年9月25日
