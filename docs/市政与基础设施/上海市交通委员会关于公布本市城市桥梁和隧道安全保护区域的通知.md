# 上海市交通委员会关于公布本市城市桥梁和隧道安全保护区域的通知

临港新片区管委会、各区交通主管部门、市道运中心：

为进一步加强本市城市桥梁和隧道安全保护区管理，确保城市桥梁和隧道的结构安全，我委会同上海城投公路投资（集团）有限公司组织有关单位开展《道路桥梁和隧道结构安全保护技术标准》的编制工作。经市住房城乡建设管理委审核，批准为上海市工程建设规范，统一编号为DG/TJ 08-2455-2024，自2024年12月1日起实施。依据《上海市城市道路管理条例》第三十四条之规定，现将城市桥梁和隧道安全保护区域范围予以公布（见附件）。

请临港新片区管委会、各区交通主管部门对照上述技术标准，做好“城市桥梁、隧道安全保护区域内施工许可”审批，并做好批后监管工作。本市公路桥梁和隧道结构保护技术要求可参照上述标准执行。

特此通知。
