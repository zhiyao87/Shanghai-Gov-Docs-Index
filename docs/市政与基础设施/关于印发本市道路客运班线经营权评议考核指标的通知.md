# 关于印发本市道路客运班线经营权评议考核指标的通知

各有关单位：

根据《上海市道路运输管理条例》等相关规定，为进一步规范本市道路客运班线经营权评议考核工作，完善线路经营权管理制度，同时突出考核结果应用，强化结果导向，优化线路运营资源配置，现将本市道路客运班线经营权评议考核指标体系及相关要求明确如下：

一、关于评议考核指标体系

（一）关于指标设置。班线经营权评议考核指标主要包括资质条件、规范经营、安全生产、优质服务和社会评价5个方面，共计17项（具体试行标准详见附件）。相关指标根据客运市场的变化和营运服务需要，适时进行修订调整。

（二）关于考核评分。评议考核分为经营权年度考核和期末考核，期末考核为各年度考核的平均分。评议考核采取“打分制”，总分值为100分（有加分项可达110分），考核等级分为优秀、合格、不合格。其中，60分及以上为合格，不满60分为不合格，考核分数降序排列前一定比例为优秀，原则上优秀比例控制在5%以内。

二、关于加强考核程序和结果应用

（一）严格考核流程管理。市道运中心应根据评议考核标准具体实施评议考核。其中，年度考核应在当年内完成，由市道运中心负责将评议考核结果通知班线客运经营者，并报备市道路运输局。期末评议考核在客运班线经营期限届满当年内完成，市道运中心负责将期末评议考核结果报送市道路运输局，并由市道路运输局正式向行业公布。

（二）加强考核结果应用。道路客运班线经营权考核评议结果作为班线到期重新许可和日常管理的重要参考依据之一。原则上经营权到期重新许可时，期末考评结果为不合格且不符合重新许可条件的线路，不予重新许可。期末评议考核结果为合格且符合重新许可条件的线路，可视情给予4年经营权；结果为优秀的，可视情给予8年经营权。每年年度评议考核不合格的班线，整改期为三个月，整改期间由市道运中心负责加强对相关经营者督促指导，并列入重点监管名单强化日常监管，经整改仍不合格的，由相关部门依法依规予以处置。

三、关于联动监管协同

评议考核期间，市道路运输局负责总体牵头，统筹协调，确保评议考核工作有序开展。市道运中心负责及时组织评议考核，汇总考核结果，加强日常监管，督促客运企业规范经营。各相关单位应加强联动协同，共享监管信息，切实形成闭环机制，全面提升本市道路客运班线运营服务水平。
