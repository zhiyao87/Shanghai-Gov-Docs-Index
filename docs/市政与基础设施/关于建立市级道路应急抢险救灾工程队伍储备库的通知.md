# 关于建立市级道路应急抢险救灾工程队伍储备库的通知

市道运中心、各高速公路项目公司：

为规范本市公路与城市道路应急抢险救灾工程的管理，完善应急抢险救灾机制，根据《上海市应急抢险救灾工程建设管理办法》相关规定要求，我局遵循公正、公平、公开和竞争的原则，通过公开预选招标并综合评定，择优选择了检测鉴定、勘察、设计、监理、施工等五个类型的道路应急抢险救灾工程服务单位共计18家（具体名单详见附表），形成市级道路应急抢险救灾工程队伍储备库。储备库名单有效期为2024年1月1日-2026年12月31日。

政府投资的市级道路应急抢险救灾工程（工程认定及范围按《上海市应急抢险救灾工程建设管理办法》执行），项目建设主体应从储备库中通过比选或随机抽选，确定具备相应资质和能力的服务单位；社会投资的市级道路应急抢险救灾工程，由项目建设单位从储备库中或者储备库外自行选取具备相应资质和能力的服务单位。

特此通知。
