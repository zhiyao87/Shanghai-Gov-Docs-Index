# 上海市道路运输管理局关于印发 《上海市停车行业发展“十四五”规划》的通知

各有关单位：

根据市政府关于“十四五”规划编制的工作要求以及关于停车难综合治理、加强停车设施建设管理等工作部署，我局编制起草了《上海市停车行业发展“十四五”规划》，并已经12月27日市道路运输局2021年第19次局长办公会审议通过。现印发给你们，请结合实际贯彻落实。

特此通知。
