# 关于印发《杨浦区排水管理体制改革实施方案》的通知

区政府各委、办、局，各街道办事处及各有关单位：

经区政府同意，现将《杨浦区排水管理体制改革实施方案》印发给你们，请认真按照执行。

上海市杨浦区人民政府

2025年8月28日

杨浦区排水管理体制改革实施方案

根据《上海市排水管理体制改革方案》，为系统治理排水瓶颈问题，提升本区公共排水设施一体化运行效能和管理水平，加快建成与超大城市发展相适应的城镇排水管理体系，结合本区实际，制定本区落实市改革方案的具体实施方案如下。

一、基本情况

（一）拟移交设施基本情况

杨浦区公共排水设施目前主要由杨浦区水务管理事务中心管理，杨浦滨江南段区域部分公共排水设施目前由区滨江集团（或新建设施建设单位）管理。根据目前进度安排，计划按照市级方案要求先行移交区水务部门管理的公共排水设施，杨浦滨江南段区域部分公共排水设施待条件成熟后另行移交。

拟首批移交设施设备包括排水管道设施635.56公里，其中雨水管道222.68公里（主管154.84公里、支管67.84公里），污水管道142.19公里（主管125.43公里、支管16.76公里），合流管道270.69公里（主管192.23公里、支管78.46公里），窨井19148座、雨水口15951个、液位仪130个;排水泵站1座，即同济大学排水系统陆家浜泵站，为合流制防汛泵站;调蓄池6座（同济大学、新江湾东、民星北、松潘、周塘浜、周家嘴），目前正逐步建成开始试运行;移动泵车1辆、液压动力站3台。

具体移交设施设备量以移交协议和后续补充协议为准，未列入移交清单、未完成移交流程的排水设施仍由本区及权属部门负责管理。

（二）设施养护情况

1.拟首批移交的排水管道设施（635.56公里）目前现由上海杨浦市政养护建设工程有限公司负责养护。

2.拟移交的排水泵站（即陆家浜泵站）现由上海申浦城市基础建设有限公司负责养护。

3.拟移交的6座调蓄池目前建成未启用或建设中，均未投入使用，暂无养护单位，拟自试运行阶段起委托上海城投集团开展运维工作。

4.拟移交的移动泵车1辆（权属为杨浦区水务管理事务中心）、液压动力站3台（权属为市排水中心）。

（三）现状养护企业和人员情况

共有总包企业2家（上海杨浦市政养护建设工程有限公司、上海申浦城市基础建设有限公司），有效期内总包合同2个。其中，涉及区属国有企业1家（上海杨浦市政养护建设工程有限公司），共有员工约101人（包括劳务派遣21人），所有人员均参与市政工程（包括道路和排水）建设和运维养护工作，无法准确拆分企业涉水人员，移交人员待下阶段另行确定。

（四）其他排水设施设备情况

未纳入首批移交设施设备包括以下几类：

1.由杨浦区水务管理事务中心管理的五角场下沉式广场排水泵站、五角场下沉式广场自动扶梯排水泵站。

2.由杨浦区市政和交通管理事务中心管理的二军大地道泵站（人行）、黑山路地道泵站（人行）、四平路地道泵站、淞沪路地道泵站、黄兴路地道等道路下立交排水设施。

3.杨浦区通沟污泥处置站。

4.尚在新建项目建设单位管理范围，尚未移交区水务或市政部门的道路或下立交排水设施。

5.权属为上实融资租赁有限公司，由市排水中心租赁后移交杨浦区使用的2辆防汛泵车。

以上排水设施设备待下阶段根据市级部署，结合我区实际另行讨论移交接管工作。

二、改革目标

三、改革任务

（一）推进平稳有序移交

1.区级方案编制。区建设管理委（区水务局）牵头完成区级实施方案编制，经区政府审议后印发。

2.移交清单建立。2025年6月底前，区建设管理委（区水务局）完成移交底数清单建立;2025年9月底前，区建设管理委（区水务局）会同上海城投集团完成移交清单现场盘点、核实查验和清单锁定，完成移交资料整理，主要包括排水设施图纸资料、排水设施生产运行资料、设备机具资料、委托养护合同协议、人员档案资料等。（2025年6月—2025年9月）

3.人员意愿征询。上海城投集团尽快明确可提供岗位职责和工作待遇。杨浦城投集团完成国企人员政策宣贯，书面告知本市和我区排水管理体制改革有关政策和人员转隶工作情况。12月底前完成人员意愿征询和接受安置工作。区国资委做好行业指导。（2025年6月—2025年12月）

4.移交协议签订。根据上海市水务局《关于本市排水管理体制改革的工作提示（二）》，由杨浦区政府与上海城投集团签订排水设施管理移交协议，根据协议移交排水设施档案和技术资料，原则上于2025年12月底前完成;由杨浦区政府（或区政府统一授权的单位）与市水务局签订政府采购委托协议，由市水务局统一进行采购，杨浦区根据采购结果分别与运维单位签订运维合同。（2025年6月—2025年12月）

5.配套政策研究。区建设管理委（区水务局）配合市级部门研究制定三大片区更新改造和应急抢修资金渠道和建设机制，配套研究区建设管理委（区水务局）和上海城投集团在此机制中的职责定位和工作范围细分。区建设管理委（区水务局）落实纳入移交范围的公共排水设施大中修政策研究的相关工作安排。（2025年5月—2025年12月）

6.既定专项任务落实。排水管道结构性病害修复、雨水系统提标改造、“消除积水”专项行动等涉及工程类项目仍由原中标单位继续执行。雨污混接普查和整治工作中，普查工作仍由原中标单位继续执行，整治工作仍由问题排水户自行组织整改落实。改革过渡期中，杨浦城投集团仍应继续配合区建设管理委（区水务局）开展既定各项任务。改革过渡期和移交接管工作完成后，上海城投集团作为杨浦区公共排水设施运维管理单位，应配合区建设管理委（区水务局）开展雨污混接普查和整治有关工作，落实公共排水管道周期性巡查机制，强化公共排水设施雨污混接问题长效管理，协助问题排水用户开展排水接入工作。

（二）构建系统运营体系

1.防汛体系建设。2025年汛期，上海城投集团派出工作组参与区防汛办、杨浦区水务管理事务中心（或杨浦市政养护公司）防汛防台应急响应工作，了解掌握我区防汛防台应急响应期间防汛指挥体系与现场处置流程。2025年底前，区建设管理委（区水务局）和上海城投集团共同研究确定我区汛期重点地区、重要用户及易积水清单梳理，上海城投集团根据杨浦区情况建立符合区域防汛防台工作需求的专业防汛抢险队伍。上海城投集团2026年起负责杨浦区涉及改革移交的公共排水设施防汛防台工作，并于2026年4月底前将防汛防台专项预案报区防汛办、区建设管理委（区水务局）。2026年5月底前，杨浦区完成区级防汛防台预案修编，将上海城投集团作为成员单位纳入指挥体系。（2025年6月—2026年5月）

2.感知体系建设。上海城投集团牵头在2026年底前建立三大片区排水感知体系和模拟评估系统建设，根据杨浦区需求开展针对性优化提升并提供技术支持和数据共享。杨浦区对排水感知体系和模拟评估系统建设提供必要的支持和配合。（2025年6月—2026年12月）

上海城投集团与区建设管理委（区水务局）共享相应片区的排水感知体系的实时监测数据和模型模拟结果，实现动态监管。针对感知体系和模拟评估系统发现问题，按照责任分工落实整改。

3.工作机制建设。现阶段排水许可、行政执法、热线处置等的工作机制和流程不变，上海城投集团按照市、区有关部门的要求落实好相关工作。（2025年6月—2026年12月）

4.泵河联动到位。上海城投集团在开展一体化运维管理的过程中，强化排水管道和防汛泵站统一调度管理，实时动态分析防汛泵站排水需求，强化泵站放江信息及时传送，提前与河道管理部门沟通做好泵河联动处置准备。（2025年6月—2026年12月）

（三）强化成本绩效管理

1.完成成本绩效分析。落实移交的公共排水设施日常运维经费和大中修经费。2025年5月底前完成成本绩效分析报告，由区建设管理委（区水务局）会同区财政局审核后上报市水务局。（2025年1月—2025年12月）

2.明确考核制度要求。原则按照市水务局牵头制定的一体化运维管理绩效考核办法，可根据我区实际情况，在协议和合同中另行明确适合我区的区域性指标要求。2026年起，市、区水务部门联合对上海城投集团开展一体化运维管理绩效考核，并完善相关管理制度。

3.明确资金结算方式。原则按照市级研究形成的统一公共排水设施日常运维经费标准及结算协调机制，可根据我区实际情况，在协议和合同中另行明确适合我区的资金结算要求。

四、职责分工

（一）区建设管理委（区水务局）、区水务中心

负责杨浦区排水管理体制改革的总体落实推进;负责全面梳理移交设施、设备、人员、合同等底数清单;负责辖区内移交排水设施运维的监督检查和绩效考核;负责对辖区内上海城投集团运维管理情况进行指导和监管;负责按照统一标准向区财政局申请移交排水设施日常运维资金;根据市水务局、市财政局要求落实统一核算机制。辖区内其他排水行业监督管理职责不变。

（二）区财政局

负责公共排水设施运维成本绩效分析相关内容的审核、配合市财政局研究形成统一的公共排水设施运维经费标准，负责按照统一标准落实移交排水设施日常运维资金，并纳入区级财政预算。负责做好移交后市级要求的雨污混接普查和整治、排水管道结构性病害修复、雨水系统提标改造、“消除积水”行动等既定专项任务的资金安排。

（三）区国资委

按照“人随事转，个人自愿”原则，配合区城投集团做好涉及事转区属国有企业人员转移工作，负责牵头涉及事转区属国有企业编制稳定方案，明确在移交人员范围内但无意愿移交人员和剩余人员的处置方案，负责其他相关事务以及潜在稳定性风险应对策略等内容，并做好稳定工作。

（四）区应急局

会同区建设管理委（区水务局）指导上海城投集团做好防汛防台和排水应急突发事项的处置工作，并向区建设管理委（区水务局）提供上海城投集团绩效考核有关意见。

（五）上海城投集团

负责按照市水务局制定的公共排水设施运维服务标准落实杨浦区公共排水设施运维管理，包括日常运行调度、巡查养护、设施大中修、更新改造、应急抢修等，以及经市政府明确的其他专项治理工作;负责杨浦区防汛排水抢险、重大活动排水保障工作;负责接管杨浦区新建公共排水设施，并加强排水设施信息的动态更新管理;负责排水设施一体化运行调度信息系统建设和维护并根据杨浦区需要提供数据接口与技术保障;负责涉及移交排水设施的热线、网格化、信访等事件的处置;负责做好排水应急保障服务;参与排水规划编制;参与杨浦区新建公共排水设施的前期研究和竣工验收;配合排水接入现场踏勘、接入方案技术指导、接入项目验收等，并配合对杨浦区排水户雨污水管接驳情况、排水及水质情况进行管控;配合杨浦区雨污混接整治、管道结构性病害修复等排水专项任务;配合开展排水行政许可、行政执法;配合杨浦区做好改革过程中的稳定工作。

（六）杨浦城投集团、杨浦市政养护公司

负责配合梳理移交设施、设备、人员、合同等底数清单;负责配合开展拟移交设施设备的现场盘点、核实查验;负责配合开展雨污混接普查和整治、排水管道结构性病害修复、雨水系统提标改造、“消除积水”行动等既定专项任务;负责做好改革过程中国企人员意愿征询和人员稳定工作。

（七）申浦公司

负责配合梳理陆家浜泵站设施、设备底数清单;负责配合开展拟移交设施设备的现场盘点、核实查验;负责做好改革过程中人员稳定工作。

五、组织保障

为顺利推动移交工作稳步实施，按照市级文件精神及市水务局工作要求，成立由区分管领导牵头的工作专班，区相关部门、上海城投集团为成员单位，建立工作例会制度，及时协调解决改革中遇到的难点问题，抓好工作落实。
