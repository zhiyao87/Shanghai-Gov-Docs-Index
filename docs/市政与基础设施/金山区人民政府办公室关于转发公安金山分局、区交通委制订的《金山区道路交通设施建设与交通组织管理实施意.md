# 金山区人民政府办公室关于转发公安金山分局、区交通委制订的《金山区道路交通设施建设与交通组织管理实施意见》的通知

各镇人民政府、街道办事处、工业区管委会，区政府各委办局、各区属单位：

公安金山分局、区交通委制订的《金山区道路交通设施建设与交通组织管理实施意见》已经区政府同意，现转发给你们，请认真遵照执行。

2017年2月9日

金山区道路交通设施建设与交通组织管理实施意见

为进一步规范本区道路交通设施建设和交通组织管理工作，明确管理职责，理顺管理机制，优化道路交通组织，确保道路交通设施完好，保障道路交通安全、畅通、有序，依据《中华人民共和国道路交通安全法》《中华人民共和国公路法》《上海市城市道路管理条例》《市交通委、市公安局关于明确交通标志、标线等交通设施管理职责的通知》（沪交设〔2014〕583号）等相关规定，结合本区实际，按照职责清晰、各司其职、协同配合的原则，特制定本意见。

一、适用范围

（一）本意见所称道路是指：本行政区域范围内除高速公路、国（省）道、农村公路以及上海石油化工股份有限公司封闭管理区域内道路以外，由区、街镇（工业区）及新城区发展公司投资建设管理的公路和城市道路。

（二）本意见所称道路交通设施是指：交通标志、交通标线、交通信号灯、交通可变信息屏（诱导屏）、监控设备、电子警察以及其他交通设施。

（三）本意见所称交通组织是指：交通分离，限行措施，交通信号灯相位设置及配时，建设工程项目新、改、扩建出入口，公交站点设置，路内停车点设置等。

二、管理职责

（一）区交通委是全区道路建设管理工作的行政主管部门，负责区管道路交通标志、交通标线、可变车道、交通可变信息屏（诱导屏）、隔离栏杆等交通设施的规划、建设和管理；指导和监督街镇（工业区）及新城区发展公司管辖道路相应交通设施规划、建设和管理工作。

（二）公安金山分局交通管理部门（以下简称“公安分局交管部门”）是全区道路交通安全管理工作的主管部门，负责全区道路交通组织调整及实施；负责全区交通设施中涉及交通信号灯、“电子警察”等设施的规划、建设和管理；指导和监督街镇（工业区）及新城区发展公司管辖道路相应交通设施规划、建设和管理。

（三）区经委、区司法局、区财政局、区环保局、区规划土地局、区住房保障房屋管理局、区城管执法局、区市场监管局等部门应当按照各自职责，共同做好道路交通管理工作。

（四）街镇（工业区）及新城区发展公司是管辖范围内在用自管道路交通设施建设、管理和维护的责任主体，配合区交通委及公安分局交管部门等各职能部门做好在用道路交通设施及交通组织管理工作。

三、交通设施建设与管理

（一）设施建设

1.道路交通设施规划、建设和管理应符合相应技术规范标准和相关规定。

2.建设单位应向区交通委和公安分局交管部门提出道路交通设施审核申请，区交通委和公安分局交管部门按照各自职责分别进行审核，并出具审核意见，审核通过后予以实施。

3.道路竣工后，建设单位应向区交通委和公安分局交管部门申请验收，区交通委和公安分局交管部门组织联合验收。验收完成后，双方分别出具验收意见书。对不符合建设要求的，建设单位按照验收意见书进行整改，整改完毕后再申请给予复验。

4.验收合格后由建设单位负责做好相关资料的整理及移交工作。正常运行3个月后，办理相关的接管手续。

（二）设施运行维护

1.区交通委、公安分局交管部门、各街镇（工业区）及新城区发展公司设施权属部门应建立道路交通设施运行、维护机制，确定专业运维队伍，组织开展日常巡视，及时发现整改设施故障或安全隐患；每年至少组织1次集中排查整治，保障道路交通设施完好。

2.区交通委、各街镇（工业区）及新城区发展公司对符合施划标线的道路鼓励采用新技术、新材料、新工艺的标线施划方式进行施划；对已施划标线的道路，热熔漆复划每两年不少于1次，冷漆复划每年不少于2次。

3.因交通组织调整，需新增、调整、撤除交通设施的，由公安分局交管部门会同设施权属部门制定交通组织和相应交通设施新增、调整、撤除方案，审核通过后，由权属部门组织实施并进行联合验收。

4.因道路养护、建设工程、沿街建筑物或构筑物维修等需临时占用道路或影响正常道路交通的，权属部门应向区交通委和公安分局交管部门提出申请，批准后方可实施。对道路或设施抢修时需要采取紧急交通措施的，区交通委、各街镇（工业区）及新城区发展公司应在组织抢修的同时及时告知公安分局交管部门。

5.道路维修期间的临时性、应急性标志、标线由维修单位负责设计、设置和维护，公安分局交管部门负责审核及监管。施工结束时，应恢复原道路交通管理设施，由公安分局交管部门和区交通委、街镇（工业区）及新城区发展公司负责联合验收。

6.遇突发事件及重大安保活动需要对交通组织进行临时调整的，由公安分局交管部门会同区交通委提出交通组织调整方案，由权属部门负责相关交通标志、标线等配套设施的组织实施。

7.各街镇（工业区）及新城区发展公司管辖道路的交通设施，由权属部门或者其委托的单位负责养护、维修，并接受道路、交通设施管理部门的监督、检查。产权移交前自行负责落实管养工作。

四、交通组织管理

（一）道路交通组织要与道路建设同时规划，同时设计。

（二）公安分局交管部门需要对现有道路交通组织(交通分离、限行措施、交通信号灯相位设置及配时)进行调整的，应会同区交通委、街镇（工业区）及新城区发展公司确定调整方案并组织实施。

（三）区交通委、街镇（工业区）及新城区发展公司对影响交通的道路施工或需要对现有道路交通组织(交通分离、限行措施、交通信号灯相位设置及配时)进行调整的，由其委托专业设计单位编制临时交通组织调整方案，报公安分局交管部门审核通过后方可实施。

（四）区管道路临时停车点新增、调整和撤除的，由公安分局交管部门会同区交通委编制方案，方案确定后，由权属部门组织实施。

街镇（工业区）及新城区发展公司管辖道路临时停车点新增、调整和撤除的，由街镇（工业区）及新城区发展公司提出申请并拟订方案，经公安分局交管部门审核同意后，由街镇（工业区）及新城区发展公司组织实施。

（五）新辟公交线路由区交通委制定计划并报公安分局交管部门审核，审核通过后由区交通委组织实施。

现有公交线路、站点有调整需求的，由该公交线路运营公司提出申请，报区交通委、公安分局交管部门审核。已投入使用的公交站点发现安全隐患的，区交通委应督促有关责任单位按照有关标准，及时排除隐患。

新增公交站点原则上应配套公交港湾式停靠站。

五、经费保障

（一）区管道路交通设施管理、维护，范围内突发事件及重点安保活动专项资金由区财政局负责落实保障。

（二）街镇（工业区）及新城区发展公司管辖道路交通设施管理、维护，范围内突发事件及重点安保活动专项资金由各街镇（工业区）及新城区发展公司自行落实保障。

（三）道路交通设施管理、维护资金应按照道路等级、数量及管养定额，逐年核定并足额落实保障。

六、问责

根据《金山区区管干部和机关工作人员有错与无为行为问责办法》，由区问责办对未履行职责或违反本意见的“有错或无为情形”，区分直接责任、主要领导责任、重要领导责任实施问责。

七、附则

（一）本意见由区交通委、公安分局交管部门负责解释。

（二）本意见自印发之日起施行。
