# 上海市水务局关于印发《上海市生产建设项目全国水土保持信息管理系统资料录入与管理规定（试行）》的通知

上海市水务局关于印发《上海市生产建设项目全国水土保持信息管理系统资料录入与管理规定（试行）》的通知

沪水务〔2021〕258号

各区水务局、临港新片区管委会、局属相关单位：

为贯彻落实《水利部办公厅关于推进水土保持监管信息化应用工作的通知》（办水保〔2019〕198号），进一步加强对上海市生产建设项目水土保持信息管理系统资料的录入与管理，明确资料录入责任，确保系统资料安全、可靠，我局制定了《上海市生产建设项目全国水土保持信息管理系统资料录入与管理规定（试行）》，现予印发，请遵照执行。

特此通知。

上海市水务局

2021年4月21日
