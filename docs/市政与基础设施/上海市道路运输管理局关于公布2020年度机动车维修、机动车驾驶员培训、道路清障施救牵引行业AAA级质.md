# 上海市道路运输管理局关于公布2020年度机动车维修、机动车驾驶员培训、道路清障施救牵引行业AAA级质量信誉企业的通知

各有关单位：

经综合考核评定，上海强生集团汽车修理有限公司、上海小昆山机动车驾驶技术学校、上海高架养护管理有限公司等94家企业分别被评为2020年度上海市机动车维修（一、二类维修企业）、机动车驾驶员培训、道路清障施救牵引行业AAA级质量信誉企业，现予公布。

根据《上海市交通委员会关于印发<2021年上海市交通运输社会信用体系建设工作要点>的通知》（沪交科〔2021〕247号），本市机动车维修行业积极推进质量信誉考核结果应用。经研究决定，对于质量信誉考核结果为AAA级的维修企业，鼓励增加经营范围；优先推荐参加全国诚信企业评比；优先推荐政府购买服务事项；在本年度中免于日常上户监管（危险货物运输车辆维修、大中型客车维修企业最多组织一次）。

附件：1.2020年度上海市机动车维修行业（一、二类维修

企业）AAA级质量信誉企业

2.2020年度上海市机动车驾驶员培训行业AAA级质

量信誉企业

3.2020年度上海市道路清障施救牵引行业AAA级质

量信誉企业

（备注：其余AA、A、B级企业的质量信誉考核等级情况可以在上海市道路运输管理局官网https://dlysj.sh.gov.cn/上进行查询，考核等级将根据实际情况进行动态调整。）
