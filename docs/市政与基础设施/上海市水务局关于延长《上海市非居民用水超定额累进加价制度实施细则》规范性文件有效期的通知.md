# 上海市水务局关于延长《上海市非居民用水超定额累进加价制度实施细则》规范性文件有效期的通知

上海市水务局关于延长《上海市非居民用水超定额累进加价制度实施细则》规范性文件有效期的通知

沪水务规范〔2024〕2号

各有关单位：

经评估，并经2024年7月 30日局长办公会审议通过，《上海市非居民用水超定额累进加价制度实施细则》（沪水务规范〔2020〕5号）继续实施，有效期延长至2029年7月31日。请遵照执行。

特此通知。

上海市水务局

2024年7月31日
