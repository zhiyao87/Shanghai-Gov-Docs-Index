# 金山区人民政府办公室转发区建设交通委《关于金山区农村（乡村）公路管理养护体制改革方案》的通知

各镇人民政府、街道办事处、金山工业区管委会，区政府各委、办、局，各区属单位：

经第60次区政府常务会议研究同意，现将区建设交通委《关于金山区农村（乡村）公路管理养护体制改革方案》予以转发，请各相关单位遵照执行。

二〇一〇年六月二十四日

关于金山区农村（乡村）公路管理养护体制改革方案

为进一步加强本区农村公路管理养护，充分保障农村公路在新农村建设中的作用，根据《国务院办公厅关于印发农村公路管理养护体制改革方案的通知》（国办发〔2005〕49号）和“上海市人民政府办公厅关于印发上海市农村（郊区）公路管理养护体制改革实施方案的通知”（沪府办〔2007〕50号）（下称《市改革方案》）的精神，结合本区的实际情况，就管理养护体制改革提出如下改革方案：

一、指导思想

以邓小平理论和“三个代表”重要思想为指导，认真贯彻执行党的十七大的精神，落实科学发展观。以建设新农村、构建和谐社会为目标，积极推进农村公路管理养护体制改革。建立健全以政府投入为主的稳定的养护资金渠道，完善农村公路管理养护体系，推行养护作业市场化机制。实现本区农村公路管理养护工作正常化、规范化，全面提高农村公路管理养护质量，充分发挥农村公路在建设社会主义新农村进程中的重要作用。

二、组织机构

成立以区政府分管副区长为组长；区建设交通委主任、区政府办公室副主任为副组长；区建设交通委、区发展改革委、区财政局、区水务局、区人力资源社会保障局、各镇、金山工业区分管领导为成员的金山区农村公路管理养护体制改革领导小组。协调、推进金山区农村公路管理养护体制改革工作。下设办公室，负责农村公路管理养护体制改革的具体工作。

三、目标和进度

根据《市改革方案》的总体要求，按照“总体规划，分步推进”的原则，2010年上半年明确区、镇管养职能分工和职责；落实农村公路管理养护资金来源和结构，以保障农村公路管理养护资金的正常使用，建立完善农村公路管理养护制度；下半年基本建立本区农村公路管理养护体系，理顺区、镇两级农村公路管理养护关系。逐步建立符合本区农村实际和社会主义市场经济要求的农村公路管理养护体制和运行机制，实现在设施量范围内的农村公路“有路必养”，确保农村公路通畅、安全。

四、管理养护形式和范围

（一）管理养护形式

对区公路管理部门确认的农村公路（指已纳入本市公路统计里程〈亦称设施量〉、但不属于县道及其以上公路的镇、村公路，下同），逐步纳入区公路管理部门的管理养护范围，建立健全统一领导、分级负责、以区为主的农村公路管理养护体制。

1、建立以区政府为农村公路养护责任主体，各镇人民政府、金山工业区管委会为配合主体，区建设交通委为行政主管部门，区公路管理署为具体管理机构，各镇人民政府村建规划办公室、金山工业区规划建设部（下称村建规划办）为配合管理机构的农村公路管理养护体系。

2、区公路管理机构按市政府有关文件要求，充实农村公路管理科室人员，增加技术管理人员2—3人，路政管理执法人员2名；配备必要的技术装备，负责本区农村公路管理养护、计划管理、技术管理、日常养护、大中修工程管理、资金管理、路政管理和业务指导、服务工作。

3、各镇、金山工业区村建规划办受区公路管理机构委托负责本辖区农村公路管理养护工作。村建规划办下设农村公路管理站具体实施农村公路管理养护工作，其行政上受村建规划办领导，业务上受区公路管理机构管理和指导，根据各自辖区内农村公路实际设施量，配备3—5名管理人员，其中路政协管员1名。区财政在农村公路养护经费中按管理人员数给予农村公路管理站3万元/人/年补贴。

（二）管理养护范围和设施量确认

以2008年度列入区农村公路养护补贴的设施量，为确认的日常管理养护范围。

新增农村公路设施量，需经区公路管理部门按上海市农村公路技术标准验收合格后予以确认。

五、职责分工

（一）区人民政府是本区农村公路管理养护的责任主体，全面负责本区农村公路的管理养护工作；负责筹措和落实农村公路管理养护资金；批准本区农村公路管理养护的有关规定。

（二）区建设交通委是本区农村公路管理养护的行政主管部门，主要职责：

1、负责批准本区农村公路日常养护、大中修计划，并报市公路主管部门核备；

2、负责对本区农村公路养护资金使用的管理工作；

3、负责对本区农村公路管理养护工作的实施进行监管、督促、检查和评比工作；

4、协调各镇、金山工业区做好农村公路路产、路权的保护工作；

5、编制本区农村公路建设和管理养护规划；

6、制定本区农村公路管理养护的有关办法和规定。

（三）区公路管理署是本区农村公路管理养护的管理机构，主要职责：

1、负责编制本区农村公路日常养护计划、大中修计划；

2、负责编制本区农村公路日常养护经费、大中修工程项目资金的测算工作，并正确使用本区农村公路养护、大中修资金；

3、负责本区内农村公路日常养护工程和大中修工程的招投标工作；

4、对本区农村公路日常养护工程和大中修工程安全、质量、进度进行监督、检查、验收，并及时上报区主管部门和市行业管理部门；

5、负责本区农村公路路政管理工作，指导各镇、金山工业区做好路产路权的保护工作；

6、组织各镇、金山工业区农村公路管理人员的培训工作。

（四）各镇人民政府、金山工业区管委会是本辖区农村公路管理养护的配合主体，配合区人民政府做好农村公路管理养护工作；负责筹措本辖区承担的农村公路养护资金。

（五）各镇、金山工业区村建规划办是本辖区农村公路管理养护的管理机构，负责本辖区农村公路管理养护工作，主要职责：

1、编报本辖区农村公路日常养护计划和大中修计划；

2、配合做好本辖区内农村公路日常养护工程和大中修工程项目的招投标工作；

3、负责本辖区农村公路日常养护工程和大中修工程项目实施工作，做好日常养护工程和大中修工程项目的安全、质量、进度的日常管理工作；

4、负责本辖区农村公路路产、路权的保护工作；配合区公路管理机构在本辖区内实施农村公路路政管理工作；

5、负责本辖区农村公路灾害性天气和突发事件的应急处置工作，制定本辖区农村公路应急预案，落实应急处理人员。

六、资金来源，出资比例及使用管理

农村公路管理养护资金遵循多方筹措、分级管理、专户存储，专款专用原则，任何单位和个人，不得挪用、占用农村公路管理养护资金。

（一）管理养护资金来源

1、成品油价格和税费改革返还收入通过转移支付方式安排的养路费专项资金；

2、按照市级专项资金区、镇配套部分；

3、市财政安排的管理养护其他专项补贴资金；

4、其他方式收取和筹措的农村公路养护资金。

（二）养护资金出资比例

根据《国办通知》和《市府办通知》等有关文件的精神。农村公路管理养护资金采用由市、区、镇三级政府财政共同出资的原则。

1、农村公路日常养护费按《上海市公路设施养护维修年度经费定额（2002）》进行估算编制。日常养护费中的道路保洁、绿化养护、路肩边坡（包括附属设施）整理费用由相关镇承担（约占日常养护费的40-50%），其余费用由区（市）承担。

2、农村公路大中修工程项目取费按上海市建设工程定额管理站《上海市市政工程预算定额（2003）》进行编制。工程资金由市、区财政出资70% ，镇财政出资 30% 。

3、桥梁新（改）建工程，按《金山区桥梁养护维修管理办法》（金府〔2009〕17号）规定执行。

（三）管理养护资金使用

1、农村公路管理养护资金，主要用于农村公路日常养护（含小修）、大中修工程及对各镇、金山工业区农村公路管理人员的经费补贴。

2、养护资金由区建设交通委会同区财政局根据年度农村公路日常养护经费计划及大中修计划经费测算，统筹安排。区建设交通委根据年度财政计划定期拨付农村公路日常养护经费，农村公路大中修工程项目应根据进度及时拨付。

3、各镇人民政府、金山工业区管委会应将本辖区承担的农村公路管理养护资金列入本年度镇级财政预算计划，并及时拨付本辖区农村公路管理机构。上级财政管理部门有权督促、检查镇财政部门的计划确定和拨付情况，确保镇级财政承担的农村公路管理养护资金到位。

4、农村公路管理养护机构，应正确使用农村公路管理养护资金，确保养护资金足额用于农村公路日常养护和大中修工程项目。

5、农村公路日常养护资金实行专户专储、专款专用的原则，及时公开农村公路管理养护资金收支情况，并接受上级公路主管部门和同级财政管理部门的监管和检查。审计部门要定期对农村公路使用情况进行审计。

七、养护作业管理

（一）农村公路管理养护应合理配置技术管理人员和装备，逐步实施信息化管理。

（二）推行养护作业市场化，农村公路的大中修项目、养护项目，投资总额在30万元以上—200万元以下的应当采取招标的方式选择施工、养护队伍；200万元以上项目应当面向社会公开招标，采用合同管理制、工程监理制、工程结算审价制；30万元以下的项目、难以通过市场化运作的特殊养护作业或者简单的日常养护，应采取适当的方式确定养护主体。

（三）区、镇农村公路管理养护机构应按照国家及本市有关农村公路技术规范、标准和操作流程对农村公路进行管理和养护，确保农村公路处于良好的技术状态，保障农村公路安全通行。

八、监督检查、考核奖励

（一）区公路管理机构要根据市农村公路管理养护标准，加强日常养护巡查力度，每季度对各镇、金山工业区农村公路管理站的管理养护情况进行检查，并将检查结果报区建设交通委。

（二）区建设交通委制定本区农村公路管理养护检查考核办法，每半年进行一次检查考核，年末根据检查考核结果，对各镇、金山工业区农村公路管理站进行物质和精神奖励。

九、附则

（一）本改革方案由区建设交通委负责解释。

（二）区建设交通委负责制定与本改革方案相关的实施细则。

（三）本改革方案自区人民政府办公室转发后实施。
