# 关于印发《无驾驶人智能网联汽车车身标识及装置要求》《智能网联汽车安全员培训和管理规范》《智慧道路建设规范》的通知

关于印发《无驾驶人智能网联汽车车身标识及装置要求》《智能网联汽车安全员培训和管理规范》《智慧道路建设规范》的通知

沪自贸临管委〔2024〕35号

管委会各部门、各直属单位，临港新片区各镇、各开发公司、各有关单位:

为贯彻落实《临港新片区智能网联汽车创新引领区发展三年行动方案（2023-2025年）》，构建临港新片区智能网联汽车标准体系，以标准创新推动临港新片区智能网联汽车智慧交通建设，实现智能网联汽车标准规范的先行先试，打造标准创新引领新示范，管委会组织制定了《无驾驶人智能网联汽车车身标识及装置要求》《智能网联汽车安全员培训和管理规范》《智慧道路建设规范》，请认真贯彻落实。

中国（上海）自由贸易试验区临港新片区管理委员会

2024年4月3日
