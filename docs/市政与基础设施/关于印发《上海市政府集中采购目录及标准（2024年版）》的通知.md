# 关于印发《上海市政府集中采购目录及标准（2024年版）》的通知

各市级预算单位、各区财政局：

根据《中华人民共和国政府采购法》和《上海市政府采购实施办法》相关规定，以及《财政部关于印发〈地方预算单位政府集中采购目录及标准指引（2020年版）〉的通知》（财库〔2019〕69号）要求，结合本市政府采购工作实际，我局编制了《上海市政府集中采购目录及标准（2024年版）》，已经市政府批准，现印发给你们，从2024年1月1日起实施。

上海市财政局

2023年12月22日
