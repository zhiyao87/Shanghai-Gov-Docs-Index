# 上海市水务局关于进一步做好水土保持相关工作的通知

上海市水务局关于进一步做好水土保持相关工作的通知

沪水务〔2023〕244号

各区水务局、临港新片区管委会：

为全面贯彻党的二十大会议精神，推进落实中共中央办公厅、国务院办公厅《关于加强新时代水土保持工作的意见》（以下简称《意见》），结合上海实际，推进本市新时代水土保持高质量发展，现就做好相关重点工作通知如下：

一、细化落实水土保持各项工作任务

各单位应将《上海市水土保持规划修编（2021-2035年）》（以下简称《规划》）作为做好区域内水土保持管理实施的依据，根据《规划》明确的具体任务和重点项目，结合区域实际，进一步细化区级工作举措，指导相关乡镇（街道）落实各项工作，可不再单独编制区级水土保持规划。

二、深化水土保持目标责任考核制度

各区应逐步建立区人民政府对乡镇（街道）人民政府的水土保持目标责任考核制度，健全区负总责，乡镇（街道）抓落实的工作机制，不断压实水土保持责任，持续加强水土保持组织建设、制度建设、队伍建设，推进解决重点难点问题。

三、严格生产建设项目水土保持监管

各单位应加强水土保持监管能力建设，保障经费、装备和人员投入，确保所辖区域范围内生产建设项目水土保持监管全覆盖。强化每年度水利部和市级加密遥感监管图斑违法违规项目整改，建立健全“周调度，月通报”工作机制，不断提升整改效率。在落实易发区生产建设项目批后监管和非易发区遥感监管图斑项目监督检查的基础上，可不再单独开展区级遥感监管。

特此通知。

上海市水务局
