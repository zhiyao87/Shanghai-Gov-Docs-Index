# 关于印发《上海市小型综合管廊规划设计导则》的通知

各区规划资源局、各派出机构、各相关单位:

为落实国家《城市综合管廊工程技术标准》（2025年修订版）要求，推动上海市市政基础设施集约化建设，组织编制《上海市小型综合管廊规划设计导则》。现予印发，请按照执行。
