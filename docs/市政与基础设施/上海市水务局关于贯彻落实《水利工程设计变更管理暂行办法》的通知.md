# 上海市水务局关于贯彻落实《水利工程设计变更管理暂行办法》的通知

上海市水务局关于贯彻落实《水利工程设计变更管理暂行办法》的通知

沪水务〔2021〕236号

各区水务局（管委会），各项目法人单位，局属相关单位：

为适应当前水利建设新形势，落实好水利改革发展总基调，进一步规范设计变更管理，水利部修订了《水利工程设计变更管理暂行办法》（以下简称《暂行办法》）并予以印发（水规计〔2020〕283号），现转发给你们，并结合本市实际提出有关工作要求，请各单位和部门认真贯彻执行。

一、强化责任落实

各级水行政主管部门要强化水利工程设计变更责任管理；项目法人应当提升管理水平，严格执行项目建设程序和批复的初步设计文件，加强设计变更管理，严控重大设计变更，减少一般设计变更；勘察设计单位应当着力提高勘察设计水平，确保勘察、设计文件满足规定深度要求，并严格设计变更文件编制；施工单位应当严格按照初步设计批复文件施工，除《暂行办法》第十八条规定的特殊情况外，严禁未审批先施工；监理单位应当按照经批准的初步设计文件和设计变更文件进行监理。

二、严控变更标准

本市水利工程重大设计变更和一般设计变更的划分按照《暂行办法》第八条和第九条的规定执行。本市中小型水利工程凡涉及下列情况之一的，按照重大设计变更管理规定执行：

（一）工程任务和规模、工程等级及设计标准发生变化或调整的；

（二）《暂行办法》第八条中涉及的工程布局及建筑物、水力机械、金属结构等内容发生变化的；

（三）线性水利工程的位置轴线局部调整超过50米的、主要水工建筑物基础处理方案变更长度连续超过50米的和主要水工建筑物上部结构型式变更连续超过100米的。

（四）线性水利工程内容局部变化调整虽不超过重大设计变更长度，但对工程任务和规模、工程等级及设计标准产生变化或调整的，以及对质量、安全、工期、投资、效益、环境和运行管理产生重大影响的。

三、规范变更程序

水利工程设计变更应当按照水利部《暂行办法》规定的程序进行审批，采用分级管理制度，项目法人应当加强与主管部门事前、事中、事后沟通协调。

重大设计变更文件应当由项目法人按原报审程序报原初步设计审批部门审批，报审材料应当包括：重大设计变更请示、重大设计变更报告、财务监理审核意见、原初步设计申报单位审核意见（会议纪要）；涉及开发任务变化和工程规模、设计标准、总体布局等方面的重大设计变更应征得可行性研究报告批复部门的同意。

一般设计变更文件应当由项目法人组织有关参建方研究确认后实施变更（必要时可组织专家评估），并原则上按照每月一次报项目主管部门核备（有特殊情况一事一核备），项目主管部门认为必要时可组织审批。按照《暂行办法》第二十三条 “项目竣工时应当全面检查竣工项目是否符合批准的设计文件要求”，本市一般设计变更核备部门为竣工验收牵头部门：

（一）市级财力和市财政专项的市级水利基本建设项目以及市级项目法人承担的水利专项项目，按照竣工验收工作分工分别报市水务局相关处室核备；河道整治类和圩区改造类水利专项项目由区水务局审核后报市水利管理事务中心备案；区堤防维修专项由区水务局审核后报市堤防泵闸建设运行中心备案。

（二）区（管委会）级水利工程由区（管委会）另行明确。

四、加强监督管理

任何单位或者个人不得擅自变更已经批准的初步设计，不得肢解设计变更规避审批。各级水行政主管部门按照职责分工负责对水利工程的设计变更实施监督管理，发生《暂行办法》第二十条所述行为时应当责令其改正，并依据相关法规追究相关责任单位和责任人的责任，有关行为记录到水利部及本市信用信息平台。

五、建立廉政机制

各级水行政管理部门和项目法人应当进一步完善水利工程设计变更工作制度，强化制度约束，严格相关岗位人员管理，严肃部门会签管理，规范设计变更审批工作规则和流程，建立水利工程设计变更长效廉政防控机制，落实防控措施，防范部门岗位廉政风险，确保水利工程设计变更审批公平、公开、公正、廉洁。

特此通知。
