# 上海市奉贤区民政局关于印发《奉贤区养老服务机构燃气安全专项整治工作方案》的通知

全区各养老服务机构：

为深入贯彻习近平总书记关于燃气安全重要指示批示要求，落实国务院安全生产委员会《全国城镇燃气安全专项整治工作方案》(安委〔2023〕3号)、《上海市安全生产委员会关于印发上海市城镇燃气安全专项整治实施方案的通知》(沪安委会〔2023〕9号)及《上海市民政局关于印发本市养老服务机构燃气安全专项整治实施方案的通知》(沪民便函〔2023〕30号)相关部署，切实保障人民群众生命财产安全，开展奉贤区养老服务机构燃气安全专项整治，现将《奉贤区养老服务机构燃气安全专项整治工作方案》印发给你们，请认真贯彻落实。

上海市奉贤区民政局

2023年9月4日

奉贤区养老服务机构燃气安全专项整治工作方案

为深入贯彻习近平总书记关于燃气安全重要指示批示要求，落实国务院安全生产委员会《全国城镇燃气安全专项整治工作方案》(安委〔2023〕3号)、《上海市安全生产委员会关于印发上海市城镇燃气安全专项整治实施方案的通知》(沪安委会〔2023〕9号)及《上海市民政局关于印发本市养老服务机构燃气安全专项整治实施方案的通知》(沪民便函〔2023〕30号)相关部署，切实保障人民群众生命财产安全，开展奉贤区养老服务机构燃气安全专项整治，结合我区养老服务机构实际情况，特制订本方案。

总体要求

认真贯彻落实习近平总书记关于燃气安全重要指示批示要求，按照区委、区政府工作部署，全面排查养老服务机构燃气安全领域风险隐患，坚决防范遏制燃气重大事故和有影响的事故发生，确保养老服务机构服务对象安全。

重点整治内容

1.对养老服务机构未落实消防安全责任制，未按规定组织对从业人员进行消防安全教育和培训，未制定和实施灭火和应急疏散预案，违规用气、用火、用电的，要依法责令限期改正，逾期不改正的，实施处罚。

2.对养老服务机构在地下或半地下空间使用瓶装液化石油气、存放气瓶总重量超过60kg但未设置专用气瓶间、在用气瓶和备用气瓶未分开放置的，连接软管长度超过2米、私接“三通”或穿越墙体、门窗、顶棚和地面的，未规范安装、使用可燃气体探测器及燃气紧急切断阀的，要依法责令限期改正，逾期不改正的，责令停止使用，可以并处罚款。

3.发现养老服务机构使用可调节出口压力的调压器，对燃烧器具进行中压供气，使用不符合国家标准或假冒伪劣的液化石油气瓶、可燃气体探测器及燃气紧急切断阀、调压器、连接软管、灶具等燃气器具及配件等的，要及时移送市场监管部门，由其对生产、流通企业进行溯源治理，依法处罚并追究刑事责任。

4.对养老服务机构未规范设置疏散通道、安全出口，疏散通道或安全出口未保持畅通、在门窗上设置了影响逃生和灭火救援的广告牌等障碍物，消防设施器材或者消防安全标志的配置设置不符合 标准或者未保持完好有效的，要责令改正，依法实施处罚，情节严重的，依法从严从重处罚;构成犯罪的，依法追究刑事责任。

工作安排

结合我区实际情况，奉贤区养老服务机构燃气安全专项整治将分三个阶段进行。

(一)集中攻坚阶段。2023年9月底前，全面排查我区养老服务机构燃气风险隐患，对排查出来的重大问题隐患要立行立改，不能立即整改到位的要落实好管控措施，建立专项整治台账，确保重大安全风险管控到位，重大隐患问题整改到位。2023年11月底前，集中力量消除养老服务机构安全生产制度落实不到位、设施设备带病运行、监管存在盲区等突出问题。

(二)巩固提升阶段。2024年3月底前，全面完成养老服务机构燃气安全专项整治。2024年6月前，开展“回头看”，并启动督促机制，确保隐患逐项整改到位，防止久拖不改、改后反弹。

(三)建立长效机制。2024年底前，深入剖析奉贤区养老服务机构燃气安全隐患生产的深层次原因，认真总结推广专项整治中好的经验做法，及时总结提炼并巩固整治成果，建立健全我区养老服务机构燃气安全长效管理体制，加强人财物等要素保障，持续提升我区养老服务机构燃气本质安全水平，推动燃气安全治理模式向事前预防转型。2025年底前，基本建成管理要素明晰、手段先进、依据完善、成果显著的燃气安全管理体系。

工作要求

(一)提高政治站位。从政治和全局的高度深刻认识做好养老服务机构燃气安全专项整治工作的重要性，力戒形式主义、官僚主义，认真按照工作方案要求开展自查自纠工作。

(二)压实工作责任。成立奉贤区民政局燃气安全专项整治工作专班，由养老分管局长负责，局养老服务科、区养老服务发展中心、区养老机构管理中心工作人员组成。各养老服务机构负责人要按照“谁主管、谁负责”的原则，扎实组织开展排查整改工作，督促各养老服务机构在规定时间节点将问题全部整改到位。

(三)加大宣传教育。开展常态化燃气安全教育宣传，发动养老服务机构加强对员工和入住老人的宣传和教育，普及燃气安全使用和应急处置知识。归纳总结好的经验做法，形成一套管用有效的制度，及时交流推广，以点带面推动整体提升。

(四)加强工作报送。各养老服务机构明确1名联系人，每月15日前报送整治进展情况，2024年3月底前报送燃气安全专项整治工作总结，报至区养老机构管理中心钱融哲。
