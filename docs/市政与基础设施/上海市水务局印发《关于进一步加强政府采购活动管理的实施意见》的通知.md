# 上海市水务局印发《关于进一步加强政府采购活动管理的实施意见》的通知

上海市水务局印发《关于进一步加强政府采购活动管理的实施意见》的通知

沪水务〔2021〕926号

局属各预算单位、局机关各处室：

为进一步加强对局机关和局属单位政府采购活动的监督管理，规范政府采购内部控制，有效防范政府采购领域廉政风险，根据政府采购相关法律法规，结合我局实际，现将局《关于进一步加强4政府采购活动管理的实施意见》印发给你们，请遵照执行。

特此通知。

上海市水务局

2021年12月29日
