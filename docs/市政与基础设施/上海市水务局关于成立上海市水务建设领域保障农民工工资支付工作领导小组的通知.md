# 上海市水务局关于成立上海市水务建设领域保障农民工工资支付工作领导小组的通知

上海市水务局关于成立上海市水务建设领域保障农民工工资支付工作领导小组的通知

沪水务〔2018〕1358号

各有关单位：

为认真贯彻落实国务院办公厅《关于全面治理农民工工资问题的意见》（国办发〔2016〕1号）、《关于印发保障农民工工资支付工作考核办法的通知》（国办发〔2017〕96号）和上海市解决企业工资拖欠问题联席会议办公室《关于进一步加强本市工程建设领域用工管理的若干意见》（沪薪联办〔2018〕6号）等文件精神，进一步加强本市水务建设领域农民工工资支付保障工作的组织领导，经研究，决定成立上海市水务建设领域保障农民工工资支付工作领导小组。现将有关事项通知如下：
