# 关于印发《在轨道交通安全保护区内作业审批办事指南》《在轨道交通安全保护区内作业方案的技术审查服务指南》的通知

各有关单位：

为持续优化上海营商环境，我委制定了《在轨道交通安全保护区内作业方案的技术审查中介服务考核评价办法》，同步对《在轨道交通安全保护区内作业审批办事指南》《在轨道交通安全保护区内作业方案的技术审查服务指南》（沪交轨〔2022〕801号）相关条款进行了补充和修订。现将修订后的《在轨道交通安全保护区内作业审批办事指南》《在轨道交通安全保护区内作业方案的技术审查服务指南》予以发布，并于2023年12月1日起实施。

特此通知。
