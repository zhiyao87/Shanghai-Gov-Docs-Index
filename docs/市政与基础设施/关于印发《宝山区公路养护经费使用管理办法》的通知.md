# 关于印发《宝山区公路养护经费使用管理办法》的通知

各相关单位：

为深入贯彻《宝山区深化农村公路管理养护体制改革实施方案》（宝府办〔2021〕42号），合理使用和有效管理公路养护管理经费，强化项目管理，提高我区公路养护水平，现将《宝山区公路养护经费使用管理办法》印发给你们，请遵照执行。

特此通知。

上海市宝山区交通委员会

2022年1月14日
