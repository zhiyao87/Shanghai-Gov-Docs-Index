# 上海市水务局关于印发《上海市取水许可告知承诺管理办法》的通知

上海市水务局关于印发《上海市取水许可告知承诺管理办法》的通知

沪水务〔2025〕442号

各区水务局、临港新片区管委会：

为优化取水许可行政审批程序，完善管理方式，提高行政效率，上海市水务局制定了《上海市取水许可告知承诺管理办法》，已经2025年11月12日局长办公会议审议通过，现予印发，请遵照执行。

上海市水务局

2025年11月18日
