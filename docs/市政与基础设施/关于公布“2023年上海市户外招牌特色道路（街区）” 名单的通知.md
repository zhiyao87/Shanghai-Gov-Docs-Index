# 关于公布“2023年上海市户外招牌特色道路（街区）” 名单的通知

各区绿化市容局：

为进一步贯彻落实《上海市市容环境卫生管理条例》《上海市户外招牌设置管理办法》，通过特色道路评选，树立示范典型，推进并引领户外招牌规范化、个性化设置，提升城市公共空间品质。根据《上海市生态空间建设和市容环境优化“十四五”规划》要求，依据《上海市绿化和市容管理局关于印发<上海市户外招牌特色道路（街区）评选办法>的通知》（沪绿容〔2020〕189号），经综合评定，现将 2023年获评的本市 40条（个）户外招牌特色道路（街区）名单公布如下：

希望各区局加强对特色道路户外招牌的日常监管和督促维护，充分发挥特色道路建设成果的溢出示范效应，引领本市户外招牌设置融入建筑、文化、环境、业态，个性反映、精雅设置、美化环境，提升城市软实力。
