# 关于印发《市级相关部门和区级人民政府农村公路管理养护权利和责任清单》的通知

各涉农区交通委（建交委）：

为深入贯彻落实《上海市农村公路管理养护体制改革实施方案》，扎实推进本市农村公路管理养护体制改革各项工作，根据中共上海市交通委员会党组《开展权责清单梳理工作情况的报告》（沪交党〔2021〕143号），结合本市农村公路管理现状，我局梳理了市级相关部门和区级人民政府农村公路管理养护权利和责任，现将《市级相关部门和区级人民政府农村公路管理养护权利和责任清单》印发给你们，请各区遵照执行。
