# 上海市道路运输管理局关于印发《上海市公路驿站规划建设及运营管理指导意见》的通知

各涉农区交通委(建交委)：

为深入贯彻党的二十大精神和习近平总书记关于“四好农村路”重要指示精神，全力助推乡村振兴。根据《关于推进本市“四好农村路”高质量发展的实施意见（2023-2027年）》(沪府办发〔2022〕25号)要求，结合本市实际，我局制定了《上海市公路驿站规划建设及运营管理指导意见》(以下简称《指导意见》)，现印发你们，请认真学习，按照《指导意见》要求，组织开展公路驿站建设和运营工作。

特此通知。
