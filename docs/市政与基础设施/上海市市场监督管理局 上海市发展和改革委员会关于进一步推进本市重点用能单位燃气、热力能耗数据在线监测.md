# 上海市市场监督管理局 上海市发展和改革委员会关于进一步推进本市重点用能单位燃气、热力能耗数据在线监测工作的通知

上海市市场监督管理局 上海市发展和改革委员会关于进一步推进本市重点用能单位燃气、热力能耗数据在线监测工作的通知

各重点用能单位，各燃气和热力能源销售、转供公司，上海市计量测试技术研究院[国家城市能源计量中心（上海）]：

上海市重点用能单位能耗在线监测系统（以下简称“能耗在线监测系统”）是本市节能减排工作推进的重要技术基础，《上海市2021年节能减排和应对气候变化重点工作安排的通知》（沪发改环资〔2021〕77号）明确要求健全能源计量、监测和预警体系。为加快本市重点用能单位燃气、热力能耗数据接入能耗在线监测系统，提升能耗数据采集覆盖面和数据质量，现通知如下：

一、工作背景

根据市发展改革委《关于印发〈加快推进本市重点用能单位能耗在线监测系统建设的实施意见〉的通知》（沪发改环资〔2015〕139号，以下简称《实施意见》）要求，2018年本市依托上海市计量测试技术研究院[国家城市能源计量中心（上海）]建成本市能耗在线监测系统的数据库和管理平台。

近两年，在各方支持配合下，本市全部重点用能单位的电力、煤炭以及部分燃气（由上海燃气集团供应）、部分热力（首批5家热力供应公司）等能耗数据已接入能耗在线监测系统，为实现全市重点用能单位能耗在线监测奠定了基础。后续本市将通过建立健全能耗在线监测体系，深化各重点用能单位能耗数据自动化采集，及时准确全面掌握重点用能单位能耗情况，服务支撑本市能源消费总量与强度“双控”形势分析、节能监察、能源计量管理等节能减排工作，为推进碳达峰碳中和提供数据支持。

二、工作内容

2021年2月，国家发展改革委环资司《关于进一步加快推进重点用能单位能耗在线监测系统建设的通知》要求，各地确保2021年年底前实现对本市全部重点用能单位电力、燃气、燃煤、热力、油等主要能源品种在线监测，并将监测数据接入当地重点用能单位能耗在线监测系统。

燃气和热力作为本市主要的能源种类，其能耗数据的采集、管理是全市能耗在线监测系统建设的重点之一。根据《实施意见》要求，重点用能单位的电力、燃气及其他集中供应的能源种类一级（关口）计量数据的采集，分别由市电力、市燃气及其他集中供能单位负责落实，重点用能单位协助配合。为加快推进本市重点用能单位外购燃气、热力能耗数据在线监测，各相关燃气、热力能源销售、转供公司要按照能耗在线监测系统建设要求，积极配合上海市计量测试技术研究院[国家城市能源计量中心（上海）]开展能耗在线监测工作，全面梳理涉及本市重点用能单位的燃气、热力销售和转供情况，实现能耗数据准确采集和稳定传输，并上传至本市能耗在线监测系统。数据上传确认成功后，相关单位可参照《上海市重点用能单位能耗在线监测系统建设项目专项扶持资金管理办法》申报专项补贴。

三、工作要求

各相关燃气和热力能源销售、转供公司（附件）要高度重视能耗数据在线监测工作，按照《实施意见》要求，确保各有关重点用能单位燃气、热力能耗数据于2021年11月底前实时上传至本市能耗在线监测系统。各重点用能单位要按照《重点用能单位节能管理办法》要求配合做好相关工作。

上海市计量测试技术研究院[国家城市能源计量中心（上海）]要积极开展调研，做好燃气、热力能耗数据接入技术支撑，跟踪、落实和确认数据的接入工作并受理专项扶持资金申报，同时对已接入的重点用能单位要做好能源计量核排查等能耗数据维护工作，确保接入能耗数据的准确性和持续性。

附件：
