# 上海市绿化和市容管理局关于印发《本市百个街道（镇）千条道路推行道路洁净工程实施意见》的通知



各区（县）绿化市容管理部门、各相关单位：
为扎实推进2011年“本市百个街道（镇）千条道路推行道路洁净工程”市政府实事项目，现将《本市百个街道（镇）千条道路推行道路洁净工程实施意见》印发给你们，请结合本区域实际认真组织实施。
