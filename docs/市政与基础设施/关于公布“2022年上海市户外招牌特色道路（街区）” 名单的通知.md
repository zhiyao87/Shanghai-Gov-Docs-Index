# 关于公布“2022年上海市户外招牌特色道路（街区）” 名单的通知

各区绿化市容局：

为贯彻落实《上海市市容环境卫生管理条例》《上海市户外招牌设置管理办法》《上海市生态空间建设和市容环境优化“十四五”规划》，根据《上海市户外招牌特色道路（街区）评选办法》规定，经综合评定，现将2022年获评的本市40条（个）户外招牌特色道路（街区）名单公布如下（排名不分先后）：

黄浦区  老西门街道  盐城路

瑞金二路街道 巨鹿路

五里桥街道  蒙自路

淮海中路街道 湖滨路

南京东路街道 大沽路

徐汇区  徐家汇街道  斜土路、零陵路、南丹路

天平路街道  永嘉路

斜土路街道  大木桥路

长宁区  新华路街道  番禺路

华阳街道   武夷路

虹桥街道   黄金城道

静安区  静安寺街道  胶州路

南京西路街道 威海路

大宁路街道  上海久光中心

普陀区  甘泉路街道  甘泉路

杨浦区  定海路街道  国际时尚中心

五角场街道  安波路（双阳北路-国定东路）

松江区  岳阳街道   乐都路

中山街道   云间粮仓街区

永丰街道   玉树路

洞泾镇    长兴路

青浦区  夏阳街道   青湖路

奉贤区  南桥镇    育秀路、秀龙路

庄行镇    安中路

崇明区  城桥镇    崇明大道

希望各区局充分发挥户外招牌特色道路(街区)的引领作用，加大正面宣传力度，增强辐射带动效应，动员各街道（乡镇）支持户外招牌特色道路（街区）评定工作，推进户外招牌设置规范化、个性化、艺术化，提升城市公共空间品质。
