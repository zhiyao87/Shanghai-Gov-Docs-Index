# 上海市水务局关于明确本市水利工程开工备案有关事项的通知

上海市水务局关于明确本市水利工程开工备案有关事项的通知

沪水务〔2014〕656号

各有关单位：

根据水利部《关于水利工程开工审批取消后加强后续监管工作的通知》要求，为规范本市水利工程开工备案程序，做好水利工程开工备案工作，现就有关事项通知如下：

一、凡在本市行政区域内建设的水利工程，应实行开工备案。

二、本市水利工程开工备案实行分级管理。市水务安全质量监督中心站负责安全质量监督的水利工程开工备案，由市水务局委托市水务安全质量监督中心站受理，同时抄送市水务局建设管理处；区（县）水务安全质量监督站负责安全质量监督的水利工程开工备案，由区（县）水务局组织受理。

三、水利工程具备开工条件后，由项目法人自主确定开工日期。水利工程项目法人应自开工之日起15个工作日内将开工情况的书面报告报对应的水行政主管部门备案。

四、项目法人单位应填写上海市水利工程开工备案表，并对填报内容的真实性、准确性负责。

五、已备案的水利工程项目，项目经理、总监理工程师如有变动的，项目法人应在15个工作日内到原开工备案机关办理变更，并提交相关材料。

六、工程中止施工一年以上的，恢复施工前，应当重新进行开工备案。

七、各级水行政主管部门应加强对新开工水利工程的监督检查，发现工程不具备条件违规开工或开工后不按规定进行备案的，应责令项目法人立即整改；对于违反国家法律法规、构成重大质量安全隐患的，应责令其停工整改，并对项目法人给予通报批评。
