# 金山区人民政府关于印发《金山区深化农村公路管理养护体制改革实施方案》的通知

各镇人民政府、街道办事处、工业区管委会，区人民政府各部门、各直属单位：

《金山区深化农村公路管理养护体制改革实施方案》 已经第120次区政府常务会议讨论通过，现印发给你们，请认真按照执行。

特此通知。

上海市金山区人民政府

2021年7月30日

金山区深化农村公路管理养护体制改革实施方案

为深入贯彻《国务院办公厅关于深化农村公路管理养护体制改革的意见》 (国办发〔2019〕45 号)，全面推进农村公路高质量发展，加快建立完善农村公路管理养护长效机制，切实“管好、护好”农村公路，助力全区乡村振兴战略的实施，根据《上海市人民政府办公厅关于印发上海市深化农村公路管理养护体制改革实施方案的通知》 (沪府办发〔2020〕3 号)要求，结合我区实际，制定本实施方案。

一、总体要求

（一）指导思想

以习近平新时代中国特色社会主义思想为指导，坚持以人民为中心，全面贯彻落实习近平总书记关于“ 四好农村路”建设的重要指示精神，紧紧围绕党中央、国务院实施乡村振兴战略和统筹城乡发展，牢固树立绿色、融合、智慧发展理念，深化农村公路管理养护体制改革，加强农村公路与农村经济社会发展统筹协调，构建“安全、通达、优质、美观” 的农村公路发展新局面，形成上下协调、密切配合、齐抓共管的管理养护工作新局面，为农民群众致富奔小康、加快推进农业农村现代化提供更好保障。

（二）工作目标

到2022年，基本建立权责明晰、齐抓共管的农村公路管理养护体制机制，形成市、 区、镇三级财政投入、职责明确、社会力量积极参与的格局。农村公路“路长制”全面落实，管理站规范设置，农村公路治理能力明显提高，治理体系基本形成。农村公路通行条件和路域环境明显提升，交通保障能力显著增强。农村公路列养率保持100%，县道和乡村道年均养护工程比例分别不低于13%和8%，路面技术状况指数（PQI）中等及以上农村公路占比不低于90%。

到2035年，全面建成体系完备、运转高效的农村公路管理养护体制机制，全面实现农村公路管理科学化，全面实现城乡公路交通基本公共服务均等化，路况水平和路域环境全面提升，农村公路治理能力全面提高，治理体系全面完善。

（三）基本原则

1.完善制度，力求实效。深化农村公路管理养护体制，完善资金投入保障、交通行政执法、养护长效管理机制，健全绩效考核、“路长制”等制度，细化实化各项工作举措，突出重点，补齐短板，力求实效。

2.落实责任，协同推进。细化区、镇管理养护责任体系，加强区级统筹指导，压实主体责任，建立协同联动机制，有序推进本实施方案落地，切实落实各方责任。

3.创新机制，转型发展。坚持绿色发展，节约集约利用资源；坚持融合发展，推进“农村公路+”多元融合；坚持智慧发展，运用新技术、新手段赋能管理养护，促进农村公路转型发展。

二、主要任务

（一）完善农村公路管理养护体制

根据“县道区管， 乡村道镇管”的原则，依托农村公路“路长制”，建立以区政府为全区农村公路管理养护责任主体，区交通委为全区农村公路管理养护行政主管部门， 区交通运输事业发展中心为全区农村公路管理机构，各镇人民政府（金山工业区管委会）为各辖区乡道、村道、村内道路管理养护责任主体， 区发改委、 区财政局、 区审计局等各行业部门为配合部门的农村公路管理养护体系。

1.建立“ 区、镇、村”三级农村公路“路长制”。设立总路长和副总路长，总路长由区长担任，副总路长由分管交通和分管公安的副区长担任；设立区级路长， 区级路长由区交通委主要负责人和公安金山分局分管负责人担任， 区级副路长由区交通委分管负责人和公安金山分局交警支队主要负责人担任；各镇（金山工业区）设立镇级路长，镇级路长由镇党委或政府主要负责人担任；各建制村设立村级路长，村级路长由村党支部或村委会主要负责人担任。同时设立区级路长办公室和镇级路长办公室。

2.区政府是本区农村公路管理养护的责任主体。全面负责本辖区内农村公路管理养护工作。

3.区交通委是全区农村公路管理养护的行政主管部门。按照“县道区管， 乡村道镇管” 的原则制定相关部门、各镇人民政府（金山工业区管委会）农村公路管理养护权力和责任清单（见附件）；负责统筹市、区级农村公路养护补助资金，编制全区农村公路养护补助资金计划；负责审批农村公路日常养护和养护维修项目计划；负责审批农村公路养护维修项目；负责协调农村公路建设与养护移交接管工作；推进全区农村公路区、镇、村三级“路长制”工作，确保农村公路管理养护及路域环境整治责任到人；组织协调各镇（金山工业区）做好农村公路路产、路权的保护工作；负责监管全区农村公路养护计划执行情况、养护质量及养护资金的管理和使用情况，开展农村公路养护资金绩效评价；对各镇（金山工业区）农村公路管理养护工作进行绩效考核。

4.区交通运输事业发展中心是全区农村公路的管理机构。对各镇（金山工业区）的农村公路养护工作实施行业管理；负责区级路长办公室的具体工作推进；负责编制县道日常养护和养护维修计划；负责对各镇（金山工业区） 乡村道和村内道路的日常养护和养护维修计划进行审核；负责农村公路路政管理工作，指导各镇（金山工业区）做好路产路权的保护工作；负责协调指挥农村公路应急工作；负责各镇（金山工业区）农村公路管理站人员的技术培训及业务指导；负责对各镇（金山工业区）农村公路管理养护工作进行行业指导和各项考核。

5.各镇人民政府（金山工业区管委会）是各辖区乡道、村道和村内道路管理养护的责任主体。负责编制所辖区域内乡村道年度养护计划建议书并报区交通运输事业发展中心；落实管理养护机构、人员和资金；负责镇、村级路长办公室的具体工作推进；负责乡村道的路产路权保护，配合做好县道的路产路权保护；负责做好辖区内乡村道路应急保障工作，按要求处置本辖区应急事件；组织村民委员会将爱路护路要求纳入村规民约，增强农民群众对农村公路管理养护的责任意识、参与意识与监督意识；通过组织开展公路养护公益活动、开发公益岗位等形式，调动农民群众爱路护路的积极性。

各镇（金山工业区）在本轮体制改革中要充分发挥镇级农村公路管理站作用，农村公路管理站可单独设置，也可与相关机构部门合署办公；强化管理站人员和职责配置，每25-30公里乡道、村道配备不少于1名农村公路专管员（合署办公人员不算在内），具体包括养护专管员、路政专管员、安全质量专管员、 内业专管员；各类专管员原则上不少于1名，其中养护专管员可适当增多，专管员按照相关职责履行工作责任；农村公路管理站相关运行经费和人员支出纳入一般公共财政预算。

6.各行业部门职责。 区财政局负责筹集农村公路养护区级配套资金，指导和监督区、镇两级农村公路管理养护资金的筹集和管理使用。 区规划资源局负责指导全区农村公路管理养护建设用地（农村公路管理站建设、道班房建设等管理养护设施用地）供应等工作。 区发改委、 区人社局、公安金山分局、 区建管委、 区生态环境局、 区农业农村委、 区水务局、 区文旅局、 区应急管理局、 区审计局、 区绿化市容局、 区城市运行中心等部门依据上级有关配套政策，积极引导、支持和促进农村公路管理养护事业发展。

（二）强化农村公路管理养护资金保障

1.完善农村公路养护经费分配机制。 区农村公路养护资金来源于市、 区、镇三级财政资金以及通过其他方式筹集的资金，不得用于公路新建和改扩建， 由区交通委和各镇人民政府（金山工业区管委会）统筹实施。自2022年起，该项资金不再列支管理机构运行经费和人员等其他支出。农村公路养护资金根据养护成本变化等因素对补助政策进行动态调整，调整周期原则上不超过5年。

县道的养护资金由市、 区两级财政分担，扣除市下达的成品油税费改革资金，其余部分由区财政承担，其中， 日常养护费用按照设施量及养护定额测算，养护维修项目费用按照不低于设施量 13%比例测算； 乡村道的养护资金由市、 区、镇（金山工业区）三级财政分担，扣除市下达的成品油税费改革资金，其余部分由区级财政承担 80%、镇（金山工业区）承担 20%，其中日常养护费用按照设施量及养护定额测算，养护维修项目费用按照不低于设施量 8%比例测算。

2.加大资金保障力度。除市下达的成品油税费改革资金外，区级公共财政资用于农村公路日常养护的总额不得低于县道每年每公里1万元， 乡道每年每公里5000元，村道每年每公里3000元。

3.强化养护资金使用监督管理。 区交通委对农村公路养护资金进行全过程预算绩效管理，确保及时足额拨付到位；养护资金使用监管按照有关规定向社会公开，接受群众监督，并接受市行业部门、 区行政主管部门、 区财政和审计部门的监管和检查，不断提升资金配置效率和使用效益。

4.探索农村公路发展投融资机制。积极推进农村公路建设养护更多向进村入户倾斜，鼓励将农村公路相关附属设施等有收益的项目与农村公路养护打包运行；鼓励将农村公路建设和一定时期的养护进行捆绑招标，将农村公路与特色产业、 乡村旅游等经营性项目实行一体化开发，运营收益用于农村公路养护，创新资金筹措方式，拓宽资金来源渠道。

（三）创新农村公路管理养护长效机制

1.深化农村公路养护市场化。将社会满意度、养护质量和资金使用效率作为衡量标准，全面推动农村公路养护市场化改革，建立政府与市场合理分工的养护生产组织模式。完善市场准入，积极培育符合农村公路特点的养护队伍，形成市场有序竞争格局。支持养护企业跨区域参与市场竞争，引导养护企业加强自身能力建设，提高养护专业化、机械化水平。

2.加强安全质量和信用管理。公路安全设施要与主体工程同时设计、同时施工、同时投入使用，并加强农村公路安全隐患整治，逐步完善现有农村公路安全设施。县道每年由市级部门组织路况检测， 乡村道每年由区交通运输事业发展中心委托专业单位组织路况检测，检测结果作为制定下年度养护维修计划的依据。加强养护质量全过程管理，提高农村公路养护运行服务水平。配合市级部门，建立以安全、质量为核心的信用评价体系，探索实施守信联合激励和失信联合惩戒，并将信用记录按照国家有关规定纳入全国信用信息共享平台，依法向社会公开。

3.强化路产路权的保护。增强农村公路行政执法和路产路权保护责任意识和执法力度，加强交通行政执法力量建设。建立“区有路政员、镇有监管员、村有护路员” 的路产路权保护队伍。 区交通委要加强对各镇（金山工业区）路产路权保护工作的指导、监督和考核，依法保障农村公路的安全、完好和畅通。

4.促进农村公路转型发展。推进农村公路养护绿色、节能、环保技术应用，严守生态保护红线，实现路与自然和谐共生；大力开展“美丽农村路”建设，切实提升路域环境。推动 5G、北斗、互联网、物联网、大数据、卫星遥感等信息化手段的应用，不断提高管养水平。推进农村公路可持续发展，科学分析公路运行状况发展变化规律，积极推广应用各类预防性养护技术。

三、保障措施

（一）加强组织领导

区交通委和各镇人民政府（金山工业区管委会）在农村公路管理养护体制改革过程中，按《国务院办公厅关于深化农村公路管理养护体制改革的意见》（国办发〔2019〕45 号），《上海市人民政府办公厅关于印发上海市深化农村公路管理养护体制改革实施方案的通知》(沪府办发〔2020〕3 号)及本实施方案，落实改革具体工作负责人，结合实际细化工作举措，层层分解任务，层层压实责任，形成推进工作的长效机制，有序推进本实施方案落地见效。

（二）强化资金保障

建立以公共财政分级投入为主，多渠道筹措为辅的农村公路管理养护资金筹措机制。 区财政部门要将农村公路管理养护资金列入年度预算。 区交通委要积极争取国家和市专项资金，缓解区级财政压力。各镇（金山工业区）要充分发挥好“ 一事一议”在农村公路管理中的作用，多渠道筹措农村公路管理养护资金。

（三）完善考核激励机制

将农村公路管理养护工作纳入区政府对各镇人民政府（金山工业区管委会）绩效考核、 乡村振兴考核等，建立健全激励约束机制， 以进一步提高各类资金的使用效益。将考核结果与补助资金挂钩，对工作推进良好的，适当增加补助；对工作推进情况较差的，实行约谈、扣减补助等措施。

（四）加大宣传力度

充分发挥传统媒体和新媒体作用，围绕改革重点任务加强政策解读，加强信息发布，正确引导社会预期，及时回应社会关注。积极宣传改革中的先进人物和典型案例，充分调动广大群众参与、监督改革工作的积极性，不断加强宣传和舆论引导，为深化改革营造良好的舆论氛围。

本实施方案由区交通委负责解释，自印发之日起施行。《金山区人民政府办公室转发区建设交通委<关于金山区农村（乡村）公路管理养护体制改革方案>的通知》(金府办〔2010〕25 号)同时废止。
