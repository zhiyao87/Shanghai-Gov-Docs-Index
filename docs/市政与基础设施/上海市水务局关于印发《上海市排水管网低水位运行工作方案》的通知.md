# 上海市水务局关于印发《上海市排水管网低水位运行工作方案》的通知

上海市水务局关于印发《上海市排水管网低水位运行工作方案》的通知

沪水务〔2023〕524号

各区水务局、相关地区管委会、城投集团、各有关单位：

为深入贯彻落实《城镇生活污水处理设施补短板强弱项实施方案》《“十四五”城镇污水处理及资源化利用发展规划》等文件要求，提升防汛保障能力，提高水环境质量，市水务局研究制定了《上海市排水管网低水位运行工作方案》，现印发给你们，请按照执行。

特此通知。

上海市水务局

2023年8月1日
