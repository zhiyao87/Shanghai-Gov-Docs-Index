# 关于印发《上海市公路沿线充电基础设施建设行动方案》的通知（交通委、发改委、道运局、上海电力）

关于印发《上海市公路沿线充电基础设施建设行动方案》的通知

市道运中心、各相关区交通委（建交委）、各高速公路项目公司：

根据交通运输部、国家能源局、国家电网有限公司、中国南方电网有限责任公司制定的《加快推进公路沿线充电基础设施建设行动方案》要求，为健全完善本市公路沿线充电基础设施，满足人民群众日益增长的电动汽车充电需求，促进电动汽车产业发展。市交通委、市发展改革委、市道路运输局、国网上海市电力公司共同研究制定了《上海市公路沿线充电基础设施建设行动方案》，现印发给你们，请认真组织实施。

特此通知。

上海市交通委员会、上海市发展和改革委员会、上海市道路运输管理局 、国网上海市电力公司

2022年9月14日
