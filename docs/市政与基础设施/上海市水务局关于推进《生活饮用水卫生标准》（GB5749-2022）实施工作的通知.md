# 上海市水务局关于推进《生活饮用水卫生标准》（GB5749-2022）实施工作的通知

上海市水务局关于推进《生活饮用水卫生标准》（GB5749-2022）实施工作的通知

沪水务〔2022〕471号

各区水务局，上海城投水务（集团）有限公司，各供水企业：

《生活饮用水卫生标准》(GB5749-2022)（以下简称《标准》）已于2022年3月15日发布，并将于2023年4月1日正式实施。为了全面贯彻落实《标准》，推动供水行业高质量发展，持续为广大市民提供安全、卫生的饮用水，现结合本市供水行业实际情况，对相关工作要求通知如下：

一、加强《标准》的学习宣贯工作

与现行国家标准（GB5749-2006）相比，《标准》由原来的106项水质指标调整为97项，其中包括常规指标43项和扩展指标54项；《标准》中新增4项指标，删除13项指标，修改了3项指标的名称，更改了8项指标限值。各供水企业要提高思想认识，组织开展好新国标的学习宣贯工作，进一步认清《标准》是保障供水安全，确保水质稳定达标的强制性标准，各供水企业应积极贯彻落实达标工作，确保水质检测、水处理工艺管控、报表统计、水质保障等各项工作顺利过渡到《标准》的要求上来。同时做好《标准》与上海市地方标准《生活饮用水水质标准》（DB31/T 1091-2018）的衔接，确保供水水质同时满足两个标准。

二、加强水质检测实验室能力建设

《标准》新增了高氯酸盐、乙草胺等扩展指标，同时将二氯乙酸、三氯乙酸等列为常规指标，并要求消毒方式采用次氯酸钠时还应加测氯酸盐。当前本市部分供水企业水质检测实验室尚不完全具备上述指标的检测能力。各供水企业实验室应进一步强化水质检测实验室能力建设，尽快开展人员培训，落实工作经费，配置检测仪器，优先选用国标方法；各供水企业应制定工作方案，细化具体步骤，力争今年年底前全面具备《标准》常规指标检测能力，部分实验室具备《标准》扩展指标检测能力；市供水调度监测中心和上海城市水资源开发利用国家工程中心有限公司等单位应同步关注《标准》55项参考指标情况，针对性地开展参考指标检测能力建设。此外各供水企业还应进一步规范实验室管理，有计划地开展实验室资质认定或者实验室认可工作，确保上海城市供水水质监测网有序规范运行。

三、强化水厂水处理工艺管控

《标准》将原标准中的二氯乙酸、三氯乙酸等消毒副产物指标调整为常规指标，进一步彰显了饮用水消毒工艺极其关键的核心作用和重要地位。《标准》更加关注饮用水消毒效果及消毒副产物指标，这对水厂消毒工艺管控提出了更高的要求，水厂消毒环节既要确保能够完全去除或者灭活病原微生物，同时也要控制好消毒副产物的形成。各供水企业应进一步强化水厂工艺管控，完善消毒剂投加环节，精准控制消毒剂投加量，确保水厂消毒工艺运行正常，消毒剂余量、消毒副产物等水质指标稳定达标。

四、完善末梢水水质保障

《标准》明确了末梢水的定义，末梢水是指出厂水经输配水管网输送至用水户水龙头的水。按照《标准》，末梢水就是用户“龙头水”。各供水企业应进一步明确工作目标，完善末梢水水质安全保障措施。一是全力做好已接管的二次供水设施的清洗和消毒工作，按要求完成水质检测和结果公示；二是应更加重视用户“三来”水质问题，及时研究、分析、解决供水区域内用户集中反映的水质问题，强化闭环管理，做好用户反馈；三是全面梳理提升末梢水水质的工程性措施，明确工作计划，从根本上杜绝发生水质问题。

五、提升供水水质保障能力

城市供水事关城市运行安全，其中供水水质又直接关系到人民群众饮水卫生和社会的和谐稳定,各供水管理部门要加强组织领导,强化监督管理，全面落实属地管理责任；各供水企业要明确工作目标,落实供水安全主体责任，提升全过程供水水质保障能力；要对照《标准》，补短板，强弱项，及时修订现有水质管理制度，及时建立水质检测方法，及时优化水处理工艺管控，及时完善供水水质保障措施，确保供水水质安全稳定。各供水企业实验室要在2022年底前完成《标准》检测的各项准备工作，2023年1月1日起按照《标准》开展日常水质检测试运行；2023年一季度作为试运行过渡期，各供水企业应做好过渡期内水质报表的统计和报送工作。

特此通知。
