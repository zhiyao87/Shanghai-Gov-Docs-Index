# 上海市交通委员会关于S32申嘉湖高速公路维持收费的通知

市道路运输事业发展中心、上海沪申高速建设发展有限公司：

S32申嘉湖高速公路改扩建工程已完成立项，拟发行地方政府债券筹措改扩建资金。经市政府同意，S32申嘉湖高速公路于2024年7月19日起维持收费，具体期限待发债计划确定后另行通知。

特此通知。

上海市交通委员会

2024年7月10日
