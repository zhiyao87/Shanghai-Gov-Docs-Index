# 上海市交通委员会关于区管省道、省市对接道路、区区对接道路相关审批权限下放各区的通知

各区交通委（建设交通委）：

按照市委、市政府深化“放管服”改革工作精神，为更好地服务区内项目建设，经研究，拟将“十四五”重点基础设施市对区支持政策中部分区内项目相关审批权限下放至各区交通行政管理部门，具体情况如下：

一、下放范围

本通知所称部分区内项目是指“十四五”重点基础设施市对区支持政策中区管省道、省市对接道路、区区对接道路，各区相关单位为项目建设主体、市发展改革委为项目立项部门。项目清单附后，项目清单如有调整以批复的调整清单为准。

二、下放内容

下放以上项目的合同信息报送、报监手续办理（质量监督登记）、施工许可审批和竣工验收等权限，由各区交通行政管理部门负责审批和监管。

三、职能分工

（一）市交通委负责行业管理、指导和监督。同时，负责全市交通综合业务平台建设，完善项目全流程审批及企业、人员闭环管理、健全交通工程市场和现场“两场联动”动态信誉考核管理体系，实现市、区两级项目审批和监管信息共享互通和动态监管。

（二）市交通安质监站、市交通建管中心负责对各区交通行政管理部门的合同信息报送、报监手续办理（质量监督登记）、施工许可审批和竣工验收等具体工作进行指导和服务，适时开展专业技术培训、交流工作，并按相关规定对区相关职能部门开展专项检查。

（三）各区交通行政管理部门应严格按照交通运输部和本市相关文件规定和办事指南，通过市交通综合业务平台办理项目行政审批。

（四）各区交通行政管理部门应加强专业队伍建设，细化建设管理措施，不断提升审批及监管水平。应进一步加强领导，结合全市行政审批改革，及时完善权责清单，加强交通工程市场管理和安全质量监督，加强区内项目参建单位、人员的资质资格审查，加强项目安全生产、质量监督日常巡查和专项检查，确保项目建设有序推进。行政审批和安全监管等内容将纳入综合交通发展水平考核中。

（五）区区对接道路因跨区建设，请所涉区交通行政管理部门提前对接，明确建设管理牵头主体和报监（质量监督登记）、施工许可、竣工验收等权责划分。如有不同意见，请报市交通委予以协调。
