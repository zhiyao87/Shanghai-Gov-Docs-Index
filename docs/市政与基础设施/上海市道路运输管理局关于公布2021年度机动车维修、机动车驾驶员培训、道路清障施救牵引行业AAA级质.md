# 上海市道路运输管理局关于公布2021年度机动车维修、机动车驾驶员培训、道路清障施救牵引行业AAA级质量信誉企业的通知

各有关单位：

经综合考核评定，上海强生集团汽车修理有限公司、上海小昆山机动车驾驶技术学校、上海安畅汽车牵引有限公司等127家企业分别被评为2021年度上海市机动车维修（一、二类维修企业）、机动车驾驶员培训、道路清障施救牵引行业AAA级质量信誉企业，现予公布。

根据《上海市社会信用条例》《上海市交通委员会关于印发<2021年上海市交通运输社会信用体系建设工作要点>的通知》（沪交科〔2021〕247号），本市机动车维修、道路清障施救牵引行业积极推进质量信誉考核结果应用。经研究决定，对于质量信誉考核结果为AAA级的维修企业，鼓励增加经营范围；优先推荐参加全国诚信企业评比；优先推荐政府购买服务事项；在下年度中降低日常上户监管频率（危险货物运输车辆维修、大中型客车维修企业除外）。对于质量信誉考核结果为AAA级的牵引企业，在下年度中降低日常上户监管频率;质量信誉考核结果为AAA、AA级的牵引企业，优先推荐政府购买服务事项；质量信誉考核结果为B级的牵引企业，在下年度中限制车辆道路运输证（备案）办理，并加强日常监管检查力度。

附件：1.2021年度上海市机动车维修行业（一、二类维修

企业）AAA级质量信誉企业

2.2021年度上海市机动车驾驶员培训行业AAA级质

量信誉企业

3.2021年度上海市道路清障施救牵引行业AAA级质

量信誉企业

（备注：其余AA、A、B级企业的质量信誉考核等级情况可以在上海市道路运输管理局官网https://dlysj.sh.gov.cn/上进行查询，考核等级将根据实际情况进行动态调整。）
