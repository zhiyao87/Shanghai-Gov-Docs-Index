# 关于印发《关于妥善处置行道树与道路公共设施关系的工作要求》的通知

各区绿化市容局、各区建管委（交通委）、市道路运输事业发展中心：

为进一步妥善处置行道树与道路公共设施关系，适应城市管理精细化的需要，现将《关于妥善处置行道树与道路公共设施关系的工作要求》印发给你们，请根据各区实际，参照执行。

上海市住房和城乡建设管理委员会

上海市道路运输管理局
