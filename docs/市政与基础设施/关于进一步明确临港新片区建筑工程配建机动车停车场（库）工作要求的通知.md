# 关于进一步明确临港新片区建筑工程配建机动车停车场（库）工作要求的通知

关于进一步明确临港新片区建筑工程配建机动车停车场（库）工作要求的通知

沪自贸临管委〔2025〕114号

管委会各部门，临港新片区各镇、各有关单位:

为进一步优化营商环境，根据《建筑工程交通设计及停车库（场）设置标准》（DG/TJ 08-7）、《上海市公共停车场（库）充电设施建设管理办法》（沪交行规〔2023〕1号）、《上海市居民小区电动汽车充电设施建设管理办法》（沪交行规〔2023〕3号）等文件，结合临港新片区发展实际，现就临港新片区产城融合区范围内建筑工程停车配建有关工作要求通知如下：

一、停车位配建工作要求

建筑工程配建停车场（库）应当符合国家、本市相关法律法规、技术标准和政策要求，并应满足以下要求：

（一）新建住宅建筑工程中，应明确各类型建筑所对应配建停车位的数量、位置，宜就近设置相对独立和集中的停车区域。

（二）新建工业建筑、物流仓储建筑中设有宿舍型保租房的，应参照公共租赁住房（成套单人型宿舍）设置配建停车位；鼓励按需配置货车、大客车停车位。

二、充电设施配建工作要求

停车场（库）充电设施配建应当符合国家、本市相关法律法规、技术标准和政策要求，并应重点关注：

（一）新建住宅建筑工程应落实100%的配建车位预留充电设施建设安装条件（包括预留充电设施、计量箱安装位置；安装配电设施，排管、桥架及保护管等线缆通道；预留电力容量等），鼓励在公共停车位配建一定数量的充电设施。

（二）公共停车场（库）应按照一类地区规定比例配建不少于总停车位15%的充电停车位，快充停车位占比应不少于总充电停车位的30%。

（三）专用停车场（库）如向公众提供经营性停车服务，应参照公共停车场（库）配建充电设施。

三、其他要求

（一）建设单位应严格落实主体责任，确保在进行新建住宅建筑工程方案设计与施工图设计时，督促设计单位落实“配建车位100%预留充电设施建设安装条件”的要求。施工图审查机构应对设计文件是否落实该要求进行审查。

（二）在党建引领物业治理工作机制下，属地镇政府、居委、物业服务企业、电力公司、建设单位等相关单位要加强协同联动，根据职责分工做好住宅小区停车管理相关工作，提升停车管理水平。

（三）本通知自2025年11月1日起正式实施，《临港新片区建筑工程停车库（场）配建指标（2022版）》（沪自贸临管委〔2022〕16号）、临港新片区管委会《关于进一步明确临港新片区新建住宅小区停车位充电设施配置操作口径的通知》同时废止。国家和本市有新要求的按新要求执行。
