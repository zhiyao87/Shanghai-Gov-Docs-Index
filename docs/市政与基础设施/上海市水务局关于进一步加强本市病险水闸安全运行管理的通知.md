# 上海市水务局关于进一步加强本市病险水闸安全运行管理的通知

上海市水务局关于进一步加强本市病险水闸安全运行管理的通知

沪水务〔2021〕530号

各相关区水务局、市水利管理事务中心、市堤防建设运行中心：

根据上海市防汛指挥部办公室、上海市河长制办公室、上海市水务局《关于加快推进本市病险水闸除险加固工作的通知》（沪汛办〔2021〕36号）要求，病险水闸作为本市水利行业重大安全隐患，在未实施除险加固前，应落实相关风险管控措施。为进一步加强病险水闸安全运行管理，保障城市安全运行，现将相关工作要求通知如下：

一、严格落实三类水闸应急处置方案

各水闸管理单位要按要求，三类闸及时制定应急处置方案，并报上级主管部门批准后实施；要严格落实应急处置方案各项措施，明确应急处置启用条件，加大病险部位日常巡视检查、维修养护及观测监测力度，落实应急抢险队伍，确保三类闸发生突发事件时应急处置到位。

二、严格执行四类水闸降标运行方案

各水闸管理单位要按要求，四类闸及时制定降标运行方案，并报上级主管部门批准后实施；要严格执行降标运行方案，采取必要的工程除险措施，限制运行频次，船闸限制船舶尺寸，加大日常巡视检查、维修养护及观测监测力度，制定应急预案，落实应急抢险队伍等。

三、加强病险水闸监督检查力度

各水闸管理单位要做好病险水闸每日巡视检查，发现问题及时上报处置；区水务局要落实属地化监管责任，每月开展病险水闸运行管理监督检查，并做好检查记录；市水利事务中心要加强行业监管，定期采取“四不两直”方式开展督查抽查。

请各水闸管理单位对照病险水闸清单，每月向市水务局报送病险水闸运行、巡视检查、维修养护、观测监测等各项措施落实情况，同步抄送市水利事务中心。

特此通知。
