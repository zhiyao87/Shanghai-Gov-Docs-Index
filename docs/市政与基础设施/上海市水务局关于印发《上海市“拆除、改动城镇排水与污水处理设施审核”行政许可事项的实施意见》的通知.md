# 上海市水务局关于印发《上海市“拆除、改动城镇排水与污水处理设施审核”行政许可事项的实施意见》的通知

上海市水务局关于印发《上海市“拆除、改动城镇排水与污水处理设施审核”行政许可事项的实施意见》的通知

沪水务〔2024〕465号

临港新片区管委会、各区水务局：

为贯彻落实《国务院办公厅关于全面实行行政许可事项清单管理的通知》（国办发〔2022〕2号）精神，进一步完善对拆除、改动城镇排水与污水处理设施的审核管理，现印发《上海市“拆除、改动城镇排水与污水处理设施审核”行政许可事项的实施意见》，请遵照执行。

特此通知。

上海市水务局

2024年10月29日
