# 关于印发《临港新片区建设项目环评文件、水保方案、排污许可和排水许可综合审批实施方案》的通知

关于印发《临港新片区建设项目环评文件、水保方案、排污许可和排水许可综合审批实施方案》的通知

沪自贸临管委〔2023〕202号

管委会各部门、各直属单位，临港新片区各镇、各开发公司、浦东新区生态环境执法支队、各有关单位:

为推行跨领域、跨行业、跨专业行政审批事项的整合，发挥临港新片区集中行使事权系统集成改革效力，进一步深化推进市场化、法治化、国际化营商环境建设，根据相关政策法规等文件要求，结合临港新片区实际，临港新片区管委会制定了《临港新片区建设项目环评文件、水保方案、排污许可和排水许可综合审批实施方案》，现印发给你们，请遵照执行。

中国（上海）自由贸易试验区临港新片区管理委员会

2023年12月30日

临港新片区建设项目环评文件、水保方案、排污许可和排水许可综合审批实施方案

为深入贯彻党的二十大精神、习近平生态文明思想和全国生态环境保护大会精神，落实党中央、国务院和市委、市政府关于深刻转变政府职能、深化优化营商环境的决策部署，充分运用市政府赋予临港新片区实行综合审批、相对集中行政处罚的体制和机制，推行跨领域、跨行业、跨专业行政审批事项的整合，发挥集中行使行政事权系统集成改革效力，进一步深化推进市场化、法治化、国际化营商环境建设，根据中共中央办公厅 国务院办公厅印发《关于加强新时代水土保持工作的意见》《中国（上海）自由贸易试验区临港新片区条例》《上海市人民政府办公厅关于印发的通知》（沪府办〔2023〕1号）、《关于印发的通知》（沪自贸临管委〔2023〕23号）等文件精神，结合临港新片区实际，制定本实施方案。

一、主要目标

在临港新片区管委会（以下简称新片区管委会）办理建设项目环境影响评价文件、生产建设项目水土保持方案、排污许可证和城镇污水排入排水管网许可（以下分别简称为环评文件、水保方案、排污许可和排水许可）审批时推行综合审批。即由原来分开办理的4个行政审批事项，改革为“一表申请、一口受理、一并审查、一张许可”的“四个一”综合审批新模式。从方便建设单位“一件事一次办”的角度出发进行流程再造，推进实施跨领域、跨行业和跨专业的突破性、引领性改革举措，持续提升建设单位办事便捷度和满意度，为建设具有国际市场影响力、竞争力的特殊经济功能区和现代化新城，更好服务国家对外开放总体战略布局提供坚实支撑。

二、适用范围

本实施方案适用于由新片区管委会集中行使环评文件、水保方案、排污许可和排水许可行政审批事权范围内，且环评文件、水保方案均属于审批制的建设项目（告知承诺制审批除外）。

实行环评文件与排污许可证“两证合一”的建设项目，应符合《上海市生态环境局关于发布的通知》（沪环规〔2023〕9号）、《上海市生态环境局关于开展排污许可与环境影响评价制度衔接工作的通知》（沪环评〔2023〕113号）等文件规定。

综合审批推行“容缺后补”的审批方式，如果实际与承诺不一致，可补充提交有关申请材料。适用综合审批的建设项目，申请人可以选择综合审批程序办理，也可以选择按常规的审批程序分开办理。

三、主要内容

（一）优化项目前期准备

申请人在建设项目开工建设前，提前开展环评文件、水保方案、排污许可和排水许可审批手续办理的准备工作，鼓励设计方案基本稳定的建设项目将环评文件、水保方案、排污许可和排水许可申请资料形成1套材料，统一办理，实现4个事项综合审批。

（二）压缩项目审批时限

综合审批时限由原来的分开办理多于40个工作日（不含法定公示和技术评审等时间）最大限度压缩至7个工作日（不含法定公示和技术评审等时间）。

（三）精简项目报批环节

1.一表申请

将原先分开办理所需的4套申请材料整合成1套申请材料，由建设单位通过“一网通办”平台一次性提交，实现综合审批“一表申请”。针对环评文件和水保方案，可选择同一家编制单位编制成一本报告。

2.一口受理（实时收件、5个工作日内受理）

临港新片区行政服务中心通过系统后台进行统一收件，对申请材料进行形式审查后，实时出具收件凭证，并移送至新片区管委会生态和市容管理处办理。生态和市容管理处在收到材料后5个工作日内对申请材料进行受理审查，对申请材料符合要求的出具受理通知书。

综合审批可实行“容缺后补”的审批方式，对于申请材料不齐的，限期补交相关材料。

3.一并审查（7个工作日）

正式受理后，在7个工作日内（不含法定公示和技术评审等时间）根据评审报告、评审意见及法定要求提交的其他材料，进行统一审查并作出行政许可决定。针对技术评审环节，不再分开进行环评文件和水保方案技术评审，可委托评审单位组织一次技术评审；针对公示环节，为落实环评文件审批法定公示要求，在综合审批前对拟审批报告进行5个工作日的公示。

4.一张许可（实时出具）

对建设项目环评文件、水保方案、排污许可和排水许可的审批内容整合成一张行政许可决定书，经生态和市容管理处完成审查后，由行政服务中心实时制作电子批文，并通过“一网通办”平台即时向建设单位反馈，建设单位可自行下载、打印电子行政许可决定书。

（四）开展事中事后综合监管和自主验收

相关监管、执法部门有条件的，可充分运用卫星遥感、无人机、大数据、“互联网+监管”等手段，按照相关法律法规和技术标准，开展环境保护、水土保持、排污和排水事中事后综合监管。包括对遵守环境保护法律法规、落实建设项目环评文件及其审批决定的情况、排污许可制度执行情况；对水土保持方案实施情况的跟踪检查和水土保持设施自主验收情况的核查；对污染物排放浓度、排放总量、排放口位置和数量、排放方式、排放去向、污染防治设施运行台账等情况；对排水许可有效期、许可内容（水量、排口数量、排口位置、处理设施）、水质等全链条全过程综合监管。

为提高专项自主验收工作效率，促进项目早日投产使用，鼓励建设单位推行综合建设项目环境保护和水土保持设施自主验收工作。

根据《生产建设项目水土保持方案管理办法》（水利部令第53号），承担水土保持方案技术评审、水土保持监测、水土保持监理工作的单位不得作为该项目水土保持设施验收报告编制的第三方机构。

（五）加快推进“四个一”综合审批场景建设

大数据中心依托“一网通办”平台建设项目，加快推进“四个一”综合审批场景建设，落实系统建设及数据支撑等工作。政务服务中心（含蓝湾分中心）做好线下办事以及帮办咨询等相关工作。

（六）加快推进综合监管业务流程再造

开展环保、水保、排污和排水领域事前事中事后综合监管业务流程再造，梳理行政许可、监管以及行政处罚事项清单，依托现有系统实现综合监管目标。

四、组织保障

（一）加强责任落实和协同配合

新片区管委会建立由办公室、制度创新和风险防范处、生态和市容管理处、数据处、行政服务中心、大数据中心、综合执法大队、浦东新区生态环境执法支队等相关部门组成的综合审批工作协调机制，指导协调、全力协作推进综合审批工作落到实处。

办公室负责对综合审批改革在新片区管委会层面上的对外宣传。

制度创新和风险防范处负责统筹协调政府职能转变、审批制度改革、综合监管“一件事”改革以及政务服务“一网通办”改革相关工作；负责“一网通办”“综合监管”数字化建设应用场景需求研提、行政权力事项和公共服务事项办事指南管理及发布等；负责按照上海市政府办公厅要求开展综合审批制度改革、“一网通办”改革等阶段性评估工作等。

生态和市容管理处负责综合审批中的具体审批工作，开展技术评审委托和具体项目的统一审查，并落实环保、水保和排水行业管理职责，负责行业宣传工作；负责落实环保、水保、排污和排水事中事后监管工作。

数据处、大数据中心根据《临港新片区城市数字化转型项目管理办法》，推进数字化系统统筹建设与整合，实现数据接入和归集管理，加强数据分析应用，为深化改革提供支撑。

行政服务中心负责综合审批中申请咨询、统一收件、材料移交、结果反馈等工作。

综合执法大队、浦东新区生态环境执法支队负责各自执法职责范围内环保、水保、排污和排水相关行政执法工作。

（二）明确工作保障和责任追究

新片区管委会各部门要加强人员、技术方面等相关支持保障，并加强业务培训。综合审批工作实施过程中涉及到平台建设、技术评审、宣传培训、阶段性评估等各部门工作经费纳入新片区管委会财政预算。对行政机关及其工作人员在干净高效干事、履职担当创新过程中，非因主观故意出现偏差失误，但不违反法律法规、达到尽职要求，按《临港新片区机关及事业单位工作人员容错免责实施办法（试行）》（沪自贸临党工委〔2020〕13号）处理；对行政机关及其工作人员存在违纪违法行为的，依法追究相关责任。

（三）加强综合审批宣传推介

将综合审批改革创新宣传推介纳入新片区审改宣传工作重点。以新片区制度创新工作案例宣传、“六五环境日”“世界水日”“中国水周”主题宣传等活动为契机，打造具有新片区特色的亮点工作，加大宣传力度，突出示范引领，提高社会各方的认同度和参与度。

（四）适时开展改革评估

在综合审批施行过程中对实施方案组织“回头看”，定期检查评估审改政策的知晓度、覆盖面和到达率，充分听取建设单位对改革举措的意见建议，及时研究解决施行过程中产生的各类问题。

五、附则

本实施方案自2023年12月31日起施行，有效期至2026年12月31日。
