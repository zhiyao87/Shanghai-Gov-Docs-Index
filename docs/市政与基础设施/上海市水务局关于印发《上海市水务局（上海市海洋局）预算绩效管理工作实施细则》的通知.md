# 上海市水务局关于印发《上海市水务局（上海市海洋局）预算绩效管理工作实施细则》的通知

上海市水务局关于印发《上海市水务局（上海市海洋局）预算绩效管理工作实施细则》的通知

沪水务〔2021〕893号

局属各预算单位、局机关各处室：

为切实加强局系统预算绩效管理，提高财政资金配置效率和使用效益，我局组织修订了《上海市水务局（上海市海洋局）预算绩效管理实施细则》,经2021年12月20日局长办公会议审议通过，现予印发，请遵照执行。原《上海市水务局（上海市海洋局）预算绩效管理实施细则》（沪水务（海洋）〔2019〕2号）同时废止。

特此通知。

上海市水务局

2021年12月23日
