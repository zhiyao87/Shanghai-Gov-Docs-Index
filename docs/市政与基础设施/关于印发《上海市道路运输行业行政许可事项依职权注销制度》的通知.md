# 关于印发《上海市道路运输行业行政许可事项依职权注销制度》的通知

局各业务部门，市道运中心、委职业资格中心、委行政服务中心：

《上海市道路运输行业行政许可事项依职权注销制度》已经上海市道路运输管理局2023年第2次局长办公室审议通过。现印发给你们。

本制度于2023年3月13日起正式实施，请各相关部门（单位）遵照执行。

上海市道路运输管理局

2023年2月15日
