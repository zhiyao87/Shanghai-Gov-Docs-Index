# 关于印发《杨浦区内部道路精细化整治推进实施方案》的通知

各有关单位：

《杨浦区内部道路精细化整治推进实施方案》已经2025年10月29日区政府第136次常务会议通过，现印发给你们，请认真遵照执行。

杨浦区建设和管理委员会

2025年11月14日

杨浦区内部道路精细化整治推进实施方案

为深入贯彻上海市城市精细化管理总体要求，依据《杨浦区“内部道路”建设和管理导则（试行）》（杨府办〔2024〕9号），进一步深入推进杨浦区“内部道路”精细化整治工作，特制定本实施方案。

一、指导原则

政府引导，多方协同

加强组织领导，凝聚治理合力。属地街道作为托底管理的主体，相关部门协同推进。强化政府统筹，明确属地责任，推动权属单位、社区以及居民共同参与，充分调动社会力量和居民的积极性，营造共治共管的良好氛围。

分类纳管，分步实施

采用移交接管、自治纳管、街道托底等多种方式，对“内部道路”进行全覆盖分类纳管，消除管理盲区。制定科学合理的行动计划，稳步推进实施，持续提升管理水平。

依法依规，完善监管

坚持依法行政，依据现行法律法规，充分利用各类管理资源，加强“内部道路”管理和日常监管，切实解决突出问题，建立健全常态化管理机制。

二、工作目标

按照“立项一批、建设一批、完成一批”的推进计划，到2027年，实现“内部道路”市容环境面貌整体改善、精细化长效治理机制基本建立、共建共治共享成效显著、市民群众满意度持续提高的目标，使“内部道路”治理成为城市治理的亮点。

2年内完成现有31条街道托底管理类的“内部道路”治理任务。

3年内完成16条自治管理类、2条移交接管类的“内部道路”治理任务。

三、建设和管理标准

“内部道路”治理要达到“路面平、排水畅、照明适宜、标线清、路牌明”的“五保”基本建设标准，街道托底管理类“内部道路”整治完成后，应严格按照上述基本建设标准以及相关标准要求进行竣工验收。日常维护管理遵循“二勤”保基本标准。

实现“内部道路”路面平整、排水通畅，井盖、路灯等附属设施完备完好，标线标识清晰、违停现象基本杜绝，交通秩序显著优化、道路环境品质全面提升。对附属设施进行周期性保洁，确保无影响绿化景观的附属物。加强经常性巡查，落实常态长效管理和定期维修。

四、工作任务

（一）全面排查，分类建档

以街道为单位，对全区范围内的“内部道路”进行全面排查，梳理现状，明确重点整治内容，形成“一图一表一清单”。按照移交接管类、自治纳管类、街道托底管理类三种管理模式，对“内部道路”进行分类建档，并纳入杨浦区城市运行管理平台。整治完成一条，纳管一条，逐步将“内部道路”纳入行政执法范畴。

滚动更新完善“内部道路”档案，每年排摸新增拟列入下一年整治工作的“内部道路”。新增需要整治的“内部道路”，应在发现后立即以街道为主体，明确其权属和管理模式，提交内部道路权属调查等相关资料，由区建设管理委组织相关部门共同确认，报分管区领导决策。

相关部门：区建设管理委、区规划资源局、区公安分局、区城管执法局、区绿容局、滨江集团、属地街道等。

（二）一路一策，制定方案

属地街道对照“内部道路”建设和管理标准，根据每条“内部道路”的权属分类和现状情况，充分征求周边群众意见和需求，突出特色体验，推进个性化改造，因地制宜制定包含硬件整治和共管共享机制的“一路一方案”。

相关部门：属地街道、区建设管理委、区绿容局、区规划资源局、区公安分局等。

（三）整治提升，长效管理

结合城市更新专项行动，以及“美丽街区”“美丽家园”、文明城区创建活动，按照轻重缓急程度，将“内部道路”治理纳入各街道年度实施计划。

1.移交接管类

经区公安交通、区市政道路管理部门认定符合市政道路管理标准后，由区道路管理部门接管，同步开展接管养护、执法管理等工作；移交接管前，暂由建设单位或属地街道落实管理措施。以移交给区道路接管部门为目标， 3年内完成现有2条移交接管类的“内部道路”治理任务。

相关部门：区公安分局、区城管执法局、区绿容局、区建设管理委、滨江集团等。

2.自治管理类

首先由权利人或受益人落实养护责任，或按比例分担责任和费用。对于落实相关权属单位、使用单位等责任主体进行自治管理的，由属地街道负责监管，组织弄管会、路管会等加强协调管理。以成立弄管会、路管会为目标，3年内完成现有16条自治管理类的“内部道路”治理任务。

相关部门：属地街道、相关权属单位、相关使用单位、区公安分局、区城管执法局等。

3.街道托底管理类

由属地街道托底纳管，区政府和相关行业部门加强协调保障，2年内完成现有31条街道托底管理类的“内部道路”治理任务。

属地街道作为托底管理的主体，相关部门协同推进。属地街道将“内部道路”纳入网格化管理，托底牵头落实日常运维管理，加强相关日常巡查，建立“发现、派单、处置”的闭环管理机制。属地街道牵头组织辖区内公安交管、派出所、城管执法、市容环卫、市场监管以及消防等部门依法对“内部道路”乱象进行全覆盖管理，公安、道路、绿容、城管和房管等各专业部门予以支持和指导。

相关部门：属地街道、区公安分局、区城管执法局、区绿容局、区市场监管局、区消防救援局、区建设管理委、区住房保障房屋管理局、滨江集团、相关使用单位等。

五、资金保障

移交接管类：明确接管单位及接管内容后，由各接管单位核定设施量并上报预算计划，区财政做好经费保障。

自治管理类：运维期间所产生的费用由各权属、使用等责任主体承担。

托底管理类：由属地街道会同各行业主管部门制定“一路一方案”，属地街道作为预算主体，将相关建设和管理预算计划报各行业主管部门审核后，上报区财政局。若存在经营收益的，实行收支两条线管理。

六、源头管控

对规划拟建、新建公共通道，根据其所处区域采取不同管理措施：

处于商务商业区的，在土地出让阶段应明确“五保”基本建设要求，以及“安全、有序、干净、整洁、美观、开放”的运行维护要求，由产权人和使用人负责运维，竣工后由属地街道监管其运行维护情况，物业的主管部门予以支持及配合。

处于居民区范围的，在土地出让阶段应明确“五保”基本建设要求，竣工验收后，移交属地街道落实运维，避免新建公共通道出现新的管养缺失问题。

七、保障措施

相关部门密切协作形成合力，各街道落实主体责任，明确分管领导，建立任务台账，实行清单式管理、项目化推进。把“内部道路”治理工作作为关键环节，纳入城市更新重点工作计划。广泛宣传“内部道路”精细化治理的目的意义，讲好杨浦故事，宣扬典型案例、推广经验做法，并适时开展后评价工作收集信息以供参考。
