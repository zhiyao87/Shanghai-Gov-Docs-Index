# 关于印发《上海市公路养护工程管理实施办法》的通知

市道运中心、各区交通委（建交委）、高速公路各项目公司：

为规范本市公路养护工程管理，提高养护质量和效益，进一步优化营商环境，根据交通部《公路养护管理办法》，我局研究制定了《上海市公路养护工程管理实施办法》，现印发给你们，请认真遵照执行。

上海市道路运输管理局

2021年10月25日
