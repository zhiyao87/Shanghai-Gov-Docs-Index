# 关于延长《上海市政府购买服务管理办法》有效期的通知

各市级预算主管部门，各区财政局：

经评估，《上海市政府购买服务管理办法》（沪财发〔2021〕3号）需继续实施，有效期延长至2031年4月30日。

特此通知。

上海市财政局

2026年4月24日
