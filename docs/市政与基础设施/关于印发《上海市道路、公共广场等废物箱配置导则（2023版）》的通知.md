# 关于印发《上海市道路、公共广场等废物箱配置导则（2023版）》的通知

各区绿化市容局：

为进一步提升本市城市精细化管理水平，践行“人民城市”重要理念，塑造干净整洁的城市形象，规范和优化本市道路、公共广场等废物箱设置，现将《上海市道路、公共广场等废物箱配置导则（2023版）》印发给你们，请认真按照执行。

特此通知。

上海市绿化和市容管理局

2023年5月5日

上海市道路、公共广场等废物箱配置导则（2023版）

1.目的和意义

为进一步提升本市城市精细化管理水平，践行“人民城市”重要理念，塑造干净整洁的城市形象，规范和优化本市道路、公共广场等废物箱设置，特制订《上海市道路、公共广场等废物箱配置导则（2023版）》（以下简称《导则》）。

2.术语和定义

2.1废物箱：设置于道路和公共广场等公共场所供人们丢弃饮料瓶罐、餐巾纸等生活废弃物的容器。

2.2可回收物：指废纸张、废塑料、废玻璃制品、废金属、废织物等适宜回收、可循环利用的生活废弃物。

2.3有害垃圾：指废电池、废灯管、废药品、废油漆及其容器等对人体健康或者自然环境造成直接或者潜在危害的生活废弃物。

2.4湿垃圾，即易腐垃圾：指食材废料、剩菜剩饭、过期食品、瓜皮果核、花卉绿植、中药药渣等易腐的生物质生活废弃物。

2.5干垃圾，即其它垃圾：指除可回收物、有害垃圾、湿垃圾以外的其它生活废弃物。

3.设置原则

3.1适应本市生活垃圾分类要求，一般仅设置可回收物、干垃圾两类收集容器。

3.2适应道路和公共广场人流特征及生活垃圾产生特点。

3.3设置位置应既方便生活废弃物的投放，也方便分类收集和运输作业。

4.分类类别和标志

4.1应成组设置可回收物和干垃圾容器作为废物箱，分别收集可回收物和干垃圾。在旅游景区、商业中心、特色商业街区、公共广场、口袋公园、开放绿地等人流集中、产生可回收物较多的公共场所，也可细化可回收物为废纸张、废塑料、废玻璃制品、废金属等组合容器，同时并列设置干垃圾容器，构成组合型废物箱。

4.2应在废物箱箱体侧面喷涂或张贴干垃圾、可回收物、废纸张、废塑料、废玻璃制品、废金属等分类标志。分类标志颜色、图形标准参照《生活垃圾分类标志管理规范》（DB31/T 1127）。

5.设置要求

5.1道路废物箱应结合公交站点设置，原则上每座公交站点应设置1处。两座公交站点相邻50米以内的，可在两座站点中间位置设置，也可根据人流量情况分别设置。轨道交通站点出入口附近50米以内，明显可见位置应设置废物箱1处。

5.2人行横道线（人行过街设施）出入口附近50米以内，以中环线以内（含）、外作为划分区域，对照采用应设、宜设要求，设置废物箱1处。人流量较大的路段，可根据人流量、废弃物产生量等因素适当增加废物箱数量。

5.3公共广场应按照每2000平方米设置1处；口袋公园、开放绿地宜按照每1500平方米设置1处。具体根据公共广场、口袋公园、开放绿地布局以及人流路径等选择适宜的位置设置废物箱。

5.4旅游景区、商业中心、特色商业街区等根据人流量配置适宜数量的废物箱，原则上每50米设置1处。商业步行街路幅平均宽度超过20米的，宜两侧交叉设置，单侧间距可大于50米。

5.5设置废物箱时其底部应采用专业技术固定，确保牢固。

6.废物箱款式及投口改造要求

6.1鼓励废物箱全面进行投口改造，废物箱款式分为精细投口废物箱、简易投口废物箱、细化分类废物箱等，废物箱款式参照样式、尺寸、材质要求等详见附件。

6.2旅游景区、商业中心、特色商业街区、公共广场、口袋公园、开放绿地可设置精细投口废物箱，或者采用细化分类的废物箱。

6.3设置的废物箱应与周边环境氛围相适应，需要时可在满足基本样式和各项使用功能需求的前提下，适当调整款式、尺寸及材质。

7.其它

7.1废物箱箱体禁止任何形式的商业广告。

7.2机场、车站、公园、乡村旅游景点等公共开放场所设置废物箱的，其款式、分类标志等可参照本导则。

7.3.本导则自2023年7月1日起施行。《上海市绿化和市容管理局关于印发修订后〈上海市道路、公共广场等废物箱配置导则〉的通知》（沪绿容〔2019〕290号）同时废止。

1.精细投口废物箱

图1

1.1尺寸及容量

外形（长×宽×高）：1090mm×450mm×1050mm；干垃圾容量为50L×1，可回收物容量为18L×3，湿垃圾容量为18L×1。根据实际设置需要，废物箱容量可适当调整，其外形尺寸同比例调整。

1.2材质

1.2.1箱体采用厚度为1.2mm不锈钢板或镀锌钢板，两侧封板1.0mm不锈钢或镀锌钢板；底座1.2mm不锈钢或镀锌钢板，门板及后背板1.0mm不锈钢或镀锌钢板。废物箱整体采用静电喷涂工艺。

1.2.2废物箱投口采用塑料或金属材质，避免垃圾残留。

1.2.3废物箱内胆采用塑料或金属材质，与废物箱投口无缝衔接。

1.2.4表面分类标志采用丝网印刷或粘贴工艺，分类标志清晰度高、防紫外线、耐酸碱。
