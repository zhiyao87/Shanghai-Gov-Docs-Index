# 关于进一步加强大件运输车辆行驶公路核查管理工作的通知

市道运中心、各高速公路项目公司：

2021年12月18日下午，湖北省鄂州市沪渝高速与大广高速互通立交匝道发生桥梁侧翻事故，初步判定为大件运输车辆行驶公路所致。为深刻吸取此次事故教训，坚决遏制和有效防范此类事故发生，确保公路桥梁和人民群众出行安全，现就进一步加强大件运输车辆行驶公路核查管理工作通知如下：

一、从严加强超限运输许可核查工作

严格按照《公路安全保护条例》《超限运输车辆行驶公路管理规定》等有关政策规定，全面加强超限运输许可材料审查、现场核查和许可管理。市道运中心对承运人提交的申请材料认真审查把关，组织人员对车货总体外廓尺寸、总质量、车牌车型、起运点等数据加强现场核查，做到人、车、货、企相一致，防范承运人发生虚报瞒报现象。如发现承运人隐瞒有关情况或者提供虚假材料申请超限运输许可的，除依法给予处理外，暂停承运人申请超限运输许可资格，直至信用修复。

二、全面落实收费站入口验证核查

各高速公路项目公司要切实履行职责，严把收费站入口关，组织收费站工作人员对大件运输车辆进行称重检测和验证核查。对于入口称重设备显示超重或外廓尺寸明显达到三类标准（车货总高超过4.5米、或者总宽超过3.75米、或者总长超过28米）的货运车辆，利用“跨省大件审批”微信公众号，认真核查《超限运输车辆通行证》记载的车牌、货物、时间、路线、重量、尺寸、护送车辆等内容；同步实现收费站治超系统联网获取许可信息，自动核查大件运输车证等相关工作。一旦发现未办理通行证、使用假证或者车证不符等违法超限运输行为，一律禁止驶入高速公路，并及时通知市交通委执法总队、市交警总队依法处理。

三、严格开展倒查和“黑名单”制度

进一步加强事前审批与事中事后监管的有效衔接，市道路运输局、市道运中心充分利用治超平台监管数据、审批系统现场核查数据、车辆GPS等数据，倒查大件运输车辆实际行驶轨迹及装载情况，与许可数据进行比对分析，及时发现查处虚假填报、“大车小证”、不按许可路线行驶等违法超限运输行为。对于失信大件运输企业，建立重点监管“黑名单”，严格落实审批、监管措施。

四、积极组织行业宣贯与培训

充分发挥大件运输协会专业技术力量和桥梁纽带作用，多举措开展政策宣贯、企业培训、信用评级、通行安全快速评估等服务，加强宣传引导，鼓励企业诚信办证、合规运输。
