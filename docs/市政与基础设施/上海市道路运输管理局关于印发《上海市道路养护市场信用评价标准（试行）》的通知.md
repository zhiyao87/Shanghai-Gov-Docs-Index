# 上海市道路运输管理局关于印发《上海市道路养护市场信用评价标准（试行）》的通知

各有关单位：

为进一步优化营商环境，完善本市道路养护行业信用体系建设，做好《上海市道路养护市场信用信息管理办法》的实施工作，我局根据本市实际情况，制定了《上海市道路养护市场信用评价标准（试行）》，现印发给你们，请遵照执行。

特此通知。

上海市道路运输管理局

2022年8月3日
