# 关于开展高速公路拥堵节点改善提升工作的通知

市道运中心、各项目公司、各相关区交通委:

根据交通运输部和市交通委工作要求，我局梳理了本市高速公路15个拥堵节点改善工作计划，请市道运中心、各项目公司和各相关区交通委开展进一步的深化研究，通过养护专项、小改小革等方式开展改善提升，按节点要求（详见附表）完成，具体如下：

一、养护专项

5个主要涉及交通标志标线调整的节点纳入养护专项实施，包括G2嘉闵节点、S4剑川路/S32节点（标线部分）、G60七莘路节点、S20-S6-S7节点和G60/S4-外环西节点。相关养护专项应于2022年底前完成。

二、小改小革项目

11个不涉及新增用地的节点按高速公路道路交通缓拥堵小改小革项目实施，包括G1503重固、G1503永盛、G1503-浏翔、G1503-白鹤、G60大港、G60新浜、S4剑川路/S32节点（土建改造部分）、莘庄立交沪闵高架-G60地面道路改建、莘庄立交西北象限苜蓿叶拓宽、S32林海公路、S32嘉闵高架等。

以上11个项目均于2023年启动，其中G60大港、莘庄立交沪闵高架-G60地面道路改建、S4剑川路/S32节点（土建改造部分）、S32林海公路、S32嘉闵高架等5个项目应于2023年内完成，G1503永盛、G1503浏翔、G1503白鹤、G60新浜、G1503重固、莘庄立交西北象限苜蓿叶拓宽等6个项目应于2024年完成。

请各项目主体牵头开展立项研究，会同公安交警、属地交通等部门深化方案并尽快实施，确保在时间节点内完成，缓解本市高速公路的拥堵情况。

特此通知。
