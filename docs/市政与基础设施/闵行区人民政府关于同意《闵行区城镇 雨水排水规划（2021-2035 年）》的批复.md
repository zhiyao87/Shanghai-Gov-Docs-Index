# 闵行区人民政府关于同意《闵行区城镇  雨水排水规划（2021-2035 年）》的批复

区水务局：
你局闵水务〔2021〕115 号文《关于报请审批并印发<闵
行区城镇雨水排水规划（2021-2035 年）>的请示》收悉，经
区政府研究，现批复如下：
1.原则同意《闵行区城镇雨水排水规划（2021-2035 年）》
（以下简称《规划》）。至 2035 年，排水系统基本达到 3～5
年一遇排水能力，50～100 年一遇内涝可控，溢流污染负荷与
《上海市城镇雨水排水规划（2020-2035 年）》一致，控制率
达到 80%。
2.同意《规划》实施策略和分期实施计划，请你局会同有关单位做好《规划》的组织实施。要结合区域实际需求和本区
综合交通规划，进一步优化完善雨水排水系统功能布局，为后
续建设预留空间。实施过程中要有所弹性，结合市层面下达的
考核任务，按照轻重缓急原则排定分年度工作计划，有力有序
推进实施，并加强跟踪监测、督促检查和考核评估。
特此批复。

公开属性：主动公开
抄送：区发改委、区建管委、区交通委、区财政局、区规划资源局、
区房管局、区绿容局、区生态环境局。
