# 关于曹建华等7人《道路运输企业主要负责人和安全生产管理人员安全考核证明》作废的决定

上海永光汽车服务有限公司：

2022年2月12日15时左右，你公司车牌为沪EF8500的54座大客车前往贵阳方向途中，在石路冲大桥上行驶时，因车辆打滑，撞上护栏后冲入对向车道，与对向车道上的出租车发生相撞，事故导致出租车上1人死亡、3人受伤。

经调查，你公司沪EF8500客车在卫星定位系统因多次长期离线已被行业管理部门暂停核发省际包车标志牌的情况下，涉嫌故意关闭卫星定位及智能视频监控装置，未申领省际包车标志牌擅自违规经营，且单程运距超过800公里，违规行为极其严重，影响极其恶劣。同时还发现你公司存在以下问题：一是内部管理混乱，管理台账不规范，对车辆运行状况不掌握；二是动态监控措施形同虚设，对长期离线异常车辆坐视不管，对监控平台报警的车辆处置不及时处罚力度轻，安全隐患排查走形式；三是车辆管理失控，“以包代管”、“包而不管”现象严重，存在重大安全隐患；四是2月28日因未按照规定制定应急救援预案和对从业人员进行教育培训，且逾期未整改被市交通委作出责令停业整顿的行政处罚。为此，你公司道路运输企业主要负责人和安全生产管理人员存在未履行法定安全生产管理职责的行为。

根据交通运输部《道路运输企业主要负责人和安全生产管理人员安全考核管理办法》第十七条规定，决定作废你公司曹建华等7人《道路运输企业主要负责人和安全生产管理人员安全考核证明》：

1.姓名：曹建华；合格证编号：A02202031240302

2.姓名：肖三元；合格证编号：A02202031240301

3.姓名：王  衡；合格证编号：A01202131421449

4.姓名：戴  敏；合格证编号：B01202131644324

5.姓名：许红亮；合格证编号：B02202031281304

6.姓名：许建军；合格证编号：B02202031280052

7.姓名：曹庚午；合格证编号：B02202031240303

本决定自发布之日起生效。
