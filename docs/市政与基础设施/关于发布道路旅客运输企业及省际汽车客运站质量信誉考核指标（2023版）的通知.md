# 关于发布道路旅客运输企业及省际汽车客运站质量信誉考核指标（2023版）的通知

各有关单位：

现发布修改后的本市道路旅客运输企业及省际汽车客运站质量信誉考核指标（2023版），道路旅客运输企业包含省际班线、省际包车、市内包车客运经营企业，请各有关单位按照修改后的指标认真做好相关考核工作。当年度考核结果请上海市道路运输事业发展中心于次年度3月31日前报上海市道路运输管理局。

附件： 1.上海市道路旅客运输企业质量信誉考核指标（2023版）

2.上海市省际汽车客运站质量信誉考核指标（2023版）

上海市道路运输管理局

2023年7月11日
