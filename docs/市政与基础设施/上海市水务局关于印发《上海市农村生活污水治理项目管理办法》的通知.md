# 上海市水务局关于印发《上海市农村生活污水治理项目管理办法》的通知

上海市水务局关于印发《上海市农村生活污水治理项目管理办法》的通知

沪水务〔2021〕260号

各区水务局：

为进一步规范和加强本市农村生活污水治理项目管理，高质量做好农村生活污水治理工作，我局研究制定了《上海市农村生活污水治理项目管理办法》，现印发给你们，请结合实际贯彻落实。

特此通知。

上海市水务局
