# 关于进一步规范农村公路命名管理工作的通知

市道运中心、各区交通委（建交委）：

为进一步规范事权下放后的农村公路命名管理工作，提升农村公路命名工作的规范化、标准化水平，根据《中华人民共和国公路法》《地名管理条例》《上海市公路管理条例》、《上海市农村公路管理办法》等的规定，现将相关工作要求通知如下：

一、命名总体原则

农村公路命名工作应当严格遵循相关法律法规的规定，适应经济社会发展、人民生活的需要，坚持规范性、稳定性、唯一性的原则。相关审批单位应严格按照公路命名工作的要求，确保命名过程合法合规、命名方案规范合理、命名材料真实有效。

二、具体工作要求

（一）农村公路中的乡道和村道，以及浦东新区、嘉定新城、青浦新城、松江新城和奉贤新城范围的县道由各区交通委（建交委）审批。

（二）需要命名的农村公路应已纳入各区最新的《农村公路建设规划》。

（三）农村公路命名方案除了符合农村公路命名原则（详见附件1）和区域发展需求，还应事先征询属地地名管理部门和公安部门的意见，避免同名同音、门牌号编排冲突等问题。

（四）命名工作应在新建公路通车的三个月前完成批复，审批后的农村公路命名报市道路运输局、市道运中心及相关区地名主管部门备案和公告，经过正式命名批复的农村公路方可纳入本市公路设施量范围。

（五）审批单位应严格审查命名农村公路的规划、建设、命名方案、意见征询单以及相关图纸等支撑材料，确保命名材料真实有效。

（六）审批单位除了将批复结果通知申请部门外，还应及时将审批结果告知设施接管部门、地名管理部门和公安部门。

（七）命名批复完成后，应督促申请部门及时设置规范的标志标牌，并准确标识经批复的路名。

（八）对于经审批废弃的农村公路路名，各区交通委（建交委）应及时告知区地名管理部门从地名库中予以注销。

三、下一步工作

（一）明确工作职责，加强组织管理

各区交通委（建交委）要切实做好负责审批的农村公路命名工作，落实专门的负责部门和人员，并保持相对稳定，请各区将名单于3月底前报送市道路运输局（格式见附件2）；加强本区内农村公路命名的组织管理，做好审批和申报人员的培训工作，确保命名的规范性落到实处，建立长效工作机制。

（二）强化沟通协作，实现信息共享

公路命名审批完成后,各区交通委（建交委）要及时将批审批结果告知各区地名管理部门，确保路名及时纳入地名管理信息平台；命名过程中，各区交通委（建交委）要做好与地名管理部门的沟通对接，接受地名管理部门的指导。

（三）夯实监督检查，确保责任落实

请各区认真核查梳理本区的农村公路命名情况，对历史遗留问题，将根据各区具体情况专题研究后进行统一调整；对于新增的命名设置不规范的，要督促申请单位立即整改；市道路运输局也将对本市农村公路的命名情况进行不定期抽查，抽查结果将纳入行业检查结果中予以通报。
