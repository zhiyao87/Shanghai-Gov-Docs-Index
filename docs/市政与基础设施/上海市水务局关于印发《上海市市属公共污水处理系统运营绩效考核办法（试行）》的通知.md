# 上海市水务局关于印发《上海市市属公共污水处理系统运营绩效考核办法（试行）》的通知

上海市水务局关于印发《上海市市属公共污水处理系统运营绩效考核办法（试行）》

沪水务〔2024〕235号

城投水务集团、市城市排水有限公司、城投污水处理有限公司：

为建立服务效能管理和评价付费挂钩的机制，进一步加强对上海市市属公共污水处理系统设施运行监督与管理，强化运营单位主体责任，提高服务质量和服务效能，上海市水务局制定了《上海市市属公共污水处理系统运营绩效考核办法》，现印发给你们，请遵照执行。

特此通知。

上海市水务局

2024年5月21日
