# 青浦区赵巷镇人民政府关于印发《赵巷镇农村生活污水处理设施运行维护考核实施方案（试行）》的通知

各村（居）、企事业单位、新城一站大居：

现将《赵巷镇农村生活污水处理设施运行维护考核实施方案（试行）》印发给你们，请认真贯彻落实。

特此通知。

上海市青浦区赵巷镇人民政府

2025年9月23日

赵巷镇农村生活污水处理设施运行维护考核实施方案（试行）

第一条  为进一步加强赵巷镇农村生活污水处理设施运行维护管理工作，提升运行维护水平，充分发挥农村生活污水处理设施效益，巩固农村生活污水治理成果。根据《青浦区农村生活污水处理设施建设和运行维护管理办法（试行）》的通知（青水〔2022〕131号）及《青浦区农村生活污水处理设施运行维护考核办法（试行）》（青水〔2019〕46号）等有关要求，制订本考核实施方案。

第二条  本考核实施方案适用于赵巷镇农村生活污水处理设施（含污水收集系统和处理系统）运行维护工作情况的考核。考核对象为赵巷镇农村生活污水处理设施（含污水收集系统和处理系统）运行维护单位，由赵巷镇农村生活污水处理设施长效运行维护管理单位组织开展对赵巷镇农村生活污水处理设施（含污水收集系统和处理系统）运行维护单位考核工作。

第三条  考核内容主要包括组织管理、站容站貌、日常养护、台账资料、社会监督等方面，具体如下：

（一）组织管理

长效管理项目部设置规范，管理人员按标准配置。

（二）站容站貌

处理站管理房室内做到干净整洁无积尘；室外保洁确保无废弃物、堆积物，各类公告公示牌完整整洁；绿化养护结合季节性特点做好施肥浇水、修枝整形、防治病虫害等，确保绿化植物无霉污、病枝、虫害，无占绿、毁绿等现象。

（三）日常养护

为满足设施正常、安全运转所需开展的常态化养护，养护技术要求严格按照《上海市水务局关于印发<上海市农村生活污水处理技术管理要求（暂行）>》等相关标准执行。主要包括收集系统、处理系统、加药装置、MBR膜、沉淀池、出水口等。

1.收集系统：集水池完好无渗漏堵塞、无结构缺损、无违章占压、无污水冒溢；各管道、窨井及井盖完好，井底无沉积物，管道畅通无冒溢。

2.处理系统：处理站隔油池、格栅池、调节池、活性生物滤床等处理相关池结构完好，无明显沉降裂缝，进水通畅，无渗漏堵塞、无污水冒溢；格栅无栅渣，无异物堵塞；水泵运行良好、无异常振动和噪声，连接管道无渗漏；电控柜内无脏乱、无外接电现象，相关工作指示灯正常，相关的接电设施无缺损，完好运行；相关锁具完好。

3.储药及生物滤料装置：添加药剂，储药箱药液液位保持正常位；生物滤料完好挂膜充足。

4.MBR膜：无明显堵塞，进水及过滤顺畅，有清洗维护资料。

5.农污底泥：有处理处置相关台账资料。

6.出水口：完好畅通无杂物堵塞。

（四）台账资料

巡查管理台账、日常养护台账及管道、设施设备台账等记录及时、完整，整理归档及时。各类整改工单、热线电话按规定时间整改反馈。

（五）上级行业督查

上级相关部门开具的行业督查整改单作为对养护单位考核打分的依据。

（六）出水水质

出水水质达标率要求达到100%。

第四条  考核实行百分制。考核总分80分以下的为不合格，考核总分达到80分及以上的为合格。

第五条  本考核实施方案由上海市青浦区赵巷镇人民政府负责解释。

第六条  本考核实施方案自发布之日起开始施行，原赵府〔2019〕42号文废止。
