# 上海市奉贤区水务局关于印发《奉贤区水资源调度实施细则（试行）》的通知

区河道水闸管理所、庄行水务管理所：

为进一步规范和加强我区重要水利工程运行控制管理，确保我区防汛安全和河道活水畅流，区水务局组织编制了《奉贤区水资源调度实施细则(试行)》，现予以印发，请遵照执行。请庄行水务管理所结合实际情况，编制圩区水资源调度方案，报区水务局备案后实施调度。

本细则自发布之日起实行，区水务局印发的《奉贤区水资源调度实施细则》(沪奉水务〔2023〕77号)同时废止。

特此通知。

上海市奉贤区水务局

2024年4月24日
