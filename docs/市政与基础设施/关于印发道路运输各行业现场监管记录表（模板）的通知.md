# 关于印发道路运输各行业现场监管记录表（模板）的通知

各有关单位：

为落实委、局领导关于完善闭环管理的工作要求，回应各区关于指导更新道路运输各行业现场监管记录表模板样式的需求，进一步加强管理和执法衔接，现将道路运输各行业现场监管记录表模板样式（见附件）印发给你们，用于行业日常现场监管。记录表中的监管内容，局各业务部门、道运中心各业务部门可在保证基本监管要素的前提下，根据实际工作需要自行调整。各区可根据实际情况参考使用。

附件：1.大件运输许可事中事后监管表（模板）

2.占掘路事中事后监管表（模板）

3.道路停车场日常监管记录表（模板）

4.公共停车场库日常监管记录表（模板）

5.道路货物运输行业上户监管表（模板）

6.道路危险货物运输行业上户监管表（模板）

7.客运企业现场监管情况记录表（模板）

8.客运站、车辆明察暗访表（模板）

9.公交营运车辆监管情况表（模板）

10.道路清障施救牵引企业监督管理表（模板）

11.机动车驾驶员培训行业现场监管表（模板）

12.机动车维修行业现场监管表（模板）
