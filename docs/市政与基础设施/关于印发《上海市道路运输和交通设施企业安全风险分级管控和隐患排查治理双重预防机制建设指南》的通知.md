# 关于印发《上海市道路运输和交通设施企业安全风险分级管控和隐患排查治理双重预防机制建设指南》的通知

各相关单位：

根据《安全生产法》《上海市安全生产条例》等有关法规要求，我局编制了《上海市道路运输和交通设施企业安全风险分级管控和隐患排查治理双重预防机制建设指南》，经2023年12月28日局党组会第22次会议审议通过，现印发给你们。请各业务处室会同市道运中心细化所辖行业安全风险分级管控和隐患排查治理双重预防机制，指导所辖行业企业制定本单位的双重预防机制，认真开展安全安全风险分级管控和隐患排查治理。

各区交通委（建管委）参照本通知细化辖区行业安全风险分级管控和隐患排查治理双重预防机制，指导辖区行业企业开展安全安全风险分级管控和隐患排查治理。

特此通知。

上海市道路运输管理局

2024年1月8日
