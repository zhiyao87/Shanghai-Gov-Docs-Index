# 关于严永清等6人《道路运输企业主要负责人和安全生产管理人员安全考核证明》作废的决定

上海嘉城汽车服务有限公司：

2021年9月16日你公司沪FH1127大客车，在嘉定区世盛路胜竹西路口与一电动自行车发生碰撞，造成电动车驾驶人当场死亡的事故，经交警部门认定该车驾驶员负全部责任。事故发生后，你公司未按照行业突发事故（件）信息报告内容及程序向管理部门报告，瞒报事故，性质恶劣。我局于2022年1月21日向全行业通报你公司事故瞒报行为，2月21日纳入上海市道路运输市场严重失信主体名单。

根据交通运输部《道路运输企业主要负责人和安全生产管理人员安全考核管理办法》第十七条规定，决定作废你公司严永清等6人《道路运输企业主要负责人和安全生产管理人员安全考核证明》：

1.姓名：严永清；合格证编号：A02202031240745

2.姓名：杜加林；合格证编号：A02202031240717

3.姓名：朱  强；合格证编号：A01202131455546

4.姓名：浦* 俊；合格证编号：B02202031240716

5.姓名：朱国栋；合格证编号：B01202131441875

6.姓名：沈  坚；合格证编号：B02202031240715

本决定自发布之日起生效。
