# 上海市水务局关于印发《上海市水闸安全鉴定工作管理办法》的通知

上海市水务局关于印发《上海市水闸安全鉴定工作管理办法》的通知

沪水务〔2023〕416号

各区水务局、市水利事务中心、市堤防泵闸建设运行中心及有关单位：

为进一步加强本市水闸安全运行管理，指导水闸规范开展安全鉴定工作，根据水利部《水闸安全鉴定管理办法》相关要求，结合本市实际，市水务局修订《上海市水闸安全鉴定工作管理办法》，于2023年5月18日局长办公会审议通过，现印发给你们，请认真遵照执行。

原《上海市水闸安全鉴定工作管理办法》（沪水务〔2011〕912）同时废止。

特此通知。

上海市水务局

2023年6月21日
