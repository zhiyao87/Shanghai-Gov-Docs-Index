# 上海市水务局关于进一步明确水利工程责任单位责任人质量终身责任追究有关事项的通知

上海市水务局关于进一步明确水利工程责任单位责任人质量终身责任追究有关事项的通知

沪水务〔2022〕863号

各有关单位：

为进一步加强水利工程责任单位责任人质量终身责任管理，压实质量终身责任，提高质量责任意识，根据《水利工程责任单位责任人质量终身责任追究管理办法（试行）》（水监督〔2021〕335号）和《上海市水务局关于进一步加强水务建设工程质量责任主体项目负责人质量终身责任的通知》（沪水务〔2018〕556号）以及相关转发文件精神，现将有关事项明确如下：

一、加强责任人质量终身责任管理制度

（一）项目负责人应在办理工程质量监督手续前签署工程质量终身责任承诺书，连同项目负责人任命文件、授权书、身份证复印件、职业资格证书复印件、变更材料等证明材料，一并由建设单位（项目法人）报工程质量监督机构备案。

（二）建设单位（项目法人）应建立水利工程责任单位项目负责人质量终身责任信息档案，档案应包括任命文件、授权书、身份证复印件、职业资格证书复印件、变更材料等证明材料。信息档案应单独整理成册。

二、强化责任人质量终身责任追究

（一）建设单位（项目法人）应加强对项目负责人履行质量责任行为的考评，并将考评成果应用到日常差别化管理和后续工程招标之中。

（二）各级水行政主管部门要严格按照《水利工程责任单位责任人质量终身责任追究管理办法（试行）》第四章要求，依法依规加强对责任单位责任人终身质量责任的追究。

特此通知。
