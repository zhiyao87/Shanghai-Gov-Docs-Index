# 关于命名沈家弄路等54条（段）道路为上海市林荫道的通知

各区绿化市容局：

对照《上海市林荫道评定办法》，通过各区绿化主管部门自评和推荐，经相关专家现场评定，沈家弄路等54条（段）道路（详见附件）符合林荫道评定标准。经公示无异议，现决定命名沈家弄路等54条（段）道路为2021年度上海市林荫道。

经对前期评定的林荫道进行复审，2012年评定的交通路林荫道，目前因道路改扩建已不符合林荫道标准，撤销其林荫道称号。

希望各区按照《本市提升行道树养护管理精细化水平三年（2019-2021）行动计划》(沪绿容〔2019〕341号)文件精神和行道树综合养护工作要求，认真落实行道树各项养护和管理措施，切实提高林荫道养护质量，进一步提升道路绿化景观面貌。

特此通知。
