# 上海市水务局关于印发《太湖流域河道外水量分配方案（上海部分）》的通知

上海市水务局关于印发《太湖流域河道外水量分配方案（上海部分）》的通知

沪水务〔2021〕897号

各有关区人民政府：

根据《中华人民共和国水法》《太湖流域水量分配方案》和《上海市实行最严格水资源管理制度考核办法》，我局组织编制了《太湖流域河道外水量分配方案（上海部分）》，现印发给你们，请认真贯彻实施。

特此通知。

上海市水务局

2021年12月23日
