# 关于沿江通道西延伸（江杨北路-富长路）改建工程涉及原市公路处部分带征土地的协调意见

上海市道路运输事业发展中心：

沿江通道西延伸（江杨北路-富长路）改建工程用地涉及你中心原郊区环线宝山段工程带征土地8371.9平方米和郊区环线北段蕰川路立交工程带征土地5802.7平方米（房屋土地权属调查报告书，成果号201800478377），根据沪府土〔2005〕583号、沪府土〔2006〕213号文件，现属宝山区土地管理部门管理。

为支持推进重大工程，经与市交通委建设处、市道运中心、宝山区重大办、宝山区规资局、城投环城高速公司等相关单位会商研究后，同意上海城投环城高速建设发展有限公司（项目建设单位）在沿江通道西延伸（江杨北路-富长路）改建工程中使用上述带征土地共计14174.6平方米，后续项目如涉及有偿征用相关带征土地的，拟用地单位与你中心（原征地主体）结算所涉土地前期征地成本。请你中心配合办理后续用地手续。

附件：1.关于批准宝山区人民政府为上海市公路管理处建设郊区环线宝山段工程征用土地、收回土地和对该项目供地的通知（沪府土〔2005〕583号）

2.关于批准宝山区人民政府为上海市公路管理处建设郊区环线北段蕰川路立交桥工程农用地转用、征用土地、收回国有土地使用权和该项目供地的通知（沪府土〔2006〕213号）

3.关于沿江通道西延伸（江杨北路-富长路）改建工程涉及带（代）征土地的情况说明
