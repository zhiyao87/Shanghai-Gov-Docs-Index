# 关于全面开征污水处理费的通告

根据《关于完善长江经济带污水处理收费机制有关政策的指导意见》（发改价格〔2020〕561号）、《上海市排水与污水处理条例》以及《上海市污水处理费征收使用管理实施办法》（沪财预〔2016〕25号）（简称《办法》）等文件规定，自2024年1月1日起将全面征收污水处理费。现将有关事项通告如下：

一、征收范围及对象

向本区城镇排水与污水处理设施排放污水、废水的单位和个人。

二、征收标准

根据《关于调整区属供排水企业服务区域居民用户水价的复函》（嘉发改价〔2023〕12号）和《关于调整区属供排水企业服务区域非居民用户水价的复函》（嘉发改价〔2023〕13号），嘉定区区属供排水企业服务区域居民用户污水处理费征收标准为2.00元/吨，非居民用户、特种用水污水处理费征收标准为2.97元/吨，排水量按用水量90%折算。

三、收费管理

根据《办法》第八条，污水处理费由上海市嘉定区水务局负责征收，属于区级收入，全额缴入区级国库。根据《办法》第十四条，污水处理费由上海市嘉定自来水有限公司、嘉定区黄渡自来水厂、上海嘉定外冈自来水厂、上海嘉定区沪翔自来水厂、上海沪江自来水有限公司、上海封浜自来水有限公司6家供水企业在收取水费时一并代征，并在发票中单独列明污水处理费的缴款数额。

特此通告。

上海市嘉定区水务局
