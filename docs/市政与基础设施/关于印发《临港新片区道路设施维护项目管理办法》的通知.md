# 关于印发《临港新片区道路设施维护项目管理办法》的通知

关于印发《临港新片区道路设施维护项目管理办法》的通知

沪自贸临管委〔2024〕44号

管委会各部门、各直属单位，临港新片区各镇、各有关单位:

为进一步保障临港新片区道路设施高效安全运行，着力提高城市精细化管理水平，根据本市有关规定，结合新片区实际，管委会组织修订《临港新片区道路设施维护项目管理办法》，现印发给你们，请认真遵照执行。

中国（上海）自由贸易试验区临港新片区管理委员会

2024年5月13日

临港新片区道路设施维护项目管理办法

第一章　总则

第一条（目的依据）

为保障临港新片区道路设施高效安全运行，着力提高城市精细化管理水平，建立健全道路维护管理的常态长效机制，以全覆盖、全过程、全天候和法治化、社会化、智能化、标准化为着力点，规范道路设施综合维护管理，提高设施维护质量和水平，提升城市品质，根据本市城市维护有关规定，结合新片区实际，制定本办法。

第二条（定义）

本办法所称的道路设施维护，是指对临港新片区产城融合区域内道路及其附属设施的大中修、日常维护、布局调整、功能提升及完善、结构调整、综合整治、应急处置以及相关运营管理活动等。

第三条（适用范围）

新片区产城融合区域内道路设施综合维护范围，包括城市道路、公路、桥梁及其附属设施、标志标线、雨水管道、雨水泵站、绿化、路灯及控制箱设施、地下综合管廊以及管委会安排的其他道路设施等，具体以设施清单的形式明确。市级管养道路设施除外，村内道路按本市有关规定执行。

新片区道路设施维护保障范围需要修改补充的，由管委会建交处会同发改处、财政处提出调整建议，报管委会领导同意后，纳入新片区道路设施维护保障范围。

第四条（职责分工）

在临港新片区城市管理精细化工作领导小组及其办公室的领导下，依托市政交通能源联席会议工作机制，管委会相关部门和单位按照职责分工，协同推进有关工作。

建交处承担联席会议办公室的日常工作，负责新片区道路设施维护管理相关规划编制、计划平衡、方案审批，统筹协调新片区道路设施维护项目前期研究、项目推进，按职责负责相关行政审批。

建交中心是新片区道路设施维护管理的管理部门，负责管委会直管道路设施的日常维护管理和镇管设施的行业管理，以及上级部门交办的其他事项。

发改处负责落实道路设施大修项目列入年度计划和项目审批。

财政处负责对道路设施维护项目年度预算资金进行管理和监督。

办公室（审计室）负责对道路设施维护项目使用资金进行审计。

综合执法大队负责在事权范围内对违反城市道路、公路管理行为进行处罚。

各镇人民政府负责镇管道路设施日常维护管理。

管委会规资处、生态处等其他相关部门根据各自职责协同实施本办法。

第五条（资金保障）

新片区道路设施维护资金，由管委会负责统筹安排并予以保障。建交处会同财政处根据城市精细化管理要求、设施量增长、养护体制改革、技术革新、标准定额制修订等情况，结合管委会财力水平，建立临港新片区道路设施维护资金增长机制。

第六条（养护作业市场化）

加大推进道路设施养护作业领域市场化改革力度，鼓励养护企业走规模化、专业化发展道路，不断提升城市基础设施养护效率和服务水平，培育稳定的养护作业队伍，加强对日常养护队伍的监管考核，鼓励养护企业进行科研创新，积极推广成果应用。

第二章　项目立项程序

第七条（发展规划）

建交处组织编制道路设施维护五年发展规划和三年行动计划。经管委会认定的道路设施维护五年发展规划、三年行动计划是临港新片区道路设施维护项目立项的重要依据。

第八条（项目储备）

临港新片区道路设施维护项目实行项目库管理。对符合临港新片区道路设施维护资金保障范围的项目，建交处应组织建交中心、各镇尽早开展项目前期研究工作，及时将成熟的项目纳入储备库，实行滚动管理。对未列入储备库的项目原则上不得批复。

第九条（项目审批）

临港新片区道路设施维护项目按照项目性质，分为工程类、日常维护类、管理类等三类。立项审批主体应委托符合相应资质要求的工程咨询机构对工程类项目设计文件进行评审。

（一）工程类项目

根据有关文件、规范，工程类项目包括大修和整治（含中修、小修）等。

1、大修项目。由建设单位组织编制项目建议书、工程可行性研究报告（初步设计深度）报管委会，建交处出具行业审核意见，发改处进行审批。

2、整治项目。对管委会直管设施，建交中心组织编制实施方案（初步设计深度），由建交处进行审批。对镇管设施，各镇组织编制实施方案（初步设计深度），由建交中心出具行业审核意见，建交处进行审批。

（二）日常维护类项目

对管委会直管设施，建交中心应根据日常养护标准定额，组织编制实施方案及项目年度预算，经建交处会同财政处审核并经管委会同意后，纳入建交中心部门预算并组织实施。对镇管设施，各镇应根据日常养护标准定额，组织编制实施方案及项目年度预算，由建交中心初审，建交处会同财政处审核通过后，纳入建交中心部门预算并由各镇组织实施。

（三）管理类项目

政策研究、规划编制、科研、指南编制、专项业务等行业管理类项目，由建交中心组织申报，建交处根据管委会有关程序，会各相关部门审核同意后，根据职责分工相关费用分别纳入建交处、建交中心预算。

应急抢险救灾工程按管委会沪自贸临管委〔2021〕744号文执行。对举办重大活动、重要节日及应急任务等其他特定需求的项目，项目审批、维护标准等可根据保障需求不同，采取“一事一议”方式，报管委会同意后实施。

第三章　年度计划和预算安排

第十条（计划和预算申报）

建交中心应根据财政预算编制要求，组织编制道路设施维护项目年度实施计划和预算初步安排并报建交处，优先安排日常维护类和工程结转项目。

建交处按照轻重缓急进行审核和排序，形成项目年度实施计划及预算支出的建议，会发改处、财政处等部门根据相关规划、年度重点工作及项目储备深度，经统筹协调、综合平衡后，向管委会提出年度道路设施维护项目实施计划和预算安排建议。

第十一条（计划确定和预算下达）

道路设施维护项目年度实施计划和预算，经管委会规定程序批准后，由相关部门下达给各有关单位和部门，相关费用在管委会建设财力和专项资金中安排。

第十二条（预算调整）

道路设施维护项目年度预算一经批准，不得自行调整。预算执行过程中，如发生项目变更、终止，确需调整的，应按照预算调整规定程序报批，经审核同意后，方可进行调整。

第四章　项目实施

第十三条（分类管理）

大修项目参照建设项目基本程序有关要求，办理项目报建、招标投标、合同信息报送、施工许可、工程质量监督、竣工验收备案等手续。

整治项目、日常维护类和管理类项目，按照管委会预算管理的有关要求执行。

第十四条（招投标和政府采购）

1、大修、整治项目。由管委会指定单位作为责任单位，严格按照招投标法律、法规、规章及相关规定进行。

2、维护类、管理类项目。建交中心、各镇应根据政府采购相关法律、法规、规章及相关规定所明确的采购方式和程序进行，并与中标单位签订协议。

第十五条（财务监理）

工程类项目和维护类项目二类经费实行财务监理制度。财政处负责委派财务监理，并抄送建交处。财务监理负责项目全过程的资金监控管理等工作。

第十六条（项目用款）

日常维护类和管理类项目按合同约定核拨。工程类项目根据管委会有关规定按进度核拨。

提交用款申请材料包括：用款申请表、项目批复文件、中标通知书、合同复印件，工程监理、财务监理报告，以及建交处、财政处要求的其他资料。

第十七条（项目监管）

建交中心应加强道路设施维护项目在整个实施过程中的考核检查，对技术、质量、安全、合同、进度、预算执行实施监管。

第十八条（概算调整）

责任单位应严格执行立项批复内容，原则上不得擅自调整或突破批复总投资，确需调整的，应按照管委会有关规定履行报批手续。

第十九条（审计监督）

大修项目竣工后，责任单位应及时组织编制决算报告，并向管委会办公室（审计室）提出审计申请，由办公室（审计室）组织项目审计，有关报告抄送建交处。

第二十条（竣工验收销项）

大修项目由责任单位组织竣工验收，建交中心参加。责任单位应根据审计意见，及时编制项目竣工决算报告（报表）上报建交中心，由建交中心负责审批和销项，并抄报建交处。

第二十一条（考核评价）

按照城市管理精细化工作要求，建交处应建立道路设施维护工作考核评价机制，建交中心对各镇的道路设施维护工作进行检查考评。考核评价工作可采用政府购买方式委托第三方实施，相关费用在建交中心预算中安排。

建交中心、各镇应加强日常管理，对道路设施日常维护、养护情况实施情况进行绩效评价。

建交处组织有关部门对建交中心、各镇及相关责任主体的项目管理工作进行考核评价。

第二十二条（违规处理）

各参建单位、管理部门及咨询、评估、监理、审价、审计、招标代理等社会中介机构应按照法律、法规规定，履行相应工作责任。

对违反国家有关规定和本办法的相关单位、人员，管委会有关职能部门可在职权范围内提出意见建议或直接给予限期整改、通报批评、暂停安排年度计划、劝诫或限制其参与城市维护工作等相应处罚；情节严重的，依法追究行政、法律责任。

第五章　附则

第二十三条（办法解释）

本规定由临港新片区管委会负责解释。

第二十四条（施行日期）

本规定自发布之日起施行，根据实际情况适时修订。
