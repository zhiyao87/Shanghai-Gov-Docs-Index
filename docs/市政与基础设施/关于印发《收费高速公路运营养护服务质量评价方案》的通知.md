# 关于印发《收费高速公路运营养护服务质量评价方案》的通知

市道运中心、各高速公路项目公司：

为进一步强化收费高速公路设施养护监管，提升收费高速公路服务质量，规范收费高速公路运营养护服务质量考核，确保高速公路品质提升专项行动实施成效，我局研究制定了《收费高速公路运营养护服务质量评价方案》。现印发给你们，请结合工作实际，认真遵照执行。
