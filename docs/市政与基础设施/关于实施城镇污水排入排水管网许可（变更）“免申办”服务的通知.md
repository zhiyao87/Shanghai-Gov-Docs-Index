# 关于实施城镇污水排入排水管网许可（变更）“免申办”服务的通知

各区水务局、临港新片区管委会，相关局属单位：

为贯彻落实国家和本市优化政务服务和营商环境等有关要求，根据市政府办公厅《依托“一网通办”加快推进惠企利民政策和服务“免申即享”工作方案》和《上海市深化“一网通办”改革 打造“高效办成一件事”最佳体验地行动方案》要求，市水务局即日起实施城镇污水排入排水管网许可（变更）“免申办”（简称排水许可变更“免申办”），该“免申办”服务已上线“一网通办”。现将有关事项通知如下：

一、适用范围

本市范围内的排水许可变更事项

二、办理流程

排水许可变更“免申办”通过数据共享、大数据比对、人工智能辅助实现“一键确认，免于填报”。

（一）内部流程。各区水务局（临港新片区管委会）通过水务海洋政务服务系统排水许可变更“免申办”模块，抓取排水户名称、法定代表人变更信息后自动预填申请信息，并通过“一网通办”企业专属空间推送消息，告知企业在单位名称、法定代表人变更之日起30日内进行“一键确认”，后续按照“即办件”流程进行办理。“免申办”服务上线前未及时变更的排水许可证，将结合本次服务上线进行集中推送办理。

（二）外部流程。企业收到推送消息后进行“一键确认”，确认后即可获取行政许可决定书和排水许可证，免去申请环节的表格填报和材料提交。

三、工作要求

各区水务局（临港新片区管委会）要准确把握排水许可变更“免申办”的服务要求和工作流程，加强对排水户的宣传指导，确保改革举措落地见效，不断提升审批服务的便捷度和企业群众的获得感。

特此通知。

上海市水务局

2026年8月12日
