# 金山区人民政府办公室关于转发《金山区关于进一步加强公共消防安全工作的意见》的通知

各镇人民政府、街道办事处、工业区管委会，区人民政府各部门、各直属单位：

《金山区关于进一步加强公共消防安全工作的意见》已经第64次区政府常务会议讨论通过，现转发给你们，请认真按照执行。

上海市金山区人民政府办公室

2019年8月2日

金山区关于进一步加强公共消防安全工作的意见

为深入贯彻落实习近平总书记在省部级主要领导干部坚持底线思维着力防范化解重大风险专题研讨班开班式上的重要讲话精神，根据《消防安全责任制实施办法》（国办发〔2017〕87号）、《上海市人民政府办公厅关于进一步加强本市公共消防安全工作的意见》(沪府办规〔2019〕5号)精神，结合本区实际，为建立本区消防安全重大风险防范化解长效机制，全力维护城市运行安全，现就进一步加强本区公共消防安全工作提出以下意见：

一、建立健全消防工作机制，全面落实消防安全责任制

1.加强政府组织领导。根据2017年国办下发的《消防安全责任制实施办法》，明确政府主要领导为消防工作第一责任人，分管领导为主要责任人。将消防工作列入政府考核内容，实行年初签约、年底考核制度，并做好考核结果运用。对重大火灾隐患单位和突出火灾隐患集中区域，实行政府挂牌督办。根据火灾事故“四不放过”原则，建立亡人火灾和较大以上火灾事故区政府牵头调查机制。

2.强化行业部门监管。推广行业消防安全标准化建设，研究解决行业消防安全难题，固化行业系统火灾特点和突出火灾隐患问题定期通报机制。根据“管行业必须管安全”的要求，各行业部门要将消防安全纳入业务工作同研究、同部署、同检查、同考核、同落实，积极开展消防安全专项治理。聘请第三方服务机构，强化消防安全高风险区域或行业领域的调研评估。实行行业系统消防安全考核机制，建立完善行业单位信用记录制度。

3.夯实基层网格管理。健全街镇（工业区）消防组织机构，将消防管理嵌入“一居一警”“一村一警”职能范畴，建强消防协管员队伍，常态化开展消防安全隐患排查和消防安全宣传教育。强化基层网格排查制度，将消防工作嵌入城市网格化综合管理信息系统和智慧综治平台，全面运用“金山区社会消防安全检查监管信息系统”，形成“基层网格—居村委—街镇（工业区）安全事务所（消防协管员工作站）、公安派出所—消防救援支队”的网格工作机制。结合“平安社区”“美丽乡村”建设，推行“消防安全社区”创建活动，实行居民住宅“楼组长”制，依托“邻里守望”微信群，强化群防群治、末端管理，有效防范化解村居住宅火灾风险。

4.落实单位主体责任。落实消防安全重点单位定期约谈、责任签约、集中培训等工作制度。鼓励企业落实消防安全管理人持证（注册消防工程师证）上岗，自主使用“金山区社会消防安全检查监管信息系统”开展消防安全自查自改。立足消防安全“四个能力”建设，全面落实“6＋1”措施，加大人防、物防、技防投入，提升单位消防安全本质度。

5.改革消防执法模式。强化消防服务意识，进一步加大“放管服”工作力度，推行公众聚集场所开业前消防安全检查承诺制，通过事中监管简化开业前审批流程。推行“双随机、一公开”，建立监管人员信息库和社会单位信息库，监督检查和处理结果全面向社会公开。监督检查由“管事”向“管人”转变，进一步强化单位主体责任落实。

二、夯实公共消防基础建设，加快推进消防站点水源建设

6.优化消防站点建设布局。年内开工建设山阳消防救援站，加快推进兴塔消防救援站建设。筹备廊下、漕泾、金山工业区（小型）消防救援站建设，由属地政府负责站点建设，区消防救援支队派员派车进驻。提前谋划金山区新一轮城市总体规划消防专项规划（2045）消防站建设。

7.积极推进消防水源建设。将市政消火栓建设列为区政府实事项目，由区交通委牵头，区发改委、区建管委、区水务局、区消防救援支队配合。属地政府要强化缺水区域消防取水码头建设，最大程度满足消防灭火救援用水需求。

三、提升综合应急救援能力，筑牢城市公共消防安全防线

8.提升综合救援队专业水平。建设城市综合应急救援体系，建立政府综合救援协作机制，统筹协调供水、供电、供气、交通运输、工程抢险、医疗卫生、应急通信等各种救援力量。结合金山区消防保卫工作形势任务特点，着力建设石油化工、水域救援、危化品槽车处置3支专业救援队伍，分类组建消防救援专家库，筹建研战实训基地，增配相应车辆装备，强化专业培训。加大消防科研投入，创新新材料、新技术在消防救援实战中的应用。

9.做大建强社会消防力量。积极推进政府、企业专职消防队站建设。制定出台微型消防站建设管理办法，明确人员、车辆和装备配备标准，实行分级管理，定期开展培训演练。着眼“打早灭小”，建立村（居）委微型消防站，其建设和运行费用按照“财政事权与支出责任相匹配的原则”，由各级财政予以保障，形成一批有人、有装备、有战斗力的“灭火先遣队”。建立志愿者队伍、第三方服务机构等社会力量参与日常消防工作机制。

10.完善“智慧消防”体系建设。持续推动社会单位消防物联网建设及智能消防社区建设，依托区“一网一平台”建设区级智慧消防综合平台，汇集各类安全信息数据，逐步形成社会单位消防自主管理状态、监管部门执法动态等“建筑、设施、单位”数据相互叠加、一图显示、底数清晰的火灾防控信息化格局。探索建立灭火救援指挥智能系统，推进无人机实战应用模式及数字化预案3D桌面推演，将参与灭火救援实力、警情等重要信息快速整合，为火场指挥员决策提供全方位、多角度、可视化信息支撑。

四、强化社会化消防宣传，夯实火灾防控群众基础

11.完善行业部门联合宣传机制。建立消防公益宣传机制，将消防安全常识作为入职培训、在职培训、换岗培训必训内容。区委宣传部、区文明办、各行业管理部门和街镇（工业区）要充分利用各种宣教资源，积极营造“铺天盖地”的消防宣传氛围，形成本区居民“人人了解消防、人人重视消防、人人参与消防”的大格局。

12.完善线上线下联动宣传机制。试点以政府购买服务的方式，推广消防宣传社会化，聘请专业团队开展消防宣传培训，做强做大“金山消防”官方媒体线上宣传，依托消防救援站建设消防安全体验设施，组织群众参与线下体验。

13.完善全民参与宣传工作机制。发动平安志愿者、社区工作者、消防宣传大使等，开展走街入户式宣传，针对“三不人群”开展点对点式服务，扩大消防宣传的覆盖面，增强消防宣传的渗透性。对在消防宣传工作中表现突出的人员予以奖励，激发参与宣传的热情和动力。

五、加强消防救援队伍职业保障，发挥应急救援主力军作用

14.强化消防救援队伍职业荣誉保障。将消防救援队伍工作纳入党委政府绩效、精神文明综治等考评奖励范畴，探索畅通消防救援干部和地方党政干部的交流渠道。对执行重大灭火救援、重大安保的集体和个人，给予即时机动表彰奖励。重大节日、重大任务、重要节点，各级党委、政府安排走访慰问消防救援队伍。

消防救援人员子女入学、家属随调、落户就业、交通出行、看病就医等方面保持原有政策。对于符合本市公共租赁住房、符合共有产权保障住房准入条件的消防指战员家庭均可纳入住房保障范畴，并享受保障住房政策。按照市与区财政事权和支出责任划分意见，结合本区实际，调整完善消防救援队伍职业保障机制。

上海市金山区消防救援支队

2019年7月15日
