# 上海市消防救援局关于印发《上海市消防安全领域依法不予行政处罚清单》的通知

各区消防救援局，局属各单位，各有关单位：

《上海市消防安全领域依法不予行政处罚清单》已经局第14次办公会审议通过，现印发给你们，请认真贯彻执行。

上海市消防救援局

2026年1月13日

上海市消防安全领域依法不予行政处罚清单

一、下列初次违法且危害后果轻微并及时改正的，不予行政处罚：

（一）违反《中华人民共和国消防法》第二十八条，损坏、挪用消防设施、器材，首次发现后，当场改正，且没有实际影响使用的；

（二）违反《中华人民共和国消防法》第二十八条，占用、堵塞、封闭疏散通道、安全出口或者有其他妨碍安全疏散行为，首次发现后，当场改正，且没有实际影响疏散逃生的；

（三）违反《中华人民共和国消防法》第二十八条，埋压、圈占、遮挡消火栓，首次发现后，当场改正，且没有实际影响使用的；

（四）违反《中华人民共和国消防法》第二十八条，占用防火间距，首次发现后，当场改正，且没有实际造成火灾蔓延的；

（五）违反《中华人民共和国消防法》第二十八条，占用、堵塞、封闭消防车通道，妨碍消防车通行，首次发现后，当场改正，且没有实际影响消防车通行的；

（六）违反《社会消防技术服务管理规定》第十五条，消防技术服务机构未建立或者保管消防技术服务档案，首次发现后，当场改正，且危害后果轻微的；

（七）违反《社会消防技术服务管理规定》第十六条，消防技术服务机构未公示营业执照、工作程序、收费标准、从业守则、注册消防工程师注册证书、投诉电话等事项，首次发现后，当场改正，且危害后果轻微的；

（八）违反《社会消防技术服务管理规定》第十四条第二款，消防设施维护保养检测机构未按照规定要求在经其维护保养的消防设施所在建筑的醒目位置上公示消防技术服务信息，首次发现后，当场改正，且危害后果轻微的；

（九）违反《高层民用建筑消防安全管理规定》第十五条第一款，在高层民用建筑内进行电焊、气焊等明火作业，未履行动火审批手续、进行公告，或者未落实消防现场监护措施，首次发现后，当场改正，且危害后果轻微的；

（十）违反《高层民用建筑消防安全管理规定》第十九条第一款，未设置外墙外保温材料提示性和警示性标识，或者未及时修复破损、开裂和脱落的外墙外保温系统，首次发现后，当场改正，且危害后果轻微的；

（十一）违反《高层民用建筑消防安全管理规定》第三十二条第二款，因维修等需要停用建筑消防设施未进行公告、未制定应急预案或者未落实防范措施，首次发现后，当场改正，且危害后果轻微的。

二、下列违法行为轻微并及时改正，没有造成危害后果的，不予行政处罚：

（十二）违反《中华人民共和国消防法》第十六条第一款第二项，未保持完好有效的消防设施类别为1类，或消防器材、消防安全标志未保持完好有效，当场改正，且不影响系统功能的；

（十三）违反《中华人民共和国消防法》第十六条第一款第二项，室内消火栓箱内配件存在缺损仅1处，当场改正，且没有实际影响使用的；

（十四）违反《中华人民共和国消防法》第二十八条，占用、堵塞、封闭疏散通道、安全出口未超过该疏散通道、安全出口总宽度的20%或仅1处，当场改正，且没有实际影响人员疏散的；

（十五）违反《中华人民共和国消防法》第二十八条，埋压、圈占、遮挡消火栓仅1处，当场改正，且没有实际影响使用的；

（十六）违反《中华人民共和国消防法》第二十八条，人员密集场所在消防救援窗、排烟窗以外的其他门窗上设置影响逃生和灭火救援的障碍物，涉及门窗数量仅1个，当场改正，且没有实际影响逃生和灭火救援的；

（十七）违反《上海市消防条例》第二十八条第三款，二类高层住宅建筑，没有随施工进度落实消防水源，当场改正，且没有造成危害后果的。

三、下列当事人有证据足以证明没有主观过错的违法行为，不予行政处罚：

（十八）违反《中华人民共和国消防法》第十六条第一款第二项，消防设施、器材或者消防安全标志的配置、设置不符合国家标准、行业标准或者未保持完好有效，当事人有证据证明已自行发现前述问题、故障，采取有效措施整改，且已落实消防安全防范措施或者将危险部位停用；

（十九）违反《中华人民共和国消防法》第二十八条，拆除、停用局部区域的消防设施、器材，当事人有证据证明因室内装修、设备维护等确需停用，已书面报经消防安全责任人或者管理人同意，并落实消防安全防范措施，在建筑入口处等显著位置张贴公告，且不影响其他区域消防设施、器材正常使用的。

四、其他符合《中华人民共和国行政处罚法》等法律、法规、规章规定的不予行政处罚情形的违法行为，依法不予行政处罚。

五、第二项列举的轻微违法行为，根据《消防监督检查规定》“对违法行为轻微并当场改正完毕，依法可以不予行政处罚”的要求，可以口头责令改正，并在检查记录上注明；其他依法不予行政处罚的，消防救援机构应当制作并送达《不予行政处罚决定书》。

六、对于适用不予行政处罚的消防安全领域违法行为，应当对单位场所的主要负责人、消防安全管理人等责任人员开展普法守法和火灾警示教育。

七、本清单由上海市消防救援局负责解释，自印发之日起施行，《上海市消防领域轻微违法行为不予处罚清单》（沪消规〔2022〕1号）同时废止。
