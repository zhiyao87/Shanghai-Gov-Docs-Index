# 上海市静安区人民政府办公室关于转发区消防支队《静安区消防救援发展三年行动计划（2019—2021）》的通知

区政府各委、办、局，各街道办事处、彭浦镇政府：

区消防支队《静安区消防救援发展三年行动计划（2019—2021）》已经区政府第135次常务会议通过，现转发给你们，请认真按照执行。

静安区消防救援发展三年行动计划

（2019—2021）

一、指导思想

为全力维护全区消防安全形势稳定，防范化解重大风险、全面提高风险隐患防控能力、严守城市运行安全底线，坚决防止发生重特大火灾事故。根据习近平总书记在省部级主要领导干部坚持底线思维着力防范化解重大风险专题研讨班开班仪式上的重要讲话精神，《中共中央办公厅国务院办公厅印发<组建国家综合性消防救援队伍框架方案>的通知》（中办发〔2018〕50号）、《上海市人民政府办公厅关于进一步加强本市城市公共消防安全工作的意见》（沪府办规〔2019〕5号），按照市委、市政府关于全市开展重大风险排查工作统一部署，结合我区消防安全高风险排摸情况，制定本计划。

二、工作任务

（一）加强消防安全防灾减灾体系建设

1．建立工作机制。建立区消防工作汇报协调机制，将防范化解消防安全重大风险纳入重要议事议程，定期听取工作汇报，分析研判形势，及时研究部署、协调解决火灾防控重点、难点和堵点问题。继续保留区消防安全委员会工作业务协调职责，保持发文立户、独立参会、协调政府有关职能部门开展工作等权限。（责任单位：区委办、区政府办公室、区委组织部、区应急局、区消防支队）

2．建设责任体系。根据国务院办公厅关于印发《消防安全责任制实施办法》，推动制定《静安区消防安全责任制实施办法》等配套文件，建立健全消防安全风险防控责任体系。推动各行业部门完善落实定期会商、隐患抄告、联动执法等制度，并深化教育、民政、卫健、文物等四部门消防安全标准化建设。联合区公安分局各派出所进一步完善监督检查、联合整治、宣传教育等职责。推动街镇持续深化“消防安全平安社区”创建活动，全面推行居民住宅“楼长”制，继续强化“邻里守望”微信群建设，广泛发动市民群众参与群防群治。（责任单位：区政府办公室、区公安分局、区应急局、区消防支队、各街镇）

3．完善考评办法。督促落实重点消防风险排查和整治工作，持续将消防工作纳入区委、区政府对各委办局、街镇的年度工作考核，落实“年初签约、项目推进、过程监督、阶段评估、定期通报、年底考核”的消防工作目标责任考核机制，实化消防考核结果运用。（责任单位：区政府办公室、区应急局、区消防支队）

4．结合区政府“十四五”规划，将消防工作纳入经济社会发展总体规划，将包括消防安全布局、消防站、消防供水、消防通信、消防车通道、消防装备等内容的消防规划纳入城乡规划，并负责组织实施，确保消防工作与经济社会发展相适应。（责任单位：区政府办公室、区发展改革委、区消防支队）

（二）进一步夯实公共消防基础

1．持续开展消防宣传教育培训。建立消防公益宣传机制，共享各级公益宣传平台，推动行业系统、各街镇落实消防宣传教育责任。将消防安全教育内容纳入党政干部晋职前培训，组织党政主要领导、行业部门、居（村）委负责人、安全干部及网格员开展消防安全培训。开展企业消防安全责任人、管理人、消防专兼职人员、消防控制室操作人员、物业保安等队伍的职业培训和职业技能资格鉴定。将消防安全培训设置为外来务工人员入职、换岗培训必训科目。分类细化落实幼儿园、中小学校“消防寒暑假期作业”、“消防安全开学第一课”、“消防演练进军训”。构建主流媒体与新媒体公众号协作机制，定期开展消防宣传和隐患曝光。（责任单位：区委组织部、区委宣传部、区委党校、区教育局、区文化旅游局、区人力资源社会保障局、区应急局、区消防支队、各街镇）

2．推进微型消防站建设。根据《上海市微型消防站建设标准》要求，鼓励企业、社区设置微型消防站，设置专（兼）职消防组织和岗位人员，确保落实“1分钟出动、3分钟处置”要求。各微型消防站队员每年按要求参加消防支队组织的相关岗位培训课程，接受消防支队对微型消防站点名和调度工作。各社区微型消防站队员必须参加本社区火灾扑救逃生演练，提升社区火灾的防控以及自救能力。探索通过政府购买服务方式，建全保安、志愿者队伍等社会力量参与日常消防安全管理机制，为企业、社区微型消防站队员投保人身意外伤害保险，完善出勤补贴制度。（责任单位：区应急局、区消防支队、各街镇，配合单位：区财政局）

3．加强消防水源建设。研究制定《静安区消防水源建设方案》，将消防水源建设纳入住宅小区“美丽家园”建设，补建市政消火栓169具，增建6个街镇（石门二路街道、江宁路街道、天目西路街道、大宁路街道、临汾路街道、彭浦镇）天然水源消防取水设施24处。本着“信息共享、积极协调”的原则，加强对公共消防设施的维护保养，建立健全消防水源长效管控机制。（责任单位：区发展改革委、区财政局、区消防支队、有关街镇）

4．持续推进政府消防实事项目。围绕老旧小区消防设施改造、高层住宅消防设施改造、电动自行车库（棚）增配消防设施器材等民生实事，持续推动市、区、街镇三级消防实事项目落地。提高养老机构消防技防水平，安装火灾自动报警、自动喷淋设施和电气火灾监控系统以及故障电弧探测器，做到能第一时间发现火患、及时整改火患，提高养老机构消防安全物防技防水平。（责任单位：区公安分局、区民政局、区财政局、区应急局、区房管局、区消防支队、各街镇）

5．开展高层建筑消防登高作业面排摸整治。对高层建筑周边消防车道开展常态化排查，其设置的停车位、绿化、架空线路、电车网架等设施不得影响消防车的停靠和作业，确保消防车道通畅，供大型登高装备作业展开。（责任单位：区公安分局、区绿化市容局、区应急局、区消防支队）

（三）持续稳控社会面消防安全形势

1．逐步整改重大隐患。采取滚动排查、梯次递进、集中挂牌方式将一批重大火灾隐患提请区政府挂牌督办，明确整改要求落到实处，及早消除重大风险隐患。同时以目标责任书的形式纳入委办局、街镇年度消防工作考评。（责任单位：区应急局、区消防支队）

2．紧盯高风险隐患场所。依托消防委平台，会同各成员单位聚焦大型商业综合体、高层建筑、老旧小区、地下空间等防火难点，不间断开展整治行动，全面查改占用消防通道、私拉乱接电线、楼道堆物、电动自行车违规充电等隐患问题，定期组织“回头看”行动，防止隐患回潮。对教育、民政、卫健、文物分行业、分领域、分类别开展专项治理，固化建立长效管理机制。（责任单位：区公安分局、区商务委、区教育局、区民政局、区文化旅游局、区卫生健康委、区应急局、区房管局、区民防办、区消防支队、各街镇）

3．加强基层消防管理。公安部门将消防管理嵌入一线综合执法民警职能范畴，开展防火安全检查、消防宣传等联勤防火工作。紧盯“九小场所”等动态性隐患，持续将消防工作纳入街镇网格化综合管理巡查范畴，最大限度调动网格员、平安志愿者、市民巡防员等基层社会治理力量参与一般火灾隐患的发现和消除，做到“消减存量、控制增量”。（责任单位：区公安分局、区城管执法局、区应急局、区房管局、区城运中心、区消防支队、各街镇）

（四）进一步提升应急救援能力

1．完善区域综合应急救援联动体系建设。立足应急救援“全灾种、大应急”，构建公安、消防、城运中心联勤联动机制，划分灾害、救援出警等级，并将社会组织、微型消防站等社会力量纳入指挥调度体系，科学调度、科学用警。整合各方应急资源，建立多元化应急联勤联保联战联训机制，区城运中心协助做好应急指挥状态时的平台支撑和保障。定期组织消防、民防、医疗卫生、环保、电力、工程机械等力量联合开展应急救援演练，磨合各救援力量联动模式。（责任单位：区政府办公室、区公安分局、区应急局、区生态环境局、区民防办、区城运中心、区消防支队）

2．逐步探索建立区消防支队与区城运中心双向分流协作机制。适时完成区城运平台与区消防平台的互通开发工作，实现工单互派。建立双向分流实施方案和工作清单，对非紧急社会救助类警情进一步细分，建立正面处置清单，成熟一块分流一块，减少社会救助警情对基层消防站队的影响，集中力量磨砺应急救援尖兵。（责任单位：区政府办公室、区应急局、区城运中心、区消防支队）

3．加强消防指挥智能化建设。在全区重点单位物联网工程建设完成基础上，进一步将“九小场所”、门面店等纳入物联网建设对象。精心打造“智慧消防”平台，将物联网数据接入“智慧消防”平台，与区城运中心、公安分局共享数据信息，为消防监督检查、应急救援提供辅助决策。（责任单位：区公安分局、区应急局、区城运中心、区消防支队）

4．推进消防站点建设。在大宁地区选址租赁建设一座小型消防站。完成万荣消防站点净地，力争万荣消防站按时建成投用。根据区总体规划和消防站点建设标准，在“十四五”规划制定中、远期消防站点专项规划。（责任单位：区发展改革委、区财政局、区规划资源局、区建设管理委、区应急局、区消防支队、各街镇）

5．完善应急救援架构建设。立足高起点，倾力打造中兴站成为上海市城区中心消防航母基地。按“一、三、四”模式构建重大灾情应急救援框架，即以中兴消防站为核心，以静安、恒丰、闸北消防站为主力，以市北、广延、保德、大宁消防站为辅助，以其他社会救援力量为补充的重大灾情应急救援架构。（责任单位：区应急局、区消防支队，配合单位：区财政局）

6．分步实施车辆装备配备更新。逐步配齐满足“全灾种、大应急”救援需要的特种车辆，加快主战车辆更新。紧盯辖区高层、城市综合体、地下空间等重大风险应急处置，强化“一队一专”建设，实现专业队装备配备集成化、模块化、专业化。按照《城市消防站建设标准》、装备达标建设和实战实际需求，提升常规装备配备数量与质量。（责任单位：区应急局、区消防支队，配合单位：区财政局）

（五）进一步加强消防职业保障

1．加强经费保障。薪资待遇上，按照消防救援工作中央与地方财政事权和支出责任划分意见，结合上海市相关政策要求，制定消防救援队伍地方经费保障办法。（责任单位：区财政局、区应急局、区消防支队）

2．强化生活待遇保障。医疗保障上，按照国家和上海市相关政策执行；伤亡抚恤待遇上，消防救援人员按规定享受国家机关工作人员伤亡抚恤待遇，被评定为烈士的消防救援人员家庭，享有烈士家属的各种荣誉和待遇。（责任单位：区委组织部、区人力资源社会保障局、区民政局、区应急局、区消防支队）

3．明确住房保障待遇。消防救援人员参照地方行政单位在职人员住房公积金管理办法及标准统一进行保障。保障消防救援人员公租房、廉租房、保障房、人才公寓。（责任单位：区人力资源社会保障局、区财政局、区人口办）

4．强化社会优待保障。根据市政府相关政策文件对消防救援人员本人及其配偶、子女在已成立的集体户和家庭户落户，调动人员户口随迁，行政编制消防救援人员家属随调、就业，离职消防员救援人员按规定享受现有就业培训扶持政策和自主创业税费优惠，消防救援人员子女入学优待予以配合。（责任单位：区教育局、区民政局、区人力资源社会保障局、区人口办）

5．实行消防救援人员优先政策。在车站、码头、医院等单位享受优待政策，确保消防救援人员可凭有效证件优先购票、挂号、通行，有条件的单位可在对外办事窗口设置“消防救援人员优先”字样标识。消防救援人员参观本区的公园、博物馆、展览馆，享受免票或与现役军人同等优待政策。（责任单位：区建设管理委、区文化旅游局、区卫生健康委）
