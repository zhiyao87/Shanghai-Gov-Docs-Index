# 中国（上海）自由贸易试验区临港新片区管理委员会关于印发《临港新片区地下空间规划设计导则（试行）》的通知

中国（上海）自由贸易试验区临港新片区管理委员会关于印发《临港新片区地下空间规划设计导则（试行）》的通知

沪自贸临管委〔2020〕922号

管委会各部门、各有关单位:

为进一步统筹临港新片区地上地下空间资源，加强地下空间的规划引领，高质量规划面向未来的立体城市，构建体系完整、功能复合、生态智慧、安全高效的地下空间系统，管委会组织制定了《临港新片区地下空间规划设计导则（试行）》，现印发给你们，请遵照执行。

中国（上海）自由贸易试验区临港新片区管理委员会

2020年11月11日
