# 关于印发《2026年虹口区为老旧小区内既有的40个电动自行车集中充电（停放）场所加装消防设施的消防为民办实事项目实施方案》的通知

区消防救援局、区住房保障房屋管理局、区公安分局、区财政局、区发改委、各街道办事处：

根据《中共虹口区委办公室 虹口区人民政府办公室印发〈2026年虹口区民生实事项目〉的通知》（虹委办﹝2026﹞2号）有关要求，为保质保量完成我区“为老旧小区内既有的40个电动自行车集中充电（停放）场所加装消防设施”建设任务，现制定《2026年虹口区为老旧小区内既有的40个电动自行车集中充电（停放）场所加装消防设施的消防为民办实事项目实施方案》，请各单位结合实际抓好落实。

特此通知。

附件：2026年虹口区为老旧小区内既有的40个电动自行车集中充电（停放）场所加装消防设施的消防为民办实事项目实施方案

虹口区应急管理局

2026年2月26日

附件

2026年虹口区为老旧小区内既有的40个电动自行车集中充电（停放）场所加装消防设施的消防为民办实事项目实施方案

为保质保量完成我区“为老旧小区内既有的40个电动自行车集中充电（停放）场所加装消防设施”建设任务，特制定本实施方案。

一、工作目标

通过为我区老旧小区内既有的电动自行车集中充电（停放）场所加装消防设施，持续改善老旧居民小区消防安全硬件环境，综合提升辖区火灾防御能级。

二、项目内容

原则上选取100平方米以上的电动自行车集中充电场所进行改造。一要增设简易喷淋系统，末端压力不小于0.03MPa。二要加装火灾探测器，火灾报警信号反馈至视频监控室或其他24小时有人值班的场所（含区域“一网统管”平台），确保初期火灾报警和应急处置及时高效。三要在出入口、充电区域增设视频监控系统，安装不少于2个数字高清摄像机，配置硬盘、交换机、显示器等相关设备（改造前已安装视频监控系统的可不再增设）。四要更换电动自行车集中充电场所老旧电气线路，统一加装空气开关等断电保护装置。五要按照规范标准要求加装消防应急照明、疏散指示标志、灭火器、手动报警装置、红外火焰探测器等消防设施设备，不断提高电动自行车集中充电场所消防安全防范水平。

三、职责分工

该为民办实事项目建设主体为区应急局，统筹开展项目建设、工程验收和管理移交等工作。区消防救援局负责协调、指导项目推进工作，对改造方案进行技术把关，并参加项目完工后的联合检查验收等工作。区财政局、区发改委负责落实项目所需经费。区住房保障房屋管理局和区公安分局各辖区派出所负责指导、协调物业服务企业和业委会配合该项工作的开展。各属地街道负责排摸辖区内电动自行车集中场所底数情况，指导协调居民小区业委会配合开展消防实事项目。

四、实施步骤

按照“统一组织、统一标准、分步实施”的原则，有序推进为民办实事项目。

(一)第一季度：做好项目立项工作，制定项目实施方案，并确定电动自行车集中充电（停放）场所选址工作；

(二)第二季度：完成项目审批、各参建单位选取和招投标工作；

(三)第三季度：全面实施建设施工。

(四)第四季度：完成项目施工和自查验收工作。

五、经费保障

经初步匡算，每个电动自行车集中充电（停放）场所建设费用以10万元计，共需经费约400万元，由区级财政承担。

六、工作要求

(一)强化组织领导。各单位要坚持“人民至上、生命至上”理念，充分认清当前老旧居民小区电动自行车集中充电场所火灾多发易发、亡人较多的短板难题，切实加强组织领导，推动将消防安全设施增配或改造项目纳入美丽家园建设、房屋修缮工程、街道惠民项目中统筹考虑、一并实施，细化具体方案，落实保障经费，定期召开协调会、推进会，跟踪督办项目进度，确保实事项目有序进行。

(二)明确标准要求。相关单位在确定项目改造点位和改造内容时，要坚持实事求是、科学合理的原则，优先选取面积较大、需求迫切的场所纳入改造，提高资金使用效益，提升群众对政府消防实事项目的获得感、满意度。

(三)规范后续维保。加装的消防设施要移交给全体业主的， 纳入小区业主共用设施设备管理范围，小区业委会与物业服务企业应当就质保期（两年）后的日常管理等事项进行约定，保障消防设施正常运维；未明确质保期后运维责任的，由街道托底保障消防设施日常运行安全。

(四)加强宣传引导。各单位要加强对消防实事项目的宣传报道，积极发动群众广泛参与，全面提升市民群众对消防实事项目的关注度和满意度。要提前做好宣传、告知和解释工作，加强施工现场的监督管理，最大限度减少对市民群众日常生活的影响。
