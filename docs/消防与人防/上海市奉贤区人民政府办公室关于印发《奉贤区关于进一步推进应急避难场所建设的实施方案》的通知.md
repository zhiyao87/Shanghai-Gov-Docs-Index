# 上海市奉贤区人民政府办公室关于印发《奉贤区关于进一步推进应急避难场所建设的实施方案》的通知

各镇人民政府，街道办事处，开发区管委会，头桥集团，区政府各部门：

《奉贤区关于进一步推进应急避难场所建设的实施方案》已经奉贤区第六届人民政府14次常务会议审议通过，现印发给你们，请认真按照执行。

上海市奉贤区人民政府办公室

2022年8月4日

奉贤区关于进一步推进应急避难场所建设的实施方案

应急避难场所是城市在地震、台风等灾害事故发生后，用于接纳受灾居民临时或较长时间避难或生活，并可供政府组织开展救灾工作的场所。推进应急避难场所建设，是增强城市韧性、提升城市抗风险能力的必要举措。为适应新一轮城市规划建设要求，根据《关于进一步推进本市应急避难场所建设的实施方案》(沪民防〔2021〕102号)通知要求，现就进一步推进本区应急避难场所建设提出实施方案如下：

一、基本原则

坚持融合式建设、标准化嵌入、功能性叠加、多灾种防护的原则。在建设方式上融入相关场地场所建设改造项目，在建设内容上充分利用现有资源和规划资源，在建设标准上全面对接相关场地场馆建设规范要求，在功能设置上不影响原主体功能发挥，在防护对象上兼顾多灾种防护需要。

二、目标任务

本区应急避难场所建设类型分为等级应急避难场所(包括6个等级)和社区应急避难场所2类，其中等级应急避难场所建设面积应不少于总量的30%。

(一)到2025年，全区建成等级应急避难场所避难面积达到87.75万平方米，设置社区应急避难场所避难面积204.75万平方米，即全区人均避难面积达到2.3平方米。

(二)到2035年，全区应急避难场所基本满足本区常住人口应急避难需求，总计建成等级应急避难场所避难面积达到111.41万平方米，设置社区应急避难场所避难面积达到273万平方米，全区人均避难面积达到3.0平方米。

三、建设方式

应急避难场所建设应结合利用城市已建或规划新建的大中小学校、公园绿地、大型公共场馆和公共空间等场地场所进行，根据相关场地场馆设施条件和规模，采取直接设置、配建设置、融入新建等方式建设。

(一）直接设置。对满足应急避难场所设置条件的场地场所，按照权属关系，由所在镇政府、街道(开发区)办事处、头桥集团或区政府相关部门(单位),组织评估和方案设计，直接设置为对应类型(等级)应急避难场所。

(二）配建设置。对基本符合条件、需增加相应应急设施的场地场所，按权属关系，分别由所在镇政府、街道(开发区)办事处、头桥集团或区政府相关部门(单位)组织评估和方案设计，配套建设相应应急设施，设置为对应类型(等级)应急避难场所。

(三）融入新建。对符合设置条件的新建(含改扩建)项目，按权属关系，由所在地镇政府、街道(开发区)办事处、头桥集团或区政府相关部门(单位)将应急避难场所建设融入新建(含改扩建)项目，按照规划要求，纳入主体建设内容，同步建设。

四、实施要求

应急避难场所建设，应严格执行选址、功能区划定和设施配置规范标准。在资源利用上，应落实能改尽改、应建尽建要求。类型划定时，优先考虑建设等级应急避难场所，后考虑建设社区避难应急避难场所。

(一）科学规划，合理布局。各镇政府、街道(开发区)办事处、头桥集团或区政府相关部门(单位)应按照规划要求，分析资源现状和城市规划建设情况，梳理各镇政府、街道(开发区)办事处、头桥集团和域内单位人员应急避难需求，兼顾人口分布、地理环境特点，对接规划和应急预案要求，科学规划布点，优化类型设置和类型等级分配，确保布局合理、总量落实、点位落地。

(二）制定计划，统筹推进。各镇政府、街道(开发区)办事处、头桥集团按区下达的目标任务，编制五年实施目标，细化年度计划安排，确保推进进度，2025年前完成总目标的75%(详见附表),2035年前全部完成建设任务。

(三）分类实施，规范流程。对可直接设置的，2021年、2022年由区民防办、区应急管理局统一指导、集中认定，后期将按隶属关系由各镇政府、街道(开发区)办事处、头桥集团和区相关部门(单位)负责实施，分阶段或集中推进实施;对需配建设置的，由镇政府、街道(开发区)办事处、头桥集团和区政府相关部门(单位)落实实施主体，根据基础条件明确设备配置和设施建设内容，组织推进落实;对融入新建(含改扩建)项目的，由项目实施单位负责实施，区政府和区相关职能部门进行项目审批时，将应急避难场所建设内容纳入新建(改扩建)项目的审批条件和基本建设管理流程。应急避难场所建设完成后，相关资料及经纬度信息报区民防办和区应急局备案。

(四）做好保障，落实经费。区政府将增加投入，2021年和2022年对成批量集中直接设置的项目由区政府统一保障，后期直接设置项目以及应急避难场所建设设计、评估及设备购置经费按照权属由区政府和属地街镇各自承担保障。对配建设置的项目，设计、评估及配套设备设施经费，由实施主体落实保障。融入新建(含改扩建)时，建设经费列入主体项目总投资，相关非区属项目建设经费由原保障渠道解决。应急避难场所建设形成的资产列入项目实施单位管理，应急避难场所建设、管理和维护由应急避难场所所在单位负责,其上级主管部门负责指导、监督应急避难场所所在单位落实主体责任。

五、职责分工

按照条块结合、属地负责的原则，在区政府的统一领导下，区民防办、应急管理局牵头，区发展改革委、规划资源局、建设管理委、财政局、教育局、绿化市容局、体育局、经委(商务委)、文化旅游局、房管局等部门履行相应职责，各镇政府、街道(开发区)办事处和头桥集团落实主体责任。

区民防办：负责制定区级应急避难场所专业规划和年度建设计划;根据上海市《应急避难场所设计规范》指导全区应急避难场所的建设，参与应急避难场所的检查和验收;负责应急避难场所建成后的管理和维护的行业监管，指导产权单位做好日常维护。

区应急管理局：参与制定区级应急避难场所专业规划和年度建设计划;参与应急避难场所的建设指导和验收;参与应急避难场所建成后的日常管理和维护的行业监管;负责全区应急避难场所启用。

区发展改革委：负责把握应急避难场所建设规划与国民经济和社会发展规划的衔接，按照规划要求把结合建设的应急避难场所建设内容纳入项目审批范围，指导街镇规划部门的项目审批。

区规划资源局：指导各街镇和相关委办局完善落实区域规划和控制性详细规划，并将避难建设按专业规划指导要求纳入规划和土地出让条件。

区建设管理委：负责把应急避难场所建设内容纳入新建、改建等城市更新项目的建设管理流程。

区财政局：负责推进落实本区应急避难场所建设和维护管理所需经费，指导街镇和相关委办局编制应急避难场所建设和维护管理经费的预算。

区教育局：负责推进在学校建设应急避难场所;负责编制本系统应急避难场所建设计划;负责推进、落实学校内应急避难场所建设、管理和维护的经费预算;负责指导、监督各学校落实在学校内建设的应急避难场所建设、管理、维护的主体责任。

区绿化市容局：负责利用公园绿地建设应急避难场所;负责编制本系统应急避难场所建设计划;负责推进、落实公园、绿地内应急避难场所的建设、管理、维护的经费预算;负责指导、监督权属单位落实公园、绿地内应急避难场所建设、管理、维护的主体责任。

区体育局：负责利用体育场馆建设应急避难场所;负责编制本系统应急避难场所建设计划;负责推进、落实体育场馆内应急避难场所的建设、管理、维护的经费预算;负责指导、监督权属单位落实体育场馆内应急避难场所建设、管理、维护的主体责任。

区经委（商务委）：负责指导、监督权属单位落实大型商超场所内应急避难场所建设、管理、维护的主体责任。

区文化旅游局：负责指导、监督权属单位落实大型展馆、文化场馆内应急避难场所建设、管理、维护的主体责任。

区房管局：负责指导物业部门协助街镇落实社区应急避难场所维护管理工作。

各镇政府、街道（开发区）办事处、头桥集团：按照区规划要求，制定本区域应急避难场所建设规划，拟制五年计划和分年度目标任务，统筹推进区域内应急避难场所建设;负责推进、落实本区域应急避难场所建设、管理、维护的经费预算;负责落实本区域应急避难场所建设、管理、维护的责任主体单位，指导、监督各相关责任主体单位落实主体责任。
