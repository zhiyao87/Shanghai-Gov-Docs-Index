# 上海市消防救援总队关于印发《进一步提升消防技术服务机构监管质效的若干措施》的通知

上海市消防救援总队关于印发《进一步提升消防技术服务机构监管质效的若干措施》的通知

各区消防救援支队，上海化学工业区消防救援支队，总队轨道交通、水上支队：

为进一步加强消防技术服务机构监督管理、推动消防技术服务行业高质量发展，总队结合国家“放管服”改革以及我市优化营商环境等相关部署，研究制定了《进一步提升消防技术服务机构监管质效的若干措施》，现印发给你们，请遵照执行。

此通知。

上海市消防救援总队

2026年4月2日

进一步提升消防技术服务机构监管质效的若干措施

一、缩短注册证书办理时限。将注册消防工程师注册办理时限从20日缩减至8个工作日，优化政务服务平台网办提交材料、采集信息等环节流程，实行“一次不用跑”“全程不见面”深度网办，提高办事满意度。

二、助力提升技术服务质量。依托上海市消防技术服务管理系统对机构及从业人员实施能力画像和评价，推动服务质量优劣辨识，有效改善“劣币驱逐良币”不合理现象。建立建筑消防设施赋码管理机制，打造技术服务领域AI智能体，为机构及其从业人员、服务项目及消防设施提供数智化全生命周期管理和服务，帮助机构提质增效。

三、明晰技术服务主体责任。推动机构签订服务合同时约定权责范围，厘清与委托单位的责任边界，明确技术服务与消防管理责任主体。督促机构与委托单位建立畅通的联系机制和反馈评价机制，推动消防设施故障修复，及时消除火灾风险隐患。火灾事故延伸调查起火单位（场所）所聘消防技术服务机构及其从业人员，倒查与火灾有关的消防技术服务主体责任。

四、提高监督执法精准性。实施分级分类监管和靶向检查。建立消防技术服务机构质量管理体系和服务项目评价机制，健全分级分类监管模式，实施差异化监督检查。运用数字化手段开展数据分析，智能筛选异常执业机构、服务项目，实施线索靶向式监督检查，精准打击冲击消防安全底线违法行为。

五、加强监管质态研判。每年定期召开专题会议，分析研判消防技术服务质态和监督管理情况；定期组织消防技术服务机构实地调研或集中座谈，了解掌握机构质量管理水平和服务质量情况，为行业监管与培育措施制定提供决策依据。

六、强化跨部门跨地区协作。会同住建部门落实定期会商、消防技术服务机构违法执业线索抄告等工作措施。强化与公安机关、检察院配合协作，对提供虚假证明文件等违法犯罪行为实施行刑衔接。探索建立与发改、人社、市场监管等部门合作机制，强化消防技术服务活动协同监管。加强跨地区联合执法，强化监管信息共享，探索建立联查协查机制，消除监管盲区。

七、健全健康政商生态。对消防救援部门工作人员指定消防技术服务机构、限制竞争、权钱交易等破坏市场秩序、谋取利益的行为，及其亲属参与或变相参与消防技术服务机构设立及经营活动的行为，依照有关规定严肃处理；构成犯罪的，依法移送司法机关追究刑事责任，营造风清气正的政商生态。

八、发挥社会监督作用。畅通消防技术服务领域问题反映渠道，主动接受社会单位和群众监督。对消防技术服务领域违法违规违纪线索优先办理、限时反馈。开展精准普法宣传，严厉打击消防技术服务机构、中介公司等盗用从业资格证书以及从业人员变造、倒卖、出租、出借资格证书、注册证、执业印章等行为，切实有效维护市场秩序。定期通报曝光违法违规典型案例，形成强力震慑。
