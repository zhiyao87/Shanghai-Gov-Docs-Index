# 黄浦区人民政府办公室印发《关于进一步加强本区城市公共消防安全工作的实施意见》的通知

区政府各委、办、局，各街道办事处：

经区政府同意，现将《关于进一步加强本区城市公共消防安全工作的实施意见》印发给你们，请认真按照执行。

特此通知。

上海市黄浦区人民政府办公室

2024年10月8日

关于进一步加强本区城市公共消防

安全工作的实施意见

为长效防范化解超大城市中心城区消防安全重大风险，全力保障城区消防安全，现就进一步加强本区城市公共消防安全工作提出实施意见如下：

一、健全消防安全责任体系

（一）强化政府统一领导。加强党对消防安全工作的全面领导，落实“党政同责、一岗双责”制度，统筹消防安全工作。建立健全消防安全工作协调机制，定期研究部署消防安全重大事项。积极组织开展火灾隐患排查整治，深入推进消防安全宣传教育，提高全民消防意识。将消防规划科学纳入城乡整体规划，加大公共消防基础设施建设力度，完善应急预案和处置机制。支持保障消防经费投入，为消防工作提供坚实保障。强化对消防安全工作的督导检查和考核评价，建立长效机制。

（二）强化部门依法监管。各部门应将防范和化解消防安全重大风险作为重点内容，全面融入行业安全政策制定、规划部署、应急预案等各个环节，并纳入日常管理、工作督办、业务检查和考核评比的重要指标。积极推行消防安全标准化管理，不断提升管理水平和效率。深入开展行业消防安全专项治理行动，查漏补缺，消除隐患。加大力度组织开展针对性强、实效性高的消防安全培训和应急演练，切实提高各级人员的消防安全意识和应急处置能力。

（三）强化单位全面负责。健全消防安全管理组织，完善消防管理制度和操作规程，确保责任明确、措施到位。定期开展火灾风险排查，及时发现并消除安全隐患。严格管理维护消防器材设施，确保其完好有效，始终处于可用状态。确保疏散通道、安全出口和消防车通道畅通无阻，严禁占用、堵塞或改变用途。落实消防安全培训制度，不断提高员工消防安全意识和技能。定期组织开展消防宣传培训和应急疏散演练，提高全体员工的火灾应对能力。

（四）强化公民积极参与。各街道办事处应加强基层消防安全组织建设，加快推进街道专职消防队建设，进一步优化完善消防安全工作制度，积极推动消防安全管理机构与消防队站的有机融合，加强信息技术手段在消防安全管理中的应用，提升基层消防安全治理效能。各居民委员会应在街道办事处指导下，持续完善并严格执行消防安全工作制度，明确消防安全管理人员，制定社区防火安全公约，加快社区微型消防站布点，发展和壮大志愿消防队伍，定期组织开展防火安全检查、消防宣传培训活动、应急疏散演练和初期火灾处置演习，提升社区居民消防安全意识和自防自救能力。

二、保障新质生产力安全发展

（五）防范化解重大风险。定期分析排查消防安全风险隐患，加强对消防安全高风险区域或行业领域的调查评估，精准识别防控重大风险和突出问题。加大新型消防技术在超高层建筑、警卫任务、节日安保、大型群众性活动等领域的研究和应用，开展大型展览活动、消防物联网、消防信用管理评价体系等消防标准研制，探索建立消防技术服务机构评级、消防安全信用评分、消防安全保险等机制。建立健全各部门信息共享协作机制，及时通报风险评估结果和防控措施，实现资源优化配置和工作效能最大化，构建全方位、多层次的消防安全风险防控体系，从源头上遏制重大火灾事故的发生，为经济社会持续健康发展创造安全稳定的环境。

（六）积极清除隐患存量。重点聚焦高层建筑、地下空间、大型商业综合体、物流仓库、易燃易爆单位、老旧小区、文物古建筑、标志性建筑、人员密集场所、“三合一”场所、群租房、自建出租房、规模租赁住宿场所等火灾风险高的单位和场所，分地区、分行业、分领域开展消防专项治理。持续加强电气火灾监测防范，强化电气焊动火作业全链条监管。建立健全轨道交通车站与毗邻建筑消防安全信息联通、火灾联防、应急联动的工作机制。深化“畅通生命通道”专项行动，健全疏散通道安全出口、门窗、消防车道综合治理机制。

（七）预防遏制风险增量。针对新技术、新业态发展趋势，建立消防安全调研评估、火灾风险形势研判、消防安全管理规范等全链条规范和管控工作机制，服务保障夜间经济、数字经济、文化经济等经济新增长点。重点支持火灾风险防控和综合应急救援技术研发，推广“智慧消防”示范项目，鼓励企业和社区升级智能消防设施。整合社会单位和智能社区的消防数据，支持街道办事处在面大量广的小型商业网点、“不放心”场所、“三合一”反复回潮场所等重点区域部署物联网传感器和AI分析系统，实现火灾风险实时监测和预警。

三、打造社会消防治理新样板

（八）提质消防安全获得感。以区政府为民办实事项目为载体，每年结合区情和市民群众对消防安全环境的诉求，落实老旧小区和“不放心”区域的消防基础设施新增、改造、维护，补齐消防安全短板、弱项，提升消防安全防护能级。推动电动自行车集中停放充电场所和消防设施建设，从严打击违法“拼、改、装”和“进楼入户”停放充电行为，修订符合实际、简便易操作的居民社区防火要求。

（九）提高消防安全参与率。将消防安全培训纳入基层治理骨干必修课程，定期组织各级领导、部门负责人及网格员参与实操培训。推广“中学生消防救援站实训”“消防安全开学第一课”“消防进军训”，探索纳入学分体系。持续推进消防安全“老伙伴”计划。加强季节性风险提示和典型案例警示，完善火灾隐患举报核查和奖励机制。定期组织社区消防安全日活动，发动消防志愿者参与宣传、隐患排查和应急演练。支持社会力量参与消防管理，形成专业机构、志愿者和公众共同参与的多元化消防安全治理模式。

（十）提升执法服务满意度。深化消防执法改革，引入优化营商环境智库，指导消防部门提升政务服务效能。在公众聚集场所投入使用、营业前消防安全检查事项办理中，推行“告知承诺”“全程网办”等举措，推进消防行政许可事项纳入“高效办成一件事”“一业一证”集成办理，健全完善消防行政许可全流程管理制度。规范消防执法行为，进一步深化“双随机、一公开”消防监管改革，分行业推进火灾风险等级评定，配套实施差异化监管措施，全力营造良好的消防安全监管环境。完善跨部门联合检查机制，建立健全“综合查一次”消防安全检查制度。以行业消防安全管理标准化为基础，制定清晰明确、统一规范的社会单位消防工作合规指引，促进消防执法检查和社会单位自我检查双向互认。

四、升级综合应急救援能力

（十一）加强专业能力建设。锚定消防救援队伍综合应急救援“国家队、主力军”职责定位，牢固树立“全灾种”“大应急”理念，进一步加强地震、水域、绳索等抢险救援专业队伍建设，配强高精尖装备，利用基地化、实战化训练培养一批专业人才和师资力量，提升攻坚克难能力。进一步加强高层建筑、大型综合体、地下空间等灭火攻坚力量建设，革新器材装备，创新战术战法，强化实战化训练和演练，提升灭火打赢能力。拓展实战化训练设施场地，为专业队伍开展训练提供有利条件。

（十二）加强消防基础建设。推动《关于进一步加强本市消防基础设施建设的实施意见》在黄浦区属地化落地，科学编制“十五五”规划，推动消防站建设布局更为科学合理、因地制宜，构建城区5分钟灭火救援响应圈，统筹区内小型消防站和消防前置执勤点布点建设，重点加强人民广场、外滩风景区、衡复风貌保护区等重点区域小型消防站和前置执勤点选址建设，形成“建制消防站+小型消防站+前置执勤点”的消防站点模式。推动消防综合训练基地规划选址，建设集应急管理培训、应急救援队伍实战训练及战勤保障等多功能为一体的综合训练基地，提升中心城区消防救援实战能力和专业化水平。

（十三）加强街道站点网格建设。结合街道、街区、社区功能定位布局，编制街道专职消防队与社区微型消防站建设任务目标，确保每个街道至少建成1个专职消防队，逐步形成“1+N”（1个街道专职消防队+N个社区微型消防站）防控网格。建立健全区政府与消防部门对街道专职消防队的统管、统训、统调机制，建立完善与街道专职消防队建设进度、消防执勤力量需求相匹配的专职消防员员额机制。推动基层消防安全管理办公室与政府专职消防队站“室站合一”“防消合一”，赋予基层消防力量全面履行灭火响应、防火巡查、宣传培训职责，构建覆盖各街道的多样化、复合型基层消防工作体系。

（十四）加强多元应急体系建设。建立健全各部门、各单位以及登记备案的社会应急救援力量共同参与的应急联动响应体系，定期组织公安民警、绿化环卫、保安等街面力量开展消防安全技能培训。针对重点、敏感区域消防安全现实需求，分级分类制定应急响应预案，定期开展实战演练，提升消防应急响应和联动处置效能。鼓励引导企业员工、社区居民、楼宇白领、外卖小哥等群体组建消防志愿者队伍，进一步丰富区域消防安全立体化防控内涵。

五、加强消防救援队伍职业保障

（十五）加强消防救援队伍职业保障。完善消防救援人员生活待遇、职业荣誉、社会优待、经费保障等职业保障体系。按照国家和本市有关规定，落实职业荣誉保障机制，安排重大节日区领导走访慰问消防救援人员，将消防救援队伍（集体、个人含政府专职消防员）的表彰奖励纳入区委、区政府以及群团组织表彰奖励范围，畅通消防救援队伍干部转岗交流渠道。按照国家和本市有关规定，落实消防救援人员在看病就医、住房、子女入学、伤亡抚恤、退出安置等方面的待遇保障。
