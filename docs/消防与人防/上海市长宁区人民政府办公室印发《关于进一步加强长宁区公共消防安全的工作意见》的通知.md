# 上海市长宁区人民政府办公室印发《关于进一步加强长宁区公共消防安全的工作意见》的通知

近期，市政府办公厅出台《上海市人民政府办公厅关于进一步加强本市城市公共消防安全工作的意见》(沪府办规〔2019〕5号)，为贯彻落实《意见》精神，进一步加强长宁区城市公共消防安全，现制定以下工作意见：

一、完善消防安全责任体系，形成齐抓共管工作格局

认真贯彻落实国务院《消防安全责任制实施办法》，进一步加强党委、政府对消防救援工作的组织领导，暂时保留区消防安全委员会工作业务协调职责，将防范化解消防安全重大风险纳入重要议事日程，定期听取工作汇报，分析研判形势，及时研究部署、协调解决城市消防安全的重点工作和重大问题。行业部门要落实监管责任，开展消防安全风险评估，细化落实防范化解对策。街镇要落实属地责任，明确街镇负责消防安全管理的部门、人员和消防工作职责，建立健全编制、任务、标准、奖惩、保障等工作运行和递进执法机制。社会单位要落实主体责任，建立消防安全组织机构，规范日常消防管理制度和消防安全操作规程，配齐消防器材设施，提高从业人员能力素质。

二、完善消防安全治理体系，净化消防安全工作环境

相关部门和各街镇要以重大风险防范化解和城市更新为契机，推动火灾隐患整治工作。强化消防安全高风险区域或行业领域调研，找准重大风险和突出问题，制定落实针对性防控措施。积极开展“回头看”专项行动，强化主要节点及敏感时期单位负责人的值班值守制度，并结合重点单位“零火灾”创建，积极推进安全管理制度的有效落实。采取综合治理的方式，对“居改非”高层建筑进行有效治理，对排摸出的老旧高层住宅建筑，逐年列入市区两级政府消防实事项目，积极推进落实整改。对于具有隐患问题的养老机构进行改造调整，加装消防设施、增设电气火灾监控系统等。积极推进部分区域业态调整，特别是对低端商贸市场加强消防设施改造，提升消防安全等级。继续推进“三合一”场所排查整治力度，运用多警联勤平台，实现“三合一”场所的实时动态治理。结合“精品小区”建设，对老旧小区消防安全设施进行综合改造，对老旧小区推进智能车棚和智能充电桩建设，将智慧车棚建设纳入三年电气火灾治理范畴。因地制宜开展安装简易喷淋、独立式火灾探测报警器等设施设备。加强消防培训和宣传，将消防安全常识作为职业培训必训内容，对重点岗位人员加强日常轮训，通过各类媒体广泛推送消防安全注意事项和火灾自救、逃生常识。

三、完善消防安全监管体系，提升企业自主管理能力

督促企业消防安全责任人、管理人切实履行责任，自觉做好本单位消防安全风险防范化解和日常自主管理工作。社区和重点单位要按照规定建立微型消防站，并与消防部门建立联勤联动联训工作机制。加大消防“放管服”力度，推行“双随机、一公开”消防监管模式，组织开展消防窗口服务“创群众满意”达标创建活动，公安派出所要将消防管理嵌入“一居一警”职能范畴。积极推进“智慧消防”建设，搭建智慧消防监控平台，利用物联网等新技术，逐步对全区建筑消防设施联网，实行实时监控，提升建筑消防设施完好率，全面提高全区火灾风险预警与防范响应处置能力。推行公众聚集场所消防安全承诺制度，落实消防安全不良行为公布、火灾事故调查问责等制度，将消防安全重大违法行为纳入城市公共信用信息管理平台，列入个人征信系统，加大守信激励、失信惩戒力度。

四、完善消防应急救援体系，筑牢消防安全应急防线

牢固树立“全灾种”“大应急”理念，加快建设城市综合应急救援体系。组建跨部门、跨行业的应急救援专家咨询组，建立灾前风险防范的专业技术支持和灾害处置中的指挥决策咨询机制，根据灾情对象、类别、等级，分级分类制定应急响应预案，定期开展多部门联动实战演练。推行社会应急装备物资、大型工程器械联储联动机制，建立快速通勤机制。加强多种形式消防队伍和微型消防站实战化培训指导，完善日常调度机制，提升火灾第一时间应急处置专业能力。细化明确相关部门消防应急救援职责，高效运用各类综合应急救援力量，进一步将基层应急力量和社会救援组织纳入统一应急响应体系。

五、完善消防综合保障体系，夯实公共消防安全基础

一方面，加大财政投入，提升消防队伍“硬实力”。落实消防救援人员生活待遇保障，确保人员招得进、留得住、能力强。完善落实与消防站建设进度、消防执勤力量需求相匹配的政府专职消防员员额机制。加大公共消防基础设施建设、装备更新升级、业务开支和专项经费投入力度，加快推进中新泾、古北等消防站点建设。将消防员住房纳入区公务员或人才住房保障体系，优先保障消防救援人员住房。按照中央与地方财政事权和支出责任划分意见，结合本区实际和消防救援队伍职业特点，调整完善保障配套机制。另一方面，健全荣誉和保障体系，提升消防队伍“软实力”。贯彻落实中办、国办《组建国家综合性消防救援队伍框架方案》要求，重大节日期间，地方党委政府安排走访慰问。重大庆典活动邀请消防英模代表参加。消防救援队伍纳入地方党委政府、群团组织表彰奖励、人才培养体系。为取得产证的消防站办理集体户口。保障消防救援人员及其家属落户要求。消防救援人员家属随调、就业等参照改制前随军随调政策执行，未就业的家属继续享受未就业补助发放政策。消防救援人员在子女入托入学、看病就医等继续保持原有优待政策，享受与现役军人同等待遇。根据《消防员职业健康标准》，建立适应消防员职业特点的职业健康保障体系。
