# 上海市应急管理局关于明确上海市防汛应急风险管理保障项目预算支出标准的通知

局机关各处室：

根据《上海市加强成本预算绩效管理的实施方案》（沪府办发〔2023〕16号）《上海市财政局关于做好2024年市级成本预算绩效分析工作的通知》（沪财绩〔2024〕5号）等文件精神，上海市应急管理局对“上海市防汛应急风险管理保障”项目开展了成本预算绩效分析。经研究，确定“上海市防汛应急风险管理保障”项目对黄浦江和苏州河的公用段、专用段防汛墙按长度进行投保的保费预算支出标准为25元/米。

为进一步加强成本预算绩效分析结果的应用，现将上海市防汛应急风险管理保障项目预算支出标准予以印发，请遵照执行。

特此通知。

上海市应急管理局

2025年4月29日
