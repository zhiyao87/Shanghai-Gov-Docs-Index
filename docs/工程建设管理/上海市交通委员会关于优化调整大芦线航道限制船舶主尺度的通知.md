# 上海市交通委员会关于优化调整大芦线航道限制船舶主尺度的通知

上海市交通委员会关于优化调整大芦线航道限制船舶主尺度的通知

沪交海〔2025〕190号

各有关单位、航行船舶:

大芦线航道经维护疏浚后，航行条件得到明显改善，我委结合航道通航需求和实际情况，开展了主尺度调整相关可行性研究。经现场勘察和研究论证，对大芦线一期、二期的限制船舶主尺度(船长×船宽×最大吃水×水线以上允许高度)作以下调整：

由 80m×12.6m×3.0m×7.0m 调整为 80m×12.6m×3.2m×7.0m。

调整自本通知发布之日起实施，请相关单位结合调整后的船舶主尺度，进一步加强大芦线航道现场管理，船长接近航道宽度的船舶禁止在航道内掉头，以确保通航安全。

特此通知。

上海市交通委员会

2025年3月26日
