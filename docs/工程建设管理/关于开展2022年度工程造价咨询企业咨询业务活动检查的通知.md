# 关于开展2022年度工程造价咨询企业咨询业务活动检查的通知

沪建标定〔2022〕429号
上海市住房和城乡建设管理委员会
关于开展2022年度工程造价咨询企业咨询业务活动检查的通知

各有关单位：
为促进本市工程造价咨询行业健康发展，进一步规范本市工程造价咨询企业服务行为，打造公平、公正的工程造价咨询营商环境，根据《工程造价咨询企业管理办法》（住房和城乡建设部令第50号修正）等相关规章要求，现决定开展2022年度工程造价咨询企业咨询业务活动检查。
本次检查将采用线上线下相结合的方式，分为企业自查、线上检查、线下抽查和总结整改四个阶段进行，检查对象为在沪的造价咨询企业。
请各造价咨询企业认真做好自查及网上资料报送等迎检工作。检查的具体方式内容、实施步骤、报送要求及评分标准等由市建筑建材业市场管理总站另行发文。
特此通知。
2022年8月29日
