# 关于转发《交通运输部 国家发展改革委关于减并港口收费等有关事项的通知》的通知

各有关单位：

为深入贯彻落实党中央、国务院决策部署，促进口岸营商环境优化，交通运输部近日下发了《关于减并港口收费等有关事项的通知》（交水发〔2022〕26号），明确减并港口收费项目、定向降低沿海港口引航费、完善拖轮费收费等政策。现将文件转发给你们，请严格按照执行。

市交通委

市发展改革委

二○二二年三月二十四日
