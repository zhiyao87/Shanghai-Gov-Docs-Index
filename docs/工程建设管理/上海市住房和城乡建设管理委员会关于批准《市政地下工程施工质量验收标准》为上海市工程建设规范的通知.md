# 上海市住房和城乡建设管理委员会关于批准《市政地下工程施工质量验收标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《市政地下工程施工质量验收标准》为上海市工程建设规范的通知

沪建标定〔2025〕519号

各有关单位：

由上海隧道工程有限公司、上海市隧道工程轨道交通设计研究院、上海城建市政工程（集团）有限公司主编的《市政地下工程施工质量验收标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-236-2025，自2026年4月1日起实施。原《市政地下工程施工质量验收规范》DG/TJ08-236-2013同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海隧道工程有限公司负责解释。

特此通知。

2025年10月11日
