# 上海市交通委员会关于印发《上海市交通领域精细化管理三年行动计划(2024-2026年)》的通知

各相关部门：

根据党中央、市委和市政府关于加强城市管理精细化的重要指示，按照《中共上海市委、上海市人民政府关于加强本市城市管理精细化工作的实施意见》《上海市城市管理精细化三年行动计划（2024-2026年）》《关于全面践行人民城市理念努力开创人民城市建设新局面的实施方案》等工作要求，现结合本市交通发展实际，制定《上海市交通领域管理精细化工作方案（2024-2026年）》。经2024年第31次党组会审议通过，予以印发，请认真抓好贯彻落实。

特此通知。

上海市交通委员会

2024年12月31日

上海市交通领域精细化管理工作方案（2024-2026年）

根据党中央、市委和市政府关于加强城市管理精细化的重要指示，按照《中共上海市委、上海市人民政府关于加强本市城市管理精细化工作的实施意见》《上海市城市管理精细化三年行动计划(2024-2026年)》《关于全面践行人民城市理念努力开创人民城市建设新局面的实施方案》等工作要求，紧紧围绕“人民交通为人民”的服务宗旨，结合本市交通发展实际，以推进一批可观可感的“民心工程”为抓手，制定上海市交通领域管理精细化工作方案（2024-2026年）。

一、提升交通设施环境品质

（一）改善城市道路环境。结合城市更新等行动，以城市道路为载体，努力在细节上、细微处下功夫，提高道路通行舒适性和安全性。整合多方资源，努力念好“精字诀”、磨好“绣花功”、打好“特色牌”、强化“创新观”、总结“好经验”，打通道路红线与建筑前区界限，推动全路域环境融合发展，道路设施精细化管理水平不断提升，有效落实人民城市、精细化、智慧化、绿色低碳等理念，实现共享共管共治，完成300条精品路建设，不断提升我市城市道路的管养水平。

（二）改善农村道路环境。结合农村公路规划建设和美丽乡村建设，推进“四好农村路”高质量发展。通过对农村道路路基、路面、桥梁、附属设施等进行改造提升，进一步提高路况技术指标，改善路容路貌和路域环境，实现农村公路“提质”“提速”“提标”，全面提升道路路况质量与服务水平，完成农村公路提档升级改造600公里。

（三）提升慢行交通空间品质。加强需求导向，重点针对大居、办公、医院、学校等人流密集区域，推进“完善慢行网络、强化空间融合、提升设施品质”重点任务，完成慢行交通专项提升项目300项。聚焦中心城区、五个新城、浦东引领区，结合“15分钟生活圈”打造、“美丽街区”建设、片区新开发等，建设功能匹配、各具特色的慢行交通精品区域50个，打造高品质的慢行交通体验提升窗口。根据人行道所在区域特点、功能定位、基础条件等，开展人行道品质提升工作，人行道整治面积不低于300万平方米，整治解决一批“行路不畅”突出问题。

（四）推进停车难综合治理。重点服务住宅小区、医院的停车需求，创建60个停车资源优化项目，开工建设9000个公共停车位，新增3000个错峰共享停车位，建成40个示范性智慧公共停车场（库），基本实现智慧道路停车场建设的全覆盖，在具备条件的智慧道路停车场推进面向居民夜间停车的按月结算优惠服务。

（五）推进城市快速路更新整治。推进内环高架“年轻化”工程，完成内环高架“年轻化”三期工程，并持续推进四期工程。施工内容主要包括桥梁结构、附属设施功能完善提升、智慧化升级改造和环境景观优化等，为提升城市管理能级、智慧城市打下坚实基础，改造后高架道路设施和服务功能将进一步提升，更有效满足市民便捷舒适的出行需求。

（六）优化国省干道线设施品质。提升国省干线道路平整度、舒适度，结合养护工程、改扩建等对老旧设施开展集中整治，完成机动车道井盖井框处置1918个，完成桥头跳车整治133处。美化路域环境，更新改造桥梁栏杆等附属设施，完成桥梁栏杆涂装改色334座，完成防撞栏修复240千米。对整治计划外的道路设施，提高养护频率，优化绿化设置，保洁频率提升至15天完成1次全线机械清理、冲洗，30天完成1次人工清洗，完成绿化种植搭配改造1648处。

二、提升交通出行服务体验

（七）提升轨道交通服务水平。推进轨道交通站点内部改造、无障碍环境等设施建设，为各类群体提供安全、便捷、温馨的乘车环境和服务。既有运营车站出入口增加电扶梯，三年累计新增19台，进一步提升老年人及特殊出行群体出行品质。既有车站厕所改造新增第三卫生间，三年累计改造新增71座，满足适老、母婴、无障碍等不同群体如厕需求，提高市民乘客对城市的归属感。

（八）提升地面公交服务水平。持续推进两网融合，强化轨道交通站点周边50米内配套公交基础设施建设，2026年底实现轨道交通站点50米范围内地面公交配套服务占比达到90%。强化车辆投放、线路服务与实际需求的精准匹配，每年投运中小车型公交车200辆，使地面公交能提供“更方便换乘、更精准、更精细”的服务。为积极打造老年友好型出行环境，结合港湾式车站改造、公交站点品质提升、人行道品质提升等项目，对300个公交站台进行适老化改造。主要改造内容包括增设无障碍坡道或抬升非机动车道路面标高方式消除高差、在乘客穿行非机动车区域增加警示标识提高安全性、针对老年乘客的使用需求完善候车环境和站台设施等。更新投运无障碍低地板公交车1200辆，以保障轮椅乘客等特殊人群的乘坐体验。

（九）提升轮渡服务水平。持续改善水路客运交通出行服务，积极创建轮渡服务品牌，增强轮渡航班信息查询、公示渠道，推动轮渡软硬件服务设施升级，提高乘客满意度，提升水路客运服务品质，扩大市内客运管理服务覆盖面。

（十）提升市域铁路服务质量。结合铁路莘庄站、松江站启用、上海南站提档升级等工作的推进，通过增开金山铁路开行列车数量的方式，逐步释放金山铁路运能，至2026年金山铁路全天开行列车38对。

（十一）提升航空客运服务水平。营造舒适贴心的乘机服务环境，提升航站楼整体形象和旅客的出行体验。持续优化虹桥机场航站楼旅客服务设施，涵盖值机柜台、卫生间、座椅等主要设施焕新和增配。推进浦东机场航站楼T1、T2及三纵三横卫生间改造，优化浦东机场公交站点和出租车站点环境。

（十二）提升国省干线出行通达度。聚焦沿线人行通道断点堵点，推进人行道断头贯通工作，三年累计完成人行道断头贯通25400㎡。针对部分缓行路段，实施道路设施局部改造，提升通行速度，三年累计完成缓拥堵提升21个点位。

三、提高交通综合管理效能

（十三）强化场景实战应用。加强互联感知、数据分析和智能决策等技术在交通行业日常管理和决策支持等方面的应用，结合市城运中心相关工作安排，以及行业工作需求，不断迭代升级交通行业应用场景，逐步优化应用功能，接入交通枢纽网约车实时供需场景，扩大成熟场景的应用频率和覆盖面。

（十四）提升交通出行服务便捷智能化水平。持续提升客运MaaS系统服务能级，围绕赋能城市治理、企业运行与市民出行，打造更多MaaS系统标志性应用场景、实用服务功能与全新解决方案。深化多元化票制、定制公交等定制出行服务探索，加快“出行+生活”服务场景拓展，为市民提供跨场景、个性化的MaaS服务，进一步提升交通领域公共数据授权运营效能，强化对城市治理、企业运行、市民出行的反哺赋能。

（十五）完善法律法规和管理规定。立足超大城市综合管理要求，根据人大立法进度，加强重点领域地方性法规和政府规章的立改废释，及时修订不符合精细化管理要求的法规规章，增强法规规章的时效性、针对性，完善综合交通管理精细化的相关制度和相关政策，健全相关法规规章和政策定期评估机制，发挥立法的引领、推动和保障作用。

（十六）健全管理制度体系。建立健全与超大城市特点相适应的综合交通管理标准体系，对交通管理工作具体范围、职责、流程、标准和法律责任等作出全面详细的规定，为精细化管理提供标尺和依据。按照可感知、可量化、易操作、易考核等原则，聚焦短板顽症，制修订差别化的交通管理标准。完善掘路修复管理制度，全面落实修复后竣工验收要求，道路技术状况指标优良率达到80%以上，在建建设工地周边道路路况全面达到合格以上水平。

四、建设绿色安全交通运输体系

（十七）推动城市货运物流业绿色发展。通过新增或更新货运城配车辆100%新能源化、推动本市冷链车辆新能源化、试点集装箱新能源车示范运营等途径，推动本市货物运输结构进一步优化、运输组织效率进一步提高、运输方式绿色化智慧化水平进一步提升。

（十八）提升上海港船舶污染防治水平。优化黄浦江和内河通航水域船舶污染物免费接收体系，持续提升上海港船舶污染物接收能力。开展船舶污染接收能力评估，优化船舶污染物免费接收方案。优化免费接收流动线路，增设公共固定接收点，增加流动转运船舶。推进船舶生活垃圾上岸接收处置。试点推进船舶生活污水直接上岸接入城市污水管网。

（十九）推动交通行业重点领域数字管安。建立本市交通行业重点领域重大事故隐患判定标准知识库，指导行业企业、管理和执法部门更有针对性地掌握判定标准的主要内容，进一步提高排查问题隐患的能力。强化重点领域安全监管，推动行业数字管安，深入推动实施针对重大风险隐患的一批“人防、技防、工程防、管理防”措施。

（二十）加强危险货物运输领域的安全管理。实现市区两级交通管理部门对所属危险货物道路运输企业检查全覆盖，严格落实企业运营安全管理主体责任，强化政府行业监管保障作用，健全安全管理责任体系。

（二十一）加强交通建设工程质量安全管理。严格落实参建单位主体责任和行业部门监管责任，实现由监管企业行为向监管企业自控体系转变。加强现场作业人员用工管理，深入开展工程质量安全检查，提高工地安全和文明施工管理水平。

（二十二）提升高速公路防灾抗灾能力。根据交通部的要求，开展高速公路防灾抗灾能力设计回溯排查工作，并梳理整治清单，制定整改工作方案，排列工作计划，按计划实施整改工作，提升设施安全和品质。

（二十三）开展普通国省干线安全整治。结合积水点改造、空洞修复等措施，对危及运行安全设施开展集中整治。三年累计完成1990个积水点改造及28个空洞点位修复工作。

五、保障措施

成立交通领域精细化管理工作专班，进一步加强管理精细化工作的统筹协调，对各区及行业单位加强指导，确保各项任务扎实有序推进，加强过程跟踪管理，注重民生需求反馈收集，确保任务目标始终与群众需求保持一致。
