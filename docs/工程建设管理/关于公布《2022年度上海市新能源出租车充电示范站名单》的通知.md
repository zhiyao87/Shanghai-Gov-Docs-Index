# 关于公布《2022年度上海市新能源出租车充电示范站名单》的通知

关于公布《2022年度上海市新能源出租车
充电示范站名单》的通知

各相关单位：
根据《上海市鼓励电动汽车充换电设施发展扶持办法》（沪发改规范〔2022〕12号）要求，市交通委会同市发展改革委、市财政局组织推进全市新能源出租车充电示范站建设。结合《关于发布2022年度上海市新能源出租车充电示范站入围名单的通知》（沪交科〔2022〕487号）以及各区交通、发展改革部门验收核查和实际通电情况，经审核，最终确认2022年度上海市新能源出租车充电示范站名单，现予公布。
本市对新能源出租车充电示范站采用动态管理、适时调整机制。请各示范站运营企业加强运营管理、规范服务流程，模范执行本市有关管理要求和行业政策，树立行业服务标杆，优先保障新能源出租车充电需求，积极发挥示范作用。
特此通知。
