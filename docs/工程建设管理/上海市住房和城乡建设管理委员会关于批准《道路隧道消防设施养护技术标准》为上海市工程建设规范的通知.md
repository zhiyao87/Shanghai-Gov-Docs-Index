# 上海市住房和城乡建设管理委员会关于批准《道路隧道消防设施养护技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《道路隧道消防设施养护技术标准》为上海市工程建设规范的通知

沪建标定〔2021〕585号

各有关单位：

由上海市道路运输事业发展中心和同济大学主编的《道路隧道消防设施养护技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为 DG/TJ08-2378-2021，自 2022年2月1日起实施。

2021年9月15日
