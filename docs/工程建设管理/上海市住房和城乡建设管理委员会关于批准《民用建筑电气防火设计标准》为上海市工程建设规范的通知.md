# 上海市住房和城乡建设管理委员会关于批准《民用建筑电气防火设计标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《民用建筑电气防火设计标准》为上海市工程建设规范的通知

沪建标定〔2024〕128号

各有关单位：

由华东建筑设计研究院有限公司、上海市消防救援总队主编的《民用建筑电气防火设计标准》，经我委审核，现批准为上海市工程建设规范,统一编号为DG/TJ08-2048-2024，自2024年9月1日起实施。原《民用建筑电气防火设计规程》(DGJ08-2048-2016)同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，华东建筑设计研究院有限公司负责解释。

特此通知。

2024年3月12日
