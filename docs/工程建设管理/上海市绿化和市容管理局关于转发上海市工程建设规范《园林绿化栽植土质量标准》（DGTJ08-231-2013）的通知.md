# 上海市绿化和市容管理局关于转发上海市工程建设规范《园林绿化栽植土质量标准》（DG/TJ08-231-2013）的通知



各区县绿化和市容管理局、各有关单位：
根据《上海市城乡建设和交通委员会关于批准<园林绿化栽植土质量标准>为上海市工程建设规范的通知》（沪建交〔2013〕1261号），由上海市园林科学研究所主编的上海市工程和规范《园林绿化栽植土质量标准》（DG/TJ 08-231-2013）自2014年2月1日起实施，原《园林绿化栽植土质量标准》（DBJ 08-231-98）同时废止。现转发给你们，请结合实际工作需要，组织各相关企事业单位认真贯彻执行。
本标准由上海市园林科学研究所负责解释。在贯彻执行中如有异议和建议，请与上海市园林科学研究所联系。（地址：龙吴路899号邮编：200232 电话：54351199）
