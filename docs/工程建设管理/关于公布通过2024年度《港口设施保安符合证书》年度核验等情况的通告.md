# 关于公布通过2024年度《港口设施保安符合证书》年度核验等情况的通告

关于公布通过2024年度

《港口设施保安符合证书》

年度核验等情况的通告

根据交通运输部《中华人民共和国港口设施保安规则》及《关于发布<港口设施保安符合证书年度核验办法>的通知》要求，现就有关情况通告如下：

一、经我委核查，上海中远海运重工有限公司码头1#-13#泊位（长兴岛新开港）等36个港口设施通过2024年度《港口设施保安符合证书》年度核验。

二、上海港外高桥港区高桥凌桥镇东高家浜凌海路918号码头等24个港口设施于2024年取得《港口设施保安符合证书》。

三、上海电力股份有限公司吴泾热电厂煤码头2号泊位（龙吴路5060号）等2个港口设施的《港口设施保安符合证书》有效期到期后未重新申请，自然失效。
