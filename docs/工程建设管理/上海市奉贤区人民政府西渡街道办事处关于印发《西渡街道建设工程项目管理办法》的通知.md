# 上海市奉贤区人民政府西渡街道办事处关于印发《西渡街道建设工程项目管理办法》的通知

机关各办，各事业单位，各村、居：

经街道办事处研究决定，现将《西渡街道建设工程项目管理办法》印发给你们，请认真贯彻执行。

上海市奉贤区人民政府西渡街道办事处

2024年7月30日

西渡街道建设工程项目管理办法

为进一步规范西渡街道建设工程项目管理工作，确保建设工程项目公开、公正、公平和规范有序建设，根据《中华人民共和国建筑法》、《中华人民共和国招标投标法》、《中华人民共和国政府采购法》及市、区级相关文件要求，结合街道实际，特制定本管理办法。

第一条(组织架构)

西渡街道成立西渡街道建设工程项目管理领导小组，领导小组组长由办事处主任担任，副组长由各分管领导担任。领导小组下设项目管理办公室(以下简称项管办)负责具体工作，办公室设在社区管理办公室，主任由街道分管规划城建副主任兼任，副主任由社区管理办主任兼任，成员由党政办、管理办、营商办、发展办、城建中心等单位主要负责人组成，项管办负责街道建设工程项目的管理工作。

第二条(适用范围)

本办法适用于由西渡街道办事处(含事业单位)作为实施主体的建设工程项目，包括使用区财力投资项目以及街道所属企业、村集体资金投资项目。

西渡街道建设工程项目一般包括以下内容：

(一)工程施工类：市政基础设施类(含道路，桥梁，土石方，桩基，绿化建设及搬迁，市政配套建设工程等);公建配套类(含各类办公用房、活动室，文化体育、卫生养老设施等公共设施的新建、扩建、改建工程及装修装饰工程等);机电工程类(强弱电施工及管线搬迁，技防设施等);环境卫生类(含店招店牌改造，市容环境整治，环卫设施工程等);农业设施类(含农桥，宅村路，机耕路，土地复垦，排灌设施，驳岸堤防，河道疏浚工程等)。

(二)工程服务类：勘察、设计、施工监理、招标代理等。

第三条(项目论证)

建设工程项目年度计划由项管办统一管理，按“谁申报、谁负责”的原则落实责任，严禁拆分申报、未批先建。街道各职能部门和下属事业单位、村居，结合本单位的实际情况和行业管理要求，在每年第三季度申报下一年度的建设工程项目投资计划及资金预算，由项管办进行汇总后报区发改委审批。使用农村自筹资金项目，根据《关于建立奉贤区农村集体经济组织重大事项预审备案制度的通知》(沪奉农经〔2020〕1号)等有关规定执行。

除应急维修、上级部署和应对突发事件需要之外，每年实施的工程项目应列入当年预算。

第四条(项目准备)

(一)项目启动

项目提出部门在项管办指导下负责各项目的具体实施，每年预算正式下达后，应根据工作安排和预算执行进度尽早安排项目实施计划，组织办理项目立项、规划建设等相关审批手续。

(二)信息公开

单项合同估算价100万元(含)以上的建设工程项目须在“上海政府采购网”上发布政府采购意向信息，其中单项合同估算价100万元(含)以上的建设工程服务类项目须同步在“上海市建设工程交易服务中心”平台上发布招标计划公告。单项合同估算价在400万元(含)以上的建设工程项目须同时在“上海政府采购网”和“上海市建设工程交易服务中心”平台上发布招标计划公告。由项目提出部门负责人提供采购需求，内容包括预算单位名称、项目名称、需求概况、预算金额、预计招标时间等，按照规定流程予以公开(涉密信息除外)，采购信息公开时间应当尽量提前，原则上不得晚于采购活动开始前30日。属于应急抢险救灾的原因急需开展的招投标项目，按相关规定执行。

(三)招标(采购)方式

项目提出部门在项管办指导审核下负责建设工程项目的采购工作。具体招标(采购)方式按下述标准执行：

1.工程施工类招标

(1)单项合同估算价30万元以下的项目，由项目提出部门邀请不少于3家具有相应资质的企业通过比选(价)方式择优选择施工单位。

(2)单项合同估算价30万元(含)以上不足100万元的项目，采用竞争性磋商、邀请招标等公平竞争方式实施。被邀请的投标人不少于三家，具体提名遴选由各项目提出部门负责。

(3)单项合同估算价100万元(含)以上不足400万元的项目：财政性资金投资项目，通过“上海政府采购网”上实施政府采购;其他资金项目，按相关规定采取公开招标方式。

(4)单项合同估算价400万元(含)以上的项目，在市、区两级建设工程招投标交易场所内实施公开招标。

2.工程服务类招标

(1)单项合同估算价30万元以下的项目，由项目提出部门邀请不少于3家具有相应资质的企业通过比选(价)方式择优选择。

(2)单项合同估算价30万元(含)以上不足100万元的项目，采用竞争性磋商、邀请招标等公平竞争方式实施。被邀请的投标人不少于三家，具体提名遴选由各项目提出部门负责。

(3)单项合同估算价100万元(含)以上的项目，应采取公开招标方式确定第三方服务机构。

(四)项目准备手续

项目采购后应及时签订合同。合同报签、用印与签订人的审批程序必须按规定进行。西渡街道司法所承担街道订立的合同的合法性审查等工作。涉及财政、审计、税收等方面的内容，可以委托法律顾问或者专业服务机构协助审查。

第五条(项目管理)

1.建设工程项目按照“谁申报、谁负责”的原则由项目提出部门负责项目协调工作。城建中心是施工期间日常监管部门，对施工过程中存在安全、质量、文明施工问题的，由项目提出部门对施工单位予以处罚，并纳入最终结算。对于监理单位、代建单位未按合同约定履职的，也处以相应处罚。

2.建设工程项目按“非必要不调整不增加”的原则严格控制项目设计及工程量变更。因无法预计或不可控因素等原因确需变更设计及调整工程量的必须按规定申报，由施工、设计、施工监理、投资监理单位、建设单位按相关规定审核签章，经报批同意后准予实施。

第六条(项目验收)

建设工程项目完成后除上级部门组织验收以外，由项目提出部门组织设计、施工、监理等相关单位进行工程竣工验收，验收合格后出具竣工验收报告。

第七条(项目审价、审计)

项目验收合格后，应按规定予以审价、审计，同时编制项目总投资工程决算。其中投资额400万元(含)以下的项目决算由行业主管部门或街道办对工程决算进行审核、出具竣工财务决算批复，并向区财政局备案;投资额在400-3000万元(含)的项目决算由行业主管部门或街道办进行全面复核后，报区财政局作合规性审核;投资额在3000万元(不含)以上的项目决算必须向区财政局申请审核批复。

第八条(资金支付管理)

项目资金拨付应根据工程进度拨付。建设工程项目结(决)算审价(审计)前付款原则上不得超过合同价的80%;审价(审计)工作和资料归档完成后，付款至结(决)算审定价的97%(合同另有约定的除外)，余款待质保期满后付清。

第九条(资料归档管理)

建设工程项目全部竣工验收合格后，由项目提出部门负责归档该项目的资料，做好后评估工作。应归档的资料包括(如有)：建设工程项目开工报告、建设工程项目竣工报告、建设工程项目竣工财务决算审批申报表、集体讨论的会议纪要、设计合同和方案、招标代理合同、招标文件、投标文件、评标记录、中标通知书、施工合同、安全协议、廉洁协议、施工资料(竣工图)、施工单位证件(营业执照、资质证书、安全生产许可证、项目经理资格证书复印件)、监理合同和资料、审价合同和报告等。

第十条(监督管理)

(一)在工程建设过程中，工程参建各方应遵循诚信、守法、自律的原则。有不良行为的，将依照有关规定处理，经领导小组同意后列入黑名单，三年内不得参加街道建设工程招投标。

(二)在建设工程项目管理过程中，若发现拆分申报、未批先建等违规现象，由项管办责令停工，并报街道纪工委(监察办)追究相关人员责任。

(三)在招投标过程中，各级领导干部带头遵章守纪，不得干预招投标的正常进行，为营造公开、公正、公平的市场竞争秩序起到表率作用。若发现有拆标、分标等违法、违规现象，将追究相关人员责任。

(四)未办理任何手续的建设工程项目工程款一律不予支持，如擅自支付将追究相关人员责任。

(五)街道纪工委(监察办)对建设工程项目开展情况以及规定执行情况进行监督，并提出整改意见，问题严重的予以问责。

第十一条(其他说明)

(一)凡项目涉及非街道资金的，相关职能部门和分管领导需积极沟通，确保项目及资金最大限度落到实处。

(二)街道属企业(含控股企业)、村集体资金投资的建设工程项目参照本办法执行。

(三)本办法由西渡街道建设工程项目管理办公室负责解释。本办法按照国家法律法规的政策制定，并根据国家有关法律和政策的变化而作出相应调整。法律或者行政法规、规章等另有规定或有更新的，从其规定。

(四)本办法自2024年7月30日实施。《西渡街道建设工程项目管理办法(试行)》(奉西街办〔2021〕18号)同时废止。
