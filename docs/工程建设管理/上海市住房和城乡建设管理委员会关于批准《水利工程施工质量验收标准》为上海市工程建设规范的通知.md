# 上海市住房和城乡建设管理委员会关于批准《水利工程施工质量验收标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《水利工程施工质量验收标准》为上海市工程建设规范的通知

沪建标定〔2021〕846号

各有关单位：

由上海市水务局和上海市水务建设工程安全质量监督中心站主编的《水利工程施工质量验收标准》，经我委审核现批准为上海市工程建设规范，统一编号为DG/TJ08-90-2021，自2022年5月1日起实施。原《水利工程施工质量检验与评定标准》DG/TJ08-90-2014 和《上海市住房和城乡建设管理委员会关于批准<水利工程施工质量检验与评定标准>局部修订的通知》(沪建标定〔2018〕420 号)同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市水务局负责解释。

特此通知。

2021年12月24日
