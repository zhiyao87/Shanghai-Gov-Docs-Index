# 关于印发《上海市园林绿化建设工程安全生产突发事件应急预案》的通知

各区绿化市容局、临港新片区管委会：

为建立健全本市园林绿化建设工程安全生产突发事件 应急处置体系，妥善处置园林绿化建设工程施工过程中的安全生产突发事件，现将《上海市园林绿化建设工程安全生产突发事件应急预案》印发给你们。请结合工作实际认真按照执行。

特此通知。

上海市绿化和市容管理局

2025年1月7日
