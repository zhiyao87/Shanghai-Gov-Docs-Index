# 关于印发《杨浦区关于创新引领、数字赋能，持续提升工程建设领域营商环境的行动计划》的通知

各有关单位：

《杨浦区关于创新引领、数字赋能，持续提升工程建设领域营商环境的行动计划》已经区政府第94次常务会议通过，现印发给你们，请认真按照执行。

杨浦区建设和管理委员会

杨浦区发展和改革委员会

杨浦区规划和自然资源局

2024年8月21日

杨浦区关于创新引领、数字赋能，持续提升工程建设领域营商环境的行动计划

为持续提升工程建设领域营商环境，进一步激发建筑市场活力和社会创造力，全面对标世界银行营商环境评估新规则和上海市营商环境创新试点新要求，现根据《上海市优化营商环境条例》、《上海市坚持对标改革持续打造国际一流营商环境行动方案》（沪府办发【2024】1号）、《关于坚持对标一流 持续深化上海市工程建设领域营商环境的行动方案》（沪建建管联【2024】249号）和《聚焦“创新四力”，升级“四大服务”杨浦全力打造营商环境》（杨府发【2024】3号）等文件精神，结合杨浦实际，制定本行动计划。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，深入贯彻党的二十大精神，全面落实习近平总书记考察上海重要讲话精神和重要指示要求，坚持对标新一轮世界银行营商环境评估体系指标内容，将世行最新的方法理念贯彻到工程建设领域营商环境改革的各项工作中，持续推动工程建设领域审批服务标准化、规范化、便利化，协同推进行政审批制度改革和事中事后监管，着力打造一流工程建设领域营商环境，开拓“四高城区”建设新局面。

二、主要举措

（一）持续推进工程建设领域审批制度改革

1、优化“施工许可一站式”改革，提升“竣工验收一站式”服务。针对免于施工图设计文件审查，分类细化一站式办理施工许可模式，持续提升服务效率和用户便利性。依托“一个系统”，持续推进交通、水务、绿化工程施工许可与规划用地审批一站式办理。进一步优化综合竣工验收办理流程，规范提前服务办理范围，细化分期验收办理方式。完善各专业验收事项“附条件通过”闭环管理，进一步明确办理要求。探索城市道路项目分段竣工验收备案。（责任部门：区建设管理委、区规划资源局、区绿化市容局、区卫生健康委、区国动办、区交警支队）

2、扩大建筑师负责制试点。在科教文卫先行先试的基础上，将建筑师负责制试点范围扩大到全区政府投资工程建设项目。鼓励社会投资项目采用建筑师负责制。发挥试点项目示范引领作用，探索相应的管理制度、取费标准、审批流程、监管模式等，鼓励推行注册建筑师职业责任保险制度。（责任部门：区建设管理委、区规划资源局）

3、深入推进“水电气网联合报装”一件事。建立市政配套统筹协调机制，推动服务单位在项目策划生成阶段提前主动开展技术指导。完善线上掘占路审批事项与“水电气网联合报装”事项集成对接，实现一口申请、办理流程和结果可实时跟踪，着力解决市政接入服务全周期贯通的难题。（责任部门：区建设管理委、区数据局）

4、推进区域评估和用地清单制。推动各实施主体在城市规划确定后、土地出让前推进区域评估。开展环境影响评价并纳入区域评估，具体项目可分类实施环评形式简化、告知承诺、共享区域环境质量监测数据等优化简化措施。加强区域评估成果公开，通过出让征询获取区域评估和现状调查结果（如周边排水、燃气管网及电力供应情况等），土地供应时一并提供给土地使用权人。持续推进多审合一、多测合一、多证合一等改革举措，进一步用好“测算合一”系统，优化工作流程，加强信息成果共享机制，推动符合“测算合一”条件的项目扎实落地。（责任部门：区规划资源局、区生态环境局、区建设管理委、区文化旅游局）

5、细化完善消防审验改革。实施分级分类管理，推行非消防审验类限额以下小型工程试行消防告知承诺制。总投资100万元以下且建筑面积300平方米以下的其他建设工程为一般项目，试点告知承诺方式备案，区建设管理部门依据承诺书出具备案凭证;重点项目进一步研究细分优化消防备案方式，加强事后监管，探索借助专业机构、专业人员、专业保险等方式，实施承诺制项目事后监管工作。（责任部门：区建设管理委、各街道）

6、持续深化建设工程招投标综合改革。全面落实新一轮建设工程招投标改革实施意见，及时跟踪改革落地情况。建立健全工程建设领域招投标公平竞争审查机制，进一步清除隐形门槛、破除市场壁垒。稳步推进分散评标，实施现场分散评标和远程分散评标。深化招投标电子化平台建设，实现事前信息融合，深化事中智慧监管，强化事后履约管理。支持中小企业发展，在政府采购工程中进一步完善预留份额制度，预留方式包括：招标项目整体预留或设置标段预留、联合体形式预留、合同分包形式预留。（责任部门：区建设管理委）

7、持续推进专业领域改革创新举措。探索“建设用地规划许可证、建设工程规划许可证”两证合一;优化“从供地到登记”全流程审批服务，强化“两个免交”，深化规划资源“竣工即交证、交地即交证、交房即交证”，实现“交地、交证、抵押联办”全程网办。巩固推行“桩基先行”，继续试行将基坑围护措施纳入桩基础工程施工许可范围，加快项目开工建设。深化推进掘占路审批机制改革，推广告知承诺制、挖掘道路一件事等措施;探索赋予公用事业单位信用额度，在额度范围内试行掘占路自动审批或备案管理。推动“建设项目占用绿地”“建设项目临时使用绿地”等行政许可事项缴纳“生态补偿费”与税务部门的跨部门协同，做到“一件事一次办”。（责任部门：区规划资源局、区建设管理委、区绿化市容局、区税务局等）

（二）全方位提升审批服务

1、全力提升政务服务。完善集约高效的线下政务服务体系，健全工程建设领域难点堵点主动发现机制，打造“办不成事”反映窗口服务品牌，畅通堵点问题反馈渠道。建立完善解决办事堵点问题清单管理，严格执行首问负责、一次性告知、限时办结等制度。不断提升热线接办效率，高效受理“一网通办”在线咨询及各类投诉、求助、建议和在线办理指导等诉求，健全“接诉即办”机制。巩固优化高频事项线上办理效能，持续提升在线预填率、预审率和一次申报成功率。（责任部门：各有关部门）

2、完善惠企政策服务。更新完善工程建设项目审批事项办事指南、申请表单、流程图等。打造定制化、套餐化、模块化的涉企服务“一类事”场景，一站式提供政策推荐、咨询、解读、申报等政策服务。建立企业“服务包”机制，推动政策精准直达、服务便利获取，积极回应企业个性化诉求。在首次监督时将关键岗位人员到岗打卡、危大工程、高处作业、起重机械、文明施工等各类最新文件规定进行宣贯告知，并打包发给工地参建各方，方便工地进一步学习并贯彻落实。完善线上“不见面审批”和线下“面对面服务”机制，对本区建设工程企业用于拓展市场、提升竞争力的资质办理和维护申请，提供精准政策指导和高效审批服务。继续完善资质换证管理和服务质量，进一步推进政务服务事项网上办理和数字化转型，为企业和群众提供更加便捷、高效的服务。一季度完成资质改革政策宣贯及实操培训，解决区属企业在换证中和换证后存在的普遍疑虑。（责任部门：各有关部门）

3、全心构建帮办服务。依托区审批审查中心，聚焦专业精神和专业能力，建立一支熟悉营商环境和工程审批制度改革各项政策、审批流程的“营商服务专员队伍”，为经营主体提供精准服务。不断提升一线人员业务能力建设，全力拓展线上线下帮办、代办服务体系，强化帮办服务专业化队伍建设，提升帮办代办响应率、解决率和满意度。针对市、区两级重点区域、重点领域重大项目加强项目全流程帮办代办，结合实际建立专班服务、专员跟进等机制，及时解决项目推进中的难点问题。（责任部门：各有关部门）

（三）全流程强化事中事后监管

1、协同实施综合监管。实施企业资质动态核查、工程招投标管理、现场监督联动，实现动态监管和全过程闭合管理，促进建筑市场的健康发展。进一步健全完善行政执法裁量权基准，深化包容审慎监管，依法拓展不予行政处罚事项，细化减轻行政处罚事项。（责任部门：各有关部门）

2、数字赋能智慧监管。应用物联传感、人工智能等信息化技术，积极推动建筑工地监管智能化转型工作,在原有深基坑管控平台基础上实施功能提升，增加远程监控、人员管理、大机管理及智能识别模块，打造杨浦区建筑工地智慧监管平台，监管平台每月自动汇总生成数据看板，展示工地情况，实现全区土建工地的统一可视化监控、智能化管理和精准化预警，进一步提升工程安全生产监管效能。依托招投标大智慧监管系统，做到施工电子招标项目智慧监管抽查比例100%。推行监管要点格式化、数字化，持续深化智能监管。拓展单个项目围串标甄别分析维度，提升跨项目组团围串标甄别功能。（责任部门：区建设管理委、区绿化市容局、区住房保障房屋管理局等）

3、互联共享信用监管。常态化推进信用评价数据采集工作，加强对信用监管机制和信用评价结果的运用，进一步实施分类监管机制，推进减少检查频次的正向激励机制和限制行业市场准入、增加监管频次等惩戒措施。加强各部门信用信息的互联共享，优化在招标投标和事中事后监管中应用。对重点监管企业全覆盖实施环境信用评价，结合执法正面清单、轻微违法免罚清单和环境信用评价制度，实施分级分类和“差异化”执法。（责任部门：区建设管理委、区规划资源局、区生态环境局、区绿化市容局、区住房保障房屋管理局、区国动办、区交警支队）

4、加强健康风险相关材料监管，推进绿色建材推广应用。进一步推进绿色低碳建材应用。社会投资项目应在预拌混凝土材料、混凝土预制构件、蒸压加气混凝土砌块（板）、预拌砂浆和建筑涂料等方面全面使用绿色低碳建材。政府（国企）投资项目应在社会投资项目的基础上增加防水卷材、防水涂料、建筑玻璃、管道等方面绿色低碳建材的应用。落实建设单位主体责任，制定绿色建材使用计划，在施工图审查、施工招标环节及竣工验收等阶段对项目进行全过程绿色建材管理。加强绿色建材和外墙外保温材料等使用情况监管，提高绿色建材应用比例。（责任部门：区建设管理委）

三、保障措施

1、完善工作推进机制。建立健全部门协同机制，合力加快推进各类建设工程，切实推进政策落地、改革见效。区建管委要发挥日常协调作用，细化任务分工，做好沟通对接。各单位要依照职责分工，配强人员力量，确保各项措施取得成效。（责任部门：各有关部门）

2、完善“一个中心”机制。深化区审批审查中心实体化建设，巩固“审批不出中心”改革成效，夯实“一个中心”服务集成，进一步细化服务标准，完善运作体系，实现同一事项无差别受理、同标准办理。深入推进工程建设项目审批标准化、规范化、便利化切实落地，深化一站式事项办理服务模式，提高整体服务能级。加强窗口和一线等入驻人员配备、管理、培训和考核，形成激励奖励措施。（责任部门：各有关部门）

3、加强培训宣传。采用政策解读、专场培训、业务指导等方式，针对性地解读杨浦工程建设领域营商环境的最新政策、特色做法和主要成效，帮助更多企业、项目享受到改革红利。推动面向实践、面向一线、面向政策执行层面的宣传，形成分层分类宣传模式，将营商政策无差别层层传导、覆盖到位。通过完善“一图读懂”、“政策流程图”等方式，广泛宣传改革举措，增加政策的易读性。（责任部门：各有关部门）

4、强化改革绩效督查考评。做好工程建设领域营商环境考核迎评工作，发挥考评指挥棒的作用，加强对各项改革政策落地情况的督导检查，将各项改革举措执行情况，审批服务情况及区审批审查中心运行情况纳入重点考核内容。加快形成各部门主动参与、主动服务、各主体主动配合，积极支持的良好氛围和机制。（责任部门：各有关部门）
