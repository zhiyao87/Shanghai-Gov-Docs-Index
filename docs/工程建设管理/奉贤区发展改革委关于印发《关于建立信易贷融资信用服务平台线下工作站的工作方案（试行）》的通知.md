# 奉贤区发展改革委关于印发《关于建立信易贷融资信用服务平台线下工作站的工作方案（试行）》的通知

奉贤区社会信用体系建设联席会议成员单位：

为更好发挥奉贤区“信易贷”平台融资信用服务功能，深化“东方美谷贷”政银担合作机制，构建以信用信息为基础的普惠融资服务体系，结合本区实际，现就建立信易贷融资信用服务平台线下工作站制定如下工作方案。

一、工作目标

依托各街镇、区属国企服务企业的阵地资源，建立覆盖全区的信易贷融资信用服务平台线下工作站，构建“线上平台+线下触点”的全域服务网络，形成“政府引导、多方参与、便捷高效”的信用融资服务体系，推动缓解银企信息不对称难题，助力实现中小微企业融资便利。

二、工作内容

(一)站点布局与建设

1、 选址原则：以街镇社区服务中心、区属国企园区服务站等现有涉企公共服务场所为基础，优先选择交通便利、企业集聚的区域。

2、硬件配置：配备专用服务窗口、办公设备、自助服务终端(含信用查询、贷款申请等功能)，统一标识和形象设计。

3、软件系统：接入市级融资信用服务平台系统，实现数据互联互通，提供一站式信用查询、融资申请、政策咨询等服务。

(二)服务功能

1、融资需求对接：收集企业融资需求，匹配金融机构信贷产品，提供个性化融资方案。

2、平台宣传推广：引导企业(个体工商户)入驻平台，进行有效实名认证、授权和获贷。

3、信用信息查询：协助企业查询信用报告、信用评分及融资资质评估(如：一键测额)。

3、政策服务与培训：开展信用政策解读、金融产品宣讲、信用修复培训等活动。

4、问题反馈与协调：跟踪企业融资进度，协调解决审批中的问题，建立诉求响应机制。

(三)运营机制

1. 日常管理：各工作站由属地街镇或区属国企指定专人负责，建立服务台账，定期报送成效数据。

2. 协作联动：建立“区发改委(牵头)+金融机构+街镇/区属国企”三方联动机制，定期召开工作例会，协调推进问题解决。

3. 考核评估：制定工作站服务清单，以服务台账成效为依据纳入年度信用体系建设工作考核。

三、实施步骤

1、筹备阶段(2025年7月)。各街镇、区属国企做好调研选址，确定首批站点名单;协调相关部门落实场地、设备、人员等资源配置。

2.建设阶段(2025年8月)。组织工作人员开展业务培训，掌握平台操作、政策解读、服务流程等;完善服务流程与问题反馈机制。

3、推广阶段(2025年8月起)。通过政府官网、媒体、企业走访等方式宣传线下工作站功能与服务;定期开展服务效能评估，持续优化站点布局与服务内容。

四、组织保障

1、明确责任分工。区发改委总体统筹协调，制定工作方案，跟踪工作进展。各街镇、区属国企负责站点选址、日常管理、人员配备及属地企业宣传动员。在奉金融机构提供信贷产品支持，配合开展政策宣讲、需求对接和成效反馈。

2、畅通沟通机制。建立区级工作微信群、月度工作成效报送、季度工作例会等沟通渠道，确保信息及时共享与问题快速响应。

3、强化服务保障。积极对接市级融资信用服务平台，及时了解我区“信易贷”各项数据报送和归集情况，配合全市完成信易贷工作任务。
