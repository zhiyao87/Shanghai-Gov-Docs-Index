# 关于印发《临港新片区水利基本建设工程项目审批制度改革试点实施细则（试行）》的通知

关于印发《临港新片区水利基本建设工程项目审批制度改革试点实施细则（试行）》的通知

沪自贸临管委〔2020〕796号

管委会各部门、各直属单位，临港新片区各镇、各开发公司、各有关单位 :

为进一步深化临港新片区“放管服”改革和优化营商环境，加快推进临港新片区水利基本建设工程审批制度改革试点工作，根据相关政策法规等要求，临港新片区管委会制定了《临港新片区水利基本建设工程项目审批制度改革试点实施细则（试行）》，现印发给你们，请遵照执行。

中国（上海）自由贸易试验区临港新片区管理委员会

2020年10月10日

临港新片区水利基本建设工程项目审批制度改革试点实施细则（试行）

为贯彻落实关于深化“放管服”改革和优化营商环境的部署要求，加快推进临港新片区水利基本建设工程项目审批制度改革试点工作，根据《上海市工程建设项目审批制度改革试点实施方案》（沪府规〔2018〕14号）、《上海市市级水利基本建设工程项目审批制度改革试点实施细则》（沪水务〔2019〕142号）等文件精神，结合水利工程基本建设程序实际，制定本实施细则。

一、实施范围

临港新片区产城融合区内由临港新片区管委会财力投资的新建、改建、扩建的水利基本建设工程项目，适用本实施细则，但以下工程项目按照现行法定程序办理：

（一）关系国家安全的涉密项目；

（二）国家重大水利工程项目。

临港新片区水利基本建设工程项目，是指由临港新片区发展改革部门立项的，使用临港新片区建设财力进行固定资产投资的项目。

水利基本建设工程项目涉及河道蓝线以外设施（需要办理不动产登记）的，其设施建设工程按上海市工程建设项目审批制度改革领导小组印发的《上海市政府投资工程建设项目审批制度改革试点实施细则》（沪建审改〔2018〕1号，以下简称《建设项目审改试点实施细则》）、《上海市工程建设项目规划资源审批制度改革工作方案》（沪规划资源建〔2020〕17号，以下简称《建设项目规资审改工作方案》）规定执行。

二、办理事项、实施流程

办理事项覆盖水利基本建设工程项目全流程所涉及的各类行政审批和技术审查、中介服务、市政公用服务以及备案等其他类型事项。行政审批包括新办、变更、延期、注销等情形，但不包括依法应报送国务院、中央部委及市级部门审批的事项。

临港新片区水利基本建设工程项目审批全流程整合归并为立项用地规划许可、工程建设许可、开工备案、竣工验收等四个审批阶段。强化工程建设项目前期研究，在正式启动项目审批之前，设置项目储备清单和项目实施清单等两个前期策划生成环节。针对涉及动迁项目，工可先行批复，以尽快启动动迁工作，同步深化初步设计及后续审批工作，总体上压缩立项到开工用时。

每个阶段实施“一家牵头、一张表单、一口受理、告知承诺、同步审批、限时办结、依次发证”。每一阶段项目法人按照规定简化办理手续，审批结束后领取相关批准文件。过程中，项目法人可以自愿向各审批部门申请咨询服务，并接受各审批部门的事中事后监管。

三、职责分工

临港水利基本建设工程项目的开工备案（含初步设计审批环节）和竣工验收等阶段各项改革措施，由生态和市容管理处负责组织、督促、协调落实，牵头各审批部门制定、更新并公布所负责审批阶段有关的标准规范和办事指南，及时研究、解决改革推进过程中出现的新情况、新问题。

临港新片区水利基本建设工程项目的立项用地规划许可、工程建设许可等阶段，按照《建设项目审改试点实施细则》、《建设项目规资审改工作方案》的规定执行。

四、办理时限

（一）初步设计审批环节

归入开工备案阶段，按照“提前启动、并联审查、串联审批”原则，在项目可行性研究报告（初步设计深度）环节同步开展相关事项工作，7个工作日内办理审批。

（二）开工备案阶段

按照“事后办理”和“一张表单、当场受理、告知承诺”原则，当场办结。

（三）竣工验收阶段

按照“提前启动”和“一家牵头、一口受理、限时办结”原则，30个工作日内办结。

五、项目储备清单

发展改革处负责项目储备清单实施管理，生态和市容管理处负责初审和申报储备项目，协调推进前期储备研究。

列入年度拟开展前期研究的项目，各项目责任单位应当提前开展项目建议书编制、基础资料收集、专业规划深化、行业意见审查、城乡规划比对、土地权属调查、设计方案研究、控详（专项）规划调整、补充耕地方案研究等工作，提升项目策划生成质量和效率。

发展改革处批复项目建议书，明确项目建设主体，项目即转出储备清单，转入实施清单。

六、项目实施清单

规划和自然资源处牵头建立并管理项目实施清单。生态和市容管理处协同配合项目实施清单的建立、实施，并推进项目法人（建设单位）开展相应工作。

转入实施清单的项目，项目法人（建设单位）可以自行决定开展勘察、设计招标活动，确定勘察、设计单位，开展地质勘察，深化设计方案，编制可行性研究报告（初步设计深度）等。同步进行环境影响、社会稳定风险、节能评估、日照分析、交通影响、水资源（含水土保持等）、节约用地等评估报告编制工作，排除否定性因素，确保方案总体稳定。

项目法人（建设单位）根据规划和自然资源处出具的综合征询意见，可开展方案设计，推进可行性研究报告（初步设计深度）及概算等技术评审工作，委托经发展改革处、生态和市容管理处认定的第三方评估机构开展综合评估。

项目可行性研究报告（初步设计深度）综合评估通过后，即可转出项目实施清单，项目进入正式审批流程。在实施清单阶段完成项目建设条件和管理要求征询、设计方案公示、设计方案联审的，正式审批阶段不再重复上述流程。

七、立项用地规划许可、工程建设许可

临港新片区水利基本建设工程项目的立项用地规划许可、工程建设许可按照《建设项目审改试点实施细则》、《建设项目规资审改工作方案》的规定执行。开工备案阶段的初步设计审批环节可在可行性研究报告（初步设计深度）通过综合评估后提前启动。

八、开工备案

按照《水利部关于水利工程开工审批取消后加强后续监管工作的通知》（水建管〔2013〕331号）、《上海市水务局关于明确本市水利工程开工备案有关事项的通知》（沪水务〔2014〕656号）规定，临港新片区水利基本建设工程项目具备开工条件后，由项目法人（建设单位）自主确定工程开工。项目法人（建设单位）自工程开工之日起15个工作日内，应当向临港新片区建交中心进行开工备案。

水利基本建设工程项目开工备案，主要包括项目法人设立、初步设计审批、施工详图设计、建设资金落实、主体工程施工和监理单位选定、质量安全监督登记以及施工准备等工作。临港新片区开工备案受理窗口设在临港新片区建交中心。

临港新片区水利基本建设工程项目初步设计审批环节，主要包括用地规划许可、划拨决定书核发、建设用地批准书核发、建设工程规划许可证核发（含设计方案审核）、可行性研究报告批复（初步设计深度，含概算审查）、初步设计技术和经济评审报告等手续。项目法人完成初步设计审批前置条件工作后，应当向新片区管委会提出初步设计审批申请，生态和市容管理处应当在7个工作日内完成初步设计审批。临港新片区水利基建项目初步设计受理窗口设在临港新片区行政服务中心。

九、竣工验收

根据《水利工程建设项目验收管理规定》（2006年水利部令30号，2017年水利部令49号修订）以及有关现行行业标准的规定，临港新片区水利基本建设工程建设项目竣工验收应当在工程建设项目全部完成并满足一定运行条件后1年内进行。不能按期进行竣工验收的，经生态和市容管理处同意，可以适当延长期限，但最长不得超过6个月。

水利基本建设工程竣工验收，主要包括工程档案、竣工财务决算审计、水土保持等专项验收（或备案），以及竣工验收技术鉴定、竣工验收条件审核、竣工技术预验收和竣工验收等手续。条件允许的，根据实际情况推行综合验收。临港新片区管委会竣工验收受理窗口设在临港新片区建设和交通管理中心。

项目法人在竣工验收申请前，应当完成各类专项验收（或备案）以及竣工验收技术鉴定、竣工验收自查报告和按规定需要进行的竣工技术预验收、工程质量进行检测等相关准备工作。

生态和市容管理处、建设和交通管理中心收到项目法人竣工验收申请以及相关资料后，应当在8个工作日内完成竣工验收条件审核，通过条件审核的应当在15个工作日内完成竣工验收，并自竣工验收通过之日起7个工作日内完成竣工验收鉴定书制作。

十、工作要求

（一）优化审批工作环节

1.提前启动审批前置条件工作。整合项目可行性研究审批与初步设计审批环节，项目可行性研究报告达到初步设计技术深度和概算编制要求，待立项用地规划许可、工程建设许可审批完成并通过初步设计技术和概算评审后，试点可行性研究报告、初步设计及概算合并审批；竣工验收所涉及各专项验收（或备案）以及竣工验收技术鉴定、竣工技术预验收等工作，可在完工验收后由项目法人自主确定提前开展，待工程满足一定运行条件后，即可提出竣工验收申请。

2.合并受理窗口。采取一个窗口受理、统一告知、依次办结等方式同步办理相关事项，初步设计审批等全部审批事项均纳入临港新片区行政服务中心大厅统一受理，工程开工备案与质量安全监督登记、工程竣工验收与质量验收等归口在建设和交通管理中心。

（二）深化咨询机构能力

1.强化评价评估报告管理。提高初步设计审批、竣工验收等所涉及的评价评估作用，严格评价评估意见管理。同时，压缩评价评估时限，原则上不超过7个工作日，技术难度特别复杂的不超过10个工作日。

2.提升咨询机构工作质量。推进行政审批中介服务标准化建设，研究编制行政审批中介服务指南，制定中介服务的工作规范、服务标准和质量、收费依据和程序；支持培育第三方咨询服务机构或预审代办机构，提供市场化专业化的咨询服务。

（三）完善管理服务功能

1.做优办事咨询服务。相关受理窗口服务单位应当完善管理服务工作，按照精细化、标准化、信息化要求，及时修订相关工作指南、办事流程等，定期分析、汇总和发布管理服务中的常见问题和处理意见，为企业提供优质咨询服务。

2.做细管理服务系统平台。按照“一网通办”规范，进一步完善临港新片区水利基本建设项目管理协同平台系统、水务工程质量安全监督管理系统，加强行政审批电子证照应用，实现“一网受理、只跑一次、一次办成”，推动全程网办。

（四）转变政府管理方式

1.加强事中事后监管。依托临港新片区“互联网+监管”系统，全面推行“双随机、一公开”监管模式，以告知承诺事项为重点，建立完善审核、记录、抽查和惩戒的事中事后监管制度，并按照职责分工开展审批和事中事后监管工作。

2.推进诚信体系建设。结合公共信用信息服务平台的信息共享机制，汇集行政审批各环节、各阶段监管部门记录的信用信息，完善临港新片区水务工程建设市场信用信息平台，建立健全覆盖项目法人、工程咨询、勘察、设计、施工、监理、检测等各类企业和从业人员信用档案，完善信用信息的记录、公开、评价和应用制度，强化守信激励和失信惩戒措施，扩大信用评价结果在项目全流程审批、招投标、资质资格准入等环节或领域的应用，加强跨部门的失信联合惩戒。

十一、实施日期

本实施细则自发布之日起试行。
