# 关于发布 《港口经营许可办事指南》的通知

各有关单位：

根据《上海市交通行政审批办事指南和业务手册编制、调整程序规定（试行）》的要求，我委对《港口经营许可办事指南》进行了修订。现印发给你们，自2022年4月15日起施行。
