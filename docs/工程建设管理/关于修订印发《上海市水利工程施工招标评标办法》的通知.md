# 关于修订印发《上海市水利工程施工招标评标办法》的通知

关于修订印发《上海市水利工程施工招标评标办法》的通知

沪水务〔2025〕383号

各区水务局、特定地区管委会、各市级项目法人：

为进一步规范本市水利工程施工招投标活动，促进水利建设市场公平竞争，维护国家和社会公共利益，保护招投标当事人的合法权益，根据《关于进一步深化本市建设工程招投标制度改革工作的实施意见》（沪建建管〔2024〕49号）要求，结合实际情况，市水务局和市住房和城乡建设管理委员会对《上海市水利工程施工招标评标办法》（沪水务〔2021〕762号）进行了修订。现将修订后的《上海市水利工程施工招标评标办法》印发给你们，请遵照执行。

特此通知。

上海市水务局

上海市住房和城乡建设管理委员会

2025年9月28日
