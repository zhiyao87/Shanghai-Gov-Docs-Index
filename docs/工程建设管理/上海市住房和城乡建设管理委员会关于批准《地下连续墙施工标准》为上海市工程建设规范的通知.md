# 上海市住房和城乡建设管理委员会关于批准《地下连续墙施工标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《地下连续墙施工标准》为上海市工程建设规范的通知

沪建标定〔2026〕125号

各有关单位：

由上海建工集团股份有限公司、上海市基础工程集团有限公司主编的《地下连续墙施工标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2073-2026，自2026年9月1日起实施。原《地下连续墙施工规程》(DG/TJ08-2073-2016)同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海建工集团股份有限公司负责解释。

特此通知。

2026年4月2日
