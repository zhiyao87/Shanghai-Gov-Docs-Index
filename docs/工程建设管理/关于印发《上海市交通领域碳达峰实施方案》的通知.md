# 关于印发《上海市交通领域碳达峰实施方案》的通知

各有关单位：
为深入贯彻落实党中央、国务院关于碳达峰碳中和的重大战略部署，按照《中共上海市委上海市人民政府关于完整准确全面贯彻新发展理念做好碳达峰碳中和工作的实施意见》《上海市碳达峰实施方案》要求，参照国家发展改革委等四部委印发的《交通运输领域绿色低碳发展实施方案》，结合上海实际，市交通委、市发展改革委共同研究制定了《上海市交通领域碳达峰实施方案》。现印发给你们，请遵照执行。
特此通知。
