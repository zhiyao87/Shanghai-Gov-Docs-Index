# 关于发布2022年度上海市新能源出租车充电示范站入围名单的通知

各相关单位：
根据《关于印发<落实2022年上海市为民办实事项目推进电动汽车充电设施建设工作方案>的通知》（沪发改能源〔2022〕71号）和《关于开展2022年度本市新能源出租车充电示范站申报工作的通知》（沪交科〔2021〕239号）文件要求，近日市交通委、市发展改革委、市财政局组织对各区申报的示范站项目进行了审核，现将有关情况通知如下：
一、经审核，同意“玖行充电金高路充电站”等11个（其中10个新增项目、1个原示范站扩建项目）已建成项目以及“上海浦东晨阳路沙泥路口出租车充电项目”等18个（其中16个新增项目、2个原示范站扩建项目）计划建设项目列为2022年度新能源出租车充电示范站入围名单（名单详见附件1、附件2）。
二、项目已建成的，各相关运营企业应加强管理，规范服务流程，建立安全运营制度，落实安全防范措施，提升充电服务质量和配套服务能力，优先保障新能源出租车充电需求，模范执行本市有关管理要求和行业政策，主动接受主管部门监管和上海充换电设施公共数据采集与监测平台的监督，树立行业服务标杆，积极发挥示范作用。
三、项目在建或计划建设的，各项目申报企业应按既定的建设计划按期完成建设，无特殊原因，未能如期完成项目建设的，将取消相关站点入围资格及后两年的申报资格；各区交通管理部门要会同区发展改革委督促、推进示范站建设，在11月底前完成验收后报市交通委、市发展改革委核定；国网上海市电力公司做好电力供应保障和送电进度保障，落实本市经营性集中式充换电设施用电价格优惠政策。
四、本市对新能源出租车充电示范站采用动态管理、适时调整机制，市交通委、市发展改革委、市财政局将组织对新能源出租车充电示范站进行评估考核，并将在年底发布新能源出租车充电示范站最终名单。
特此通知。
