# 上海市住房和城乡建设管理委员会关于批准《城镇污水处理厂分类技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《城镇污水处理厂分类技术标准》为上海市工程建设规范的通知

沪建标定〔2025〕317号

各有关单位：

由上海城投污水处理有限公司主编的《城镇污水处理厂分类技术标准》，经我委审核，现批准为上海市工程建设规范,统一编号为DG/TJ08-2140-2025，自2025年12月1日起实施。原《城镇污水处理厂分类技术标准》（DG/TJ08-2140-2014）同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海城投污水处理有限公司负责解释。

特此通知。

2025年6月16日
