# 上海市住房和城乡建设管理委员会关于批准《地质灾害危险性评估技术标准》为上海市工程建设规范的通知

各有关单位：

由上海市自然资源调查利用研究院主编的《地质灾害危险性评估技术标准》，经我委审核，现批准为上海市工程建设规范,统一编号为DG/TJ08-2007-2026，自2027年2月1日起实施。原《地质灾害危险性评估技术规程》DG/TJ08-2007-2016同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市自然资源调查利用研究院负责解释。

特此通知。

2026年8月10日
