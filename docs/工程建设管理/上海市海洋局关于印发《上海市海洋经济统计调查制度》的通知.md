# 上海市海洋局关于印发《上海市海洋经济统计调查制度》的通知

上海市海洋局关于印发《上海市海洋经济统计调查制度》的通知

沪海洋〔2024〕18号

市发展改革委、市经济信息化委、市教委、市科委、市交通委、市农业农村委、市文化旅游局、市长兴岛管委会、上海海事局、沿海区海洋局、沿海区统计局、涉海企业（园区）：

根据《上海市统计局关于批准执行上海市海洋经济统计调查制度的函》（沪统审制〔2024〕3号），《上海市海洋经济统计调查制度》已批准自2024年2月开始执行，有效期至2026年4月。现将制度印发给你们，请认真遵照执行。制度电子版可在我局官方网站（https://swj.sh.gov.cn）或市统计局官方网站（https://tjj.sh.gov.cn/dftc/20191109/0014-213786.html）下载，在制度执行过程中，相关问题和建议请及时反馈我局。

特此通知。

上海市海洋局

2024年3月8日
