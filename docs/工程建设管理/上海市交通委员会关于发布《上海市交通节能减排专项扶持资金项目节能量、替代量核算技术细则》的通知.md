# 上海市交通委员会关于发布《上海市交通节能减排专项扶持资金项目节能量、替代量核算技术细则》的通知

上海市交通委员会

关于发布《上海市交通节能减排专项

扶持资金项目节能量、替代量核算

技术细则》的通知

各有关单位：

《上海市交通节能减排专项扶持资金管理办法》（沪交行规〔2022〕5号，以下简称《办法》）已于2022年6月24日正式发布。为做好上海市交通节能减排专项扶持资金项目节能量、替代量的核算工作，根据《办法》的扶持标准及要求，上海市交通委员会组织编制形成《上海市交通节能减排专项扶持资金项目节能量、替代量核算技术细则》，现予以发布，请各单位遵照执行。

特此通知。

附件：上海市交通节能减排专项扶持资金项目节能量、替代量核算技术细则
