# 关于调整本市非居民用户天然气销售基准价格的通知

各有关单位：

根据《关于本市非居民天然气用户上下游价格联动机制的通知》（沪发改规范〔2022〕10号）相关规定，结合本市天然气上游气源价格变动情况，决定调整非居民用户天然气销售基准价格。调整后的价格见下表：

请各供应企业认真做好准确抄表、宣传解释等工作，妥善处理实施中的有关问题，提高服务质量和管理水平，确保全市燃气稳定安全供应。
