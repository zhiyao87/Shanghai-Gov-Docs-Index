# 上海市自然灾害防治委员会关于增补更新市自然灾害防治委员会成员单位的通知

各区人民政府、市自然灾害防治委员会各成员单位：

根据工作需要，经市领导同意，决定增补上海市人民政府台湾事务办公室、中国（上海）自由贸易试验区临港新片区管理委员会、上海化学工业区管理委员会、中国铁路上海局集团有限公司、上海机场（集团）有限公司、上海城投（集团）有限公司为市自然灾害防治委员会成员单位，原成员单位中国安能第二工程局上海分公司更新为中国安能集团华东区域总部。

上海市自然灾害防治委员会

2022年9月26日
