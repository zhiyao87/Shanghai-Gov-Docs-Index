# 关于调整庄行镇小型建设工程项目管理实施意见的通知

各居村、企事业单位，镇政府各部门：

为进一步规范本镇小型建设工程项目管理，加强廉政建设，确保工程项目体现“问题导向、需求导向、效果导向”等三个原则，并使小型建设工程公开、公正、公平和规范有序地建设，现根据有关法律法规的规定及中央、市、区相关文件要求，并结合本镇实际情况，对《关于进一步加强庄行镇小型建设工程项目管理的实施意见》(奉庄府〔2022〕6号)(以下简称《实施意见》)中的部分内容作如下调整：

一、更改和补充事项

1.对《实施意见》中适用范围进行补充

原文件内容：“小型建设工程是指全部或部分使用市、区或镇级政府性资金、且投资额在400万元以下(不含400万元)的建设工程”。

调整为：“小型建设工程是指全部或部分使用中央、市、区或镇级政府性资金以及其他公共资金，且投资额在400万元以下(不含400万元)的建设工程”。

2.对《实施意见》中小型建设工程项目管理领导小组人员及成员单位进行调整

调整后如下：

组    长：陶 清 镇党委书记、一级调研员

3.对《实施意见》中工作职责部分内容进行更改

原文件内容：“镇财政所、资产公司参与初审、竣工验收工作，负责小型项目的资金拨付、结算审计等”。

调整为：“镇财政所参与对使用财政资金的小型项目，进行初审、竣工验收等工作，并负责审价、资金拨付等;其他出资单位参与对本单位出资的小型项目进行初审、竣工验收等工作，并负责审价、资金拨付等。”

4.对《实施意见》中项目报批管理部分内容进行更改

原文件内容：“形成初审意见，再由镇项目办统一提交镇长办公会审批”。

调整为：“形成初审意见，再由建设单位提交镇长办公会审批”。

5.对《实施意见》中施工招投标管理部分内容进行更改

(1)原文件内容：“投资总额在10万元以上(含10万元)100万元以下(不含100万元)的小型建设工程可采取邀请招标方式”。

调整为：“投资总额在30万元(含)以上，不足100万元的小型建设工程可采取邀请招标方式”。

(2)原文件内容：“投资总额在10万元以下(不含10万元)的特殊小型建设工程，由建设单位通过比价的方式发包给有资质的施工单位”。

调整为“投资总额在30万元以下(不含30万元)的特殊小型建设工程，由建设单位经不少于3家单位比价后择优确定施工单位”。

(3)对原文件内容：“设备采购：小型建设工程中属设备、货物和服务等项目，一律纳入政府采购程序”，该段予以删除。

修改说明：此段内容已删除。

(4)原文件内容：“镇项目办、建设单位委托具有相应资质的招标代理机构进行代理招标”。

调整为“建设单位委托具有相应资质的招标代理机构进行代理招标”。

6.对《实施意见》中施工管理部分内容进行更改或补充

(1)原文件内容：“建设单位为小型项目质量、安全、文明施工管理的第一责任人，项目中标单位应是具有相应施工资质的施工单位，建设单位要督促中标单位切实加强施工现场的安全质量等管理，镇项目办负有监督责任”。

调整为：“建设单位为小型项目质量、安全、文明施工管理的第一责任人，项目中标单位应是具有相应施工资质的施工单位，建设单位要督促中标单位切实加强施工现场的安全质量等管理，镇项目办、镇建管站、属地村居负有监督责任”。

(2)原文件内容：“项目开工前，建设单位应到镇建管站办理安全质量监督备案手续，取得施工通知书后方可进场施工”。

调整为：“项目开工前，建设单位应到镇建管站办理安全质量监督备案手续，施工单位应取得建设单位发出的施工通知书后方可进场施工”。

(3)原文件内容：“本镇小型建设工程推行工程监理制度……，30万元(不含30万元)以下建设项目，且施工复杂性、专业性不强的，经领导小组讨论同意，可由建设单位履行施工质量、安全等监管”，

调整为“本镇投资额在100万元(含)以上的小型建设工程推行工程监理制度……，100万元(不含)以下建设项目，且施工复杂性、专业性不强的，经领导小组讨论同意，可由建设单位履行施工质量、安全等监管”。

7.对《实施意见》中档案管理部分内容进行补充

修改后内容(补充)：归档的资料中增加“镇建管站备案文件、开/竣工报告、合同工程工程量确认单、工程签证、竣工图、初验文件”。

8.对《实施意见》其他要求中的部分内容进行更改

原文件内容：“各村投资总额在30万元以下(不含30万元)的小微工程项目按庄行镇村级‘小微权力’有关规定实施，但工程需报项目办备案”。

调整为“各村投资总额5万元及以上小型建设项目需进行预审备案，且在项目施工前需报镇建管站备案，其中30万元(不含)以下的工程按村小微权力执行”。

二、其他事项

1.通知自发文之日起执行，其他内容仍按原《实施意见》执行。

三、本通知由小型建设工程项目管理办公室解释。
