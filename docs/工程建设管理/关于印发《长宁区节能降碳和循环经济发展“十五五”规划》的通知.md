# 关于印发《长宁区节能降碳和循环经济发展“十五五”规划》的通知

区政府各委、办、局，各街道办事处，新泾镇政府：

《长宁区节能降碳和循环经济发展“十五五”规划》已经区政府第 141 次常务会议、十一届区委常委会第 211 次会议审议通过，现予以印发。

特此通知。

上海市长宁区发展和改革委员会

2026年8月27日

长宁区节能降碳和循环经济发展“十五五”规划

为进一步推动节能降碳和循环经济工作，如期实现碳达峰目标，建设资源节约利用、生态清新宜人、更加宜商宜居的绿色城区，依据《上海市节能降碳和循环经济发展“十五五”规划》《长宁区国民经济和社会发展第十五个五年规划纲要》《长宁区碳达峰实施方案》，制定本规划。

一、发展基础

(一)发展成效

“十四五”期间，长宁区绿色低碳发展取得显著成效，节能降碳目标顺利完成。能耗强度方面，“十四五”单位生产总值能耗累计下降18.5%，完成“十四五”初制定的13.5%目标。新能源发展方面，“十四五”期间，全区新增光伏发电项目累计并网17726千瓦，达成市级目标。产业结构、建筑节能、交通节能等重点领域同步推进，服务业占比稳步提升，既有建筑节能改造规模居全市首位，电动汽车充电桩示范小区建成数量位列全市前列。在此基础上，长宁区在既有公共建筑管理机制、城市生物多样性保护等多个绿色低碳领域率先探索，形成了一批国内领先的创新实践，为全区高质量发展奠定了坚实基础。

1.节能降碳管理推进机制持续完善

推进碳达峰碳中和统筹协调。与全市碳达峰碳中和顶层设计相衔接，编制发布《长宁区碳达峰实施方案》。每年制定区年度碳达峰碳中和节能减排重点工作安排，将节能目标和可再生能源建设任务完成情况纳入区政府重点工作和机关绩效考核体系。严格实施节能审查制度。全面落实市级节能管理相关规定，强化节能审查与验收的全过程闭环管理，按管理要求完成“十四五”期间新增固定资产投资项目节能审查和节能审查验收。强化节能降碳精细化管理。在全市率先探索开展区级温室气体清单编制工作。扩大重点用能单位管理范围，实施能耗“双控”目标管理。组织多部门联合开展“双随机、一公开”监督检查，通过实地走访、专题座谈、信息技术等方式指导用能单位完善节能管理体系。加大政策资金支持力度。出台《长宁区支持节能减排降碳若干政策措施》。“十四五”期间，节能减排和低碳发展专项资金合计支出约1.75亿元，重点支持大型公共建筑节能改造、光伏建设、电动汽车共享充电桩小区等项目。

2.产业结构和能源结构不断优化

促进主要产业结构升级。现代服务业发展态势良好，绿色低碳日益成为行业共识和内生新动力，2021年至2024年，服务业(第三产业)完成增加值占全区生产总值的比重从89.9%增长至97.1%。有力推动能源结构改善。开展全区光伏建设潜力资源排查，制定《长宁区“十四五”光伏建设实施方案》。重点推进国有企业和公共机构光伏项目建设，明确目标任务与责任分工。“十四五”期间新增光伏17726千瓦光伏建设。

3.重点领域节能减碳成效显著

引领实施建筑节能改造。完成12个既有公共建筑节能改造项目，共163.41万平方米，其中节能率15%的改造面积86.47万平方米，全市排名第一。实施公共建筑能(碳)效对标工作，完成11项建筑能源审计，既有公共建筑能效达标(合理值)率70%(含先进值)。完成3个超低能耗建筑项目共4.29万平方米，制定《上海市小型既有公共建筑超低能耗改造技术标准》。发布CN100建筑碳中和倡议机制。加快推动交通绿色转型。建成充电桩设施2229个(含280处快速充电设施)。建成全市唯一共享充电桩全覆盖街道。累计完成63个电动汽车共享充电桩小区建设，建成数量位居全市前列。新增环卫作业车、公务车100%新能源化。编制《长宁区慢行交通建设规划》，新建慢行步道5.12公里。结合15分钟社区生活圈理念与地铁通勤TOD模式，编制《北新泾区域低碳交通系统规划方案》。创建公共机构节能示范。加强公共机构用能运行管理和节能改造，区公共机构单位建筑面积能耗累计下降4.14%，人均能耗累计下降7.9%，人均水耗累计下降15.88%。持续推进公共机构资源节约工作，逐步扩大示范创建范围，适存小学、同仁医院、天山路街道社区卫生服务中心等获评上海市节约型公共机构示范单位。拓展生态碳汇普惠举措。“十四五”期间，累计完成立体绿化建设12.85万平方米，新建公共绿地9.51万平米，全区人均公园绿地面积达到7.81平方米/人，绿化覆盖率达到34.33%。

4.资源循环综合利用能力稳步提升

持续加强塑料污染源头减量。全面落实本市塑料污染治理工作要求，向大型商场、超市和标准化菜市场全面下发限塑禁塑通知，试点实施菜市场塑料购物袋集中购销制度，督促电商平台、宾馆酒店等各类主体落实塑料减量和垃圾分类措施。完善垃圾集疏运和回收体系建设。推进生活垃圾分类投放点更新改造，完成湿垃圾转运设施升级改造。持续完善可回收物‘点、站、场’体系建设，截至2025年底，建设8座可回收物中转站，其中2座为示范型可回收物中转站，生活垃圾回收利用率达48.95%。

5.节能降碳示范引领效应不断扩大

航空枢纽绿色转型成效显著。虹桥机场“打造绿色航空枢纽项目”入选生态环境部2021年绿色低碳典型案例，虹桥商务区机场东片区绿色生态城区成功获评三星级上海市绿色生态城区。绿色低碳韧性社区培育取得阶段性成果。北新泾绿色低碳韧性社区成为联合国“创建韧性城市2030行动计划”国内首个社区试点项目。社区生境花园建设成效显著。建成生境花园30座，总面积约21910平方米。启动新泾镇生境社区建设，“绿八乐颐生境花园”入选联合国生物多样性100+全球典型案例名单，建成全国首家社区生境博物馆。编制《长宁区生物多样性保护空间网络与生境花园行动方案》等多项城市生物多样性保护文件。企业绿色升级实践更加普遍。一批企业开展绿色升级，如上海朗诗绿色中心实施既有公共建筑超低能耗改造并获多项国内评价认可，博世(中国)投资有限公司入选上海市节能模范单位，该公司“践行可持续发展目标，推动产业链供应链绿色升级”案例入选“上海市第一批现代环境治理体系十大典型案例”，百联西郊购物中心被评为“2024年度上海市既有建筑绿色低碳更新改造(铂金奖)”。

6.能源管理基础能力显著提升

加强能源统计能力建设。优化《长宁区能源统计数据质量控制管理办法》，明确数据评审办法。开展能源领域数据核查工作，对重点用能单位开展能源统计执法检查。构建全区公共机构能源管理联络员与统计员队伍。加强能源计量工作。开展企业能源计量实务培训，对10家单位开展能源计量核排查和关口核查，帮助企业健全能源计量管理制度、提高能源计量管理水平，加强重点用能单位能耗在线监测，提高重点用能单位能源计量管理水平。

7.绿色低碳生活成为社会风尚

树立绿色低碳长宁形象。结合节能宣传周、全国低碳日、世界环境日等重要节点深入开展多元化低碳主题宣传活动，连续三届组团参展上海国际碳中和博览会，编制《长宁区低碳地图》。全面引导各类社会主体绿色低碳行为。全区累计168个社区绿色社区创建达标。垃圾分类习惯基本养成，减塑意识普遍增强。龙之梦城市生活中心成功入选“2024年度全国绿色商场示范创建”，百联西郊购物中心、长宁来福士通过创建满三年以上既有绿色商场复评。

(二)面临形势

“十五五”期间，国家将积极推动工业、城乡建设、交通运输、能源等重点领域绿色低碳转型，从能耗双控全面转向碳排放双控。中央经济工作会议明确提出，坚持“双碳”引领，推动全面绿色转型。深入推进重点行业节能降碳改造，加快新型能源体系建设。

虽然长宁区“十四五”期间在绿色低碳转型发展方面已取得一定成效，但面对碳达峰的刚性约束、“碳双控”机制的更高标准，以及高质量发展、高水平安全和民生持续改善的多重要求，面向高密度城市高质量发展的绿色发展机制尚未成型，节能降碳和循环经济发展工作还面临较大的压力和挑战。

具体表现为：一是能效进一步提升空间有限。从全市层面看，我区能源利用效率已处于领先水平，“十五五”能效提升的边际效应逐步显现。二是可再生能源拓展空间有限。作为高密度建成区，城市空间形态制约了可再生能源的大规模布局与应用。三是新经济产业集聚度不足。科创等新经济业态尚未形成规模效应和产业集群，对绿色低碳转型的带动作用有限。四是城市更新与载体约束明显。目前城市更新机制仍不成熟，经济社会发展的绿色转型面临政策空间与物理载体不足的双重制约。五是住宅建筑用能持续刚性增长。全区住宅建筑占比高，随着居民生活水平提升，居民用能需求仍将保持增长态势。

二、总体要求

(一)指导思想

坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻党的二十大和二十届历次全会精神，深入践行习近平经济思想、生态文明思想和考察上海重要讲话精神，落实加快经济社会发展全面绿色转型要求，以实现碳达峰碳中和目标为牵引，紧紧围绕长宁“十五五” 愿景目标，因地制宜统筹推进，充分发挥政策效应，不断完善市场机制，有效调动全社会的积极性，确保2030年前高质量实现碳达峰目标。

(二)基本原则

1.前瞻布局。探索节能降碳机制建设，研究运用碳排放预算、可再生能源消纳等措施，实现精细化管理。提前布局未来绿色低碳发展重点领域和关键技术方向。立足区域实际，围绕楼宇经济高效业态，培育绿色发展新动能。

2.多维统筹。以2030年前实现碳达峰为目标，统筹经济社会发展与节能降碳目标。深挖建筑、交通等重点领域降碳潜力，多维度系统性提升城市低碳运行水平。整合政府政策与市场资源，构建政府、企业、社会多元共治格局。

3.因地制宜。在巩固现有成效基础上，坚持因地制宜，积极推动新技术应用示范。着力探索新机制实践路径，加快培育新模式。充分运用市场机制与社会机制，引导生产生活方式绿色低碳转型。努力在重点领域形成具有长宁特色的创新实践。

(三)发展目标

推动能耗双控向碳排放双控制度转变，完成本市下达的碳排放双控目标，确保2030年前碳达峰目标如期实现。加快生产生活方式全面绿色转型，节能降碳管理更为精细，节能新技术、新机制应用示范取得良好成效，绿色生活方式成为自觉选择，绿色低碳循环的经济社会体系基本形成，成为高效集约发展的中心城区标杆。

三、主要任务

(一)构筑绿色低碳产业生态

1.加快绿色低碳产业发展平台建设。加快推动低效园区与楼宇绿色转型，积极建设绿色低碳产业孵化器、众创空间及特色产业园区。建立与专业机构、高等院校、重点楼宇园区的合作机制，共同打造若干绿色可持续消费示范场景。对接国家及市级专业平台资源，搭建新能源产业服务平台，打造长宁绿色产业生态，有效集聚和服务新能源企业。

2.培育壮大特色绿色产业。支持基于可持续发展理念的生物材料、时尚创意等新兴绿色产业发展。依托双碳认证、碳足迹等领域的碳咨询企业，强化推广支撑，培育壮大双碳咨询服务业，在绿色转型发展中发挥引领作用。支持能源替代和绿色智算等产业领域发展，鼓励节能降碳技术研发，构建从技术研发到产品推广的绿色闭环。

3.健全绿色低碳专业服务。搭建区级绿色产业转化与展示平台，着力新增一批标志性绿色企业，形成产业示范与带动效应。围绕长宁绿色产业主攻方向，组织吸引具有高影响力的行业活动落地。

4.推动数字化赋能产业绿色转型。聚焦长宁“3+3”重点产业和重点区域开展数字化技术应用示范试点，助推企业提升研发创新能力。鼓励企业应用新能源及智慧能源管理系统，以“数字化+低碳化”双轮驱动产业发展。

5.支持企业低碳技术创新研究。支持企业开展低碳技术创新，鼓励企业承担国家、上海市绿色低碳重大科技项目，发挥在绿色低碳技术研发、示范应用和产业化中的主体作用。鼓励企业参与国际级、国家级绿色低碳产品、技术和项目评比活动，制定高于国家标准、行业标准、地方标准，具有竞争力的通用标准。

(二)健全低碳管理体系

6.优化节能降碳先导管理。全面落实能耗双控、碳双控制度，统筹调度全区企业能(碳)排放指标。落实固定资产投资项目节能审查和碳排放评价制度，严格能(碳)验收闭环管理。加强重点用能设备节能诊断，加快推动落后设备淘汰更新。积极推动产品碳标识认证制度实施并广泛应用。鼓励外资总部型企业、国内行业龙头等先行示范企业，率先建立涵盖绿电、绿证及ESG管理的双碳全流程管理体系。

7.落实碳排放双控考核机制。围绕民用建筑、商业设施、公共机构等领域，衔接本市碳排放目标，研究提出面向区重点单位、行业管理部门的分项目标和任务。推动落实碳排放预算管理，定期开展预算执行情况评估，实行动态调整优化。开展碳双控评价考核，加强考核成果运用。

8.加强重点用能单位管理。通过目标考核、能效分级、绿色电力、绿色信用等激励约束机制，有效推动重点单位和楼宇加强节能降碳管理，落实节能降碳管理要求。鼓励重点单位和楼宇开展碳排放核算，研究碳减排方案，建立节能降碳管理机制。

9.提升能碳数字管理水平。完善区能耗和碳排放数字化管理体系，整合多源数据，形成兼具宏观决策、中观管理和微观指导功能的政府能碳管理数字化工具。推动大型公共建筑建立能碳数字化管理系统。

(三)深化建筑提质增效

10.推进既有建筑能效碳效提升。结合城市更新，推进既有建筑规模化节能改造。支持公共机构、大型公共建筑采取高效制冷行动。采用智慧能源管理技术，实现对建筑能耗的动态监测、智能调控与持续优化。引导公共建筑运行能效应达尽达先进水平。深化CN100建筑碳中和倡议实施，拓展成员网络并提升减排实效。因地制宜探索全电化应用场景，提升大型公共建筑电气化水平，面向全市编制发布公共建筑全电化操作指南。

11.推广绿色建筑与绿色施工。新建建筑100%执行绿色建筑标准，引导新建建筑运行能效达到先进水平，逐步推动新建建筑全电化。落实本市超低能耗建筑发展要求，鼓励新建建筑采用更高节能标准设计建设。推广绿色施工和装配式建筑，推动节约型工地建设和装修垃圾减量，大力推进工程渣土等废弃物循环利用。鼓励新建建筑按照全生命周期零碳标准进行规划、设计与建造。

(四)加速交通绿色转型

12.优化城市出行结构与绿色出行环境。持续完善公共交通体系，提升全区轨道交通600米覆盖半径至85%以上。强化轨道交通站点末端接驳及公交两网融合，深化公共交通“最后一公里”和“最后一米”建设。完善慢行交通设施，着重构建东部、中部、西部三个重点区域的立体慢行勾连体系，融合城市更新和“15分钟社区生活圈”建设，提高慢行交通网络的可达性和便捷性。

13.加快绿色交通基础设施建设。重点推进充电基础设施网络建设，加快布局充电桩、出租车专用充电站、配套电网。结合新建场库验收与既有场库经营备案，持续推进电动汽车充电桩建设，每年新增200个公共充电桩，科学布局大功率快充设施(60KW及以上)，重点加强薄弱区域备案场库的设施覆盖。持续推进建设共享充电桩小区。推动“加油+充电”综合充能站建设试点，新建综合充能站。

14.推动运输工具装备低碳转型。加大传统燃油车辆的低碳替代力度，政府公务用车、环卫作业车辆等公共领域新能源新增或更新车辆原则上有适配车型的均使用纯电动汽车，持续推进公共服务企业运营车辆及社会乘用车辆电动化发展。引导企业对机场区域内非道路移动源实施清洁能源与新能源替代。

(五)加快能源结构优化

15.大力推进可再生能源建设。落实市可再生能源在中心城区的布局，进一步实施光伏项目建设，开展“光伏+”行动。严格落实市级新建建筑可再生能源建设要求，规范新建建筑可再生能源建设项目立项审批、设计审查与竣工验收等流程。到2030年，公共建筑光伏覆盖率进一步提升。研究试点居住小区屋顶光伏项目。加强既有光伏项目管理，确保发电效率。

16.扩大可再生能源消纳消费。推动能源消费绿色低碳化，加大绿电等社会化机制应用，有效提升可再生能源消纳消费。响应市应对可再生能源的新型电力系统工作要求，以市场化方式稳妥推进虚拟电厂建设。探索结合公共机构、商业设施、居住社区的公共充电场站运营，开发V2G场景，进行相关基础设施提升改造。

17.打造零碳试点示范项目。在虹桥机场东片区、临空经济园区、虹桥开发区、硅巷街区等重点区域推进低碳示范项目建设，包括近零能耗建筑、零碳建筑、零碳园区、“光储直柔”建筑能源系统等创新示范，探索虹桥T1航站楼蓄车场管理用房等一批零碳建筑特色项目。

(六)构建全社会绿色低碳循环体系

18.推进生活垃圾源头减量。坚决遏制奢侈浪费和不合理消费，制止餐饮浪费行为，全面推行“光盘行动”。严格落实减塑限塑，全面推进一次性塑料制品源头减量，推广可降解替代产品和循环模式，强化企业主体责任，督促生产、销售等环节落实塑料减量化措施。

19.构建高效回收利用体系。推进废弃物处置中心改造升级项目。逐步推进可回收物精细化分类，完善可回收物中转站、集散场硬件设施和运营管理水平，促进可回收物资源化利用，研究增设资源回收站点，实现“公益交投”和“惠民回收”双覆盖，构建“线上+线下”一体化“沪尚回收”新模式。

20.引导绿色低碳生活方式。鼓励企业开发餐饮、商超、文旅、体育、交通等多元领域的碳普惠应用场景，引导居民通过低碳出行、绿色消费参与碳普惠。鼓励企业推出碳中和产品和服务，探索会议、展览等大型活动碳中和场景。聚焦园区、企业、街镇、社区等继续打造一批现代环境治理体系应用案例。持续推进绿色低碳韧性社区建设，形成可操作、可复制、可推广的经验做法，面向全市编制发布社区绿色低碳转型指，形成特色鲜明的社区低碳路径。培育一批具有示范效应的生境花园项目，持续优化生境花园社会化运维机制。探索形成绿色低碳与社会治理深度融合、具有长宁特色的社区绿色治理模式。

四、保障措施

(一)强化组织保障

围绕“双碳”目标，加强市区衔接、协同推进，建立高效的区级节能降碳工作的顶层设计构架。强化年度工作计划制定与执行，定期对全区各领域进展情况进行跟踪推进，督促各项目标任务完成。不断完善区政府统筹领导、主管部门统一监管、相关部门协同配合、社会共同参与的节能降碳与循环经济管理工作体系。

(二)完善政策支持

积极落实国家和上海市绿色低碳、循环经济发展支持政策，完善区级节能降碳、资源综合利用支持体系，形成政策合力。加大财政资金投入，突出创新引领，重点支持低碳产业生态打造、关键技术研发、示范项目建设等核心领域。积极引入社会力量参与企业和楼宇绿色转型，推广托管和合同能源管理等模式实施节能改造与运营系统优化。

(三)加大宣传推广

通过专题活动、教育培训、媒体传播等多种形式，提升全社会节能降碳意识和实践能力，促进相关领域人才、技术和项目交流合作，推动绿色产业发展与产业绿色转型。积极开展国内外城市对话与社区实践交流，分享绿色低碳经验。结合世界地球日、世界环境日、全国节能宣传周、全国低碳日等主题，联合社会组织深入开展节能降碳、资源节约及绿色生活宣传，引导居民践行绿色低碳生活方式。强化塑料污染治理、快递包装转型、高耗能电器淘汰等方面的公众宣传，在全区营造绿色发展浓厚氛围。
