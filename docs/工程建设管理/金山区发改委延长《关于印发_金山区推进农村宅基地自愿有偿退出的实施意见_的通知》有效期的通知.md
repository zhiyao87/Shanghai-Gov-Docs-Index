# 金山区发改委延长《关于印发<金山区推进农村宅基地自愿有偿退出的实施意见>的通知》有效期的通知

各镇政府、街道办事处、园区管委会，各相关委办局：

经评估，2019年12月18日区发改委印发的《关于印发<金山区推进农村宅基地自愿有偿退出的实施意见>的通知》(金发改规〔2019〕2号)需继续实施，有效期延长至2029年12月14日。

特此通知。

2024年12月13日
