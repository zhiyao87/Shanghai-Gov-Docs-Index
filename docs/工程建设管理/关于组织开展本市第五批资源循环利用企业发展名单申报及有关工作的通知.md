# 关于组织开展本市第五批资源循环利用企业发展名单申报及有关工作的通知

市经济信息化委、市商务委、市住房城乡建设管理委、市农业农村委、市生态环境局、市水务局、市绿化市容局，各区发展改革委：

按照《关于进一步支持本市资源循环利用行业稳定发展的实施意见》（沪发改环资〔2021〕133号，以下简称《实施意见》），目前本市已发布四批资源循环利用企业发展名单（以下简称“名单”）。为进一步提升全市资源循环利用行业发展规模和能级水平，发现并吸纳更多优质资源循环利用企业，同时加强对现有名单内企业生产经营情况的跟踪管理，现组织开展本市第五批资源循环利用企业名单申报和前四批名单动态调整工作。相关工作通知如下：

一、关于第五批资源循环利用企业名单申报工作

（一）申报组织

请各区发展改革委会同区相关部门积极组织区域内相关资源循环利用企业进行申报，于2026年9月24日前将推荐企业名单等材料（附件1）书面版报送市发展改革委。市发展改革委将根据企业所属行业类别分送至相关市级行业主管部门进行初评。

（二）部门初评

请市级行业主管部门对企业申报材料开展初评，具体内容包括：

1.与本市资源循环利用产业导向和需求符合性；

2.用地性质和规划符合性；

3.企业综合能力，如管理体系认证、企业诚信、技术知识产权等；

4.企业资源综合利用能力和业绩，如固废来源、利用规模、工艺技术先进性、产品销路等；

5.企业节能环保情况，如企业节能审查和验收情况、环评批复及环保竣工验收公示情况、排污许可情况、近一年环保检测报告、环境投诉与重大事故情况等。

市行业主管部门根据初评情况，于2026年10月16日前将符合要求的企业推荐名单（附件1）书面报送市发展改革委。

二、关于前四批资源循环利用企业名单动态调整工作

（一）已发布名单调整

请市行业主管部门根据日常管理情况，对各领域纳入前四批资源循环利用企业发展名单的企业进行评估，于2026年10月16日前将建议调整企业名单（附件2）汇总后书面报送市发展改革委。

（二）已调整企业重新申报

对于此前仅因存在运营主体变更和设施点位搬迁而调整出名单内的企业（附件3），可按变更后的运营主体或搬迁后的设施点位重新申报，申报采取简易流程。请相关单位于2026年9月24日前将相关证明材料书面报送市发展改革委。

三、名单确定

市发展改革委组织开展新增企业名单和调整企业名单评估，并将评估意见提交市节能减排及绿色低碳转型工作协调机制集中审议后动态更新名单。

附件：

1.资源循环利用企业推荐名单

2.资源循环利用企业建议调整名单

3.已调整企业名单（可重新申报）
