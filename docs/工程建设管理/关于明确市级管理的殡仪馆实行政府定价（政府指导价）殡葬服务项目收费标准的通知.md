# 关于明确市级管理的殡仪馆实行政府定价（政府指导价）殡葬服务项目收费标准的通知

各市级管理的殡仪馆：

为规范殡葬服务收费行为，根据《中华人民共和国价格法》《上海市殡葬管理条例》《上海市定价目录》《上海市殡葬服务项目清单》等相关规定，现将上海市龙华殡仪馆、上海市宝兴殡仪馆、上海市益善殡仪馆（以下简称各市级管理的殡仪馆）实行政府定价（政府指导价）的殡葬服务项目收费标准及相关事项通知如下：

一、各市级管理的殡仪馆相关服务项目收费标准详见下表。

二、对于实行政府定价的殡葬服务项目，各市级管理的殡仪馆应严格按照核定的收费标准执行；对于实行政府指导价的殡葬服务项目，各市级管理的殡仪馆应在核定的收费标准范围内确定具体收费标准。

三、各市级管理的殡仪馆应切实做好明码标价工作，在营业场所显著位置、网站等渠道公示服务项目、收费标准、文件依据和举报电话等，引导合理消费、明白消费，并自觉接受社会监督。

此通知自印发之日起实施，此前规定与本文不符的一律废止。

上海市发展和改革委员会

上海市民政局
