# 上海市住房和城乡建设管理委员会关于批准《优秀历史建筑保护修缮技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《优秀历史建筑保护修缮技术标准》为上海市工程建设规范的通知

沪建标定〔2025〕201号

各有关单位：

由上海市房屋管理局、上海市房屋安全监察所（上海市历史建筑保护事务中心）、上海市房地产科学研究院主编的《优秀历史建筑保护修缮技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-108-2025，自2025年10月1日起实施。原《优秀历史建筑保护修缮技术规程》DG/TJ08-108-2014同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市房屋管理局负责解释。

特此通知。

2025年4月8日
