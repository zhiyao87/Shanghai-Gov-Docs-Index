# 上海市住房和城乡建设管理委员会关于批准《工程物探技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《工程物探技术标准》为上海市工程建设规范的通知

沪建标定〔2026〕124号

各有关单位：

由上海勘察设计研究院（集团）股份有限公司主编的《工程物探技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2271-2026，自2026年9月1日起实施。原《工程物探技术标准》(DG/TJ08-2271-2018)同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海勘察设计研究院（集团）股份有限公司负责解释。

特此通知。

2026年4月2日
