# 上海市住房和城乡建设管理委员会关于批准《民防工程运行维护技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《民防工程运行维护技术标准》为上海市工程建设规范的通知

沪建标定〔2023〕76号

各有关单位：

由上海市民防科学研究所、华东建筑设计研究院有限公司、上海民防建筑研究设计院有限公司主编的《民防工程运行维护技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2418-2023，自2023年7月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市民防科学研究所负责解释。

特此通知。

2023年2月13日
