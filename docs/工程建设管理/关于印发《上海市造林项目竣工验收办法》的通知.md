# 关于印发《上海市造林项目竣工验收办法》的通知

各涉林区绿化市容局、相关市属国企：

根据《上海市造林项目管理办法》（沪绿容〔2023〕89号），为确保项目验收工作有序、规范的开展，现将《上海市造林项目竣工验收办法》印发给你们。

请各区参照本办法组织开展验收工作，并注重将验收工作与市级核查标准相衔接。

上海市绿化和市容管理局

2024年5月6日
