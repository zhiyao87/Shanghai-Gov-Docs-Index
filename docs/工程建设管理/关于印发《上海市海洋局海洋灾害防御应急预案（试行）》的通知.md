# 关于印发《上海市海洋局海洋灾害防御应急预案（试行）》的通知

关于印发《上海市海洋局海洋灾害防御应急预案（试行）》的通知

沪海洋〔2022〕19号

局属相关单位，各区海洋局：

为做好市海洋局关于海洋灾害的相关应急处置工作，市海洋局组织研究制定了《上海市海洋局海洋灾害防御应急预案（试行）》，现印发给你们，请遵照实施。

原《上海市海洋局海洋灾害观测预报应急预案》（沪海洋〔2014〕43号）、《上海市海洋局赤潮灾害应急预案》（沪海洋〔2014〕41号）同时废止。

特此通知。

上海市海洋局

2022年5月18日
