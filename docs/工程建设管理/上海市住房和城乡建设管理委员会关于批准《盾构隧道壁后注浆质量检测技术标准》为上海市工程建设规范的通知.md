# 上海市住房和城乡建设管理委员会关于批准《盾构隧道壁后注浆质量检测技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《盾构隧道壁后注浆质量检测技术标准》为上海市工程建设规范的通知

沪建标定〔2025〕461号

各有关单位：

由同济大学主编的《盾构隧道壁后注浆质量检测技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2485-2025，自2026年3月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，同济大学负责解释。

特此通知。

2025年9月16日
