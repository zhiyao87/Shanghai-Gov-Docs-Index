# 关于完善我市居民瓶装液化石油气价格机制有关事项的通知

各居民瓶装液化石油气经营企业：

为加快推进我市居民瓶装液化石油气价格市场化改革，促进行业可持续发展，保障瓶装液化石油气安全稳定供应，现就进一步完善我市居民瓶装液化石油气价格机制有关事项通知如下：

一、我市居民瓶装液化石油气价格实行“基准价+上下浮动”的机制。经营企业可根据市场供求情况并充分考虑用户承受能力，在上浮不超过基准价20%范围内自主制定价格，下浮不限。

二、基准价实行上下游价格联动，每月调整一次,上海市发展和改革委员会在门户网站公布。

三、各经营企业应合法经营，严禁价格联盟、哄抬价格、实施垄断协议、滥用市场支配地位等价格违法行为。

本通知自2023年5月10日起实施。

上海市发展和改革委员会

2023年5月6日
