# 上海市交通委员会关于印发《机动车驾驶员培训机构经营技术规范》的通知

上海市交通委员会关于印发

《机动车驾驶员培训机构经营技术规范》的通知

各有关单位：

为进一步做好机动车驾驶员培训机构经营备案、便民服务和规范驾培行业经营事中事后监管，保证市民的驾驶员培训品质和提升服务质量，市交通委编制完成《机动车驾驶员培训机构经营技术规范》，现予以发布，请各单位遵照执行。

特此通知。

上海市交通委员会

2023年5月18日
