# 上海市住房和城乡建设管理委员会关于发布《上海市建筑师负责制第三批试点项目清单》的通知

上海市住房和城乡建设管理委员会关于发布《上海市建筑师负责制第三批试点项目清单》的通知

沪建建管〔2025〕247号

各区建设管理（交通）委、特定地区管委会、相关行业协会，各有关单位：

根据《上海市推进浦东新区实施建筑师负责制若干规定》《上海市建筑师负责制扩大试点实施办法（试行）》（沪建建管联〔2022〕727号）和《关于延长〈上海市建筑师负责制扩大试点实施办法（试行）〉有效期的通知》（沪建建管联〔2024〕590号）要求，为深入推进建筑师负责制试点工作，我委会同市相关部门梳理形成了《上海市建筑师负责制第三批试点项目清单》，现予以发布。

特此通知。
