# 上海市奉贤区南桥镇人民政府关于进一步加强南桥镇小型建设工程项目规范管理的实施办法（试行）

为进一步规范我镇建设工程项目管理，加强廉政建设，确保小型建设工程公开、公正、公平和规范有序建设，现根据《中华人民共和国建筑法》、《中华人民共和国招标投标法》、《中华人民共和国政府采购法》和《上海市奉贤区建设和管理委员会等五部门关于加强小型建设工程项目管理的通知》等有关规定，结合南桥镇实际情况，提出如下实施办法。

一、适用范围

本办法所指的小型建设工程是使用各级政府性资金、集体资金、融资资金、自筹资金、社会捐款等各种资金，且投资总额在400万元以下(不含400万元)的建设工程，具体包括：

1、市政基础设施：乡村道路、桥梁，市政配套建设、土石方、桩基、绿化、环卫设施等工程。

2、公共事业项目：学校、医院和党政机关、事业单位的行政办公楼等的新建、扩建、改建工程以及修缮、装饰等工程。

3、农业、水利基础设施：农用桥梁、排灌设施、驳岸、堤防、河道疏浚、土地整治等工程。

4、拆违、建设用地减量化、动拆迁等项目中的建筑物或构筑物拆除工程;

5、其他需纳入的小型建设工程。

需经区级及以上部门审批通过的建设工程项目不纳入本实施办法。

二、组织机构及其职责

(一)项目管理领导小组

镇政府成立小型建设工程项目管理领导小组(以下简称领导小组)，领导小组组长由镇长担任，副组长由各分管副镇长担任。成员单位为镇党政办、规划办、农办、财政所、城建中心、农业中心、城管中队。

领导小组工作职责：

1.召集成员单位召开联席会议。

2.确定项目管理组织的管理任务和组织结构。

3.确定项目管理办公室的人员及其职责、分工和权限。

4.监督项目稽查与审计工作。

(二)项目管理办公室

领导小组下设项目管理办公室(以下简称项管办)，项管办主任由分管规划副镇长兼任，副主任由镇规划办负责人兼任，成员由镇党政办、规划办、农办、财政所、城建中心、农业中心、城管中队指定专人组成。

项管办工作职责：

1、负责建设工程的立项批复管理、建设指标的审核、项目考核的组织、奖惩的认定。

2、审核项目建设计划，项目文件，包括建设需求、设计方案、投资概算等。

3、指导各类合同的商谈、签订，确定项目需用资源的提供方式和核算办法。

4、委托、指导与监督招标工作的开展。

5、委托、督查监理代建工作，保证项目的安全、质量、进度、投资、文明施工及管理目标。

6、监督项目管理目标责任书落实。

7、委托实施项目稽查和审计工作。

8、负责对项目建设单位提供相应过程性指导。

9、负责邀请镇纪委监察办对项目进行全过程监督。

10、其他需完成的项目管理工作。

三、审批管理

(一)上报

建设单位确定年度部门预算意向项目，上报建设工程项目备案表(附件1-1、1-2)或报批表(附件2)、设计方案、经核价后的工程预算(概算)等所需材料，如涉及土地需征询城建中心土地管理部门填写意见征询单(附件3)。使用农村集体资金的村级项目，根据《关于建立奉贤区农村集体经济组织重大事项预审备案制度的通知》(沪奉农经[2020]1号)等相关文件，需通过“三重一大”及重大事项预审备案程序的，按照文件相关规定执行，并将相关材料作为附件一并上报。

(二)审核

项管办对上报项目进行审核并出具审核意见，相关项目必须符合党委政府既定的发展目标、发展方向，符合我镇发展的需要和财力的现状，符合南桥镇总体规划、土地利用规划以及相关控制性规划等。

1、5万(不含5万)以下的项目，由建设单位向项管办报备后自行负责把关项目可行性和概算并实施。

2、5万(含5万)至30万(不含30万)的项目，经各分管领导签字同意，由项管办负责把关项目可行性和概算并实施备案管理。

3、30万(含30万)至400万(不含400万)的项目，经分管领导签字同意、财政所审核资金来源后，由项管办负责审核项目可行性和概算。

(三)批准

1、30万(含30万)至100万(不含100万)的项目审核完成后，通过项管办研究批准并出具审核意见。报领导小组批准后项目方可进入下一步招标和施工阶段。

2、100万(含100万)至400万(不含400万)的项目审核完成后，通过领导小组会议研究批准。经批准后项目方可进入下一步招标和施工阶段。

四、招标管理

经备案或审批后，由建设单位负责办理招投标手续。

1、100万(不含100万)以下的项目。属于非政府采购项目，由采购人按照相关预算支出管理规定和本单位内部控制采购规程组织实施采购。其中预算资金5万(含5万)至30万(不含30万)的，由建设单位经比选形式择优确定;预算资金30万(含30万)至100万的，由建设单位采取邀标形式组织采购。

2、100万(含100万)至400万(不含400万)的项目。依法采用公开招标方式，由财政所在奉贤政府采购管理平台立项审批通过后，在上海市政府采购网电子招标。

3、涉及公共安全、抢险、政府重大活动等急需完成的建设工程项目。经镇长办公会集体讨论同意后，委派施工单位先行施工，并及时办理相关手续。

五、施工管理

建设单位是施工管理的第一责任单位，负责对项目施工过程进行管理。

(一)开工管理

1、项目开工前由施工单位向建设单位提交工程项目开工报告。施工单位应加强安全质量及文明施工管理，对存在施工问题的，按问题的程度分小、中、大，建设单位对施工单位处以不同金额的处罚，并纳入最终结算，对于监理单位未发现该问题的，也处以同等处罚，并在服务费结算时扣除。

2、施工单位应具有相应专业施工资质。施工单位需切实加强施工现场安全质量管理，项目经理对施工现场的安全质量负主要责任。

3、建设单位应指派专人负责工程的安全质量监管工作。

(二)隐蔽工程

所有隐蔽工程应及时组织验收，关键性隐蔽工程由建设单位、监理单位、施工单位、设计单位负责人签字认可，同时留好影像资料。隐蔽工程验收完毕后，方可进行下一道施工工序。手续齐全的隐蔽工程是工程结算的重要依据之一。

(三)签证管理

1、设计变更。在施工过程中，对因客观原因需要变更设计内容的，由建设方、监理方、施工方共同确认后由设计单位变更设计图。因工程设计变更造成的工程款调整原则上不超过工程中标价的 5%。

2、工作量变更。建设单位必须严格控制工程量的增加，项目如存在增加的工程量，由建设方、监理方、施工方共同签证确认。因工作量变更造成的工程款调整原则上不超过该工程中标价的5%。

未按上述规定进行审批，擅自变更设计、增加工程量的，在工程结算时，增加部分的工程款不予认定。

(四)验收备案

建设工程项目按设计要求完成施工后，由施工单位按照竣工验收和备案制度，整理各类技术资料，向建设单位提交建设工程项目竣工报告，建设单位组织设计单位、施工单位、监理公司等责任主体单位的代表，会同有关部门按施工图纸、工程变更签证，根据国家有关验收规范、合同要求内容进行工程验收，做好验收记录，出具验收报告、会议纪要。

六、审价结算

建设工程项目竣工验收合格后，建设单位填写建设工程项目审价申请表(附件4)，凭相关项目资料报镇财政所申请审价，审价完成后由建设单位依据最终审定价格完成项目审价审计决算。

七、资金管理

建设单位在申请资金拨付时，需将立项批复文件或已完成备案的工程建设报批表附于资金申请材料内(包括村级集体资金项目)，作为资金拨付凭证(发票税率注意符合合同或审价报告的约定)。未经项管办批复、备案或审价程序未经过财政所委托的建设工程项目资金不予拨付。

八、档案管理

建设工程项目全部竣工验收合格后，由建设单位负责归档该项目的资料，做好后评估工作。应归档的资料包括：建设工程项目备案表(附件1-1、1-2)或批复、建设工程项目开工报告、建设工程项目竣工报告、建设工程项目审价申请表(附件4)、集体讨论的会议纪要、设计合同和方案、招标代理合同、招标文件、投标文件、评标记录、中标通知书、施工合同、安全协议、廉洁协议、施工资料(竣工图)、施工单位证件(营业执照、资质证书、安全生产许可证、项目经理资格证书复印件)、监理合同和资料、审价合同和报告等。建设单位应切实加强归档管理工作。

九、全过程监督管理

相关部门应严格执行本办法相关规定。建设单位负责人对建设工程项目负有直接管理责任，应切实加强对项目申报、招投标、安全质量、资金和归档的全过程管理。项管办应建立项目管理日常检查制度，不定期对项目执行情况进行抽查、考评，重点检查各相关单位项目申报情况、项目招投标管理、安全质量管理、资金管理和档案管理等内容，检查结果报领导小组会议，由领导小组视情节轻重分别予以通报、提醒、约谈。镇纪委监察办作为监督部门，对本办法执行情况进行全过程监督，对违反相关规定的将严格依纪依规依法处理。

十、其他

(一)各村、园区、集体企业参照执行(江海置业、贝港天地等房地产项目除外)，村属企业按照集资委相关规定执行即可。

(二)本办法自发布之日起实施，试行一年。原《关于进一步加强南桥镇小型建设工程项目规范管理的实施办法》(南府〔2024〕4 号)同时废止。

(三)本办法如与国家和上海市的有关法律法规及上级文件精神有抵触的，以法律法规及上级文件精神为准。

(四)本办法由建设工程项目管理办公室负责解释。
