# 关于印发《上海市司法鉴定项目基本目录和收费标准》的通知

各司法鉴定机构：

为规范司法鉴定收费行为，保障委托人、当事人和司法鉴定机构合法权益，根据《上海市定价目录》《上海市司法鉴定收费管理办法》相关规定，现将《上海市司法鉴定项目基本目录和收费标准》印发给你们。

本通知自2024年1月1日起执行。
