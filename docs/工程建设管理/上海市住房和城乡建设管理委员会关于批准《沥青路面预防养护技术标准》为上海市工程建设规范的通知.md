# 上海市住房和城乡建设管理委员会关于批准《沥青路面预防养护技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《沥青路面预防养护技术标准》为上海市工程建设规范的通知

沪建标定〔2024〕252号

各有关单位：

由上海市市政规划设计研究院有限公司、上海市道路运输事业发展中心主编的《沥青路面预防养护技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2176-2024，自2024年12月1日起实施，原《沥青路面预防性养护技术标准》DG/TJ08-2176-2015同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市市政规划设计研究院有限公司负责解释。

特此通知。

2024年5月24日
