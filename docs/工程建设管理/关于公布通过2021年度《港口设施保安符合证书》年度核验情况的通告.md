# 关于公布通过2021年度《港口设施保安符合证书》年度核验情况的通告

根据交通运输部《中华人民共和国港口设施保安规则》及《关于发布<港口设施保安符合证书年度核验办法>的通知》要求，经我委核查，洋山深水港四期码头等63个港口设施通过2021年度《港口设施保安符合证书》年度核验。
特此通告。
