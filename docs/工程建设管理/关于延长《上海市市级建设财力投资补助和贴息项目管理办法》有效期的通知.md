# 关于延长《上海市市级建设财力投资补助和贴息项目管理办法》有效期的通知

各有关单位：

2021年1月18日市发展改革委、市财政局印发的《上海市市级建设财力投资补助和贴息项目管理办法》（沪发改规范〔2021〕1号），经评估需继续实施，有效期延长至2031年2月26日。

特此通知。
