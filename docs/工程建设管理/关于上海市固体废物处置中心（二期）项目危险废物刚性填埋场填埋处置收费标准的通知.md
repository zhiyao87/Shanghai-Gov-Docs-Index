# 关于上海市固体废物处置中心（二期）项目危险废物刚性填埋场填埋处置收费标准的通知

上海城投（集团）有限公司：

根据《上海市定价目录》《国家发展改革委关于创新和完善促进绿色发展价格机制的意见》（发改价格规〔2018〕943号）等相关规定，结合项目实际，现将上海市固体废物处置中心（二期）项目危险废物刚性填埋场（以下简称“危险废物刚性填埋场”）填埋处置收费标准通知如下：

一、危险废物刚性填埋场的填埋处置费性质为经营服务性收费，实行政府指导价管理。

二、危险废物刚性填埋场的填埋处置费基准价为4500元/吨，可上浮不超过30%，下浮不限。

三、你公司应在政府指导价范围内确定具体收费标准，同步做好明码标价和收费公示，自觉接受市场监管部门及社会的监督。

上述收费标准自2025年9月1日起试行，试行期两年。

上海市发展和改革委员会

2025年8月19日
