# 上海市住房和城乡建设管理委员会关于批准《文物和优秀历史建筑消防技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《文物和优秀历史建筑消防技术标准》为上海市工程建设规范的通知

沪建标定〔2022〕451号

各有关单位：

由上海建筑设计研究院有限公司、上海市消防救援总队主编的《文物和优秀历史建筑消防技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2410-2022，自2023年2月1日起实施。

本规范由上海市住房和城乡建设管理委员会负责管理，上海建筑设计研究院有限公司负责解释。

特此通知。

2022年9月9日
