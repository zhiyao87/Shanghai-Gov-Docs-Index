# 关于印发《关于进一步加强上海市海洋经济统计工作的实施意见》的通知

关于印发《关于进一步加强上海市海洋经济统计工作的实施意见》的通知

沪海洋〔2025〕146号

市发展改革委、市经济信息化委、市教委、市科委、市交通委、市农业农村委、市文化旅游局、上海海事局、临港新片区管委会、长兴岛管委会，沿海各区海洋局、统计局，重点涉海企业、园区：

为深入贯彻党的二十届三中全会关于“完善促进海洋经济发展体制机制”“健全支撑高质量发展的统计指标核算体系”以及中央财经委员会第六次会议关于“推动海洋经济高质量发展”有关部署要求，进一步完善本市海洋经济统计、调查、核算制度和数据管理、发布、共享机制，切实提高海洋经济运行监测评估能力，助力海洋经济高质量发展，市海洋局、市统计局联合印发《关于进一步加强上海市海洋经济统计工作的实施意见》，请按要求执行。

特此通知。

上海市海洋局

上海市统计局

2025年9月29日
