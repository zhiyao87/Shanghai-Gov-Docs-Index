# 关于印发《关于进一步加强宝山区综合执法队伍建设的实施意见》的通知

现将《关于进一步加强宝山区综合执法队伍建设的实施意见》印发给你们，请遵照执行。

特此通知。

上海市宝山区城市管理行政执法局

2021年8月11日

关于进一步加强宝山区综合执法队伍建设的实施意见

为认真贯彻《宝山区关于完善街镇管理体制整合街镇管理服务资源的实施方案》和《关于进一步加强本市街道乡镇综合执法队伍建设的实施意见》，进一步加强城市管理综合执法工作，提升队伍能力素质和执法水平，现就加强本区综合执法队伍建设提出如下实施意见：

一、指导思想

坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻习近平总书记考察上海重要讲话精神，认真践行“人民城市人民建，人民城市为人民”重要理念，围绕科创宝山赋予城市管理综合执法职责要求，按照行政执法类公务员分类管理相关规定，以提高队伍整体素质为重点，着力打造一支正规化、专业化、职业化执法队伍，为推动我区科创中心主阵地建设提供有力执法保障。

二、建设原则

一是坚持双重管理。在“属、管、用”体制不变的前提下，既要发挥街镇主体责任作用，又要发挥区城管执法局在业务培训、执法办案、队伍建设、工作绩效和作风纪律等方面的监管作用，共同实现条块联系、优势互补。

二是坚持统筹指导。着眼执法队伍长远发展，牢固树立全区“一盘棋”执法理念，建立健全培训、晋升、交流、考核等各项队伍管理制度，确保执法队伍建设规范化、正规化、制度化。

三是坚持实绩导向。以工作实绩为导向，强化考核结果运用，提升城管综合执法实效，提高队伍整体素质。

四是坚持从严监督。加强执法队伍规范化建设，严格监督执法行为规范，切实把从严管理、从严监督贯彻在队伍建设的全过程。

三、基本制度

（一）严格执法人员招录

坚持“凡进必考”原则，将综合执法人员招录工作纳入行政执法类公务员专项招录，实行全市统一的执法人员招录制度，区城管执法局会同各街镇制定招录计划报区委组织部审核，全区统一组织实施面试、体检和考察等工作，重点加强对政治素质和道德品行的考察力度，严把“进口关”。按照基层执法人员缺编情况，统筹调配新进人员，切实提高基层执法人员“进口”质量。

（二）强化执法资格管理

新进执法人员应参加由市公务员局、市司法局、市城管执法局联合组织的初任上岗培训考试，培训考试情况作为试用期满考核内容。经培训考试合格、取得市司法局颁发的《行政执法证》后方可从事执法工作。经补考不合格的，不予办理《行政执法证》。《行政执法证》实行定期换发制度，到期换证人员须通过市城管执法局组织的执法业务轮训和考试。未取得《行政执法证》的人员不得从事执法工作。

（三）落实执法培训考试

根据本市行政执法类公务员队伍能力建设行动计划，按照“入职必训、专业调训、晋级应训”的要求，加大执法人员理想信念、思想作风、执法能力和职业道德等方面的教育培训力度。建立完善区、街镇两级教育培训体系，区城管执法局制定年度教育培训方案，分层分类开展执法人员培训工作，基层各单位要统筹安排执法人员参加培训，组织开展内部学习活动。严格落实培训学时学分管理制度，强化培训考核结果运用，未完成规定的培训学时学分的，当年度考核不得确定为优秀等次。逐步建立执法人员能力等级考试制度，按职级层次分类组织测试，进一步提高执法人员加强业务知识学习的积极性和主动性，能力等级考试不合格的，当年度考核不得确定为优秀等次。

（四）实施定期轮岗交流

推动街镇综合执法人员在全区范围内有序流动，在同一职位工作满5年的主要负责人，在同一职位工作满10年的其他执法人员，应当进行转任交流。区城管执法局在充分听取街镇意见的基础上，制定轮岗交流方案，经区委组织部审核同意后组织实施。各街镇要遵照执行，配合办理轮岗交流手续。执法人员应当服从轮岗交流决定，拒不执行轮岗交流决定的，将视情节给予相应处理。

（五）统筹干部培养使用

在区委组织部统筹指导下，着眼综合执法队伍长远发展，注重加强干部的选拔和培养。区城管执法局要加强后备干部调研，会同街镇建立全区综合执法队伍科级领导干部调研对象名单和优秀青年人才名单。科级领导干部选拔人员范围一般应为调研对象或优秀青年人才。要加强统筹，在全区城管系统范围内择优选拔敢于负责、勇于担当、善于作为、实绩突出的干部，树立鲜明的用人导向。

明确区城管执法局和街镇在干部选拔、干部调整等工作的职责分工。街镇综合行政执法队正科级领导干部的选拔任用，由街镇党（工）委提出启动意见，区城管执法局党组提出初步人选，街镇党（工）委组织开展推荐、考察、测评，根据干部管理权限进行讨论决定和任命；街镇综合行政执法队副科级领导干部的选拔任用，由街镇党（工）委提出动议，书面征求区城管执法局党组意见，街镇党（工）委组织开展推荐、考察、测评，根据干部管理权限进行讨论决定和任命。

各街镇制定行政执法人员职级晋升方案，经区城管执法局党组备案，报区委组织部（区公务员局）审核同意后组织实施。

（六）完善执法绩效考核

区城管执法局要不断完善方式方法，加强对街镇综合行政执法单位工作考核评议，实现绩效考核科学化、标准化。要建立健全考核机制，坚持日常考核与年终考核相结合，坚持定量分析与数据运行相结合，坚持监督检查与社会评价相结合。要合理设置考核指标，围绕依法履职、规范执法、队伍建设、为民服务、系统运用、执法实效与社会宣传等方面，细化量化指标。要注重考核结果运用，充分发挥考核指挥棒、风向标作用，基层综合执法单位考核结果分优秀、良好、一般三个等次，原则上年度考核优秀等次不超过30%。要及时通报反馈，区城管执法局对街镇综合行政执法单位考核结果应及时向区相关部门和街镇通报反馈，并作为评先评优、职级晋升、干部选拔调整的重要依据，年度考核后三名的单位负责人，当年度个人考核一般不得确定为优秀等次。

（七）规范在编在岗管理

按照从严控制、严格程序、规范管理要求，防止随意借用行政执法人员。街镇综合行政执法人员原则上不得外借从事与执法无关的工作，确因工作需要临时借用的，应按规定报批备案，借用期限原则上不超过6个月。街镇综合行政执法人员职务职级、人事关系、组织关系等发生变化的，应及时向区城管执法局报备。

（八）建立条块联席会议

区城管执法局要搭建街镇综合执法联席会议平台，定期组织召开街镇相关负责人联席会议，及时传达市、区对执法队伍建设的相关精神，专题研究执法队伍建设存在的矛盾和问题，商讨干部调整、轮岗交流等事宜，交流党建廉建、队伍建设、执法业务等方面的工作经验。

四、工作要求

（一）落实工作责任

要充分认识城市管理建设和发展需要对加强综合执法队伍建设的紧迫性和重要性，按照职责分工，切实承担起队伍建设责任。区城管执法局要在区委组织部指导下，结合本地区实际情况，研究制定队伍建设的具体方案，强化对街镇综合行政执法人员的指导、培训和监督。街镇应当加强对综合执法队伍领导管理，促进队伍整体素质不断提高。

（二）健全工作机制

区城管执法局要对照本实施意见，结合城管体制改革以来出现问题，研究健全人员招录、教育培训、轮岗交流、选拔晋升、考核评议等制度规范和工作机制，确保队伍建设有章可循，有章可依。

（三）严格制度执行

区城管执法局要细化相关制度配套细则，加大指导力度。各街镇要严格按照行政执法类公务员分类管理相关规定和市区相关制度，规范管理综合执法队伍，严格执行落实制度。
