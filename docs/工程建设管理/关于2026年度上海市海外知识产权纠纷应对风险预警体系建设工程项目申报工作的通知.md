# 关于2026年度上海市海外知识产权纠纷应对风险预警体系建设工程项目申报工作的通知

关于2026年度上海市海外知识产权纠纷应对风险预警体系建设工程项目申报工作的通知

沪知局保〔2026〕5号

各有关单位：

为加强海外知识产权纠纷应对和维权援助服务，建立国际知识产权风险预警和应急机制，根据《国务院关于涉外知识产权纠纷处理的规定》《国家知识产权局 中央宣传部 最高人民法院等9部门关于印发知识产权保护体系建设工程实施方案的通知》要求，我局组织开展2026年度上海市海外知识产权纠纷应对风险预警体系建设工程项目申报工作。现将有关事项通知如下：

一、项目设置

项目一：支持企业开展对相关出海国家或地区海外知识产权侵权风险分析，如FTO专利自由实施分析等。

项目二：支持服务机构为企业（不少于5家）撰写海外知识产权（商标或专利）布局和侵权预警报告。

二、申报对象

项目一：申请人为在本市经营的企业，经营状态正常，信用记录良好，近三年无知识产权领域的违法违规行为。

项目二：申请人为在本市经营的服务机构，包括高校、科研院所、科技情报机构、行业组织、产业园区生产力促进机构、知识产权代理机构、律师事务所以及其他相关服务机构等，拥有专业的知识产权检索、诉讼信息检索、海外信息分析服务的工作团队，经营状态正常，信用记录良好，近三年无知识产权领域的违法违规行为。

三、支持政策

根据《上海市知识产权专项资金管理办法》规定，项目承担单位可享受我局相关经费支持政策，每家不超过30万元。

四、申报要求和程序

（一）申报程序（可选择线下申报或线上申报）

线下申报：申报单位向市知识产权局提交申报表、相关证明材料（一式三份）和电子文件。

线上申报：申报单位通过“一网通办”平台“随申兑”专区搜索“2026年上海市海外知识产权纠纷应对风险预警体系建设工程建设项目”进行线上申报。

（二）申报要求

申报截止时间为2026年6月1日。我局经材料审核、专家评审等程序后，通过上海市知识产权局官网、官微等途径，公示项目申报结果。经公示无异议或异议不成立的，与项目承担单位正式签订项目合同书，并于2027年6月组织对项目成果进行评估验收。
