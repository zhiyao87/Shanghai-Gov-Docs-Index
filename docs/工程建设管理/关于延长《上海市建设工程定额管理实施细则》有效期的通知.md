# 关于延长《上海市建设工程定额管理实施细则》有效期的通知

沪住建规范〔2021〕6号
上海市住房和城乡建设管理委员会
关于延长《上海市建设工程定额管理实施细则》有效期的通知

各有关单位：
经评估，《上海市建设工程定额管理实施细则》（沪建标定〔2016〕384号）需继续实施，有效期延长至2026年6月30日。
特此通知。

二○二一年五月十八日
