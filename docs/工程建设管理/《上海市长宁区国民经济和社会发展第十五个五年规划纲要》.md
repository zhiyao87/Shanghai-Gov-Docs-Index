# 《上海市长宁区国民经济和社会发展第十五个五年规划纲要》

“十五五”时期(2026-2030年)是我国基本实现社会主义现代化夯实基础、全面发力的关键时期，是上海乘势而上的全面发力期、转型升级的攻坚决胜期，也是长宁基本建成具有世界影响力的国际精品城区的关键时期。

《长宁区国民经济和社会发展第十五个五年规划纲要》根据《中共上海市委关于制定上海市国民经济和社会发展第十五个五年规划的建议》和《中共上海市长宁区委关于制定长宁区国民经济和社会发展第十五个五年规划的建议》编制，是指导长宁未来五年发展的宏伟蓝图，是全区人民共同奋斗的行动纲领。

一、发展新阶段新起点

“十四五”时期，长宁区在市委、市政府和区委的坚强领导下，始终坚持以习近平新时代中国特色社会主义思想为指导，面对错综复杂的国际形势和艰巨繁重的改革发展稳定任务，经受住世纪疫情严重冲击，牢记嘱托、勇担使命、克难前行，坚持不懈抓发展、谋改革、惠民生、优治理，“十四五”规划主要目标任务如期实现，各项事业呈现出蓬勃发展的生动局面，具有世界影响力的国际精品城区建设迈出扎实步伐。

(一)发展基础

1.经济实力跨步提升。地区生产总值年均增速位居全市首位，人均GDP和地均GDP分别位列中心城区第二位和第三位。区级一般公共预算收入年均增速达到8.8%。重点产业发展稳中有进，“3+3”重点产业综合税收占全区税收比重超七成。城市数字化转型深入推进，集聚数字经济企业7000余家，综合税收占全区税收比重近六成。“虹桥之源”在线新经济生态园升格为三个市级在线新经济生态园之一。“总部增能”行动深入实施，新增跨国公司地区总部23家。楼宇经济持续发展，税收亿元楼逐年增加，从2020年的30幢增长至40幢。首次诞生税收“百亿楼”，创下全市商务楼宇“亩产奇迹”。东虹桥中心、上海荟聚、晶耀虹桥等一批区位好、品质高的经济载体陆续竣工投入使用，全区新竣工楼宇面积累计达200万平方米，新开工面积累计达140万平方米。

2.改革创新有力推进。全力服务虹桥国际开放枢纽国家战略落地，加快推进虹桥出海企业总部集聚区、虹桥国际低空经济产业园、虹桥国际机器人产业协同创新中心建设，东虹桥片区税收占虹桥国际中央商务区税收比重超过40%，位居四片区首位。“上海硅巷”科创街区建设初显成效，集聚了一批创新型企业，启动了“上海硅巷”高质量孵化器建设。持续迭代推出营商环境“八张特色牌”，获评全国首批、全市唯一的网络市场监管与服务示范区，颁发全国首张外商独资购物中心业态综合许可证，推出全国首个健身行业预付资金公证提存监管平台。深化国资国企改革，推进国资布局优化。拓展提升上海虹桥海外人才一站式服务中心功能，深化人才引进落户审批全程网办。

3.城市更新活力显现。苏州河慢行步道长宁段全线贯通，外环林带生态绿道开放启用，华东政法大学“百年校园”与中山公园“百年公园”融合开放。上生·新所、中环桥下空间、苏河超级管等标志性更新项目持续涌现，愚园路、武夷路分别获评第二批国家级、市级旅游休闲街区。外环抬升工程进入实质性启动阶段，北翟路协和路天桥工程全面完工。架空线入地和杆箱整治累计竣工150.9公里，已竣工道路占比居全市第一。海绵城市建设不断深化，36个河道断面水质年均值达到或优于Ⅲ类水。建成生境花园30座，“绿八乐颐生境花园”入选联合国生物多样性100+全球典型案例名单。推动低碳发展实践区、低碳社区创建，电动汽车共享充电小区建设数量居全市前列。

4.民生服务优质均衡。获评全国义务教育优质均衡发展区，整区推进教育数字化转型入选教育部优秀案例，上外附中国际部长宁校区投入使用。获评全国健康城市建设样板区，区妇幼保健院改扩建、光华中西医结合医院异地迁建(一期)将陆续竣工。成功创建成为第四批国家公共文化服务体系示范区，虹桥体育公园、苏州河中山公园游船码头投入使用，娄山关路445弄等项目即将竣工。清池路养老院建设项目完成施工，全区养老床位总数占户籍老年人口比例超过3%，持续位居中心城区首位。实现认知障碍友好社区、就业服务站街镇全覆盖。率先实施社会救助信用告知承诺制，深化救助领域“政策找人”。实现精品小区建设开工全覆盖，实施新式里弄房屋卫生设施改造12.7万平方米，完成既有多层住宅加装电梯超1100台。保障性租赁房源累计筹措建设15000余套、供应10400套，虹桥人才公寓约3600套房源达到可供应条件。

5.城区治理有序推进。新时代“凝聚力工程”内涵持续拓展延伸，全过程人民民主基层实践成果丰硕，长宁实践案例入选中组部全国干部培训教材。深化“一网通办”“一网统管”，推进“升规达标”等惠企利民政策服务“免申即享”，城区生命体征实现“一屏统览”。探索推进“多格合一”网格治理，城区安全韧性不断增强。率先实现优秀级“上海市儿童友好社区示范点”全覆盖。“15分钟社区美好生活圈”建设基本覆盖全区。获评商务部首批“城市一刻钟便民生活圈”试点地区。因地制宜开展“平安屋”“平安商户联盟”建设，基本实现区、街镇、居民区三级综治中心(站)规范化建设，八类刑事案件破案率居全市前列，以满分成绩通过全国心理服务体系建设试点评估。

(二)发展阶段

“十五五”时期在长宁基本建成具有世界影响力的国际精品城区进程中具有承前启后的重要地位。“十五五”时期,长宁将处于经济社会高质量发展巩固提升的关键阶段，更加需要巩固特色优势、破除瓶颈制约、补强短板弱项，推动产业焕新向多核驱动提升，科技创新向起势成势提升，城市更新向有机生长提升，公共服务向可感可及提升，社会治理向共治共享提升，不懈努力、接续奋斗，推动事关长宁现代化全局的战略任务取得重大突破，为基本建成具有世界影响力的国际精品城区奠定更加坚实的基础。

(三)发展环境

当前和未来一段时期，世界变乱交织、动荡加剧，大国博弈更加复杂激烈，大国关系牵动国际形势，国际形势演变深刻影响国内发展。

从全国看，我国发展处于战略机遇和风险挑战并存、不确定难预料因素增多的时期，但经济基础稳、优势多、韧性强、潜能大，长期向好的支撑条件和基本趋势没有变，将持续成为世界经济的重要稳定器和动力源。

从上海看，龙头带动优势、改革开放优势、科技和人才优势、治理现代化优势更加彰显，“五个中心”建设加速推进，城市能级和核心竞争力不断提升，但也在新旧动能转换、超大城市治理等方面持续承压。

从长宁看，虹桥国际开放枢纽国家战略加持赋能，“数字长宁”先发优势持续显现，千亿级产业集群初具规模，数智化绿色化转型和企业“走出去”布局发展趋势带来新的机遇。同时，也要清醒认识城区发展面临的重大挑战，“十四五”期间主要经济指标高速增长带来的高基数压力愈加明显，新旧动能转换面临阵痛，跨境电商、产品贸易和货运代理等外向型经济受到国际经贸斗争波及影响，城区空间载体存量更新不足、增量拓展有限，人口结构变化特别是老龄化、少子化趋势对社会治理模式和公共服务供给结构不断提出新的课题。

面向“十五五”，全区要深刻领悟“两个确立”的决定性意义，增强“四个意识”、坚定“四个自信”、坚决做到“两个维护”，切实把思想和行动统一到党中央、市委和区委对国内外形势的基本判断上来，紧扣“虹桥源、国际范、数字化、精品型”的城区特质，始终保持战略定力，增强必胜信心，积极识变应变求变，集中力量办好自己的事，在多重目标中保持动态平衡，在多重约束中寻求最优突破，以自身发展的确定性对冲外部环境的不确定性，以自身努力的持续性牢牢掌握未来发展的主动权。聚焦“虹桥源”，加强政策集成和制度创新，推动枢纽功能完善、高端产业集聚、产城融合高效，让“最虹桥”品牌不断激发新势能。聚焦“国际范”，充分发挥跨国公司地区总部云集、海内外高层次人才集聚、国际人文交流汇聚优势，提升软实力、辐射力、影响力，让长宁做大朋友圈、享誉海内外。聚焦“数字化”，持续打响“数字长宁”品牌，做大数字经济规模，深化数据要素市场化配置改革，让数据价值得到最大限度释放。聚焦“精品型”，深入推进全景深度城市更新，精心勾勒生产、生活、生态各界面，让人与城和谐共生、相互成就。

二、指导思想和发展蓝图

(一)指导思想和基本原则

“十五五”时期，长宁区经济社会发展的指导思想是：坚持马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观，全面贯彻习近平新时代中国特色社会主义思想，深入贯彻党的二十大和二十届历次全会精神，全面落实习近平总书记考察上海重要讲话精神，完整准确全面贯彻新发展理念，围绕推动高质量发展首要任务和构建新发展格局战略任务，以经济建设为中心，坚持稳中求进工作总基调，以科技创新为引领，以改革创新为动力，以国家重大战略为牵引，以城市治理现代化为保障，深入践行人民城市理念，巩固提升“四大特质”，加快实施“四大战略”，奋力打造“大虹桥东引擎”，建强“大都市西门户”，推动经济实现质的有效提升和量的合理增长，确保加快建成具有世界影响力的国际精品城区取得实质性进展，在推进中国式现代化中充分彰显长宁担当。

基本原则是：

——坚持党的全面领导。坚决维护党中央权威和集中统一领导，提高党把方向、谋大局、定政策、促改革能力，把党的领导贯穿经济社会发展各方面全过程，推动党中央和市委决策部署落地落实、见行见效，为长宁现代化建设提供根本保证。

——坚持战略牵引。以“四个放在”为战略基点，服务上海“五个中心”建设，深层次融入长三角一体化发展，全方位对接落实虹桥国际开放枢纽建设，始终从战略所指、区域所能，思考和谋划长宁发展、增强和创造长宁优势，推动城区能级和核心竞争力全面提升。

——坚持高质量发展。以科技为第一生产力，以人才为第一资源，以创新为第一动力，统筹扩大内需和深化供给侧结构性改革，促进各类先进生产要素向发展新质生产力集聚，不断为区域高质量发展注入新动能、塑造新优势，促进经济结构优化升级。

——坚持全面深化改革。对标最高标准、最好水平，聚焦制约高质量发展的体制机制障碍，全方位大力度推进首创性改革、引领性开放，协同促进高质量“引进来”、高水平“走出去”，坚持有效市场和有为政府相结合，打造市场化法治化国际化一流营商环境，持续增强发展动力和社会活力。

——坚持人民城市理念。深入践行全过程人民民主，尊重人民主体地位，坚持把最好的资源留给人民、用优质的供给服务人民，注重在发展中保障和改善民生，在满足民生需求中拓展发展空间，推动经济和社会协调发展、物质文明和精神文明相得益彰，让现代化建设成果更多更公平惠及全体人民。

——坚持系统观念。加强前瞻性思考、全局性谋划、战略性布局、整体性推进，把握好全局和局部、当前和长远、宏观和微观的关系，进一步统筹各方面工作、凝聚各方面力量。统筹发展和安全，在发展中固安全，在安全中谋发展，有效防范化解各类风险，增强经济和社会韧性，以新安全格局保障新发展格局。

(二)发展目标和主要指标

“十五五”时期，长宁区经济社会发展的奋斗目标是：到2030年，服务“五个中心”和虹桥国际开放枢纽建设取得新成效，科技创新和产业创新深度融合迈出新步伐，全面深化改革开放实现新突破，人民城市建设和城区治理现代化结出新成果，城区能级和核心竞争力跃上新台阶，加快建成具有世界影响力的国际精品城区取得实质性进展。

——经济实力进一步提升。经济增长保持在合理区间，全要素生产率稳步提升，内需拉动经济增长主动力作用持续增强，科技创新和产业创新深度融合，主导产业、新兴产业、未来产业竞相成长，产业集群核心竞争力显著增强，新质生产力发展壮大，现代化产业体系加快构建、动能更强、韧性更足。

——改革攻坚进一步突破。紧抓长三角一体化发展、虹桥国际开放枢纽建设等国家战略重大机遇，围绕产业所向、企业所需、人才所盼的改革更加精准聚焦，制度型创新持续涌现，营商环境更加优化，经营主体充满活力，经济社会发展的改革动力源源不断、澎湃强劲。

——民生福祉进一步增进。基本公共服务全方位提升、全领域可及、全龄段可感，实现更充分的高质量就业，教育卫生资源供给更加优质，幸福养老体系更加健全，群众住有所居、居有所安，数字化、品质化、个性化的公共服务供给丰富多样，人民群众有更多获得感、幸福感、安全感。

——人文魅力进一步彰显。文化自信更加坚定，主流思想舆论不断巩固壮大，社会主义核心价值观广泛践行，城市精神和城市品格大力弘扬，文化体育设施配置更加完备，文化产业体系和发展生态健全完善，具有长宁特色的文化品牌和标识更为鲜明，城区文化软实力更具魅力。

——环境品质进一步提高。生产空间、生活空间、生态空间布局更加优化、利用更加高效，城市更新取得积极突破，重点区域形态、功能和品质进一步优化，生态环境和人居环境进一步改善，绿色生产生活方式基本形成，主要污染物排放总量持续减少，生态系统多样性稳定性持续性不断提升。

——治理效能进一步增强。区域国家安全体系和能力建设进一步加强，重点领域风险得到有效防范化解，公共安全治理水平明显提高，共建共治共享的社会治理格局更加完善，更高水平平安长宁建设扎实推进，全过程人民民主充分赋能基层城区治理体系和治理能力现代化。

接续奋斗，到2035年长宁经济实力、科创动力、核心竞争力和国际影响力大幅提升，社会主义现代化建设取得显著成就，基本建成具有世界影响力的国际精品城区，成为新时代人民城市建设的生动范例。

(三)发展战略

(三)以扩大贸易开放度为重点服务国际贸易中心建设

聚焦推动贸易新业态新模式领域制度型开放，持续优化贸易制度环境，不断拓展贸易发展空间。大力发展服务贸易，积极推动医疗、法律、文化等领域开放发展。创新发展数字贸易，推动数字产品、数字服务出口，培育数字订购、数字内容交付、数据加工等新增长点，支持跨境电商等新业态新模式发展，集聚更多数字贸易经营主体。推动离岸贸易优惠政策落地，支持离岸转手买卖、全球采购、跨境分拨等离岸贸易做大规模。加快发展绿色贸易，支持绿色低碳产品和技术进出口。优化升级货物贸易，加强品牌、质量和渠道建设。推动展贸联动发展，积极承接中国国际进口博览会溢出效应，持续放大“6天+365天”交易服务平台功能。

十、持续建设生态宜居的美丽城区

以碳达峰碳中和为牵引，协同推进降碳、减污、扩绿、增长，持续深入打好污染防治攻坚战，高标准巩固“无废城市”建设成果，全面推进绿色低碳、环境优美、生态宜居、安全健康、智慧高效的美丽长宁建设，全力打造美丽城市示范标杆。

(一)积极稳妥推进和实现碳达峰

推动能耗双控向碳排放双控制度转变，加快生产生活方式全面绿色转型，推进重点用能单位节能降碳管控，提升建筑领域节能降碳水平，确保2030年前实现碳达峰。

1.健全低碳管理体系。全面落实碳排放总量和强度双控制度。支持双碳服务、能源替代、绿色智算等领域发展，加强节能降碳技术和产品研发与推广应用。鼓励引导重点单位和楼宇加强节能管理、碳排放核算和碳减排路径研究。健全绿色低碳专业服务体系，加快开展产品碳足迹管理和标识应用。完善能耗和碳排放智慧管理体系，持续提升能碳数字管理水平。

2.推动重点领域低碳转型。推动能源消费绿色化低碳化，扩大可再生能源消纳消费。稳步提高绿色能源比重，提高终端用能电气化水平。加强智能电网和虚拟电厂建设，提升电网安全稳定性。深化CN100建筑碳中和倡议实施。深化既有建筑节能改造，落实绿色建筑星级标准，推动新建建筑全面执行超低能耗标准。加快发展绿色低碳产业。

3.推广绿色生活方式。深入推进生活垃圾源头减量和资源化利用，完善垃圾分类治理体系。优化可回收物“点、站、场”体系建设，完善可回收物中转站建设布局，提高中转站、集散场运营管理水平。加快推进区废弃物综合处置中心升级改造。健全绿色消费激励机制，鼓励汽车、家电、耐用消费品以旧换新，鼓励企业开发碳普惠应用场景。布局绿色交通基础设施，引导居民低碳出行。

(二)持续改善生态环境

全面落实精准科学依法治污，更加注重源头治理，强化减污降碳协同、多污染物控制协同、区域治理协同，以更高标准深入打好蓝天、碧水、净土保卫战。

1.稳步提升大气环境质量。以细颗粒物控制为主线，氮氧化物和挥发性有机物为主攻方向，协同控制臭氧污染。深入推进移动源清洁化行动，实施新阶段移动源排放标准和油品标准，推进加油站三次油气回收治理。加快推进剩余燃油锅炉清洁能源替代。持续开展重点企业挥发性有机物排放综合治理，全面实施低挥发性有机物含量物料推广等源头替代工程。加强扬尘源、餐饮油烟全方位全过程精细化管控。

2.全面改善水生态环境。深入推动水生态环境保护，实现水质趋稳、水生态扩面提标。持续推进入河排污口分类整治、长效管理。加强排水系统运维管理和雨污混接排查整治。严格落实河长制湖长制，系统实施河道水质提升和生态治理，试点开展河道清澈度示范建设，推进野奴泾等河道生态修复与环境提升。

3.强化土壤和固废环境管理。以防新增、控风险、去存量为目标，开展土壤污染源头防控。严格重点建设用地再开发利用准入管理，推行“净土收储”“净土供应”等全过程土地管控机制，强化企业土壤环境管理。持续深化“无废城市”建设，实施固体废物综合治理行动，加强建筑垃圾处置利用。加强环境风险防控，深入推进新污染物治理。对照生态环境标准，完善监管、监测、执法等综合管理体系。

16.“三乱”治理(第56页)：指沿街公共场所乱张贴、乱刻画、乱涂写现象治理。治理范围主要包括：市政道路沿线建筑物、构筑物三米线以下立面，市政道路、人行道路面，以及行道树、废物箱、各类箱杆表面等。

17.公安新质战斗力(第59页)：在党的绝对领导下，以科技创新为主导，集多种能力于一体的信息化条件下的战斗力质态，核心是实现“专业+机制+大数据”的警务生态改革。

18.多格合一(第4页、第60页)：通过完善网格划分标准，将城运网格、警务网格、综治网格等多种网格进行“合一”，在不打破原有管理执法运行逻辑、不改变原有权责归属的前提下，全面整合街镇现有力量，推进条条协同、条块联动和政社互动，推动从管理向治理的实质性提升。
