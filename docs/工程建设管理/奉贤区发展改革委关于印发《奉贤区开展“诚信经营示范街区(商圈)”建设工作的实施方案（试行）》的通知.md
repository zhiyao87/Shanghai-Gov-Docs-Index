# 奉贤区发展改革委关于印发《奉贤区开展“诚信经营示范街区(商圈)”建设工作的实施方案（试行）》的通知

各街镇：

为弘扬中华民族诚实守信的传统文化，践行社会主义核心价值观，引导市场主体诚信经营，规范市场经济秩序、营造诚实守信的良好社会环境，助力营商环境优化和文明城区创建工作，现将《奉贤区开展“诚信经营示范街区(商圈)”建设工作的实施方案(试行)》印发给你们，请遵照执行。

特此通知。

2025年4月14日

奉贤区开展“诚信经营示范街区(商圈)”

建设工作的实施方案(试行)

为弘扬中华民族诚实守信的传统文化，践行社会主义核心价值观，引导市场主体诚信经营，规范市场经济秩序、营造诚实守信的良好社会环境，助力营商环境优化和文明城区创建工作，结合我区实际，特制定本实施方案,具体方案如下：

一、指导思想

全面贯彻习近平新时代中国特色社会主义思想和党的二十大及二中、三中全会精神，以“诚信经营”为主题，加强诚信宣传教育，切实维护消费者合法权益，规范市场主体经营行为，建立公平、公正的市场竞争环境和放心、安全的市场消费环境。通过创建活动，选树一批诚实守信、文明经营、管理规范的先进典型，充分发挥示范引领作用，切实推动企业、个体工商户诚信经营，充分发挥信用在营造公平高效的营商环境、增强街区(商圈)经济活力中的积极作用。

二、工作目标

加强信用数据应用共享。整合街区(商圈)信用信息化系统，建立商户信用档案库，公共信用信息与市场信用信息共享融合，信用监测预警产品精准高效，数字化试点场景创新突破。

提升信用监管服务效能。街区(商圈)管理部门协同联动，在市场准入经营、消费者服务、信用承诺、信用监管等方面创新一批守信激励的“信用+”便利化举措，探索完善营商环境体制机制，让市场主体和人民群众的获得感显著提升。

树立街区(商圈)诚信品牌形象。“诚信示范商户”“放心消费单位”、信用评价良好的商户比例持续增加，售后服务机制、投诉处理机制等消费者权益保护坚实有力，市场消费环境更加“安心、放心、舒心”，街区(商圈)品牌形象显著提升，街区(商圈)影响力、吸引力、竞争力进一步增加。

三、工作内容

(一)建立健全街区(商圈)商户信用档案。构建“信用+市场”的评价模型，试点开展诚信示范街区(商圈)商户信用评价应用，探索零售企业经营主体的信用码上可见、消费者可以码上维权。

(二)开展信用承诺和规范经营活动。建立商户诚信服务承诺制度，引导商户签订《放心消费创建承诺书》、《主动公示型信用承诺书》和《行业自律承诺书》等，并将签订情况及时上传至“奉贤区公共信用信息服务平台”，督促商户严格遵守相关要求，在街区(商圈)形成“消费者至上、放心消费、诚信兴商”的良好市场环境。

(三)构建“诚信自律”商户自治机制。以街区(商圈)商户自治管理为前提，建立诚信示范街区(商圈)诚信自律“伙伴”关系，加强行业诚信自律，引导街区(商圈)商户自觉维护公平竞争的市场秩序。推举带头“小伙伴”负责监督巡查街区(商圈)各商户的经营规范、门前三包、垃圾分类等工作，各商户则主动配合相关要求，做到诚信经营、规范经营。

(四)落实“柔性执法”政府监管。持续落实“轻微免罚”制度，对街区(商圈)商户推行容错机制，进一步提升行政执法质效。试点轻微违法行为免于处罚信用承诺制，形成“以改代罚”柔性执法导向。持续开展分级分类监管，扩大“无事不扰”远距离监管试点企业范围，结合“双随机、一公开”实施差异化监管，联动开展“一业一查”综合监管。

(五)强化诚信宣传掘诚信亮点。进一步开展形式多样的宣传活动，充分利用现有的电子宣传屏或街道小景等空间，布置“诚信示范街区(商圈)”“放心消费”等宣传内容，营造浓厚的宣传氛围。借助“五五购物节”、“诚信兴商宣传月”等活动开展街区(商圈)诚信宣传。结合“诚信计量”示范建设等工作，扩大诚信街区(商圈)影响力。培育街区(商圈)诚信标杆商户，鼓励企业创建自身诚信品牌，共塑诚信形象。

四、工作要求

(一)强化组织领导

各街镇应建立诚信示范街区(商圈)建设推进工作机制，细化部门职责分工，推动落实各项工作任务。区信用办应加强对街区(商圈)建设的统筹协调和跟踪指导，实施阶段评价。

(二)完善制度标准

各街镇应强化街区(商圈)信用管理制度保障，完善信用目录清单管理。研究制定街区(商圈)商户信用评价规范及诚信商户的评选标准。

(三)加大信用宣传

区、镇两级要加强与各媒体的沟通、协调与合作，发挥各类主流媒体和自媒体作用，增强正面宣传效果，促使广大企业、个体工商户牢固树立守信光荣、失信可耻、信用无价、诚信是金的价值观，引领社会文明诚信风尚。

(四)加强跟踪评估

围绕完善的信用管理制度、健全的信用数据体系、完备的信用管理系统、科学的信用评价模型以及丰富的诚信宣传教育等五大维度，定期跟踪评估诚信示范建设区域服务经济发展和社会治理的效能。结合评估结果，持续完善改进工作方式，不断增强市场主体和人民群众对信用建设的获得感。
