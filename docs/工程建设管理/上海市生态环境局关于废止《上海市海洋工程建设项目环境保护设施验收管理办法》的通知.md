# 上海市生态环境局关于废止《上海市海洋工程建设项目环境保护设施验收管理办法》的通知

各有关单位：

根据《上海市行政规范性文件管理规定》相关要求，经研究，现决定对《上海市海洋工程建设项目环境保护设施验收管理办法》（沪环规〔2020〕7 号）予以废止，废止文件自本通知印发之日起停止执行。
