# 关于印发《宝山区交通强区建设实施方案（2023-2035年）》的通知

各相关单位：

根据上海交通强市建设领导小组办公室印发的《关于推进交通强区（交通强市建设先行示范区）创建的通知》（沪交强市办〔2023〕1号）文件精神，我委拟制了《宝山区交通强区建设实施方案（2023-2035年）》，已报上海交通强市建设领导小组办公室完成行业审核，现印发给你们。

特此通知。

上海市宝山区交通委员会

2024年1月18日
