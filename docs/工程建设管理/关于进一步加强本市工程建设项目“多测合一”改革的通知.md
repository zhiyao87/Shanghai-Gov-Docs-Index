# 关于进一步加强本市工程建设项目“多测合一”改革的通知

各区规划资源、建设、交通、绿化市容、民防、房屋管理部门，各有关单位:

本市自2018年开展“多测合一”改革工作以来，深入贯彻落实党中央、国务院关于深化“放管服”改革优化营商环境的部署要求，各相关部门协同推进，在减少重复测绘、减轻企业负担、提高工作效率等方面取得了积极成效。为进一步深化“多测合一”改革，推动解决当前改革中存在的问题，根据《国务院关于开展营商环境创新试点工作的意见》《上海市营商环境创新试点实施方案》和自然资源部关于工程建设项目“多测合一”改革的工作要求，依据《中华人民共和国测绘法》《测绘资质管理办法》《上海市测绘地理信息行业信用管理办法》等法律法规，结合本市实际，现就进一步加强本市工程建设项目“多测合一”改革的有关工作通知如下：

一、优化整合测绘事项

按照“同一标的物只测一次”的原则，分阶段整合规划、土地、房产、交通、绿化、民防、消防等测绘测量事项，整合后工程建设项目审批全流程保留3个测绘事项，即立项、用地、规划许可阶段的土地勘测定界；施工许可阶段的开工放样复验检测；竣工验收阶段的“多测合一”（含规划资源验收测绘、机动车停车场（库）测量、绿地面积测量、民防工程面积测绘、消防测量和房产测绘）。

每个阶段测绘事项委托一次，形成一份测绘成果，后阶段应充分利用前阶段形成的用地范围、界址点等测绘成果，避免对同一标的物重复测绘，发生变化的可以进行补充测绘。（责任部门：市规划资源局，市住房城乡建设管理委，市交通委，市绿化市容局，市民防办，市房屋管理局，市道路运输局）

二、逐步扩大改革范围

严格落实《关于进一步深化“多测合一”改革的若干措施》（沪规划资源调〔2021〕97号），推进市政交通基础设施场站工程施行“多测合一”。同时，研究交通线性工程“多测合一”实施路径，探索推进线性工程“多测合一”试点。配合“一证多验”改革优化“多测合一”竣工验收成果。（责任部门：市规划资源局，市交通委，市住房城乡建设管理委，市绿化市容局，市民防办，市房屋管理局）

切实推动房产测绘改革落地，所有实施竣工验收项目的房产测绘工作统一按“多测合一”要求开展，确保“测”“算”工作的可靠衔接。测绘服务机构应严格按照“多测合一”技术标准，出具包含房产平面测量在内的“多测合一”成果，确保成果真实准确。房屋调查机构应基于“多测合一”成果进行房屋权属调查和产权面积计算工作，不得另行开展房产平面测量并收取房产平面测量或房屋实地勘丈的测绘费用。（责任部门：市房屋管理局，市规划资源局）逐步扩大“测算合一”适用的建筑工程项目范围，从厂房、仓储等产业类项目扩大到不涉及产权分割和共有面积分摊的行政办公、文化教育、体育卫生、会展等自持的公共建筑工程项目。（责任部门：市规划资源局，市房屋管理局）

三、加快地方标准编制

在国家和行业标准的框架下，规划资源、住房建设、交通、绿化市容、民防、房屋等管理部门应结合管理实际统一相关技术标准，完成上海市工程建设规范《建筑工程“多测合一”技术标准》编制工作。（责任部门：市规划资源局，市住房城乡建设管理委，市交通委，市绿化市容局，市民防办，市房屋管理局，市道路运输局）

积极推动“多测合一”成果标准与基于地理实体的全息测绘标准相互衔接，完善基于“多测合一”的基础地形实时更新机制，探索基于“多测合一”的三维模型动态更新。（责任部门：市规划资源局）在此基础上进一步研究交通线性工程“多测合一”技术标准。（责任部门：市规划资源局，市交通委，市民防办）

四、推动成果共享互认

按照“同一测绘成果只提交一次”的目标，承担“多测合一”项目的测绘服务机构应当按要求向市规划资源管理部门汇交符合“多测合一”技术标准的测绘成果资料，市规划资源管理部门将“多测合一”成果数据及报告实时推送市大数据中心数据中台，加强与市工程建设项目审批管理系统信息共享。（责任部门：市规划资源局）

市、区住房建设、交通、绿化市容、民防、房屋管理部门在工程建设项目竣工验收中应通过市大数据中心在线调取“多测合一”成果数据和报告，不得收取线下报告、单项报告，不得额外增加测绘要求。（责任部门：市住房城乡建设管理委，市交通委，市绿化市容局，市民防办，市房屋管理局，市道路运输局）

五、激发市场主体活力

按照“非禁即入”的原则，建立“多测合一”服务机构名录。持有规划资源管理部门颁发的测绘资质证书，且具备工程测量、界线与不动产测绘专业类别的测绘服务机构自动纳入名录，并实行动态管理。测绘服务机构应在测绘资质等级许可的作业限制范围内从事测绘活动。

落实自然资源部关于“开放市场，促进公平”的有关要求，支持具备资质条件的外省市测绘单位，通过“一网通办”完成来沪测绘单位备案后，动态进入本市“多测合一”服务机构名录。（责任部门：市规划资源局）

六、强化成果质量监管

测绘服务机构应严格按照“多测合一”技术标准出具符合要求的“多测合一”成果，保证其完成的“多测合一”成果数据及报告的真实性和准确性，对测绘成果质量负责，并承担相应法律责任。任何单位不得以任何理由要求测绘服务机构伪造、篡改测绘成果。因建设单位提供的基础材料不实，产生质量问题的，由建设单位承担相关法律责任。

市规划资源管理部门联合各相关管理部门，按照“双随机、一公开”监管模式，持续加大“多测合一”成果质量监督检查力度。加快测绘行业信用体系建设，逐步构建守信激励和失信惩戒机制。对纳入“多测合一”名录的测绘服务机构和从业人员实行信用分级分类管理，建立信用档案。对伪造篡改成果、测绘成果质量不合格的测绘服务机构，按照规定记入严重不良信息，责令限期整改，整改期间移出名录；情节严重的，依法予以处罚。（责任部门：市规划资源局，市住房城乡建设管理委，市交通委，市绿化市容局，市民防办，市房屋管理局，市道路运输局）

七、加强部门统筹协调

规划资源、住房建设、交通、绿化市容、民防、房屋等管理部门应当切实加强组织协调，落实部门责任，加强对本系统工作推进情况的指导和监督，将“多测合一”政策执行情况纳入各系统区级管理部门年度综合考评内容，确保改革落地。

各有关管理部门应当加强工作协同，按各自职责加大对测绘服务机构测绘能力的培扶，及时研究解决改革中出现的新情况新问题，持续提升企业获得感，服务经济社会高质量发展。（责任部门：市规划资源局，市住房城乡建设管理委，市交通委，市绿化市容局，市民防办，市房屋管理局，市道路运输局）
