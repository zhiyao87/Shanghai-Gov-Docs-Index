# 关于下达本市2026年节能减排专项资金和超长期特别国债资金安排计划（第十一批）的通知

市商务委：

你委报来的资金使用计划申请函（沪商市场〔2026〕187号）已收悉。经研究，现将资金安排计划下达给你们，共3项，安排市节能减排专项资金4167.759171万元，2026年超长期特别国债12948.9052万元。有关事项通知如下：

一、安排计划

1.按照《2026年上海市汽车以旧换新补贴政策实施细则》（沪商市场〔2026〕24号）规定，安排经审核通过的2026年第七批934人次汽车报废更新补贴资金，由2026年超长期特别国债安排1418.6067万元。

2.按照《2026年上海市汽车以旧换新补贴政策实施细则》（沪商市场〔2026〕24号）规定，安排经审核通过的2026年第七批8962人次汽车置换更新补贴资金，由2026年超长期特别国债安排11530.2985万元。

3.按照《上海市可再生能源和新能源发展专项资金扶持办法（2020版）》（沪发改规范〔2020〕7号）和《上海市可再生能源和新能源发展专项资金扶持办法》（沪发改规范〔2022〕14号）规定，安排经审核通过的2026年第一批9075个可再生能源和新能源项目补贴资金，由市节能减排专项资金安排4167.759171万元。

二、有关要求

请根据上述资金安排计划向市财政局申请拨付资金，并严格按照相关管理办法和实施细则的规定，合理规范使用各项资金，确保资金使用的公开、公正和公平，进一步提高资金使用效率。

特此通知。
