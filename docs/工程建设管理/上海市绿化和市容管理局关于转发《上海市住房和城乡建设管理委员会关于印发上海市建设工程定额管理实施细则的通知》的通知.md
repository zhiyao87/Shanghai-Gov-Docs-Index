# "上海市绿化和市容管理局关于转发《上海市住房和城乡建设管理委员会关于印发上海市建设工程定额管理实施细则的通知》的通知"



沪绿容〔2016〕412号
各有关单位：
为提高绿化市容行业标准定额管理水平，促进绿化市容建设和养护作业工程管理科学化、规范化、市场化，现将《上海市住房和城乡建设管理委员会关于印发上海市建设工程定额管理实施细则的通知》（沪建标定〔2016〕384号）转发给你们，请结合工作实际，认真贯彻执行。在贯彻实施中若有意见和建议，请及时反馈市局科技信息处。
联系人：陈立民  52567168
