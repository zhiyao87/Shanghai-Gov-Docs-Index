# 上海市住房和城乡建设管理委员会关于批准《城市灾害损失评估技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《城市灾害损失评估技术标准》为上海市工程建设规范的通知

沪建标定〔2021〕556 号

各有关单位：

由上海市防灾救灾研究所和上海市岩土工程检测中心主编的《城市灾害损失评估技术标准》，经审核，现批准为上海市工程建设规范，统一编号为 DG/TJ08-2383-2021，自 2022年2月1日起实施。

本规范由上海市住房和城乡建设管理委员会负责管理，上海市防灾救灾研究所负责解释。

特此通知。

2021年9月3日
