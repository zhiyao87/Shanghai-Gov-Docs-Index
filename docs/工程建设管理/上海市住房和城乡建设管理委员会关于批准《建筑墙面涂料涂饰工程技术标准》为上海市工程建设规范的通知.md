# 上海市住房和城乡建设管理委员会关于批准《建筑墙面涂料涂饰工程技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《建筑墙面涂料涂饰工程技术标准》为上海市工程建设规范的通知

沪建标定〔2021〕559号

各有关单位：

由上海市建筑科学研究院有限公司主编的《建筑墙面涂料涂饰工程技术标准》，经审核，现批准为上海市工程建设规范，统一编号为 DG/TJ08-504-2021，自2022年2月1日起实施。 原《外墙涂料工程应用技术规程》（DG/TJ08-504-2014）同时废止。

本规范由上海市住房和城乡建设管理委员会负责管理，上海市建筑科学研究院有限公司负责解释。

特此通知。

2021年9月3日
