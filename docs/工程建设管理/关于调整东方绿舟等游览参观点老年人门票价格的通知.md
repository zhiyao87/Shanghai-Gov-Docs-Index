# 关于调整东方绿舟等游览参观点老年人门票价格的通知

各有关游览参观点运营管理单位：

为不断提升本市为老服务水平，更好满足老年人对美好生活的向往，根据《上海市定价目录》《上海市游览参观点门票价格管理办法》等规定，现就调整东方绿舟等游览参观点老年人门票价格有关事项通知如下：

一、自2022年9月1日起，东方绿舟等11家政府指导价管理的游览参观点（名单见附件）对持有效身份证件的65周岁及以上老年人实行免费开放。对60周岁（含）至65周岁以下老年人继续执行现行门票价格优惠政策。

二、有关游览参观点要认真开展准备工作，在扎实做好疫情防控的同时，努力提高运营管理水平，并严格落实明码标价规定。
