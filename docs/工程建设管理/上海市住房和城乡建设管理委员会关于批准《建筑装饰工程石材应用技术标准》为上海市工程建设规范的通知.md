# 上海市住房和城乡建设管理委员会关于批准《建筑装饰工程石材应用技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《建筑装饰工程石材应用技术标准》为上海市工程建设规范的通知

沪建标定〔2025〕11号

各有关单位：

由上海石材行业协会主编的《建筑装饰工程石材应用技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2134-2024，自2025年7月1日起实施。原《建筑装饰工程石材应用技术规范》DG/TJ08-2134-2013同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海石材行业协会负责解释。

特此通知。

2025年1月8日
