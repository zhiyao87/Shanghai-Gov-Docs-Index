# 上海市发展和改革委员会、上海市民政局、上海市市场监督管理局关于延长《上海市养老机构服务收费管理办法》有效期的通知

各区发展改革委、民政局、市场监管局，各有关单位：

市发展改革委、市民政局、市市场监管局于2021年4月22日联合印发的《上海市养老机构服务收费管理办法》（沪发改规范〔2021〕3号），经评估需继续实施，有效期延长至2031年5月31日。

特此通知。

上海市民政局

上海市市场监督管理局
