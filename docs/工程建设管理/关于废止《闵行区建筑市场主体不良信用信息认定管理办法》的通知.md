# 关于废止《闵行区建筑市场主体不良信用信息认定管理办法》的通知

关于废止《闵行区建筑市场主体不良信用信息认定管理办法》的通知

各有关单位：
根据《上海市行政规范性文件管理规定》《闵行区人民政府重大行政决策程序规定》《闵行区行政规范性文件管理办法》等规定，在对现行有效的区建设管理委规范性文件开展全面清理评估的基础上，经集体审议，《闵行区建筑市场主体不良信用信息认定管理办法》（闵建管规〔2022〕2号）即日起废止。
特此通知。

上海市闵行区建设和管理委员会
2025年7月9日
