# 上海市交通委员会关于转发《交通运输部关于加强交通运输安全生产标准化建设的指导意见》的通知

市道路运输局，各区交通行政管理部门，委、局所属相关单位：

现将《交通运输部关于加强交通运输安全生产标准化建设的指导意见》转发给你们，请认真贯彻落实，及时将文件精神传达至管辖企业，加强对企业开展安全生产标准化工作的宣传引导、监督检查。

特此通知。
