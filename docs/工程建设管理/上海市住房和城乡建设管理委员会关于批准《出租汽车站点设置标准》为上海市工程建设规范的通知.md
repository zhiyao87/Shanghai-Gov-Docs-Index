# 上海市住房和城乡建设管理委员会关于批准《出租汽车站点设置标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《出租汽车站点设置标准》为上海市工程建设规范的通知

沪建标定〔2023〕229号

各有关单位：

由上海城市交通设计院有限公司主编的《出租汽车站点设置标准》，经我委审核，现批准为上海市工程建设规范，统一编号为 DG/TJ08-2108-2023，自2023年11月1日起实施。原《出租汽车站点设置规范》DG/TJ08-2108-2012同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海城市交通设计院有限公司负责解释。

2022年5月9日
