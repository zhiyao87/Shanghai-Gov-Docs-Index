# 关于转发《国家发展改革委关于规范高效做好基础设施领域不动产投资信托基金（REITs）项目申报推荐工作的通知》的通知

各区发展改革委，临港新片区管委会：

为进一步提升基础设施领域不动产投资信托基金（REITs）项目申报推荐质量和效率，促进基础设施REITs市场平稳健康发展，近期，国家发展改革委印发《关于规范高效做好基础设施领域不动产投资信托基金（REITs）项目申报推荐工作的通知》（发改投资〔2023〕236号，以下简称《通知》），就认真做好基础设施REITs项目前期培育、合理把握项目发行条件、切实提高申报推荐效率等方面提出相关要求。现将《通知》转发你单位，并就进一步做好基础设施REITs相关工作通知如下：

一、继续加强项目储备管理

《通知》提出“优先支持百货商场、购物中心、农贸市场等城乡商业网点项目，保障基本民生的社区商业项目发行基础设施REITs”。请各区发展改革委、临港新片区管委会会同国资、商务等部门，积极梳理辖内存量消费基础设施项目，加强项目储备管理，并广泛宣传、动员，引导推动符合条件的企业将消费基础设施资产通过REITs方式盘活。

同时，结合此次《通知》明确的项目收益、规模等方面要求，继续在园区基础设施、保障性租赁住房、仓储物流等重点领域，做好梳理筛选资产、完善合规手续、解决难点问题等项目前期培育工作。

二、组织做好部门协调

对于有意向通过基础设施REITs盘活存量资产，且属于REITs支持范围的，请各单位按照《国务院办公厅关于进一步盘活存量资产扩大有效投资的意见》（国办发〔2022〕19号）要求，在依法合规的前提下，积极落实项目盘活条件，重点围绕投资管理手续完善、产权证书办理、土地使用合规、资产转让条件确认等，协调本地区行业管理、自然资源、住房城乡建设、国资等部门对项目发行基础设施REITs予以支持。

三、做好申报试点项目初审

对于项目基本符合基础设施REITs申报条件，且原始权益人向各单位正式报送申报材料的，请各单位根据要求，抓紧对项目权属情况、依法依规取得固定资产投资管理相关手续情况、项目持续健康运营保障条件情况等内容进行初审，并及时将相关意见报送我委。
