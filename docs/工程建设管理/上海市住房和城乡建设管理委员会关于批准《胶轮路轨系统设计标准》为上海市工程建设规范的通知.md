# 上海市住房和城乡建设管理委员会关于批准《胶轮路轨系统设计标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《胶轮路轨系统设计标准》为上海市工程建设规范的通知

沪建标定〔2022〕12号

各有关单位：

由上海市隧道工程轨道交通设计研究院主编的《胶轮路轨系统设计标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2392-2022，自2022年6月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市隧道工程轨道交通设计研究院负责解释。

2022年1月5日
