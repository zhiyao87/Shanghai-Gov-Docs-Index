# 上海市应急管理局关于撤销11家企业二级安全生产标准化等级的通告

上海连成（集团）有限公司等4家企业2023年分别发生一起生产安全死亡事故（序号1-4），上海兰笋山庄有限公司等7家企业出现关闭、搬迁等情形（序号5-11），依据《企业安全生产标准化建设定级办法》（应急〔2021〕83号）第十一条有关规定，我局决定撤销上述11家企业二级安全生产标准化等级，名单如下。

1.上海连成（集团）有限公司

2.上海凯波电缆特材股份有限公司

3.上海阿尔斯通交通设备有限公司

4.上海飞航电线电缆有限公司

5.上海兰笋山庄有限公司

6.上海顶发食品有限公司

7.埃迈诺冠气动器材（上海）有限公司

8.上海安浦鸣志自动化设备有限公司

9.上海克莱德贝尔格曼机械有限公司

10.宝钢金属有限公司上海秉玟型材分公司

11.上海宝钢车轮有限公司

特此通告。

上海市应急管理局

2024年2月20日
