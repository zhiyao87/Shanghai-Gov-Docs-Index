# 上海市交通委员会、上海市公安局关于71路中运量西延伸公交线路实行专用车道管理的通告

目前，71路中运量西延伸工程已具备试运营条件。为确保行车安全，维护行车秩序，提高通行效率和承运能力，根据《上海市道路交通管理条例》《上海市公共汽车和电车客运管理条例》有关规定，结合本市实际情况，对71路中运量西延伸公交线路实行专用车道管理，现就有关事项通告如下：

一、71路中运量西延伸路中式专用车道，东起沪青平公路吴宝路交叉口，沿沪青平公路—华翔路—申兰路—申长路—天山西路——申昆路，至丰虹路停车场，总长约9.6公里，为71路中运量公交线路车辆专用，2023年5月13日零时启用。除执行紧急任务的警车、消防车、救护车、工程救险车外，全天禁止其他车辆通行。

二、具有下列情形之一的，车辆可以临时使用71路西延伸公交专用车道：

（一）清障施救车辆对专用车道内的车辆实施清障施救的；

（二）道路交通管制以及发生爆炸、火灾、道路塌陷等重大突发案事件或者重大交通事故，可以根据交通警察的指挥通行，通过管制区域、事发路段后应当立即驶离；

（三）非营运时段内，在确保交叉口通行安全的条件下，中运量公交设施维护车辆以及71路西延伸沿线专用道路内侧施工、维护车辆实施施工或维护工作的。

三、违反本通告规定，车辆擅自驶入71路西延伸沿线专用车道的，由公安机关依据《中华人民共和国道路交通安全法》《上海市道路交通管理条例》的有关规定予以处罚。

特此通告。

市交通委
