# 上海市徐汇区人民政府办公室关于转发区商务委制订的《徐汇区关于进一步推进早餐工程建设的实施意见》的通知

徐府办发〔2020〕24号

上海市徐汇区人民政府办公室关于转发

区商务委制订的《徐汇区关于进一步推进早餐工程建设

的实施意见》的通知

区政府各委、办、局，各街道、华泾镇，各有关单位：

经区政府同意，现将区商务委制订的《徐汇区关于进一步推进早餐工程建设的实施意见》转发给你们，请认真按照执行。

2020年11月26日

徐汇区关于进一步推进早餐工程建设的实施意见

为贯彻落实十一届市委九次全会精神，推动早餐供应更便捷、更丰富、更健康，更好满足市民群众生活需要，根据市委办公厅、市政府办公厅《关于进一步推进我市早餐工程建设的意见》（沪委办〔2020〕36号）要求，现就徐汇区进一步推进早餐工程建设提出如下实施意见。

一、总体考虑

将早餐工程建设作为践行“人民城市人民建，人民城市为人民”理念的重要切入点和工作抓手，完善规划布点，创新供给方式，深化制度创新，在全市早餐工程建设中探索出徐汇经验和徐汇样式。在工作推进中，突出民生需求导向，解决区域居民吃得上、吃得好的问题，体现城区温度和品质；突出优化营商环境，解决楼宇园区早餐网点配套不足、白领上班族早餐难的问题，体现一流营商服务；突出在线经济引领，探索新的早餐供给模式，引领新型商业模式和业态深入发展；突出智慧赋能治理，依托徐汇“一网统管”先行区的优势，加强对早餐市场的智慧服务和智慧监管，体现徐汇治理水平和能级。

二、工作目标

通过推进我区早餐工程建设，进一步优化早餐网点布局，逐步实现社区、园区、楼宇早餐布点的优化覆盖，提升区域早餐服务的可及性和便捷性；进一步建立多元早餐供给体系，整合相关资源，引导和支持各类市场主体参与，拓宽供给渠道和供给方式，丰富供给品种，提升区域早餐服务的多元性和丰富性；进一步探索早餐工程建设范式，发挥区域外资总部餐饮品牌集聚和老字号品牌的资源禀赋优势，依托在线新经济、一网统管等方面的工作基础，探索形成早餐工程建设的徐汇范式，体现区域早餐服务的示范性和引领性。

三、主要任务

（一）聚焦各类需求，完善布局布点

1.制定早餐工程规划。依托街镇组织力量，对全区各区位进行排摸梳理，厘清各区位对于早餐网点及业态的精准需求，在此基础上编制区域早餐工程布局规划。（责任单位：区商务委、区规划资源局、区市场监管局，各街道镇）

2.夯实“家门口”早餐布点。以居民社区为单位，以社区百姓为主要对象，摸清早餐供给的空白点与薄弱点，完善供给配置，体现零距离的亲民便利化。（责任单位：区商务委、区市场监管局，各街道镇）

3.充实“单位旁”早餐布点。在徐家汇、衡复、滨江、漕开发、枫林园区等商业集聚地、产业集聚地、大院大所集聚地、医疗机构集聚地，以楼宇园区企事业单位白领员工为主要对象，优化强化早餐供给保障，体现高品质的营商服务。（责任单位：区商务委、区市场监管局，各街道镇，徐家汇商城集团、徐房集团、西岸集团、枫林集团，漕开发总公司、仪电集团）

4.落实“流动中”早餐布点。在徐家汇、万体馆、上海南站、漕溪路、陕西南路、桂林路等地铁及公交枢纽位置，以各类必经人流为主要对象，实现优质充足的早餐供给，体现跨距离的供应时效性。（责任单位：区商务委、区市场监管局，各街道镇）

（二）创新供给方式，拓展多元供给

5.完善“菜市场+早餐服务”。在全区现有标准化菜市场体系中，按需补足布点，推进菜市场早餐门店标准化建设。（责任单位：区商务委、区市场监管局、区生态环境局、区绿化市容局，各街道镇，国投集团、徐房集团、新徐汇集团、汇成集团、新路达集团）

6.拓展“便利店+早餐服务”。开展与全家、罗森、7-eleven、良友金伴、百联逸刻等连锁便利品牌合作，鼓励其拓店经营并强化门店早餐供给功能。（责任单位：区商务委、区市场监管局、区生态环境局、区绿化市容局，各街道镇）

7.创新“老字号+早餐服务”。创新供给形式和品类，支持乔家栅、二食肆等上海老字号品牌以网点拓店、营养早餐、共享套餐等形式提供特色早餐供给。（责任单位：区商务委、区国资委、区市场监管局、区生态环境局、区绿化市容局，各街道镇，新路达集团）

8.做强“外资总部餐饮消费品牌+早餐服务”。立足区域外资总部资源集聚优势，推动星巴克、麦当劳、百胜中国、汉堡王等外资总部餐饮消费品牌以网点拓店、营养早餐、共享套餐等形式提供品质早餐供给。（责任单位：区商务委、区市场监管局、区生态环境局、区绿化市容局，各街道镇）

9.探索“网订柜取+早餐服务”。加强与阿里盒小马、百联逸小兔等品牌合作，以楼宇园区、地铁站为网订柜取主要布点区域，为白领上班族提供便捷优质的早餐供给。（责任单位：区商务委、区市场监管局、区生态环境局，各街道镇）

10.推行“流动餐车+早餐服务”。加强与光明良友、粮全其美、百联逸小兔、阿里盒小马等首批市流动餐车品牌企业合作，在人流量大、商务办公密集区域精准布点，为消费者提供便捷健康的早餐供给。（责任单位：区商务委、区建设管理委、区市场监管局、区生态环境局、区绿化市容局、区城管执法局、区公安分局，各街道镇，徐家汇商城集团、西岸集团、城开集团、枫林集团）

（三）深化制度创新，激发市场活力

11.降低准入门槛。帮助早餐网点企业提高开办营业效率，探索实施早餐企业“一证多址”“一地多证”、深化小餐饮备案管理，简化消防等开业检查许可事项，实行告知承诺管理，释放行业发展潜力。（责任单位：区市场监管局、区应急局、区消防救援支队）

12.创新监管模式。放宽早餐门店对外宣传形象限制，允许早餐网点在安全、有序、美观的前提下展示个性化门头、标识、宣传设计，审慎包容监管店招店牌。（责任单位：区绿化市容局、区市场监管局、区城管执法局）

13.提供高效服务。支持流动餐车规范运营，优化早餐时段交通组织管理，增加早餐时段道路临时停车点位，放宽早餐时段停车限制。（责任单位：区公安分局、区商务委、区建设管理委）

14.加强综合扶持。对国企房屋低价出租用于早餐网点给予一定的房租补贴；对于纳入早餐工程网点的老字号品牌改造或新建项目给予扶持；鼓励支持菜市场开展早餐门店标准化改造；对纳入早餐网点的企业优先享受财税方面的政策服务。（责任单位：区财政局、区税务局、区商务委、区国资委，新路达集团）

（四）倡导营养均衡，推动健康生活

15.倡导健康营养。支持早餐企业在现有早餐供应和确保食品安全的基础上，针对幼童、学生、老年人、上班族、糖尿病人、心血管病人等不同人群开发出低热量、低油、低糖、低盐等不同口味的健康营养套餐。（责任单位：区卫生健康委、区市场监管局、区商务委）

16.制止餐饮浪费。推广使用绿色环保包装材料，减少一次性餐具的使用。倡导合理膳食，培养节约习惯，营造浪费可耻节约为荣的氛围。（责任单位：区文明办、区卫生健康委、区市场监管局、区生态环境局、区商务委）

（五）践行智慧治理，突出精准服务

17.实行汇商码管理。积极尝试对区域早餐工程实行智慧治理，拓展运用汇商码，将全区所有早餐商铺和流动点位纳入汇商码管理体系，实现“一店一码、互动互联、共治共享”。（责任单位：区市场监管局、区商务委，各街道镇）

18.拓展大数据应用。全面归集早餐网点注册许可、行业评价、监督检查、政策信息、消费评价、社会舆情等方面的数据，打造政府治理、早餐经营、市民消费三方各得所需的应用场景，提升徐汇早餐工程管理服务能级。（责任单位：区市场监管局）

四、组织实施

（一）加强组织领导

将早餐工程纳入区长负责制，建立由区政府主要领导挂帅、分管副区长具体牵头的联席会议制度，办公室设在区商务委。相关成员单位包括：区商务委、区建设管理委、区国资委、区卫生健康委、区公安分局、区规划资源局、区市场监管局、区生态环境局、区财政局、区税务局、区应急局、区绿化市容局、区城管执法局、区文明办等部门，各街道镇，徐家汇商城集团、徐房集团、西岸集团、国投集团、城开集团、枫林集团、新路达集团、新徐汇集团、汇成集团等区属国资公司，以及漕开发总公司、仪电集团等2个大型园区国企。

（二）完善工作机制

完善徐汇区推进早餐工程建设工作机制，区商务委为牵头责任部门，各相关职能部门明责履职，各街道镇强化属地责任，各国资公司积极参与。建立工作例会机制，定期召开联席会议，加强沟通协商。建立信息报送机制，定期编辑工作简报。建立重大事项协调机制，及时解决出现的问题和困难，有序有效推进区域早餐工程建设工作。

（三）推进工作节点

1.各相关职能部门、各街道镇、相关国资公司分别制定本单位推进早餐工程建设的工作方案或政策制度。（2020年9月20日前完成）

2.各街道镇对所辖区域进行排摸梳理，厘清本辖区对早餐网点及业态的精准需求，形成详细书面材料汇总至区商务委。（2020年9月30日前完成）

3.在各街道镇排摸的基础上，由区商务委牵头，研究编制徐汇区早餐工程建设规划。（2020年10月31日前完成）

4.由区商务委牵头，各有关责任部门、国企配合，完成徐汇区2020年6类早餐供给服务52个网点建设工作（详见附表）。（2020年12月31日前完成）
