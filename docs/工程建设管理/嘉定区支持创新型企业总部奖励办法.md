# 嘉定区支持创新型企业总部奖励办法

为加快推动嘉定创新型经济发展，鼓励各类创新主体提升能级，打造复合型企业总部，为区域经济高质量发展提供有力支撑，根据《上海市创新型企业总部认定和奖励管理办法》（沪发改规范〔2023〕3号）（以下简称“市级管理办法”）和财政资金管理有关规定，结合本区实际，特制定本办法。

一、支持对象及内容

对已获“上海市创新型企业总部”认定并享受上海市战略性新兴产业发展专项资金的企业，依据市级管理办法有关规定，给予相应区级财政资金支持。已享受其他总部相关政策的不再重复奖励。

二、资金拨付

区级资金根据现行财政管理体制，由区、镇两级财政共同承担，分别安排预算列支。区发展改革委通过“免申即享”方式安排拨付区本级承担部分。

三、责任追究

对于已获得认定的创新型企业总部，如发生认定资格被取消或市级专项资金被收回等情形，区级支持资金将同步予以收回。

四、其它

1、企业依据本办法申请并获得支持后，若销售收入首次达到更高级别认定标准的，可按照申报流程再次申请。

2、本办法自印发之日起施行，有效期至2028年2月29日。实施期间如遇国家及本市有关政策调整，则按调整后的政策执行。

3、本办法由区发展改革委负责解释。
