# 关于印发 《2019-2021年上海市开放休闲林地建设项目竣工验收办法》的通知

金山、松江、青浦、奉贤和崇明区绿化市容局：

为规范本市开放休闲林地项目验收工作，客观评价项目实施成效和资金使用情况，根据《2019-2021年上海市开放休闲林地建设项目管理办法》（沪绿容〔2019〕556号）要求，现将《2019-2021年上海市开放休闲林地建设项目竣工验收办法》印发给你们，请按照执行。

上海市绿化和市容管理局

2022年7月4日

2019-2021年上海市开放休闲林地建设项目竣工验收办法

为规范本市开放休闲林地项目检查验收工作，提高项目实施成效和资金使用效益，依据《2019-2021年上海市开放休闲林地建设项目管理办法》（沪绿容〔2019〕556号），制定本办法。

一、验收范围

纳入2019-2021年计划的开放休闲林地建设项目。

二、验收内容

包括项目程序、档案资料、完成情况、变更情况和资金使用等方面。

项目程序情况。包括项目实施过程中相关程序是否符合管理办法，是否按规定执行项目法人责任制、招投标制、合同制、监理制等情况。

档案资料情况。包括项目批复文件、设计文件以及与项目有关的资料归档情况。

完成情况。包括项目建设地点、内容、规模、质量以及完成时间等情况。

变更情况。包括项目在实施过程中发生的变更情况，按规定要求办理变更手续的情况。

资金使用情况。包括按照相关批复规定的用途使用资金等情况。

三、验收程序

（一）项目自查。项目结束后，建设单位根据项目立项和作业设计批复对实施项目工程量、施工质量和资金使用等进行全面自查，形成自查报告，提出区级验收申请。

（二）区级验收。区绿化市容局对建设单位申请验收材料进行认真审核，并根据项目单位区级验收申请，组织区级验收。通过区级验收后，由建设单位根据区级验收意见进一步完善项目，并由区绿化市容局形成区级验收报告，向市绿化市容局提出项目验收申请。

（三）市级验收。根据区绿化市容局提出的市级验收申请，市绿化市容局会同市发改委、市财政局组织市级项目验收，并出具验收意见。

四、验收材料

项目验收材料主要包括：项目竣工验收请示、区级验收报告、项目实施方案审核意见及相关文本，立项和作业设计批复及相关文本、招投标材料、项目变更调整的文件或材料、项目竣工报告、竣工图、资金使用情况对照表、竣工决算、审价报告、监理报告、相关行政许可材料,以及照片资料等。

五、验收方法

（一）内业检查。对项目管理程序、档案资料、资金使用等相关材料进行审查，检查其完整性、规范性。

（二）外业检查。对项目范围内林地抚育、景观改造、各类设施等全部建设内容的工程量及规格质量进行实地验收。实地验收采取全部核查和抽样核查相结合的方式。设施类采取全部核查。林地抚育、景观改造采取抽样核查，抽样区域总面积不少于项目实施面积的10%。对重点区域和非连续地块分别进行抽查，抽查比例不少于相关区域面积的10%。对地块进行现场核查后填写开放休闲林地项目质量验收表(详见附件)。

六、质量检查标准

林地抚育、景观改造、基础设施、休憩设施、服务设施等全部建设内容应与竣工图一致，竣工图应与作业设计一致，如有变更应有作业设计调整相关手续。

（一）林地抚育。主要检查作业面积和作业质量；其中作业面积根据上报完成面积，核对实际作业面积；作业质量重点检查是否按作业设计要求实施，是否存在应采未采、错采、乱开天窗、越界采伐等问题，其质量应达到设计明确的要求。

（二）景观改造。核查地块内乔木、灌木和地被种植数量、规格及成活情况，要求核实率≥95%，成活率≥95%，珍贵树种和孤植树应100%成活。苗木栽植应达到工程种植要求，按照植物特性和主导功能进行修剪，保持良好的形态、长势，景观改造应达到设计明确的建设要求。

（三）设施建设。核查基础设施、休憩设施、服务设施等重点建设内容的数量、规格、材质是否达到设计明确的建设要求，与周边环境相协调并满足基本的游憩活动需求。

（四）养护管理。清除死亡苗木并及时补植，现场无违章搭建、垃圾、建筑材料等杂物，是否及时清除杂草。

七、验收结论

分通过验收和不通过验收两个结果。对通过验收的项目，由验收组织单位进行批复；对无法达到验收通过标准的项目，验收组织单位应向项目建设单位提出限期整改要求，项目按要求整改后，再组织验收。若项目无法整改或整改后仍无法满足验收通过标准的，则认定项目未通过验收，由验收组织单位按照项目管理有关规定进行处理。

（一）通过验收的项目

同时符合下列条件的项目视为验收通过：

1.档案材料完整、规范；

2.在规定时间内按时完成项目施工；

3.核实项目建设面积，林地抚育、景观改造、基础设施、休憩设施、服务设施建设等符合要求，严格按图施工；

4.各项经济、技术指标符合本市相关规定的；

5.项目实施过程中无重大违纪违规问题，无未解决纠纷；

6.项目经费使用未出现违法、违纪、违规的。

（二）不通过验收的项目

经整改仍有下列情况之一的项目视为不通过处理：

1.未经建设单位、林业主管部门和发改部门同意，项目建设地块、面积以及建设内容出现重大调整，超出批复范围10%的；

2.未在规定时间内按时完成项目施工；

3.各项经济、技术指标不符合本市相关规定的；

4.图实严重不符。包括林地抚育涉及的苗木品种、规格与设计图、竣工图完全不符；种植模式、密度与设计图、竣工图完全不符；基础设施面积、休憩设施、服务设施数量、规格与设计图、竣工图完全不符；

5.项目实施过程中出现重大问题，存在纠纷未解决的；

6.项目经费使用出现违法、违纪、违规的；

通过验收的项目，由区绿化市容局申请项目资金清算。项目验收批复后，区绿化市容局应明确后期管护主体，落实养护责任。

八、附则

本办法由上海市绿化和市容管理局负责解释。
