# 上海市交通委员会关于印发《公交站台适老化指导意见（试行）》的通知

市道路运输事业发展中心、各区交通行政主管部门、各相关单位：

根据交通运输部、国家铁路局、中国民用航空局、国家邮政局、中国残疾人联合会、全国老龄工作委员会办公室联合印发的《关于进一步加强适老化无障碍出行服务工作的通知》（交运函〔2024〕20号）精神，为进一步提升上海公交站台设施适老化服务水平，落实市政府2024年为民办实事工作要求，依据现行国家、行业、地方规范和标准，结合本市老年人出行需求，我委研究制定了《公交站台适老化指导意见（试行）》，现印发给你们。请结合工作实际，认真抓好贯彻落实。

特此通知。
