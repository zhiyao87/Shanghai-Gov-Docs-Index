# 上海市住房和城乡建设管理委员会关于批准《应急避难场所设计标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《应急避难场所设计标准》为上海市工程建设规范的通知

沪建标定〔2023〕277号

各有关单位：

由上海市园林设计研究总院有限公司、华东建筑集团股份有限公司主编的《应急避难场所设计标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2188-2023，自2023年12月1日起实施。原《应急避难场所设计规范》(DG/TJ08-2188-2015)同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市园林设计研究总院有限公司负责解释。

特此通知。

2023年6月1日
