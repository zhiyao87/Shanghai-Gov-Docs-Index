# 上海市松江区城市管理行政执法局关于印发 《关于推进2026年度松江区违法建筑治理工作的实施方案》的通知

各镇、街道、经开区：

现将 《关于推进2026年度松江区违法建筑治理工作的实施方案》印发给你们，请认真贯彻执行。

松江区违法建筑整治工作专办

松江区城市管理行政执法局（代章）

2026年4月8日

关于推进2026年度松江区违法建筑治理工作的实施方案

2026年，是实施“十五五”规划开局之年，也是推进高质量发展关键之年。松江区违法建筑治理工作思路为：聚集“四个区”功能定位，锚定“控新增、减存量、攻难点、惠民生、保安全”目标要求，坚定信心、干字当头、奋力再跳，全力打赢违建治理攻坚战突围战，为建设“科创、人文、生态”现代化新松江营造良好环境。

一、强力管控正在搭建违建

进一步加强源头管控。完善装修报备、物业上报、执法巡查、投诉举报等预警机制，积极借助无人机巡航、视频监控等科技赋能，提高正在搭建违建的发现率、及时率和查处率，确保正在搭建违建“动态清零”。进一步加强拆罚结合。对正在搭建违建必须予以快速认定、快速查处、快速拆除。对违建情况严重，造成恶劣社会影响或违建点位反复拆后重建的，在坚决拆除的前提下，严格予以依法处罚。特别对因发现、制止、上报不及时，造成小区正在搭建违建屡禁不止的物业，依法依规加大处罚力度。进一步加大监管力度。健全专管员“划片包干”工作机制，指导督促各街镇（经开区）加大正在搭建违建投诉点位拆除力度，力争每月清零，严防不作为、慢作为等情况。进一步加大问责力度。对街镇（经开区）应立未立，立案后无进展，对物业未履职没有立案查处的，开具区级提示单；发现街镇（经开区）在3个月内未拆除，且未制作送达强拆决定书的，开具区级巡查案件提示单。

二、加快消除已建成违建

重新排摸分析市无证建筑数据库内涉松已建成违建点位的性质和构成，将市级部署任务细化分解到各街镇（经开区），早谋划、强推进，抓紧库内、库外拆除销项，全力完成年度区级拆违量20万平方米以上，同时加大补证销项、政策销项等工作力度。坚持问题导向、紧盯痛点堵点，加快对市级高度关注的70个案件（均为2025年库转新增违建诉件）和全区165个“已立案未整改”违建案件整改进度，确保在2026年6月底前完成整改任务，真正解决一批长期应解决未解决的违建问题，并以此为鉴、举一反三，进一步转变工作作风、增强履职能力。

三、持续推进别墅私搭乱建专项整治

聚集已录入自然资源部数据库违建点位，按照“三个一批”处置方式，分类施策，加速推进。采取“以拆为主、注记为辅、刚柔并济”的方式，继续推进拆除工作，补足剩余缺口，累计拆除点位366处；全面启动立案程序，库内2273处违建点位年底前完成整治率80%以上，争取三年行动两年提前完成。运用提醒、约谈等工作机制，重点对思想不重视、履职不到位、工作推进慢、推诿扯皮的单位和个人，不定期进行提醒。

四、深化拓展厂房仓库消防安全隐患专项整治

在已有工作机制的基础上，继续加强与区消防、区应急等部门沟通联系，进一步加大监管合力、提升监管效力。指导督促属地拆违部门协同相关部门强力推进厂房仓库违建治理，及时消除消防安全隐患。重点排查整治厂房仓库违规搭建雨棚、移动棚等改建占用消防通道以及导致其他消防隐患的问题，坚持“即查即改”原则，严格依法查处，切实筑牢城市安全防线，对不能立即整改的高风险隐患及时启动联合整治。

五、协同推进小散园区专项整治

严格对照“四个一批”处置要求及完成标准，加强协同配合，指导督促街镇（经开区）对辖区园区内私搭乱建、乱设广告招牌、损坏房屋主体和承重结构以及擅自增设夹层、加顶等违法违规行为，全面开展排查摸底，锁定目标任务，全力推进小散园区（产业地块）城管执法领域专项整治工作。重点加强对223个园区中第三、四类园区的现场核查以及《“四个一批”属地协调诉求转办单》的处置反馈工作。

六、密切关注社情民意和舆情处置

持续加大违法建筑危害性以及相关法律法规和政策文件的宣传力度，充分利用海报、横幅、小区滚动屏以及微信公众号、“社区云”、《松江报》等宣传平台，高频次、不间断、大范围地宣传全区违法建筑治理情况，推广经验做法，曝光问题短板，进一步提升市民群众的防违控违意识。强化数据赋能、深化协同联动、加强检查监督，助力相关部门向市民群众交出满意答卷，有效提高市民群众对“12345”热线违建投诉处置的满意度和获得感。适时会同区级相关部门举办违法建筑治理工作培训班，重点围绕违建管控难点剖析、拆违行政案例解析和正在搭建违建投诉件办理等问题，开展交流探讨、释疑解惑，进一步提高拆违工作人员依法办案水平、违建工单处置水平和联系沟通回复能力。
