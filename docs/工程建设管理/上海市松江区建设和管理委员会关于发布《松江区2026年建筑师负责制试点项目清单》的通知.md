# 上海市松江区建设和管理委员会关于发布《松江区2026年建筑师负责制试点项目清单》的通知

各单位：

为全面落实上海市关于持续深化建筑师负责制扩大试点的工作部署，根据《松江区建筑师负责制实施导则（试行）》（沪松建管〔2024〕140号）要求，我委通过企业自主申报、街镇推荐等方式排摸了一批试点项目，并会同区发改委、区财政局、区规资局通过综合评估，最终形成了《松江区2026年建筑师负责制试点项目清单》，现予以公布。

特此通知。
