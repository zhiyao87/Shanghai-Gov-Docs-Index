# 上海市住房和城乡建设管理委员会关于批准《城市综合管廊维护技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《城市综合管廊维护技术标准》为上海市工程建设规范的通知

沪建标定〔2026〕126号

各有关单位：

由上海市城市综合管理事务中心（上海市地下管线监察事务中心）、上海电器科学研究所（集团）有限公司主编的《城市综合管廊维护技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2168-2026，自2026年9月1日起实施。原《城市综合管廊维护技术规程》(DG/TJ08-2168-2015)同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市城市综合管理事务中心（上海市地下管线监察事务中心）负责解释。

特此通知。

2026年4月2日
