# 上海市自然灾害防治委员会  上海市安全生产委员会关于命名浦东新区曹路镇社区等50个社区为2021年度上海市安全发展和综合减灾示范社区的通知

各区自然灾害防治委员会、安全生产委员会：
2021年，根据《上海市安全发展和综合减灾示范创建工作管理办法（试行）》（沪灾防委〔2021〕3号）有关要求，上海市自然灾害防治委员会、安全生产委员会在全市范围内开展了年度上海市安全发展和综合减灾示范社区候选单位推荐工作。在各区有关部门联合指导、评选、检查和推荐基础上，市自然灾害防治委员会办公室牵头，联合市安全生产委员会办公室成立市级评审工作组,对全部申报社区进行了实地考评，经社会公示无异议后，市自然灾害防治委员会、市安全生产委员会决定命名浦东新区曹路镇社区等50个社区为2021年度上海市安全发展和综合减灾示范社区（名单见附件）。
各区要牢固树立安全发展理念，不断提升防灾减灾能力，深入组织开展上海市安全发展和综合减灾示范社区创建，持续提升创建水平，不断夯实基层应急管理工作基础，充分发挥示范引领效应，进一步增强人民群众获得感、幸福感、安全感。

附件：2021年度上海市安全发展和综合减灾示范社区名单
