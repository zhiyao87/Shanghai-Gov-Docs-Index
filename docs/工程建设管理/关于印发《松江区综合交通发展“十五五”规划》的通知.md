# 关于印发《松江区综合交通发展“十五五”规划》的通知

各相关部门、各街镇（园区）：

经区政府第139次常务会议审议通过，现将《松江区综合交通发展“十五五”规划》印发给你们，请遵照执行。

2026年7月7日

松江区综合交通发展“十五五”规划

为进一步落实交通强区建设，持续增强交通辐射和服务能级，全面服务松江“四个区”建设，根据《中共上海市松江区委关于制定松江区国民经济和社会发展第十五个五年规划的建议》和《上海市松江区国民经济和社会发展第十五个五年规划纲要》编制本规划，规划期限为2026-2030年。

一、“十四五”发展评估

（一）“十四五”发展情况

“十四五”以来，围绕建设“科创、人文、生态”的现代化新松江的总体目标，在“强枢纽、富通道、多模式、高融合”的总体思路指引下，全区综合交通体系不断完善，基本形成“网络化、精细化、智慧化”的交通发展模式。“十四五”规划目标总体执行良好，重要指标基本符合预期，重点任务和重大项目全面有序推进。

1.对外服务能力显著增强

西南门户枢纽地位逐步确立。2024年12月26日，上海松江站随沪苏湖铁路同步开通运营，形成“三线双通道”枢纽格局，可辐射覆盖长三角地区80%以上城市。截至2025年底，松江站累计客流超1593万人次，成功应对2025年春运、五一、国庆等多轮大客流考验，松江枢纽已具备成为上海西南门户枢纽的坚实基础与条件。

高快速路服务能力不断提升。“三横两纵”高速公路骨架持续完善，配合推进G50沪渝高速、S32申嘉湖高速、G15沈海高速功能提升工程，建成G60莘砖公路匝道，优化高速节点布局。新城快速环路规划布局基本成型，沪松公路快速化开工建设。

水运服务能级持续增强。内河航道初步形成以黄浦江、苏申外港线、杭申线、杭平申线和油墩港5条高等级航道为骨架，22条支线航道为补充的网络体系，内河码头年货运吞吐量达560万吨。积极配合落实市级航道项目，协同完成淀浦河、叶榭塘等航道的疏浚任务及平申线航道整治任务，协助推进油墩港航道整治工作。持续推动区级航道养护疏浚，顺利完成人民河、通波塘、北泖泾等航道疏浚工作。

2.“四网融合”体系加速成型

多层次轨道交通网效益逐步凸显。轨道交通12号线西延伸建设加快推进，6个站点全面开工建设；轨道交通9号线通过缩短工作日晚高峰列车运行间隔、上海松江站开行多头班车及大客流日延时运行等方式提高运能。有轨电车通过调整早晚高峰和节假日班次，优化运营效率。多网融合成效彰显，完成轨道交通9号线上海松江站的站厅布局优化改造并设置铁路与轨道交通的乘客单向免安检通道，强化地面公交与金山铁路车墩站的接驳，新城轨道交通站点（含有轨电车）50米地面公交接驳基本实现全覆盖。

地面公交服务不断优化。全区公交客流强度达到128人次/百公里，每年调整优化线路10条以上，新城建成区公交站点500米覆盖率达到96%。针对文商旅体展农、助学、通勤等需求，累计开通定制公交线路18条。推动公共交通硬件服务品质提升，累计新建公交候车亭265座。完善区内公共交通基础设施，佘山站、九亭站、铁东生活片区公交枢纽及南永丰公交停保场等场站陆续建成并投入使用，同步配套充电设施，助力公交绿色转型。

3.道路交通系统持续完善

区域路网格局基本形成。骨干道路建设有力推进，G320车亭公路松江段、叶新公路新浜段、嘉松公路（金玉路-塔闵路）建成通车，嘉松公路越江接线、叶新公路、昆港公路南延伸等关键工程有序实施，总体形成“六横五纵”骨架路网，全区干道（含省道）总里程约242公里，实施率提升至75.5%。泖亭路—剑川路、胡曹路—兴北路区区对接道路持续推进。关键道路节点贯通加速推进，完成人民南路、谷阳南路等铁路节点贯通前期工作，建成明华路、申北四路等穿铁道路，有效疏通交通瓶颈。

重点区域配套路网持续完善。松江枢纽核心区15条配套道路与松江枢纽同步建成投用，确保枢纽集散高效便捷。大型居住社区配套路网密度明显提升，建成金玉路（玉树路-辰塔路）、玉阳大道（白苧路-车香路）等一批外配套道路，以及茶亭路（披云门路-松卫北路）、官绍路（银圩路-旗亭路）等一批内配套道路。“大虹桥”拓展片区道路建设加速推进，盛龙南路、长安泾路等关键道路有序实施，有力赋能拓展片区的联动发展。

完善“四好农村路”助力乡村振兴。完成360条（段）农村公路提档升级工程，里程达387.2公里，县道、乡道优良路率（MQI）均达到98%，道路通行能力与安全性全面提升。完成新一轮农村公路建设规划，推进环佘山旅游公路的建设和申报，路域环境与道路状况显著改善，有力支撑了乡村振兴发展。

4.民生交通工程彰显成效

慢行网络连通性不断增强。建成通波塘绿道、东升港路滨河绿道等一批高品质绿道。完成广富林、泰晤士小镇、印象城等慢行精品区建设及慢行设施提升类项目40余项，新城慢行网络密度[1]提升至9.21km/km2，形成连续舒适的慢行环境。

多措并举缓解停车供需矛盾。累计新增公共停车场项目155个，共计43882个停车位，新建轨道交通9号线佘山站、大学城站、九亭站等P+R停车库，增加867个泊位，轨道站点周边增加非机动车泊位1700个。通过停车共享、错时停放等措施缓解医院、老旧小区等停车难问题，完成33个错峰共享项目，共释放1047个共享泊位，完成市一南院、松江中心医院等7家医院停车预约项目，有效缓解停车矛盾。

扎实推进交通缓拥堵工作。系统推进多项交通组织优化工程，完成7个路段潮汐车道改造、37个交叉口可变车道工程，实施昆港公路-光华路交叉口渠化、北松公路分隔带开口优化以及景区出入口专用蓄车道改造，车道利用率和道路通畅率明显提高，重点路段和区域交通压力得到有效缓解。

道路环境品质持续提升。开展“四新技术”在车行道、人行道路况和桥梁养护的应用，加强城市道路四类设施日常养护和管理以及无障碍过街设施建设和改造。累计完成24条精品道路创建，总长度31.24公里，区域交通环境与服务品质显著提升。

5.绿色智慧发展协同并进

物流运输体系持续深化。推进西南片区货运枢纽和集疏运网络布局的专项研究；建成并投用上海市首个航空前置货站—松江综合保税区航空前置货站，实现了包括预安检、报关、卡车转运在内的一站式服务功能，有效提升了空运货物在松江的集散与通关效率，畅通高时效物流链条。

绿色低碳交通加快构建。加快新能源车辆推广和配套设施建设，新能源公交车占比达100%（除应急车辆外）；持续推进充电设施网络建设，新增公共充电桩15394个。

交通信息化赋能显著提升。全区公交线路实时信息全面接入“上海交通”APP，完成“上海市公共停车信息平台”接入工作，推进停车场无感支付，打造了松江印象城等一批智慧停车场（库），试点“一路一档”信息化建设，陆续建成广富林路示范路信息系统、交通建设工程安全质量监督平台、水上搜救及航道安全监控系统等一批信息化项目。

（二）面临挑战和问题

对外客货服务能力有待深化，松江枢纽轨交、道路配套有待完善，物流运输结构仍需优化，航道及港区功能尚未充分发挥。轨交对地区发展的支撑还需增强，轨交9号线入城断面依然拥堵，既有线网服务能力与城市发展需求存在差距。道路交通服务水平仍需提升，G60沪昆高速和沪松公路入城段高峰期间拥堵仍然明显，高速公路出入口压力持续增大，老铁路沿线、新城西部等区域路网通行效能有待提升。交通服务品质与人民城市要求仍有差距，地面公交、省际客运等转型需求迫切，轨交站点非机动车停车矛盾依然存在，老旧小区、医院等重点区域停车难问题仍需系统化解，智慧交通的应用有待进一步加强。

二、发展趋势及要求

长三角一体化及G60科创走廊战略进入关键期，要求提升对外辐射能级。面对长三角一体化与G60科创走廊带来的客货运需求增长，松江区交通系统应深度融入全市多层次立体交通网络，依托“轨道上的长三角”完善对外客运服务体系，构建公铁水空协同的多式联运体系，高效畅达长三角、上海大都市圈与中心城区，奠定区域竞争新优势。

全域新空间和新布局迎来加速期，要求构建高效综合交通系统。随着新城建设迈入功能全面提升新阶段，全区“一城发力、两片提升”空间格局加速深化，“2+4”现代化产业体系持续构建，松江枢纽、松江大学城科创源、国家级经开区等新空间加快布局，“大虹桥”拓展片区和南部绿色发展实践片区功能品质不断提升。区域综合交通系统应以“四网融合”为指引，系统补齐出行短板，提升功能板块间快速联系，完善新城独立交通体系，促进全区空间优化与新城功能集聚。

城市更新进入提质期，要求推动交通服务高品质转型。落实第五次中央城市工作会议精神，面对城市发展从增量扩张转向存量提质的新阶段，“十五五”时期松江需践行人民城市理念、推动城市更新迈向高质量发展，区域交通系统需更注重市民出行需求和既有设施挖潜利用，统筹推进道路优化、公交转型、慢行提质与停车挖潜。

科创绿色发展迈入发力期，要求推动交通新质生产力发展。依托G60科创走廊与松江大学城科创源建设，松江具备培育交通领域新质生产力的先发优势。应推动交通与大数据、人工智能、车路协同等新技术的深度融合，打造“智慧化、平台化、数字化”的交通管理与服务体系，强化交通智慧赋能，实现绿色低碳与效率提升的双重目标。

乡村振兴及文商旅体展农进入融合期，要求交通发挥先行引领和融合纽带作用。落实乡村振兴战略，服务文商旅体展农融合发展。需以“四好农村路”建设补齐农村地区路网短板，提升城乡交通基础设施和服务一体化水平；创新推动交通与文商旅体展农深度融合，优化配套功能设施，完善交通集散体系和交通组织保障，以畅达交通彰显人文松江魅力，助力打造“上海之根”文旅大IP。

三、发展方向

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十大和二十届历次全会精神，深入落实习近平总书记关于交通强国的重要论述精神、中央城市工作会议精神以及考察上海重要讲话精神，聚焦服务长三角一体化、G60科创走廊建设等国家战略，践行人民城市理念，锚定建设上海“五个中心”重要使命，围绕松江区打赢打好转型发展攻坚战突围战、基本建成“四个区”主要目标，着力构建更高能级的交通体系，支撑新城发力、产业升级、城乡融合与绿色发展，推动“科创、人文、生态”现代化新松江建设迈上新台阶。

战略引领为先：围绕长三角一体化、G60科创走廊建设、新城发力、乡村振兴等发展战略，强化区域协同发展，以松江枢纽为核心支点，完善区域协同综合交通网络，进一步增强西南门户枢纽能级，全面提升与长三角城市群、上海中心城、虹桥国际开放枢纽及周边区域快速连接水平。

四网融合为基：注重域内成网与网络优化，建设完善多层次公共交通体系，夯实“四网融合”发展基础。统筹推进全域综合交通网络布局，推动新城交通体系高质量发展，提升城市综合承载能力，服务松江大学城科创源建设、重点产业园区及文商旅体展农融合新空间，实现“人享其行、物畅其流”。

服务品质为本：坚持以人民为中心，提升居民出行品质和交通系统服务水平。优化交通基础设施布局，强化交通供给与城市功能、民生需求的协同，增强交通管理精细化与服务品质化，为建设人民向往的现代化新松江提供坚实保障。

智慧创新为驱：构建与现代化新城建设样板区相匹配的智慧型交通体系，推动大数据、智能化技术在交通治理与服务中的深度融合，提升综合交通系统运行效率和应急响应能力，以数字化转型驱动交通体系高质量发展。

至“十五五”末期，坚持“强枢纽、富通道、融网络、提品质”的发展思路，建成“枢纽聚能、外联内畅、融合高效、智慧绿色”的综合交通体系，服务“科创、人文、生态”现代化新松江建设。

四、发展思路

围绕现代化新松江的建设要求，以长三角一体化、G60科创走廊和新城发力等发展战略为契机，紧扣“枢纽强辐射、四网深融合、服务高品质”三大主线，重点实施“提升门户枢纽能级、深化四网融合、完善多层次路网、优化出行服务、赋能文商旅体展农”等五类任务和十五项重点举措。

（一）持续增强西南门户枢纽能级

高标准推动松江枢纽站城融合发展。强化站城一体理念，加快打造功能复合的“城市客厅”，促进交通功能与城市功能深度融合与相互赋能。优化松江枢纽集疏运体系，基于枢纽客流特征，持续完善轨道交通、道路交通、地面公交等多方式接驳体系，加快推进松江枢纽高架联络道建设，深化金玉路功能提升方案研究，明确建设时序并适时启动，完成玉树路(塔闵路-真玉路)拓宽和玉阳大道(玉树路—白苧路)工程建设。

高水平推进物流运输结构优化调整。积极配合落实市级航道项目，配合推进油墩港航道、苏申外港线等市级航道整治工作，同步做好交通配套设施衔接规划。规划整合松江综合保税区前置货站、铁路货场及内河港区等资源，推进物流和多式联运体系规划研究。积极承接市中心铁路货运功能疏解，拓展高效物流通道。深化内河港区规划，推进公共作业区规划建设，加强对码头的综合管理治理效能，提升岸线资源集约化利用水平。同时深化电动重卡充换电基础设施布局研究。

（二）不断深化“四网融合”的公共交通系统

加快构建多层次的轨道交通网络。推进联系中心城的轨道交通规划建设，全力推进轨道交通12号线西延伸段建设，积极争取更多直接服务松江新城和枢纽的轨道交通线路纳入建设规划，构建多通道轨道交通网络。

推动公共交通多网融合发展。优化有轨电车运营组织，深化有轨电车与地面公交两网融合，推进配套公交线网功能性重组。开展轨道交通12号线西延伸段沿线公交线网规划及站点配套布置，优化轨道交通9号线及金山铁路支线等轨交站点周边公交线网，实现轨交与地面公交的高效衔接。探索新型公交服务，注重与就医、就学、旅游、产业等需求相适应的线路布设。

推进公交场站设施落地。推进漕河泾公交枢纽、西部经开区公交枢纽等项目的规划建设，提升公交车辆运行效率和乘客出行体验，切实增强公交服务保障能力。

（三）加快完善外联内畅的道路交通网络

完善对外联系通道。加快推进沪松公路快速化建设，同步优化沿线路网，构建高快速路、主干路、次支路多通道分流体系，提升与中心城的衔接效率。加快推进泖亭路、胡曹路等区区对接道路建设，持续研究与闵行、青浦、金山等相邻地区的路网衔接，切实提升松江对外通达效率和区域一体化交通服务水平。

强化高快速路服务。配合推进G50沪渝高速、S32申嘉湖等高速功能提升工程，同步做好配套交通设施衔接规划。完善高速立交匝道布局，研究新增G60松江西、G1503广富林等立交匝道，均衡全区高速立交匝道流量和节点服务水平，推动实现新城范围内任意一点10分钟内接入高速公路系统。深化新城快速环路规划研究。

畅通区内道路网络。以沪昆铁路南移为契机，完善跨铁通道体系，完成谷阳南路、人民南路、昆港公路南北贯通，推进松金公路、玉树路等跨铁路通道平交改造，加强新城南北向交通联系，提升松江枢纽对外集散效率。优化浦南区域路网，完成叶新公路改建和嘉松公路越江接线工程建设。打通道路断点，实施乐都西路西延伸和思涌路北延伸等项目，完善区域交通循环系统。加密次支路网，打通断头路，提高路网密度和通达性，增强应对突发交通事件的韧性。

（四）系统提升绿色高质的出行服务

促进慢行出行品质提升。系统提升轨道交通9号线站点周边慢行路网密度，保障配套轨道交通12号线西延伸站点周边慢行设施。持续开展道路慢行设施功能完善和品质提升工作，同步结合滨水空间开发和新城绿环建设，打造高品质人行道和骑行道，构建连续、舒适、富有特色的慢行网络。

建管并重缓解停车矛盾。结合轨道交通建设规划及现状轨道交通，加强P+R、B+R停车设施建设管理，引导个体机动化交通向绿色化、集约化出行方式转移。充分利用符合条件的公园、绿地等地下空间及桥下空间，设置公共停车场库，推进智慧道路停车建设。通过内部挖潜、存量盘活与错峰共享等方式开展综合治理，有效提升停车资源供给水平。强化智慧道路停车场建设和管理，按照本市智慧道路停车场建设工作要求，同步落实相关服务措施。

推进交通精细化改造。聚焦拥堵路段，持续推进“小改小革”，实施交叉口可变车道、路口渠化、增设隔离栏等交通组织优化，提升通行效率与安全。交通调查分析长效机制，升级改造沪松公路和叶新公路部分路段交调设施，加强动态监测评估，为决策提供数据支撑。

培育智慧交通新业态。积极融入全市MaaS出行服务平台体系，深度整合松江枢纽智慧化服务功能，为市民提供全链条、多模式的出行信息服务。开展低空经济交通应用场景研究，前瞻性推进基础设施配套研究，培育智慧交通新业态，提升区域交通运行效率与服务品质。

（五）促进乡村振兴、文商旅体展农融合发展

高标准推进农村公路规划建设。深化城乡联系通道规划研究，助力城乡一体化发展。扎实推动“四好农村路”建设，系统实施既有农村公路提档升级改造。结合地区发展特征，实施农村公路分类分级管理，完善慢行空间安全保障。

加强乡村地区交通数字赋能与精细化管理。持续推进农村公路“一路一档”信息化系统建设，打造设施管养“智慧地图”。扩大公交线路覆盖范围、提升站点服务品质，推进公交实时到站信息服务，全面提高农村公交数字化水平。

支撑文商旅体展农深度融合发展。打造“快进慢游、智慧体验”的旅游交通体系，完善重点文旅、商圈周边道路停车、公交等交通配套设施，加强会展赛事交通保障，推动智慧停车、预约出行等便捷服务，以交通畅达赋能全域旅游，助力打造“上海之根”文旅大IP。

五、组织实施

立足“十五五”发展新要求，健全区域规划建设协同机制，提升任务推进效率。完善区内重大项目建设协调机制，着力破解交通项目推进过程中涉及的动迁腾地、工程技术、要素平衡、重要设施等关键环节堵点，强化项目全周期管理，确保各项任务有序实施、动态跟踪与闭环管理。同时强化交通建设项目土方综合利用，实现源头减量。围绕缓解交通供需矛盾、促进服务公平共享、激励技术创新应用等重点方向，优化项目审批机制，保障重大工程高效推进。加强对低空经济等新兴业态的规范引导与管理服务，支持智慧交通信息化项目建设。积极争取国家和市级资金支持，鼓励社会资本参与，提升资金管理使用效率与透明度，为综合交通高质量发展提供有力政策与资金保障。围绕交通规划、建设、管理，制定专业人才引进与培养计划，加强专业人才队伍建设。充分发挥长三角G60科创走廊与松江大学城科创源科技创新与产业创新策源优势，加强与高校、科研院所及企业的合作，定向培养复合型、技术型人才。建立健全人才评价与激励机制，在重大项目建设中充分激发专业人才的创新活力，为规划目标的实现提供坚实的人才支撑和保障。
