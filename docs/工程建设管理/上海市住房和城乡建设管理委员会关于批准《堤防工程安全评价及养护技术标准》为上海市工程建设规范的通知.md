# 上海市住房和城乡建设管理委员会关于批准《堤防工程安全评价及养护技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《堤防工程安全评价及养护技术标准》为上海市工程建设规范的通知

沪建标定〔2025〕237号

各有关单位：

由上海市堤防泵闸建设运行中心、上海市水利工程设计研究院有限公司和上海市政工程设计研究总院（集团）有限公司主编的《堤防工程安全评价及养护技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2471-2025，自2025年11月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市堤防泵闸建设运行中心负责解释。

特此通知。

2025年4月29日
