# 上海市住房和城乡建设管理委员会关于印发《2021年上海市工程建设规范编制计划（第二批）》的通知

上海市住房和城乡建设管理委员会关于印发《2021年上海市工程建设规范编制计划（第二批）》的通知

沪建标定〔2021〕721号

各有关单位：

根据《上海市建筑市场管理条例》和《上海市工程建设地方标准管理办法》等有关规定，结合本市工程建设实际需要，我委组织制订了《2021 年上海市工程建设规范编制计划（第二批）》，共有 4项。现印发给你们，请抓紧做好编制工作。

特此通知。

附件：2021年上海市工程建设规范编制计划（第二批）

2021年11月12日
