# 关于印发上海市2023年度各区优化营商环境优秀案例的通知

各区人民政府、各相关单位：
营商环境是企业生存发展的土壤，好的营商环境就是生产力、竞争力。2019年以来，我市已推出三批共47个区级优秀案例，营造奋勇争先的创新氛围，激发比学赶超的干事劲头，持续打造全市优化营商环境品牌。2023年，各区积极落实市委市政府优化营商环境工作要求，聚焦经营主体反映的突出问题，立足本区域产业发展特点，主动作为、开拓创新、攻坚克难，工作中形成了一批好案例、好做法。今年11月，经过网络投票初选和专家集中评审，选出各区创新性强、实效性高、可复制推广的20个优化营商环境优秀案例（见附件）。
为促进各区间相互学习借鉴，提升上海整体营商环境水平，现印发公布2023年度各区优化营商环境优秀案例。下一步，各区要对标先进、发力创新，压茬推进营商环境持续优化提升，切实打造近悦远来的营商发展环境，争做企业的“事业合伙人”，让企业在上海办事更顺心、经营更放心、扎根更安心。
附件：上海市2023年度各区优化营商环境优秀案例
上海市发展和改革委员会
