# 虹口区绿色低碳产业发展“十五五”规划

“十五五”时期是我国基本实现社会主义现代化夯实基础、全面发力的关键时期，是国家绿色转型战略逐步由“能耗双控”全面转向“碳排放双控”的实施阶段，也是如期实现2030年碳达峰目标的决胜阶段。根据《虹口区国民经济和社会发展第十五个五年规划纲要》等文件精神，立足本区产业基础与城区功能定位，加快推动千亿级绿色低碳产业集群集聚成势，特编制本规划。

一、总体目标

“十五五”期间，以习近平生态文明思想为遵循，全面贯彻落实碳达峰碳中和重大战略决策，立足上海“五个中心”建设总体布局，牢牢把握2030年碳达峰战略机遇，围绕“产业发展绿色化”和“绿色发展产业化”，聚焦“强化企业与平台招引、聚焦应用场景打造、优化企业服务生态、深化产业图谱研究、推进光伏与双碳工作、营造科普宣传氛围”六个方面，加快绿色低碳千亿产业集聚成势、全面提升产业显示度与核心竞争力。

二、主要任务

践行绿色低碳发展理念，全域推进经济发展绿色化、城区运行绿色化、城市生活绿色化全方位绿色转型，以张江高新区虹口园为核心载体，聚力培育千亿级绿色低碳产业集群，构建头部引领、腰部提质、高成长企业集聚的梯次产业生态。

（一）夯实企业根基，筑牢千亿集群建设支撑

1.实施梯度赋能，推动企业进阶提质

持续做细做实绿色低碳企业全周期服务保障工作，常态化开展走访调研，精准掌握企业生产经营、技术研发、市场拓展及要素需求等发展动态。鼓励头部企业进一步上规模、提能级，重点支持其深耕主业、拓展国内外市场、整合上下游优质资源，发挥链主引领作用，带动产业链整体协同升级；鼓励腰部企业进一步上台阶、增实力，引导企业加大技术改造与创新投入，扩充优质产能、打磨核心产品，持续提升市场竞争力与行业影响力；鼓励高成长企业多多益善，持续加大孵化培育力度，优化人才、场地、资金、技术等关键要素供给，破解初创及成长型企业发展瓶颈，助力企业快速扩容、提质增效。梯度赋能企业分层培育、提质扩容、迭代升级，为区域绿色低碳千亿产业整体布局筑牢坚实的企业与产业支撑。

2.全面挖掘潜力，加速传统产业绿色转型

立足辖区产业发展实际，同步盘活传统产业存量资源，大力推动传统产业向数智化、绿色化、融合化方向迭代升级，补齐区域产业低碳转型短板。积极引导辖区传统企业主动革新生产经营模式，大力推广引入智慧能源管理系统、新型低碳生产装备，普及资源循环利用、清洁生产等绿色发展模式，有效降低生产能耗与污染物排放，全方位提升企业资源利用效率。同时强化专项政策协同赋能与转型标杆示范引领，精准扶持传统企业开展绿色技改、低碳升级，持续提升全域产业绿色关联度，逐步构建全域覆盖、全链联动、新旧协同的绿色低碳产业发展全新格局。

3.细化关联系数，完善统计监测机制

夯实区域绿色低碳产业统计测算体系基础、提升产业研判精准度，搭建数字化监测研判体系，依托人工智能语言大模型技术优势，针对辖区各类市场主体的绿色低碳业务开展智能化、精细化量化分析。创新构建“主营业务定档-附加项加分-信息校验-模糊数据校准”标准化研判流程，为每家企业建立专属绿色低碳“一企一档”关联系数，精准界定企业绿色低碳产业关联属性。同时结合企业自主填报的经营、技改、研发等专项材料开展二次人工复核校验，双向修正数据偏差，有效保障企业绿色低碳关联系数数据精准化、档案可追溯、指标可对比，全面健全产业动态统计、实时监测、精准研判的常态化工作机制。

（二）加大精准招引服务，聚焦产业图谱全方位协同

1.碳服务：深化碳市场建设，全面提升服务能级

紧扣国家碳排放总量和强度双控要求，支持上海环交所继续发挥全国碳排放市场功能，扩大碳市场覆盖范围，配合做好碳排放配额分配、核查、清缴等全流程服务保障。积极争取全国碳排放交易机构挂牌设立，建立配额储备和市场调节机制，丰富交易产品，优化交易流程，提升交易规模。培育壮大一批技术服务商，形成覆盖碳核查、碳估值、碳咨询、碳培训及法律、设计咨询、人力资源等多元化服务业态。持续开展区级温室气体排放清单编制，推动大气污染排放与温室气体排放融合清单的应用。依托虹口区数据创新实验室，鼓励开发碳足迹追踪、碳减排量核算等数字化应用场景。探索碳数据资源化、资产化、产品化。推动企业开展能碳数据平台建设，提升数智化管理水平，助力自主碳核算、碳控制、碳减排。

2.绿色技术：结合市场需求导向，强化创新成果转化

支持龙头、链主企业组建各类技术研发平台，推动绿色关键核心技术研发与集成应用。联合链主企业和科研院所，共建专业孵化器、加速器和新型研发机构，加快培育优质孵化器。依托上海生态环境科技研发与转化平台建设，围绕源头创新、概念验证、示范应用、投资孵化、产业落地、发展加速全链条，构建绿色低碳科技创新生态，搭建一个平台、组建一个机构、落地一批项目的运行体系，加快创新成果概念验证与中试放大转化，培育和加速一批具有代表性的绿色低碳企业在虹口区集聚。鼓励企业加大科技创新投入，攻坚新技术，开发新产品，突破关键核心技术。支持企业专业化、精细化、特色化发展，加强企业创新能力建设。围绕重点领域产业链供应链需求，支持企业提高产业配套能力，着力提升产业链供应链韧性和安全水平。鼓励企业承接重大科技项目、产学研合作项目，开展核心技术攻关，加速绿色技术迭代与产业创新发展，努力打造中试平台或场景试验场等公共创新平台。支持企业联合科研院所、高等院校力量，建立创新联合体，组建新型研发机构、企业技术中心等。

3.绿色航运：发展绿色燃料交易平台，打造服务枢纽

依托上海航运交易所核心功能优势，紧扣国家部委绿色航运发展部署，积极争取绿色船用燃料国际认证体系事务中心和上海国家航运绿色燃料交易平台落地，试点开展绿色燃料认证确权、登记、交易、结算、注销全闭环业务，打造集船舶交易、航运指数、绿色燃料交易等服务产品，探索绿色燃料指数研发。推动绿醇、绿氢、绿氨等清洁绿色燃料在航运领域规模化应用，推动上海航运交易所向国家化、专业化、数字化深耕发展，为成为具有国际影响力的航运要素交易市场、航运指数供应商和航运信息服务商筑牢坚实基础。建设全球航贸供应链管理服务平台，以数据底座为核心、功能模块为支撑、多元应用为延伸，整合航运贸易全链条数据要素，覆盖从市场需求、采购供应、生产制造、物流仓储、跨境贸易到市场销售、售后服务的“端到端”业务环节。发挥国际航运绿色发展共同体作用，支持建设绿色燃料投资集采平台，整合绿色燃料供需资源，促进绿色燃料规模化、低成本供应。支持建设国际航行船舶能效管理综合服务平台，充分发挥船舶能效管理机构作用，指导航运企业有效实施国际海事组织温室气体减排各项措施。

4.绿色金融：紧扣绿色金融大文章，提供高质量金融供给

紧扣绿色金融大文章，探索绿色金融产业规模统计测算方法。推动碳交易与绿色金融有效衔接，争取各类绿色金融试点先行先试，聚焦多元化碳金融产品创新，打造可复制、可推广的碳金融产品与服务模式。稳步拓展气候投融资、绿色指数、水信托、碳信托等多元化绿色金融产品服务，推进碳指数、碳保险等工作创新。引导金融机构将绿色低碳转型因素纳入资产组合管理考量，推动环境要素与金融要素深度融合，争取碳资产纳入金融机构合格担保品范围，引导金融机构在依法合规、风险可控、商业可持续的前提下，开发与资源环境要素相关的绿色信贷、绿色保险、绿色债券等金融产品和服务。强化绿色金融政策支撑，推动碳金融产品规模化发展，创新碳保险、挂钩碳指数的碳债券等产品开发。

5.绿色贸易：推动业态转型升级，拓展国际市场空间

积极拓展国际贸易新业态，发挥全球航贸供应链管理服务平台作用，引导龙头企业带动外贸产供链加快绿色低碳转型。聚力培育具有区域特色的服务贸易新优势，推动“产品”向“产品+服务+数据”高附加值贸易转型，引导优质企业发展成为综合服务提供商。加大绿色低碳产品推广力度，推行ESG认证，降低产品碳排放量。拓展绿色低碳领域贸易合作，引导外贸产供链加快绿色低碳转型，主动对接国际绿色贸易规则，稳妥应对欧盟碳边境关税（CBAM）影响。

（三）健全产业生态体系，夯实区域功能底座

1.加快功能性机构引入，发挥要素配置协同发力

着力新增功能性机构或平台2-3家。发挥区域龙头性绿色低碳功能性平台“四梁八柱”作用，依托上海生态环境科技研发与转化平台，北外滩绿色低碳产业联盟，联动两中心三协会等专业机构，常态化开展资源互通、企业对接、技术推介活动，打通产业资源、技术成果、市场需求的对接壁垒，构建多方联动、优势互补、协同赋能的产业要素配置体系，持续激活区域产业发展动能。

2.抢占行业标准高地，提升产业竞争话语权

锚定区域“双碳”目标，依托区内功能性机构、科研院所和优质企业，持续完善绿色标准化体系，推进绿色产品认证、绿色标识培育等体系建设，积极支持企事业单位申报各级标准化试点示范项目，鼓励牵头或参与团体标准制修订，主动投身地方、国家乃至国际低碳标准研制工作，积极推动与国际标准衔接互认，以标准创新引领产业升级，持续提升虹口绿色低碳产业行业影响力与核心话语权。

3.优化营商环境建设，厚植产业发展沃土

创新多元化投资支持机制，撬动市场投资。深化“三贷联动”“虹口秒贷”等特色融资服务，切实降低绿色低碳企业融资成本。探索设立专注于绿色低碳的基金。常态化搭建政企沟通对接渠道，通过座谈走访、线上反馈、专人对接等多种方式倾听企业诉求、收集发展建议，快速响应、闭环解决企业发展难题。精准落实绿色低碳产业惠企政策，提供融资、人才、法律、出海等增值服务，持续扩容“免审即享”“直达快享”政策服务清单，扩大政策覆盖范围。

（四）强化场景示范引领，提升产业转型升级

坚持以场景育产业、以应用促发展，鼓励政府机关、社区各类服务阵地、学校、医院等公共机构向市场加大场景开放力度，推出各类应用场景示范案例30个，推动从“一个场景”到“一类场景”，促进产业链上下游联动和企业集聚，形成绿色低碳产业生态。

1.培育绿色低碳新领域场景

聚焦绿色低碳产业前沿赛道与未来产业变革方向，前瞻布局新兴领域创新场景。重点围绕标准体系引领、专业人才培育、碳管理服务建设、企业ESG规范化发展、生态产品价值实现等领域，系统性开展绿色低碳场景技术攻关、创新模式探索和规模化试点示范。充分激发市场主体创新活力，鼓励企业深耕生产性服务细分领域，积极培育中试验证、质量检验检测、技术成果转化等专业化服务场景，持续推动绿色低碳产业业态迭代升级，打通技术创新落地应用壁垒，加速优质低碳场景从科研成果走向市场化规模化应用。

2.打造传统产业绿色转型场景

立足产业绿色提质增效发展需求，全方位推进传统产业绿色低碳转型赋能。持续推进可再生能源建设，稳步扩大区域清洁能源装机规模，区域累计并网量超25000千瓦（确保完成市下达目标），探索光伏+近零能耗建筑、道路隔音棚等多元化应用场景。聚焦重点载体绿色升级，加快零碳楼宇（园区）、虚拟电厂和绿色工厂建设，推动楼宇用能系统智能化升级，完善储能配套设施，扩大绿电应用范围，推进既有建筑节能改造，全面深挖建筑领域节能降碳潜力，持续提升区域传统领域绿色低碳发展整体水平。

3.构建社会治理与民生普惠场景

全方位拓展面向居民生活、生态宜居的绿色低碳民生应用场景。持续完善生活垃圾资源化、无害化工作体系，健全垃圾分类、回收利用、资源化处置全链条机制，有效提升生活垃圾综合利用效率。大力推广雨水蓄集、中水回收循环利用等节水节能技术。常态化开展全民绿色低碳科普宣传，积极倡导文明节约生活方式，持续深化“光盘行动”、绿色出行、低碳消费等文明实践。健全完善碳普惠运行、激励、管理机制，引导全民主动参与低碳行动，因地制宜打造特色生境花园、口袋公园等，持续丰富多元化、接地气、可普及的绿色低碳民生场景。

（五）优化空间布局结构，打造特色产业载体

深化“双北联动”战略，以张江高新区虹口园为核心载体，创建特色空间载体10家左右，提升绿色低碳改造成效，促进绿色技术、人才、资金等要素在全区范围内顺畅流动，提升区域整体竞争力与影响力。

1.北外滩区域：打造绿色总部服务标杆

依托北外滩高端服务业集聚发展试验区，加快重点楼宇绿色转型，持续推进总部经济和碳服务类企业集聚。发挥龙头链主企业带动作用，形成集聚规模效应。积极拓展多元孵化路径，依托创新平台，引导企业孵化向绿色低碳领域转型。支持白玉兰广场、滨港商业中心等楼宇开展绿色低碳创建。严格落实新建建筑绿色建设要求，新出让地块大型公共建筑全面执行绿色民用建筑三星级标准，推进建筑垃圾分类处理和资源化利用，鼓励再生建材产品生产应用。

2.北中环区域：构建绿色技术转化高地

立足北中环科创产业集聚带，重点深耕新型储能、新型电力系统、合成生物、碳减排技术、智能电网等核心领域，提升科创策源能力和成果转化。采用“存量提质+增量高质”双路径推进，对上汽花园坊、临港新业坊等载体进行绿色化、专业化提档升级；发挥区域内龙头链主企业作用，依托天工开物、绿色土工中心等创新孵化器，推动科技创新资源和产业资源高效对接。

3.虹口全域：深化“双北联动、全域协同”发展格局

建立常态化对接协同机制，推动功能互补、空间互联、要素互通，推动北外滩高端服务业资源与北中环硬核技术成果双向赋能，构建“总部+研发”“服务+技术”的闭环链条。同时，以嘉兴路街道作为市级碳达峰碳中和试点标杆，充分用好国家绿色发展基金投资契机，逐步拓展至全区各街道，依托社区载体与公共空间全域推广绿色低碳治理实践，加快形成全域覆盖、可复制、可推广的城区绿色低碳生活方式。

三、组织实施

严格落实《上海市发展规划条例》要求，发挥规划导向作用，完善规划实施机制，加强规划实施保障，确保本规划提出的主要目标任务如期实现。按照“531”的总体工作框架（“5”即“十五五”规划，“3”即三年的实施意见；“1”即当年度工作要点），分阶段梯次推进，构建从规划到落地的工作体系闭环。强化市区协同联动，主动对接市级部门与产业平台，集聚优质资源赋能区域绿色低碳产业发展，激活产业发展内生动力。完善政策资金保障，统筹使用绿色低碳产业专项资金，优化资金全流程管理，提升资金使用效益，持续健全产业培育、企业赋能、创新激励等扶持政策体系，筑牢产业发展政策根基。压实工作责任与督导考核，细化工作分工、明确岗位职责，实行闭环管理与常态化督导问效，推动各项工作落地见效。强化人才队伍支撑，围绕产业发展需求，引育碳服务、绿色技术等领域高层次人才与专业技能人才，完善人才服务体系，夯实产业发展智力支撑。深化品牌活动引领，着力将“天骄湾杯”绿色低碳创新创业大赛打造成为虹口绿色低碳的品牌特色，汇聚产业创新资源，持续传播虹口绿色低碳发展理念与成果，讲好“绿色低碳故事”。健全监测评估体系，开展规划实施情况动态监测、中期评估和期末评价，强化监测结果和评估报告的有效应用。
