# 上海市应急管理局关于注销汉高化学材料（上海）有限公司等21家企业危险化学品安全生产许可证的通报

闵行区、嘉定区、金山区、松江区、青浦区、奉贤区应急管理局，各有关企业：
根据《危险化学品生产企业安全生产许可证实施办法》（原国家安全监管总局令第41号）第四十条的规定，上海市应急管理局决定注销汉高化学材料（上海）有限公司等21家企业危险化学品安全生产许可证。
特此通报。
