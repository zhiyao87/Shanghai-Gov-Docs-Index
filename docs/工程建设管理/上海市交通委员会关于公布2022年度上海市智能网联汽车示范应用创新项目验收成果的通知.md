# 上海市交通委员会关于公布2022年度上海市智能网联汽车示范应用创新项目验收成果的通知

各有关单位：
为加快上海科技创新中心和国际航运中心建设，不断提升城市数字化能级和核心竞争力，构建具有上海特色的智能网联汽车产业体系和应用生态，服务智慧交通体系建设，根据《关于开展2022年度上海市智能网联汽车示范应用创新项目的通知》（沪交科〔2022〕90号），以及《关于开展2022年度上海市智能网联汽车示范应用创新项目验收工作的通知》（沪交科〔2023〕3号）要求，我委对2022年度13个智能网联汽车示范应用创新项目开展了终期验收。12家创新试点企业共投入548辆智能网联汽车（含无人驾驶装备），完成智能载人56.3万单、智能载货12.6万TEU、智能配送63万单、智能清扫作业超1.6万小时。
智能网联汽车示范应用创新试点工作，有力支撑了法规政策制定，依托相关实践经验和输出成果，实现智能网联汽车地方法规及政策突破，形成比较完备的政策保障体系。极大助推了企业研发创新，为自动驾驶企业打造良好试验田，提供测试应用条件，助力智驾技术提升。初步构建了创新应用生态，精准匹配不同的业务场景，开展示范性质的交通运输服务，打造智能出行服务、智能货物转运、智能生产作业等创新应用生态。积极探索了商业运营路径，创新试点企业积累抓住用户流、降低运营成本、提升组织水平等运营经验，部分项目也成功拓展至全国多地开展运营活动，智能网联汽车的商业运营路径渐趋清晰。
经现场检查、企业自评、第三方机构评估及专家组论证，智能出租（百度智行、裹动科技、赛可出行）、智能重卡（上港集团）、智能零售（新石器）、智能配送（三快科技、白犀牛）、智能清扫（酷移机器人）、智慧车列（德鑫礼行）等6类场景的9个创新项目完成预期试点目标（详情见附件），通过终期验收。
特此通知。
