# 上海市交通委员会 关于印发《上海市车路协同创新应用工作实施方案（2023-2025年）》的通知

各有关单位：
根据《上海市人民政府办公厅关于印发〈上海市全面推进城市数字化转型“十四五”规划〉的通知》（沪府办发〔2021〕29号）要求，为加快推进车路协同技术在本市交通领域的创新应用，上海市交通委员会制定了《上海市车路协同创新应用工作实施方案（2023-2025年）》。现予以印发，请遵照执行。

上海市交通委员会
2022年11月1日
