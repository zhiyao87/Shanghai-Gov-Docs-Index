# 上海市水务局关于印发《上海市水工程建设规划同意书制度管理办法实施细则（试行）》等文件的通知

上海市水务局关于印发《上海市水工程建设规划同意书制度管理办法实施细则（试行）》等文件的通知

沪水务〔2024〕257号

临港新片区管委会、各区水务局：

为贯彻落实《国务院办公厅关于全面实行行政许可事项清单管理的通知》（国办发〔2022〕2号）精神，进一步落实水工程建设规划同意书制度，我局制定了《上海市水工程建设规划同意书制度管理办法实施细则（试行）》《上海市水工程建设规划同意书论证报告编制导则》《上海市水工程建设规划同意书技术评审要点》，现予印发，请遵照执行。自印发之日起，上述文件适用范围内的水工程，除已开工的项目外，均须按要求办理水工程建设规划同意书行政许可。

特此通知。

附件：1.上海市水工程建设规划同意书制度管理办法实施细则（试行）

2.上海市水工程建设规划同意书论证报告编制导则

3.上海市水工程建设规划同意书技术评审要点

上海市水务局

2024年6月7日
