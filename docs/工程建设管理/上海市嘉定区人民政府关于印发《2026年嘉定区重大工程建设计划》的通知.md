# 上海市嘉定区人民政府关于印发《2026年嘉定区重大工程建设计划》的通知

各镇人民政府，区政府各委、办、局，街道办事处，嘉定工业区、菊园新区管委会，各重大项目单位：

区重大工程建设工作专班拟定的《2026年嘉定区重大工程建设计划》已经区政府研究同意，请各有关单位认真执行，扎实推进项目实施，以月保季，以季保年，确保完成全年建设目标任务。

上海市嘉定区人民政府

2026年1月13日

2026年嘉定区重大工程建设计划

2026年是“十五五”规划的开局之年，也是乘势而上、推动高质量发展的关键一年。为牢牢把握新发展阶段的战略机遇，持续强化重大项目“强支撑、增动能、提品质、优治理”的牵引带动效应，制定《2026年嘉定区重大工程建设计划》。

2026年嘉定区共安排重大工程正式项目67个。其中，嘉定新城30个、北虹桥16个，嘉定新城、北虹桥两大战略引擎区域项目数量占比约67%。计划新开工项目27个、计划建成项目16个、在建项目24个，项目总投资约762亿元，2026年计划完成投资120.9亿元。同时安排9个预备项目。

一、正式项目

1.市政设施类

市政设施类项目5个，其中计划新开工2个、计划建成2个、在建1个，项目总投资约17.1亿元，2026年计划完成投资6.9亿元。

（1）2个计划新开工项目分别是：嘉定新城绿环三期和“联影大道”嘉唐公路（绿意路-宝钱公路）；

（2）2个计划建成项目分别是：汇旺路（和陈公路-世盛路）和“联影大道”嘉唐公路（树屏路-绿意路）；

（3）1个在建项目是：110kV输变电工程（云安、发祥、嘉好、嘉罗输变电等）。

2.社会事业类

社会事业类项目14个，其中计划新开工6个、计划建成6个、在建2个，项目总投资约87.3亿元，2026年计划完成投资16亿元。

（1）6个计划新开工项目分别是：嘉定工业区04-10地块高中、菊园新区九年一贯制学校（嘉一实验初级中学）、江桥镇37-06地块小学（星慧小学）、嘉定新城G02-11地块高中（上实高中）、南翔镇44-04、21-05地块完全中学（复旦附中嘉定学校）和南翔医院二期；

（2）6个计划建成项目分别是：嘉定新城复华园区小学、嘉定区江桥镇金虹社区K1-06地块中学新建工程（上海市嘉定区曹杨二中江桥实验中学海波路校区）、安亭镇18CA-01地块幼儿园、安亭新镇二期13-01地块初级中学、江桥大居商品房配套B地块九年一贯制学校和区中医医院迁建工程；

（3）2个在建项目分别是：上海大学嘉定校区扩建工程和区中心医院整体改扩建工程。

3.产业发展类

产业发展类项目29个，其中计划新开工13个、计划建成5个、在建11个，项目总投资约188亿元，2026年计划完成投资39.3亿元。

（1）13个计划新开工项目分别是：南亚电子产业研发创新中心、上海开艺建筑新能源科技创新中心、鼎捷软件上海总部、延锋安亭新基地、越炬新能源汽车配套零部件生产基地、汽车自动化生产线生产基地（丹景一期）、重塑新能源电堆生产研发中心、圣和药业上海研发中心、TMSR新能源核心装备总装生产线（一期）项目（钍基熔盐堆项目）、星环聚能上海实验基地、医疗器械生产、研发、销售基地、佳轩集团智能制造研发生产总部和光子芯片研发能力提升项目；

（2）5个计划建成项目分别是：联影生产研发基地高端医疗影像设备产业化基金项目（研发+工业）、嘉定新城主城区JDC11201单元25-04地块（汽车芯片设计产业园二期）、上汽清陶工业厂房、硅产业总部项目和新型直接驱动先进激光实验平台条件建设项目；

（3）11个在建项目分别是：生命元谷•翔云科技园二期产业化基地、嘉菊智湾人工智能产业园项目、物联网研发中心、华瑞时尚集团上海总部、聚升集团全球贸易中心项目、苏州建研院上海总部、厚朴中医总部基地、环同济片区21-02B地块方正电机研发总部、上海清陶研发中心项目、核电MSR管研发制造总部和凯笛芯全球智能发行总部。

4.住房保障类

住房保障类项目7个，其中计划新开工3个、计划建成3个、在建1个，项目总投资约78.8亿元，2026年计划完成投资15.9亿元。

（1）3个计划新开工项目分别是：嘉定区华亭新市镇镇区16-08地块征收安置房项目、嘉定区黄渡大居（一期）22A-02地块征收安置房项目、嘉定区黄渡大居（一期）23A-01地块征收安置房项目；

（2）3个计划建成项目分别是：南翔镇JDC2-0501单元14-06地块保障性租赁住房项目、南翔镇JDC2-0201单元37-05地块征收安置房项目、南翔镇JDC2-0201单元18-05地块征收安置房项目；

（3）1个在建项目是：嘉定区城北大型居住社区JD010201单元0107B-01地块征收安置房项目。

5.两旧一村类

两旧一村类项目12个，其中计划新开工3个、在建9个，项目总投资约390.9亿元，2026年计划完成投资42.9亿元。

（1）3个计划新开工项目分别是：安亭镇黄渡（南区）项目、南翔镇红翔村项目和徐行镇徐行村项目（一期）；

（2）9个在建项目分别是：西门历史文化街区、江桥地产北虹城中村项目、嘉定工业区（北区）朱桥地块项目、新成路街道新成村项目、马陆镇彭赵村（北片区）项目、马陆镇彭赵村（南片区）项目、安亭镇黄渡（北区）项目、江桥镇五四村高潮村项目和徐行镇徐行老街项目。

二、预备项目

9个项目分别是：

1.110kV输变电工程（永丰、丰华、嘉前站）；

2.胜华波智能科技装备研发及生产制造基地；

3.天海电子电器研发中心暨汽车零部件生产基地；

4.六晶材料研发生产总部；

5.丹景二期；

6.上海三只小山羊总部研发生产基地；

7.研发中心建设项目及精准激光系统产业化建设项目；

8.上海医药现代药械创新产业园项目；

9.中国科学院上海微系统与信息技术研究所新微项目。

预备项目条件成熟实现开工后，将转化为正式项目并纳入统计范围。此外，我区涉及的2026年市属市重大工程有关项目，待市年度计划下达后一并推进实施。
