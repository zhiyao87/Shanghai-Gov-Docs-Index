# 上海市住房和城乡建设管理委员会关于批准《地下空间一体化设计标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《地下空间一体化设计标准》为上海市工程建设规范的通知

沪建标定〔2026〕127号

各有关单位：

由华东建筑设计研究院有限公司、上海市城市建设设计研究总院（集团）有限公司、上海市地下空间设计研究总院有限公司主编的《地下空间一体化设计标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2477-2026，自2026年9月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，华东建筑设计研究院有限公司负责解释。

特此通知。

2026年4月2日
