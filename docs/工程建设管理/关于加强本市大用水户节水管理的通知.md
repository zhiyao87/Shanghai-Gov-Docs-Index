# 关于加强本市大用水户节水管理的通知

关于加强本市大用水户节水管理的通知

沪水务〔2021〕545号

各区水务局、区经委（商务委）、区卫生健康委、区机管局，供水企业、各大用水户：

为深入贯彻习近平生态文明思想和“节水优先、空间均衡、系统治理、两手发力”的新时期治水思路，加快落实《国家节水行动方案》和《上海市节水行动实施方案》，积极树立“节水即减污”的新发展理念，按照水资源刚性约束和节水减排工作的要求，现就加强全市大用水户节水管理工作通知如下：

一、总体原则

大用水户是重要的用水单元，做好节水工作意义重大。以强化大用水户节水管理为重点，以“节水减污，点滴开始；供排联动，系统治理”为主要原则，进一步提高用水效率和节水水平，为促进城市绿色发展、推进碳达峰碳中和提供支撑。

二、管理范围

大用水户指本市年用水量50万立方米以上的企业和单位，根据2019年全年用水情况统计（2020年受疫情影响），全市大用水户共157家（名单见附件）。

三、具体目标

2021年，完成21家大用水户节水型企业（单位）创建，用水量较2019年力争下降110万立方米（日节水量3000立方米左右），节水率较2019年提升3%。

2022年，大用水户节水型企业（单位）创建率达到75%，节水率较2019年提升5%。

2023年，大用水户节水型企业（单位）创建率达到90%，节水率较2019年提升8%。

四、主要措施

（一）实行“一企一策”管理

各大用水户需根据《上海市水资源管理若干规定》等要求，定期开展水平衡测试，因地制宜使用雨水、再生水等非常规水源利用，积极推动污水资源化利用，开展企业用水审计、水效对标和节水改造，推进企业内部工业用水循环利用，提高重复利用率。市区两级水务主管部门应强化用水定额管理，促使大用水户严格按照行业定额标准进行对标整改和提升，促进单位用水单耗稳步下降。各大用水户应做好每月节水数据统计、汇总和分析工作，并按时上报至市区两级水务主管部门。

（二）巩固节水示范载体建设

各大用水户是开展节水型载体创建的责任主体，应及时对照节水型示范（标杆）载体考核评价体系，组织开展节水型载体创建工作，充分发挥节水示范引领作用，全面提升用水户的用水效率和管理水平。继续依托节约用水工作联席会议制度，市区水务、经信、教育、卫健、机关事务、商务等部门协调推进工业企业、高校、医院、机关（单位）、宾馆、商业综合体等多领域大用水户的节水型载体创建工作。

（三）强化计划与定额管理

市区两级水务主管部门和供水企业应结合非居民用水超定额累进加价制度，深入推进实施大用水户的定额（计划）用水管理，严格执行定额水量核定和复核的增减条件，同步落实新一轮水价改革政策，进一步发挥价格杠杆的调节作用，促进大用水户提升节水管理水平。

（四）做好重点用水监控工作

大用水户均需纳入本市重点用水监控名录，市区供水企业应对大用水户全面实施远传表更换工作，并将实时在线数据上报给市区两级水务主管部门共享。水务主管部门要做好对大用水户用水在线监管工作，对大用水户用水异常现象做好主动服务和及时告知。大用水户对内部用水异常现象应做到及时排摸和整改。

（五）推动合同节水管理

鼓励在公共机构、高耗水工业企业等领域推进实施合同节水管理。大用水户可结合节水项目特点，科学合理选择合同节水管理模式，通过“智慧节水”等信息化手段提高单位用水精细化管理水平和用水效率。相关行业部门要加大合同节水管理宣传力度、宣贯有关政策和技术标准。

（六）强化节水监管和宣传教育

市区两级水务主管部门应加强对大用水户的节约用水监管工作，在用水单位的定额对标、节水管理制度建设、节水型器具使用、非常规水源利用等方面给予监督和指导，确保大用水户节水目标落到实处。各行业主管部门及大用水户应持续加强节水科普宣传，充分发挥单位内部多种宣传阵地作用，进一步引导树立节水责任意识。
