# 关于废止行政规范性文件《崇明区创新型企业总部认定和奖励管理办法》的通知

各乡、镇人民政府，区政府各有关部门，各产业园区：

根据《上海市行政规范性文件管理规定》相关要求，经评估，决定废止《崇明区创新型企业总部认定和奖励管理办法》（沪崇发改规〔2023〕1号）。废止文件自2026年8月15日起停止执行。

特此通知。

上海市崇明区发展和改革委员会

2026年8月6日
