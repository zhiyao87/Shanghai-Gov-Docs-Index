# 上海市住房和城乡建设管理委员会关于批准《自动化集装箱码头建设技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《自动化集装箱码头建设技术标准》为上海市工程建设规范的通知

沪建标定〔2021〕564号

各有关单位：

由中交第三航务工程勘察设计院有限公司主编的《自动化集装箱码头建设技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2371-2021，自2022年2月1日起实施。

本规范由上海市住房和城乡建设理委员会负责管理，中交第三航务工程勘察设计院有限公司负责解释。

特此通知。

2021年9月9日
