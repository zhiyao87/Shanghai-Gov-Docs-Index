# 关于废止本市水资源费相关政策文件的通知

各有关区发展改革委：

根据《关于印发〈水资源税改革试点实施办法〉的通知》（财税〔2024〕28号）和《关于本市水资源税改革试点有关事项的通知》（沪财发〔2024〕9号）有关要求，自2024年12月1日起，本市征收水资源税，停止征收水资源费。经清理，现对《关于调整本市深井水费、地下水水资源费有关事项的复函》等文件予以废止（详见附件）。
