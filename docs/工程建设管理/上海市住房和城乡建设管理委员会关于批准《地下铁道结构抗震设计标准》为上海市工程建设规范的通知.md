# 上海市住房和城乡建设管理委员会关于批准《地下铁道结构抗震设计标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《地下铁道结构抗震设计标准》为上海市工程建设规范的通知

沪建标定〔2022〕272号

各有关单位：

由同济大学、上海申通地铁集团有限公司和上海市隧道工程轨道交通设计研究院主编的《地下铁道结构抗震设计标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2064-2022，自2022年11月1日起实施。原《地下铁道建筑结构抗震设计规范》DG/TJ08-2064-2009同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，同济大学负责解释。

特此通知。

2022年6月23日
