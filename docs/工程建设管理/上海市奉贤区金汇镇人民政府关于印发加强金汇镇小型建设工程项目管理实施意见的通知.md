# 上海市奉贤区金汇镇人民政府关于印发加强金汇镇小型建设工程项目管理实施意见的通知

机关各科室、各村(居)委、企事业单位：

《关于加强金汇镇小型建设工程项目管理的实施意见》已经镇政府研究同意，现印发给你们，望认真贯彻执行。

特此通知。

2019年4月3日

关于加强金汇镇小型建设工程项目管理

为进一步规范本镇建设工程项目管理，加强廉政建设，确保建设工程公开、公正、公平和规范有序建设，依据《中华人民共和国建筑法》、《中华人民共和国招标投标法》、《中华人民国共和政府采购法》、《必须招标的工程项目规定》等有关法律、法规的规定和《关于加强小型建设工程项目管理的实施意见》文件精神，并结合本镇实际情况，特制定本实施意见。

一、适用范围

本意见所指的小型建设工程是指施工单项合同估算价在400万元以下(不含400万元)全部或者部分使用国有资金投资，国家融资的项目和使用国际组织或者外国政府贷款、援助的项目。机关团休楼堂馆所等建设项目依据有关文件规定执行。具体包括：

1、市政基础设施项目：乡村道路、桥梁，市政配套建设、土石方、桩基、绿化和环卫设施等工程。

2、公共事业项目：学校、医院和党政机关、事业单位的行政办公楼等的新建、扩建、改建工程以及修缮、装饰工程。

3、物业新建、维修项目：防水工程、下水管道工程、道路工程、绿化工程及其他各类维修项目。

4、旅游项目：景区道路、景观工程等。

5、农业水利基础设施项目：农用桥梁、排灌设施、驳岸、堤防、河道疏浚和土地整治等工程。

6、村居建设项目：和美宅基(楼道)、河道整治、农家会所、生活驿站、林荫小道、老年人基础设施改造、各类微家建设等项目。

7、镇政府认为需纳入的其他小型建设工程。

二、组织机构及其职责

成立金汇镇小型建设工程项目管理领导小组(以下简称“领导小组”)，领导小组组长由镇长担任，副组长由镇党委副书记(党群，政法)、镇党委委员(纪委、武装)、条线分管副镇长担任，成员包含镇所属相关科室、中心以及村(居)等相关部门负责人。领导小组下设常设机构金汇镇小型建设项目管理办公室(以下简称项目办)，主任由分管城建规划副镇长兼任，办公地点设在镇规划科，具体负责建设项目的初审、报建、招投标等日常管理和其他事务性工作。

三、小型建设工程过程管理

1、建设单位首先将预算通过的项目报项目办初审，初审通过后再提交镇政府讨论审批。

2、镇政府审批通过后，投资总额在100万元以下(含100万元)的小型建设项目，由镇政府全额出资且不需要办理规划、用地等手续的，由项目办按照有关规定向镇政府立项报批，并将批复文件抄送区发改委;市、区级建设财力直接投资或补贴占总投资 50%及以上的建设工程，应将项目方案和投资估算报区发改委审核，审核意见作为镇政府批复的依据。

3、镇政府审批通过后，投资总额在100万元(含100万)以上

400万元以下(不含400万元)的小型建设项目由项目办按照有关规定向区发改委立项报批。

4、各建设单位不得对项目进行拆分后按小型工程进行审批。

5、由建设单位负责办理方案设计、预算等前期手续。

(二)项目信息报送管理

1、投资总额100万元及以上的新建、改建、扩建工程、装饰装修工程、房屋修缮工程(非住宅工程)的小型建设工程，完成立项批复后，应进行项目信息报送。

2、投资总额100万元及以上的城市基础设施维修类的小型建设工程，完成区交通委或相关行业主管部门的批准文件后，应进行项目信息报送。

3、其他类型工程按照各行业规定执行。

(三)施工招投标管理

1、责任主体。由项目办牵头办理招投标手续，成立招投标工作小组，成员为：财经科、规划科、监察室、财政所、城建中心、投资公司、建设单位等部门负责人。

2、小型工程。施工单项合同估算值在100万元以上400万元以下(不含400万元)的小型建设工程，项目办按规定的程序委托具有相应资质的第三方企业，通过公开招标方式确定施工承包单位。

使用镇级政府性资金的小型建设工程，镇招投标工作小组受镇领导小组委托负责招标投标过程的监管;使用市、区级政府性资金的建设工程，由区招标办负责招标投标过程的监管;专业工程有行业专

门规定的，按相关行业管理规定实施。

3、小微工程。施工单项合同估算值在100万元以下(不含100万)的小微建设工程由项目办委托具有相应资质的第三方企业通过邀请招标方式确定施工承包单位，被邀请的投标人不得少于3人。施工单项合同估算值在10万元以下(不含10万元)的特殊小微建设工程，由项目办直接发包给有资质的施工单位。

4、特殊工程。对涉及公共安全、政府重大活动等急需修建的小型建设工程，可经镇领导小组集体讨论后，择优选择施工单位先行进行施工，并及时办理相关手续。

5、设备采购。小型建设工程中属设备、货物和服务等项目，一律纳入政府采购程序。国家机关、事业单位和团体组织使用财政性资金采购未达到公开招标数额标准的工程建设项目，应严格政府采购非招标方式执行，遵守《中华人民共和国政府采购法》及相关规定。

(四)施工管理

1、责任单位。建设单位为小型项目施工安全、质量、文明施工管理的第一责任人，项目办负责监管。

2、小型建设工程推行工程监理制。在开工前项目办通过邀请招标或经领导小组集体讨论后择优选择具有相应资质的施工监理单位。

3、变更设计。在施工过程中，因客观原因需要变更设计内容的，建设单位应当向项目办提出申请，再由项目办交镇领导小组审核同

意后由设计单位变更设计图。

4、投资控制。各建设单位必须严格控制因增加使用功能、提高标准等级而增加的工作量。凡属非增加使用功能、提高标准等级而增加的工程量，建设单位应当向项目办提出申请，再由项目办交镇领导小组审核同意后并由建设方、监理方和施工方共同签证确认。

未按上述规定进行审批，擅自增加工程量的，在工程结算时，增加部分的工程款不予认定。

(五)安全质量管理

1、建设工程开工前应办理安全质量监督申报手续，并按市、区现行的规定，由区或镇的建设管理部门实施安全质量监督管理。

2、建设工程中标单位应是具有施工资质的施工单位。施工单位应切实加强施工现场安全质量管理，项目经理对施工现场的安全质量负主要责任。

3、工程项目竣工后，建设单位应组织勘察、设计、施工和监理等单位进行工程验收，并在验收合格之日起 15 天内向项目办备案。同时按有关规定向建设行政管理部门办理竣工备案手续。

(六)资金管理

1、小型建设工程竣工结算必须按照招标文件和合同，并根据相关规定进行工程审计，对项目总投资30万元以上(含30万元)、400万元以下(不含400万元)由项目办在区财政局、区审计局已建立的资源库中确定社会中介机构负责审价;30万元以下的小型项目由财政所选择审价单位进行审价。

2、经镇领导小组审核同意，由建设各方签证确认增加的工程量，其工程款应按施工合同和招投标文件中约定的投标单价结算。最终结算价原则上应控制在不超过合同价款的5%以内。

3、付款的方式和期限严格按合同约定履行，财政所在接到由建设单位经办人、法人、上级主管部门负责人、分管领导及镇领导小组组长签字的付款确认单后及时足额安排付款。未经项目办审核的工程，财政所不予安排付款。

4、项目办安排接受上级部门的检查和审计工作，负责汇总统计并报镇监察部门备案。

(七)档案管理

项目办必须建立完善的建设工程项目档案管理制度，督促各建设单位收集整理档案，由档案管理员集中统一管理，并及时向项目办移交一套完整的归档资料。

归档的资料包括：工程项目立项批文、集体讨论的会议纪要、工程项目报建表、招标代理合同、招标文件、投标文件、施工图设计文件、评标记录、中标通知书、施工合同、施工单位证件(营业执照、资质证书、安全生产许可证、项目经理资格证书复印件)、监理合同、工程项目审计情况表和廉洁协议等。项目办应分年度建立小型建设项目数据库，以便管理和查询。

四、纪律要求与责任追究

(一)在工程建设中，参建各方必须严格遵循诚信、守法和自律的原则。

(二)建设单位与中标的施工单位就工程建设的有关事宜签订《施工协议》、《廉洁协议》和《安全协议》，明确各方的权利和义务。

(三)建设单位及上级(主管)部门的分管领导对工程项目负有直接和领导责任，切实加强对工程建设的管理和领导。违反下列规定的将追究领导或有关责任人员的责任：

1、建设单位有意将工程项目分拆以逃避项目办监管的行为及其他不严格执行本意见规定的;

2、工程建设管理人员以打招呼、插手干预等方式，影响工程招标正常进行的;

3、招投标过程中，各种弄虚作假和规避招投标行为的;

4、违反国家建设法律、法规及强制性标准，造成工程质量安全事故的;

5、未按工程建设规定，擅自扩大建设规模，提高工程建设标准，增加或变更使用功能，聘用无资质施工队伍组织施工的;

6、违反财务规定和纪律，收受贿赂或贪污等行为的;

7、工程竣工验收后，不按规定及时整理工程档案资料，导致档案缺失，或未按照规定验收，擅自交付使用的;

8、施工单位、监理单位和中介服务机构等出现违法违规行为，造成后果的;

9、其他违法违规行为。

五、其他

(一)本意见自发布之日起实施。原《金汇镇小型建设工程项

目管理实施意见》(奉金府 (2011 )34号) 自本意见发布之日起废止。

(二)本意见如与国家和上海市的有关法律、法规及上级文件精神有抵触的，以法律、法规及上级文件精神为准。

(三)本意见由金汇镇建设工程项目管理领导小组办公室负责解释。
