# 上海市住房和城乡建设管理委员会关于印发《上海市房屋（住宅）建筑防水工程质量指导手册》的通知

上海市住房和城乡建设管理委员会关于印发《上海市房屋（住宅）建筑防水工程质量指导手册》的通知

沪建标定〔2025〕12号

各区建设管理部门、各特定地区管委会、各有关单位：

为进一步提高本市房屋（住宅）建筑防水工程质量管理水平，我委组织市、区建设管理部门，有关行业协会，以及工程项目参建单位，编制了《上海市房屋（住宅）建筑防水工程质量指导手册》。现印发给你们，请遵照执行。

特此通知。

2025年1月8日
