# 关于经营性公墓墓穴、骨灰堂格位维护管理费有关事宜的通知

各经营性公墓、骨灰堂：

为做好公墓（骨灰堂）设施维修、保养和管理工作，现将墓穴（格位）维护管理费有关事宜通知如下：

一、收费标准

墓穴维护管理费每年的收费标准上限为45元/平方米，计费面积为墓穴证上载明的面积。

骨灰寄存、壁葬维护管理费每年的收费标准上限为格位费1%。

二、相关要求

各经营性公墓、骨灰堂应在政府规定的幅度内确定具体收费标准，并按规定做好明码标价。维护管理费一次性收取不超过10年，收取维护管理费应及时开具发票。经营管理单位应做好对收费的解释工作。

特此通知。
