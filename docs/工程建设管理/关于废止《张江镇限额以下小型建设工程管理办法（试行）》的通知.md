# 关于废止《张江镇限额以下小型建设工程管理办法（试行）》的通知

镇机关各办公室、镇属企事业单位、村(居)委、相关单位：

经评估且经张江镇2026年1月14日第101次镇长办公会议审议通过，决定自2026年2月1日起废止《张江镇限额以下小型建设工程管理办法(试行)》(浦张府规〔2025〕2号)。

特此通知。

上海市浦东新区张江镇人民政府

2026年1月22日
