# 关于进一步加强临港新片区建设工程招标投标规范管理工作的通知

关于进一步加强临港新片区建设工程招标投标规范管理工作的通知

沪自贸临管委〔2024〕37号

管委会各部门、各直属单位，临港新片区各镇、各开发公司、各有关单位:

《上海市建设工程招标投标管理办法实施细则》（沪建规范〔2024〕3号，以下简称《实施细则》）已正式发布，自2024年4月15日起施行。为贯彻落实好《实施细则》，进一步规范临港新片区建设工程招标投标管理，现将有关要求通知如下：

一、进一步明确职责分工，形成管理合力

临港新片区管委会建设和交通管理处（以下简称建交处）负责牵头协调和指导，临港新片区城市建设交通运输事务中心（以下简称临港建交中心）履行临港新片区建设工程招标投标管理办公室（以下简称临港标办）职责，负责临港新片区建设工程招标投标活动的具体管理工作。

临港标办负责临港新片区范围内必须招标的工程建设项目工程总承包、勘察、设计、施工、监理，以及与工程建设有关的重要设备、材料招投标的监督管理及招标投标情况备案；对评标委员会成员的确定方式、评标专家的抽取和评标活动监督检查；对本行政区域内招投标行为监督检查；汇总反馈监管信息；及时受理并依法处理建设工程领域的招投标投诉举报，加大投诉处理的查处力度。

临港建交中心（质量安全监督站，以下简称临港质安监站）受临港新片区管委会委托，负责临港新片区范围内建设项目质量安全监督管理。

临港新片区行政服务中心负责临港新片区招投标场所管理、合同信息报送管理、信息化建设等工作。

临港管委会发改处、财政处和建设工程相关职能部门按照各自职责，做好有关协同监管工作。

二、进一步加强招标市场与施工现场“两场”联动

畅通数据共享。临港标办将在招投标监管中发现的存在甄别数据异常、放弃中标、信访等情形的项目，纳入后续施工现场监督重点监管对象。临港质安监站对在施工现场检查中发现的存在无证施工、安全质量、人员到岗履职等问题的项目，一律倒查该项目招投标相关活动，加大对应招未招、工程转包、违法分包以及项目经理、项目技术负责人不在岗等违法违规行为的惩治力度。

完善对接机制。行政服务中心在合同信息报送中发现的违法违规行为，及时进行线索移交，由建交中心进行调查处置。

三、进一步深入推进招投标改革试点

在新片区范围内广泛推广远程分散评标，试点现场分散评标，促进招投标交易场所和评标专家资源互联互享。

鼓励招标人将属于上海市公共资源交易平台建设工程招投标分平台交易范围中第三类的项目，纳入该平台进行交易。

鼓励招标人接受银行保函等其他非现金的担保方式缴纳投标保证金。在临港新片区范围内探索推广银行保函电子化。

四、进一步建立健全监管机制

（一）加强智慧监管。临港标办对所有符合条件的招投标项目100%进行智慧监管。招标投标智慧监管系统发现异常情况2次及以上的，或收到招投标活动异常函询且复函明显不当2次及以上的，临港标办向相应管委会相关行业主管部门发出建设工程承发包风险警示函。

（二）强化监管处置。临港标办制定检查指引，对临港新片区建设单位、建设工程采取线下抽查等形式加强监管力度，严厉打击查处转包、挂靠、违法分包、出借资质、围标串标等违法违规行为。对问题易发多发环节以及发生过违法违规行为的主体，可采取增加抽查频次、开展专项检查等方式进行重点监管。抽查情况同时报送建交处。

（三）落实信用监管。加强对依法必须招标项目合同订立、履行及变更的行政监督，强化信用管理，防止“阴阳合同”“低中高结”等违法违规行为发生；坚决打击不诚信履约行为。对各招投标主体的违法违规行为及时进行处置，并按照规定纳入信用记录；严格执行行政处罚决定公开；坚持行政监督、社会监督和行业自律相结合。

五、进一步加大监管处罚力度

（一）加强对招标人的监管。对招标文件条款设置明显不合理、应提交集体决策材料而未提交或明显不规范的、担任评标委员会成员的招标人代表在评标过程中存在严重不当行为或履职水平明显不足等情况，临港建交中心依法采取函询、约谈、暂停招投标活动等举措，待纠正后方可继续。

（二）加强对投标人的监管。依托智慧监管，加强对投标人相互串通投标的线索排查。经查实存在违法行为的，依法实施行政处罚。

（三）加强对招标代理的监管。招标代理机构应当依法依规开展经营活动，严守职业道德，维护招投标活动当事人合法权益。建交中心严格招标代理行为记录，定期进行公示。将招标代理行为纳入市场检查监管范围，对参与围标串标等扰乱市场秩序的行为严格实施行政处罚。

（四）加强评标专家的监管。严肃评标纪律，按照评标专家评标行为记录办法对评标专家行为开展监管，落实约谈、扣分曝光、评标后评估各项工作，提高评标专家责任心、专业度。

六、进一步加强招标投标监管信息共享

临港标办每周通过线上线下方式对在临港新片区开展招投标活动的招标代理机构行为记录进行曝光，每半年度发布工作通报。

临港标办负责汇总临港新片区涉及国有资金的建设工程招标投标监管数据，如涉及以下数据，及时报送管委会相关行业主管部门：

（一）经招标人书面申请，符合法定免于招标情形，免于招标的项目；

（二）通过招标人集体决策启用资格预审、设置投标人筛选条件、进行定标澄清等事项的项目；

（三）招标人采用预选招标、批量招标的项目；

（四）招标代理机构行为记录情况；

（五）监管过程中发现的违法违规行为。

七、其他

自2024年4月15日《上海市建设工程招标投标管理办法实施细则》施行之日起，本通知同步生效。《关于进一步规范临港新片区建设工程招投标活动的通知》（沪自贸临管委〔2023〕50号）、《临港新片区建设工程招标代理信用管理办法》（沪自贸临管委〔2023〕148号）同步失效。各招投标主体应当严格遵守法规要求，依法合规开展招投标活动。
