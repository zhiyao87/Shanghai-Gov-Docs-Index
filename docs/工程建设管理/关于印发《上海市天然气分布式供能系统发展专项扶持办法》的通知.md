# 关于印发《上海市天然气分布式供能系统发展专项扶持办法》的通知

各有关单位：

为提高清洁能源综合利用效率，推进节能减排和能源转型发展，促进分布式供能规范有序、健康可持续发展。经市政府同意，市发展改革委、市住房城乡建设管理委、市财政局、市经济信息化委、市科委制订了《上海市天然气分布式供能系统发展专项扶持办法》。现印发给你们，请按照执行。
