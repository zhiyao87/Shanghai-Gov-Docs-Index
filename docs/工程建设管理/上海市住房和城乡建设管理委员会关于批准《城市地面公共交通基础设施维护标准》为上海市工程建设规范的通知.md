# 上海市住房和城乡建设管理委员会关于批准《城市地面公共交通基础设施维护标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《城市地面公共交通基础设施维护标准》为上海市工程建设规范的通知

沪建标定〔2022〕67号

各有关单位：

由上海城市交通设计院有限公司主编的《城市地面公共交通基础设施维护标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2104-2022，自2022年6月1日起实施。原《城市地面公共交通基础设施维护规程》DG/TJ08-2104-2012同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海城市交通设计院有限公司负责解释。

2022年1月26日
