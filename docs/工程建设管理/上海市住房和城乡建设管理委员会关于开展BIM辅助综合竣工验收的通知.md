# 上海市住房和城乡建设管理委员会关于开展BIM辅助综合竣工验收的通知

上海市住房和城乡建设管理委员会关于开展BIM辅助综合竣工验收的通知

沪建建管〔2026〕293号

各有关单位：

根据《上海市全面推进建筑信息模型技术深化应用的实施意见》（沪住建规范联〔2023〕14号）要求，本市在房屋建筑工程已推行BIM辅助施工图审查，提升了施工图审查效率和质量。为完善本市BIM技术应用全过程管理体系，经研究，于2026年7月20日起，在本市房屋建筑工程中推行BIM辅助综合竣工验收和数字化交付。现就有关事宜通知如下。

一、实施范围和做法

本市应当实施BIM技术应用的新建、改建和扩建的房屋建筑工程，在综合竣工验收时，由建设单位委托的设计或施工单位，下载使用“市工程审批系统信息填报客户端软件”（竣工验收版，简称“竣工验收填报软件”），填报或导入竣工验收工程相关指标以及模图同源的竣工模型和经设计、施工及监理单位签章的竣工图，完成数据和模型预检后，一键上传至上海市工程建设项目审批管理系统网页端（简称“市工程审批系统”）。建设单位登录市工程审批系统审核相关数据、模型和图纸后，提交综合竣工验收申请。

二、操作流程

（一）竣工模型和竣工图准备

建设单位委托的设计或施工单位（以下简称“填报单位”）应按约定，在综合竣工验收申请前，完成竣工模型建模以及竣工图编制，竣工模型内容和深度等应符合《上海市房屋建筑竣工建筑信息模型（BIM）交付要求》（沪建建管〔2026〕289号，以下简称“交付要求”）。填报单位完成竣工模型后，导出竣工模型（IFC格式）和“图模同源”竣工图（PDF格式）。“图模同源”竣工图按交付要求中规定的范围实施，非规定范围的竣工图按国家和地方标准规范自行选择方式编制。

（二）数据填报和模型与竣工图导入

建设单位在市工程审批系统中填报项目综合竣工验收申请信息，明确竣工验收内容并点击通知传图后，填报单位操作“竣工验收填报软件”关联该竣工验收申请和获取数据，按操作说明填报数据，导入竣工模型（IFC格式）以及设计、施工和监理签章的全套竣工图（PDF格式）。

（三）预检和上传

填报单位完成第（二）项工作后，通过“竣工验收填报软件”对填报数据、竣工模型和竣工图进行预检，预检通过后，一键上传至市工程审批系统。原综合竣工验收中要求上传的施工资料、监理资料扫描件以及施工图取消上传，后续逐步推行全过程数字化交付。

（四）复核和提交

建设单位登录市工程审批系统，查看填报单位上传的数据、竣工模型和竣工图，复核无误后，线上提交综合验收申请。

三、综合竣工验收办理

综合竣工验收牵头部门接收申请后，系统自动对提交的数据、竣工模型和竣工图进行联合预审，生成预审参考意见，辅助竣工验收部门出具验收意见。

四、推进安排

2026年7月20日起，选择符合条件的本市实施综合竣工验收的房屋建筑工程进行试点。2026年10月1日起，实施范围内的项目全面推行。

五、管理和服务

市工程审批系统中设立“BIM辅助竣工验收”专栏，同步公示咨询热线、线上咨询渠道等服务联系方式，解答和解决企业操作问题，持续完善系统功能和用户体验。

市、区建设管理部门和特定地区管委会应当做好BIM辅助竣工验收的管理和服务。组织开展BIM辅助竣工验收的业务和操作培训，建立所管辖项目的快速咨询服务渠道，并加强推进管理，保证规定范围的项目全面实施。

特此通知。

2026年7月1日
