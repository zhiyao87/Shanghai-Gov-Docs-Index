# 上海市水务局关于进一步加强水务建设工程现场关键岗位人员履约管理的通知

上海市水务局关于进一步加强水务建设工程现场关键岗位人员履约管理的通知

沪水务〔2023〕242号

各区水务局、相关地区管委会、相关市级建设单位：

《上海市水务局关于加强水务建设工程现场关键岗位人员履约管理的通知》（沪水务〔2023〕66号，以下简称《通知》）已于2023年2月1日正式印发各区、各单位。为切实督促相关措施落地落实，现将有关工作事项通知如下：

一、开展关键岗位人员线上视频考勤

上海市水务建设工程安全质量监督中心站已在上海市水务建设工程安全质量监督系统开发关键岗位人员线上视频考勤模块。请各在建水务工程施工总包单位自行选择采购相应的人脸识别考勤设备，并按要求进行接口对接和数据导入（考勤数据推送接口说明详见附件1）。人脸识别考勤设备采购费用列入项目安全防护、文明施工措施费用列支。请各建设单位督促施工总包单位及时完成设备采购和数据对接，并于5月1日对施工、监理单位关键岗位人员实施视频考勤。

二、落实建设单位履约管理主体责任

各水务工程建设单位应按照《通知》要求，进一步建立健全关键岗位人员变更和合同履约管理制度，加强关键岗位人员变更管理，及时开展对主要参建单位的履约考核，并按照项目管理权限，将关键岗位人员变更管理制度、2023年第一季度关键岗位人员变更和处置情况、2023年第一季度履约考核结果，于5月6日前报相应的水行政主管部门备案，后续情况应在每季度末最后一周完成上报。

三、强化政府日常监管和监督处置

各级水行政主管部门要加强对建设单位上报的关键岗位人员变更管理制度的审核，对于变更条件不明确、违约责任不严格、制度不具备操作性的变更管理制度，可责成建设单位予以修订并重新备案；要及时梳理汇总关键岗位人员变更和处置情况，实施掌握关键岗位人员考勤情况，并依据《通知》精神开展差别化监管和信用惩戒。

请各区水行政主管部门将所属水务工程2023年第一季度关键岗位人员变更和处置情况，于5月10日前汇总上报市局建管处，后续于每季度第一周完成上季度变更处置情况报送。
