# 关于印发《汽车清洗“一件事”办事指南》的通知

关于印发《汽车清洗“一件事”办事指南》的通知

沪水务〔2021〕725号

局属相关单位，虹口区绿化和市容管理局，各有关单位：

根据《上海市人民政府办公厅关于以企业和群众高效办成“一件事”为目标全面推进业务流程革命性再造的指导意见》（沪府办〔2020〕6号）和市审改办《关于做好2021年度“一件事”业务流程革命性再造工作的通知》（沪审改办发〔2021〕3号）要求，将汽车清洗企业办理“城镇污水排入排水管网许可”和“机动车清洗企业设立备案”两个事项整合为汽车清洗“一件事”。现印发《汽车清洗“一件事”办事指南》，请遵照执行。

特此通知。

上海市水务局

上海市绿化和市容管理局

2021年10月29日
