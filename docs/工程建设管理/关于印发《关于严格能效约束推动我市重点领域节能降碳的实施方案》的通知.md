# 关于印发《关于严格能效约束推动我市重点领域节能降碳的实施方案》的通知

各区人民政府，市政府有关委、办、局，各有关单位：

为落实国家发展改革委、工业和信息化部等5部委印发的《关于严格能效约束推动重点领域节能碳降的若干意见》，市发展改革委会同市经济信息化委、市生态环境局、市市场监管局制定了《关于严格能效约束推动我市重点领域节能降碳的实施方案》，现印发给你们，请认真贯彻落实。
