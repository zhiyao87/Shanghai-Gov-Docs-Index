# 上海市住房和城乡建设管理委员会关于批准《广电接入网工程技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《广电接入网工程技术标准》为上海市工程建设规范的通知

沪建标定〔2021〕726号

各有关单位：

由东方有线网络有限公司主编的《广电接入网工程技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2009-2021，自2022年4月1日起实施。原《有线网络建设技术规范》DG/TJ08-2009-2016同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，东方有线网络有限公司负责解释。

2021年11月17日
