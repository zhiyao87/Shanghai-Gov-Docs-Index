# 上海市住房和城乡建设管理委员会关于批准《装配式混凝土预制构件设计--生产数据交互标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《装配式混凝土预制构件设计--生产数据交互标准》为上海市工程建设规范的通知

沪建标定〔2025〕365号

各有关单位：

由上海中森建筑与工程设计顾问有限公司、上海市工程建设质量管理协会主编的《装配式混凝土预制构件设计--生产数据交互标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2478-2025，自2026年2月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，上海中森建筑与工程设计顾问有限公司负责解释。

特此通知。

2025年7月17日
