# 上海市住房和城乡建设管理委员会关于批准《城市轨道交通CBTC信号系统技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《城市轨道交通CBTC信号系统技术标准》为上海市工程建设规范的通知

沪建标定〔2021〕519号

各有关单位：

由上海申通轨道交通研究咨询有限公司主编的《城市轨道交通CBTC信号系统技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2369-2021，自2021年12 月1日起实施。

本规范由上海市住房和城乡建设理委员会负责管理，上海申通轨道交通研究咨询有限公司负责解释。

特此通知。

2021年8月10日
