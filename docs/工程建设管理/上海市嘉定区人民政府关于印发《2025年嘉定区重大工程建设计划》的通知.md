# 上海市嘉定区人民政府关于印发《2025年嘉定区重大工程建设计划》的通知

各镇人民政府，区政府各委、办、局，街道办事处，嘉定工业区、菊园新区管委会，各重大项目单位：

《2025年嘉定区重大工程建设计划》已经区政府研究同意，请各有关单位认真执行，扎实推进项目实施，以月保季，以季保年，确保完成全年建设目标任务。

上海市嘉定区人民政府

2025年2月17日

2025年嘉定区重大工程建设计划

2025年是“十四五”规划的收官之年，也是“十五五”规划的谋划之年。为切实发挥重大工程“保投资、显形象、惠民生、促发展”的示范引领作用，持续提升嘉定城市能级和核心竞争力，打造“创新活力充沛、融合发展充分、人文魅力充足、人民生活充裕”的现代化新型城市，2025年将继续重点推进一批事关经济社会发展的重大工程建设，制定《2025年嘉定区重大工程建设计划》。

2025年嘉定区共安排重大工程项目58个。其中，嘉定新城30个、北虹桥8个，嘉定新城、北虹桥两大战略引擎区域项目数量占比约65%。在58个项目中，计划新开工项目13个、计划建成项目31个、在建项目14个，项目总投资约518.1亿元，2025年计划完成投资101.3亿元。

一、市政设施类

安排重大项目13个，其中计划新开工2个、计划建成9个、在建2个，项目总投资约42亿元，2025年计划完成投资12.7亿元。

（1）2个计划新开工项目分别是：林润路（项泾-城北路）、汇旺路（和陈公路-世盛路）；

（2）9个计划建成项目分别是：“联影大道”嘉唐公路（树屏路-绿意路）、涉铁道路（外青松公路）、苏河源综合公园（体育设施和停车库综合工程）、嘉定西门文化公园和周边道路、2024年嘉定新城绿环绿道项目、申纪港公园改造提升项目、嘉定区湿垃圾资源化处理工程（二期）、嘉定新城污水处理厂三期、真江西排水系统初期雨水控污调蓄池工程；

（3）2个在建项目分别是：嘉定新城“集散交通”优化市政道路（崇文路、崇寿路、招贤路等）、北虹桥“城中村”配套市政基础设施（昌瑞路、万宁路、幸福水岸公园等）。

二、社会事业类

安排重大项目14个，其中计划新开工4个、计划建成6个、在建4个，项目总投资约65.3亿元，2025年计划完成投资22.4亿元。

（1）4个计划新开工项目是：嘉定新城JDC10502单元（复华园区）小学、江桥镇金虹社区K1-06地块中学、江桥镇37-06地块星慧小学、安亭新镇二期13-01地块中学；

（2）6个计划建成项目分别是：嘉定新城G13-4、G14-2九年一贯制学校（上海交通大学附属嘉定实验学校）、嘉定新城E14-4地块高中（嘉一实验高中）、嘉定区复华02-02地块高级中学、安亭同济小镇20-02地块中学（安亭初级中学）、南翔镇嘉程路中学、嘉定区看守所；

（3）4个在建项目分别是：江桥大居商品房配套B地块九年一贯制学校、江桥大居商品房配套B地块幼儿园、嘉定区中医医院、嘉定区中心医院。

三、产业发展类

安排重大项目22个，其中计划新开工6个、计划建成11个、在建5个，项目总投资约289.7亿元，2025年计划完成投资43.7亿元。

（1）6个计划新开工项目分别是：嘉定新城主城区JDC11201单元25-04地块项目（汽车芯片设计产业园二期）、聚升集团全球贸易中心项目、延锋首发地块搬迁项目、安亭镇环同济片区21-02B地块方正电机研发总部项目、上汽清陶工业厂房等；

（2）11个计划建成项目分别是：联影生产研发基地一期（高端医疗影像设备产业化基金项目）、联影生产研发基地二期（高端医疗影像设备产业化基金项目）、嘉定新城主城区JDC11201单元26-04地块项目（嘉宝智慧湾首发地块项目）、西门历史文化风貌区C1-02、C1-07、C3-04、C3-10地块项目、外冈工业园区JDS3-0101单元17-06地块厂房一期工程（法雷奥舒适及驾驶辅助系统生产基地）、中国海螺创业控股有限公司嘉定新城F16a-01、F16a-04地块项目（海创嘉定新城总部研发基地）、云+智能驾驶创新基地项目厂房及配套设施、真新南四块航空智谷产业园和通航产业园、上海机动车检测认证技术研究中心综合试验楼项目、氢燃料电池催化剂涂覆膜项目；

（3）5个在建项目分别是：嘉定工业区（北区）JDSB0202单元23-05A地块项目、上海清陶研发中心项目、新徕路工程研发项目、砂之船（上海嘉定）奥莱项目、硅产业总部项目。

四、住房保障类

安排重大项目9个，其中计划新开工1个、计划建成5个、在建3个，项目总投资约121.1亿元，2025年计划完成投资22.5亿元。

（1）1个计划新开工项目分别是：南翔镇JDC2-0501单元14-06地块保障性租赁住房项目；

（2）5个计划建成项目分别是：菊园新区JDC1-0404单元43-02地块租赁住房项目、菊园社区JDC1-0404单元51-03地块租赁住房项目、菊园新区JDC1-0403单元30A-01地块租赁住房项目、江桥镇金虹社区23-02及23-06、04-10地块征收安置房项目、外冈镇郊野单元01-01地块征收安置房项目；

（3）3个在建项目分别是：真新社区W06-1601单元13-05地块保障性租赁住房项目、南翔镇JDC2-0201单元37-05地块征收安置房项目、南翔镇JDC2-0201单元18-05地块征收安置房项目。
