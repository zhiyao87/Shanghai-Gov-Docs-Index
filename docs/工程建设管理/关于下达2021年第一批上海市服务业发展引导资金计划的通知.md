# 关于下达2021年第一批上海市服务业发展引导资金计划的通知

沪发改服务〔2021〕21号

各区发展改革委、经委（商务委）、财政局：

根据《上海市服务业发展引导资金使用和管理办法》（沪府规〔2018〕5 号，以下简称《引导资金办法》）的要求，市发展改革委、市经济信息化委、市商务委和市财政局等部门联合组织开展

了本市服务业发展引导资金的申报及评审工作。各区转报的申请材料通过专家评审和专业咨询机构评估，经市服务业发展引导资金评审小组研究审议、网上公示及征询行业主管部门的意见，现将评审结果和有关事项通知如下：

一、原则同意各区转报的“基于工业大数据的钢铁行业智能运维服务平台”等110 个项目列入2021年第一批上海市服务业发展引导资金支持项目，下达市级引导资金共计21760 万元，首笔拨付引导资金8600 万元（详见附件）。上述获得市服务业发展引导资金支持的区，应根据《引导资金办法》的要求按照不低于1 ∶1的比例安排配套资金（奉贤区、金山区、崇明区可按照不低于与市级支持1 :0.5 的比例安排配套资金）。

二、市服务业发展引导资金主要用于设备购置安装、软件开发、技术转让、人员培训、系统集成、设计咨询、研发测试以及资质认证等。

三、对于列入市服务业发展引导资金计划的项目，请各区尽快与项目单位签署《上海市服务业发展引导资金项目实施框架协议书》，并向市服务业发展引导资金评审小组报备。

请各项目实施单位抓紧组织项目建设，确保达到预期目标。各区要切实推进项目实施，并加强对项目的监督、检查和管理，确保项目质量，使服务业发展引导资金发挥应有的经济和社会效益。

特此通知。
