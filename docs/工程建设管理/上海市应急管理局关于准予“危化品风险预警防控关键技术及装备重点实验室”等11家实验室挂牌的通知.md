# 上海市应急管理局关于准予“危化品风险预警防控关键技术及装备重点实验室”等11家实验室挂牌的通知

各有关单位：

按照《上海市应急管理局重点实验室管理办法》（以下简称《管理办法》）规定，经形式审查、专家评审、现场核查、公示等程序，现准予“危化品风险预警防控关键技术及装备重点实验室”等11个上海市应急管理局重点实验室挂牌（见附件）。

准予挂牌的重点实验室应在本通知发布之日起1个月内，向市应急局提交《上海市应急管理局重点实验室建设任务书》（格式详见《管理办法》），进一步细化研究方向、研究内容、队伍建设、运行机制等内容。

各有关单位应紧密结合应急管理工作实际，按照《管理办法》的要求全面落实各项保障措施，积极做好重点实验室的建设、研究、管理工作，确保实验室安全运行。通过不断提升重点实验室科技创新水平，支撑以新质生产力保障应急管理工作高质量发展。

附件：准予挂牌重点实验室名单
