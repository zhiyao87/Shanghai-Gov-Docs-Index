# 关于印发《宝山区水利工程项目和资金管理办法》的通知

各镇人民政府：

根据市水务局、市财政局关于印发《上海市河道整治工程项目和资金管理办法》的通知，市水务局加大了对水利项目的投资力度，调整了部分水利建设项目补贴政策。我们联合制定了《宝山区水利工程项目和资金管理办法》。经区政府同意，现印发给你们，请遵照执行。

上海市宝山区水务局

2016年2月5日

宝山区水利工程项目和资金管理办法

第一章  总  则

第一条为加强本区水利工程建设管理，规范建设资金使用，根据《上海市河道管理条例》和《上海市河道整治工程项目和资金管理办法》等文件精神，结合本区实际，制定本办法。

第二条本办法适用于列入市、区水利专项工程年度计划的水利工程。

第三条区水务局、区财政局负责编制辖区水利专项建设计划，制定本区资金补贴政策，落实区级配套资金，组织项目实施管理，审核支付工程建设资金，开展日常监督管理等工作；各镇人民政府负责配合开展项目建设，落实镇级配套资金等工作。

第二章 项目储备和审批

第四条区水务局会同区财政局根据区域总体规划及实际情况，按照突出重点、远近结合、统筹兼顾的原则，科学合理确定水利工程的储备项目，并报市水务局、市财政局审核。

第五条区水务局负责水利工程储备项目前期工作，根据年度计划，委托具有相应资质的勘测设计单位编制工程可行性研究报告，并及时上报市水务局审核

第六条区水务局、区财政局按照部门预算编报的要求，向市水务局和市财政局联合上报下一年度水利工程计划，经市水务局和市财政局审核后纳入财政年度预算。

第三章 项目实施和验收

第七条项目法人按照项目法人责任制、工程招投标制、建设工程监理制和合同管理制等要求，加强项目监管。

第八条项目法人应当根据招投标法等相关规定，遵循公开、公平、公正的原则，对项目的勘测、设计、监理、施工等实行公开招投标，择优确定中标单位。

第九条项目法人应当按照经批准的设计文件组织工程实施，不得擅自变更建设地点、规模、标准和建设内容。

第十条项目法人需要对建设内容进行重大调整、设计方案进行重大变更或者动用工程预备费的，按照下列规定执行：

（一）在批准的工程概算内，由区水务局初审并上报市水务局审核同意后，方可组织实施；

（二）超过批准的工程概算，由区水务局、区财政局初审并上报市水务局、市财政审核同意后，方可组织实施。

第十一条工程完工后，项目验收工作按照《上海市水利工程建设项目验收管理实施细则》执行。

第十二条项目法人应当按照水利工程建设项目档案验收管理的要求，做好工程项目档案的管理工作，并办理工程项目档案资料的归档手续。

第十三条水利工程通过项目法人验收后，项目法人应当及时向管理单位办理工程及档案资料移交工作；管理单位应当落实管养措施和管养经费，保障工程效益的发挥。

第四章 资金配套政策

第十四条骨干河道综合治理项目资金配套政策

骨干河道综合治理工程是指按规划实施市、区管河道综合整治，包括新建护坡、疏浚河床和种植绿化等。

市管河道工程费用由市财政全额承担，区管河道工程费用市、区按6:4比例承担。市、区管河道前期费用由市财政按环线外32万/亩、环线内5000元/平米标准补贴腾地费用；区财政按40万/亩补贴腾地费用，并承担绿化、管线及国有土地上的企业动迁费用；相关镇承担集体土地上的企业动迁费用；居农民房屋动迁费用由区、镇两级财政按5：5比例承担。

第十五条河道生态治理项目资金配套政策

河道生态治理主要是针对镇级（含镇级以下）河道的水质改善，包括疏浚、绿化、生态修复等内容。

工程费用按市、区、镇6：2：2比例承担。前期费用由所在镇承担。

第十六条水系沟通项目资金配套政策

水系沟通项目主要内容为拆坝建桥和打通局部堵塞水系。

涉及中小河道的工程费用按市、区、镇6:3:1比例承担，涉及骨干河道的工程费用按市、区6:4比例承担。

第十七条中小河道综合治理项目资金配套政策

中小河道综合整治是指按规划实施镇级（含镇级以下）河道综合整治，包括新建护坡、疏浚河床和种植绿化等。

工程费用按市、区、镇6:3:1比例承担，前期费用由所在镇承担。

第十八条农田水利项目资金配套政策

农田水利项目是指粮田、菜田和果林的田间水利和外围配套水利建设。包括沟、渠、路、喷滴灌设施、排涝泵站、灌溉泵站和河道整治等内容。

工程费用按市、区、镇6：3：1比例承担。

第十九条农村生活污水处理项目资金配套政策

农村生活污水处理项目是指在农村地区敷设污水管道、污水检查井、化粪池、小型污水处理站等设施，将区域内生活污水集中处理，达标排放。

工程费用按市、区、镇5:3:2比例承担。

第五章 资金管理

第二十条项目法人应当根据年度投资计划，编制财务用款计划并提出用款申请，按照年度资金计划安排工程建设进度，确保“当年计划，当年完成”。

第二十一条区财政局负责按年度计划申请市级补助资金，并按照国库资金集中支付的原则，支付项目建设资金。

第二十二条水利工程实行财务监理制度和项目审价审计制度。

第二十三条区水务局会同区财政局按照审计结果向市水务局和市财政局上报工程财务决算。

第二十四条项目法人应当按照批准的工程建设内容使用建设资金，并按照财政专项资金管理办法，实行专款专用；对不按规定使用工程建设资金的，水务部门及财政部门有权终止项目执行并由财政部门将资金收缴国库。对违反财经纪律的项目单位和负责人，将按照《财政违法行为处罚处分条例》（国务院第427号）的规定进行处理。

第二十五条本办法自2014年1月1日起施行。
