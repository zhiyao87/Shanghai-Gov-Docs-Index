# 关于公布《2020-2021年度上海市新能源出租车充电示范站名单》的通知

各相关单位：
根据《上海市促进电动汽车充（换）电设施互联互通有序发展暂行办法》（沪发改规范〔2020〕4号）要求，市交通委会同市发展改革委、市财政局组织推进全市新能源出租车充电示范站建设，结合《关于发布2020年度上海市新能源出租车充电示范站名单的通知》（沪交科函〔2020〕711号）、《关于发布2021年度上海市新能源出租车充电示范站名单的通知》（沪交科〔2021〕345号）以及各区交通、发改部门验收情况，经审核，最终确认了2020-2021年度上海市新能源出租车充电示范站名单，现予以公布。
本市对新能源出租车充电示范站采用动态管理、适时调整机制。请各示范站运营企业加强运营管理、规范服务流程，模范执行本市有关管理要求和行业政策，树立行业服务标杆，优先保障新能源出租车充电需求，积极发挥示范作用。
原沪交科函〔2020〕711号、沪交科〔2021〕345号文件发布的新能源出租车充电示范站名单随本通知发布自动废止。
