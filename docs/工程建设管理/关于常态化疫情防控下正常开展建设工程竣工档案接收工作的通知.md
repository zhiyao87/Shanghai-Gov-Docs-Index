# 关于常态化疫情防控下正常开展建设工程竣工档案接收工作的通知

关于常态化疫情防控下正常开展建设工程竣工档案接收工作的通知
沪规划资源行〔2021〕64号
本市各级城建档案管理机构:
为进一步贯彻落实市委、市政府关于统筹疫情防控和经济社会发展的工作部署，按照我局常态化疫情防控下有序开展规划资源管理各项工作的要求，即日起，本市各级城建档案管理机构在做好常态化疫情防控同时，在低风险地区正常开展建设工程竣工档案接收和催交工作。
特此通知。
上海市规划和自然资源局
2021年2月25日
