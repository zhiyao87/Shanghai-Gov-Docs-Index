# 关于印发《临港新片区建筑工人集中居住临时设施管理实施细则》的通知

关于印发《临港新片区建筑工人集中居住临时设施管理实施细则》的通知

沪自贸临管委〔2021〕678号

管委会各有关部门，临港新片区各开发公司、各有关单位 :

为贯彻落实《临港新片区建筑工人集中居住临时设施管理指导意见》（沪自贸临管委〔2020〕267号）文件精神，进一步规范建筑工人集中居住临时设施日常管理，经研究，现下发《临港新片区建筑工人集中居住临时设施管理实施细则》，请认真贯彻执行。同时《临港新片区建筑工人集中居住临时设施管理实施细则（试行）》（沪自贸临管委〔2021〕212号）废止。
