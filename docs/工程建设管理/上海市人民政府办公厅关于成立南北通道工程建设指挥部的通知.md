# 上海市人民政府办公厅关于成立南北通道工程建设指挥部的通知

各区人民政府，市政府有关委、办、局，各有关单位：

经研究，市政府决定成立南北通道工程建设指挥部（以下简称“指挥部”），其组成人员如下：

总   指   挥：张小宏 副市长

常务副总指挥：王为人 市政府副秘书长

副   总   指  挥：于福林 市交通委主任

成    员：陈国忠 市发展改革委副主任

王训国 市规划资源局副局长

裴 晓 市住房城乡建设管理委副主任

肖 辉 市交通委副主任

金宏松 市水务局副局长

朱心军 市绿化市容局副局长

张玉学 市公安局交通管理总队总队长

毕桂平 浦东新区副区长

宣一洲 虹口区副区长

陆 罡 上海城投集团副总裁

于 宁 申通地铁集团副总裁

指挥部下设办公室（设在市交通委），办公室主任由肖辉同志兼任，副主任由毕桂平、宣一洲同志兼任。

今后，指挥部组成人员的职务如有变动，由其所在单位接任领导自然替补。指挥部不作为市政府议事协调机构，工作任务完成后自行撤销。
