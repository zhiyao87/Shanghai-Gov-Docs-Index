# 七宝镇限额以下小型建设工程管理的实施意见

为进一步规范七宝镇建设工程管理工作，完善我镇建筑市场管理体制和运行体制，强化建设项目全覆盖、全过程监管，根据《上海市关于印发<上海市工程建设项目审批制度改革试点实施方案>的通知》（沪府办〔2018〕14号）、《上海市住建委关于印发<上海市建筑装饰装修工程管理实施办法>的通知》（沪住建规范〔2020〕3号）、《闵行区人民政府办公室关于转发<闵行区限额以下小型建设工程管理办法>的通知》（闵府办〔2020〕42号）等规定，结合我镇实际，制定本实施意见。
一、适用范围
限额以下小型建设工程（以下简称“限额以下工程”）是指本镇行政区域内总投资额在100万元以下的建设工程（包括新建、改建、扩建的建设工程，装饰装修、维修养护涉及的房屋、市政、水务、绿化、民防以及拆除工程、土方工程等）。
家庭居室装修、农民自建低层住房工程，区建管委受理报建的工程均不适用本实施意见。
二、组织机构
为营造规范、有序、健康的市场秩序，体现公开、公平、公正的原则，促进廉政建设，经研究，成立七宝镇建设工程管理领导小组。组长由分管副镇长担任，具体人员名单详见附件1。
三、工作流程
1.限额以下小型建设工程需向镇规建办进行申报（使用社会资金为30万元以下的项目除外），根据项目实际情况由相关部门及领导小组组长进行会签，主要采用告知承诺制。项目应具备规划、立项、施工建设等条件，涉及规划批复、施工图审查、方案公示等要求的，应取得相应的批复或审核意见。法律、法规、规章及本市、区规范性文件有其他要求的，从其规定。
2.建设单位完成项目申报后到镇规建办办理报建手续，收到镇规建办反馈的《限额以下小型建设工程报建备案表》后根据相关规定办理相关承发包手续。
3.使用财政预算资金、土地开发基金和其他财政资金，以及镇所属企事业单位、镇村集体经济组织，及国有、集体资金控股或占主导地位的企业自筹资金投资建设，总投资额在100万元以下的项目纳入限额以下工程施工承发包管理范围。限额以下工程承发包实行预选承包商名录制度。预选承包商管理办法和限额以下工程承发包规则由镇采购办另行制定。
4.建设单位完成承发包手续后到镇规建办办理施工许可手续。施工许可手续办结后，镇规建办反馈建设单位《限额以下小型建设工程施工（许可）备案表》一份，并发放施工许可证。
5.施工过程中，由镇规建办、安监所对在建限额以下小型建设工程履行安全、质量、文明施工监督程序。竣工验收由建设单位自行组织，领导小组成员单位进行监督。建设项目通过竣工验收、收齐所有竣工资料后，由建设单位向镇规建办提交竣工备案资料，对于符合条件的，办结竣工备案手续, 镇规建办反馈《限额以下小型建设工程竣工验收备案表》一份。
6.总投资为30万至100万元的小型建设工程统一在闵行区限额以下小型建设工程管理系统上办理报建、施工许可、施工监管、竣工备案等申报，具体操作详见《闵行区限额以下小型建设工程管理系统用户手册》；总投资为30万元以下的小型建设工程至镇规建办办理施工备案手续。
四、镇规建办办理手续及监管的具体操作规程
（一）限额以下小型建设工程项目申报操作规程
1.适用范围
（1）使用财政、集体资金总投资在100万元以下的小型建设工程项目；
（2）使用社会资金总投资在30万元至100万元的小型建设工程项目。
2.申报主体
（1）使用财政、集体资金的在100万元以下的小型建设工程项目由建设单位申报；
（2）使用社会资金在30万元至100万元的小型建设工程项目由户管单位申报，户管单位为居委的由建设单位申报。
3.操作流程
（1）使用财政、集体资金的限额以下小型建设工程项目
建设单位至镇规建办申报项目，填报《七宝镇限额以下小型建设工程项目申报流转表》、《七宝镇限额以下小型建设工程承诺书》，经相关部门会签后，提交相关资料至镇规建办审核，待领导小组组长签字后由镇规建办出具《七宝镇限额以下小型建设工程项目受理告知书》。
凡使用财政资金的限额以下项目由镇财政所会签，使用财政资金的学校项目由镇教委、财政所会签，其它项目根据实际情况进行会签。
（2）使用社会资金的限额以下小型建设工程项目
建设单位填报《七宝镇限额以下小型建设工程项目申报流转表》、《七宝镇限额以下小型建设工程承诺书》，与相关资料提交至项目所在辖区的户管单位，由户管单位与镇投促中心共同签署会签单位意见后交至镇规建办审核，户管单位为居委的由建设单位直接报至规建办审核，待领导小组组长签字后由镇规建办出具《七宝镇限额以下小型建设工程项目受理告知书》。
4.提交材料
（1）《七宝镇限额以下小型建设工程项目申报流转表》（提交一份）；
（2）《七宝镇限额以下小型建设工程承诺书》（提供版本，提交一份）；
（3）使用集体资金的项目提交集资委会议纪要（50万元至100万元项目）或“三重一大”会议纪要（50万元以下项目）（提交一份）；
（4）使用社会资金的项目提交公司决议或其它相关材料（提交一份）；
（5）房屋装饰装修项目、房屋修缮项目应提交既有建筑物房地产权证复印件，建设单位与房地产权利人不一致时，应提交房屋租赁合同复印件和所有权人同意进行装饰装修的相关证明文书（提交一份，原件复核）；
（6）全套施工图及技术资料。凡涉及改变原有结构、使用功能调整、防火设施变动等特殊类装修项目必须进行施工图设计文件及消防审查，并提交审查意见书，涉及规划批复、方案公示的提交相应批复或审核意见。（提交一份）；
（7）预算书（提交一份）。
镇规建办在收到建设单位的申报材料后（所有资料需加盖建设单位公章），对符合条件的，在规定期限内办结（5个工作日），并将项目信息抄送至各相关部门。对于材料不齐全的不予收件并一次性告知材料递交要求。
（二）限额以下小型建设工程报建操作规程
1.适用范围
总投资在30万元至100万元的小型建设工程项目
2.申报主体
限额以下小型建设工程项目的建设单位
3.操作流程
申报单位在闵行区限额以下小型建设工程管理系统中进行网上报建申报,网上受理后至镇规建办提交相关资料审核，审核通过后取得《限额以下小型建设工程报建备案表》，完成报建办理。
4.提交材料
（1）《限额以下小型建设工程报建备案表》（网上打印，提交二份）；
（2）建设单位营业执照（副本）及有关证明复印件（提交一份，原件复核）；
（3）工程项目专用账户银行开户证明复印件（提交一份，原件复核）；
（4）法定代表人委托书（提供版本，提交一份）；
（5）经办人身份证复印件（提交一份）。
镇规建办在收到建设单位的《报建备案表》等报建申请材料后（所有资料需加盖建设单位公章），对符合条件的，在规定期限内办结（3个工作日）。对于材料不齐全的不予收件并一次性告知材料递交要求。
（三）限额以下小型建设工程施工许可操作规程
1.适用范围
总投资在30万元至100万元的小型建设工程项目。
2.申报主体
限额以下小型建设工程项目的建设单位。
3.操作流程
申报单位在闵行区限额以下建设工程管理系统中进行网上施工许可申报,并至镇规建办提交相关资料，审核通过后取得《限额以下小型建设工程施工许可备案表》，完成施工许可办理后方可开工。
4.提交资料
（1）《限额以下小型建设工程施工（许可）备案表》（网上打印，提交二份）；
（2）建设工程施工承发包合同副本复印件（提交一份，原件复核）、《七宝镇限额以下建设工程施工总包合同备案表》（提供版本，提交一份）；
（3）施工中标通知书，中标单位营业执照、资质证书、安全生产许可证，项目经理资格证书，安全员证书复印件（提交一份，原件复核）；
（4）施工总包企业设立的外来从业者工资发放账户银行开户回执复印件（提交一份，原件复核）；
（5）施工组织设计或施工方案（提交一份）；
（6）按照规定应该委托监理的工程提交监理合同复印件（提交一份；
（7）建设工程一切险、质量险缴付凭证（提交一份）；
（8）支付农民工工资承诺（提交一份）。
镇规建办在收到建设单位的《施工（许可）备案表》等施工许可申请材料后（所有资料需加盖建设单位公章），对于材料齐全的，在规定期限内办结（3个工作日），核发小型建设工程施工许可证，并将项目开工信息抄送至各相关部门。对于材料不齐全的不予收件并一次性告知材料递交要求。
（四）限额以下小型建设工程竣工备案操作规程
1.适用范围
总投资在30万元至100万元的小型建设工程项目。
2.申报主体
限额以下小型建设工程项目的建设单位。
3.操作流程
建设单位在闵行区限额以下建设工程管理系统中进行网上竣工备案申报,并至镇规建办提交相关资料，审核通过后取得《限额以下小型建设工程竣工验收备案表》，完成竣工备案办理。
4.提交资料
（1）《限额以下小型建设工程竣工验收备案表》（网上打印，提交二份）；
（2）建设工程竣工验收报告（含设计、施工和监理单位工程质量合格证明书）（提交一份）；
（3）涉及规划的需提交规划部门出具的认可文件或者准许使用文件复印件（提交一份，原件复核）；
（4）涉及消防的需提交建管委消防审批科出具消防备案受理凭证或消防验收意见复印件（提交一份，原件复核）；
（5）涉及防雷工程的需提交气象部门出具的建设项目防雷工程验收意见书复印件（提交一份，原件复核）；
（6）工程款支付证明（提供版本，提交一份）；
（7）施工单位签署的工程质量保修书（提供版本，提交一份）；
（8）农民工工资发放记录（提交一份）；
（9）全套施工竣工资料（提交一份）。
镇规建办在收到建设单位的《竣工验收备案表》等竣工验收备案申请材料后（所有资料需加盖建设单位公章），对于符合条件的，在规定期限内办结（3个工作日），并将项目竣工信息抄送至各相关部门。对于材料不齐全的不予收件并一次性告知材料递交要求。
（五）限额以下小型建设工程30万元以下施工备案操作规程
1.适用范围
总投资在30万元以下的小型建设工程项目。
2.申报主体
限额以下小型建设工程项目的建设单位。
3.操作流程
项目施工前，申报单位至镇规建办提交相关资料，审核通过后取得《七宝镇30万元以下小型建设工程施工备案收件回执单》，完成施工备案方可开工。
4.提交资料
（1）建设单位营业执照（副本）及有关证明复印件（提交一份，原件复核）；
（2）法人或经办人身份证复印件（提交一份，原件复核）；
（3）房屋装饰装修项目、房屋修缮项目应提交既有建筑物房地产权证复印件，建设单位与房地产权利人不一致时，应提交房屋租赁合同复印件和所有权人同意进行装饰装修的相关证明文书（提交一份，原件复核）；
（4）《七宝镇30万元以下小型建设工程施工备案表》（提供版本，提交二份）；
（5）《七宝镇限额以下小型建设工程承诺书》（提供版本，提交一份）；
（6）施工合同复印件（提交一份，原件复核）；
（7）施工单位营业执照、资质证书、安全生产许可证、安全员证书复印件（提交一份，原件复核）；
（8）概算书（提交一份）；
（9）施工图纸（提交一份）。
五、职责分工
1.镇规建办为限额以下工程项目管理的主管部门，负责推进、协调工程各环节的相关工作，做好镇辖区范围内相关工程的巡查、备案、报建、施工监管、竣工验收及档案归档等工作。对存在违法违规建设的项目及时发放《暂缓施工通知单》，对仍不按整改意见执行的抄告相关单位。对发现有新搭建违章情况的立即反馈镇两违办由其进行执法拆除；对发现存在安全质量隐患的项目责令其整改，情节严重的，责令施工单位暂时停止施工并及时上报区相关部门。
2.镇监察室负责对限额以下工程管理的行为行使监督职能，及时查处限额以下工程管理的违纪违法行为，促进相关单位和职能部门依法履行职责。
3.镇采购办负责对使用财政性资金及集体资金的限额以下小型建设工程做好施工承发包工作。
4.镇财政所负责对使用财政性资金限额以下小型建设工程的资金来源及使用情况进行监管。
5.镇经管中心负责对村属、镇属企业 (包括村集体经济组织，以及集体资金控股或占主导地位的企业)限额以下小型建设工程资金来源及使用情况进行监管。
6.镇投促中心负责对辖区内财政、村、镇属公司、居委户管外使用社会资金的限额以下小型建设工程的经营业态进行把关。
7.镇安监所负责对限额以下小型建设工程的安全进行监管，并协同消防部门对限额以下工程的消防安全进行监管及指导。
8.镇两违办负责对施工过程中新搭建的违章进行执法拆除，并对限额以下工程因历史原因无产证但列入市、区无证建筑库的房屋在施工期间进行监管。
9.镇城管中心负责镇域范围市政道路沿街面限额以下工程的巡查监督、宣传教育工作，发现违法违规建设项目及时报送镇规建办与镇城运中心，并协助镇规建办对办理完成施工许可的工程实施现场监管、竣工验收等工作。
10.镇城运中心负责收集涉及限额以下工程的民意投诉和镇相关部门巡查发现的违法违规建设行为情况，并及时反馈镇规建办。
11.建设单位应尽到建设方主体责任。严格遵守相关法律法规和规范标准，认真履行建设工程合同所规定的责任和义务。对未实行监理的工程，组织建设单位相关人员履行监理单位职责。
12.房屋产权方及出租方应尽到管理责任，落实产权方主体责任，杜绝“以租代管，只租不管”的行为。与承租者签订合同中应明确安全生产责任工作，并有效督促承租单位的安全管理工作。
13.项目户管单位（各村、合作社、镇属公司、相关部门、居委会）负责配合户管辖区域内使用社会资金的限额以下小型建设工程做好手续办理，以及巡查监督、宣传教育工作，发现违法违规建设项目及时上报镇规建办与镇城运中心，并协助镇规建办对办理完成施工许可的工程实施现场监管、竣工验收等工作。
六、工作要求
1.镇各相关部门应按照相关规章、制度，落实专人，明确职责，做好工程项目管理的相关工作。
2.对不按照本实施意见要求办理工程备案手续的建设单位，由镇规建办提出整改意见；仍不按整改意见执行的建设单位，由镇规建办上报区相关部门进行立案处理。
3.严格执行工程建设五方责任制的相关规定，并按相关规定落实相关监理单位；做好工程的竣工备案、档案管理、统计及备案上报工作。
4. 各村、合作社、镇属公司、相关部门、居委会应与镇规建办、安监所、两违办、城管中心、城运中心等相关部门建立日常联动机制，加强现场监管、信息沟通和工作协调，强化日常巡查发现报告机制，及时发现、制止各类违法违规建设行为。
5.镇各相关单位应把专职监管人员纳入到日常培训工作中，加强对监管人员的业务指导，提升监管人员的管理水平。
6.本实施意见中限额以下工程的质量安全监管参照《中华人民共和国建筑法》、《中华人民共和国安全生产法》、《上海市建设工程质量安全监督工作手册》、《闵行区限额以下建设工程管理办法》等相关法律法规进行实施。
