# 上海市住房和城乡建设管理委员会关于批准《道路可变信息标志技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《道路可变信息标志技术标准》为上海市工程建设规范的通知

沪建标定〔2022〕69号

各有关单位：

由上海市道路运输事业发展中心和上海市城乡建设和交通发展研究院主编的《道路可变信息标志技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2396-2022，自2022年6月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市道路运输事业发展中心负责解释。

2022年1月26日
