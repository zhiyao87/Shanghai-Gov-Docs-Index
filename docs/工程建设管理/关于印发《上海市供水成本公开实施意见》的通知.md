# 关于印发《上海市供水成本公开实施意见》的通知

各区发展改革委、水务局，各供水企业：

为贯彻落实《城镇供水定价成本监审办法》（国家发展改革委令第45号）、《城镇供水价格管理办法》（国家发展改革委令第46号）文件精神，进一步提高我市供水价格的科学性和透明度，促进供水行业健康可持续发展，市发展改革委、市水务局共同研究修订了《上海市供水成本公开实施意见》。现印发给你们，请遵照执行。
