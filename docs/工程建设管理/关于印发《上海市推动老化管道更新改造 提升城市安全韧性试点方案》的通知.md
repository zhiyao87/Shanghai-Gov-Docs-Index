上海市推动老化管道更新改造 提升城市安全韧性试点方案

推动老化管道更新改造是提升城市安全韧性、深入践行人民城市理念的重要工作内容。为贯彻落实国家《深入实施以人为本的新型城镇化战略五年行动计划》《试点引领以人为本的新型城镇化战略五年行动计划实施的工作方案》以及《上海市深入实施以人为本的新型城镇化战略五年行动计划的实施方案》精神，扎实推进我市新型城镇化五年行动计划和试点工作，特制订本试点方案。

一、试点要求

坚持以习近平新时代中国特色社会主义思想为指导，贯彻落实党的二十大以及二十届三中全会精神，深入践行以人民为中心的发展思想和人民城市重要理念，着力推进城市燃气、供水、排水等老化管道更新改造，加强物联感知设施部署和联网监测，积极探索地下综合管廊运营管理新机制，持续提升城市安全韧性水平，不断增强人民群众获得感、幸福感、安全感。注重以人为本。坚定不移贯彻总体国家安全观，把保障人民群众安居乐业作为头等大事，在统筹发展和安全上见行见效，在提升城市治理现代化水平上善作善成，切实保障人民群众生命财产安全。注重建管并举。坚持一手抓更新改造，聚焦短板弱项持续加力，加快消除老化管道风险隐患；一手抓长效管理，建立老化管道系统更新和可持续运维机制，加强物联感知设施部署和联网监测，提升运维管护智能化、信息化、网络化能力，常态长效保障城市安全运行。注重系统治理。坚持将城市作为生命有机体，聚多方合力、护一方平安，统筹市政建设与管道改造，统筹新建工程与老化改造，统筹检测普查与修复改造，统筹不同行业、不同管线，合理安排施工区域、改造时序，将对市民生活影响降到最低。

二、试点目标

统筹面上改造和点上探索，用一年左右时间，着力完善上下联动、齐抓共管的工作推进机制，启动一批具有示范性、引领性的老化管道更新改造工程，2025年完成不少于750公里燃气管道更新改造，燃气道路管改造全面完成；完成150公里供水管道和100公里排水管道更新改造；积极探索地下综合管廊运营管理新机制。到2028年，在提前一年全面完成各类燃气老化管道更新改造的基础上，基本完成燃气管道重要节点智能物联感知设备安装，全面构建城市管道安全管理长效机制，全市老化管道实现“两个清零”（安全隐患基本动态清零、未排查隐患管道基本清零），探索形成一批可复制、可推广的老化管道更新改造和综合管廊运营管理“上海经验”，城市安全韧性水平再上新台阶。

三、行动任务

主要实施四大专项行动9项重点任务：

（一）实施老化管道全面体检专项行动

任务1：实施地下管网信息普查工程。研究制订地下管线普查技术标准，编制新一轮地下管线普查计划，全面摸清地下管线类别、空间位置、材质、权属、敷设方式等数据，加快实现建成区地下管线普查全覆盖。修订地下管线跟踪测量工作实施意见，优化地下管线测量技术标准，实现数据一次测量、一数一源一责。

任务2：实施地下管网“一张图”建设工程。优化完善全市统一的地下管线地理信息数据库，建立管线类别齐全、基础数据准确、数据共享安全、数据价值发挥充分的地下管网“一张图”体系，着力提高“设施、隐患、治理、监测”一张图管理能力。

（二）实施燃气管道更新改造专项行动

任务3：实施城市燃气管道更新改造计划。将城市燃气老化管道更新改造作为安全韧性城市建设的重要内容，聚焦老旧小区、沿街商铺、大型商业综合体用气场所等重点区域，加快更新改造城市市政道路和街坊燃气老化管道，2025年完成不少于750公里更新改造。

任务4：完善城市燃气管道改造施工和运维养护机制。依托市、区燃气安全专项整治工作专班，完善燃气管道更新改造综合协调机制。围绕减少更新改造对市民生活影响，健全完善项目施工统筹机制。结合更新改造工作，推广使用智能物联感知设备等先进技术工艺，着力构建从“气源端”到“用户端”全覆盖的感知监测网络，加快完善城市燃气管道和设施运维养护长效机制。

（三）实施供排水管道更新改造专项行动

任务5：实施城市供排水管道更新改造计划。将城市供排水老化管道更新改造作为安全韧性城市建设的重要内容，精细化推进城镇公共供排水管道更新改造，2025年完成150公里供水管道、100公里排水管道更新改造，基本完成结构性病害排水管道修复。结合实施我市排水管理体制改革，研究形成石洞口、竹园、白龙港等三大片区公共排水设施更新改造的近远期建设机制。

任务6：实施供水智能化改造工程。结合供水管网设施更新改造，推动全市供水管网在线感知元增加密度、优化布局、丰富种类，探索建设全市管网水力模型，提高城市供水管网数字化、信息化管理水平。

任务7：实施排水感知系统完善工程。全面开展我市三大片区感知监测布点工作，到2025年底感知监测点位密度达到每5公里1个。加快覆盖中心城区的排水厂站网一体化综合管理平台、动态评估系统和感知端建设，2025年基本建成中心城区感知体系，在白龙港片区先行开展常态化动态评估。

（四）实施地下综合管廊运营模式创新专项行动

任务8：实施综合管廊标准化试点。优化形成经济实用、投资可控的综合管廊管沟建设标准，选取部分区域试点标准化综合管廊，结合架空线入地工程试点标准化缆线管沟，降低地下综合管廊管沟建设成本。

任务9：完善综合管廊建设运营机制。探索综合管廊投资、建设、运营、维护新机制，修编我市综合管廊专项规划，开展综合管廊不动产登记试点，完善综合管廊管沟管理模式，健全管廊建设运维成本合理分担机制，提高管廊综合效益。

四、工作机制

依托我市新型城镇化工作机制，明确各专项行动牵头单位，确保各项任务扎实完成。具体分工：

1. 老化管道全面体检专项行动。由市住房城乡建设管理委、市规划资源局牵头负责，统筹推进全市地下管线安全排查和整治工作，定期通报工作推进进度，研究解决重难点问题。各管线行业管理部门和专业经营单位密切配合、形成合力，共同推进地下管线安全排查和整治工作。

2. 燃气管道更新改造专项行动。由市住房城乡建设管理委牵头负责，编制2025年上海市燃气管道更新改造实施方案，推进全市燃气管道更新改造工作，完善燃气管道运维机制，维护城市燃气基础设施安全运行。

3. 供排水管道更新改造专项行动。由市水务局牵头负责，编制2025年上海市供排水管道更新改造实施方案，围绕供排水老化管道安全隐患排查治理，加快补短板、强弱项，不断提升供水安全保障。协同市住房城乡建设管理委做好三大片区公共排水设施更新改造的近远期建设机制研究。

4. 地下综合管廊运营模式创新专项行动。由市住房城乡建设管理委、市规划资源局牵头负责，全面实施上海市地下管网管廊及设施建设改造实施方案（2024-2028年），因地制宜有序推进地下综合管廊建设，创新完善地下综合管廊建设运营模式。

五、组织实施

1. 强化全链条统筹协调。建立健全政府统筹、专业经营单位实施、各部门齐抓共管的地下管网管廊建设改造工作机制，形成工作合力。压实各区人民政府属地责任，加强管理和监督，做好与“两旧一村”改造、汛期防洪排涝等工作衔接，避免改造工程碎片化、重复化。夯实专业经营单位主体责任，抓紧实施老化管道更新改造和综合管廊建设项目。建立健全信息报送和总结评估机制，各部门、各单位应定期将试点进展、经验做法、典型案例等报送市区域高质量发展领导小组办公室，市区域高质量发展领导小组办公室适时组织开展试点工作总结评估，复制推广好经验好做法。

2. 强化全方位政策支持。统筹用好国家一揽子增量政策和市级补贴资金，积极争取中央预算内投资、“两重”建设支持，鼓励符合条件的项目发行资产证券化产品、公司信用类债券等，建立健全更新改造资金多元共担机制。

3. 强化全过程安全监管。建立健全地下管网全生命周期管理机制，牢牢守住建设改造安全风险底线。加强施工管理，严格落实工程质量和施工安全责任，杜绝质量安全隐患。加强建管衔接，按规定做好改造后通气、通水等关键环节安全监管，做好工程验收移交。加强事后监管，进一步完善地下管网建设、运营、维护、管理相关机制，压实专业经营单位巡查检查、检测检验、维护抢修等责任。加强应急处突，实现城市基础设施安全风险常态监测、动态预警、精准溯源、协同处置。
