# 关于“河道管理范围内建设项目工程建设方案审批”“智慧好办”上线运行的通知

关于“河道管理范围内建设项目工程建设方案审批”“智慧好办”上线运行的通知

沪水务〔2025〕423号

各区水务局、临港新片区管委会，局属相关单位、局机关相关处室：

根据市政府办公厅印发的《上海市推进“人工智能+”行动打造“智慧好办”政务服务实施方案》《上海市加快“人工智能+政务服务”改革推动“高效办成一件事”实施方案》和上海市水务局印发的《2025年上海市水务海洋政务服务“一网通办”改革实施方案》要求，市水务局对高频许可事项“河道管理范围内建设项目工程建设方案审批”开展“智慧好办”功能改造，并于2025年10月10日实现市、区两级同步上线“一网通办”运行。

新功能上线后，申请人在申报“河道管理范围内建设项目工程建设方案审批”时，通过“办理须知”“智能导办”“材料预检”“智能填表”和“在线签章”等环节，可快速精准完成事项申请，事项办理过程中也可通过线上人工帮办系统进行“在线咨询”。

推进高频许可事项“智慧好办”是全市推进“一网通办”改革的一项重要举措，下一步，请各单位围绕“申报预填比例超70%，首办成功率超90%，线上人工帮办解决率超90%”的“799”服务效能目标，积极做好服务指导工作，宣传引导申请人体验“智慧好办”功能，加强帮办人员业务培训，认真做好窗口咨询解答、在线人工帮办以及审查要点知识库内容查遗补缺、问题反馈等工作。

特此通知。

上海市水务局

2025年11月7日
