# 关于印发2021年全市各区优化营商环境优秀案例的通知

各区人民政府、各相关单位：

近年来，上海市委、市政府高度重视营商环境建设，按照党中央、国务院有关部署，持续发力推进国际一流营商环境建设，不断提升企业的感受度和满意度。2021年，各区高度重视、真抓实干，聚焦市场主体反映的突出问题，开拓创新、攻坚克难，推出了大量针对性强、有特色的改革举措，形成了一批典型经验做法。

为进一步推进我市营商环境建设，推动各区间互学互鉴，复制推广好经验、好做法、好案例，创建营商环境区域特色品牌，形成比学赶超的良好氛围，现将各区营商环境实践优秀案例整理汇集印发给各区、各单位学习借鉴。下一步，各区要主动对标国际国内先进经验和做法，进一步抓好工作落实，更大力度探索创新，切实解决企业关心的政策难点、执行堵点、监管盲点、体制痛点，共同努力打造市场化、国际化、法治化的一流营商环境，让企业在上海办事更顺心、经营更放心、扎根更安心。
