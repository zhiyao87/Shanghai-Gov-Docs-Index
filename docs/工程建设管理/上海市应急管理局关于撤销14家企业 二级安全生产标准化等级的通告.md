# 上海市应急管理局关于撤销14家企业 二级安全生产标准化等级的通告

经核查发现，上海华通企业集团有限公司、上海鼎天时尚科技股份有限公司、上海核之力实业有限公司、上海核威实业有限公司等4家企业在2020年取得二级安全生产标准化等级后，安全生产标准化管理体系未持续、有效运行，安全风险分级管控和隐患排查治理双重预防工作机制落实不到位；上海大通会幕新型节能材料股份有限公司等10家企业出现关闭、搬迁到外地、生产经营业态改变等情形，依据《企业安全生产标准化建设定级办法》（应急〔2021〕83号）第十一条有关规定，我局决定撤销上述14家企业二级安全生产标准化等级。现将企业名单通告如下。
1.上海华通企业集团有限公司，所在区：青浦。
2.上海鼎天时尚科技股份有限公司，所在区：松江。
3.上海核之力实业有限公司，所在区：松江。
4.上海核威实业有限公司，所在区：松江。
5.上海大通会幕新型节能材料股份有限公司（现已关闭），
原址所在区：金山。
6.上海神舟新能源发展有限公司（现已关闭），原址所在区：
闵行。
7.上海百吉食品有限公司（现已关闭），原址所在区：闵行。
8.上海星月环保服务有限公司（现已关闭），原址所在区：
闵行。
9.上海索广电子有限公司（现已关闭），原址所在区：浦东
新区。
10.上海威侃电子材料有限公司（搬迁到外地），原址所在区：
嘉定。
11.基伊埃工程技术（中国）有限公司（搬迁到外地），原址所在区：闵行。
12.上海易教电子科技有限公司（搬迁到外地），原址所在区：奉贤。
13.上海浦东船厂（生产经营业态改变），原址所在区：闵行。
14.伟巴斯特车顶供暖系统（上海）有限公司（生产经营业态改变），原址所在区：闵行。
特此通告。

上海市应急管理局
2022年3月9日
