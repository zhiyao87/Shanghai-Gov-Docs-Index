# 上海市崇明区港沿镇人民政府关于印发《港沿镇政府投资小型建设工程项目管理办法》的通知

机关各部门、各事业单位、各村（居）：

为进一步规范我镇建设工程项目管理，确保建设工程公开、公正、公平和规范有序建设，切实提高质量管理和资金管理效率，根据《关于印发〈上海市崇明区政府投资项目管理办法〉的通知》（沪崇发改〔2020〕478号）、《关于印发〈上海市崇明区政府投资小型建设工程项目管理办法〉的通知》（沪崇建管〔2020〕76号）等有关规定，结合本镇实际制定本办法。

一、适用范围

本办法所指的小型建设工程，是全部或部分使用国家、市、区或镇级政府性资金，以及村（居）集体资金，且投资总额在100万元（不含）以下的建设工程（100万元（含）以上的建设工程按分级分类管理办法纳入建设管理流程），具体包括：

（一）农业、水务、能源、交通、城乡公用设施等基础性项目；

（二）教育、科技、文化、卫生、体育、民政、社会保障、生态建设、环境保护、资源节约等公益性项目；

（三）党政机关办公楼及管理用房等项目；

（四）社区管理等政府公共服务设施项目；

（五）经认定需要纳入的其他小型建设工程。

二、组织机构及其职责

（一）成立港沿镇小型建设工程领导小组（以下简称“领导小组”），领导小组组长由镇行政主要负责人担任，副组长由市政分管领导和项目申请条线分管领导担任，成员由党政办、规环办、经发中心和实施相关工程项目的部门及有关村（居）负责人组成。

（二）领导小组下设办公室，设在规环办，统筹协调小型建设工程项目规范化管理。各项目主管部门（单位）、村（居）作为建设单位，负责按流程规范实施小型项目建设，做好合同签订、技术交底、工程安全质量监督、组织完工验收、审价、资金拨付、资料归档等工作。党政办负责项目议题储备。经发中心负责项目资金的预决算管理及政府采购业务管理。

三、小型建设工程过程管理

（一）项目报批管理

小型建设工程管理过程中应遵循集体决策、手续完备的原则。

1.建设单位应在每年年底前向领导小组申报次年项目，领导小组依据项目的可行性、必要性、轻重缓急等原则以及资金落实情况，统筹安排小型项目。

2.建设单位按照各自工作职责，拟定小型建设工程议题（村（居）议题需经插村领导和部门分管领导审核，报行业主管部门汇总），提请党政领导班子会议集体讨论，并据此审定是否纳入次年度小型建设工程计划。

3.立项前，建设单位应委托有资质的工程造价咨询公司作为投资顾问，出具预算报告，严格控制各项费用。

4.严禁拆分项目。工程总投资100万元以下的由镇政府立项或者审批后实施。其中：项目总投资额大于3万元（含）、小于5万元（不含）的，由政府办公会议负责审议；总投资额大于5万元（含）、小于100万元（不含）的，需先经政府办公会议审议通过后，再提交镇党委会议表决。总投资超过100万元（含）的项目，由区发展改革委立项批复。

5.各村（居）还须按要求落实“四议两公开”等规定程序。

（二）工程采购管理

1.镇（村（居））级小于3万元（不含）的项目，应在明确工程量、总投资额，并经插村领导、分管领导审核后，向小型工程项目领导小组备案，可由项目建设单位直接择优选择并确定与项目规模相匹配的施工单位签订施工合同后组织实施。

2.项目总投资额大于3万元（含）、小于5万元（不含）的小型建设工程项目，通过政府办公会集体审议确定与工程项目规模相匹配的施工企业实施。

3.总投资额大于5万元（含）、小于100万元（不含）的小型建设工程项目，应在提交镇党委会审议通过后，根据拟建项目特点，采用邀请招标等形式进行项目发包。

4.对涉及公共安全、重大活动等急需抢修、建设的小型建设工程，可经党政领导班子集体讨论后，择优选择施工单位先行施工,最后根据实际工程量审价后拨付工程款。

5.小型建设工程中属货物和服务采购，列入当年政府采购集中采购目录和采购限额标准的，应执行政府采购的相关规定。

（三）施工管理

1.小型建设工程的建设单位为施工管理的责任单位。

2.本镇小型建设工程推行工程监督制。建设单位应在开工前择优选择施工监督人员，并做好监管台账。

3.项目变更设计。在施工过程中，因客观原因需要变更设计内容的，施工单位应当向建设单位提出申请，经建设单位报领导小组审核同意后由设计单位变更设计。

4.项目工作量变更。建设单位应严格控制因增加使用功能、提高标准等级而增加的工程量。凡属非增加使用功能、提高标准等级而调整的工程量，建设单位应向领导小组提出申请，经领导小组审核同意后方可实施。

5.项目变更原则上应控制在原建安费的5%以内。未按上述规定进行审批，擅自变更设计、增加工程量的，在工程结算时，变更部分不予认定。

（四）安全质量管理

1.由本镇立项的小型建设工程，向领导小组办公室报备后组织开工，由项目建设单位及其主管部门负责安全质量监督管理。

2.项目质量管理。涉及专业工程的，行业有专门规定的，按相关规定执行；法律法规及规章无明确规定的，由项目建设单位负责质量监督管理或委托符合资质要求的工程监理单位实施。

3.项目安全管理。小型建设工程施工单位应是具有施工资质证书及安全生产许可证书的施工企业。施工企业应切实加强施工现场安全质量管理，项目经理对施工现场的安全质量负主要责任。

4.项目建设单位应指派专人负责工程的安全质量监管工作。工程项目竣工后，由项目建设单位组织设计、施工等各方进行工程验收，有整改内容的，需明确整改要求、期限及责任人，并跟踪整改情况直至验收合格。验收合格之日起15日内向领导小组办公室备案。

（五）资金管理

建设单位应在工程竣工后委托有资质的审价单位进行审价，根据审价报告和合同约定拨付项目款项。

（六）档案管理

各相关单位必须建立完善的建设工程项目档案制度。归档的资料包括：集体讨论的会议记录、招投标文件、施工图设计文件、中标通知书、施工合同、施工单位证件（营业执照、资质证书、安全生产许可证、项目经理资格证书复印件）、咨询单位合同、审价报告等。

四、纪律要求与责任追究

（一）纪律要求

1.在工程建设中，参建各方必须严格遵循诚信、守法和自律的原则。

2.建设单位应与中标的施工企业就工程建设的有关事宜签订《施工合同》《廉洁协议》，明确各方的权利和义务。

（二）责任追究

镇小型建设工程领导小组对工程项目负有直接和领导责任，依法切实加强对工程建设的管理和领导。违反下列规定的，将追究领导或有关责任人员的责任：

1.参建单位不严格执行本办法规定的；

2.工程建设管理人员以打招呼、插手干预等方式，影响工程招标正常进行的；

3.招投标过程中，各种弄虚作假和规避招标投标行为的；

4.违反国家建设法律法规及强制性标准，造成工程质量安全事故的；

5.未按工程建设规定，擅自扩大建设规模，提高工程建设标准，增加或变更使用功能，聘用无资质施工队伍组织施工的；

6.违反财务规定和纪律，收受贿赂或贪污等行为的；

7.工程竣工验收后，不按规定及时整理工程档案资料，导致档案缺失，或未按照规定验收，擅自交付使用的；

8.施工企业、监理企业和中介服务机构等出现违法违规行为，造成后果的；

9.其他违法违规行为。

五、其他

（一）本办法自发布之日起实施，未尽之处由镇小型建设工程领导小组负责解释。

（二）本办法如与国家、市、区的有关法律法规及文件精神有抵触，或上级部门颁布新规定的，以法律法规及上级文件精神为准。
