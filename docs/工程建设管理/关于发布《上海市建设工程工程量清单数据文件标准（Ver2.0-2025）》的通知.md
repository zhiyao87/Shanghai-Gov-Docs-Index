# 关于发布《上海市建设工程工程量清单数据文件标准（Ver2.0-2025）》的通知

沪建建管〔2026〕23号

上海市住房和城乡建设管理委员会

关于发布《上海市建设工程工程量清单数据文件标准（Ver2.0-2025）》的通知

各有关单位：

为落实住房城乡建设部2024版国家工程量清单计价标准，现根据《上海市建设工程工程量清单计价应用规则（2025版）》（沪建标定〔2025〕521号），我委对原数据标准进行升级，编制了《上海市建设工程工程量清单数据文件标准（VER2.0-2025）》，现予以发布，请遵照执行。

2026年1月14日
