# 关于印发《浦东新区区级政府投资项目财务（投资）监理管理办法》的通知

新区各委、办、局，各管理局（管委会），各街道办事处、镇政府，各相关单位：

为进一步提高浦东新区区级政府投资资金的运行效率和使用效益，切实规范区级政府投资项目的财务（投资）监理工作，结合新区实际情况，浦东新区发展和改革委员会、浦东新区财政局联合制定了《浦东新区区级政府投资项目财务（投资）监理管理办法》，现印发给你们，请认真贯彻执行。

特此通知。
