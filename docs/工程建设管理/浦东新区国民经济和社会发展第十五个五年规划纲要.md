# 浦东新区国民经济和社会发展第十五个五年规划纲要

浦东新区第七届人民代表大会第六次会议关于浦东新区国民经济和社会发展

第十五个五年规划纲要的决议

2026年1月24日浦东新区第七届人民代表大会第六次会议通过

浦东新区第七届人民代表大会第六次会议审查了浦东新区人民政府提出的《浦东新区国民经济和社会发展第十五个五年规划纲要（草案）》。会议决定，批准《浦东新区国民经济和社会发展第十五个五年规划纲要》。

一、牢记嘱托、砥砺奋进，准确把握浦东发展新阶段新特征新要求

1.“十四五”时期浦东引领区建设迈出坚实步伐

2020年11月12日，习近平总书记出席浦东开发开放30周年庆祝大会并发表重要讲话，赋予浦东新区打造社会主义现代化建设引领区新的重大使命。五年来，浦东牢记嘱托、感恩奋进，在习近平总书记和党中央的亲切关怀下，在市委、市政府的坚强领导下，坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻落实习近平总书记考察上海重要讲话精神，全面贯彻落实《中共中央国务院关于支持浦东新区高水平改革开放打造社会主义现代化建设引领区的意见》，积极应对错综复杂的国际经贸形势，经受住世纪疫情重大考验，统筹推进高质量发展、高水平改革开放、高品质生活、高效能治理，各项事业取得新的重大成就，打造社会主义现代化建设引领区实现良好开局。

综合经济实力再上新台阶。地区生产总值连续跨过5个千亿级台阶，2025年达到1.88 万亿元。规上工业总产值达到1.39万亿元，货物进出口总额2.76万亿元，一般公共预算收入1343亿元。经济结构优化升级，工业增加值占地区生产总值比重保持在20%以上，战略性新兴产业制造业产值占工业总产值比重从48.0% 提升至54.8%，信息服务业、科技服务业等知识密集型产业保持较快增长。发展动力更加强劲，“十四五”期间，累计新设市场主体超24万户，实际利用外资超470亿美元，完成固定资产投资超1.6万亿元。

改革开放开创新局面。引领区建设、综合改革试点、自贸试验区制度型开放等国家战略任务总体完成率超95%，170项经验做法在全国复制推广。改革系统集成协同高效试出新经验。试点建设用地按规划期总量管控，创设产业综合用地类型，单位建设用地生产总值较2020年提升30%以上。发布首批境外职业资格证书认可清单，率先开展全域电子口岸签证试点。上海数据交易所挂牌数据产品近5500个。商事制度改革全面深化，“一业一证”改革核发行业综合许可证超1.9万张。高水平制度型开放形成新优势。在金融、电信、医疗等服务业领域扩大开放实现一批全国首创项目落地。东方枢纽国际商务合作区先行启动区封关运行。全国首家民非性质“走出去”综合服务中心构建覆盖全球270个城市的服务网络。法治保障体系更加健全，累计推动出台24部浦东新区法规、37部管理措施。

核心功能取得新突破。“五个中心”核心区建设成效显著，“四大功能”持续强化。全球资源配置功能进一步增强，全国性大宗商品仓单注册登记中心、国际再保险登记交易中心等一批功能性平台落地，集聚13家金融要素市场、1250家持牌类金融机构。新增各类总部251家，落户49 家国际经济组织。科技创新策源功能进一步增强，每万人口高价值发明专利拥有量从30件增加到110件，人才资源总量超过200万。高端产业引领功能进一步增强，集成电路、生物医药、人工智能三大先导产业规模预计分别达到3500亿元、4400亿元、1800亿元，C919国产大型客机、首艘国产大型邮轮实现商业运营。开放枢纽门户功能进一步增强，港口集装箱吞吐量突破5000万标准箱，支撑上海港连续16年全球第一，浦东国际机场货邮吞吐量跃居全球第二，口岸贸易规模占全国1/4。

城市品质实现新提升。现代化城区建设加快推进，精品城区、现代城镇、美丽乡村全面提升。“两旧一村”改造惠及居民约5万户，街道范围内“城中村”改造全面完成。乡村振兴战略全面推进，累计建成65个乡村振兴示范村、54个美丽乡村示范村。交通网络更加畅达，轨道交通运营里程达到343公里，高快速路里程达到367公里。生态环境更加宜人，公园数量达到225座，人均公园绿地面积达到13.5平方米。黄浦江东岸24公里公共空间实现贯通，陆家嘴水环全线开放，世博水环启动建设。空气质量优良率达到89.0%，地表水达到或好于Ⅲ类比例达到100%。

民生福祉达到新水平。城乡居民人均可支配收入预计达到9.9万元左右。“十四五”时期累计财政民生投入超3700亿元。公共服务资源扩容提质，基本保障类公共服务15分钟可达率提升到95.6%。教育发展更加优质均衡，创建上海首个教育综合改革示范区。卫生养老体系更加健全，集聚4个国家级医学中心、16家三级医院，建成“东西南北中”7家区级大型养老机构，人均预期寿命超85岁。文化软实力显著提升，上海博物馆东馆、世博文化公园、浦东足球场等一批重大文体设施建成投用，万人以上大型演出数量占全市70%以上，有效带动文商旅体展融合发展。城市治理、街区治理、社区治理体系日趋健全，城市安全和应急管理水平显著提升，社会保持和谐稳定。

这些成绩的取得，根本在于以习近平同志为核心的党中央领航掌舵，在于习近平新时代中国特色社会主义思想的科学指引，在于习近平总书记考察上海、浦东系列重要讲话的把脉定向，是市委、市政府正确领导和全区人民团结奋斗的结果。

2.“十五五”时期是浦东引领区建设承前启后的关键时期

从国际环境看，世界百年变局加速演进，国际力量对比深刻调整，大国博弈更加复杂激烈，地缘冲突易发多发，国际经贸秩序遇到严峻挑战，世界经济增长动能不足。从发展动力看，全球科技创新进入密集活跃期，以人工智能为代表的科技革命和产业变革加速突破，引领未来增长的新技术、新赛道不断涌现。从我国发展看，经济长期向好的支撑条件和基本趋势没有变，产业升级快速推进，人口结构发生变化，全国统一大市场建设向纵深推进，城市发展进入存量提质增效为主的内涵式发展阶段。从上海发展看，“十五五”时期是乘势而上的全面发力期、转型升级的攻坚决胜期，要坚持以改革开放先行先试，推动“五个中心”能级不断实现新提升，“四大功能”不断取得新突破，人民城市建设不断取得新进展，在推进中国式现代化中充分发挥龙头带动和示范引领作用。从浦东自身看，经过35年开发开放，奠定了坚实的改革开放优势、核心功能优势、科技创新优势、现代产业优势、人才集聚优势、社会治理优势。当前，浦东正处于经济社会转型的关键期、新旧动能转换的突破期、产业结构调整的攻坚期、民生服务保障的提升期，但对标中央和市委要求，对标人民群众期盼，浦东改革开放压力测试的力度还不够大，国际竞争力还不够强，新质生产力有待壮大，资源环境紧约束突出，城乡二元结构依然明显，民生保障存在短板弱项，老龄化少子化程度加深，重点领域仍有风险隐患。

浦东开发开放是一代代浦东人接续奋斗的伟大事业。面对新形势、新任务、新挑战，我们必须坚持以习近平总书记对上海“四个放在”和对浦东“两个放在”“三个在于”的要求为工作基点，牢记嘱托、感恩奋进，勇立潮头、敢闯敢试，立足国家战略，保持战略定力，增强必胜信心，始终保持干事创业激情、始终高举改革创新旗帜、始终践行人民城市理念，不断激发锐意创新的勇气、敢为人先的锐气、蓬勃向上的朝气，以历史主动精神识变应变求变，加快推进更深层次改革、更高水平开放，积极代表国家参与国际合作竞争，深入推进“五个中心”核心区建设，更好服务长三角一体化发展，勇挑经济大梁、勇当改革先锋、勇作民生标杆，当好排头兵中的排头兵、先行者中的先行者，奋力开创引领区建设新局面。

二、为国担当、勇为尖兵，奋力谱写社会主义现代化建设引领区新篇章

3.指导思想和基本原则

坚持马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观，全面贯彻习近平新时代中国特色社会主义思想，深入贯彻党的二十大和二十届历次全会精神，深入贯彻习近平总书记考察上海重要讲话精神，统筹推进“五位一体”总体布局，协调推进“四个全面”战略布局，完整准确全面贯彻新发展理念，围绕推动高质量发展首要任务和构建新发展格局战略任务，以经济建设为中心，坚持稳中求进工作总基调，为国担当、勇为尖兵，以打造社会主义现代化建设引领区为使命，以建设上海“五个中心”核心区为重点，以科技创新为引领，以改革开放为动力，以国家重大战略为牵引，以城市治理现代化为保障，深入践行人民城市理念，持之以恒推进全面从严治党，深入实施功能跃升战略、科教兴区战略、人才强区战略、“走出去”战略、硬核集群战略、城乡融合战略，推动经济社会发展全面转型升级，推动经济实现质的有效提升和量的合理增长，推动共同富裕和人的全面发展迈出坚实步伐，更好满足人民日益增长的美好生活需要，确保打造社会主义现代化建设引领区取得决定性进展。

“十五五”时期，经济社会发展必须遵循以下原则：坚持党的全面领导，更好发挥总揽全局、协调各方作用;坚持人民至上，在发展中保障和改善民生，在满足民生需求中拓展发展空间;坚持高质量发展，推动经济持续健康发展和社会全面进步;坚持全面深化改革，持续增强发展动力和社会活力;坚持有效市场和有为政府相结合，充分发挥市场在资源配置中的决定性作用，更好发挥政府作用;坚持统筹发展和安全，实现高质量发展和高水平安全良性互动。

4.发展目标和主要指标

到2030年，贯彻落实各项国家战略任务取得新突破，经济社会转型升级实现新跃升，人民城市建设迈上新台阶，加快建设更加开放、创新、人文、美丽、智慧的社会主义现代化新浦东。

建设面向全球的开放浦东。连通世界的链接织密成网，与国际通行规则相衔接的制度体系更加成熟，营商环境、生活环境的国际化水平进一步提升，资金、信息、技术、人才、货物等要素配置的全球影响力进一步彰显，浦东始终挺立国家对外开放最前沿，成为全球网络的重要节点。

建设活力四射的创新浦东。创新策源能力显著增强，科技创新和产业创新深度融合，创新创业环境全面优化，创新机构高度集聚，创新人才纷至沓来，创新引领经济发展、城市管理、基层治理、社会生活各方面，浦东成为创新创造创业的梦想之城。

建设充满魅力的人文浦东。中华优秀传统文化和世界优秀文化交融共生，国际范、时尚风、烟火气闪亮大街小巷，舒适体验、暖心服务、品质生活融入城乡社区，崇德向善的文明风尚深入人心，浦东成为充满魅力、更有温度、人人向往的人文之城。

建设生态宜居的美丽浦东。生产、生活、生态融合协调发展，推窗见绿、四季有花、满目皆景，亮丽的城市景观、宜人的市容环境、滨水的休闲空间、美丽的乡村风貌成为浦东的重要标识，浦东成为人与人、人与城市、人与自然和谐共生的美好家园。

建设数实融合的智慧浦东。数智化转型深入发展，大数据、大模型、区块链等数智技术全面赋能经济发展、城市运行、市民生活，“一网通办”全面覆盖，“一网统管”精准高效，“一网通享”广泛普及，浦东成为引领未来的智慧城市样板。

在此基础上再奋斗五年，到2035 年，浦东现代化经济体系全面构建，现代化城区全面建成，现代化治理全面实现，人均地区生产总值比2020年翻一番，城市发展能级和国际竞争力跃居世界前列。

三、优化区域功能布局，拓展发展新空间新优势

加快完善“一轴引领、四带联动、八城辉映”生产力布局体系，实现多极支撑、协同共进。深入推进“精品城区、现代城镇、美丽乡村”现代化城区建设，促进城乡共同繁荣。

5.优化“一轴引领、四带联动”总体功能布局

16.推动国际贸易中心核心区提质增效

促进人水和谐发展。统筹水资源、水环境、水生态、水安全、水文化。加强城市供水保障和老旧管道更新改造，完成迎宾水厂(一期)建设和通水运行，推进东方枢纽、上海华力等重大工程供水设施建设，到2030年，供水水质合格率不低于99%。深化水污染防治，推进实施学海路等污水管道建设工程，加强园区、工业企业污水达标排放监管。加强河湖综合治理，推动生态清洁小流域建设。提升防汛排涝能力，建成北横河泵闸、杨思水闸等外围口门，开展外环运河等骨干河道建设，推进镇级河道建设。加强水文化保护传承。

43.全面改善生态环境质量

高标准推进“无废城市”建设，完善生态环境治理体系，到2030年，细颗粒物浓度达到上海市要求，重点建设用地100% 安全利用。

打造智慧循环的“无废城市”样板。提升工业固废治理能级，加强源头减量和高效利用，全过程监管危险废物，健全新污染物治理机制。强化生活垃圾资源化利用水平，贯彻落实限塑政策，推进可循环快递包装应用试点，强化生活垃圾分类收运过程监管。完善建筑垃圾资源化利用体系，推进建筑垃圾源头减量和全过程监管。

健全生态环境治理体系。完善生态环境监管体系，健全生态环境保护督察制度，落实排污许可“一证式”管理。推动数智赋能高水平环境治理，构建现代化生态环境智慧监测体系，启动数字孪生水网建设，促进水利数字化转型。推进生态环境治理市场体系，推动生态保护修复多元化投入机制，完善生态保护补偿机制。

十四、强化规划实施保障

落实任务分工和实施责任。制定规划实施方案，明确责任分工、时序安排和推进措施。加快完善相关指标的统计、监测和考核。对公共服务、生态环保、安全保障等领域任务，合理配置公共资源，有效引导社会资源。对产业发展、结构调整等领域任务，充分发挥市场对资源配置的决定性作用，创造良好政策环境。

加强资源配置和政策保障。引导要素资源向有利于发展规划实施的方向合理配置，促进人口、财政、土地、就业、金融、产业、区域等政策协同发力。对列入发展规划的重大项目，简化审批流程，优先保障资金、土地、海域、能源等资源要素。开展空间资源使用效益评估，推动低效空间资源依据发展规划优化配置和转型利用。拓展资金要素多元支持，财政资金优先投向发展规划确定的重大任务和重大项目，充分激发民间投资活力。

完善规划实施监测评估。完善规划实施全周期管理制度，健全监测评估机制，开展规划实施情况动态监测、中期评估和总结评估，分析规划实施存在的主要问题及其原因，提出加强和改进规划实施的应对举措。健全监督考核机制，发挥人大对推进规划实施的监督作用，鼓励开展第三方评估，主动接受社会各方监督。

强化规划衔接协调。发挥发展规划战略导向作用，加强发展规划对其他各类规划的指导性和约束力。强化国土空间规划基础作用，为发展规划落地实施提供空间保障，对专项规划、区域规划提出的空间开发保护活动提供指导、约束和支撑。增强专项规划、区域规划实施支撑作用。加强年度计划与发展规划的衔接，设置年度目标并做好年度间综合平衡，合理确定年度重点工作。

名词解释

1.“四大功能”：全球资源配置功能、科技创新策源功能、高端产业引领功能、开放枢纽门户功能。

2.“四个放在”：把上海发展放在中央对上海发展的战略定位上、放在经济全球化大背景下、放在全国发展大格局中、放在国家对长三角发展的总体部署中思考和谋划。

3.“两个放在”：把浦东新的历史方位和使命，放在中华民族伟大复兴战略全局、世界百年未有之大变局这两个大局中加以谋划，放在构建以国内大循环为主体、国内国际双循环相互促进的新发展格局中予以考量和谋划。

4.“三个在于”：浦东发展的意义在于窗口作用、示范意义，在于敢闯敢试、先行先试，在于排头兵的作用。

5.概念验证平台：从技术、市场、产业等维度，对科技成果进行验证的平台，旨在验证技术可行性并判断商业价值、评估市场潜力，推动科技成果形成产品、迈向市场化产业化应用阶段。

6.中试熟化平台：产品正式投产前的试验平台，即中间阶段的试验平台，是把处在试制阶段的新产品转化为产业化应用的过渡性试验平台。

7.揭榜挂帅：也称“科技悬赏制”，是指注重任务导向和结果导向，针对目标明确的科技难题和关键核心技术攻关，设立项目或奖金，不设门槛限制要求，向全社会公开张榜征集创新性科技成果的一种制度安排。

8.独角兽企业：成立时间不超过10年，获得过私募投资且尚未上市，估值超过10亿美元的企业。

9.瞪羚企业：创业后跨过死亡谷、以科技创新或商业模式创新为支撑、进入高成长期的中小企业。这类企业像瞪羚一样，成长性好，具有跳跃式发展态势。

10.专精特新企业：具备专业化、精细化、特色化和创新型特征的中小企业。

11.单项冠军企业：长期专注于制造业特定细分领域，生产技术或工艺水平达到国际先进或国内领先水平，且单项产品市场占有率位居全球或国内行业前列的企业。

12.“潮汐式”学校：通过灵活调整学校功能或学位供给，以应对学龄人口变化带来的学位供需波动，提升资源利用效率。

13.社区嵌入式养老：在社区内围绕老年人生活照料、康复护理、精神慰藉等基本需求，嵌入相应的功能性设施、适配性服务和情感性支持，让处于深度老龄化的社区具备持续照料能力，让老年人在熟悉的环境中、在亲情的陪伴下原居安养。

14.“平急两用”公共基础设施：集公共卫生、应急医疗和物资保障为一体的重大工程设施，重点在有条件的大城市布局，“平时”可用作旅游、康养、休闲、仓储物流等，“急时”可转换为人员临时安置、物资应急中转场所，满足公共卫生防控救治、临时安置、物资保障等需求。

15.“新八级工”：学徒工、初级工、中级工、高级工、技师、高级技师、特级技师、首席技师构成的职业技能等级序列。

16.“15分钟社区生活圈”：在市民慢行15分钟可达的空间范围内，完善教育、文化、医疗、养老、休闲及就业创业等基本服务功能，形成“宜居、宜业、宜游、宜学、宜养”的社区生活圈，构建以人为本、低碳韧性、公平包容的“社区共同体”。

17.“一套房、一间房、一张床”：“一套房”指保障性租赁住房中的小户型住宅，面向新市民、青年人等群体，提供稳定、可负担的长期居住空间“;一间房”指宿舍型租赁房源，适合单身或合租需求，如为一线公共服务人员提供的合租单元“;一张床”则聚焦最基础的住宿单元，通常为集体宿舍形式，优先保障低收入或过渡性住房群体。

18.“10、15、30”综合交通出行圈：中心城区超80%居民10分钟内步行或自行车可达轨道交通站点，全域机动车15分钟进入高快速路系统，所有街镇中心及特色产业园区30分钟可达主要交通枢纽。

19.“源网荷储”一体化：通过整合电源、电网、负荷和储能系统，构建多要素协同互动的新型电力系统模式。其核心目标是解决新能源波动性与电网稳定性之间的矛盾，实现能源高效利用和低碳转型。

20.“两旧一村”改造：旧区改造、旧住房成套改造和“城中村”改造。

21.“乡村CEO”：也称农村集体经济经理人，指为发展壮大新型农村集体经济，受农村集体经济组织委托，从事资源发包、物业出租、居间服务、经营性财产运营等经济活动经营管理的人员。

22.“两个100万”：第一个“100万”指在张江科学城等重点区域推出100万平方米以上可拎包入住的青年公寓，毕业3年内的高水平大学本科及以上学历青年人才，来浦东重点产业领域工作的，可享受租金不超过2000元/月、最长3年的优惠支持。第二个“100万”指在产业集聚区域推出100万平方米以上的创业孵化空间，新入驻的青年科创项目可享受日租金不超过1元/平方米、最长3年的优惠支持。入驻项目可获得企业注册、投融资对接、人才招聘、创业导师等服务。
