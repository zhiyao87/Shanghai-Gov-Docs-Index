# 上海市奉贤区人民政府金海街道办事处关于印发《金海街道关于规范小型建设工程项目管理实施办法》的通知

各科室、中心、村居、有关单位：

现将《金海街道关于规范小型建设工程项目管理实施办法》印发给你们，望你们认真贯彻落实。

特此通知。

上海市奉贤区人民政府金海街道办事处

2024年8月27日

金海街道关于规范小型建设工程项目管理实施办法

为进一步规范街道小型建设工程项目管理，确保小型建设工程公开、公正、公平和规范有序建设，现根据有关法律、法规的规定和《上海市奉贤区建设和管理委员会关于印发〈关于加强小型建设工程项目管理的实施意见〉、〈奉贤区政府投资项目标前管理办法〉等四个文件的通知》(沪奉建发〔2019〕5号)、《关于进一步落实政府性投资项目财务监理制的通知》(沪奉财〔2021〕33号)、《上海市奉贤区人民政府关于印发修订后的〈奉贤区政府投资管理办法〉的通知》(沪奉府规〔2022〕6号)、《关于印发〈奉贤区政府投资建设项目竣工财务决算管理操作规程〉的通知》(沪奉财〔2023〕9号)文件精神，并结合街道实际，制定本实施办法。

一、适用范围

本办法所指的小型建设工程是指全部或部分使用市、区、街道政府性资金、村级集体资金，且投资总额在400万元以下(不含400万元)的建设工程，具体包括：

(一)市政基础设施：乡村道路、桥梁、市政配套建设、土石方、桩基、绿化、环卫设施等工程。

(二)公共事业项目：学校、医院和党政机关、事业单位的行政办公楼等的新建、扩建、改建工程以及修缮、装饰工程。

(三)农业、水利基础设施：农用桥梁、排灌设施、驳岸、堤防、河道疏浚、土地整治等工程。

(四)街道认为需纳入的其他小型建设工程。

二、管理职责

项目建设责任单位(部门)负责项目的具体实施推进;街道营商环境办公室负责项目的预决算管理;街道社区发展办公室负责建设工程项目的日常监管工作及投资计划申报;街道城市建设管理事务中心负责安全质量监管工作。

三、小型建设工程过程管理

(一)项目报批管理

街道在小型建设工程管理过程中应遵循集体决策、手续完备的原则。

1、列入区发改委政府投资计划的项目：街道各单位(部门)应将小型建设工程列入区政府项目投资计划，落实建设资金。实施部门提交街道主任办公会或党工委会讨论后须形成会议纪要，编制项目可行性研究报告，按相关规定报区发改委立项审批。

2、使用预算外资金的项目：由实施部门编制项目概算，经街道评估后，报主任办公会决策，经集体讨论通过后实施。涉及概算金额30万及以上属于“三重一大”的提交党工委讨论决策。

3、使用村集体经济组织资金的项目：农村集体经济组织的小型建设工程项目须先经村两委班子集体讨论后报街道集体资产监督管理委员会审批，通过后召开村民(代表)大会表决通过。由项目实施部门编制项目概算。由街道进行评估，概算资金20万以下(不含20万元)报办事处备案。涉及概算金额20万及以上属于“三重一大”的提交党工委讨论决策。

4、绿化、水务、房修及政法基础设施等建设项目依据有关行业管理规定文件规定执行，并报主任办公会决策，经集体讨论通过后实施。涉及概算金额30万及以上属于“三重一大”的提交党工委讨论决策。

5、各单位(部门)不得对项目进行拆分后按小型工程进行审批，不得出现未批先建、未经招投标先发包等行为，确因特殊原因需先施工后报批、招投标的需经街道党工委会讨论同意明确先实施后补手续后方可实施，并及时补办相关手续。

(二)项目报建管理

1、投资总额100万元及以上或建筑面积300平方米及以上的新建、改建、扩建工程、装饰装修工程、房屋修缮工程(非住宅工程)的小型建设工程，完成立项批复后，应进行项目报建。

2、城市基础设施维修类、绿化工程、水务工程及房屋修缮工程(住宅工程)的小型建设工程，完成相关行业主管部门的备案要求后，应进行项目报建。

3、其他类型工程按照各行业规定执行。

(三)施工招投标管理

1、招标方式的确定

(1)施工单项合同估算值在100万元以上(含100万元)400万元以下(不含400万元)的小型建设工程，应采取公开招标方式确定施工承包单位。

(2)施工单项合同估算值在100万元以下(不含100万元)的小型建设工程可采用邀请招标方式，被邀请的投标人不得少于3人。

(3)对涉及公共安全、政府重大活动等急需修建的小型建设工程，需经街道党工委会集体讨论后，可择优选择施工单位先行进行施工，并及时办理相关手续。

(4)小型建设工程中属设备、货物和服务等项目，一律纳入政府采购程序。

2、招标投标程序

(1)招标。实施部门应按规定的程序自行组织招投标，或委托具有相应资质的招标代理机构进行代理招标，招标投标程序应严格按照《中华人民共和国招标投标法》相关规定执行。采用公开招标方式的，实施部门应按规定在相关对外网站发布招标公告，确保周知性。其中，国家机关、事业单位和团体组织使用财政性资金采购未达到公开招标数额标准的工程建设项目，应严格按照政府采购程序，遵守《中华人民共和国政府采购法》及相关规定。采用邀请招标方式的，实施部门应邀请不少于3家具备相应资质要求的施工单位参加投标。

(2)招标文件。实施部门在招标前应编制招标文件，明确评标办法，评标办法应采用经评审的最低标价法或综合评估法。在评标过程中，不得改变招标文件规定的评标标准、方法和中标条件，招标文件在招标前应按监管权属向相应监管部门备案。招标人可在招标文件中要求投标人的法定代表人或拟派项目经理参加开标，并要求投标人在投标文件中明确拟派遣管理团队名录，并承诺中标后不得替换，不可抗力因素除外。

(3)评标。评标应成立评标小组，评标小组人员一般由5人以上单数组成。其中，实施部门可有1人，其余为工程技术、经济类专家，评标专家由实施部门从区小型建设工程评标专家库随机抽取。

(4)中标。经评标小组评审确定施工单位后，实施部门应将中标结果在相应范围内予以公示。公示结束且无异议后按规定发出中标通知书，并按招标文件和中标人订立合同。同时按《上海市建设工程建管程序告知单》的要求办理相关施工手续。

3、招投标组织与监督

各小型建设项目的实施部门组织项目的招投标，街道社区发展办公室负责招投标过程的监管，专业工程有行业专门规定的，按相关行业管理规定实施。

4、信用管理

小型建设工程推行信用评价管理，实施部门可依据以下情况评定投标人履约不合格，评定履约不合格的投标人不得参与实施部门后续组织的小型建设工程招标活动。

(1)中标后无故放弃承包权或不签订合同;

(2)未按照招标文件要求派驻现场管理人员;

(3)将承包的工程转包或违反规定进行分包;

(4)不按时进场施工，不能按时按质按量完成施工任务;

(5)未按图纸要求施工，导致最终结算价超过合同价款的5%(不含5%);

(6)不履行安全生产责任制，发生安全事故的;

(7)与其他潜在投标人或者招标代理人串通，以他人名义或者其他方式弄虚作假骗取承包权;

(8)以停工、撤场、延期交付等方式胁迫招标人追加工程投资;

(9)未达到合同约定的项目管理目标;

(10)招标人认定的其它不履约行为。

5、规范招标代理人行为

(1)招标代理人在出售招标文件时应通过检验购买标书人员的身份证、社保证明等方式，确定购买标书人员的身份，并不得将两份及以上标书出售给同一购买标书人员;

(2)招标代理人出售招标文件、开答疑会及发补充招标文件等过程，应当全程进行摄像、录音，并刻盘保存;

(3)开标前招标代理人应对投标报名、招标文件领取等相关信息予以保密，不得透露其他投标人的相关信息;

(4)招标人在招标文件中要求投标人的法定代表人或拟派项目经理参加开标的，招标代理人应检验开标人员的身份证、社保证明等方式确认开标人员信息;

(5)对于街道评价履约不合格的投标人，招标代理人不得出售招标文件给不合格的投标人。

(四)施工管理

1、实施部门为小型项目施工安全、质量、文明施工管理的第一责任人。

2、街道小型建设工程推行工程监理制度。实施部门应按规定选取施工监理单位。监理单位必须具备相应监理资质。

3、投资额200万以下(不含200万)及建筑面积2000平方米以下(不含2000平方米)的小型工程项目由街道建管站负责街道项目的质量、安全、文明施工的监管。投资额200万以上(含200万)及建筑面积2000平方米以上(含2000平方米)的工程项目，实施部门应在开工前向区建设行业主管部门报备，并接受监管。

4、变更设计。在施工过程中，因客观原因需要变更设计超过概算金额5%及以上的，实施部门应当向街道提出申请，经街道审核同意后由设计单位变更设计图。

5、工作量变更。各实施部门必须严格控制因增加使用功能、提高标准等级而增加的工程量。凡属非增加使用功能、提高标准等级而增加的工程量，按照“先报审、后变更、再实施”的程序执行，实施部门应当向街道提出申请，经街道审核同意，并由建设方、监理方、施工方共同签证确认。

未按上述规定进行审批，擅自变更设计、增加工程量的，在工程结算时，增加部分的工程款不予认定。

(五)安全质量管理

1、小型建设工程开工前应办理安全质量监督申报手续，并按市、区现行的规定接受安全、质量监管部门的安全质量监督管理。

2、小型建设工程中标单位应是具有施工资质的施工企业。施工企业应切实加强施工现场安全质量管理，项目经理对施工现场的安全质量负主要责任。

3、实施部门应指派专人负责工程的安全质量监管工作，工程项目竣工后，由实施部门组织设计、施工和监理等各方进行工程验收，并在验收合格之日起15日内向街道备案。

(六)资金管理

1、小型建设工程竣工结算按以下方法执行：

(1)使用区财政计划资金的项目：项目完工后由项目(法人)单位委托第三方中介机构审价、就项目总投资编制工程决算;由主管部门对工程决算进行审核、出具竣工财务决算批复;批复文件报区财政局备案。

(2)使用预算外资金的项目：项目完工后由项目(法人)单位委托第三方中介机构审价、就项目总投资编制工程决算;街街道财务主管部门对工程决算进行审核、出具竣工财务决算批复。

(3)使用村集体经济组织资金的项目：项目完工后由项目(法人)单位委托第三方中介机构审价、就项目总投资编制工程决算;由街道财务主管部门对工程决算进行审核、出具竣工财务决算批复。

2、付款的方式和期限等应严格按合同约定履行。

3、若出现增加工作量导致最终结算价超过合同款，按照以下标准执行：

(1)列入区发改委政府投资计划的项目：项目出现超概算，实施部门须将调整情况报区发改委，区发改委审核后办理调整手续。

(2)使用预算外资金或村集体经济组织资金的项目：

①项目最终结算价不超过合同价款的5%且超出概算30万元以下(不含30万元)：实施部门须报主任办公会决策，经集体讨论通过后实施执行。由建设各方签证确认增加的工程量，其工程款应按施工合同和招投标文件中约定的投标单价结算。

②项目最终结算价超过合同价款的5%或超出概算30万元以上(含30万元)：实施部门须上报街道主任会及党工委会决策，经集体讨论通过后实施执行。由建设各方签证确认增加的工程量，其工程款应按施工合同和招投标文件中约定的投标单价结算。

最终结算价原则上应控制在不超过合同价款的5%以内。

4、小型建设工程涉及的相关设计、监理等相关费用不得高于国家、市相关收费标准，各项目责任单位不得擅自高于收费标准签订相关合同。

5、实施部门应将审计结果报街道营商环境办公室，营商环境办公室负责汇总统计。

(七)档案管理

各实施部门必须建立完善的小型建设工程项目档案制度。其中，应归档的资料包括：工程项目立项批文、集体讨论的会议纪要、工程项目报建表、招标代理合同、招标文件、投标文件、施工图设计文件、评标记录、中标通知书、施工合同、施工单位证件(营业执照、资质证书、安全生产许可证、项目经理资格证书复印件)、监理合同、工程项目审计情况表和廉洁协议等。

四、检查考核、纪律要求与责任追究

1、在工程建设中，参建各方必须严格遵循诚信、守法、自律的原则。

2、实施部门与中标的施工企业就工程建设的有关事宜签订合同和廉洁协议，明确各方的权利和义务。

3、实施部门及上级(主管)部门的分管领导对工程项目负有直接和领导责任，切实加强对工程建设的管理和领导。违反下列规定的将移交有关部门处理：

(1)实施部门不严格执行本意见，存在违规规避招标、干预招标等行为的;

(2)违反国家建设法律、法规及强制性标准，造成工程质量安全事故的;

(3)未按工程建设规定，擅自扩大建设规模，提高工程建设标准，增加或变更使用功能，聘用无资质施工队伍组织施工的;

(4)工程竣工验收后，不按规定及时整理工程档案资料，导致档案缺失，或未按照规定验收，擅自交付使用的;

(5)参建单位等出现违法违规行为，造成后果的;

(6)擅自对项目拆分后按小型工程进行审批的;

(7)其他违法违规行为。

4、各级领导干部不得违规插手干预工程建设，不得利用职权为本人、亲属及其他人谋取私利或特殊照顾。对各类违规插手干预工程建设的行为根据《关于领导干部违规插手干预工程建设行为记录报告工作的实施办法(试行)》工作要求，如实记录报告。

五、其他

1、本意见自发布之日起实施。

2、本意见如与国家和上海市的有关法律、法规及上级文件精神有抵触的，以法律、法规及上级文件精神为准。

3、投资总额在400万元以上(含400万元)的建设工程参照《上海市奉贤区人民政府关于印发修订后的〈奉贤区政府投资管理办法〉的通知》沪奉府规〔2022〕6号文件精神执行。
