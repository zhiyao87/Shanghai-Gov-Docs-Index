# 关于印发《徐汇区促进绿色低碳产业发展的扶持意见》的通知

区各有关委、办、局，各街道、华泾镇，有关单位：

《徐汇区促进绿色低碳产业发展的扶持意见》已经区政府同意，现印发给你们，请认真按照执行。

徐汇区发展和改革委员会

2025年1月24日

徐汇区促进绿色低碳产业发展的扶持意见

为全面贯彻新发展理念，高质量落实碳达峰碳中和战略部署，促进徐汇区绿色低碳发展，根据《中华人民共和国节约能源法》《中共中央国务院关于加快经济社会发展全面绿色转型的意见》《上海市瞄准新赛道促进绿色低碳产业发展行动方案(2022-2025年)》，结合区域实际，特制定本扶持意见。

一、支持对象

本政策适用于依法经营的绿色低碳产业法人或非法人组织机构，以及其他依法经区政府批准的支持对象。上述主体须符合区域产业发展导向，经营状况良好，无严重违法失信行为。

二、支持方式

(一)提升绿色低碳产业发展能级

1.推动绿色低碳企业集聚。围绕储能电池及系统、核能制造及设计服务、新能源汽车、充电设施、绿色燃料、节能环保等细分领域，加快吸引和促进符合区域产业发展导向的具备行业优势、高成长型绿色低碳企业，经综合评估，最高可给予3000万元支持，对其中能级较高的，经综合评估，最高可给予1000万元的一次性支持。

2.搭建创新型功能型机构和平台。支持搭建碳排放监测、碳核查认证、碳足迹认证、碳标签、碳排放披露、碳排放交易等具备公共服务属性、能够协作开展产业技术研发、科技成果产业化和公共服务的创新平台，对能促进产学研深度融合的平台机构，根据引进集聚企业的综合贡献，经综合评估，最高可给予一次性300万元奖励。

3.加强绿色低碳核心技术攻关。支持各类新设主体开展绿色低碳重点领域“卡脖子”核心技术攻关、重大装备及关键零部件研发等，对发起或参与国际大科学计划、承担国家科技计划项目、纳入市级高新技术成果转化项目的，经综合评估，最高可给予300万元奖励。发挥绿色技术对绿色低碳发展的关键支撑作用，支持各类新设主体申报绿色低碳先进技术示范项目，经综合评估，最高可给予100万元奖励。

(二)创新绿色低碳新模式新场景

4.促进绿色金融健康发展。加快吸引和促进符合区域产业发展导向的绿色金融研究咨询机构等，根据支持集聚绿色低碳机构的情况，经综合评估，最高可给予100万元支持。鼓励资管机构以绿色指数为基础开发绿色基金、绿色信托、绿色债券等绿色金融产品，经评审，首次发行最高可给予50万元奖励。

5.支持绿色燃料试点创新发展。围绕以生物柴油、可持续航煤、生物燃料乙醇、可再生甲醇、可再生氨等为代表的可再生能源领域，加快吸引和促进符合区域产业发展导向的绿色燃料研发生产销售型企业，经综合评估，最高可给予一次性300万元支持。鼓励航空和船舶企业推广应用绿色燃料，强化节能降碳运营管理，加快吸引和促进符合区域产业发展导向的企业，获得市级及以上资金扶持或取得显著成效的，经综合评估，最高可给予一次性100万元支持。

6.鼓励企业开展碳排放服务。支持企业开展碳排放管理、产品碳足迹评估与认证、航运清洁燃料认证、欧盟CBAM等相关认证(碳关税)、CDP问卷申报(碳披露项目)、ESG管理体系建设与报告发布等服务，对节能减排效果明显或获得国内外权威认可的企业，经评审，可按项目服务价格的10%给予奖励，最高20万元。

7.积极创建绿色低碳试点示范。在本区实施的市级绿色建筑、超低能耗建筑、既有建筑节能改造、可再生能源与建筑一体化等建筑节能和绿色建筑示范项目，经评审，可按市区配套1:0.5的比例，最高可给予300万元支持。优化充电桩等新型基础设施布局，对在建筑楼宇、充电场站、园区等场景，结合电网调峰调频需求，采用多元主动错峰错时缓解电网压力的，经评审，可按项目总投资的30%给予扶持，最高50万元。

(三)构建绿色低碳产业发展生态

8.营造产业发展的浓郁氛围。支持各类主体主导参与绿色低碳国际标准、国家标准、行业标准、地方标准、团体标准等标准制定项目，经评审，最高可给予100万元奖励。支持碳普惠核证减排量交易，对备案公布的碳普惠方法学制定机构，经评审，最高可给予10万元/个奖励。鼓励企业开发碳普惠应用程序，打造碳普惠场景，经评审，最高可给予10万元/个奖励。支持各类主体参加或举办具有影响力的碳达峰碳中和领域活动，经评价，可按实际投入的50%给予补贴，最高50万元。

9.做实做细人才服务保障。对用人单位的国内外优秀人才，按照相关政策推荐申请“光启人才行动计划”，并提供人才落户、安居、医疗、出入境等方面便利化服务。

三、附则

(一)在享受本政策期间，如同时可享受本区其他同类政策，按照“就高不重复”原则施行。在实施过程中如遇国家、上海市颁布新政策，按新政策执行。

(二)对弄虚作假骗取扶持资金、擅自改变资金用途等行为，将追究扶持对象的责任。对违反相关法律法规的扶持对象，经查实，根据情节轻重，在一定时期内取消对象申报扶持资金的资格。

(三)本意见规定的经区政府批准、经综合评估、经评审等(以下统称认定)，应当按照公平合理客观的认定条件和规范透明的认定程序，依法依规开展相关认定工作。

(四)本意见由徐汇区发展和改革委员会会同徐汇区投资促进办公室、徐汇区财政局负责解释。

(五)本意见自2025年2月24日起试行，试行期二年。在本意见施行前享受原政策的，按原政策执行。自试行之日起，《徐汇区促进绿色低碳产业发展的扶持意见》(徐发改规〔2022〕1号)文件废止。
