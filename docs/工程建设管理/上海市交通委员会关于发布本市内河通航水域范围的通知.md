# 上海市交通委员会关于发布本市内河通航水域范围的通知

各有关单位：
根据《中华人民共和国内河交通安全管理条例》、《上海市内河通航安全管理规定》等法规的规定，我委结合实际划定本市内河通航水域范围，现予发布（附录）。后续相关通航水域发生变化的，由各辖区交通主管部门提出申请，我委研究确定后统一更新发布。
特此通知。

附件：上海市内河通航水域范围

二○二二年五月十五日
