# 上海市住房和城乡建设管理委员会关于批准《人民防空工程安全风险评估技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《人民防空工程安全风险评估技术标准》为上海市工程建设规范的通知

沪建标定〔2025〕135号

各有关单位：

由上海市民防监督管理事务中心、同济大学主编的《人民防空工程安全风险评估技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2281-2025，自2025年9月1日起实施。原《公用民防工程安全风险评估技术标准》（DG/TJ08-2281-2018）同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市民防监督管理事务中心负责解释。

特此通知。

2025年3月5日
