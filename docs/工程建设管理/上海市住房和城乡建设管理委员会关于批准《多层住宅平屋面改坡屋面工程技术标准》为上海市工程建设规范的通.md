# 上海市住房和城乡建设管理委员会关于批准《多层住宅平屋面改坡屋面工程技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《多层住宅平屋面改坡屋面工程技术标准》为上海市工程建设规范的通知

沪建标定〔2022〕78号

各有关单位：

由上海市住宅修缮工程质量事务中心和上海市房地产科学研究院主编的《多层住宅平屋面改坡屋面工程技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-023-2022，自 2022年7月1日起实施。原《多层住宅平屋面改坡屋面工程技术规程》DG/TJ08-023-2006同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市住宅修缮工程质量事务中心负责解释。

2022年1月28日
