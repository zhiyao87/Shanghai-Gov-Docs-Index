# 上海市第一次自然灾害综合风险普查领导小组办公室关于进一步加强自然灾害综合风险普查宣传工作的通知

各区第一次自然灾害综合风险普查领导小组，市第一次自然灾害综合风险普查领导小组各成员单位：
目前，全市第一次自然灾害综合风险普查 (以下简称普查) 工作已进入攻坚阶段。为进一步做好本市普查的宣传工作，营造良好的普查工作氛围，争取社会各界对普查工作的理解和支持，根据《国务院第一次全国自然灾害综合风险普查领导小组办公室 中共中央宣传部关于印发<第一次全国自然灾害综合风险普查宣传工作方案>的通知》（国灾险普办发〔2021〕11号），《上海市人民政府办公厅关于本市开展第一次自然灾害综合风险普查的通知》《上海市第一次自然灾害综合风险普查领导小组办公室 中共上海市委宣传部关于印发<上海市第一次自然灾害综合风险普查宣传工作方案>的通知》(简称《宣传工作方案》)要求，现就进一步加强普查宣传工作有关事项通知如下。
一、高度重视普查宣传工作
第一次全国自然灾害综合风险普查是一项重大的国情国力调查，是提升自然灾害防治能力的基础性工作。做好普查宣传工作，是顺利开展风险普查的重要前提。各区灾险普查领导小组（办公室）、各成员单位要深入贯彻落实习近平总书记关于提高自然灾害防治能力重要论述精神，李克强总理重要批示要求，高度重视，精心组织普查宣传工作，为普查工作顺利实施创造良好环境。各区灾险普查领导小组（办公室）要积极与新闻宣传部门沟通协调，印发工作动态、落实宣传单位,做好统筹、组织、实施等工作，确保各阶段宣传任务落到实处。
二、做好全面调查阶段集中宣传工作
为贯彻落实６月22日第一次全国自然灾害综合风险普查工作电视电话会议关于深入开展宣传动员工作的要求，各区灾险普查领导小组（办公室）、市灾险普查领导小组各成员单位要对全面调查阶段的集中宣传工作作出周密安排，针对调查工作涉及面广、参与单位和人员多的特点，开展多种形式的宣传活动，自本通知发布起每月报送不少于2篇的宣传报道（图文或视频）至市灾险普查办。要在普查工作实施过程中，广泛宣传普及自然灾害风险、灾害风险防范和应对的相关知识和技能，强化灾害风险管理理念，努力提升基层防灾减灾救灾意识和能力。
三、做好宣传产品多渠道投放工作
各区灾险普查领导小组（办公室）、市灾险普查领导小组各成员单位要使用好国务院普查办、市灾险普查办提供的普查LOGO、标语口号、宣传海报、公益宣传片、科普动画、宣传手册、宣传长图等产品（链接：https://pan.baidu.com/s/1RSfIZ385tkUe0
iuWMcT8vQ，提取码：2021），发挥主观能动性，设计开发形式多样、具有地区特色的宣传产品，做好宣传品的发放使用。要充分调动本地区和本部门传媒载体，利用户外大屏幕、标语横幅、网络媒体(如微信、微博、抖音、快手等)、建筑外墙、楼宇电梯、宣传长廊和橱窗等多种渠道，集中开展宣传产品投放工作，确保宣传效果。要及时填报《第一次自然灾害综合风险普查宣传情况汇总表》（附件），于每月底前报送至市灾险普查办。
四、强化宣传工作督导通报
各区灾险普查领导小组（办公室）、市各成员单位要加强对本地区和本行业宣传工作的督促指导，及时掌握宣传工作开展情况和存在问题，分析评价宣传产品投放和宣传活动效果，并向市灾险普查办报告有关情况。市灾险普查办将对各地区和各成员单位宣传工作进展和实效开展阶段性分析评估，适时通报有关情况。
