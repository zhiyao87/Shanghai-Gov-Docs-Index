# 关于印发《上海市节水型农业示范区评价指标及考核办法》的通知

关于印发《上海市节水型农业示范区评价指标及考核办法》的通知

沪水务〔2021〕459号

各区水务局、农业农村委：

为深入贯彻“节水优先”治水思路，落实国家和本市节水行动方案，根据《中共中央 国务院关于全面推进乡村振兴加快农业农村现代化的意见》（中发〔2021〕1号）精神，市水务局、市农业农村委合力推进上海市节水型农业示范区建设，并在《上海市节水型农业园区评价指标和考核办法（试行）》（沪水务〔2012〕983号）的基础上，研究制订了《上海市节水型农业示范区评价指标及考核办法》，进一步明确了节水型农业示范区创建范围、标准和程序，现印发给你们，并就有关事项通知如下：

一、充分认识创建节水型农业示范区的重要意义

开展节水型农业示范区创建工作是持续落实国家节水行动方案的重要内容，通过树立节水示范标杆的方式，积极引导各区促进农业用水方式转变，推进高效节水灌溉设施建设及灌溉精细化管理，进一步提高农业灌溉用水效率和水资源集约节约利用水平，增强农业用水领域节水、爱水、护水意识，促进农业节水减排和可持续发展。

二、加强部门协作，明确任务分工

上海市节水型农业示范区的考核工作由市水务局和市农业农村委共同负责，上海市水利管理事务中心负责推进具体创建工作。市级水务、农业部门每年面向全市组织开展节水型农业示范区的申报工作，并负责申报后考核复核及技术指导；区级水务、农业部门要按照职责分工，组织做好农业示范区的申报自评、设施和用水管理等工作；各农业示范区根据评价指标及考核办法的要求，完成自查自评，并将自评结果及相关申报材料报上海市水利管理事务中心。各级各部门要加强部门沟通、上下联动，建立协同推进机制，共同做好创建工作。

三、强化科学评价，规范考核程序

按照公平、公开、公正的原则，满足要求的农业示范区通过申报、自评、现场核查等程序完成节水型农业园区创建工作。市水务局、市农业农村委组织开展节水型农业示范区考核和命名工作。被命名为上海市节水型农业示范区称号的，每五年开展一次复评。

四、落实保障措施，确保工作成效

一是加强组织领导。各级各部门要高度重视节水型农业示范区创建工作，市相关部门加强协调组织和工作指导，各区要具体落实责任，明确任务和分工，确保农业示范区发挥标杆作用。

二是保障经费落实。各区积极支持节水型农业示范区创建工作，加大农业节水改造投入力度，加强节水技术推广和应用。同时，结合农业灌溉设施管护，研究出台相应的配套激励制度，进一步提高创建工作的积极性。

三是加强监管应用。对已评定为节水型农业示范区的灌区加强日常监管，鼓励通过信息化监管手段，实时监测农业用水量。同时加强成果应用，视情况将创建成果纳入水资源管理考核或农田管护考核工作中。

四是加大组织宣传。各级主管部门可通过电视、报纸、网络媒体等方式，宣传节水型农业示范区创建经验和成效，推广做法、树立典型，形成农业节水减排的良好氛围。
