# 关于印发《关于进一步加强宝山区街镇综合行政执法工作的实施意见》的通知

各街镇：

现将《关于进一步加强宝山区街镇综合行政执法工作的实施意见》印发给你们，请遵照执行。

特此通知。

上海市宝山区城市管理行政执法局

2021年8月24日

关于进一步加强宝山区街镇综合行政执法工作的实施意见

为深入贯彻落实市委、市政府《关于完善街道乡镇管理体制整合街道乡镇管理服务资源的实施意见》（沪委办发〔2020〕28号）和市城管执法局《关于进一步加强本市街道乡镇综合行政执法工作的实施意见》（沪城管联〔2021〕4号）文件精神，全面推进宝山区街镇综合行政执法工作，现结合我区实际制定如下实施意见。

一、指导思想

深入贯彻习近平总书记考察上海重要讲话精神，践行“人民城市人民建，人民城市为人民”重要理念，围绕宝山科创中心主阵地建设战略定位，以“权责清晰、指挥顺畅、运行高效、行为规范、服务优良、保障有力”为目标，健全完善行政执法工作体制，整合街镇执法资源，实现“一支队伍管执法”，进一步提高基层治理能力，提升人民群众获得感和幸福感。

二、主要内容

（一）完善街镇综合行政执法体系

1.明确街镇综合执法职责。街道办事处、镇人民政府为辖区内相对集中行政处罚权的执法主体，按照规定的权限，统一组织开展辖区内综合行政执法活动，对辖区内职能部门负责的执法事项进行综合协调，整合辖区内管理服务执法资源力量，提高综合行政执法效能。街镇综合行政执法队（城市管理行政执法中队）以街道办事处、镇人民政府名义，具体承担本辖区内综合行政执法工作。

2.理顺街镇综合执法关系。区城管执法局主要负责街镇综合执法法制指导、业务培训和统筹协调等工作。区城管执法局执法大队具体负责街镇综合执法协调、监督等工作。街镇综合行政执法队（城市管理行政执法中队）承担辖区内综合行政执法工作。区城管执法局要加强与区职能部门对接沟通，厘清管理部门和街镇综合执法职责边界，及时研究解决街镇综合执法中的综合性问题，开展联合培训，提高服务街镇综合执法工作的能力和水平。

3.优化街镇综合执法力量。根据综合行政执法职责调整和人口变化等情况，适当调整充实街镇综合行政执法人员编制，重点向区域面积较大、城市化进程较快、外来人口较多、管理执法任务较重的街镇倾斜。

（二）强化街镇综合行政执法队伍建设

1.加强综合执法队伍党的建设。坚持把政治建设放在首位，街镇综合行政执法队（城市管理行政执法中队）有正式党员3名以上的，应建立党支部。严格落实党的组织生活基本制度，加强对党员的教育管理监督，充分发挥党支部战斗堡垒作用和党员先锋模范作用。

2.开展街镇综合行政执法工作评议。区城管执法局制定街镇综合行政执法工作评议办法，结合执法办案的数量、质量与实效以及队伍建设等综合情况，对街镇综合行政执法工作开展考核与分析，并提出工作建议，评议结果纳入各街镇年终考核。

3.严格执法人员日常管理。建立统筹规范的培养选拔、教育培训、职级晋升、考核奖惩和转任交流等管理制度。严把人员进口关、严格执法人员持证上岗制度，严禁无执法资格人员从事执法活动。严禁随意抽调、借调执法人员，确保执法人员在编在岗，严禁使用非在编人员担任执法队领导职务，加大教育培训力度，严格落实培训学时学分管理制度，不断提高街镇执法人员业务能力水平。

（三）规范街镇综合行政执法行为

1.依法承接赋权执法事项。根据《上海市城市管理综合行政执法条例》规定，涉及城市管理领域的相关行政执法职权，下放至街道办事处和乡镇人民政府并以其名义集中行使。区城管执法局、街镇依据《上海市街道办事处乡镇人民政府首批行政执法事项目录清单》分别行使执法事项。

2.统一执法流程和标准。按照上海市城管执法局等相关职能部门制定并颁布的街镇综合行政执法流程和标准，统一执法程序，统一执法文书，统一裁量基准，统一制服装备。

3.严格执行行政执法三项制度。街镇城管综合执法部门全面落实行政执法公示、执法全过程记录、重大行政执法决定法制审核制度。街镇司法所负责街镇重大行政执法决定法制审核工作。重大行政执法决定未经法制审核或者审核未通过的，不得作出行政处罚决定。街镇司法所在重大行政执法决定法制审核过程中确实需要听取区城管执法局意见的，可以会商区城管执法局，区城管执法局给予支持配合。街镇可通过建立法律顾问制度、加强法制审核人员配备等方式，提高依法行政水平。

（四）创新街镇综合行政执法勤务模式

1.拓展社会治理新路径。健全完善街镇普法宣传教育机制，强化执法服务宣传工作。组织开展“7·15公众开放日”“夏令热线”等公众参与活动，建立街镇综合执法第三方评价机制，积极动员基层自治组织、社会组织等参与社会治理。

2.优化勤务调度处置机制。构建区城运中心、区局指挥中心和街镇指挥平台三级城市管理执法综合指挥监管体系。区城管执法局指挥中心突出勤务指挥、数据运维、分析研判、日常管控和对突发情况的处置调度，协调指挥区域内重大活动保障；街镇综合行政执法队（城市管理行政执法中队）指挥平台聚焦数据报送、属地管理、现场处置，实现综合行政执法全域覆盖、依责承接、智能派单、分级响应、高效处置。

3.推进综合执法数字化转型。主动对接融入“一网统管”建设。区城管执法局指导、监督各街镇综合行政执法队（城市管理行政执法中队）用好网上勤务、网上办案、网上督察、网上考核等业务信息系统，提高现代化科技手段在执法办案中的应用水平。推动城市管理等重点治理领域的智能应用场景建设。推行非现场执法、“双随机、一公开”抽查等创新方式，提高街镇综合行政执法效率。

（五）落实街镇综合行政执法协作机制

1.健全管执联动机制。健全区城管执法局、街镇与建管、规资、交通、房管、公安、市场、环保、应急、绿容、水务等职能部门之间执法协调衔接机制，进一步健全相互告知、案件移送、协助调查、联合执法、信息共享等工作制度，确保管理与执法有效衔接。

2.完善执法协作机制。发挥数据驱动功能，完善与区城运中心等部门数据信息共享协作机制，为街镇综合行政执法提供有力支撑，深入推进城市管理精细化。

3.落实两法衔接和非诉执行。街镇综合行政执法部门在行政执法中发现违法行为涉嫌犯罪的，应当依法将案件移送司法机关查处。有关移送条件、流程和规范依据《上海市城市管理行政执法与刑事司法衔接工作办法》执行。与法院对接，建立行政处罚决定强制执行机制。

（六）加强街镇综合行政执法监督检查

1.完善执法监督体系。加强对综合执法三项制度的监督检查，在明确市、区、街镇三级监督职责和工作重点的基础上，创新执法监督方法，完善执法监督规定。通过执法建议、第三方社会测评等方式，完善监督机制，提高执法监督的精准度和实效性。加强对接纪委监委、法院、检察院等部门，建立联合监督机制。强化监督结果应用，将监督结果纳入街镇综合执法工作考核评价范围。

2.遵守行政执法人员执法行为规范。按照上海市城管执法局相关要求，执法人员应坚持执法为民理念，尊重当事人的基本权利和合法权益，严格遵循法定程序，做到语言文明、行为规范、结果公正，严禁暴力执法、徇私枉法。

3.落实执法人员责任过错追究。对街镇综合行政执法队（城市管理行政执法中队）行政执法过错责任人，根据其违法事实、情节、后果和责任程度，依据《上海市城市管理行政执法责任制规定（试行）》严肃追责。

三、工作要求

（一）加强组织领导

要充分认识综合行政执法工作的重要性和必要性，及时研究解决推进过程中产生的问题与矛盾，合力构建符合街道乡镇综合行政执法工作特点的管理体制机制。

（二）强化工作落实

要进一步细化措施，夯实责任，加强综合行政执法队伍全面建设，做到综合执法工作规范有序、实效明显。

（三）注重宣传引导

要注重对街镇综合行政执法工作的社会宣传和舆论引导，广泛发动和积极引导广大市民及社会力量的支持和参与，为街道乡镇综合执法工作营造良好舆论氛围。
