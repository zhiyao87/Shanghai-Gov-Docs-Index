# 上海市嘉定区人民政府关于批转《2021年嘉定区重大工程建设进度计划》的通知

各镇人民政府，区政府各委、办、局，街道办事处，嘉定新城、嘉定工业区、菊园新区管委会，各项目单位：

区重大办拟定的《2021年嘉定区重大工程建设进度计划》（嘉重建[2021]1号）已经区政府研究同意，现批转给你们，请按照执行。

上海市嘉定区人民政府

2021年1月29日

2021年嘉定区重大工程建设进度计划

2021年是“十四五”规划开局之年，并将迎来中国共产党成立100周年。为持续提升嘉定城市能级和核心竞争力，打造“创新活力充沛、融合发展充分、人文魅力充足”的现代化新型城市，2021年将继续重点推进一批事关经济社会发展的重大工程建设。根据1月5日区政府第93次常务会议精神，现已编制完成《2021年嘉定区重大工程建设进度计划》。

一、年度计划安排

2021年共安排市政设施、社会事业、产业发展、住房保障四大类重大工程项目40个，其中新开工项目26个，在建项目8个，建成项目6个，完成投资83.8亿元。

（一）市政设施类

共安排重大工程项目9个，其中新开工项目3个，在建项目3个，建成项目3个。

1.3个新开工项目分别是：汇旺路、嘉定新城架空线入地、区污水厂污泥资源化利用项目；

2.3个在建项目分别是：安亭污水处理厂三期扩建、涉铁春浓路、永胜水厂三期扩建及深度处理；

3.3个建成项目分别是：裕民南路地道、区区对接临洮路、娄陆公路。

（二）社会事业类

共安排重大工程项目8个，均为新开工项目。

分别是：区档案馆、惠亚路中学、嘉定新城马陆社区27-2地块九年学校、嘉定新城中心区B24-4地块幼儿园、嘉定新城G10-1地块小学、嘉定新城中心区B24-3地块小学、区公共卫生综合大楼、华东师范大学第五附属学校。

（三）产业发展类

共安排重大工程项目15个，其中新开工项目11个，在建项目1个,建成项目3个。

1.11个新开工项目分别是：温州（嘉定）科技创新园二期、上海机动车检测认证中心氢能与燃料电池检测中心、上海安亭科学仪器厂FFT全球总部、上海浩源云企业发展公司云+智能驾驶创新基地、禾赛新建超级工厂项目、高博航空技术（上海）公司研发及制造基地、上海厚孚信息技术公司研发及制造基地、上海艾普强粒子设备公司企业总部、上海洗霸科技公司总部园区、临港嘉定科技城一期、上海冠龙阀门机械公司冠龙阀门企业总部；

2.1个在建项目是：12英寸集成电路研发制造用厂房及配套设施项目;

3.3个建成项目分别是：迅达电梯四号地块项目、智能传感器创新中心能力建设、沃尔沃汽车研发中心（三期）。

（四）住房保障类

共安排重大工程项目8个，其中新开工项目4个，在建项目4个。

1.4个新开工项目分别是：安亭镇泰东公寓（三期）征收安置房、嘉定工业区菊园社区42-06地块征收安置房、徐行镇32-02地块征收安置房、徐行镇33-02地块征收安置房；

2.4个在建项目分别是：外冈镇02-01地块征收安置房、外冈镇04-01地块征收安置房、嘉定工业区南门社区29-06地块征收安置房、江桥镇G1A-09A地块征收安置房。

此外，涉及我区的市属市重大工程有关项目，按市下达计划执行，同时作为区重大工程。

二、具体实施要求

1.项目单位（代建单位）要加强组织领导，加快项目建设推进，抓开工、促施工、保竣工。对新开工项目，要抓紧项目前期筹备，加快履行建设程序，依法合规开工建设。对建成和在建项目，要细化节点目标，优化施工组织，抓好文明施工，在确保安全质量的前提下加快建设进展。

2.涉及街镇要加强服务保障，积极创造实施条件。配强一线人员，积极稳妥推进征地出劳，及时完成征收腾地。要按照区镇分工，及时启动、按时完成道路、水电气等配套建设，支持重大工程建成投运。要切实做好信访矛盾化解和维护稳定工作，保障重大项目按计划顺利推进。

3.职能部门要加强指导服务，加快项目审批审核。要以优化营商环境为导向，以加快完成规划用地手续，取得施工许可证为核心，促成项目尽早开工建设。要按照“有求必应、无事不扰”的要求，帮助指导项目单位切实有效加快履行建设程序，努力当好项目建设推进的“店小二”。

4.区重大办要加强统筹谋划，做好总体协调推进。坚持目标导向、需求导向、问题导向，抓开工、促施工、保竣工。做好跟踪服务，加强分类指导，充分发挥平台桥梁作用。进一步健全完善全方位、多层次的协调推进机制，形成举全区之力推进重大工程建设的良好氛围。

重大工程建设作为区政府重点工作之一，已经列为2021年重点督办事项，区政府办公室将会同区重大办对重大工程建设推进情况定期进行督查和通报。
