# 上海市住房和城乡建设管理委员会关于批准《城镇污水处理厂污泥干化焚烧处理工程建设标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《城镇污水处理厂污泥干化焚烧处理工程建设标准》为上海市工程建设规范的通知

沪建标定〔2022〕129号

各有关单位：

由上海市政工程设计研究总院（集团）有限公司主编的《城镇污水处理厂污泥干化焚烧处理工程建设标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08- 2394-2022，自2022年7月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市政工程设计研究总院（集团）有限公司负责解释。

2022年3月1日
