# 上海市住房和城乡建设管理委员会关于批准《道路声屏障结构技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《道路声屏障结构技术标准》为上海市工程建设规范的通知

沪建标定〔2023〕58号

各有关单位：

由上海市道路运输事业发展中心和上海建设结构安全检测有限公司主编的《道路声屏障结构技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为 DG/TJ08-2086-2023，自2023年7月1日起实施。原《道路声屏障结构技术规范》DG/TJ08-2086-2011同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市道路运输事业发展中心负责解释。

2023年1月31日
