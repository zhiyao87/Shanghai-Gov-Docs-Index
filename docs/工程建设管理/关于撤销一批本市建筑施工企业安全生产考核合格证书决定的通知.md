# 关于撤销一批本市建筑施工企业安全生产考核合格证书决定的通知

沪建质安〔2022〕331号
上海市住房和城乡建设管理委员会
关于撤销一批本市建筑施工企业安全生产考核合格证书决定的通知

各有关单位:
依据《建筑施工企业主要负责人、项目负责人和专职安全生产管理人员安全生产管理规定实施意见》（建质〔2015〕206号）和《上海市建筑施工企业主要负责人、项目负责人和专职安全生产管理人员安全生产考核发证管理办法（试行）》（沪住建规范〔2020〕6号）规定，因弘历工程管理（上海）有限公司等5家建筑施工企业的项目负责人和专职安全生产管理人员在办理安全生产考核合格证书进沪换证时做出虚假承诺，未按要求提供相关证明材料，并未按要求整改，现决定对涉事企业予以行业通报，同时撤销相关人员违规取得的安全生产考核合格证书，并自通知下发之日起，一年内不再受理相关人员安全生产生产考核合格证书申请。具体单位、个人及证书信息详见附件。
特此通知。

附件：撤销证书人员和相关企业名单

2022年7月20日
