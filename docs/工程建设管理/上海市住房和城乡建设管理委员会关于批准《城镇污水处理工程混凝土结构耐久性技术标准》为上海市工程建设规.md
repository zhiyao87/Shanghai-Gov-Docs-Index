# 上海市住房和城乡建设管理委员会关于批准《城镇污水处理工程混凝土结构耐久性技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《城镇污水处理工程混凝土结构耐久性技术标准》为上海市工程建设规范的通知

沪建标定〔2025〕426号

各有关单位：

由上海市建筑科学研究院有限公司、上海城投污水处理有限公司、上海市排水管理事务中心主编的《城镇污水处理工程混凝土结构耐久性技术标准》，经我委审核，现批准为上海市工程建设规范,统一编号为DG/TJ08-2483-2025，自2026年3月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市建筑科学研究院有限公司负责解释。

特此通知。

2025年8月28日
