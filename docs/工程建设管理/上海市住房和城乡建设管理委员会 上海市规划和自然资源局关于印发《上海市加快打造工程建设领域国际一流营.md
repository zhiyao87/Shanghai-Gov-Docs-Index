# 上海市住房和城乡建设管理委员会 上海市规划和自然资源局关于印发《上海市加快打造工程建设领域国际一流营商环境行动方案（2026年）》的通知

上海市住房和城乡建设管理委员会 上海市规划和自然资源局关于印发《上海市加快打造工程建设领域国际一流营商环境行动方案（2026年）》的通知

沪建建管联〔2026〕188号

各有关单位：

为持续推进工程建设领域优化营商环境改革，根据《上海市优化营商环境条例》《上海市加快打造国际一流营商环境行动方案（2026年）》相关规定，现将《上海市加快打造工程建设领域国际一流营商环境行动方案（2026年）》印发给你们，请认真按照执行。

2026年5月11日

上海市加快打造工程建设领域国际一流营商环境行动方案（2026年）

一、聚焦实际需求，提升市场主体获得感

1.提升工程项目全流程审批效能。强化国土空间规划引领，持续推动“用地清单制”改革。推动区域评估成果应用，支持有建设需求的成片开发地区按需开展各类区域评估，结果供区域内项目共享使用，简化或减少单个项目相关专项评估评审。巩固提升“一站式施工许可”改革成效。深化“多审合一、多证合一、多测合一、多验合一”的审批制度改革，进一步加强部门协同，降低企业制度性交易成本。

2.加强城市更新政策供给。以“三师”联创机制推动更新规划编制与实施，加强规划、建筑、评估等多专业融合创新。优化改建、装修施工许可审批流程，加快城市更新项目开工。引导低效商办楼宇和商办设施更新，支持低效商办楼宇保持主体不变、产证性质不变、主体结构不变的情况下，在一定时期内功能兼容转换，加快形成政府引导、市场运作、公众参与的更新模式，加大政策法规支持，深化商办楼宇更新“一口受理”，推进存量商办楼宇更新提升“线下一口咨询，线上一口受理”的服务机制。

3.护航重大工程落地投产。适当扩大水票政策覆盖范围，研究水票续借及分期归还机制，落实重大工程环评审批“绿色通道”机制及林地要素保障。提高审批服务能级，主动跨前服务建设单位，推动重大工程高效落地。

4.拓展“高效办成一件事”集成服务。深化水电气网联合报装“一件事”，推动各服务单位通过服务单获取项目关联信息，为建设单位提供全程服务，强化报装服务系统与审批管理系统互联互通。完善建设项目开工“一件事”，将新增事项“建设工程垃圾处理方案备案”纳入联办流程，优化系统交互设计和审批流程节点。常态化推进建设项目联合验收“一件事”，落实《上海市建筑工程综合竣工验收管理办法》规定，进一步规范办事流程，提升企业感受度。

二、激发竞争活力，促进建筑市场健康有序发展

1.促进行业转型发展。提升我市建筑业、工程技术与设计服务业企业核心竞争力、释放增长潜能，加强行业经济运行分析和监测预警，构建高质量行业监测数据库，为优化政策方针、制订改革举措、促进行业发展提供数据支撑。

2.健全完善竞争和履约机制。坚持充分竞争与有效竞争相结合，在建设工程招投标中推广应用异常低价识别和处置机制，综合提升投标报价的竞争力和合理性，防止“内卷式”竞争。加强招标和履约管理衔接，拓展招投标项目的合同网签、合同变更及合同信息公开范围。推行房建市政施工项目结算公开，广泛接受社会监督。

3.维护工程招投标领域市场公平秩序。严格落实公平竞争审查制度，在政府投资工程中预留份额专门面向中小企业招标。扩大暗标双盲评审范围，加大分散评标推进力度，推进跨省远程异地评标。大力推进工程招投标领域AI辅助评标应用，深化智慧清标分析规则与招标文件合规性检测。

4.优化建筑业生产组织模式。对标国际通行做法，深化完善建筑师负责制管理制度和工作机制，鼓励浦东新区先行先试，允许符合条件的境外建筑师经备案后担任责任建筑师，学习借鉴境外先进实践。发布上海市建筑师负责制试点项目评估相关文件，逐步完善本土化的建筑师负责制应用模式。

三、夯实服务底座，打造高效便捷的政务环境

1.深化“一个中心”建设。贯彻落实区级审批审查中心建设工作指引，加强机构设置，明确职责定位，提升各区审批审查中心统筹协调能力。规范场所设置和人员、事项入驻，健全融合线上线下咨询服务体系。持续强化营商服务专员队伍建设，常态化开展培训教育，提升对企业的服务能力和业务水平。

2.完善数字化政务服务。推动AI赋能咨询服务，依托大语言模型能力归集最新政策文件、行业标准规范，提升线上智能客服的政策咨询质效。完善工程建设项目审批管理系统，设立针对房屋建筑工程的单位工程库，通过建立关联机制，进一步完善应用场景。加快智慧工地建设，科技赋能危大工程、人员行为等关键监管环节，实现智能预警与分级监管，提升建设工程质量安全保障能力。推动BIM（建筑信息模型）技术应用，升级BIM智能辅助审图系统，将BIM方案模型纳入招投标评标体系，开发BIM辅助智能竣工验收系统。

3.鼓励各区先行先试。鼓励各区在高效办成一件事、商务楼宇更新提升、区级审批审查中心建设等方面，结合各自特点优化创新，形成更多可复制可推广经验。

四、加强工作保障，推动改革举措见行见效

强化改革举措跟踪问效，通过常态化走访、专题座谈、政企沙龙及问卷调查等方式，广泛听取意见建议，及时掌握企业经营发展中的难点堵点。建立改革成效评估机制，结合工作实际和企业反映情况，定期对已出台改革举措进行评估分析，适时予以优化调整，确保政策精准有效。开展常态化政策宣贯培训，紧密围绕最新政策导向，深入调研经营主体实际需求，针对不同群体开展政策解读和专题辅导，切实提升政策知晓度与执行效能，打通政策落地“最后一公里”。
