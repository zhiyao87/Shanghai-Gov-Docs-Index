# 上海市住房和城乡建设管理委员会关于进一步加强本市既有多层住宅加装电梯工程质量安全管理的通知

沪建质安〔2023〕579号
各有关单位：
既有多层住宅加装电梯工程（以下简称“加装电梯工程”）是改善市民生活、方便老人出行的重要民生工程。为进一步落实加装电梯工程参建各方责任，规范建设行为，强化施工过程的质量安全管控，依据《关于进一步做好本市既有多层住宅加装电梯工作的若干意见》（沪建房管联〔2019〕749号），现通知如下：
一、一般规定
（一）工程建设参与各方应当严格遵守法律法规、工程建设规范标准和相关文件的规定以及合同约定，对建设工程承担相应的质量安全责任。
（二）建设（代建）、勘察、设计、施工、监理单位项目负责人依法承担质量终身责任，签署工程质量终身责任承诺书（样表见附件1—5）。施工单位项目经理、监理单位监理工程师必须到岗履职并实行考勤管理。
（三）项目开工报送、告知书接收确认未完成前，一律不得开工。禁止开工报送范围外的任何施工行为。
（四）施工现场应提供经房屋安全性专家论证通过的设计文件。工程建设参与各方应当将涉及工程质量安全、技术、市场行为等资料存放于现场备查。
（五）工程建设参与各方应当对提交监管单位的材料的真实性、有效性负责。对涉及通过联审平台进行填报的内容，工程建设参与各方应当按照要求，及时、准确进行信息采集和上报。
（六）加梯工程实行施工和监理单位关键岗位人员实名制管理。通过“随申办”建设市场信息服务的工程实名制应用，扫个人建设码完成聘用登记和项目分配，以及加梯现场进退场登记，扫工地码完成个人考勤登记，落实参建人员到岗履责。
（七）工地现场发生质量安全事故的，应当依照规定及时报告监管单位，不得无故拖延、隐瞒不报或擅自处理。
（八）工程通过房屋管理部门组织的综合竣工验收后，方可交付使用。
二、建设（代建）单位
（一）加装电梯申请人委托代建单位的，应签订书面合同，并由代建单位承担建设单位质量安全责任。
（二）按要求进行开工信息报送，在联审平台中上传代建、勘察、设计、施工、监理工程合同以及参建各方项目人员任命书、关键岗位人员信息登记表、参建各方项目负责人工程质量承诺书、地基与基础分部工程验收记录、主体结构分部工程验收记录（样表见附件1—8）。
（三）应当委托具有相应资质的检测机构进行检测，且该检测机构不得与加梯工程相关的参建单位有隶属关系或者其他利害关系。
（四）组织参建单位编制加装电梯项目的建筑设计方案和施工图设计文件。
（五）加强人员管控，加装电梯施工过程中,对总包、监理单位关键岗位人员（关键岗位人员信息详见附件8）进行考勤。
（六）参与地基基础、主体结构等分部工程的验收，并组织加装电梯工程的竣工验收。代建单位应邀请业主代表一同参与上述节点验收。
（七）协调组织成立安全巡视小组，加强对施工作业时间施工楼道等部位的安全和消防检查，禁止堆放易燃、易爆物品，并保持通道畅通，消防设施齐全，对施工区域周边配置足量临时照明器具。
三、勘察单位
（一）严格按照国家强制性标准开展勘察工作，按要求进行原始记录，确保取样的真实性、代表性。
（二）勘察报告成果内容齐全、图表清晰、数据准确、可靠，结论建议合理，相关的签字、盖章手续齐全，勘察报告符合相关的法律、标准和合同规定要求。
（三）及时协助总包处理施工过程中涉及到的勘察问题，按要求参与地基验槽、基础验收、竣工验收等工作，按规定提交工程质量检查报告。
四、设计单位
（一）应当考虑施工安全操作和防护的需要，对涉及施工安全的重点部位和环节，以及使用建筑材料的性能等要依规定在设计文件中注明。
（二）对涉及重要部位进行专项交底并应加强现场服务。施工过程中，现场发现有与设计图纸情况差异较大，影响工程施工或存在质量安全隐患时，设计单位应到场确认，配合相关工作。
（三）涉及重大设计变更，应按照《上海市既有多层住宅加装电梯施工图设计重大变更实施办法》（沪房安监〔2022〕20号）文件要求，办理变更手续，在市安监所组织对拟变更的施工图设计方案审核通过后，方可作为施工图设计文件指导施工。
五、施工单位
（一）安全管理方面
1.建立安全生产责任制，项目经理到岗履职，落实项目经理带班制度。建立施工现场安全管理机构，配备专职安全生产管理人员，在施工作业时进行旁站监护。建立安全教育培训制度，落实作业人员安全教育和交底。
2.编制施工组织设计、各类专项施工方案（如临时用电、脚手架搭设、钢结构吊装、起重吊装作业等），并按规定审核、审批。
3.施工区域（材料堆场区域）与居民住宅、生活区应设置围挡进行划分，在显著位置设置安全警示（标识）牌，居民出入通道应保持畅通，并设置通道防护棚。
4.脚手架及围护密目网应采用阻燃材料，并合理规划人员、车辆进出通道及材料运输通道。吊装施工作业前对施工作业车辆报审，对施工作业人员进行交底，按照方案进行吊装施工。在施工作业时，专职安全生产管理人员进行旁站监护、监理实施旁站监理。
5.现场临时用电应单独设置配电箱，满足三级配电两级保护要求，确保漏电保护有效，接地可靠有效，严禁使用自制或家用拖线板。
6.电缆线路应架空或埋地敷设，绝缘无破损，施工区域上方存在外电线路穿越的，搭设脚手架、吊装施工前，必须确保外电线路已经采取隔离防护措施避开施工区域，严禁外电线路直接穿越脚手架体，并应悬挂醒目的安全警示（标识）牌。
7.特种作业人员按照规定持证上岗施工作业。
8.做好现场消防管理工作，现场动火施工作业时必须配备监护人员，配备足量的消防器材，现场易燃、易爆物品应有安全管理制度并分类进库。
9.建筑垃圾应集中堆放，平时采取覆盖等各类抑制扬尘的措施。
（二）质量管理方面
1.严格按照设计图纸要求施工；当对设计文件提出修改意见时，应当经过设计同意并提出设计变更。
2.严格现场材料管理，根据加装电梯工程的现场实际情况，对质量检测应按以下要求实施：
锚杆静压桩应按设计文件要求进行桩基承载力检测，如现场不具备条件，可按设计要求进行桩基承载力验证；
混凝土强度应以设计规定龄期的标准养护试件的抗压强度进行检验。如现场不具备留置混凝土强度试件条件的，可采用实体混凝土非破损检测代替；
对于同一厂家、同一规格、同一牌号的钢筋及同一厂家、同一品种的防水材料、防火涂料、砌体材料、植筋胶、电线的质量抽样检验，检验报告在出具后6个月内，可适用于同一代建单位、同一施工单位在同一行政区域内总包施工的加装电梯工程的验收。
窗以型式检验报告、质量保证书作为进场验收依据。需要检测时，建设单位（或代建单位）应委托第三方检测单位进行复试检测。
3.建立材料采购、验收、检验、使用综合台账。对于混凝土、钢筋、紧固件、焊缝、防水、防火涂料等应及时进行材料复试，钢结构后置埋件、防火涂装和焊缝探伤报告等进行实体检测。
4.检测送检应使用试件唯一性标识，且配备相应的见证员、取样员，对于检测中发生的不合格情况必须及时处理或退场，并留存相应单据及手续。如监管单位在监督检测中发现不合格建材，则要求该施工单位在该项目所处行政区内对使用的同类建材均按照规范要求送检复试。
六、监理单位
（一）现场实行总监理工程师负责制的，按要求配备监理工程师，并按照要求履行监管职责。
（二）充分使用监理手段，对工程关键节点(如桩基、基坑挖填、钢筋绑扎、混凝土浇筑、钢结构吊装等)实施旁站监理并按要求进行隐蔽工程验收。组织相关单位开展地基基础及主体结构分部工程质量验收。
（三）结合工程实际情况，落实监理报告制度。发现工程存在质量和安全事故隐患的，应及时督促施工单位整改或暂停施工；对于施工单位拒不改正或不停止施工的，应及时报告建设单位（或代建单位）和监管单位；对于地基基础、主体结构等分部工程的验收及加装电梯工程的竣工验收未邀请业主代表参与的，应及时报告监管单位。
七、监督管理要求
（一）各监管单位应按照本市《既有多层住宅加装电梯技术标准》等相关技术标准、经房屋安全性专家论证通过的施工图设计文件，开展质量安全监管工作。
（二）各监管单位可在项目完成开工信息报送后至施工现场进行首次监督检查，也可根据实际情况，进行线上核查，或纳入过程监督抽查环节合并实施。
（三）各监管单位在加装电梯工程施工过程中应开展质量安全抽查，每个项目应至少到位抽查一次。重点抽查涉及结构安全和危险性较大的施工作业内容。
（四）各监管单位在参加房屋管理部门组织的竣工验收时，应重点查看参建各方提交竣工验收报告情况、过程监督抽查中发现的问题整改情况及竣工铭牌完成情况。
（五）在日常监管过程中，如存在监管力量不足的，各监管单位可通过购买服务委托第三方专业机构协助开展加梯工程的质量安全监管，各区财政应予以保障。
（六）各监管单位应按照本通知要求加强监督。对于加装电梯工程存在违规的，应责令责任单位及时整改。对存在严重违法违规行为的企业和个人，按相关法律法规进行项目经理记分及行政处罚并记入诚信档案。
