# 上海市应急管理局关于明确安全生产资格考试考核经费项目预算支出标准的通知

局机关各处室、上海市安全生产科学研究所：

根据《上海市加强成本预算绩效管理的实施方案》（沪府办发〔2023〕16号）《上海市财政局关于做好2024年市级成本预算绩效分析工作的通知》（沪财绩〔2024〕5号）等文件精神，上海市应急管理局、上海市安全生产科学研究所对“安全生产资格考试考核经费”项目开展了成本预算绩效分析。经研究，确定“安全生产资格考试考核经费”项目中，政府采购考点的预算支出标准为51元/人次。

为进一步加强成本预算绩效分析结果的应用，现将安全生产资格考试考核经费项目政府采购考点的预算支出标准予以印发，请遵照执行。

特此通知。

上海市应急管理局

2025年4月29日
