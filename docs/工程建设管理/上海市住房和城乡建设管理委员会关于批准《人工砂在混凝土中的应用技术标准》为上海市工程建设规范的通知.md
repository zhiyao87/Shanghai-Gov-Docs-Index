# 上海市住房和城乡建设管理委员会关于批准《人工砂在混凝土中的应用技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《人工砂在混凝土中的应用技术标准》为上海市工程建设规范的通知

沪建标定〔2025〕388号

各有关单位：

由上海建工建材科技集团股份有限公司、上海市建筑科学研究院有限公司、上海石材行业协会主编的《人工砂在混凝土中的应用技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-506-2025，自2026年2月1日起实施。原《人工砂在混凝土中的应用技术规程》（DG/TJ08-506-2017）同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海建工建材科技集团股份有限公司负责解释。

特此通知。

2025年8月4日
