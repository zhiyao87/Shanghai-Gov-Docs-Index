# 关于印发《松江区水利项目建设和资金管理办法（修订）》的通知

各相关科室、基层单位：

现将《松江区水利项目建设和资金管理办法（修订）》印发给你们，请结合本单位实际，认真抓好落实。

附件：《松江区水利项目建设和资金管理办法（修订）》

上海市松江区水务局

2022年6月30日

松江区水利项目建设和资金管理办法

为进一步加强本区水利工程建设项目管理，规范建设程序，明确建设流程，提升管理水平，保证建设项目的安全、质量和工期，充分发挥投资效益，根据《中华人民共和国招投标法》、《上海市建设工程招标投标管理办法》、《上海市河道整治工程项目和资金管理办法》、《水利工程建设项目法人管理指导意见》、《松江区政府投资项目管理办法》、《本市国土空间用途管制实施细则（试行）》及《松江区小微工程管理导则》等文件精神，结合松江实际，制定本办法。

一、适用范围

本办法适用于本行政区域内全部或部分使用区级及以上财政资金投入或由区水务局审批（含行业审核）的水利项目,主要包括骨干河道整治、中小河道整治、圩区达标改造、除险加固等工程及其配套和附属工程。其他有关河湖的建设类项目(不包括河道维修养护类的疏浚工程)、雨水泵站及调蓄池可参照执行。

应急抢险救灾等水利项目按《松江区应急抢险救灾工程建设管理实施办法》执行。

二、
建设项目组织管理

以区水务局统筹领导为基本原则，明确水利项目建设管理机构与建设单位职能，确保各部门分工明确、职责清晰、相互监督、协作推进。

（一）水利项目建设管理机构的组成

1.成立水利项目建设管理领导小组：区水务局局长任组长，分管局长任副组长，成员有建管科、计财科、审批科、安法科、河长科、水资源科等部门负责人。

2.设立领导小组办公室：水利项目建设管理领导小组下设办公室（简称项目办），办公室主任由分管局长兼任，建管科具体行使项目办日常工程管理的组织、协调、监督等工作。

（二）水利项目建设管理办公室主要任务与分工

1.项目办负责水利项目的全过程管理，具体包括：

1.1拟定全区水利项目库及水利项目建设计划；

1.2初审街镇上报的水利项目；

1.3拟定区级水利项目库中项目的项目法人；

1.4建立水利项目前期设计咨询单位合作名单，负责合作单位的诚信管理；

1.5组织水利项目的立项内审，对项目可行性进行审核；

1.6编制区级水利项目年度预算，审核街镇水利项目年度预算；

1.7负责对水利项目施工承发包进行监管；

1.8组织对水利项目设计变更等事项进行预审；

1.9负责对水利项目施工过程中质量、安全、进度、项目验收、资金拨付、资料归档等环节进行监管。

2.项目办成员结合所属职能部门的行政管理职能进行具体分工：

2.1水利项目的建设管理。建管科统筹水利项目的建设推进、负责局下属单位作为项目法人的区级项目的“三重一大”制度执行的衔接和相关项目重要事项的上会汇报。

2.2水利项目的资金管理。计财科负责水利项目年度预算（市、区两级）的编制、调整和资金执行的统计和监督。

2.3水利项目涉河行政审批。行政审批科根据职责权限，负责受理建设单位申报的各类区管涉河行政许可手续办理；并协助各建设单位办理市管相关涉河行政许可。

2.4水利项目的安全监督。安法科负责在建水利工程项目安全生产及安全度汛的监督指导工作。

2.5水利项目工程设施移交。河长科负责水利项目验收后的设施移交至运行管理单位的组织、协调工作。

（三）各街镇（开发区）职责与任务

各街镇（开发区）按照项目分工和属地化管理的要求，负责本辖区内水利项目的计划上报和建设管理工作，规范项目法人组建，加强对项目法人的监督和管理。

各街镇（开发区）应支持本辖区内国家、市级、区级水利项目的建设，努力创造良好的建设环境，按要求做好市、区管河道整治等水利项目的前期腾（征）地、动拆迁等工作。

（四）建设单位职责与任务

建设单位即项目法人，项目法人单位的组建应按照《水利工程建设项目法人管理指导意见》的要求。不能按照要求组建项目法人的，应通过委托代建等方式，引入社会专业技术力量，协助项目法人履行相应管理职责。

项目法人对项目建设负总责，实行全过程管理，全面负责项目前期、项目推进、质量安全、投资控制、项目法人验收、档案资料、移交管理等工作。

三、水利项目建设流程

项目办围绕“事前、事中、事后”做好服务、监管、管理，抓好计划预算阶段、立项审批阶段、施工承发包阶段、施工管理阶段和验收移交阶段五个关键环节的规范运作。

（一）计划、预算阶段

1.项目库建立。区水务局建立由区级水利项目与街镇水利项目组成的水利项目储备库，实行动态管理，每年更新一次，由局分管领导确认，经局党组讨论确定，并下达建设计划。其中区级水利项目由项目办负责并拟定，街镇项目库由街镇上报，项目办审定。水利项目应依据松江区“三区三线”划定成果、城市总体规划、河道蓝线专项规划和本区域经济发展规划，结合水利防汛排涝设施实际情况，科学合理确定。

2.项目法人的确定。区级项目由项目办拟定项目法人，经过局党组讨论后确定；街镇项目由街镇上报项目法人主体及相关资质，由项目办审核认定。

3.水利项目前期设计咨询单位合作名单管理。为进一步提升水利建设项目的质量，区水务局对水利项目前期设计咨询单位实行预选合作名单管理，由项目办形成前期设计咨询单位合作名单，经局党组讨论确定。该名单两年更新一次，项目法人原则上需在预选名单内选取前期设计咨询单位。

4.年度预算的确定。项目法人根据年度建设计划，制定预算上报项目办，项目办预审后提请局党组讨论通过。其中，需纳入本区及以上财政资金保障的项目，由区水务局和财政局按照部门预算编报的要求，向市水务局和财政局联合上报下一年度水利项目建设计划，经市水务局和财政局审核后纳入财政年度预算。

5.招标代理公司的确定。区级项目由项目法人按照区水务局《关于非政府采购（零星采购）项目有关事项的通知》要求确定代理单位。街镇项目根据街镇相关制度实施。

（二）立项审批阶段

1.水利项目应当分阶段编制河道整治工程可行性研究报告和初步设计报告。但下列工程，经市水务局同意，工程可行性研究报告和初步设计报告可以一阶段编制上报：

（1）河道整治项目工程费用5000万元以下（含5000万元）的工程，并且设计费用小于100万元的工程；

（2）应急抢险工程。

工程可行性研究报告和初步设计报告一阶段编制上报的，其工程可行性研究报告应当编制到初步设计报告深度。

2.纳入市水利专项的项目，工程可行性研究报告和初步设计报告由区水务局组织预审后，报市水务局审批。纳入区级及以下财政资金保障的新（改、扩）建项目，由区水务局进行行业审核、区发改委审批。其他由市、区两级资金保障，明确由区（或市）发改委立项的，由区水务局（或报市水务局）进行行业审核。

城维类水利项目，按照《松江区区级城市维护项目管理办法》的规定执行。

3.年度水利投资计划下达，水利项目工程可行性研究报告批准后，项目法人即可开展前期准备工作，主要包括开展腾（征）地、动拆迁、勘察设计招投标、土地手续办理等工作。

（三）施工承发包阶段

1、承发包要求。水利项目招标工作按照《上海市建设工程招标投标管理办法》（沪府令第50号）执行。承发包要求如下：

（1）施工单项合同估算价在400万元（含400万元）以上；勘察、设计、监理等服务的采购，单项合同估算价在100万元（含100万元）以上需要按照《必须招标的工程项目规定》公开招投标；

（2）施工单项合同估算价在400万元以下的按照《松江区小微工程管理导则》执行；

（3）勘察、设计、监理等服务的采购，单项合同估算价小于100万元的按照零星采购项目采购方式进行采购。

其中局下属单位作为项目法人的区级项目进入招标、采购前应由项目法人向项目办上报采购方案并填报《松江区区级水利项目实施政府采购和公开招标审核表》，工程费用5000万元以下（含5000万元）项目由分管局长审批；5000万元以上项目由局长审批。涉及单位集体决策采用资格预审、信用合格分设置等，需通过局党组“三重一大”。

2.水利工程开工前，建设单位应到松江区工程建设项目审批审查中心及时办理相关行政许可手续，并到区水务建设工程安全质量监督站办理报监、开工备案等手续。

（四）施工管理阶段

1.水利工程具备开工条件后，主体工程方可开工建设。开工条件包括：初步设计报告已经批准；施工、监理招投标已完成并分别订立了合同；质量安全监督报监及开工备案手续已完成；水行政许可手续已办理；土地手续已经办理完成;施工准备等工作满足主体工程开工需要。

2.项目法人应当按照批准的设计文件组织工程实施，不得擅自变更建设地点、规模、标准和建设内容。工程建设内容调整或者工程设计变更，纳入市级财政资金保障的项目按照水利部《水利工程设计变更管理暂行办法》文件执行；纳入区级及以下财政资金保障的项目按照松江区关于印发《关于严格控制工程结算造价“三超”的操作口径》的通知（松发改字〔2019〕86号）文件执行。重大设计变更经报批同意后方可组织实施。

3.项目法人应严格控制工程投资，不得擅自扩大签证范围或者对工程范围之外的工程内容进行签证，确需签证的，根据相关规定执行。对于勘察、设计、施工一体化的项目，原则上不得进行签证。

4.项目法人单位应加强对参建单位工人工资的支付管理。建筑工人工资支付按照《上海市水务建设工程建筑工人工资支付管理暂行办法》执行,应当按月足额支付，并实行分账管理,通过银行代发制度，按照“用工前办理银行卡登记，用工中过程监管，用工后及时支付”原则实施。

5.项目建设周期（指安排项目预算当年开始至项目决算批复止），河道类项目原则上不超过36个月，农村圩区达标改造项目原则上不超过24个月。纳入市级财政资金保障的项目确需延期的，项目法人应提前3个月上报延期请示，并经市水务局和财政局同意。

（五）验收移交阶段

1.水利工程完成后，项目竣工验收工作按照《上海市水利工程建设项目验收管理实施细则》执行。水利工程未经验收或者验收不合格的，不得交付使用或者进行后续工程施工。验收分为法人验收和政府验收，严格按照《水利水电工程验收规程（SL223-2008）》和相关规定执行。

法人验收主要包括：分部工程验收、单位工程验收和合同工程完工验收。法人验收是政府验收的基础，由项目法人组织验收。

政府验收主要包括：阶段验收、专项验收和竣工验收。水闸、桥梁（涵）等工程拆坝通水前，须进行工程阶段验收。工程具备政府验收条件时，项目法人应向区水务局提出申请验收报告。竣工验收应在工程建设项目全部完成，并在通过完工验收后1年内完成。

2.水利项目实行财务决算制度。其中纳入市级财政资金保障的项目由区水务局会同区财政局按照审计结果向市水务局和市财政局上报工程财务决算，市水务局会同市财政局对上报的工程财务决算进行审核并批复。纳入区级及以下财政资金保障的项目由各建设单位所在属地政府按照审计结果向区水务局和区财政局上报工程财务决算，区水务局和区财政局对上报的工程财务决算进行审核并批复。

3.项目法人应当按照水利工程建设项目档案验收管理的要求，做好工程项目档案的管理工作。在工程竣工验收前，应当进行工程项目档案专项验收，通过后办理工程项目档案资料的归档手续。

4.水利工程竣工验收通过、绿化工程完工验收通过后满1年，项目法人应及时与运行管理单位办理移交手续，项目法人应当及时向运行管理单位办理工程及档案资料移交工作，管理单位应当提前落实管养措施和经费，保障水利项目发挥效益。

5.水利项目的勘察、设计、监理（施工、财务）等咨询服务单位出现工作失职情况的，按《松江区关于加强财政性基本建设项目财务监理服务的指导意见》（松财〔2009〕第33号）等执行。

四、其他

1.水利设施应急抢险修复等工作按照市、区相关文件执行。

2.中小河道轮疏工作按照市、区相关文件执行。

3.本办法自发布之日起施行，原《松江区水利工程建设项目管理办法（试行）》（沪松水[2017]185号）同时废止。在执行本办法时，市、区相关部门出台新的政策规定的，从其规定。
