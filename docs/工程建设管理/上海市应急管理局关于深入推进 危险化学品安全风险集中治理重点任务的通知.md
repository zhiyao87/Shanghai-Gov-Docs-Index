# 上海市应急管理局关于深入推进 危险化学品安全风险集中治理重点任务的通知

各区应急管理局：

为贯彻落实《上海市安全生产委员会关于印发<上海市危险化学品安全风险集中治理实施方案>的通知》（沪安委会〔2022〕1号）和《上海市安全生产委员会办公室关于印发<上海市深化大型油气储存基地安全风险管控实施方案>等6个工作方案的通知》（沪安委办〔2022〕9号）要求，现就深入开展危险化学品安全风险集中治理各项工作通知如下。

一、加强组织领导和工作统筹

各区应急管理局要认真贯彻习近平总书记关于安全生产重要指示批示精神，落实市委、市政府工作部署，切实提高防范化解危险化学品重大安全风险的政治判断力、政治领悟力、政治执行力，确保集中治理工作已纳入区级党委政府职责清单和年度工作任务清单。

3月以来，受疫情影响，本市危险化学品安全风险集中治理工作有所减缓，进度有所落后。当前大上海保卫战取得重大阶段性成果，相关单位基本复工复产。各区应急管理局要坚持统筹推进，将集中治理各项工作和复工复产各项措施紧密结合、融合开展，要聚焦集中治理各项重点任务的年度目标、推进情况、主要问题（见附件1），进一步优化细化工作方案，确保各项工作有效组织、有序推进。要将落实危险化学品安全风险集中治理工作和安全生产“十五条硬措施”有机结合，切实解决一批安全生产顽症痼疾，提升危险化学品安全保障能力。

二、持续健全工作推进机制

各区应急管理局要不断优化合作研判、联合会商、联合执法等工作机制，研究解决集中治理重点工作推进中的难点问题。在危险货物（危险化学品）运输、危险废物（危险化学品）、油气长输管道安全风险管控等涉及多部门监管职能交叉的领域，要在已有联合监管机制的基础上，结合《上海市交通委员会安全生产委员会办公室关于印发<上海交通行业危险货物运输安全风险集中治理工作任务清单>的通知》（沪交安委办〔2022〕28号）、《上海市生态环境局 上海市应急管理局关于印发<上海市废弃危险化学品等危险废物风险集中治理工作方案>的通知》（沪环土〔2022〕77号）、《上海市发展和改革委员会关于转发<国家能源局综合司关于印发油气长输管道占压专项排查清理工作方案的通知>等的通知》（沪发改能源〔2022〕75号）要求，建立健全与行业主管部门的联动工作机制，相互通报工作进度，及时共享工作信息，配合对发现的重大隐患联合督办，对发现的突出问题依法严格处罚，对违法违规单位实施联合惩戒、综合施策，保障集中治理重点专项稳步推进。

三、切实完成各项重点任务的阶段性目标

各区应急管理局要重点关注化工园区监管机构和人员配备、化工园区安全整治提升、油气长输管道专项治理、重大危险源专项督导检查和大型油气储存基地、高危细分领域、老旧装置安全风险防控、“工业互联网+危化安全生产”试点和危险化学品企业双重预防机制数字化建设、化学品登记系统和风险监测预警系统升级改造、危险化学品企业工伤预防能力提升培训工程等重点任务的推进情况，以问题为导向，定期会商，靶向施策，深入整治，逐一攻坚，确保按照相关任务的时间节点完成各个阶段性目标。

四、深化专家指导服务工作机制

结合前期本市开展的危险化学品重点县、硝化、光气、环氧乙烷企业专家指导服务，由市安委会危险化学品安全专业委员会牵头，继续深化完善工作机制，推动危险化学品安全风险集中治理各项重点任务落细落实。各区应急管理部门、临港新片区管委会、上海化工区管委会要参照市级工作模式组建专家团队，持续优化专家管理、调配、培训，制订完善检查标准，严格隐患整改验收，强化执法处罚衔接，适时组织“回头看”，不断做强专家指导服务。加快开展化工园区和“重点县”指导帮扶，大型油气储存基地、重大危险源督导检查、老旧装置、高危细分领域和化工医药企业安全风险防控以及双重预防机制数字化、风险监测预警系统改造升级等信息化建设的专项指导服务，寓指导服务于各类专项检查之中，建立问题隐患和整改措施清单，推动全面落实“一企一策” “一园一策”“一库一策”，不断提升集中治理成效。

五、加强重点任务督导考核

各区应急管理局要建立完善危险化学品安全风险集中治理工作专班调度机制，加强对集中治理重点任务的跟踪调度，掌握总体进度和典型做法。要强化督导问效，对工作责任不落实、进度缓慢、整改不力的单位开展专门督导，严格压实园区和企业主体责任。要及时对照应急管理部印发的《危险化学品安全风险集中治理工作进展情况评估规则》（附件2）查找集中治理各个重点专项推进过程中的短板漏项，不断优化工作措施，并于每月20日下午17:00前将集中治理的主要措施和工作推进情况报送市应急局。市应急局将定期调度各区工作进展情况，对典型问题进行通报。
