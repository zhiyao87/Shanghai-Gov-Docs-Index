# 上海市交通委员会关于下达2023年度标准规范项目计划的通知

上海市交通委员会
关于下达2023年度标准规范项目计划的通知

各有关单位：
为进一步加强本市交通运输行业标准化工作，提升标准化发展水平，促进交通运输转型升级和安全、高效、协调、创新发展，经审议通过，现正式下发2023年度标准规范项目计划。请各单位认真组织做好修编工作，确保项目按质如期完成。
特此通知。
