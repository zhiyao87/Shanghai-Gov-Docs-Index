# 关于印发《浦东新区专业服务业提升行动方案》的通知

新区各委、办、局，各管理局(管委会)，各街道办事处、镇政府，各相关单位：

现将《浦东新区专业服务业提升行动方案》印发给你们，请认真贯彻执行。

上海市浦东新区发展和改革委员会

2024年12月31日

浦东新区专业服务业提升行动方案

为贯彻落实《关于进一步优化发展环境促进上海专业服务业高质量发展的指导意见》，加快专业服务业高质量发展，促进浦东引领区建设，特制定本行动方案。

一、主要目标

结合区域特点，浦东新区重点推进法律服务、会计审计服务、咨询调查服务、广告服务、人力资源服务、检验检测认证服务、知识产权服务、物流及供应链服务、绿色低碳服务、信用服务、设计服务和金融科技服务等领域的专业服务业发展。围绕“品牌化、数字化、国际化、绿色化”的发展方向，加快集聚培育高能级专业服务机构，塑造浦东“全球专业服务商”品牌，以专业服务业提升赋能新质生产力发展。到2025年，浦东新区专业服务业增加值占全区GDP比重达5%左右，集聚一批具有较强国际影响力和品牌效应的高能级机构，涌现一批品牌度较高、竞争力较强的本土知名专业服务企业。到2035年，浦东新区专业服务业增加值占全区GDP比重超过8%，年均增速保持5%左右，集聚和培育20家具有全球影响力和品牌美誉度的专业服务机构，吸引5-10家专业服务领域国际组织落户。

二、实施“品牌化”提升行动

1. 集聚培育全球一流的专业服务机构。全面实施拓展“全球专业服务商引领计划”(GIS)，鼓励各片区打造高能级、跨行业的交流平台。开展专业服务业战略合作伙伴计划，集聚培育一批具有影响力、带动力、辐射力、品牌力和创新力的专业服务机构。支持高能级专业服务机构规模化发展，通过并购重组、混业发展等方式，实现规模跃升。试点推进法律服务业品牌建设。推动具有国际影响力的商会、行业协会、产业联盟、国际性专业标准组织等国际经济组织在浦东设立总部或分支机构。

2. 打造特色鲜明的空间品牌。推动专业服务机构向陆家嘴、世博前滩等沿江地区集聚发展，鼓励各片区打造特色专业服务业品牌。支持陆家嘴金融城加快推动专业服务机构集群化、国际化发展，着力建设陆家嘴国际会计中心，打造浦东专业服务核心功能承载区。支持世博前滩地区加快建设国际法律服务园，依托国际商会仲裁院、新加坡国际仲裁中心及大韩商事仲裁院等平台，加快建设国际仲裁高地。充分发挥陆家嘴金融科技产业园、张江金融数据港功能，打造“陆家嘴金融城+张江科学城”金融科技产业融合示范区域。支持张江科学城依托浦东知识产权保护中心等平台，打造以知识产权为特色的专业服务核心区。支持金桥片区着力推动专业服务与制造业融合发展，加快打造检验检测认证服务示范区。支持外高桥片区打造物流及供应链服务集聚区，着力提升跨境服务能力，助力跨境电商发展。

3. 加强专业服务品牌推广。鼓励专业服务机构参与“上海市品牌引领标杆企业培育”，积极申报“上海品牌”认证。鼓励专业服务机构参加国内外权威竞赛。依托“丝路电商”等高端平台，加强与国际国内主流媒体对接，做好专业服务品牌宣传推介。持续做强“陆家嘴全球专业服务商大会”“浦东国际人才港论坛”等专业服务业品牌活动，鼓励举办具有国际影响力的行业峰会、论坛等，持续提高服务品牌认可度、美誉度。依托“上海国际大学生广告节”等活动品牌，拓展专业服务机构全球化网络。

4. 支持参与各类标准的研制应用。支持高能级专业服务机构、行业组织牵头或参与国际标准、国家标准、行业标准和地方标准的制修订。鼓励推出团体标准、企业标准的外文版文本，提高专业服务业能级。

三、实施“数字化”赋能行动

5. 加快数字技术赋能应用。支持专业服务机构抢抓数字化转型发展机遇，加强人工智能、大数据、云计算、区块链、5G等新技术应用，提升专业服务能力和服务效率。鼓励有能力、有意愿的专业服务机构，通过多种方式，将软件开发、系统集成、技术服务等业务分离成独立的数字化服务主体，赋能其他企业发展。培育发展专业服务业领域数商，加快人力资源、法律服务等行业数据资产化试点，支持符合条件的数据资产在数据交易所挂牌交易。配合市级相关部门做好专业服务行业基础数据库或资料信息平台搭建工作，行业主管部门联合行业协会及时采集信息，统一数据存储方式和数据标准，根据需要推动数据依法依规共享共用。

6. 探索数智化新业态新模式。鼓励法律科技企业、法律服务机构和高校、研究机构等合作共建法律科技产品孵化实验室，联合开发法律服务人工智能大模型。引导会计审计、咨询调查服务机构加快探索AI+法律、AI+会计等新业务模式。加快数字广告业发展，推动AIGC在数字广告领域应用，提升数字广告创意水平，增强广告服务核心竞争力。鼓励人力资源服务机构发展个性化定制服务、开发人力资源软件等新产品，开展网络招聘、协同办公、在线培训和灵活用工服务等业务模式创新。引导检验检测认证服务机构深化机器视觉、人工智能等技术应用，开发检验检测认证领域的人工智能大模型。鼓励金融科技企业加快金融大模型开发，深化金融服务智慧再造，开展精准营销、智能投研、智能投顾和智能风控等创新。鼓励设计服务机构全面推进智能化转型，加快探索AI+集成电路设计、AI+汽车设计、AI+建筑设计等新业务模式，引导建筑设计服务机构全面推进建筑信息模型(BIM)技术应用，优化设计流程，提高设计效率。

四、实施“国际化”发展行动

7. 建立与国际接轨的专业服务制度型开放体系。对标CPTPP、DEPA、RCEP等国际高标准经贸规则，推动专业服务业在行业准入、资质要求等方面实行更大力度开放，探索推进职业资格、服务标准、认证认可等领域规则对接。支持推动中外律师事务所联营办公室试点工作，鼓励香港、澳门律师事务所与浦东律师事务所成立合伙型律师事务所。推动涉外商事立法，健全涉外商事纠纷解决机制，探索创新海事仲裁模式。探索建立律师事务所特别合伙人制度，依法探索允许符合条件的注册会计师、税务师、注册造价工程师、专利代理人、人力资源管理、信息技术等专业人员成为律师事务所的合伙人。

8. 支持专业服务机构“走出去”。鼓励本土法律、会计审计、咨询调查、广告、人力资源、知识产权等专业服务机构“走出去”发展，通过国际并购、加盟合作、联合经营等方式，加强国际网络布局。积极为专业服务机构“走出去”提供项目洽谈、产业对接等媒介服务，助推专业服务企业扩大海外业务。探索优化自由贸易账户功能，鼓励金融机构为符合条件的专业服务机构提供跨境金融服务。

9. 护航企业“走出去”。组建浦东新区“一带一路专业服务团”，搭建交流对接平台，推动各方达成出海服务战略合作。鼓励专业服务机构紧贴走出去企业服务需求，提升在海外知识产权维权、投资地法律支持、国际化战略布局、广告营销推广等事项上的国际化服务能力。配合市级相关部门编制“走出去”重点目的地国家专业服务机构指南，动态更新各类海外专业服务机构信息，积极布局海外法律服务分支机构、知识产权服务工作站，拓展海外专业服务网络。

五、实施“绿色化”转型行动

10. 推动专业服务业绿色化发展。加快专业服务重点领域绿色转型。发展绿色物流及供应链服务，大力推广节能和清洁能源运输工具与物流装备，加快推动快递包装绿色化、减量化、标准化和循环化，支持企业建设节能环保型、智慧化、共享型的现代仓储设施。推动物流及供应链服务与制造业融合发展，为制造企业量身定做供应链管理库存、线边物流、供应链一体化服务等物流解决方案。引导和支持跨境物流企业等高质量推进海外仓、海外物流中心建设。

11. 培育发展绿色低碳服务。积极培育绿色低碳服务机构，引进培育一批绿色低碳专业服务机构，鼓励开展碳足迹核算、评价、认证、管理、咨询等业务。做强“浦东新区绿色低碳产业发展联盟”，为企业提供绿色低碳一站式服务。鼓励各类专业服务机构拓展绿色低碳、环境社会责任和公司治理(ESG)等业务，着力提升ESG国际服务能力。

六、实施营商环境优化行动

12. 构建精准高效的信用管理体系。鼓励专业服务细分领域加快推动行业诚信体系建设。鼓励各行业协会建立健全行业信用承诺制度。开展专业服务重点领域信用分级分类评价，实行以信用为基础的新型监管方式。支持拓展信用应用场景，深化信用评价运用于考核评优、项目申报等事项。完善公共信用信息修复制度，探索信用修复结论共享互认。全面推动专用信用报告代替有无违法记录证明。

13. 优化政府监管与服务效能提升。有效整合多方优质资源，打造政府、专业服务机构、企业充分联动的综合服务体系，提供高效便捷的一站式服务。鼓励专业服务机构及其业务伙伴参与浦东新区相关政策和立法制定的咨询、论证、评审等工作。

14. 有效发挥协会联盟作用。鼓励浦东新区各专业服务领域成立行业协会、商会、联盟等行业自治性组织。发挥各行业自治组织作用，推动行业自律，引导本行业的经营者依法竞争、合规经营，鼓励专业服务机构开展执业质量自查，提高行业专业性和规范性。

七、实施服务保障强化行动

15. 强化组织实施。建立浦东新区专业服务业发展工作专班，区发改委加强统筹谋划和组织协调，各行业主管部门、各管理局明确本领域、本区域的重点任务，积极探索，推进各项任务措施落地见效。

16. 加大政策支持。加大对专业服务业发展支持力度，设立浦东新区促进专业服务业发展专项资金，配合市级相关部门做好服务业发展引导资金等专项资金发放工作。试点推出浦东新区专业服务券。鼓励国有企业采购专业服务，支持国有企业扩大发展版图，延展专业服务业务链条。鼓励专业服务机构申报技术先进型企业。

17. 优化人才服务。研究制定专业服务人才发展政策，为符合条件的专业服务业高端紧缺人才和特色人才，在人才落户、人才公寓入住保障等方面提供便利，对符合条件的外籍专业服务业人才提供浦东永久居留推荐“直通车”、长期工作许可及居留许可等出入境和停居留等便利化服务。支持一批优质专业服务机构加入“浦东新区全球引才伙伴计划(GTP)”。

18. 完善统计监测。根据上海市专业服务业统计范围和分类标准，结合浦东新区专业服务业发展实际，加快完善新区专业服务业统计分类标准，建立专业服务业常态化统计监测机制，全面反映新区专业服务业发展态势。加强大数据在专业服务业统计中的运用，推动部门之间、部门与自贸试验区各片区管理局之间的信息共享。完善统计信息发布机制，鼓励社会研究机构编制浦东新区专业服务业发展报告和发展指数，为新区专业服务业高质量发展贡献智慧。
