# 关于印发《关于开展本市建设工程档案“单套制”管理试点工作方案》的通知

各区规划资源局、各城建档案机构、各有关单位:

现将《关于开展本市建设工程档案“单套制”管理试点工作方案》印发给你们，请按照执行。

上海市规划和自然资源局

2026年8月28日

关于开展本市建设工程档案“单套制”管理试点工作方案

为加快本市城建档案工作数字化转型，服务本市“量子城市”高质量建设，坚持数字驱动、改革创新，探索建立全流程电子化档案管理新模式，提升建设工程档案管理效能与服务水平，制定本试点工作方案。

一、范围与定义

（一）定义

建设工程电子档案“单套制”管理，是指建设工程档案自形成起即以原生电子形式进行归档、移交、接收、保存和提供利用，除法律法规明确规定须保留纸质载体或涉及国家秘密等特殊情形外，原则上不再同步制作、移交和保存对应纸质档案的新型管理模式。

（二）适用范围

本市行政区域内的房屋建筑工程、市政基础设施工程。涉密工程、抢险救灾工程暂不纳入本次试点范围。优先选择管理基础扎实、数字化条件成熟、保障能力完备的建设单位，以及具有一定规模、代表性较强的项目开展试点，试点周期为三年。

（三）申报流程

试点实行自愿申报、自主参与、服务指导、动态管理原则。有意愿参与试点的建设单位可直接向市、区城建档案机构申请，经沟通协商后实施。

二、工作原则

（一）依法合规，安全可控

严格遵守《中华人民共和国档案法》《上海市档案条例》《上海市城市建设档案管理办法》《上海市城市建设电子档案管理规定》等法律法规及标准规范，建立覆盖电子档案全生命周期的安全管理体系，确保电子档案符合真实性、完整性、可用性、安全性的“四性”检测要求，电子档案具备完整法律凭证效力。

（二）统筹协同，标准引领

强化市区联动与部门协同，形成工作合力。坚持标准先行，以统一规范的标准体系为支撑，推动业务流程再造与系统互联互通，实现电子文件与电子档案的规范管理、有效利用。

（三）便捷高效，务求实效

坚持以服务项目建设、便利建设单位归档为导向，优化管理流程、精简操作环节，切实减轻企业负担。聚焦破解传统档案管理模式中的难点堵点问题，全面提升管理效率与服务体验。

三、主要内容

（一）制度建设

试点建设单位应将建设工程档案“单套制”管理要求，全面嵌入项目管理全生命周期。建立健全涵盖电子文件生成、流转办理、归档管理、移交接收等全链条的内部管理制度、操作规范与质量控制体系，明确各环节责任部门、岗位及人员职责，确保档案管理要求与项目管理流程同步设计、同步部署、同步实施、同步检查、同步验收，实现业务办理与档案管理全流程一体化深度融合。建设单位应对建设工程档案的真实性、准确性和完整性负责。

（二）系统建设

试点建设单位作为建设工程电子档案管理的责任主体，应重点建设或升级改造与项目业务流程深度融合、满足电子文件“单套制”归档及长期保存需求的建设工程档案管理信息系统。该系统应确保在业务办理全流程中，同步生成符合国家和本市规范标准要求的电子文件（包含完整元数据、电子签名、时间戳、格式固化信息等关键要素），并具备与城建档案信息管理系统安全、合规、稳定、顺畅对接的能力，实现电子文件从形成、流转、办理到归档的一体化闭环管理。

（三）指导服务

市城建档案馆牵头制定本市建设工程全文电子文件归档相关标准体系；市、区城建档案机构应为试点建设单位提供从项目前期到竣工验收的全过程业务指导、技术咨询与系统对接支撑，定期开展政策解读与实操培训，协助建设单位及时解决试点过程中的各类问题，有序推进“单套制”试点工作。

（四）档案移交

建设单位应当在试点项目竣工验收后，依据国家和本市标准规范，系统整理并形成完整的建设工程电子档案，按规定向市、区城建档案机构移交。城建电子档案移交接收应当通过符合安全管理要求的网络和信息系统进行；不具备在线移交条件的，应当配备符合安全管理要求的存储介质进行离线移交。城建档案机构应依据相关标准对移交的电子档案真实性、完整性、可用性、安全性等进行检测，检测合格后予以接收。电子档案与其他形式的档案具有同等效力，可以以电子形式作为凭证使用。

（五）安全管理

试点建设单位应当建立健全电子档案安全管理制度，明确管理责任部门和人员，定期开展安全风险评估。试点项目电子档案的全过程管理，应当符合国家网络安全、数据安全、个人信息保护、保密管理、密码管理等法律法规规定，采取有效技术和管理措施，防范信息篡改、丢失、泄露、损毁等风险，筑牢电子档案安全防线。

（六）评估总结

市规划资源部门应当建立试点工作动态跟踪与定期评估机制。试点周期完成后，全面梳理试点成效、剖析存在问题、提炼实践经验。重点围绕建设工程电子档案法律效力保障、全流程管理规范、系统互联互通、安全保存利用等关键环节，研究制定一套符合国家要求、契合上海实际、可复制可推广的建设工程档案“单套制”管理制度和操作规程，为全市完善顶层设计、全面推广试点成果提供坚实支撑。

四、工作机制

（一）强化统筹联动

市规划资源部门牵头试点工作，负责总体部署、政策指导与监督管理。统筹协调相关职能部门结合各自管理职责，配合做好电子档案的认可机制，形成从审批、建设到验收的全流程闭环管理，确保单套制管理覆盖工程建设全链条。

区规划资源部门落实属地推进职责，推动辖区试点落地实施。建立市、区两级联动工作机制，定期会商研判难点问题，实行清单化、闭环式推进，确保上下协同、落地见效。

（二）明确各方职责

市城建档案馆：负责全市试点工作的顶层设计、标准规范制定、业务培训、技术指导，承担市管试点项目电子档案的接收、保管与利用工作。

区城建档案机构：负责本区域内试点项目受理的具体执行、业务指导与过程监管，承担区管试点项目电子档案的接收、保管与利用工作。

试点项目建设单位：作为实施主体与责任主体，健全内部管理制度，完善系统及配套设施建设，保障电子文件与电子档案的规范形成、有效管理和完整移交。建设单位应当在招标文件及合同中明确电子文件生成、移交的技术标准、时间节点及违约责任。

试点项目参建单位：勘察、设计、施工、监理等参建单位应根据工程项目建设进度，同步完成建设工程档案资料的收集、整理和归档工作，并及时向建设单位移交，建设单位应对其工作进行协调和督促。各参建单位应当按照建设单位要求及合同约定，在各自业务环节同步生成、移交符合标准的电子文件，并对所生成、移交的电子文件的真实性、完整性负责。

（三）夯实支撑保障

优化城建档案管理平台功能，健全电子档案全流程管理体系，筑牢技术安全防线；开展专项业务培训，提升从业人员专业能力；完善配套制度规程，强化试点工作支撑保障。

（四）营造支持环境

加强试点工作宣传，通过专题交流、经验简报、现场观摩等形式，推广可复制的工作模式与典型案例，营造支持改革、参与试点的良好氛围。
