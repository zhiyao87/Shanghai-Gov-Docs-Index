# 上海市住房和城乡建设管理委员会关于批准《道路与交通设施规划标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《道路与交通设施规划标准》为上海市工程建设规范的通知

沪建标定〔2021〕842号

各有关单位：

由上海市城市规划设计研究院主编的《道路与交通设施规划标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2393-2021，自2022年6月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市城市规划设计研究院负责解释。

特此通知。

2021年12月24日
