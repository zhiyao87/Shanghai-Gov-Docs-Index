# 上海市住房和城乡建设管理委员会关于批准《现场施工安全生产管理标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《现场施工安全生产管理标准》为上海市工程建设规范的通知

沪建标定〔2022〕271号

各有关单位：

由上海市建设工程安全质量监督总站、上海市建设安全协会主编的《现场施工安全生产管理标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-903-2022，自2022年11月1日起实施。原《现场施工安全生产管理规范》（DGJ08-903-2010）同时废止。

本规范由上海市住房和城乡建设管理委员会负责管理，上海市建设工程安全质量监督总站负责解释。

特此通知。

2022年6月23日
