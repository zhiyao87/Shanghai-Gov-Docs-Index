# 静安区促进民营经济高质量发展的实施方案

各相关单位：

《静安区促进民营经济高质量发展的实施方案》已经区 委、区政府主要领导同意，现印发给你们，请认真贯彻执行。

静安区发展和改革委员会

2025年7月1日

静安区促进民营经济高质量发展的实施方案

为深入贯彻落实习近平总书记在民营企业座谈会上的重要讲话精神以及上海市促进民营经济高质量发展大会精神，落实《新时代新征程促进民营经济高质量发展的若干措施》，促进静安区民营经济高质量发展，提出如下措施。

一、营造公平竞争的市场环境

（一）严格实施市场准入负面清单。落实“全国一张清单”管理要求，推进市场准入壁垒排查清理，确保清单之外无违规另设市场准入行政审批和市场准入限制性条件。（责任单位：区市场监督管理局）

（二）严格落实公平竞争审查制度。对涉及经营主体经济活动的政策措施及规范性文件，依法开展公平竞争审查。建立公平竞争审查投诉举报受理、处置机制。（责任单位：区市场监督管理局、各相关单位）

（三）确保建设工程招投标全过程公开公平公正。推动招投标监管制度化和智能化；推进评标项目智慧监管，全面推行现场分散评标与远程分散评标。进一步规范建设工程市场行为，加强投标门槛设置情况监管。（责任单位：区建管委）

（四）支持中小企业参与政府采购。严格落实政府采购促进中小企业发展政策，用好预留采购份额、价格评审优惠等政策，提高中小企业在政府采购中的中标率。（责任单位：区财政局）

二、加大民营企业投融资支持力度

（五）鼓励民营企业扩大投资。加强对民营企业参与“两重”“两新”建设的指导、服务。支持民营企业投资经济社会重点领域和产业新赛道。建立民间投资重点项目库。鼓励政府投资基金、产业扶持资金等支持民间投资项目。（责任单位：区发展改革委、各相关单位）

（六）引导支持民间投资参与重点领域建设。引导民间资本参与保障性租赁住房等领域项目建设和运营管理。支持民营企业参与绿色建设，鼓励应用区块链等技术建设绿色低碳转型场景。鼓励引导有能力的民营企业申报可信数据空间创新发展试点。（责任单位：区发展改革委、区房管局、区数据局）

（七）加大银行信贷支持力度。鼓励区内银行加大对民营企业信贷投放力度。鼓励引导区内银行创新金融产品与服务模式。发挥支持小微企业融资协调工作机制、融资信用服务平台作用，鼓励金融机构为中小企业提供“无缝续贷”“无还本续贷”服务。推动“商会批次贷”扩面增效，推动中小微企业政策性融资担保基金增量扩面，加大中小企业政策性担保贷款财政贴息贴费支持力度。（责任单位：区投资办、区财政局、区发展改革委、区工商联）

（八）助力民营企业对接多层次资本市场。完善上市服务机制，助力民营企业在科创板、创业板、主板等多层次资本市场融资。整合区内券商、专业服务机构资源，搭建合作交流平台，助力民营企业多渠道获得资本市场支持。发挥股权投资集聚区优势，推动产业链上下游对接、产业资本对接。（责任单位：区投资办、各相关单位）

（九）鼓励民营企业开展高质量并购重组。大力推进并购集聚区建设，鼓励民营企业聚焦新质生产力强链补链和传统产业转型升级开展并购重组。提升并购服务水平，为民营企业提供专业咨询、融资对接、运营保障、投后管理等一站式服务。（责任单位：区投资办、区科经委）

（十）加快“区块链+金融”创新应用。搭建供需对接平台，鼓励区块链企业围绕信贷融资、供应链金融、跨境支付、融资租赁等开发创新应用。支持龙头企业充分利用区块链技术开展供应链金融服务。支持供应链上民营中小微企业开展订单贷款等业务，鼓励民营企业开展供应链票据业务。（责任单位：区投资办、区数据局）

（十一）优化民营企业知识产权融资服务。鼓励区内银行基于商标、专利、著作等知识产权，创新推出质押贷、跨境收益贷等产品，优化为民营企业融资增信模式。鼓励区内银行建设、申报“知识产权质押贷款特色网点”。（责任单位：区投资办、区市场监管局）

（十二）完善综合性金融服务体系。推动普惠金融顾问服务进一步深入中小园区、楼宇，将个性化“服务包”送达企业。推动融资服务中心进一步下沉，实现惠企便民的“一站式”综合金融服务。依托“一网通办”静安旗舰店的“智能帮办”系统，提供“一对一”远程融资业务咨询。（责任单位：区投资办）

三、大力支持民营企业创新发展

（十三）支持民营企业提升创新策源能力。支持民营企业参与国际国内重大技术研发、行业共性技术攻关。支持民营企业参与重点实验室、新型研发机构、大企业开放创新加速器等创新平台建设。鼓励民营企业参与共建院士工作站、博士后工作站。（责任单位：区科经委、区人才局）

（十四）提升民营经济特色产业能级。高标准建设“数通链谷”国家区块链应用示范区建设、“视听静界”上海超高清视听产业集聚区、“美创静界”皮肤健康管理创新中心，建设高能级的民营经济产业集群。（责任单位：区数据局、区科经委、区商务委、市北功能区、大宁功能区）

（十五）培育创新型民营企业“雁阵”。加强领军型民营企业“头雁”示范效应，加快“专精特新”企业梯度培育，推动领军企业与专精特新企业围绕产业链协同创新，促进大中小民营企业融通发展。建设数字化转型赋能载体，提供智能制造、工业互联网等领域的专业服务支撑。（责任单位：区科经委）

（十六）构建国有民营协同发展格局。支持民营企业与医疗机构、科研院所等资源协同创新，建设公共研发服务、临床医学转化、技术创新孵化等功能性平台。推动国企民企在供应链、创新链等领域的深度协作。支持民营企业参与公共数据资源开发利用。（责任单位：区科经委、区国资委、区数据局、市北功能区、大宁功能区）

（十七）加强民营企业知识产权服务和保护。发挥知识产权扶持政策作用，鼓励企业加大知识产权开发。发挥上海市知识产权保护中心静安分中心作用，依法为重点民营企业提供专利快速预审服务，加速科技成果转化。依托静安区专利超市，创建综合性知识产权交易平台建设。加大知识产权大保护力度，持续依法打击侵权行为。推动商业秘密保护创新试点工作，强化商业秘密保护行政执法。（责任单位：区市场监管局、区法院、区检察院、区公安分局）

四、打造民营经济高质量发展高地

（十八）大力集聚民营企业总部和功能性机构。鼓励优质民营企业做大做强，引育一批民营企业总部；鼓励民营企业在静安设立研发中心、全球供应链管理中心、资金结算中心、贸易总部等功能性机构，在人才引进、跨境资金结算和数据流动等方面提供支持和服务，构建双向开放的功能高地。（责任单位：区商务委、区科经委、区人才局、区网信办）

（十九）打造民营企业出海服务高地。发挥全球服务商理事会平台优势，推出出海联盟、出海学院等，为民营企业“出海”提供综合性、集成式专业服务。加大专业服务券等政策支持力度，支持民营企业不断拓展海外业务、完善海外布局。支持民营企业在海外参展参会，提升国际影响力。（责任单位：区发展改革委、区商务委、区司法局、区人力资源社会保障局）

（二十）加强优质民营品牌培育。加强专项政策支持，推动知名民营品牌在静安集聚发展。聚焦首发经济，依托重大节庆展会活动，助力民营品牌提升市场影响力。大力发展后街经济，为民营品牌提供更多发展空间。（责任单位：区商务委）

（二十一）建设民营经济高质量发展示范区。发挥静安苏州河沿线作为近代民族工商业发祥地的优势，以上海总商会旧址为核心地标，打造“苏河湾民营经济会客厅”，构建具有影响力的政企沟通枢纽、资源对接平台和民营经济智库。加快市北高新民营企业总部集聚区建设，打造以“云数智链”为特色的民营经济集聚高地。（责任单位：苏河湾功能区、市北功能区）

五、依法保护民营企业和民营企业家合法权益

（二十二）持续清理拖欠中小企业账款。建立防范化解拖欠中小企业账款的长效机制，定期开展全面排查。强化政府采购履约验收制度建设。完善拖欠账款投诉处理和监督问责常态化机制。（责任单位：区科经委、区国资委、区财政局）

（二十三）强化守信激励和失信惩戒。依法实施守信激励和失信惩戒，及时更新“信用上海（静安）”网站信息。做好政务诚信跟踪，将政府违约失信情况纳入评价体系。优化公共信用修复“一件事”功能，探索“AI+信用修复”。（责任单位：区发展改革委）

（二十四）强化民营经济法治保障。依法保护企业家合法权益，严格区分经济纠纷与违法犯罪。依法规制牟利性职业索赔、职业举报行为，对经确认为牟利性职业索赔的投诉，可依法依规不予受理或终止调解。依法打击治理“职业维权人”“职业闭店人”等违法犯罪。聚焦重点领域、常见问题，编制企业合规经营手册指引。（责任单位：区委政法委、区法院、区检察院、区司法局、区市场监管局）

（二十五）优化涉企行政检查。全面推行“风险+信用”分级分类检查制度。全面推行涉企行政“检查码”，提升涉企检查质效。运用大数据、人工智能等技术，减少非必要现场检查。建立市场监管行政执法报告发布制度。（责任单位：区相关行政执法部门、区发展改革委、区司法局、区市场监管局、各相关单位）

（二十六）深化包容审慎监管。推进轻微违法不罚举措。综合运用多种手段，给予企业更多容错机制。推行初创企业“辅导期”机制，对一年辅导期内企业实施“触发式监管”。优化新经济、新业态监管制度供给，支持新型业态发展。（责任单位：区市场监管局、区城管执法局）

（二十七）规范涉企案件办理。严格执行涉案财物处置程序规定，审慎采取查封、冻结等强制措施和惩戒措施。制定关于财产保全的相关实施细则，对民营企业审慎采取保全措施，最大程度减少对企业正常经营活动的影响，允许以信用保函替代实物担保。优化异地公安机关刑事办案协作请求审核，扎实推进违规异地执法和趋利性执法司法专项监督，促进跨区域执法公平公正。加强商事调解跨部门协作联动。（责任单位：区法院、区检察院、区公安分局、区司法局、区工商联）

（二十八）优化法治护企服务。升级“卫企”经济犯罪法律风险防控联盟，深化“沪企管家 护企有我”线上专窗建设，推进“蓝鲸”护企工作站建设，完善涉企风险防范提示。落实检察护航法治化营商环境举措，推进张园、市北高新园区法律服务工作站建设，完善园区护企“一站式”服务。（责任单位：区公安分局、区检察院、区法院）

（二十九）营造清朗网络环境。对编造传播虚假不实信息、以处置负面信息为由要挟企业合作等问题开展专项整治，集中打击并惩治涉企造谣传谣违法犯罪行为，依法严惩利用“网络水军”损害企业商誉、利用平台漏洞恶意“薅羊毛”等严重影响企业发展经营的行为。（责任单位：区检察院、区网信办、区公安分局）

六、切实加强民营经济发展服务保障

（三十）优化惠企政策服务。涉企政策制定广泛听取民营企业和行业协会商会意见。提高“一网通办”服务水平，拓展“政策找企业、企业找政策”双向通道。拓展政策“免申即享”“直达快享”范围。持续实施“政策领航计划”。（责任单位：区政府办公室、区投资办、区政务服务中心、各相关单位）

（三十一）强化各类要素保障。推动商业载体焕新升级、老旧商务楼宇更新、产业用地高效利用，为民营企业提供多样化载体空间。推动优秀民营企业人才通过“直通车”“绿色通道”进入职称评审的更高层级。鼓励民营企业与高校共建职业人才培训基地、订单式培养人才。（责任单位：区规划资源局、区商务委、区科经委、区投资办、区人力资源社会保障局）

（三十二）完善与民营企业常态化沟通交流机制。完善常态化政企沟通机制，巩固民营经济发展联席会议、民营企业圆桌会议等平台作用，定期或不定期召开民营企业座谈会，持续完善政策举措。加强招商引资和企业服务一体化，用好重点企业“服务包”制度，加大力度推进涉企问题发现和有效解决。（责任单位：区工商联、区发展改革委、区投资办）

（三十三）加强民营经济统计分析。按照国家民营经济统计口径，对民营经济发展情况进行统计分析，定期发布有关信息。（责任单位：区统计局、各相关单位）

（三十四）加强组织保障。建立完善静安区促进民营经济高质量发展工作协调机制，切实抓好各项任务举措落实。区发展改革委会同有关单位统筹推进相关工作。（责任单位：区发展改革委、各相关单位）
