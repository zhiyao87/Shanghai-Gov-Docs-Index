# 上海市住房和城乡建设管理委员会关于批准《桥梁工程超高性能混凝土应用技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《桥梁工程超高性能混凝土应用技术标准》为上海市工程建设规范的通知

沪建标定〔2022〕103号

各有关单位：

由上海市政工程设计研究总院（集团）有限公司、上海市城市建设设计研究总院（集团）有限公司、上海市市政规划设计研究院有限公司主编的《桥梁工程超高性能混凝土应用技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2401-2022，自2022年7月1日起实施。

本规范由上海市住房和城乡建设管理委员会负责管理，上海市政工程设计研究总院（集团）有限公司负责解释。

特此通知。

2022年2月15日
