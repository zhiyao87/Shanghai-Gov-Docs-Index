# 关于公布《2023年度上海市新能源出租车充电示范站名单》的通知

各相关单位：

根据《上海市鼓励电动汽车充换电设施发展扶持办法》（沪发改规范〔2022〕12号）要求，为保障纯电动巡游出租汽车有序运营和充电安全，市交通委、市发展改革委、市财政局共同组织对2023年度上海市新能源出租车充电示范站进行申报评选工作。经审核，最终确认2023年度上海市新能源出租车充电示范站名单，现予公布。

本市对新能源出租车充电示范站采用动态调整机制。请各示范站运营企业继续加强运营管理、规范服务流程，模范执行本市有关管理要求和行业政策，树立行业服务标杆，优先保障新能源出租车充电需求，积极发挥示范作用。

特此通知。
