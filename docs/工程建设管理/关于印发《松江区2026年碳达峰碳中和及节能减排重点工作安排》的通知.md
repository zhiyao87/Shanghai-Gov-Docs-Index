# 关于印发《松江区2026年碳达峰碳中和及节能减排重点工作安排》的通知

各镇人民政府、街道办事处、经开区，区政府各部门：

《松江区2026年碳达峰碳中和及节能减排重点工作安排》已经区政府同意，现印发给你们，请认真按照执行。

特此通知。

上海市松江区发展和改革委员会

2026年8月20日

松江区2026年碳达峰碳中和及

节能减排重点工作安排

为贯彻落实《中共中央办公厅 国务院办公厅关于更高水平更高质量做好节能降碳工作的意见》《上海市2026年碳达峰碳中和及节能减排重点工作安排》等有关精神，积极稳妥推进碳达峰碳中和，加快经济社会发展全面绿色转型，为“十五五”开好局起好步，结合松江区实际，现将2026年碳达峰碳中和及节能减排重点工作安排如下：

一、坚持目标导向，落实双碳主体责任

2026年，全区单位生产总值碳排放量按照市级要求完成年度目标，新增可再生能源建设规模88兆瓦，各部门、各街镇、经开区夯实主体责任，完善推进机制，积极完成行业或区域分解目标。主要污染物氮氧化物、挥发性有机物、化学需氧量和总磷减排量完成市级下达目标。

二、深化源头控碳，协同推进节能减排

（一）推进产业优化升级。编制《松江区节能降碳“十五五”规划》《美丽松江建设“十五五”规划》。聚焦重点区域调整，瞄准“三高三低”企业推进产业结构优化调整。聚焦“2+4”现代化产业体系建设，促进产业数智化、绿色化转型，推进新能源电力装备产业集聚发展。围绕绿色低碳应用场景，推动零碳园区建设，积极参与国家级、市级零碳园区申报建设。围绕绿色转型，加快发展碳管理、能源审计等绿色低碳专业服务，促进先进制造业和现代服务业深度融合。

（二）促进能源绿色转型。编制《松江区推进能源高质量发展行动方案（2026—2030年）》。推进韧性电网建设，有序开展电力重点项目的续建、新建。推广天然气等清洁能源应用，研究推进石湖荡重型燃机项目。严格落实《关于推进本市新建建筑可再生能源应用的实施意见》（沪建建材联〔2022〕679号）对各类建筑屋顶太阳能光伏安装面积比例要求，推动可再生能源（光伏）建设发展。全面推进新城“光伏+”开发，重点推进工业、农业、建筑、交通、公共机构等领域可再生能源（光伏）开发建设。加快促进绿电生产消费，积极推进绿电绿证交易。持续推进区域虚拟电厂发展。

三、聚焦重点领域，推动绿色低碳发展

（三）强化工业通信业低碳升级。加大劣势企业调整力度，实施产业结构调整项目不低于60项。鼓励企业开展节能技改、合同能源管理等节能举措。以新能源电力装备产业集聚为牵引，加速推动以研发制造、系统集成、场景应用、市场服务为一体的储能产业链发展，推进储能项目建设。大力推动数据中心能效提升，持续提高单位算力能效和单位信息流量能效。严格落实源头把关，做好拟新建智算中心项目“两高”及符合性评估工作。

（四）加强建筑领域绿色发展。全区新建民用建筑100%执行绿色建筑标准，按照绿色建筑一星级标准全覆盖，其中，新建国家机关办公建筑、大型公共建筑和其他由政府投资且单体建筑面积达到5000平方米的公共建筑按照绿色民用建筑三星级标准建设，支持可再生能源与建筑一体化发展。持续推进绿色生态城区建设，建设安全舒适绿色智慧的“好房子”。积极开展绿色生活活动，推进“无废城市”建设。持续推进绿色商场贯标和复核等工作。上海科技影都（华阳湖中心城区）绿色生态城区建设严格执行“一年一自查、三年一评估”要求。积极推进云间站城核绿色生态城区规划设计项目申报工作。

（五）构建完善绿色交通体系。深化“四网融合”综合交通体系建设，推进轨道交通12号线西延伸、沪松公路快速化等项目建设，积极发展多式联运。构建低碳城市交通体系，挖掘停车资源，推进静态交通智慧赋能。持续推进停车场错峰共享。优化调整公交线路10条，新增充电桩700个。配合推进重卡充电设施布局。推进东明广场、九亭金地广场、菜花泾市场停车场线上线下错峰共享泊位140个。

（六）深化公共机构节能管理。落实公共机构节能降耗目标任务。持续推进区内公共机构节能降耗工作，提升节能管理能力，强化公共机构的节能责任意识，降低日常的能源、资源消耗。有效控制全年的综合能源消费总量，使单位建筑面积能耗、人均能耗、人均水耗和单位建筑面积碳排放量等指标在2025年的基数上均有所下降。开展公共机构节能审查，提高公共机构能源利用效率。

（七）提升循环经济助力作用。优化实施“两新”工作。加强对资源源头减量、过程利用、末端资源化利用的全过程控制，打造循环型产业体系。提高农业、工业、城建和生活等领域废弃物资源化利用水平和能力，促进能源、水资源、土地资源等资源节约利用。持续推进生活垃圾分类减量工作，建设循环型社会，推进建设领域循环发展。持续推进农业面源污染治理，推行循环农业发展模式。推进粮油秸秆综合利用和提升畜禽粪污资源化利用水平，促进农业废弃物回收利用。推进上海天马生活垃圾末端处置综合利用中心飞灰资源化提标系统改造项目建设。

四、注重提质增效，强化过程监督管理

（八）深化节能降耗和污染物减排。对区重点用能单位进行能碳审计，鼓励企业实施节能技术改造和清洁生产审核。推进企业能源管理中心建设，支持企业开展能源管理体系认证，全面提升重点用能企业能效利用率和能耗管理水平。加强工业重点用能单位的能源消耗监测，完善重点用能单位管理机制，开展节能政策的培训和宣贯会。

（九）强化重点用能企业管理。对重点用能企业逐级分解能耗、碳排放强度和总量双控目标，并进行评价考核，同时对其能耗、碳排放强度和总量双控目标提出建议。依法严格实施固定资产投资项目节能审查和碳排放评价工作。加强能源消耗计量、统计、监测以及节能认证等基础工作，强化执法监察。聚焦重点领域、重点区域碳排放计量需要，推进有条件的重点用能单位开展能耗在线监测系统改造，推动辖区内能耗数据采集、上传。

（十）开展生态环境治理。发布并实施《松江区清洁空气行动计划2026年任务清单》。严格实行“批项目、核总量”环境影响评价制度，加大主要污染物减排力度。开展建设项目氮氧化物和挥发性有机物新增排污权有偿使用和交易。组织开展各类大气专项执法攻坚行动，加大对建筑工地、道路扬尘污染防治监管力度。持续深入打好碧水保卫战，全面推进入河排污口整治。持续深入打好净土保卫战。全面完成优先监管清单地块土壤污染管控目标。持续保障全区重点建设用地安全利用。

（十一）全面推进生态文明建设示范区建设。根据《上海市松江区国家生态文明建设示范区规划（2024—2035年）》，对标生态文明建设示范区建设要求，积极开展示范区建设工作。推动新建绿地、绿道、立体绿化、口袋公园等建设，优化“沪尚回收”网络布局。推进石湖荡镇申报“两山”基地，完成新增1个街镇“两山”基地建设纳入市级遴选储备库。

五、加强保障支撑，筑牢双碳工作基础

（十二）完善市场机制和政策支持。贯彻落实《松江区关于支持经济社会绿色低碳发展的若干意见》要求，规范我区绿色低碳发展专项资金的使用和管理。全面实施碳排放总量和强度双控制度，研究制定《松江区“十五五”碳达峰行动方案》。大力发展绿色信贷、绿色债券、绿色基金、绿色保险等金融产品和服务。鼓励节能降碳企业积极利用国家自愿减排管理平台，开发碳资产、参与碳交易。加强区内企业培育和应用场景创建。加快推进国家级制造业中小企业数字化转型城市试点工作，打造一批转型行业标杆，遴选一批专业服务机构，凝练一批优质轻量化产品，有效提升试点行业企业数字化水平。深入实施节能产品政府强制采购和优先采购制度，鼓励各类主体提高节能产品采购标准和比重。

（十三）提升科技创新能力。以上海低碳技术创新功能型平台建设为抓手，依托大学城科创源等资源，推动绿色低碳重大科技攻关。强化绿色技术创新攻关项目“揭榜挂帅”机制，推动绿色技术创新企业健康发展。支持企业、高校、科研机构等打造一批绿色技术应用转化平台，努力实现低碳领域开发利用共性技术和关键技术成果转移转化。引进集聚一批具有自主知识产权高层次科技人才，推动低碳技术成果产业化。

六、强化全员参与，确保工作落地落细

（十四）强化目标责任落实。合理分解年度可再生能源建设任务和碳排放强度控制目标，强化各职能部门行业主管责任、街镇、经开区属地责任，国有企业加强节能降碳示范引领。注重考核结果运用，全面提升各级单位对节能降碳工作积极性。

（十五）积极倡导绿色低碳全民参与。深入推进塑料污染治理、快递包装绿色转型、粮食节约和反食品浪费等工作。扎实推进《上海市机关食堂反食品浪费工作成效评估和通报制度实施方案》，常态化开展机关食堂反食品浪费工作。强化宣传教育和培训，将绿色低碳理念融入大中小学教育体系。开展全国生态日、全国节能宣传周、全国低碳日等主题系列活动，广泛动员全社会参与节能降碳，营造绿色低碳生活新风尚。

（十六）加强区域交流合作。依托本区产业优势，持续深化与安徽省六安市等长三角区域、西藏日喀则市等东西部协作地区、云南省西双版纳傣族自治州和昭通市等对口合作地区及其他区域在新能源开发利用、技术产业协同、绿电交易、碳排放权交易、资金、人才等方面交流合作和信息共享，推动开展可再生能源、储能等领域合作和交流。
