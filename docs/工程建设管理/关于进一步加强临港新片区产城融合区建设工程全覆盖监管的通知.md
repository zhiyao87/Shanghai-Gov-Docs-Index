# 关于进一步加强临港新片区产城融合区建设工程全覆盖监管的通知

关于进一步加强临港新片区产城融合区建设工程全覆盖监管的通知

沪自贸临管委〔2024〕39号

管委会各有关部门，临港新片区各镇、各有关单位:

为健全部门协同、条块联动的建设工程安全监督管理体系，2023年9月22日浦东新区建交委等部门联合印发《关于进一步加强浦东新区建设工程全覆盖监管的实施意见》（浦建委建管〔2023〕44号，以下简称《实施意见》）。

为贯彻落实好《实施意见》，努力实现临港新片区产城融合区建设工程监管全覆盖，结合临港新片区管理实际情况，现将有关要求进一步明确如下：

一、总体要求

在市和区建设、交通、水务、海洋、绿化市容、民防、房屋等行政管理部门的指导下，临港新片区管委会按照具体委托管理事项，负责临港新片区产城融合区内建设工程的管理。管委会建交处、应急处、规资处、生态处、综合执法大队按照职责分工，分别对接区建设交通、应急、规划资源、生态环境、城管执法等行政管理部门，协同落实建设工程全覆盖监管。

二、分类分级管理

（一）纳入建设程序管理的工程

根据管委会的有关规定和要求，管委会相关部门按照职责分工依法进行监督管理。管委会未明确规定的，按照区政府有关规定执行。

涉及需管委会和区政府多个部门联合处置的工程建设行为，按照“条块联动、各司其职、信息共享、协同处置”的原则，由管理部门和属地镇实行动态联动处置。

镇政府要切实履行发现职责，加大巡查力度，充分发挥网格巡查的作用，定期开展排摸，及时发现、制止各类违法违规建设行为。排摸中发现的存在违法建设行为，要及时登记相关信息，上报临港新片区建筑施工专委办（以下简称“专委办”）。

（二）限额以下小型工程

镇政府应严格落实市建设行政管理部门和区政府有关要求，制定管理规定，落实管理队伍，对辖区内小型工程进行全覆盖监管。各镇应建立安全生产基本工作制度，完善日常巡查发现机制，加强日常监督检查，督促建设单位、施工企业落实施工现场的安全管理，排查整治安全隐患等；应整合城管、村居、网格、安监等资源，建立健全登记备案和安全生产告知承诺制度、安全生产日常巡查制度和日常监管台账制度，加大对辖区内小型工程安全生产监督检查力度。同时，要切实履行发现责任，做好辖区建设工程纳管工作。

根据《实施意见》，浦东新区建交委指导浦东区域各街镇开展限额以下小型工程安全监督管理工作。其中，临港新片区产城融合区南汇新城镇、书院镇、泥城镇和万祥镇（以下简称“临港四镇”），由临港建交中心（质安监站）负责具体指导。

临港建交中心（质安监站）应将相关工作纳入日常管理，监督和指导相关镇做好小型工程的安全监管工作，建立台账，汇总小型工程项目，并按要求报送专委办和浦东新区建交委等相关管理部门。

三、部门协同

区相关行政管理部门要加强行业管理和指导。管委会相关部门根据管委会具体委托管理事项，加强与区相关行政管理部门的工作对接，建立区（区政府）委（管委会）协同管理工作机制，不断完善建设工程全覆盖监督管理体系。

（一）管委会建交处对接区建设交通部门、生态处对接区生态环境部门，按职责分工落实相关建设工程的管理要求。

（二）管委会规资处对接区规划资源部门，协助认定擅自搭建建筑物、构筑物的违法行为。

（三）管委会应急处对接区应急部门，发挥临港新片区安委办综合协调职能，会同专委办指导监督各部门、各镇规范落实建设施工安全监管工作。

（四）管委会综合执法大队对接区城管执法部门负责执法保障。综合执法大队负责南汇新城镇、区城管执法局负责其余各镇违法用地及擅自搭建建筑物、构筑物的违法行为行使立案查处，配合属地镇政府做好整治、拆除工作。

四、联动处置

临港新片区产城融合区各镇应按市和区相关要求，落实属地管理职责，做好联动处置各项工作。临港四镇镇政府对巡查发现的违法建设行为按照以下类别移送相关部门进行牵头处置：

（一）涉及违法用地及未经审核擅自违法搭建的，由区城管执法部门、临港新片区执法大队和镇政府按各自职责执法查处；

（二）涉及应领取施工许可证未领取的，投资额100万以上或建筑面积300平方米以上的建设工程移送至专委办；

（三）涉及其他违法违规行为的，按照行业管理分工移送至其他部门；

（四）对违法建设行为实施过程中发生生产安全事故的，管委会应急处负责南汇新城镇区域、其余各镇负责属地区域，配合区应急管理部门进行事故调查和处置。

五、其他

（一）临港新片区产城融合区奉贤区行政区域内，纳入建设程序管理的工程按照本通知的有关要求执行，限额以下小型工程各镇应严格按照奉贤区政府相关规定加强对辖区内限额以下小型工程的监督管理。

（二）市、区政府出台相关新规定的，按新规定执行。
