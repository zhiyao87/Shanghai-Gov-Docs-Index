# 上海市住房和城乡建设管理委员会关于批准《住宅修缮工程质量检测及评定标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《住宅修缮工程质量检测及评定标准》为上海市工程建设规范的通知

沪建标定〔2023〕241号

各有关单位：

由上海市建设工程检测行业协会和上海市住宅修缮工程质量检测中心主编的《住宅修缮工程质量检测及评定标准》，经我委审核，现批准为上海市工程建设规范，统一编号为 DG/TJ08-2431-2023，自2023年12月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市建设工程检测行业协会负责解释。

2023年5月19日
