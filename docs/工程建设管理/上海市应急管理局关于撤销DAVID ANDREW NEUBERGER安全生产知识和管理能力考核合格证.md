# 上海市应急管理局关于撤销DAVID ANDREW NEUBERGER安全生产知识和管理能力考核合格证的通告

经调查，DAVID ANDREW NEUBERGER未参加生产经营单位主要负责人安全生产知识和管理能力考核。现对其取得的安全生产知识和管理能力考核合格证（证号：566446399；人员类型：主要负责人；行业类别：危险化学品经营单位；有效期限：2020-12-18至2023-12-17）予以撤销。
特此通告。

上海市应急管理局
2021年9月14日
