# 上海市住房和城乡建设管理委员会关于本市进一步推广工程建设项目勘察、设计、施工电子招标投标的通知

上海市住房和城乡建设管理委员会关于本市进一步推广工程建设项目勘察、设计、施工电子招标投标的通知

沪建建管〔2022〕348号

各有关单位：

为加强电子招标投标应用，根据《电子招标投标办法》（国家发展改革委等八部委第20号令）、《上海市建设工程招标投标管理办法》（沪府令50号）等规定，经研究决定，自2022年9月1日起，在本市建设工程招标投标交易场所实施勘察、设计、施工招标投标的工程建设项目进一步推行电子招标投标。有关事项通知如下：

一、推行电子招标投标的范围包括本市工程建设项目勘察、设计招标投标，水利、园林绿化和其他行业（电力、港口航道、通信、铁路、冶金、石油化工等）工程建设项目施工招标投标。

二、有关电子招标投标交易系统、工具软件和技术支持等事项，按现行的电子招标投标相关规定执行。

特此通知。

2022年8月1日
