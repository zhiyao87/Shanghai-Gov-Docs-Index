# 上海市应急管理局废止关于进一步全面落实企业安全生产主体责任的意见的通知

各区应急管理局、各有关单位：

上海市安全生产委员会办公室已于2023年7月27日印发《关于进一步强化生产经营单位安全生产主体责任落实的指导意见》（沪安委办〔2023〕30号）。经研究，决定废止《关于进一步全面落实企业安全生产主体责任的意见》（沪应急行规〔2020〕2号）。

本通知自印发之日起施行。

上海市应急管理局

2023年8月3日
