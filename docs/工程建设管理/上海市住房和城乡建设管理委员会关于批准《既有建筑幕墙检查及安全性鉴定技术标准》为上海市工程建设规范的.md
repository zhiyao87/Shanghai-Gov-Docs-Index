# 上海市住房和城乡建设管理委员会关于批准《既有建筑幕墙检查及安全性鉴定技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《既有建筑幕墙检查及安全性鉴定技术标准》为上海市工程建设规范的通知

沪建标定〔2024〕377号

各有关单位：

由上海建科检验有限公司主编的《既有建筑幕墙检查及安全性鉴定技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-803-2024，自2024年12月1日起实施。原《建筑幕墙安全性能检测技术规程》DG/TJ08-803-2013同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海建科检验有限公司负责解释。

2024年7月22日
