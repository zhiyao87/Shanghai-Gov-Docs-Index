# 月浦镇关于建设工程安全文明施工的实施办法（试行）

各基层单位、相关部门：

为了进一步加强对月浦镇镇域内建设工程的依法监管，提高建设工程安全生产、文明施工的管理水平，并使各建设工程施工现场安全管理处于受控状态，特制定以下实施办法。

一、组织机构

月浦镇规划建设和环境保护办公室、安全管理事务所和城市管理行政执法中队是镇域内建设工程管理的责任部门，组成月浦镇建设工程安全文明施工监督管理组（以下简称“镇建设工程监管组”）。各公司、村、居民区根据本辖区内建设工程的规模现状和发展趋势，落实分管领导，并设立1-2名建设工程专职（或兼职）管理人员（以下简称“专管员”）。

二、管理机制

1.在区建交委“宝山区建设工程管理信息系统”名录中的工程项目，由镇建设工程监管组配合区建设交通委（区安质监站）开展建设工程安全生产和文明施工日常巡查、监督管理工作。

2.镇政府财政资金投资建设的投资额在200万元以下（含200万）的小型项目，包括新建、扩建、改建的土建工程及水务、绿化、修缮等工程（应急抢险等项目除外），按照《月浦镇财政投资小型建设工程项目操作办法（试行）》中的相关规定办理手续。由建设单位（代建单位）负责建设工程安全生产和文明施工的日常巡查、监督管理工作。

3.村级集体资金及村级集体资金占控股或者主导地位的，投资金额200万以下（含200万）的新建、扩建、改建、修建等各类小型工程建设项目，按照《月浦镇村级集体投资小型建设工程项目管理办法（试行）》中的相关规定办理手续。由村专管员负责建设工程安全生产和文明施工的日常巡查、监督管理工作。

4.村级集体资金投资额10万以下小型工程建设项目，经村“两委”讨论通过，形成书面决议后，可按年度打包，择优选定具有相应资质的施工企业进行施工。由村专管员负责建设工程安全生产和文明施工的日常巡查、监督管理工作。

5.农村村民建房工程，由各村专管员及镇市容办巡查员对项目的安全生产和文明施工进行日常巡查和监督管理。

6.各公司专管员负责对下属企业的建设工程项目进行安全生产和文明施工的日常巡查和监督管理。

7.各居民区专管员负责对辖区内的建设工程项目进行安全生产和文明施工的日常巡查和监督管理。

三、专管员主要职能

各公司、村、居民区专管员对管辖范围内在建工程承担的主要监管职能包括：

（一）负责做好管辖范围内在建工程项目安全生产、文明施工日常巡查工作。

（二）及时接受镇建设工程监管组对管辖范围内监管信息的通报，对管辖范围内在建工程的违法行为，以及未履行建设程序的新建工程项目，及时报告镇建设工程监管组。

（三）配合镇建设工程监管组开展在建工程日常监管，对镇建设工程监管组要求建设工程参与各方落实安全生产责任制的情况，做好跟踪督查和信息反馈工作；协助镇建设工程监管组做好安全生产事故处理，做好事故善后处置工作。

（四）掌握管理范围内在建工程项目建设相关单位用工管理情况，配合镇建设工程监管组对用工单位拖欠农民工工资行为的协调工作。

四、监管内容和方式

（一）日常监督管理

各公司、村、居民区负责对管辖范围内在建工程的安全生产、文明施工开展日常管理工作。对施工现场的安全生产和文明施工状况进行巡查，每周不少于一次。对日常巡查中发现的建设工程施工现场存在违反安全生产及文明施工规范的行为，要立即责令施工单位采取措施立即整改，并填写检查月报表（附件1），上报至镇建设工程监管组。

（二）监管信息通报

1.对在建工程项目违反安全生产、文明施工行为的处理。各公司、村、居民区专管员在检查中发现施工现场存在安全生产隐患以及严重违反文明施工规范的行为，或者被信访投诉、媒体批评曝光的情形，在责令建设相关责任单位立即整改的同时，立即上报镇建设工程监管组（附件2）。镇建设工程监管组在接到报告后的24小时内，指派专人到现场核查，根据核查作出相应的处理（必要时由镇建设工程监管组上报区监管部门进行核处），并将处理的信息及时反馈给各公司、村、居民区。

2.对未立项已开工工程项目的处理。对在巡查中发现的未立项已开工的在建工程项目，立即报送镇拆违办，由其按照相应处理程序执行。

3.对未完全履行建设工程项目行政审批程序的在建工程项目的处理。各公司、村、居民区在实施日常监督巡查过程中，一旦发现管辖范围内建设工程出现违法开工情况，要及时制止施工单位继续施工，并将违法开工工程的相关信息及时上报镇建设工程监管组。镇建设工程监管组上报镇分管领导，并按情况抄报区政府相关部门。

4.对存在其他问题的处理。在开展日常巡查中，对发现的严重拖欠农民工工资、不按规定开展安全教育、特种作业人员无证上岗等违反建筑工程管理法规规范的行为，及时上报镇建设工程监管组，镇建设工程监管组按规定通报区建设交通委、区安全监管局、区人力资源和社会保障局等相关监管部门。

（三）协同监督管理

1.配合镇建设工程监管组组织日常监管和巡查工作。参与镇建设工程监管组组织开展的管辖范围内建设工程安全生产和文明施工隐患排查治理专项活动，并加强与镇建设工程监管组开展信息互通和工作联动，在日常管理检查中加强联动、合力推进。

2.督促建设相关责任单位抓好整改工作。根据镇建设工程监管组监管信息，对要求限期整改的项目，在整改期限内，坚持每周不少于一次的跟踪督促检查，督促建设有关责任单位，按整改要求限期落实整改，并将整改情况反馈给镇建设工程监管组。

3.及时掌握工程进展情况，并向镇建设工程监管组上报工程进度信息。

4.做好事故预防及事故处置工作。参与镇建设工程监管组开展的建设工程应急救援演练活动，在本管理范围内建设工程发生事故时，按照本单位事故应急处置预案，配合镇建设工程监管组开展应急救援和善后处置工作。

五、工作机制

（一）培训制度

各公司、村、居民区专管员要参与镇建设工程监管组组织开展的专业培训。按照镇建设工程监管组具体的业务指导，不断增强业务能力，努力提高对管辖范围内的建设工程开展监督管理的水平。

（二）会议制度

参加镇建设工程监管组定期组织的工作会议，研究、部署、协调、推进建设工程监管工作。

（三）考评制度

1.各公司、村、居民区要加强对专管员的教育和管理，并充分发挥在建设工程管理中的监管作用。

2. 镇建设工程监管组对各公司、村、居民区开展建设工程安全生产、文明施工监管工作进行年度考评。对专管员在开展建设工程施工管理工作中，因失职、渎职导致所管辖范围内建设工程发生安全事故或因文明施工被投诉、媒体曝光批评的，要严格落实问责制度。对因工作不力、未尽到监管职责，或因徇私舞弊，违反有关廉洁规定的，由镇纪检部门按有关规定作出相应处罚。
