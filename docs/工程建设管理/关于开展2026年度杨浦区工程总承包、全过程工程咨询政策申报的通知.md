# 关于开展2026年度杨浦区工程总承包、全过程工程咨询政策申报的通知

区投资促进办、各科技园区、各相关单位：

为大力促进本区工程总承包、全过程工程咨询业务发展，根据《杨浦区加快科技服务业高质量发展若干措施》（杨科经规〔2026〕3号），区科技经济委开展2026年度工程总承包、全过程工程咨询政策申报工作，现将有关事项通知如下。

一、申报主体条件

依法依规开展工程总承包、全过程工程咨询业务的企业。企业需具有健全的财务管理制度，会计信用、纳税信用和社会诚信度良好，三年内无严重失信行为和违法违规行为。

二、申报材料

1.杨浦区工程总承包、全过程工程咨询政策申请报告;

2.2024年度和2025年度企业财务审计报告（2025年度报告中应体现工程总承包或全过程工程咨询业务收入金额）;

3.其他相关材料（企业相关资质、团队荣誉等）。

三、申报方式

1.申报时间：即日起至2026年7月31日（周五）止。

2.企业将完整申报材料（纸质材料1份、电子版1份）经由户管单位（区投促办或科技园区）出具推荐意见后报送至区科技经济委。

纸质版材料送至：杨浦区江浦路627号2号楼405室

电子版材料发送至：ypkwqyk@163.com

3.联系方式：65690561

四、声明

杨浦区科技经济委从未委托任何机构或个人代理工程总承包、全过程工程咨询政策项目申报事宜，请申报单位自主申报。杨浦区科技经济委将严格按照有关标准和程序受理，不收取任何费用。如有机构或个人假借区科技经济委工作人员名义向申报主体收取费用的，请知情者向区科技经济委举报（举报邮箱：ypkwqyk@163.com;邮寄地址：杨浦区江浦路627号2号楼405，邮编：200082）。举报时间截至项目立项公示前。
