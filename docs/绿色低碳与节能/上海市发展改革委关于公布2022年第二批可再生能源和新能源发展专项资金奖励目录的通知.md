# 上海市发展改革委关于公布2022年第二批可再生能源和新能源发展专项资金奖励目录的通知

各有关单位：

根据《上海市可再生能源和新能源发展专项资金扶持办法》（沪发改能源〔2016〕136号，以下称“136号文”）、《上海市可再生能源和新能源发展专项资金扶持办法（2020版）》（沪发改规范〔2020〕7号，以下称“7号文”）和《关于做好2021年可再生能源和新能源发展专项资金扶持项目申报和奖励资金申请工作的通知》（沪发改能源〔2021〕18号，以下称“18号文”），我委会同市财政局组织开展了2022年第二批可再生能源专项资金扶持项目申报和评审工作。经各区初审、委托市节能减排中心评审和社会公示，现将有关事项通知如下。

一、关于新列入专项资金奖励目录项目情况

共有1775个项目纳入奖励目录，总装机容量249376.418千瓦。其中，海上风电项目1个（合计45500千瓦）、光伏电站项目1个（3499.97）、企业分布式光伏项目315个（合计183784.37千瓦）、居民光伏项目1458个（合计16592.078千瓦）。

二、关于已纳入专项资金奖励目录项目的信息变更情况

13个项目申请项目变更条件予以确认，其中：企业分布式项目5个。（1）经青浦区发展改革委申请核实，“上海电气建筑节能有限公司利用国展中心屋顶建设2.2MW分布式光伏电站项目（2017年第二批目录）”，单位名称从“上海电气建筑节能有限公司”变更为“上海电气数智生态科技有限公司”。（2）经崇明区发展改革委申请核实，“上海绿兆新能源科技有限公司实施崇匠建设（上海）有限公司52.02KW屋顶分布式光伏发电项目（2021年第一批目录）”，单位名称从“上海绿兆新能源科技有限公司”变更为“崇电科技（上海）有限公司”。（3）经嘉定区发展改革委申请核实，“上海圣飞新能源嘉定区兴贤路789号上海连盈螺丝有限公司559千瓦分布式光伏发电项目（2021年第一批目录）”，单位名称从“上海圣飞新能源科技有限公司”变更为“嘉兴胜锦新能源有限公司”。（4）经金山区发展改革委申请核实，“上海复镝实业有限公司20千瓦分布式光伏发电项目（2018年第一批目录）”，单位名称从“上海复镝实业有限公司”变更为“上海复镭投资管理有限公司”。（5）经闵行区发展改革委申请核实，“国核工程有限公司146.965KWp屋顶分布式光伏发电项目（2020年第一批目录）”，单位名称从“国核工程有限公司”变更为“上海核工程研究设计院有限公司”。

居民光伏8个。经青浦区发展改革委申请核实，（1）“上海市青浦区赵巷镇业煌路168弄173号（2017年第二批）”用户名从“孙仟花”变更为“侯笑宇”；（2）“上海市青浦区赵巷镇业前路1688弄446号（2019年第一批）”用户名从“宋厚波”变更为“王花”；（3）“上海市青浦区徐泾镇沪青平公路1638弄156号（2018年第一批）”用户名从“刘喜芝”变更为“夏永玲”；（4）“上海市青浦区朱家角镇浦祥路581弄1801号（2019年第一批）”用户名从“沈琼”变更为“金纪宁”；（5）“上海市青浦区青浦镇新园路509弄32号301室（2015年第一批）”用户名从“赵林涛”变更为“周冠卿”；（6）“上海市青浦区赵巷镇沪青平公路2558弄123号（2021年第一批）”用户名从“田树涛”变更为“TIANSHUTAO”；（7）“上海市青浦区赵巷镇置发路68弄52号（2017年第三批）”用户名从“方婷”变更为“陈芳”。经奉贤区发展改革委申请核实，（8）经奉贤区发展改革委申请核实，“上海市奉贤区海湾旅游区海马路5888弄609号”用户名从“蒋惠祥”变更为“印桂花”。

三、关于新增奖励目录项目奖励资金申报

按照7号文、18号文要求，市电力公司应按季度做好本批奖励目录项目的电量统计和奖励资金申报工作，项目奖励电量总数达6050小时或者奖励期满5年，奖励结束。各区发展改革委做好项目的监督和管理，切实发挥专项资金的支持引导作用。

特此通知。
