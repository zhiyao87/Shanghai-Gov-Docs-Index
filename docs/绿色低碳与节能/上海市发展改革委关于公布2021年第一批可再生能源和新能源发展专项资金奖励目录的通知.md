# 上海市发展改革委关于公布2021年第一批可再生能源和新能源发展专项资金奖励目录的通知

沪发改能源〔2021〕135号

各有关单位：

为促进全市可再生能源发展，根据《上海市可再生能源和新能源发展专项资金扶持办法（2020版）》（沪发改规范〔2020〕7号，以下称“7号文”）和《关于做好2021年可再生能源和新能源发展专项资金扶持项目申报和奖励资金申请工作的通知》（沪发改能源〔2021〕18号，以下称“18号文”），我委会同市财政局组织开展了2021年第一批可再生能源专项资金扶持项目申报和评审工作。经各区初审、委托市节能减排中心评审、社会公示，现将有关事项通知如下。

一、关于新列入专项资金奖励目录项目情况

共有1035个项目纳入奖励目录，总装机容量181880.188千瓦。其中，海上风电项目1个（12000千瓦）、光伏电站1个（110000千瓦）、企业分布式项目108个（合计51020.175千瓦）、居民光伏925个（合计8860.013千瓦）。

二、关于已纳入专项资金奖励目录项目的信息变更情况

7个项目符合变更条件予以确认，其中：

企业分布式项目3个。经长宁区发展改革委申请核实，“上海虹桥迎宾馆（10号楼)光伏发电项目（2017年第三批）”，由于企业自身发展原因，单位名称从“上海虹桥迎宾馆”变更为“上海虹桥迎宾馆有限公司”。经金山区发展改革委申请核实，“上海津力生物科技股份有限公司700千瓦分布式光伏项目（2019年第一批）”，由于企业自身发展原因，单位名称从“上海津力生物科技股份有限公司”变更为“上海津力药业股份有限公司”。经青浦区发展改革委申请核实，“上海顺利实业有限公司利用上海索罗日用品有限公司屋顶建设62.4千瓦分布式光伏发电项目（2016年）”，由于项目收益权转让原因，单位名称从“上海顺利实业有限公司”变更为“上海索罗日用品有限公司”。

居民光伏4个。经青浦区发展改革委申请核实，（1）“青浦区朱家角镇绿舟路188弄52号（2016年）”用户名从“钱恺”变更为“任洁”；（2）“青浦区赵巷镇嘉松中路6633弄501号（2017年第一批）”用户名从“褚奇虎”变更为“张韧”；（3）“上海市青浦区徐泾镇沪青平公路1517弄231号（2019年第一批）”，用户名从“党晨”变更为“龚子棋”。经杨浦区发展改革委申请核实，（4）“上海市杨浦区政和路538弄178号(2017年第一批)” 用户名从“苏泉荣”变更为“韩维玮”。

三、关于新增奖励目录项目奖励资金申报

按照7号文、18号文要求，市电力公司自2021年三季度开始应按季度做好本批奖励目录项目的电量统计和奖励资金申报工作，项目奖励电量总数达6050小时或者奖励期满5年，奖励结束。各区发展改革委做好项目的监督和管理，切实发挥专项资金的支持引导作用。如有项目需调整，由各区发展改革委核实后按季度汇总报送我委。

特此通知。
