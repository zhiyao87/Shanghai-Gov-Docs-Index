# 关于印发《中国（上海）自由贸易试验区临港新片区管理委员会关于持续推进海绵城市建设的指导意见》的通知

关于印发《中国（上海）自由贸易试验区临港新片区管理委员会关于持续推进海绵城市建设的指导意见》的通知

沪自贸临管委〔2019〕72号

各有关单位：

现将《中国（上海）自由贸易试验区临港新片区管理委员会关于持续推进海绵城市建设的指导意见》印发给你们，请结合实际认真贯彻落实。

中国（上海）自由贸易试验区临港新片区管理委员会

2019年12月13日

中国（上海）自由贸易试验区临港新片区管理委员会关于持续推进海绵城市建设的指导意见

第一条（指导思想）

以习近平新时代中国特色社会主义思想为指导，深入贯彻落实习近平总书记考察上海重要讲话精神，按照“一个尊重、五个统筹”的城市发展要求，高标准高质量建设“自然积存、自然渗透、自然净化”的海绵城市，着力把新片区打造成更具国际市场影响力和竞争力的特殊经济功能区，建设成开放创新、智慧生态、产城融合、宜业宜居的现代化新城。

第二条（推进思路）

在深入总结前阶段海绵城市建设试点工作经验、巩固试点建设成果的基础上，进一步把海绵城市建设理念作为指导城市空间规划布局、加强城市开发建设整体衔接、促进城市精细化管理水平提升的重要手段，嵌入规划编制、土地出让、项目审批、施工图审查、竣工验收、城市运维管理全过程，加强涉水基础设施建设和管理的整体性、系统性。

城市新建区以目标为导向开展海绵城市建设，已建区结合城市更新改造，重点解决积水内涝、水体污染等涉水问题。主城区注意保护滴水湖水系水环境质量，提升区域排水防涝综合能力。产业区和物流园区注意统筹生产、生活、生态布局，加强雨水资源化利用，控制面源污染，确保排水防涝的安全红线。

第三条（部门职责）

生态和市容管理处负责牵头推进临港新片区海绵城市建设工作，统筹协调相关问题。管委会相关处室按照职责分工协同推进有关工作。探索推进政府购买服务引导第三方加强技术统筹和指导。

第四条（系统研究）

针对主城区、产业区、物流园区、综合区等不同区域组织开展系统性研究，提出区域海绵城市建设总体目标和途径。结合现状和规划地形地貌、管网、路网、河网等，合理划分管控分区。根据雨水流动的自然规律，明确分区从源头到末端的管控方案，拟定区域性海绵体的规模布局，提出系统性治理措施的内容安排。新建区域针对规划用地布局、城市竖向控制以及上下游排水衔接提出管控要求。

第五条（规划编制）

组织编制临港新片区海绵城市建设专项规划，统筹区域系统研究成果，全面分析城市生态本底特征以及排水防涝、水生态环境、水资源利用等面临的突出问题，确定蓝绿自然生态空间格局，明确河湖水系、绿地、湿地等自然调蓄空间保护范围，从水安全保障、水环境改善、水生态修复、水资源利用等方面提出海绵城市建设的整体目标和指标，并按照管控分区逐级分解落实，明确具体实施路径、管控要求和保障措施。

第六条（规划衔接）

临港新片区海绵城市专项规划定位于综合性专项规划，指导城市排水防涝、水利水系、绿地系统、道路交通等相关专项规划和详细规划的编制实施。

国土空间规划编制时应吸收海绵城市专项规划成果。城市排水防涝、水利水系、绿地系统、道路交通等专项规划编制时应衔接落实海绵城市专项规划提出雨水管控要求。城市控详规划编制时应，要充分考虑控规单元与海绵城市专项规划确定的管控分区之间的兼容性，衔接落实海绵城市专项规划提出的用地布局、竖向控制等要求。

第七条（指标管控）

海绵城市专项规划确定的相关指标是指导和推进海绵城市建设的重要抓手。

土地划拨（或出让）时应在规划设计条件或（土地出让合同）中明确海绵城市建设指标要求。规划土地综合验收时应采用监测评估或模拟评估等手段对海绵城市建设指标进行验收。

第八条（区域统筹）

区域整体划拨（或出让）时可对该区域海绵城市建设指标进行统筹管理，其中区域总体指标为控制性指标，该区域内单个地块的指标为指导性指标。统筹管理指标的区域应建立指标动态调整机制，对于无法完成指导性指标的地块，通过区域内部平衡方式，确保总体指标达标。

第九条（项目立项）

新建、改建、扩建项目应在立项阶段明确海绵城市建设内容要求。

财力投资项目应在工程可行性研究报告中对海绵城市建设的技术、经济可行性进行全面分析论证，明确建设内容、规模及投资估算。发展改革处应在工程可行性研究报告评审中组织专家对相关内容进行审查，并在批复文件中载明。

第十条（设计管理）

新建、改建、扩建项目在编制各个阶段设计文件时均应同步编制海绵城市专章（或专篇）。海绵城市设计文件除满足国家和上海市相关技术标准外，还应符合临港新片区发布的相关技术规定。

第十一条（事中事后监管）

在不新增审批环节、不延长审批时限的原则下，由方案设计、初步设计审批部门组织对海绵城市设计文件质量进行审核，审核方式可采用行业专家评审，也可采用第三方机构审查。

项目建设单位根据实际需要，可申请采用告知承诺制，由审批部门事后组织审核，对审核不通过的项目定期予以通报或约谈。

第十二条（施工图审查）

施工图审查机构应按照国家、上海市和临港新片区海绵城市建设相关技术标准、规定对海绵城市设计内容进行审查，并出具审查报告。建设单位委托其他第三方机构对海绵城市设计内容进行专项审查的除外。

第十三条（项目验收）

建设项目主体工程验收时应同步对海绵设施进行验收，并将结果写入验收结论。验收前，施工单位应对海绵设施标高、规模及重要参数进行测量、复核，出具复核报告，并经设计单位、监理单位确认。

第十四条（监测评估）

海绵城市建设项目应按要求同步配建海绵城市监测设施，并接入临港海绵城市智慧管控平台。临港海绵城市智慧管控平台运维单位根据监测数据对项目成效进行评估，并将结果反馈海绵城市建设主管部门。

第十五条（运维主体）

海绵设施及监测设备原则上同主体工程同步办理移交手续。市政道路、公共绿化、河道等基础设施建设项目的海绵设施原则上由相应的道路、绿化和河道接管单位接管，并落实养护单位进行养护。住宅小区海绵设施原则上由相应小区的物业管理单位接管养护。

第十六条（资金保障）

市政道路、公共绿化、河道等基础设施建设项目的海绵设施建设和养护费用由临港新片区管委会财政资金予以保障。住宅小区等社区投资项目的海绵设施建设和养护费用原则上由建设单位和管养单位自行解决，管委会根据实际需要研究制定相应的扶持政策。

第十七条（设计取费）

海绵城市规划设计取费应参考国家或行业关于海绵城市规划设计取费的相关标准，相关标准缺乏时，可根据工作量大小合理提高承担海绵城市设计任务的相关专业的原有取费标准。

第十八条（社会服务）

鼓励开发建设主体，特别是承接区域整体开发任务的建设主体，以及海绵设施养护单位，通过购买服务方式聘请专业第三方机构提供海绵城市建设全过程技术咨询服务。

第十九条（公众参与）

有关部门和社区、居委等基层组织要积极开展海绵城市建设理念的宣传普及活动。鼓励市民通过合法渠道和方式参与海绵城市规划、设计、建设和运维，不断提高市民的参与度和满意度。

第二十条（产业政策）

鼓励临港新片区管理部门、开发建设主体、科研设计单位等开展海绵城市建设相关的科学研究和先进技术、设备和材料的推广应用，特别是城市面源污染治理、河湖水环境保障、盐碱土壤改良等方面技术。管委会根据实际需要研究制定相应的扶持政策。
