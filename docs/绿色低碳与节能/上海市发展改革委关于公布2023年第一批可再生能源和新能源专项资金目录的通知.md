# 上海市发展改革委关于公布2023年第一批可再生能源和新能源专项资金目录的通知

各有关单位：

根据《上海市可再生能源和新能源发展专项资金扶持办法（2020版）》（沪发改规范〔2020〕7号，以下称“7号文”）、《上海市可再生能源和新能源发展专项资金扶持办法》（沪发改规范〔2022〕14号，以下称“14号文”），我委会同市财政局组织开展了2023年第一批可再生能源专项资金扶持项目申报和评审工作。经各区初审、市节能减排中心评审和社会公示，现将有关事项通知如下。

一、关于新列入专项资金奖励目录项目情况

共有1155个项目拟纳入奖励目录，总装机容量421168.597千瓦。其中，海上风电项目1个（合计206400千瓦）、企业分布式光伏项目315个（合计205420.47千瓦）、居民分布式光伏项目839个（合计9348.127千瓦）。

二、关于已纳入专项资金奖励目录项目信息变更情况

经相关区发展改革委申请核实，对21个项目申请信息变更予以确认，其中：5个企业分布式光伏项目变更项目单位名称，15个居民分布式光伏项目变更用户名称，1个居民分布式光伏项目变更装机容量。

三、关于新增奖励目录项目奖励资金申报

按照7号文、14号文要求，请市电力公司及时做好奖励目录的电量统计和奖励资金申报工作，确保发电量数据、奖励时段、请款金额信息的准确。各区发展改革委做好项目的监督和管理，切实发挥专项资金的支持引导作用。

特此通知。
