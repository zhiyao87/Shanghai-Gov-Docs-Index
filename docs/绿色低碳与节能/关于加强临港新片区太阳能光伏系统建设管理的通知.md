# 关于加强临港新片区太阳能光伏系统建设管理的通知

关于加强临港新片区太阳能光伏系统建设管理的通知

沪自贸临管委〔2022〕83号

管委会各部门、各有关单位:

为推动临港新片区太阳能光伏系统在建筑中的应用，促进光伏系统与建筑的结合，规范太阳能光伏系统的设计，保证工程质量和系统高效发电，根据《中华人民共和国可再生能源法》、《光伏发电站设计规范》等相关法律法规和技术标准，梳理新片区太阳能光伏系统建设情况，现将有关要求通知如下：

一、适用对象

本通知适用于临港新片区产城融合区（431平方公里范围内）新建、改建和扩建的建筑光伏系统工程的设计、建设，主要使用对象包括在临港新片区范围的规划、建设、运营管理全过程中参与工作的政府管理部门、设计单位、开发单位和建设单位等。

新建、改建和扩建的建筑光伏发电系统应纳入建筑工程设计，统一规划，同步设计、同步施工、同步验收。

在既有的建筑上安装或改造太阳能光伏系统应按相关标准执行。

建筑光伏发电系统设计、施工除应符合本通知要求外，尚应符合国家、行业和上海市相关标准。

二、总体要求

依据《建筑光伏系统应用技术标准》（GBT51368-2019）、《上海市工程建设规范建筑太阳能光伏发电应用技术标准》（DGTJ08-2004B-2020）、《民用建筑太阳能光伏系统应用技术规范》（JGJ203）等，新片区太阳能光伏系统建设应遵循以下原则：

1、分区分类管理。

2、积极使用新材料、新技术，体现安全、高效。

3、集约、高效利用屋顶面积，应建尽建。

三、规划建设管理要求

（一）总体要求

临港新片区产城融合区工商业厂房，党政机关、学校和医院等公共建筑，公交场站和停车场等公共交通场所，公租房，需全面建设建筑光伏发电系统；鼓励符合建设条件的居民自建房场所，应建尽建。

（二）职责分工要求

管委会清洁能源领导小组全面负责新片区光伏工作。各处室按照职责分工各自负责推进建筑光伏发电系统建设。发改处负责项目备案，且建筑光伏一体化项目光伏部分应单独备案。规资处负责项目方案中涉及光伏架构的风貌和建筑规范性审核。对于政府财力建设学校及医院，由社发处协助，投资主体与学校、医院管理方协商建设太阳能光伏系统建设管理模式，原则上可由投资主体负责投资建设、运营维护。建交处负责项目建设总体推进，电力公司负责协调推进和指导建筑光伏发电系统大范围接入并网工作，管委会各部门和各镇按照各自职责，协同推进相关工作。

（三）安装比例要求

根据《上海市碳达峰实施方案》（沪府发[2022]7号）要求，2022年起，新建政府机关、学校、工业厂房等建筑屋顶安装光伏的面积比例不低于50%，其他类型公共建筑屋顶安装光伏的面积比例不低于30%，到2025年，公共机构、工业厂房建筑屋顶光伏覆盖率达到50%以上，到2030年，实现应装尽装。

各场景建筑总面积可安装光伏发电比例以第三方咨询机构评估结果为准。

（四）光伏组件要求

为提高发电效率，充分利用太阳光资源，建筑光伏发电系统采用的单晶硅、多晶硅等光伏组件初始效率不应低于21%。对于风貌管控有特殊要求的区域，推荐采用薄膜光伏、建材光伏、钙钛矿等新型光伏组件，且应兼顾组件效率。太阳能光伏系统整体发电效率不低于80%。

（五）设计施工要求

太阳能光伏系统规划设计应满足友好临港、生态临港和智慧临港整体基调，结构与布局与建筑物周边风貌保持一致，组件倾角设计和施工应统筹考虑太阳光最佳入射角度和建筑风格，光伏支架设计方案需综合考虑项目所在地的基本风压、雪压、光伏组件荷载等因素，作用效应组合的计算方法应符合《建筑结构荷载规范》（GB50009-2012）中第3条、第7条、第8条及现行国家标准、规范的相关要求，同时，对于存量建筑光伏项目，光伏支架设计以不破坏原有屋面结构，不破坏原有屋面的防水隔热层为原则。

临港地区建筑太阳能光伏发电系统抗风等级设计和施工应参考安装区域近50年最大风力等级。

（六）信息报送要求

为快速、有序推进临港新片区清洁能源发展，加强对太阳能光伏系统建设项目监管力度，太阳能光伏项目均需按程序完成备案，并在开工前30个工作日内向建设和交通管理处报送项目信息（见附表1）。项目取得电力公司出具的并网验收意见（并网型光伏系统）或竣工验收完成后（非并网型光伏系统）7个工作日内，至建设和交通管理处办理项目规模管理确认审批表（见附表2），同时提交项目主设备出厂合格证书、招标采购合同复印件、并网验收单、竣工验收意见（验视原件）。

（七）验收与生产评价要求

为保证太阳能光伏系统高效持续输出清洁电能，太阳能光伏发电项目应在竣工验收完成时向项目建设主管部门提交具备光伏发电系统检测资质的第三方出具的太阳能光伏系统运行效能评估与分析报告。进入运营期后，太阳能光伏发电项目需每年提交上一年度发电量证明材料，并基于光伏组件效率合理衰减范围区间，对于实际装机容量大于等于2兆瓦的太阳能光伏发电项目，需每五年进行一次系统效率检测，由行业主管部门组织评审，对不达标项目责令整改，电力公司负责督办。
