# 关于印发《关于加强宝山区农民相对集中居住住宅质量安全管控的管理办法》的通知

各有关单位：

为更好地推进我区农民相对集中居住工作，进一步提升我区相对集中居住住宅质量安全建设管理水平，根据《加强本市农民相对集中居住住宅质量安全管控的指导意见》（沪建村镇〔2021〕53号）等文件精神，我委制订了《关于加强宝山区农民相对集中居住住宅质量安全管控的管理办法》，现予以印发，请遵照执行。

特此通知。

上海市宝山区建设和管理委员会

2021年4月6日

关于加强宝山区农民相对集中居住住宅

质量安全管控的管理办法

第一条（政策依据）

为更好推进农民相对集中居住工作，全面提升我区进城镇集中居住的安置房和农村平移集中居住点的住宅建设水平，切实加强有关住宅质量安全管控工作，根据《中华人民共和国建筑法》、《上海市农村村民住房建设管理办法》（上海市人民政府令第16号）、《加强本市农民相对集中居住住宅质量安全管控的指导意见》（沪建村镇〔2021〕53号）、《宝山区农村村民住房建设管理规定》（宝规划资源〔2019〕83号）等有关法规和文件，结合本区实际，特制定本管理办法。

第二条（指导思想）

本区农民相对集中居住住宅建设在符合城市总体规划和乡村规划的基础上，分类实施、统筹推进，按照“高起点规划、高水平设计、高质量施工、高标准管理”要求，全面提升集中居住社区规划、建设、配套、服务等综合水平，加强项目建设的全过程监管，确保工程质量，消除安全隐患。

第三条（适用范围）

本办法适用于本区行政区域范围内的进城镇集中居住的新建安置房和农村平移集中居住点的新建住宅的质量安全管控工作。

进城镇集中居住，是指通过建设安置房形式将农户统一安置于城镇区内。

农村平移集中居住点，是指通过村内归并或跨村归并的形式将农户安置于农村规划集中居住点。

第四条（职责分工）

区规划资源行政管理部门负责本辖区内村民建房的规划、用地管理。

区建设行政管理部门负责本辖区内进城镇集中居住的安置房和农村平移集中居住点的建设活动行业管理，是本区进城镇集中居住项目质量安全管理的实施主体，指导、协调各相关镇对农民相对集中居住住宅质量和安全的监督管理。

各镇人民政府是本镇农民相对集中居住住宅质量安全管理的实施主体，落实部门和人员，定期开展安全检查，负责进行农户建房安全质量的现场指导和监督检查。各相关村委会配合镇政府，开展村内住宅日常巡查和保修，在村规民约中明确安全防护要求。

区农业农村委、区发展改革委、区生态环境局、区绿化市容局、区公安分局、区民政局等有关部门按照各自职责，协同实施本办法。

第五条（机构配置及队伍建设）

（一）机构配置

各相关镇要加强组织领导，明确分管负责人和监管机构，结合街镇（园区）建设工程专管员制度，配好配强农民相对集中居住建设工程质量、安全、文明施工等专业监管队伍，并落实相应的工作经费保障。

（二）队伍建设

各相关镇要加强农民相对集中居住建设工程监管队伍的日常管理和信息化建设，建立健全质量安全监管细则，明确检查标准、工作流程等，推进业务程序化、管理规范化和监督标准化。

（三）业务培训

区建设行政管理部门定期组织开展农民相对集中居住建设工程监管人员的工作例会和业务培训，逐步提高综合管理水平。

第六条（工程主体责任）

房屋产权人或项目建设单位要加强对农民相对集中居住建设工程的管理，并对建筑结构和消防安全等负责。建设单位依法对工程设计、勘察、施工安全质量负首要责任。设计、勘察、监理、施工等单位依法对建设工程设计、勘察和施工安全质量负主体责任。各参建单位从业人员依法对建设工程设计、勘察和施工安全质量承担相应的个人责任。

第七条（工程监管）

（一）进城镇集中居住

该类项目的工程建设要严格按照建设管理部门的基本建设程序进行，要引导有实力、资质等级较高、诚信度较高的企业参与安置房的建设工作，全面提升工程质量，防范质量通病。区建设管理部门按照《上海市建设工程质量和安全管理条例》负责监督与管理工作，加强质量安全监管，确保工程质量安全总体受控，确保安置房的建设工作按时有序推进。

（二）农村集中平移居住点

（1）由各镇统一建设的农村集中平移居住点项目，参照进城镇集中居住项目的建设程序，按相应规定进行勘察、设计、施工、监理单位的招标。区建设管理部门按照《上海市建设工程质量和安全管理条例》负责监督与管理工作，在设计环节应加强对农村住宅设计方案和农村整体风貌把关，形成施工图；在施工环节应加强对项目的指导监督，及时掌握工程进度，保证工程质量和安全；在验收环节应加强分户验收，未经验收或验收不合格的，不得交付农民使用。

（2）由农民委托建房的农村集中平移居住点住宅，各镇要加强对施工单位资质的审核，禁止无资质或超资质施工，出台总包单位名单供农民选择；工程开工前，农民应向工程所在区域的镇政府申请开工报告，各镇应认真做好工程相关资料台账登记工作；施工单位应成立项目管理机构，必须具有相应资质的项目管理人员，现场的安全、质量、材料管理人员必须取得相应资质；工程参建各方在施工过程中，应参照《住宅质量安全管控重点概述》，在施工现场明显位置张贴施工铭牌，明确施工参与各方负责人、联系电话以及管理部门和电话，接受相应监督；项目竣工后，由镇政府委托有关机构对工程进行验收，并做好项目竣工备案。

第八条（第三方委托）

由农民委托建房的农村集中平移居住点的新建住宅，其施工图设计文件审查、现场安全质量检查、工程质量等技术领域的，各相关镇可委托第三方专业机构协助工作，以第三方专业机构出具的意见作为日常监管的参考依据。

第九条（质量安全巡查）

区建设管理部门建立常态化质量安全巡查制度，落实相关责任部门，制定切实可行的巡查制度，对农民相对集中居住住宅质量安全管控工作定期组织开展质量安全巡查。对于检查中发现的问题，及时通知相关单位进行限期整改，并及时跟进整改情况。

第十条（投诉处理）

区建设管理部门负责进城镇集中居住的新建安置房和由各镇统一建设的农村集中平移居住点的新建住宅涉及质量安全的12345热线转办件和信访件的处理。

各镇负责由农民委托建房的农村集中平移居住点的新建住宅的12345热线转办件和信访件的处理。

第十一条（督查考核）

区建设管理部门负责牵头对各镇农民相对集中居住住宅质量安全管控工作进行督查考核，对相关镇重点考核开工信息报送、资料台账登记、监管实施细则、检查制度建立、问题整改回复以及质量安全投诉、信访处理等，考核结果将纳入区领导干部绩效考核。

第十二条（实施日期）

本办法自发布之日起实施，具体由宝山区建设和管理委员会负责解释。
