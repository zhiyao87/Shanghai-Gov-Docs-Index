# 关于进一步加强临港新片区征收安置住房项目建设和管理工作的通知

关于进一步加强临港新片区征收安置住房项目建设和管理工作的通知

沪自贸临管委〔2023〕40号

管委会各部门、各直属单位，临港新片区各镇、各开发公司、各有关单位:

为进一步提高新片区征收安置住房建设和管理水平，提升管理效能，根据《关于修订的通知》（沪房规范〔2021〕1号）、《关于加强区属征收安置住房建设和管理工作的若干意见》（沪房建管〔2021〕207号）等文件要求，对《临港新片区征收（动迁）安置住房项目建设管理实施意见》（沪自贸临管委〔2020〕324号）作补充完善，并通知如下：

一、建设管理要求

（一）资金专账核算。在管委会专户设立专账，用于核算临港新片区征收安置住房建设、供应、使用及管理等环节资金收支。

（二）加强资金管理。强化资金监管，提高资金使用效益，确保资金安全。建房协议价格、供应价格及其调整应经新片区住房保障领导小组审核确定；购房资金应及时上缴专户，资金拨付和结算应严格按照建设等协议进行，不得拖欠和超付。

（三）提升建设品质。明确征收安置房与普通商品住房同品质建设，严格落实《中国（上海）自由贸易试验区临港新片区高品质住宅建设管理大纲（试行）》要求，提升建设品质；确保项目周边市政、公建配套满足住宅交付使用要求。

（四）建设单位管理。开发建设单位试行短名单制，并动态更新；开发建设单位最低资本金比例不低于20%且最低资本金不低于购地资金。

（五）加强金融支持。鼓励银行等金融机构加大对开发建设单位的信贷支持力度，优化授信条件，降低融资成本。

二、房源管理要求

（六）加强统筹管理。强化安置房源统一管理和区域统筹使用，由住保中心统筹管理，按照房源高效使用原则，完善异镇安置政策，优化统筹使用方案。

（七）提升供需适配。各属地镇政府应加强需求排摸精度，提高征收安置房供需适配度，并作为临港新片区管委会对各镇年度考核的重要指标。

（八）强化供应管理。住保中心负责牵头制定统一的房源使用流程，规范房源调拨回购等环节。在房源具备供应条件（取得施工许可证）后，住保中心应督促项目建设单位与用房单位签订房源供应协议（或回购协议）；建设单位（或用房单位）应及时向住保中心报送房源供应信息，并按要求报市房屋管理局备案。

（九）盘活闲置房源。确因房型配比等问题闲置多年的未使用房源，按规定程序可转化为其他保障性住房或阶段性用作租赁住房；相关收益应及时收缴专户，专项用于保障性住房建设，提高资金使用效能。

三、信息化管理要求

（十）加快信息化建设。住保中心牵头加快建立完善临港新片区保障性住房房源管理信息系统，形成统一的房源数据库。

（十一）夯实台账管理。住保中心应会同相关部门及各镇政府、建设单位等，建立健全基础台账，为每套征收安置住房建档立卡，加强数据汇总和分析，实现全过程精细化管理。

四、其他

（十二）自通知发布之日起施行。
