# 黄浦区人民政府办公室关于印发黄浦区旧区改造和重大项目“十四五”规划的通知

区政府各委、局、办，各街道办事处：

《黄浦区旧区改造和重大项目“十四五”规划》已经区政府同意，现印发给你们，请认真按照执行。

特此通知。

上海市黄浦区人民政府办公室

2021年6月30日

黄浦区旧区改造和重大项目“十四五”规划

“十四五”时期,是全面深化“五个中心”建设、加快建设具有世界影响力的社会主义现代化国际大都市的关键时期，也是黄浦全面提升城区能级和核心竞争力、加快建设具有世界影响力的社会主义现代化国际大都市核心引领区的重要时期。根据《中共黄浦区委关于制定黄浦区国民经济和社会发展第十四个五年规划和二〇三五年远景目标的建议》和《上海市黄浦区国民经济和社会发展第十四个五年规划纲要和二〇三五年远景目标》关于加快推进旧区改造和重大项目建设的目标任务，编制本规划。

一、“十三五”规划总体完成情况

2016年以来，黄浦区旧改建设系统深入贯彻落实区委、区政府关于旧区改造和重大项目建设的总体决策，紧紧抓住城市更新重大机遇，全面落实并顺利完成旧区改造和重大项目专项规划中的各项目标任务，切实提升城市品质。

（一）总量目标顺利实现

“十三五”期间，全区聚焦对民生改善、社会经济发展有重要战略意义的旧改和建设项目，累计启动35个旧改项目，完成收尾31个项目，实现旧区改造受益居民超过5万户；着力推动20个重点商业商务功能性项目以及一批重大基础设施项目建设，累计竣工面积超过160万平方米。旧区改造和重大项目建设规划任务目标均圆满、超额完成。

（二）重点项目有序推进

1.旧区改造

启动项目方面，实现淮海中路130街坊、福佑北块、福佑中南块、546街坊、547街坊等10个土地储备项目启动生效；实现乔家路东块、乔家路西块、余庆里地块等7个政企合作项目启动生效；实现琴海苑、亚龙西块、亚龙东块、新昌路1号南块及7号地块等11个毛地项目启动生效。此外，还启动实施了72街坊、太仓路拓路、徽宁路拓路等社会事业项目。

收尾项目方面，完成董家渡18号地块、轨道交通14号线豫园站、豫泰确诚等31个项目的收尾工作。

2.重大建设项目

一是“一江一河”滨水区建设取得重大成效。黄浦滨江贯通工程全面竣工开放，苏州河3公里岸线西段、东段基本完工，黄浦江滨水区域形成慢行景观示范效应。

二是重点商业商务功能性项目加快推进。南外滩594/596地块、复兴地块、董家渡金融城项目部分楼宇竣工投产，淮海中路123/124/132地块、尚贤坊、160街坊等项目顺利开工，为优化城区功能布局、提升商业商务能级拓展了必要空间。

三是区域商业结构调整，城市空间进一步打开。南京东路东拓项目高质量建设，实现整体公共空间的高品质塑造，依托沿线产业功能提升，形成三大特色分区。

3.架空线入地和合杆整治

全区累计完成84条道路竣工，改造总长37.8公里，形成西藏路-复兴路-南北高架-南京路18余公顷无架空线示范区和外滩-南外滩-董家渡13余公顷无架空线示范区。

二、“十四五”期间推进形势

（一）旧改推进任务仍十分繁重

“十三五”期末，全区仍余留成片二级旧里地块39个，涉及房屋总量3万余户，主要集中在北京路、老城厢及周边、建国东路地区等3大区域中，既有密度极高的毛地，又有部分实施的停滞基地，情况十分复杂；同时，零星二级旧里改造也面临进一步提速；因此，从全市来看，黄浦依然是旧改任务最为繁重的中心城区，旧改推进任务异常艰巨。

（二）旧改关键问题需要不断聚焦

1.旧改项目筹资需要新举措。未来五年，资金仍将是制约旧改推进最为主要的瓶颈问题。一方面，在旧改规模和力度不断提升的背景下，财政资金保障压力愈发凸显；另一方面，毛地项目筹资难度也逐步加大。因此，投入旧改的资金方式和途径仍需创新和突破。

2.历史风貌保护进入新阶段。随着旧区改造的深入推进，如何传承历史风貌、实现保留保护建筑的活化利用则尤为重要。特别是黄浦四大风貌保护区内的旧改项目都有大量老旧建筑需要保护和利用。这些建筑既有文物建筑，也有优秀历史建筑，还有一般历史建筑，如何科学、合理的实施保留保护，需要不断研究、深化。

3.旧改可持续推进需要新突破。经过多年的开发建设，黄浦剩余可利用土地均为开发难度较大的地区，主要表现在房屋密度高、保留保护要求高。同时，随着全市房地产市场持续高位运行，房屋评估价格、安置房源供应价格大幅上扬，居民安置成本也有较大幅度增长，对旧改成本管控造成较大压力。因此，如何实现“综合平衡、动态平衡、长期平衡”，有效保障旧改可持续推进，仍需进一步深入研究。

（三）重大项目建设需要持续攻坚

“十四五”期间，我区重大项目推进仍然面临征收腾地、风貌保护、城市承受度、精细化管理、安全稳定等很多难题，需要通过结合规划功能定位、行政审批改革、施工现场监管等多方面入手，全力保障重大项目有序推进，统筹实现建筑、空间、环境以及城区基础设施协调发展，积极应对商业商务空间多元化供应，进一步提升空间形态和建设品质。

（四）主要机遇

1.黄浦面临进一步提升民生温度、创造高品质发展的重大契机。黄浦是承载上海核心功能的中心城区，“十四五”期间，将牢牢把握全市重点推动高质量发展、创造高品质生活两大方向，通过旧区改造、城市更新、低效用地退出等途径，提高全区地均产出比例，发挥投资的关键作用。坚持把旧区改造作为最大的民生、最大的发展，多渠道、多途径、多方式地改善市民群众居住条件，全力打赢旧改攻坚战。

2.工作方法的持续探索为旧改项目顺利推进奠定坚实基础。旧区改造既是民生工程，也是民心工程。近几年来，黄浦在旧改推进体制机制、管理模式上不断完善，政策口径和操作流程不断优化，队伍建设也在不断加强，阳光征收由点及面形成共识，依法行政进一步成为工作准则，这些都已成为旧改工作顺利推进和后续项目建设的坚实保障。

3.建设项目行政审批改革的不断深化促进了项目早开工、早建设。近年来，本市陆续出台相关政策文件，不断深化行政审批制度改革，从准入立项、用地管理、规划许可、开工手续、竣工验收和服务效能等方面提出了诸多加快推进重大项目建设的有效措施，使得建设项目前期工作周期进一步压缩，为建设项目尽早落地、尽早开工、尽早见效提供了强有力的支撑。

三、总体发展目标

（一）指导思想

“十四五”期间，黄浦将全面贯彻市委、市政府关于旧区改造各项工作要求，继续以“四个优先”（优先考虑居住条件、生活环境最差的地块，优先考虑与重点功能区建设直接相关地块，优先考虑市区重大建设项目，优先考虑毛地处置项目）为原则，以“四个坚持”（坚持以人为本、坚持规划引领、坚持多元参与、坚持品质为先）为指引，全面强化“四个统筹”（速度和质量相统筹，征收和改造相统筹，风貌和开发相统筹，投入和产出相统筹），全力打好旧区改造攻坚战，高质量推进重大项目建设。

（二）规划目标

1.任务目标。旧区改造方面，继续加强市区联手、政企合作，全面统筹平衡好资金、房源、队伍，确保到“十四五”期末前，全面完成本区二级以下旧里改造。商业商务项目方面，以“开工一批、推进一批、竣工一批”为抓手，实现竣工面积180万平方米。同时，架空线入地和合杆整治道路长度完成60公里。

2.形态目标。结合旧区改造的不断深化，继续加快推进重大市政工程以及重点功能区建设，黄浦区域范围内核心交通体系将基本构建完毕；一江一河景观功能将大幅提升；重点功能区将实现加速建设，南外滩与太平桥高端商务区将全面建成，老城厢及周边区域形态将基本确立，北京东路与建国东路地区更新将全面提速。

（三）重点工作

1.强化协调，努力推动重大工程项目建设

一是按照市轨道交通建设的总体安排，继续保障14号线黄浦区段建设进度，重点协调推进地铁结建的金陵路区域项目，确保轨交按期实现通车。届时，我区将全面完成8条地铁线路、18个地铁站点、37.5公里的轨道交通建设。

二是加快推进黄浦滨江建设，通过市区联手、政企合作推动浦西世博园区及周边地区整体规划和综合开发，释放更大空间，加快推进核心功能产业向滨水空间集聚。同时，继续推进滨江生态景观公共空间建设，实现董家渡景观花桥工程、会馆弄绿地、外萃丰弄绿地、新码头街绿地等滨江沿线绿地竣工。通过清退、改造、建设，进一步增加滨江沿线公共绿地，推动岸线的景观功能逐步向腹地延伸。

三是激发苏州河岸线活力，充分挖掘苏州河中段（乌镇路桥—河南路桥）沿线腹地的空间潜力，以135地块中央商务区泵站公园建设为契机，塑造大体量的特色公共空间，实现滨水岸线与腹地的联动提升，通过腹地的整体改造提升，使苏州河岸线具有文化、创新、科研、生活服务等更多元、更富活力的城市功能，进一步扩大苏州河沿岸的辐射力和影响力。

同时，按照管建并举、管理为重、安全为先的方针，完善重大项目和重点功能区建设推进机制。

2.聚焦重点，着力推进功能区联动拓展

深入结合“三带两轴四组团”的总体规划建设，明确区域定位，重点聚焦北部片区战略性区域和豫园-南外滩增长极。全面打通豫园与外滩的联系，全面实现北京东路区域以及淮海中路西段的旧区改造及重大项目建设，充分发挥区域历史文化价值，挖掘区域商业、文化、旅游及科研产业发展的基础要素，重现街区商旅文融合发展的活力。

3.多策并举，探索创新改善民生新途径

除了加快成片征收，还将聚焦零星旧里、风貌保护街坊，注重因地制宜、多策并举，综合运用拆落地重建、抽户改造等方式，千方百计改善居民居住条件。同时，将继续按照“政府主导、国企实施、分步推进”的思路，全力推进外滩“第二立面”的城市更新和功能重塑工作，通过市区联手、市场化运作，加快推进沿线项目的功能置换和更新改造，以点带面推动外滩“第二立面”整体形象和功能提升。

4.打造标杆，创建无架空线示范区

以城市精细化管理为导向，按照“以点连线、延伸成片、连片成面”的原则，聚焦一带四组团为核心的城市发展重点区域和新开发地块同步实施架空线入地和合杆整治，基本实现主次干道架空线全部入地，合杆全覆盖。聚焦创建无架空线全要素整治示范区，打造完成环人民广场-新天地区域18公顷、环南外滩-豫园区域13公顷的无架空线全要素整治示范区。

5.发挥合力，稳妥推进社会事业项目

结合本区教育、市政等部门“十四五”总体发展规划，重点推进一批学校新建、改扩建、道路拓宽项目的开工建设。

四、主要保障措施

（一）优化体制机制，有效增强推进合力

加强统筹，力争调动一切有利因素，增强推进合力。一方面，为更好、更快地适应本区新一轮旧改加速推进，对旧改领导体制、推进机制进一步予以调整充实强化，全面构建领导小组-旧改办-项目部-事务所四级联动推进的组织架构，共同保障旧改工作顺利推进。另一方面，进一步加强重大项目工作领导小组的统筹决策功能，紧紧围绕行政审批改革的总体方向，强化重大办的协调、督促工作机制，进一步坚持条块结合，全面提升项目建设推进的速度、质量。

（二）坚持依靠群众，全力提升服务能力

近年来，我区在信息化、规范化、制度化方面，不断完善、不断深化，已经形成了一整套的操作规范、工作标准和管理制度，为旧改依法合规、高效平稳推进提供有力支撑。一是广泛发动，夯实群众参与基础。坚持以提升送达率、知晓率为工作要求，依托多种渠道，广泛发动群众、依靠群众，全面提升群众参与度；通过座谈会、听证会等多种方式，充分听取群众意见，保障旧改征收工作向着更加规范、更加专业、更加高效的方向推进。二是加强监督，确保阳光透明公开。通过成立由党员代表、人大代表、政协委员、律师组成的人民调解工作站，从第三方的公正立场为居民群众提供政策解释、人民调解及法律咨询服务；同时，通过社会公信人士提前介入、全程监督，确保政策前后一致，确保公开公平公正。三是规范为先，强化队伍建设管理。进一步严格工作纪律、强化责任落实，通过多种形式的培训，努力提升队伍业务能力，打造一支结构合理、能力突出、纪律严明的旧改工作队伍。

（三）强化党建引领，实现高质量推进

在旧改推进过程中形成“党建联席会议+临时党支部”的党建工作架构，并设立专项小组直接面对居民，及时搭建沟通平台化解各类矛盾，切实做到将广大群众对改善居住条件的殷切期盼转化为对旧改工作的支持和认同。同时，注重发挥好支部战斗堡垒和党员先锋模范作用，建立由居民区和征收事务所工作人员为骨干的党员先锋队，聚焦群众关心关注的重点难点问题，有针对性地把居民需求转变成政策框架许可下的实在举措。

（四）深化思路创新，全面推动瓶颈突破

政策方面，始终要充分听取群众意见，认真分析、研判，在保持旧改政策持续性的基础上，不断有针对性的进行调整和优化，努力提高政策的覆盖面、适应性。资金方面，既要更加合理的做好资金调配管理工作，提高资金周转使用效率，也要继续推进社会资金管控，千方百计协调各开发企业到位资金，保障项目有序推进。房源方面，进一步强化安置房源规范管理，坚持政策导向，全面提升安置房源的使用水平和周转效率，努力实现安置结构更加合理、更加均衡。毛地方面，继续以“一地一方案”为抓手，强化协调沟通，找准有效切入点，多策并举、高质量完成毛地项目开发、建设。

（五）加强推进管理，全力保障安全稳定

一是要坚持推进与稳定并重，既要保持高速推进，又要不放松对历年遗留矛盾、新增信访矛盾的梳理化解工作。二是要进一步明确职责，坚持一岗双责，坚持“谁实施、谁负责”，认真推进责任下沉，充分落实各相关征收事务所、建设单位的主体责任；三是要进一步强化在拆、停滞基地、在建工地的安全管理工作，确保不发生重大安全生产事故。
