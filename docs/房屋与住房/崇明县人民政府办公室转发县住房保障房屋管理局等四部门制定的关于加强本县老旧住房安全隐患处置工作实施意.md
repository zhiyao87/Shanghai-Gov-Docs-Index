# 崇明县人民政府办公室转发县住房保障房屋管理局等四部门制定的关于加强本县老旧住房安全隐患处置工作实施意见的通知

各乡、镇人民政府，县政府各委、办、局，县各直属单位，在崇市属有关部门：

县住房保障房屋管理局、县建设交通委、县财政局、县规划土地局制定的《关于加强本县老旧住房安全隐患处置工作的实施意见》已经县政府同意，现转发给你们，请认真按照执行。

2015年1月5日

关于加强本县老旧住房安全隐患处置工作的实施意见

老旧住房的安全关系到人民群众的生命、财产安全，是城市公共安全和运行安全的重要内容。为加强本县老旧住房安全管理，坚决防止房屋安全恶性事故发生，根据《市住房保障房屋管理局等五部门关于加强本市老旧住房安全隐患处置工作实施意见的通知》（沪府办发〔2014〕52号）的相关要求，结合本县老旧住房安全排查情况，现就加强本县老旧住房安全隐患处置工作提出如下实施意见。

一、总体要求

按照《城市危险房屋管理规定》（建设部令第4号）、《住房城乡建设部关于组织开展全国老楼危楼安全排查工作的通知》（建办电〔2014〕7号）等规定，根据本县老旧住房安全排查情况，以“分清原因、分类指导、属地解决、确保安全”为原则，采取切实有力处置措施，排除本县老旧住房安全隐患，杜绝房屋安全恶性事故，保护人民群众生命、财产安全，维护社会和谐稳定。

二、工作目标

（一）在已对本县老旧住房开展安全排查的基础上，2015年3月底前，完成对严重损坏房屋的检查和处置实施方案的制定等工作。

（二）2015年年底前，全面实施对排查发现的严重损坏房屋的处置整改，力争2016年年底前完成。

（三）“十三五”期间，全面完成对排查发现的一般损坏房屋的处置整改。

三、组织领导

成立崇明县老旧住房安全隐患处置工作领导小组（以下简称“领导小组”），成员单位包括县住房保障房屋管理局、县发展改革委、县建设交通委、县财政局、县规划土地局、各乡镇政府及各系统公房产权单位。领导小组负责本县老旧住房安全隐患处置工作的相关政策制定、部门间综合协调、处置责任落实、处置整改方案认定、重大项目或事项会商及监督考核等工作。领导小组下设办公室，设在县住房保障房屋管理局，各成员单位派员参加，具体负责工作推进和落实。

四、分类推进

各乡镇政府按“属地管理”原则，做好辖区内老旧住房安全隐患处置整改工作。县各相关职能部门在领导小组的协调和上级主管部门的指导下，做好分类推进工作。

（一）对房屋年久失修、自然老化、接近或者超过使用年限等原因引起损坏的房屋，由县住房保障房屋管理局指导进行后续处置。

（二）对由于周边道路等基础设施建设引起损坏的房屋，由县建设交通委协助明确侵权责任人并进行后续处置。

（三）对由于其他建设工程、房屋施工质量等原因引起损坏的房屋，由县建设交通委协助明确侵权责任人并进行后续处置；

（四）对疑难房屋或存在责任交叉不清的老旧房屋，经领导小组会商确定牵头职能部门进行后续处置。

五、处置方式

（一）开展房屋安全检测鉴定工作

县住房保障房屋管理局对此次排查中存在危险隐患的老旧住房，根据专业检测单位的评估意见，督促房屋产权人（或委托管理人）、使用人委托专业单位进行房屋安全检测，对经检测结论为危房（局部危房）的，由检测单位报请市住房保障房屋管理局组织市房屋检测技术委员会专家进行技术审定。

（二）坚持分级处置落实

1.经初步排查发现存在损坏的直管公房，由县住房保障房屋管理局负责后续处置整改工作。

2.经初步排查发现存在损坏的售后公房、系统公房，由房屋所在乡镇政府进行现场调查摸底（如征询业主改造意愿、确认房屋权属等），制定改造方案，于每年10月份报县住房保障房屋管理局，统筹后列入下一年度修缮改造计划，由所在乡镇政府根据《上海市住宅修缮工程管理办法》（沪府办〔2013〕69号）规定，办理县发展改革委审批等相关手续并负责房屋修缮的具体实施工作。

3.经初步排查发现存在损坏的宿舍、小产权房、村民集资房，由房屋所在乡镇政府进行现场调查摸底（如征询业主改造意愿、确认房屋权属等），协调相关产权单位（或产权人）制定改造方案，于每年10月份报县住房保障房屋管理局，统筹后列入下一年度修缮改造计划，由所在乡镇人民政府根据《上海市住宅修缮工程管理办法》（沪府办〔2013〕69号）规定，办理县发展改革委审批等相关手续并负责房屋修缮的具体实施工作。

4.经初步排查发现存在损坏的私房、商品房，由房屋所在乡镇政府督促产权人进行后续处置整改工作。

（三）加强安全管理和巡查工作

各乡镇政府对确定的危险房屋及时制定汛期等极端气候条件下人员避险应急预案，落实专人负责，坚决杜绝房屋坍塌、伤人等事故发生。对存在消防安全隐患的老旧住房，制定针对性防范措施，配合消防部门做好火灾防控工作。同时，对此次排查中未发现隐患的老旧住房，也要进一步加强巡查，及时发现问题并进行处置。

六、分析原因，明确责任

按照“谁的房子谁负责、谁造成的原因谁负责”原则，坚持“区分责任、区分产权、区分危险程度”，根据房屋安全检查鉴定结论，认真分析隐患产生原因，明确相关责任单位并落实处置资金。

（一）对市政道路、公共设施以及其他建设工程引起的房屋安全后续整改处置费用，由侵权人或责任人负责。

（二）对经鉴定认定由原施工质量问题引起的房屋安全后续整改处置费用，由原建设、施工单位负责。

（三）对因单位、居民违法建设引起的房屋安全后续整改处置费用，由违法人承担后续处置费用。

（四）对因自身老化、年久失修等原因引起的后续整改处置费用，由房屋业主承担后续处置费用。

（五）对责任人不明确或无力承担，建设、施工等单位无法追溯的，经领导小组研究会商后，明确后续处置方案。
