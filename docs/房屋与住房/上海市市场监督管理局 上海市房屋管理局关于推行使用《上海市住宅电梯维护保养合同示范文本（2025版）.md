# 上海市市场监督管理局 上海市房屋管理局关于推行使用《上海市住宅电梯维护保养合同示范文本（2025版）》的通知

上海市市场监督管理局 上海市房屋管理局关于推行使用《上海市住宅电梯维护保养合同示范文本（2025版）》的通知

各区市场监管局、住房保障房屋管理局，临港新片区市场监管局，市市场监管局机场分局，各有关单位：

为规范本市住宅电梯维护保养工作，厘清电梯使用管理单位与维护保养单位的权利义务，促进电梯维护保养行业健康有序发展，根据《中华人民共和国民法典》《中华人民共和国特种设备安全法》《上海市电梯安全管理办法》等法律法规以及特种设备安全技术规范的规定，上海市市场监督管理局、上海市房屋管理局制定了《上海市住宅电梯维护保养合同示范文本（2025版）》，并于2025年10月1日起在全市范围推行使用。现就有关事项通知如下：

一、2025年10月1日起，在本市住宅电梯维护保养项目中，当事人均可使用《上海市住宅电梯维护保养合同示范文本（2025版）》，也可参照《上海市住宅电梯维护保养合同示范文本（2025版）》自行制定合同文本。

二、各单位要做好《上海市住宅电梯维护保养合同示范文本（2025版）》的宣传和推行使用等工作，向住宅小区业主大会、业主委员会、物业服务企业、电梯维护保养单位宣贯相关法律法规和政策规定要求，引导使用合同示范文本，就住宅小区电梯运维管理事项进行约定。

三、《上海市住宅电梯维护保养合同示范文本（2025版）》通过上海市市场监督管理局网站（http://scjgj.sh.gov.cn/）和上海市房屋管理局网站（http://fgj.sh.gov.cn/）予以公布。

四、《上海市住宅电梯维护保养合同示范文本（2025版）》由上海市市场监督管理局、上海市房屋管理局联合制定，任何单位和个人不得出于商业目的擅自翻印和出售。在未制定新的版本前，本版本延续使用。
