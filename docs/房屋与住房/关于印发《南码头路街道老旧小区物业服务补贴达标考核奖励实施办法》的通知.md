# 关于印发《南码头路街道老旧小区物业服务补贴达标考核奖励实施办法》的通知

各相关职能部门、各居委会、各物业服务企业：

现将《南码头路街道老旧小区物业服务补贴达标考核奖励实施办法》印发给你们，请认真遵照执行。

特此通知。

上海市浦东新区人民政府南码头路街道办事处

2025年7月18日

南码头路街道老旧小区物业服务补贴达标

考核奖励实施办法

为进一步提高南码头路街道老旧小区物业服务工作，规范物业服务行为，切实改善广大业主居住环境，根据《浦东新区老旧住宅小区物业服务补贴达标考核奖励实施意见》(浦建委物管〔2023〕2号)，并结合南码头路街道实际，现制定本实施办法。

一、补贴范围

(一)南码头路街道范围内的售后房(包括直管公房和系统公房)小区;

(二)南码头路街道范围内按照1991年《上海市城市房屋拆迁管理实施细则》安置的早期动迁房小区;

(三)南码头路街道范围内发生可能影响公共安全、社会稳定、对外形象等突发性事件的住宅小区。

二、考核标准

以提供保障型的物业管理服务为基本原则，申请达标补贴的物业服务企业提供的物业管理服务必须同时达到以下标准：

(一)履行物业管理服务合同的约定;

(二)符合国家和本市规定的相关技术标准、服务规范;

(三)及时向业主、使用人告知安全合理使用物业的注意事项;

(四)定期听取业主的意见和建议，改进和完善服务;

(五)配合居民区党组织和居民委员会做好社区管理相关工作;

(六)符合《浦东新区老旧住宅小区物业服务达标基本标准》和《上海市住宅物业管理服务规范》(DB31/T000-2018)基本规范和一级服务规范。

物业服务达标基本标准按照合理、必须、基本的原则。上述标准中，合同约定的部分项目服务标准高于其它规定标准的，按合同约定的标准执行。

各物业服务企业要加强对物业服务达标基本标准的学习和宣传，切实做好保安、保洁、保绿、保修以及综合管理和设施设备管理等服务，为保障小区公共秩序、公共卫生和公共安全奠定良好的基础。

三、考核原则

物业服务达标考核工作应当遵循公正、公平、公开的基本原则，考核工作每季度一次，根据考核结果按季拨付补贴资金。对于辖区内物业管理产业面积不足3万平方米的物业服务企业原则上不再予以补贴。

四、考核方式

考核工作按照“街镇统筹、房办操作、业主参与”的要求，以定期考核与日常检查相结合的方式，由第三方、房管办和居民区实行三方独立测评考核。第三方考核由街道委托第三方专业机构进行，每季度开展物业服务质量测评。房管办考核由房管办负责，每月实地测评小区，三个月平均值作为房管办考核分。居民区考核由居民区党组织牵头居委会、业委会等共同参与，每季度参照测评表内容，对相关小区物业服务工作做出评价。三方独立测评后，由房管办对三方考核情况按季度进行汇总。

分值计算为：第三方考核分×50%+房管办考核分×30%+居民区考核分×20%。

根据考核分值核定考核等级，考核等级分为“优秀、达标、基本达标、不达标”四个等级。

(一)考核为“优秀(86-100分)”的住宅小区，按照基本补贴资金总额予以全额补贴，并按照基本补贴资金20%的标准实施奖励;

(二)考核为“达标(71-85分)”的住宅小区，按照基本补贴资金总额予以全额补贴;

(三)考核为“基本达标(60-70分)”的住宅小区，按照基本补贴资金总额的70%予以补贴;

(四)考核为“不达标(59分及以下)”的住宅小区，不予补贴。

五、补贴标准及补贴用途

老旧小区基本达标补贴资金的标准为：0.25元/平方米·月(考核“优秀”为0.30元/平方米·月、考核“达标”为0.25元/平方米·月、考核“基本达标”为0.175元/平方米·月)。

基本补贴资金按照预算执行要求，按季度拨付至物业服务企业账户。基本补贴资金结余部分纳入街道统筹补贴资金中支出，且年度基本补贴考核结余不得超过全年基本补贴资金的3%。

物业服务企业应当建立健全企业财务制度，严格执行补贴资金专款专用，必须用于补贴小区保安、保洁、保修、保绿、综合管理及公用设施设备维护等服务成本的支出。

六、重大事件考核细则

(一)物业服务企业、物业项目经理在本区域的管理项目被职能部门记分的，以记分的相应分值在下一季度分值中直接扣减，一个考核周期内多部门、多次扣分的累计计算。

(二)在全国、市、区新闻媒体或短视频平台中出现负面报道，且物业管理单位确有责任的，取消该小区半年补贴。

(三)因物业服务企业严重不负责、不按合同约定及行业规定实施管理，引发重大安全责任事故或群体性事件的，取消该小区半年补贴。

(四)影响文明社区、垃圾分类等街镇、区、市重点创建工作，造成重大不良后果的，取消该小区半年补贴。

(五)街道每年委托第三方审计机构，对享受区级达标补贴的物业服务企业上年度补贴资金使用情况作出评价。针对审计意见中的问题，责令限时整改，严重者通报批评、取消下一年度补贴资格。第(二)(三)(四)项如发生在第三、四季度的，取消半年补贴顺延至次年。连续发生两次或年度内发生两次以上(含本数)取消该小区半年补贴情形的，取消下一年度补贴资格。

七、街道统筹补贴资金的组成和使用

街道统筹补贴资金由基本补贴资金“差别化”结余部分和区考核奖励资金组成，主要用于提升老旧住宅小区物业服务水平，专项审计费用，补贴老旧小区保洁保安等专业化管理成效明显小区，补贴老旧小区垃圾分类成效显著小区，补贴一般性基础设施的改造提升，以及辖区内住宅小区涉及公共安全、社会稳定的民生保障类突发性应急事件处置，对辖区内提升物业服务成效显著、考核优秀的物业服务企业和住宅小区项目给予激励嘉奖。

八、其他

物业规范托底小区(含动迁房小区、托管小区、1.5万平方米以下的零星小区)补贴考核方式及补贴标准参照本方案执行(补贴资金另行支出)。

本办法自2025年10月1日起实施，有效期至2028年9月30日。本办法实施过程中，如上级部门发布新规定、调整相关标准，按上级文件执行。

本办法由南码头路街道办事处负责解释。
