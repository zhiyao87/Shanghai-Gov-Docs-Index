# 上海市住房和城乡建设管理委员会关于批准《预制拼装桥梁结构标准设计图》为上海市建筑标准设计的通知

上海市住房和城乡建设管理委员会关于批准《预制拼装桥梁结构标准设计图》为上海市建筑标准设计的通知

沪建标定〔2022〕85号

各有关单位：

由上海市城市建设设计研究总院主编的《预制拼装桥梁结构标准设计图》，经我委审核，现批准为上海市建筑标准设计，统一编号为DBJT08-135-2022，图集号为2022沪Q002,自2022年7月1日起实施。

本标准设计由上海市住房和城乡建设管理委员会负责管理，上海市城市建设设计研究总院负责解释。

2022年1月29日
