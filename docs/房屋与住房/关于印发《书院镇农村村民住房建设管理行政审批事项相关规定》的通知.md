# 关于印发《书院镇农村村民住房建设管理行政审批事项相关规定》的通知

机关各科室及各村委：

《书院镇农村村民住房建设管理行政审批事项相关规定(修订版)》已经镇政府同意，现予印发，请认真贯彻执行。

特此通知。

浦东新区书院镇人民政府

2025年10月9日

书院镇农村村民住房建设管理行政审批事项相关规定(修订版)

为加强书院镇农村村民住房建设和宅基地管理工作，规范农村村民建房秩序，保护农村村民合法权益，推进乡村振兴战略实施，根据浦府规〔2021〕5号《浦东新区农村村民住房建设管理实施细则》文件规定，结合书院镇的实际，对符合申请建房审批条件的农村村民，制定本规定。

一、审批制度

农村村民住房建设管理实行联席会议制度，联席会议由以下部门组成：镇规划建设和生态环境办公室(以下简称“ 规建办”)、镇城市建设管理事务中心(以下简称“ 城建中心”)、镇农业农村发展办公室(以下简称“ 农发办”)、镇经济发展服务中心(以下简称“ 经发中心”)。

其中：镇规建办为牵头部门，城建中心集中受理村民委员会报送的书面申请等材料，并负责将建房申请材料在审核部门间流转以及审核通过后上报批准等工作流程。

二、审批流程

(一)村级审查流程

1.受理

符合宅基地申请条件的农户或者对原有住房进行改建、翻建和易地新建的，应向所在地村民委员会提出宅基地和书面建房申请。

2.初审

村民委员会接到书面申请后，应对申请人主体资格、成员人数及其他建房条件进行初步审查。

3.张榜公布

初审通过后，应当在村务公开栏内将农户成员人数、建房位置等相关信息张榜公布，公布期限不少于30日。

4.报送和异议处理

公布期间无异议的，申请人填写《浦东新区农村宅基地和建房(规划许可)申请表》, 村民委员会签署认定意见(资格和人口数量)后，连同建房申请人的书面申请和宅基地使用承诺书等，通过上海市农村宅基地信息管理系统报送至镇级审核。公布期间有异议的，村民委员会应当召集村民会议或者村民代表会议讨论决定。

(二)镇级审批流程

由镇农发办、经发中心、规建办、城建中心等部门分别审核以下内容：

1.镇农发办和经发中心审核内容

(1)审核申请人和用地人数是否符合申请资格条件，是否有在本市他处已计入批准建房用地人数的人员，或者因宅基地征收(拆迁)、农民相对集中居住等已享受补偿安置的人员等情况，审定农户建房人数。

(2)宅基地和建房申请等相关信息村务公开公示程序是否履行到位。

(3)其他需要审核的内容。

2.城建中心审核内容

(1)申请用地是否符合宅基地合理布局条件。

(2)用地建房是否符合书院镇郊野单元规划的条件。

(3)用地面积标准。

(4)其他需要审核的内容。

3.镇规建办审核内容

(1)建房图纸是否符合法定要求。建造两层或者两层以上住房的，应当使用具备资质的设计单位设计或经其审核的施工图纸，或者免费使用市住房城乡建设行政管理部门推荐的通用图纸。

(2)房屋结构是否符合安全标准。

(3)建筑形态是否符合本地区风貌管控要求等。

(4)建筑面积标准。

(5)其他需要审核的内容。

4.联席会议审核

由镇规建办召开联席会议对建房申请以及各项审核内容进行综合评审。

5.审批决定

(1)综合评审通过后，由城建中心报镇人民政府审批，镇人民政府对农户宅基地和建房申请做出审批决定。

(2)审批后，由规建办合并发放农村宅基地批准文件和乡村建设规划许可证。

6.审批时限

镇人民政府在接到村民委员会报送的建房申请人的书面申请之日起30日内完成审批。审批不通过的，在规定时限内出具退件单，将全部材料退回村民委员会， 由村民委员会将退件单及全部申请材料退交申请人。

三、相关标准

(一)用地面积、建筑面积标准

农户建房的用地面积、建筑面积按照下列规定计算：

1.用地面积标准：1人户的宅基地总面积控制在60平方米以内;5人户及5人以下户的宅基地面积不超过140平方米;6人户及6人以上户的宅基地面积不超过160平方米。

2.建筑面积标准：农村村民申请建房以户为单位，每户中按每人不超过45平方米建筑面积总体控制，具体核准面积需结合地块周边情况综合审定。其中，1人户建筑占地面积控制在45平方米以内;5人户及5人以下户建筑占地面积不超过90平方米、建筑面积不超过225平方米;6人户及6人以上户建筑占地面积不超过100平方米、6人户的建筑面积不超过270平方米，家庭人数超过6人的，每增加1人，可以增加建筑面积20平方米。

(二)建筑占地面积的计算标准

农户建房的建筑占地面积按照下列规定计算：

1.室外有顶盖、有立柱的走廊的建筑占地面积，按立柱外边线水平面积计算;

2.有立柱的阳台、内阳台、平台的建筑占地面积，按立柱外边线或者墙体外边线水平面积计算;

3.立柱、无顶盖的室外走道和无立柱的阳台不计建筑占地面积，但不得超过批准的宅基地范围。

(三)用地人数的计算方法

农户申请建房用地的人数，符合下列条件之一的人员，可计算人数。

1.实行家庭联产承包责任制以来享有土地承包经营权，具有书院镇农业户口且户口、生产生活在本村的集体经济组织成员;

2.具有本市农业户口，且因合法的婚姻、收养关系户口迁入本村的集体经济组织成员;

3.具有本市农业户口，且根据国家移民政策户口迁入本村的集体经济组织成员;

4.2001年1月1日以后出生，父母至少一方为农业户口的本集体经济组织成员，其本人城镇居民户口地址以及生产、生活在本村的人员，可以计入户内;

5.领取本市《独生子女父母光荣证》(或者《独生子女证》)的独生子女，按2人计算;2016年1月1日以后出生的独生子女，父母至少一方持有《独生子女父母光荣证》(或者《独生子女证》)且为农业户口的，按2人计算;

6.户口暂时迁出的现役军人(武警)、在校学生、服刑人员，可以计入户内;

7.符合区人民政府规定的其他人员，可以计入户内;

8.农户内在本市他处已计入批准建房用地人数的人员，或者因宅基地征收(拆迁)、农民相对集中居住等已享受补偿安置的人员，不得计入用地人数。

四、建立管理台账

宅基地用地、建房审批完成后，将相关资料一式四份归档留案，并在批准之日起15日内，将审批情况分别上报区农业农村、规划资源行政管理部门备案。

五、审批结果的公布

经审批符合条件同意新建房屋(含翻建等)的，镇人民政府将农户建房的审批结果张榜公布，时间不少于30日，接受群众监督。公布期间有异议的，镇人民政府在5个工作日内对该户申请进行复核，并根据复核结果进行相应处理。

六、批后监管

(一)开工申请

经批准利用宅基地建房的农户，应当在取得农村宅基地批准文件和乡村建设规划许可证之日起一个月内确定开工日期，并在开工前向镇人民政府申请划定宅基地范围。镇人民政府在接到农户申请后5个工作日内，由镇规建办组织城建中心、精细办“五违”条线、第三方技术单位及该村民房专管员到现场查验，丈量划定宅基地，确定宅基地内建筑物的平面位置、层数、高度和风貌。农户应当严格按照乡村建设规划许可证、施工图纸等的要求进行施工。

(二)质量和安全监督

农户应当与施工队伍签订建房协议，并约定质量和安全责任。镇人民政府应当落实质量安全专管人员对农户建房实质量和安全监督，也可以委托符合条件的第三方质量安全管理机构实施质量和安全监督。

(三)配套设施

镇人民政府应当配套完善农村居民点内道路、路灯、污水 处理、生活垃圾分类处置、通讯等设施。农户建房应当按《上海市排水与污水处理条例》规定配建相应设施。

(四)竣工期限

镇人民政府在审核发放乡村建设规划许可证时，应当核定竣工期限。竣工期限一般为1年，最长不超过2年。

(五)竣工验收

农户建房完工后，应当向镇人民政府申请验收。镇人民政府在接到农户申请后5个工作日内，由镇规建办组织城建中心 、精细办“五违”条线及该村民房专管员进行实地验收并出具书面验收意见。经验收合格的，镇人民政府在15日内，将相关验收情况分别报区农业农村、规划资源和建设行政管理部门备案。同时把验收数据上传至上海市农村宅基地信息管理系统。

七、其他事项

(一)本规定由书院镇人民政府负责解释。

(二)本规定自2025年11月1日起施行，有效期2年。如上级有新的相关规定，根据新规定执行。
