# 上海市嘉定区人民政府办公室关于转发《嘉定区限额以下小型房屋建筑工程安全生产管理的实施细则》的通知

各镇人民政府，区政府各委，办，局，街道办事处，嘉定工业区，菊园新区管委会：

区建设管理委拟定的《嘉定区限额以下小型房屋建筑工程安全生产管理的实施细则》已经区政府同意，现转发给你们，请认真按照执行。

上海市嘉定区人民政府办公室

2026年1月8日

嘉定区限额以下小型房屋建筑工程安全生产管理的实施细则

为进一步提升全区建设领域整体管理水平，加强限额以下小型房屋建筑工程安全监管，明确属地监管责任，形成合力、补齐短板，根据《上海市限额以下小型房屋建筑工程安全生产管理办法》（沪府办规〔2025〕12号），结合我区实际，特制定本实施细则。

一、适用范围

本细则所称限额以下小型房屋建筑工程（以下简称“小型房建工程”）指按照规定可不申请办理施工许可证的工程投资额在100万元以下且建筑面积在300平方米以下的既有建筑装饰装修工程（含原装饰装修内容拆除）和工程投资额在100万元以下的房屋建筑工程。

住宅装饰装修、临时性房屋建筑、农民自建低层住宅、抢险救灾工程、军事建设工程、文物及优秀历史保护建筑修缮装修工程和拆房、市政公路、水务、园林绿化等其他由建设行政管理部门直接监督管理的工程按照有关规定执行，不适用本办法。

二、职责分工

（一）部门及属地职责

在区政府组织领导下，按照“属地管理、分级负责、条块联动、社会共治”的原则，各部门、各街镇应依托上海市限额以下小型房屋建筑工程信息管理系统（以下简称“小型房建工程信息系统”），切实履行行业指导和属地监管职责，具体分工如下。

1.嘉定区建设和管理委员会（以下简称区建管委）作为区级建设行政管理部门，负责本区报监建设工程监督管理，依法对接报或发现的无证施工等职责范围内有关违法违规行为进行查处，组织开展街镇监管人员业务培训，协调指导街镇对小型房建工程实施安全监管并对工作落实情况开展督导检查。

2.嘉定区住房保障和房屋管理局（以下简称区房管局）负责全区房屋使用安全的综合监督管理工作。

3.区商务、教育、民政、规资、卫健、应急、国资、体育、机管、消防、城管及其他有关行业、专业主管部门或综合监管部门按照职责分工，加强各行业领域小型房建工程安全管理，指导督促相关单位做好安全生产工作。区建管、绿容、消防、城管等各有关管理部门按照职责分工，指导街镇依法对小型房建工程违法违规行为进行查处，对超出街镇执法权限的违法违规行为及时查处。

4.各街镇承担属地监管责任，负责细化管理机制，建立监管台账；对小型房建工程实施全过程安全生产管理和无证施工行为排查，定期上报小型房建工程清单；按要求上报疑似无证施工项目信息；受理有关疑似无证施工和小型房建工程违法违规行为和安全隐患投诉、举报，及时核查处理。

（二）参建单位责任

业主（指房屋所有权人）负有使用安全责任，自行或授权建设单位登录小型房建工程信息系统，进行小型房建工程备案。建设单位（指投资进行小型房建工程建设的单位或个人）负首要责任，施工单位负主体责任。业主、建设单位、施工单位应严格落实各项安全措施，各方的安全责任不因出租、外包、承包等合同约定而转移。

三、属地管理要求

（一）建立“三个一”管理机制。各街镇要建立“一套规则”，根据市区文件细化形成属地非报监小项目管理办法，建立责任清晰、分工明确的工作制度，规范小型房建工程监管流程，明确属地部门考核标准；要建立“一支队伍”，整合城建部门、基层网格、基层执法等力量，形成一支稳定的监管队伍，并组织监管人员参加建设工程管理培训，考取相关管理资质，鼓励通过购买第三方服务等方式提升专业技术能力；要形成“一个体系”，打通城建部门、基层网格、基层执法之间的壁垒，形成整体联动的管理体系，实现信息共享、响应迅速、处置高效。

（二）强化排查备案管理。各街镇要充分运用网格力量和智慧化监管手段，对辖区内全数房屋建筑工程定期开展排查，对未按要求备案的小型房建工程发放管理职责清单和备案指引并进行备案登记，备案后发放登记回执，督促项目将登记回执、安全生产承诺书等内容张贴在工程主要入口处醒目位置。发现具备条件且应办理但未依法办理施工许可手续的房屋建筑工程，应立即制止施工，整合属地相关监管力量进行调查处置，并及时向区建管委报送疑似无证施工项目的现场施工照片、房地产权证、施工合同等信息和初步调查和处置情况。每月梳理汇总小型房建工程清单（见附件1）和疑似无证施工项目清单（见附件2）报送区建管委。各街镇应督促小型房建工程做好完工销项申报工作，实现闭环管理。其中，高风险小型房建工程应购买安全生产责任保险。

（三）强化重点领域管理。各街镇要重点管好高层建筑、厂区园区和商业综合体等关键场所，重点抓好涉及人员密集场所动火作业、变动建筑主体和承重结构等高风险小型房屋建筑工程，重点消除高处作业、安全防护、临时用电、悬挂类易高坠设施设备等易发风险隐患，在非报监小项目管理办法内明确相关管理手势、动态更新底数清单，加大巡查和安全管理力度。各街镇要组织开展安全宣传培训教育，加强事故警示教育、风险告知，督促责任主体做好班前教育和作业安全交底等工作。

（四）强化安全监督检查。各街镇要自行或委托第三方专业团队开展日常安全生产检查，对辖区内小型房建工程在施工过程中开展至少一次安全检查并做好检查记录，对高风险小型房建工程等安全风险较大的项目增加检查频次。对发现的安全隐患及时处置，并通过小型房建工程信息系统填报相关信息，对超出权限范围的执法事项移送相关部门处理。对发生安全生产事故的小型房建工程，应按照《进一步加强突发事件紧急信息报送工作的通知》等要求，在半小时内口头、一小时内书面报告。

四、部门指导要求

（一）加强信息共享。区建管委每月向各街镇发送新核发施工许可证项目清单和竣工备案项目清单，指导街镇做好小型房建工程和无证施工项目排查工作。

（二）强化行业指导。区建管委做好小型房建工程监管指导，并牵头组织对小型房建工程监督抽查，对发现的违法违规行为，及时制止并督促整改，依法依规予以处理，并将抽查结果告知街镇，督促街镇举一反三加强监管。组织各街镇开展集中培训，加大对相关政策、法律法规、文件规范等的宣贯力度，切实提升各街镇安全管理水平。

（三）开展交叉互检。区建管委牵头各街镇对小型房建工程监管情况进行交叉检查，查阅资料台账，开展现场检查，指出现场隐患和街镇管理问题并督促落实整改。

（四）加强年度考核。区建管委结合街镇信息报送、安全管理和区级监督抽查、交叉互检等情况，将小型房建工程管理工作纳入区建管委对街镇的年度绩效考核。

（五）形成部门合力。各部门要根据职责分工，指导、配合各街镇做好小型房建工程监管和违法违规行为处置工作。区安委办对发生小型房建工程安全生产亡人事故的，抄告街镇主要领导督促整改并要求举一反三加强监管，将相关情况纳入区安委办对街镇的年度绩效考核；区城运中心配合区建管委依托“网格+”机制，建立小型房建工程发现、报送、处置的闭环管理模式；区绿化市容局督促市容环境卫生作业服务单位在清运小型房建工程垃圾前，查验备案信息登记办理回执，发现未按照规定办理备案信息登记的，不予清运建筑垃圾，并及时将有关情况报送街镇；对造成承重结构破坏等严重后果的小型房建工程，区规资局依法将有关事项记载于工程所在房屋的不动产登记簿。

五、责任落实要求

（一）建设单位首要责任。业主应履行使用安全责任，如租赁给他人进行经营的，应督促承租人履行建设单位首要责任，做好项目备案和现场安全管理工作。业主（承租人）作为建设单位应与具有相应施工资质的企业签订施工合同。对经街镇多次催报但仍拒不报送小型房建工程信息的，街镇应加大安全检查频次力度，压实建设单位首要责任，并联合区建管、房管、消防、绿容、应急等部门开展检查，督促建设单位履职尽责。

（二）施工单位主体责任。施工单位应建立安全生产工作制度，加强施工现场安全管理，做好作业人员安全生产宣传、培训、教育等工作。对于高风险小型房建工程应购买安全生产责任保险。

（三）属地监管责任。各街镇应切实履行管理责任，督促辖区内小型房建工程做好备案管理，加强属地安全巡查并做好各类信息报送工作。对存在项目监管不实、问题整改不严、信息报送严重滞后的街镇，由相关区级部门采取约谈、函告、通报等方式督促履职。对街镇监管不力且发生小型房建工程安全生产事故的，街镇应承担相应责任。

（四）行业指导责任。区建管委应统筹指导各街镇做好项目备案、信息报送和安全管理等工作，加大对街镇的安全生产培训力度，提升街镇履职能力。区房管局指导街镇督促业主履行使用安全责任。应急、城运和绿容等职能部门应履行指导责任，充分赋能街镇做好小型房建工程监管工作。教育、卫健、体育、国资等有关行业主管部门要指导行业内小型房建工程落实项目信息报送、现场安全管理等工作。

（五）强化责任追究。对发生安全生产亡人事故的小型房建工程，区应急局会同相关部门和街镇依法开展事故调查，追究相关责任单位或人员责任；对有关违法违规行为，由相关部门依法采取约谈警示、行政处罚、信用惩戒等措施。

六、其他

小型房建工程备案信息登记、安全生产承诺等工作按照市住建委《关于印发〈高风险限额以下小型房屋建筑工程判定标准〉等文件的通知》（沪建质安〔2025〕556号）要求执行。

本实施细则自发布之日起实施，有效期两年，由区建管委负责解释。实施过程中，如遇国家和本市有关政策调整，按新政策执行。
