# 上海市住房和城乡建设管理委员会关于批准《建筑浮筑楼板保温隔声系统构造》为上海市建筑标准设计的通知

上海市住房和城乡建设管理委员会关于批准《建筑浮筑楼板保温隔声系统构造》为上海市建筑标准设计的通知

沪建标定〔2021〕512号

各有关单位：

由中国建筑标准设计研究院有限公司和上海建科检验有限公司主编的《建筑浮筑楼板保温隔声系统构造》，经审核，现批准为上海市建筑标准设计，统一编号为 DBJT08-133-2021，图集号为2021沪J112，自2021年12月1日起实施。本标准设计由上海市住房和城乡建设管理委员会负责管理，中国建筑标准设计研究院有限公司负责解释。

特此通知。

2021年8月10日
