# 关于下发《闵行区维修资金（公共收益）管理制度（试行）》的通知

闵房管〔2018〕240号
各街镇（工业区）：
为加强我区维修资金和公共收益管理，完善事前、事中、事后监管，根据《上海市商品住宅维修基金管理办法》、《关于加强住宅物业专项维修资金管理工作的通知》等相关规定，特制定《闵行区维修资金（公共收益）管理制度（试行）》（以下简称《管理制度（试行）》）。现将《管理制度（试行）》下发至各单位，请予以参照执行。
特此通知。
