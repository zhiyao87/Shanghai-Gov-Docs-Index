# 上海市普陀区人民政府关于同意《红旗村地块征收集体土地居住房屋补偿方案》等三个文件的批复

区规土局、长征镇：

你们《关于报批<红旗村地块征收集体土地居住房屋补偿方案>、<红旗村地块征收集体土地居住房屋补偿人口认定办法>及<红旗村地块征收集体土地居住房屋补偿产权调换购房办法>的请示》（普规土〔2015〕58号）已收悉。

经区政府研究，同意你们上报的《红旗村地块征收集体土地居住房屋补偿方案》、《红旗村地块征收集体土地居住房屋补偿人口认定办法》及《红旗村地块征收集体土地居住房屋补偿产权调换购房办法》。请你们会同相关部门适时开展签约工作。

特此批复。

上海市普陀区人民政府

2015年12月7日
