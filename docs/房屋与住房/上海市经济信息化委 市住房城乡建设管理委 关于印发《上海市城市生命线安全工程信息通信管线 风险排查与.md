# 上海市经济信息化委 市住房城乡建设管理委 关于印发《上海市城市生命线安全工程信息通信管线 风险排查与评估导则》的通知

有关单位:

为了更好有效提升上海城市精细化治理水平，构建韧性安全城市，落实《上海市城市生命线安全工程建设实施方案》（沪建设施联〔2025〕108号）相关要求，指导本市信息通信业科学构建信息通信管线及其配套设施的风险识别、风险评估、风险分级管控体系，市经济信息化委会同市住房城乡建设管理委组织编制了《上海市城市生命线安全工程信息通信管线风险排查与评估导则》，现印发给你们，请参照执行。

特此通知。
