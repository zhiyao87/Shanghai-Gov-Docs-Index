# 上海市住房和城乡建设管理委员会等部门关于印发《上海市既有住宅承重结构损坏及修复检测鉴定技术导则》（试行）、《上海市既有住宅承重结构损坏修复技术导则》（试行）的通知

上海市住房和城乡建设管理委员会等部门关于印发《上海市既有住宅承重结构损坏及修复检测鉴定技术导则》（试行）、《上海市既有住宅承重结构损坏修复技术导则》（试行）的通知

沪建城管联〔2024〕180号

各有关单位：

为贯彻市委、市政府关于坚决遏制、严厉打击房屋装修过程中损坏承重结构的违法行为，切实保障房屋使用安全和居民居住安全的要求，市住房城乡建设管理委、市城管执法局、市房屋管理局组织编制了《上海市既有住宅承重结构损坏及修复检测鉴定技术导则》（试行）、《上海市既有住宅承重结构损坏修复技术导则》（试行），现印发给你们，请按照执行。

特此通知。

市房屋管理局

市城管执法局
