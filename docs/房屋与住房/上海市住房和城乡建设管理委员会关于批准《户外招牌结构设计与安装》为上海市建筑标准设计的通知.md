# 上海市住房和城乡建设管理委员会关于批准《户外招牌结构设计与安装》为上海市建筑标准设计的通知

上海市住房和城乡建设管理委员会关于批准《户外招牌结构设计与安装》为上海市建筑标准设计的通知

沪建标定〔2023〕272号

各有关单位：

由上海市工程建设质量管理协会、上海市建工设计研究总院有限公司、上海建设结构安全检测有限公司主编的《户外招牌结构设计与安装》，经审核，现批准为上海市建筑标准设计，统一编号为DBJT08-111-2023,图集号2023沪G902,自2023年12月1日起实施。原标准设计《店招店牌结构设计与安装》（DBJT08-111-2009），图集号2009沪G902同时废止。

本标准设计由上海市住房和城乡建设管理委员会负责管理，上海市工程建设质量管理协会负责解释。

特此通知。

2023年6月1日
