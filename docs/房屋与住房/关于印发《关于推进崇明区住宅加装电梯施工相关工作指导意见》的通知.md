# 关于印发《关于推进崇明区住宅加装电梯施工相关工作指导意见》的通知

各乡镇：

为进一步推动住宅加装电梯工作，结合本区实际，制定了《关于推进崇明区住宅加装电梯施工相关工作指导意见》。现将该文件印发给你们，请结合实际情况执行。

特此通知。

上海市崇明区住宅小区综合管理联席会议办公室

2019年7月8日

（此件依申请转主动公开）

关于推进崇明区住宅加装电梯施工相关工作指导意见

为进一步推进崇明区住宅加装电梯工作，缩短施工周期，让居民尽早享受生态岛建设红利，根据领导指示，现就加装电梯施工中的市政管线搬迁问题，特制定指导意见如下：

为优化电梯加装单位、属地政府和管线产权单位就管线搬迁方案协商环节，加快市政管线搬迁进度，进一步节支降本，可采取“一门对接，统筹施工”模式，即电梯加装单位以“包干”方式直接与水、电、煤、通信等管线产权单位对接，统筹安排施工时间。

根据本区加装电梯过程中与各管线产权单位实际发生的费用，测算了电梯加装单位包干费用，供参考。同时包干费用由电梯加装单位与属地政府根据实际搬迁项目，可作适当增减。包干费用具体参考如下：
