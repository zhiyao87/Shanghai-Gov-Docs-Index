# 关于印发《周浦镇农村村民住房建设管理行政审批事项相关规定》的通知

周浦镇农村村民住房建设管理行政审批事项相关规定

为加强周浦镇农村村民住房建设和宅基地管理工作，规范农村村民建房秩序，保护农村村民合法权益，推进乡村振兴战略实施，根据浦府规【2021】5号《浦东新区农村村民住房建设管理实施细则》文件规定，结合周浦镇的实际，对符合申请建房审批条件的农村村民，制定本规定。

一、审批制度

农村村民住房建设管理实行联席会议制度，联席会议由三方部门组成：

(一)镇规划建设和生态环境办公室

(二)镇经济发展服务中心

(三)浦东新区规划和自然资源局第四管理所(周浦所)

其中：镇规划建设和生态环境办公室为牵头受理部门，集中受理村民委员会报送的书面申请等材料，并负责将建房申请材料在审核部门间流转以及审核通过后上报批准等工作流程。

二、审批流程

(一)村级审查流程

1、受理

符合宅基地申请条件的农户或者对原有住房进行改建、翻建和易地新建的，应向所在地村民委员会提出宅基地和书面建房申请。

2、初审

村民委员会接到书面申请后，应对申请人主体资格、成员人数及其他建房条件进行初步审查。

3、张榜公布

初审通过后，应当在村务公开栏内将农户成员人数、建房位置等相关信息张榜公布，公布期限不少于30日。

4、报送和异议处理

公布期间无异议的，申请人填写《浦东新区农村宅基地和建房(规划许可)申请表》，村民委员会签署认定意见(资格和人口数量)后，连同建房申请人的书面申请和宅基地使用承诺书等，报送至镇规划建设和生态环境办公室。公布期间有异议的，村民委员会应当召集村民会议或者村民代表会议讨论决定。

(二)镇级审批流程

由镇经济发展服务中心、浦东新区规划和自然资源局第四管理所(周浦所)、镇规划建设和生态环境办公室三部门分别审核以下内容：

1、镇经济发展服务中心审核内容

(1)审核申请人和用地人数是否符合申请资格条件，是否有在本市他处已计入批准建房用地人数的人员，或者因宅基地征收(拆迁)、农民相对集中居住等已享受补偿安置的人员等情况，审定农户建房人数;

(2)宅基地和建房申请等相关信息村务公开公示程序是否履行到位;

(3)其他需要审核的内容。

2、浦东新区规划和自然资源局第四管理所(周浦所)审核内容

(1)申请用地是否符合宅基地合理布局条件;

(2)用地建房是否符合(周浦镇郊野单元规划)的条件;

(3)用地面积标准;

1人户的宅基地总面积控制在60平方米以内。

5人户及5人以下户的宅基地面积不超过140平方米。

6人户及6人以上户的宅基地面积不超过160平方米。

(4)其他需要审核的内容。

3、镇规划建设和生态环境办公室审核内容

(1)建房图纸是否符合法定要求。建造两层或者两层以上住房的，应当使用具备资质的设计单位设计或经其审核的施工图纸，或者免费使用市住房城乡建设行政管理部门推荐的通用图纸;

(2)房屋结构是否符合安全标准;

(3)建筑形态是否符合本地区风貌管控要求等;

(4)建筑面积标准：

农村村民申请建房以户为单位，每户中按每人不超过45平方米建筑面积总体控制，具体核准面积需结合地块周边情况综合审定。

1人户建筑占地面积控制在45平方米以内。

5人户及5人以下户建筑占地面积不超过90平方米，建筑面积不超过225平方米。

6人户及6人以上户建筑占地面积不超过100平方米;6人户的建筑面积不超过270平方米，家庭人数超过6人的，每增加1人，可以增加建筑面积20平方米。

(5)其他需要审核的内容。

4、联席会议审核

由镇规划建设和生态环境办公室召开联席会议对建房申请以及各项审核内容进行综合评审。

5、审批决定

(1)综合评审通过后，由规划建设和生态环境办公室报分管领导审核，主要领导审批。

(2)审批后，由规划建设和生态环境办公室合并发放农村宅基地批准文件和乡村建设规划许可证。

6、审批时限

镇人民政府在接到村民委员会报送的建房申请人的书面申请之日起30日内完成审批。

审批不通过的，在规定时限内出具退件单，将全部材料退回村民委员会，由村民委员会将退件单及全部申请材料退交申请人。

三、建立管理台账

宅基地用地、建房审批完成后，将相关资料一式四份归档留案，并在批准之日起15日内，将审批情况分别上报区农业农村、规划资源行政管理部门备案。

四、审批结果的公布

经审批符合条件同意新建房屋(含翻建等)的，镇人民政府将农户建房的审批结果张榜公布，时间不少于30日，接受群众监督。

公布期间有异议的，镇人民政府在5个工作日内对该户申请进行复核，并根据复核结果进行相应处理。

五、批后监管

按照《周浦镇农村村民住房建设监管办法》的相关规定执行。

六、验收报备

农户建房完工后，应当向镇人民政府申请验收。镇人民政府在接到农户申请后5个工作日内，由镇规划建设和生态环境办公室组织联席会议相关部门进行实地验收并出具书面验收意见。

经验收合格的，镇人民政府在15日内，将相关验收情况分别报区农业农村、规划资源和建设行政管理部门备案。

七、其他事项

(一)本规定由周浦镇人民政府负责解释。

(二)本规定自2022年8月16日起施行，有效期至2027年12月31日。
