# 关于印发《虹口区危险房屋应急处置工作办法（试行）》的通知

区政府相关部门、各街道办事处、有关单位：

《虹口区危险房屋应急处置工作办法》已经区政府常务会议审议通过，现印发给你们，请按照执行。

特此通知。

虹口区住房保障和房屋管理局

2024年8月14日

虹口区危险房屋应急处置工作办法（试行）

第一条（目的和依据）

为进一步完善虹口区危险房屋应急处置项目管理和资金保障机制，规范相关项目实施及应急资金使用管理，根据《上海市应急抢险救灾工程建设管理办法》《上海市房屋使用安全管理办法》《上海市住宅物业管理规定》等法律法规，结合本区实际情况，制定本办法。

第二条（适用范围）

本市实行房屋使用安全责任人制度。

本区范围内的房屋发生或即将发生危害公共安全或危及人民生命财产安全情形，须立即采取工程措施，但房屋使用安全责任人责任无法立即落实的，由区房管局或属地街道代为组织实施的危险房屋急修、房屋突发安全应急抢险和既有住宅外墙高坠隐患处置等项目的认定、实施、监督管理等活动，适用本办法。

第三条（工作原则）

坚持人民至上、生命至上，安全第一、决策科学，处置快速、经济高效原则。在排除结构安全、高坠风险施工时，应严格落实工程安全措施和管理责任，同时确保房屋使用功能不受影响。

第四条（危险房屋的定义）

本办法所称的危险房屋，是指经专业房屋检测鉴定机构依据《危险房屋鉴定标准》《民用建筑可靠性鉴定标准》等规范鉴定为C、D级的房屋，包括但不限于房屋出现基础下沉、主体结构损坏、墙体开裂等结构安全隐患。

本办法所称的既有住宅外墙存在严重高坠隐患，是指经专业房屋检测鉴定机构依据《建筑结构检测技术标准》《建筑外墙外保温系统修缮标准》《红外热像法检测建筑外墙饰面粘结质量技术规程》等规范鉴定为存在高坠隐患，或已发生外墙大面积空鼓，外墙保温材料、瓷砖、装饰线条、附属构筑物或整体面层脱落危险情况的。

本办法所称的房屋安全突发情况，是指可能造成或者已经造成严重危害，必须立即采取紧急措施的情形。相关责任主体应保留现场情况记录，尽快组织专家评审作为应急处置依据。

第五条（管理职责）

区房管局牵头组织开展本区危险房屋应急处置工作，加强房屋安全监管，对工程进度、安全质量等方面开展监督检查，做好对街道危险房屋应急处置工作的技术指导。

区应急局负责督促指导相关职能部门和街道，协调推进危险房屋应急处置工作。

区国资委、区卫健委、区商务委、区教育局、区文旅局、区体育局、区民政局等部门应当按照各自职责，督促落实行业管理范围内的房屋使用安全责任人配合做好危险房屋应急处置工作。

区人武部、区退役军人事务局配合做好军队危险房屋应急处置工作，畅通地方与部队的沟通渠道。

区财政局负责落实资金保障，对危险房屋应急处置资金使用情况进行指导和监管。

区房管局、各街道应当加强对区域内危险房屋应急处置工作的管理，完善操作流程，细化工作标准，依法组织实施。

第六条（隐患发现）

（一）日常巡查

1.物业服务企业或小区自行管理机构应结合住宅小区实际情况，定期对房屋主体结构、外墙墙面等部位进行日常巡查，对发现的隐患采取防护措施并及时报送属地街道。

2.各行业主管部门、区属集团应督促职责范围内房屋产权人或管理人落实日常巡查机制。对发现的隐患及时报送相应主管部门、区属集团。

3.街道应落实属地责任，充分利用现有网格化巡查力量，积极调动城发公司、市容协管队伍等街面管理人员，做好常规房屋安全巡查，建立隐患发现、上报、处置流程机制。

（二）专项检查

房屋产权人或使用人可自行或委托专业单位定期对房屋进行安全检查，发现隐患的及时报送属地街道。

（三）隐患报送及应急措施

各行业主管部门、属地街道、区属集团及时汇总隐患信息并报送区房管局。经初判符合应急处置条件的，相应主体应启动应急处置预案，做好人员疏散、警示设置、防坠网搭设等应急措施。

第七条（实施条件）

（一）因自然灾害、事故灾难、公共事件、人为因素和社会安全事件等突发事件引起；

（二）房屋已经存在严重安全隐患，无法确认产权人或产权人、使用人未能履行房屋安全主体责任，区房管局、行业主管部门及属地街道已按相关法律法规规定，采取了约谈、发函督促、居委会代为履行业委会职责等必要措施，产权人、使用人仍不履行的；

（三）需立即采取措施，不采取紧急措施排除险情极易给社会公共利益或者人民生命财产造成较大损失或者社会影响的。

第八条（认定要求）

区房管局、属地街道应严格落实应急处置项目的认定管理，相关实施范围、工程措施及修缮工艺应严格按照专业单位意见实施，必要时应召开专家论证会予以确认，不得擅自放宽认定条件，扩大工程范围。

第九条（实施主体）

（一）对金额大于100万元的项目，由区房管局牵头召开专家评审会，开展项目论证、评估工作。经评估通过后，由区房管局报区政府同意后实施；

（二）对金额大于20万元小于等于100万元的项目，由区房管局会同属地街道共同认定通过后，由区房管局实施；

（三）对金额小于等于20万元的项目，由属地街道认定，认定结果报区房管局备案后由街道实施。

第十条（预算设立）

危险房屋应急处置资金纳入区房管局预算经常性项目，实施金额20万及以上项目由区房管局负责年度预算管理和日常资金使用管理；实施金额20万以下项目由各街道预算统筹保障；区财政局做好对预算项目设立、资金使用的指导和监督。

第十一条（简化审批流程）

依照本办法认定的危险房屋应急处置项目，依法需办理的各项审批手续，各有关管理部门应当在职权范围内，对相关行政审批程序予以简化。对如不采取工程措施，将发生危及生命财产安全的房屋，经评估后确需立即开展应急处置的，应先行实施，相关审批流程应同步跟进。

第十二条（发包管理）

应急处置项目各参建单位可通过邀请招标进行确认，或不进行招投标直接确定承包单位，参建单位须具有相应资质，严禁转包或者违规分包。

第十三条（合同管理）

应急处置项目实施前，应当先签订合同，确因情况紧急未签订合同的，应当自工程实施之日起1个月内启动补签合同流程，明确承包单位、工程费用或者计价方式、验收标准、工期、质量安全保证责任等内容。

第十四条（资金管理）

应急处置项目应配备审价单位，对项目决算金额进行审定；对工程实施金额大于200万元的项目应另行配备投资监理单位，对项目进行投资控制，提高资金投资使用效益。

第十五条（项目管理）

区房管局和属地街道应加强对项目参建单位的日常管理，各参建单位应按照相关法律法规要求，做好项目组织实施，确保工程安全和质量，按时高效完成项目实施。

第十六条（绩效评估）

项目实施后，应由区房管局和属地街道按职责分工及时进行项目资料备案，配合区财政局做好项目绩效跟踪和评价工作。

第十七条（责任追究）

相关部门、单位工作人员在工程实施过程中有滥用职权、徇私舞弊等行为的，依法进行问责；对违规认定危险房屋应急处置项目和险情发生后不及时组织实施的责任单位和责任人，按照相关规定追究责任。

第十八条（其他）

区房管局或属地街道依照本办法实施的应急处置项目发生的费用应由房屋使用安全责任人或导致房屋安全情况发生的责任方承担。

各行业主管部门按职责开展的本行业房屋应急处置项目可参照本办法执行。

第十九条（实施日期）

本办法自发布之日起实施，有效期2年。
