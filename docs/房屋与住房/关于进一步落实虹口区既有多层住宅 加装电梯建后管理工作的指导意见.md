# 关于进一步落实虹口区既有多层住宅 加装电梯建后管理工作的指导意见

各加装电梯的相关业主、相关单位：

为进一步规范虹口区既有多层住宅加装电梯使用管理，进一步完善加装电梯管理机制，保障加装电梯安全平稳运行。根据《物业管理条例》、《上海市住宅物业管理规定》、《上海市电梯安全管理办法》、《关于进一步做好本市既有多层住宅加装电梯工作的若干意见》、《关于加强既有多层住宅加装电梯管理的指导意见》(沪精细化办联〔2021〕10号)、《关于落实既有多层住宅加装电梯使用管理责任的指导意见》（沪精细化办〔2024〕1号）等文件精神，结合《关于进一步加强虹口区既有多层住宅加装电梯建后管理工作的指导意见》（虹房管〔2022〕20号）的实施情况，现将虹口区既有多层住宅加装电梯建后管理工作的指导意见更新如下：

一、电梯建后管理的责任主体

（一）加装电梯所有权人

本指导意见所称的加装电梯所有权人，是指共同出资加装并按约定按份共有电梯设备和新增设施设备所有权的业主或者公有住房承租人。房屋产权人发生变更或转移后，自该房屋变更、转移登记之日起，受让人相应变更或转移为新的电梯所有权人，享有原加梯协议约定的权利和履行相关义务。

如原房屋产权人不为电梯所有权人，应在房屋所有权发生变更、转移前，明确告知受让人相关情况。受让人就加装电梯费用及维保费用与其他电梯所有权人协商一致并出资后，可成为电梯所有权人。

（二）电梯使用管理单位

电梯使用管理单位履行电梯安全管理和新增设施设备管理义务，对日常电梯使用安全负责。根据《特种设备使用单位落实使用安全主体责任监督管理规定》的相关规定，加装电梯所有权人须委托物业服务企业、维护保养单位或者专业公司等市场主体为电梯使用管理单位。

加装电梯投入使用后，鼓励电梯使用管理单位与加装电梯所有权人协商后安装电梯物联网远程监测装置、购买电梯安全责任险等，以进一步保障电梯安全运行。

（三）电梯维护保养单位

电梯使用管理单位应当主动与加装电梯所有权人进行协商，确定电梯维护保养单位，具体承担电梯维护保养业务，对电梯的安全性能负责。

二、相关责任主体的职责

（一）加装电梯所有权人

1.明确管理单位。通过签订协议、合同等方式明确电梯使用管理单位、电梯维护保养单位，约定加装电梯管理方面的权利、义务和责任，并将加装电梯全过程资料移交电梯使用管理单位存档。加装电梯投入使用后，正确连接和运用电梯远程监测装置。

2.开设并管理加装电梯管理经费账户。开设加装电梯管理经费账户，承担电梯及其新增设施设备的日常管理、维护保养、修理、检验检测、安全评估、更新改造等所需费用，并按时足额交纳相关费用。加装电梯所有权人可以委托本小区物业服务企业开设加装电梯管理经费账户，并按门号立账实施日常管理。加装电梯所有权人自行开设并管理加装电梯管理经费账户的，要书面约定账户管理人，承担具体管理工作。

3.保障电梯安全运行。加装电梯投入使用前，应当安装电梯远程监测装置接入智慧电梯平台，并在使用过程中保持实时在线。鼓励购买电梯安全责任保险等，进一步保障电梯安全运行。

4.监督加装电梯管理。参与电梯管理、修理、改造、更新等事务的协商表决，监督电梯使用管理单位、电梯维护保养单位提供的日常管理和维护保养服务，并对电梯运行维护费用和电梯专项维修费用的支出情况享有知情权。

5.制定电梯管理公约。制定电梯管理公约，明确电梯安全使用说明和安全注意事项，文明乘梯、规范用梯等。发现危害电梯安全的违法违规行为，有权向相关部门进行投诉、举报。

（二）电梯使用管理单位

1.履行电梯安全管理义务。按照规定建立并执行电梯安全管

理制度，建立电梯安全技术档案，设置安全管理机构或者配备专

职安全管理人员，定期对电梯进行巡查并如实记录巡视时间、检查人员等情况；保管电梯层门钥匙、机房钥匙和安全提示牌；做好电梯安全乘用的宣传，劝阻不文明乘梯行为；制定电梯事故应急预案，并定期组织电梯的应急演练。

2.委托及配合电梯维护保养工作。根据与加装电梯所有权人的约定，委托制造单位或者取得电梯安装、改造、修理资质的单位承担电梯维护保养工作并查验相关资质证书。电梯使用管理单位具备电梯制造、安装、改造、修理资质的，可以接受加装电梯所有权人的委托承担电梯维护保养工作。配合电梯维护保养单位开展工作，签字确认维护保养记录；在相关单位对电梯进行安装、改造、修理、检验、检测、评估时，做好现场配合工作，协助相关单位落实安全防护措施，监督其履行保证电梯安全性能的职责。

3.公示电梯基础信息。在电梯轿厢内或者出入口的显著位置

张贴有效的电梯使用登记标志、安全使用说明、上海智慧电梯码、

安全注意事项、警示标志、本单位应急救援电话号码、电梯安全

责任保险的投保信息等，并确保不被遮挡。

4.响应电梯紧急报警装置（含三方通话）。确保电梯紧急报警装置（含三方通话）有效运行，即时响应乘客被困报警，做好安全指导工作，并在乘客被困报警后5分钟内通知电梯维护保养单位采取措施实施救援。

5.处置电梯故障及事故。发现电梯存在故障或者其他影响电 梯正常运行的情况时，及时作出停止使用的决定，报告本单位负

责人、加装电梯所有权人及小区业主委员会并通知电梯维护保养单位；在需要暂停使用的电梯出入口张贴停用告示，需停止电梯运行时间超过24小时以上的，应当公告电梯停止运行的原因和修复所需时间，并采取避免电梯乘用的安全措施。电梯发生事故时，应当组织排险、救援，保护事故现场，并于1小时内报告电梯所在地的区特种设备安全监督管理部门。

6.申请检验与评估。应当按照规定在电梯检验合格有效期届满前一个月，向特种设备安全检验机构提出电梯年检要求，未经定期检验或者检验不合格的电梯，不得继续使用。电梯达到设计年限或者次数，需要继续使用的，应当按照安全技术规范的要求，委托经依法核准的检验、检测机构开展安全评估。投入使用满15年以及故障频发影响使用、遭受水浸、火灾等灾害的电梯，电梯使用管理单位经电梯所有权人同意，可以委托检验、检测机构开展安全评估，并根据评估结论确定是否继续使用或者进行修理、改造、更新。评估结论应向全体业主公开，并向属地街道报送备案。

7.管理新增设施设备。落实专业人员定期对新增设施设备进行巡视，并如实记录巡视时间、检查人员、隐患发生位置、隐患情况以及处置结果；做好电梯厅窗户、照明、地砖以及与房屋本体间的连接结构等部位的日常保洁、维护保养和定期巡视等工作并做好记录，巡视记录至少保存5年；对新增设施设备存在高空坠物隐患的区域，应当及时设置警戒线，并以书面形式报告加装电梯所有权人和业主委员会，情况严重的应当同时报告属地街道。加装电梯所有权人、业主委员会和属地街道接到通知或报告后，按照《上海市房屋使用安全管理办法》等相关规定予以处置。如发现新增设施设备存在安全隐患，可能影响电梯正常使用的，应当及时通知加装电梯所有权人和电梯维护保养单位，并根据加装电梯所有权人或者电梯维护保养单位的意见停用电梯。

8.开设并管理加装电梯管理经费账户。根据加装电梯所有权人的委托，将运行维护费用和专项维修费用（如有）按门号立账实施日常管理，并每月公布1次电梯运行维护费用和专项维修费用的收支情况，接受加装电梯所有权人的监督。

9.其他。严格按照国家市场监督管理总局《特种设备使用单位落实使用安全主体责任监督管理规定》（国家市场监督管理总局令第74号）落实使用管理单位职责，以及由加装电梯所有权人和电梯使用管理单位约定的管理职责。

（三）电梯维护保养单位

1.执行资质及规范要求。具备电梯制造或者安装、改造、修理许可资质；更换的电梯零部件应当具有产品质量合格证明，如更换《电梯型式试验产品目录》中的零部件，还应当提供相应的型式试验证明；至少每6个月对电梯进行1次自行检查，向电梯使用管理单位出具自检报告，并向加装电梯所有权人公示；电梯维护保养单位应当对自监督检验合格之日起使用年限超过15年的电梯，根据实际运行状况增加维护保养频次和维护保养项目。

2.开展电梯维护保养工作。按照电梯安全技术规范、相关标 准和使用维护保养说明的要求，制定安全管理制度、维护保养计划并告知电梯使用管理单位;按期开展限速器校验、125%荷载制动试验、日常小修等工作。指派具有资质的维护保养人员，开展日常维护保养工作，建立维护保养和故障处置记录，并至少保存5年。在维护保养期间应做好现场安全防护措施，保证施工安全；检查本单位配置的电梯远程监测设备的运行情况。

3.保障电梯应急救援处置。制定应急救援预案，确保应急救援电话24小时保持有效应答和应急救援装置完备，接到乘客被困报警后，30分钟内赶到现场完成救援解困，并做好救援记录；

发现电梯设备存在故障、安全隐患，或者在接到故障通知后，及时排除故障和隐患；对故障和隐患暂时难以排除的，应当及时向电梯使用管理单位通报有关情况、书面提出排除故障和隐患的解决方案、措施或建议，并告知电梯使用管理单位故障排除前不得使用。

4.公示电梯维保信息。在电梯显著位置，标明本单位的名称、

应急救援电话号码和投诉电话号码；在电梯轿厢内或者出入口公布最近一次电梯维护保养信息，信息至少应当包括维护保养人员、维护保养时间和内容等。

5.加强人员教育培训。定期对作业人员进行安全教育和技术培训，建立作业人员教育培训记录并至少保存5年，支持作业人员取得职业技能资格。

6.其他。由电梯使用管理单位和电梯维护保养单位约定的职责。

三、落实电梯使用管理单位

加装电梯所有权人申请加装电梯前，应商讨一致形成加装电梯建后管理方案，确定电梯使用管理单位和电梯维护保养单位，明确服务事项、服务内容、服务标准、收费事项和收费标准等具体内容，约定加装电梯管理经费筹集与分摊内容。在加装电梯的综合竣工验收环节，由加装电梯所有权人委托的代建单位向所属街道办事处报备加装电梯建后管理方案。

对已表决通过的加装电梯具体方案中未明确后续管理事宜且加装电梯尚未交付使用的，属地街道要抓紧组织加装电梯所有权人共同协商，明确后续管理事宜，避免影响加装电梯竣工后的正常使用。

对加装电梯已交付使用但委托管理协议或者代建单位免费维保期即将到期的，属地街道要指导加装电梯所有权人提前开展加装电梯使用管理单位续聘或者重新选聘工作，在原委托管理协议到期前签订新的委托管理协议，避免使用管理单位出现断档。

四、加装电梯管理经费账户管理

按照《上海市电梯安全管理办法》等相关规定，加装电梯日 常管理、能耗、维护保养、改造、修理、检验、检测、安全评估

以及委托他人管理服务或者购买相关保险等所需的费用，由加装

电梯所有权人承担。

（一）加装电梯管理经费构成

（二）加装电梯管理经费筹集

设立加装电梯管理经费账户，加装电梯所有权人应当按照相关协议自行筹集加装电梯管理经费。加装电梯管理经费由所在门号加装电梯所有权人选出的代表按协议约定的电梯运行维护费用及各户分摊比例收齐后，统一存入加装电梯管理经费账户。当账户余额不足时，加装电梯所有权人代表要及时组织和加装电梯所有权人按照约定比例续筹，街道可以协助组织加装电梯所有权人筹集落实资金。

加装电梯管理经费的筹集途径主要包括：

1.加装电梯产权人自筹资金；

2.加装电梯专项账户的余额；

3.在加装电梯内设置广告、商业推广等经营设施而获得的公共收益；

4.购买社会保险；

5.其他出资方式。

（三）加装电梯管理经费使用

加装电梯管理经费按照委托管理协议的约定或者加装电梯 所有权人的决定使用。发生需使用加装电梯管理经费情形的，由加装电梯所有权人代表按照加装电梯委托管理协议约定或者加 装电梯所有权人的决定，在加装电梯管理经费账户中提取，并支付给相关单位。

1.引入专业资金托管模式

加装电梯所有权人可以自行开设并管理加装电梯管理经费账户，也可以委托加装电梯使用管理单位或者专业资金监管机构开设并管理加装电梯管理经费账户。专业资金监管机构接受委托开设并管理加装电梯管理经费账户的，要与加装电梯所有权人签订书面托管协议，明确服务事项、服务费用、信息公开等事项，并按门号(梯)立账实施日常管理，确保管理经费使用安全、公开透明。

2.发挥保险产品积极作用

鼓励加装电梯所有权人购买加装电梯全生命周期管理保险产品，通过“保险+服务”模式解决加装电梯安装和管理问题。加装电梯所有权人在选购加装电梯管理保险产品时，要统筹考虑电梯设备和新增设施设备的相关保险，涵盖电梯维护保养、检验、维修、井道主体结构运营风险等内容，并与保险公司共同协商确定加装电梯使用管理单位，实现加装电梯全方位保险保障。

五、物业服务企业全程参与

物业服务企业要不断提高政治站位和服务意识，积极发挥自身专业优势，做好以下工作：

（一）积极配合开展既有多层住宅加装电梯工作

1.各物业服务企业要按照《关于加强既有多层住宅加装电梯使用管理的指导意见》(沪精细化办联〔2021〕10号)的相关要求，在意见征询、现场施工、后续管理等环节积极发挥自身专业优势，全程参与加装电梯工作。并根据小区地形地貌、道路、绿化、停车位配置、管线位置等实际情况提供专业建议，推动业主就加装电梯相关事宜达成共识。

2.积极配合提供房屋原始竣工图纸和建筑材料、建筑垃圾堆放场地。相关场地需占用小区道路或者机动车停车位的，要做好道路交通和机动车停放引导工作。涉及停车费用、占用公共空间等由居委会组织业委会、业主、物业服务企业和建设单位协商解决。同时，配合施工单位做好现场管理，维护施工现场秩序。

（二）主动承接加装电梯所有权人的委托

提供加装电梯使用管理服务，在公平合理、协商一致的基础上主动承接加装电梯所有权人的委托，与加装电梯所有权人签订书面加装电梯委托管理协议，明确约定服务事项、服务内容、服务标准、收费事项和收费标准等具体内容。

六、档案管理

电梯使用管理单位应对每台电梯建立安全技术档案，妥善保存电梯相关资料。

加装电梯所有权人委托物业服务企业作为加装电梯的使用管理单位，应移交相关资料原件或复印件，包括：上海市特种设备使用登记证、电梯产品出厂合格证明、电梯监督检验报告、建设工程竣工验收报告等其他电梯相关资料。

电梯使用管理单位应向加装电梯所有权人提供相关资料复印件并加盖公章，包括：营业执照、特种设备安装改造维修证、特种设备作业人员证等其他相关资料。

电梯使用管理单位负责运维管理期间，应做好年检合格证、日常维保记录、故障处置记录等的留档。

七、其他

1.在加装电梯投入使用前，各街道应协调加装电梯所有权人与电梯使用管理单位就电梯建后接管达成一致意见并签署委托管理协议（可参照附件2示范文本），确保相关维保监管责任得以落实。

2.各街道应结合物业达标奖励考核工作，将加装电梯建后接管及管理情况作为物业服务企业达标奖励考核依据，给予适当加分、优先发放达标奖励等政策激励措施，引导物业企业积极参与既有多层住宅加装电梯建后管理工作。

3.区住房保障房屋管理局和区市场监管局等相关行业主管部门负责既有多层住宅电梯建后管理的指导工作。
