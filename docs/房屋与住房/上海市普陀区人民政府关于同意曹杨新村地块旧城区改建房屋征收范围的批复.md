# 上海市普陀区人民政府关于同意曹杨新村地块旧城区改建房屋征收范围的批复

上海市普陀区住房保障和房屋管理局：

你单位《关于申请确认曹杨新村地块旧城区改建范围的请示》（普房管〔2026〕78号）已收悉。经研究批复如下：

一、原则同意曹杨新村（北岭北杨枫岭地块、北梅园地块、兰岭园地块、南溪桂花地块）地块列入我区旧城区改建范围。曹杨新村（北岭北杨枫岭地块、北梅园地块、兰岭园地块、南溪桂花地块）地块房屋征收四至范围分别为：

1.北岭北杨枫岭地块：东至曹杨路，南至枫桥路、梅岭北路、梅岭苑（梅岭北路400弄），西至安居兰庭和曹杨二村160-163、168-171号以东，北至武宁路;

2.北梅园地块：东至棠浦路，北至梅岭北路，西至花溪路，南至朝春中心小学;

3.兰岭园地块：东至兰溪路，北至武宁路，西至曹杨公寓，南至曹杨三村218-220、292-293号以北;

4.南溪桂花地块：东至百禧公园，南至兰溪路，西至梅岭北路，北至曹杨新村第三幼儿园、中桥大楼小区。

二、在启动改建前，按照《上海市国有土地上房屋征收与补偿实施细则》有关规定，组织开展居民意愿征询和房屋征收补偿方案征询，在被征收人、公有房屋承租人同意旧城区改建和签订附生效条件的补偿协议达到规定的比例后，方可实施改建工作。

特此批复，请抓紧组织实施。
