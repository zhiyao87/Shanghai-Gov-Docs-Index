# 关于优化家庭生活困难提取住房公积金政策的通知

上海市公积金管理中心：

为支持家庭生活困难职工提取使用住房公积金，现就优化家庭生活困难职工提取住房公积金政策通知如下：

一、职工家庭经本市民政部门认定属于最低生活保障家庭、最低生活保障边缘家庭、刚性支出困难家庭的，或者职工本人、配偶或其父母、子女患重大病的，本人及配偶可以申请提取住房公积金账户内的存储余额。

二、符合提取条件的，可以多次提取，提取金额不超过账户余额（账户余额不能为零元）。本人、配偶或其父母、子女患重大病的，应在就医治疗的两年内申请办理。

三、市公积金管理中心可以根据本通知制定业务指南。

四、本通知自2024年12月1日起施行。有效期五年。

上海市住房公积金管理委员会

二○二四年九月三十日
