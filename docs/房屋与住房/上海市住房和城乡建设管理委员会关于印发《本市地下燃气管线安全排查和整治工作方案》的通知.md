# 上海市住房和城乡建设管理委员会关于印发《本市地下燃气管线安全排查和整治工作方案》的通知

上海市住房和城乡建设管理委员会关于印发《本市地下燃气管线安全排查和整治工作方案》的通知

沪建设施〔2022〕120号

各区建设管理（交通）委、浦东新区城管执法局，各燃气企业：

为贯彻落实市委、市政府关于组织开展地下管线安全隐患排查和整治的工作部署，现制定《本市地下燃气管线安全排查和整治工作方案》印发给你们，请各单位认真贯彻执行。

特此通知。
