# 关于印发《吴泾镇规模化居住租赁场所长效管理工作制度》的通知

关于印发《吴泾镇规模化居住租赁场所长效管理工作制度》的通知

机关各办（部门），各居、村委，镇属事业单位（公司）：
《吴泾镇规模化居住租赁场所长效管理工作制度》经镇党委、政府研究通过，现印发给你们，请认真组织学习，抓好贯彻落实，确保各项目标任务圆满完成。

闵行区吴泾镇人民政府
2023年12月27日

吴泾镇规模化居住租赁场所长效管理
工作制度

为全面加强城市精细化管理，针对当前镇域规模化居住租赁场所监管主体缺失、责任不明、机制不全、监控不力和经营不规范、安全隐患突出等问题，现就吴泾镇规模化居住租赁场所长效管理制定如下工作制度：
一、工作目标
坚持“安全第一、规范管理”，建立吴泾镇规模化居住租赁场所长效管理机制，把规模化居住租赁场所纳入规范化管理，明确责任部门、明确职责分工、明确监管机制、明确工作内容、明确措施方法，规范经营秩序、规范管理制度、规范设施配置、规范安全要求，确保镇域规模化居住租赁场所安全、有序、规范运作。
二、管理范围
除宾馆以外达到一定居住数量规模（出租房屋30间以上、租赁期限不低于30天）的集中租赁居住场所，主要包括长租公寓（镇域内通过非居住房屋（厂房、仓库、商办、会所、综合楼和研发楼等）改建的集中式规模化居住租赁项目）、动迁临时安置房和企业出租宿舍、园区出租公寓等。
三、组织领导
镇层面成立吴泾镇规模化居住租赁场所长效管理领导小组，统筹协调推进我镇规模化居住租赁场所长效管理，领导小组组长由镇党委副书记担任，副组长由副镇长担任；镇经发办、平安办、城运中心、房管所、行政执法队、吴泾派出所、塘湾派出所、新吴泾公司、司法所、市场监督管理所、水务站、规建生态办负责人为领导小组成员。领导小组下设办公室，办公室设在镇房管所，房管所所长兼领导小组办公室主任，同时落实2人为领导小组办公室专职工作人员。
四、职责分工
领导小组办公室负责全面研究、把控全镇规模化居住租赁场所的存量和增量情况，传达上级精神、部署工作任务、履行统筹指挥协调、数据集中统计、疑难问题会商、工作定期汇报等职责。各职能部门各司其职，相互协同，齐抓共管，充分发挥好职能优势，切实履行好各自职责，具体分工如下：
房管所牵头领导小组办公室工作，负责监管长租公寓、单位租赁房、类住宅等有正规物业管理的场所，做好基础数据的统计，牵头负责场所调增和调减工作，传达上级精神，部署工作任务。
经发办负责监管企业自行建造的职工宿舍，核实企业用工信息，督促厂区、园区宿舍管理方落实主体责任。
平安办负责联合整治时的全面协调工作，做好实有人口信息的登记、注销、核实、巡查、办证等工作，确保实有人口信息准确率达98%以上。协同派出所做好治安安全管理。
城运中心负责对市民投诉、民生热线反映的规模性租赁问题进行分流、反馈，配合做好巡查和整治；负责牵头对规模化居住租赁场所消防等安全隐患定期开展监督检查和整治。
行政执法队负责对规模化居住租赁场所存在的违法搭建等违法行为开展执法检查。对认定为存在违法搭建且存在严重安全隐患的规模性租赁住宿场所进行拆除。
新吴泾公司负责监管过渡性动迁安置房、镇属公司自管或委托管理的场所，配合做好场所安全管理，来沪人员信息上报，督促委托管理方落实属地管理责任。
司法所负责对规模化居住租赁场所的法治宣传、矛盾纠纷化解，引导律师做好法律咨询和法律援助。
派出所负责监管各规模化居住租赁场所做好场所治安安全管理，开展治安检查，对违反治安管理等相关法律法规的行为责令改正并依法实施行政处罚。
市场监督管理所负责做好规模化经营居住租赁场所经营主体资质的审核、查处违规经营行为。
水务站负责做好对二次供水建设的指导服务。
规建生态办负责督促对破坏房屋结构的单位委托第三方检测机构对房屋质量进行安全评估。
五、长效机制
（一）定期例会制度
领导小组办公室负责召集联络员召开月度工作例会，通报最新的排摸、检查、处置情况，做到上情及时下达，下情及时上传，季度或年度工作例会由领导小组视情形召开。
（二）常态监管制度
明确行业监管主要责任以及监管主体责任，打好“持久战”，形成常态化，定期开展消防安全、房屋结构安全、治安安全、实有人口信息等各类专项检查，及时更新数据，实行动态管理，确保各项安全措施落实到位，发挥业务指导和专业执法作用，切实守住“消防安全、房屋结构安全、治安管理安全”三条底线。
（三）巡视检查制度
领导小组办公室根据上级部署和常态化管理的要求，不定期随机巡查，草拟定期督查和专项检查方案，按照检查内容确定牵头部门，并形成专题报告，跟踪督促规模化居住租赁场所完善各项管理制度，配齐配全硬件和管理人员。
（四）考核奖惩制度
规模化居住租赁场所长效管理将纳入镇对各职能部门、村年度工作考核内容，同时也是镇重点工作督查项目。对长效管理过程中表现突出的单位和个人适时予以表彰，对管理不到位，不具备经营条件的场所予以处罚或关闭取缔。
六、工作要求
（一）明确职责，宣传发动。各成员单位根据工作方案和工作任务进行细化分解各项措施，同时，充分利用各类宣传载体，广泛开展宣传，教育经营者，增强群众的参与意识。
（二）部门联动，形成合力。各成员单位要发挥各自职能作用，加强工作中的沟通、协调，相互支持，相互配合，齐抓共管，切实形成上下联动、部门联动、地区联动的综合治理局面和强大的整治合力。
（三）加强监督，着眼长效。各成员单位要注重工作实效，开展定期或动态评，对检查中发现问题的规模化租赁住宿场所列为整改重点，逐一指导、督促落实整改措施，并对整改情况进行复查验收，维护镇域内规模化居住租赁场所良好的经营秩序。
