# 关于本市部分房车租赁企业车辆额度超期失效的公告

为进一步规范本市房车租赁行业管理，促进房车租赁市场规范有序发展，经梳理研究，部分房车租赁企业已获批的房车租赁额度，未在批复有效期内办理上牌和营运证件等手续，已处于超期状态，现决定对相关获批的房车租赁车辆额度作失效注销处理（清册附后），且自公告发布之日起，一年内遇行业投放经营性房车租赁车辆额度时，相关企业原则上不予考虑新增。

其他尚在批复有效期内的房车租赁车辆额度，如在批复一年内未能及时办理上牌和营运证的，相关批复额度自动失效注销。

附件：部分企业房车额度到期注销清册
