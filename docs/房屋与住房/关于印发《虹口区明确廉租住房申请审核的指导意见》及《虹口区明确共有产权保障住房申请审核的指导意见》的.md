# 关于印发《虹口区明确廉租住房申请审核的指导意见》及《虹口区明确共有产权保障住房申请审核的指导意见》的通知

各街道办事处：

根据《上海市廉租住房申请审核实施细则》（沪房规范〔2019〕10号）、《上海市共有产权保障住房申请、供应审核实施细则》（沪房规范〔2019〕22号）、《上海市廉租住房租金配租管理实施细则》（沪房规范〔2019〕8 号）文件内容，并按照区纪委监委、审计局等部门的要求，制定了《虹口区明确廉租住房申请审核的指导意见》和《虹口区明确共有产权保障住房申请审核的指导意见》，现印发给你们，请认真按照执行。
