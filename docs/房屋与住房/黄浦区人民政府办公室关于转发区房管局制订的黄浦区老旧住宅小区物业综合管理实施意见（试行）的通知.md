# 黄浦区人民政府办公室关于转发区房管局制订的黄浦区老旧住宅小区物业综合管理实施意见（试行）的通知

区政府各委、局、办，各街道办事处，各有关企业（集团）公司：

区房管局制订的《黄浦区老旧住宅小区物业综合管理实施意见（试行）》已经区政府同意，现转发给你们，请认真按照执行。

特此通知。

上海市黄浦区人民政府办公室

2019年4月17日

黄浦区老旧住宅小区物业综合管理

实施意见（试行）

为进一步提升黄浦老旧住宅小区物业管理水平，依据《上海市住宅物业管理规定》、《黄浦区住宅小区建设“美丽家园”三年行动计划（2018-2020）》等法规及文件要求，结合黄浦实际，不断完善老旧住宅小区物业管理模式，制定工作实施意见（试行）。

一、高瞻远瞩，明确总体工作目标

（一）指导思想。按照“一流城市要有一流治理”的总体要求，不断深化市委“1+6”文件精神，加强“创新社会治理，加强基层基础建设”，聚焦打造“四个标杆”、“四个前列”、“四个进一步”的黄浦发展定位，对标城市精细化管理要求，聚焦居住条件最为薄弱的老旧住宅小区，全面推行物业综合管理工作，提升老旧住宅小区物业管理水平，改善群众居住品质。

（二）基本原则。老旧住宅小区物业综合管理工作应当遵循以下原则。一是以人为本。在改革探索中保障和改善民生，以群众满意为出发点和落脚点，坚持问题导向、需求导向、实效导向，直面管理最短板，回应群众最企盼，提供更优质、更充分的物业管理服务，全力满足群众日益增长的对美好生活的需要。二是规范统一。倡导精细化管理的理念，加强顶层设计，全方位、多层次梳理重构老旧住宅小区物业综合管理体系，形成全区统一的管理模式与操作口径，推动管理品质提升。三是系统协同。注重部门间的协同合作，管理资源的集中统筹，实现小区内外的相互衔接，管理内容的无缝覆盖；系统性优化工作机制，突出协同配合。

（三）具体目标。在城市精细化管理的框架下，通过实施老旧住宅小区物业综合管理，构建主体明晰、权责明确、条块协同、内外互补、系统运作的老旧住宅小区物业综合管理工作格局，形成各方协同的管理机制、构建多方参与的评价体系、凸显科学高效的资金使用效果，打造一批具有黄浦特色的管理示范小区，以点带面形成辐射效益，让老旧住宅小区“环境更优美、居住更安全、服务更优质、秩序更井然”，促使管理能级显著提升、群众满意度显著提升，让老小区焕发新活力。

二、有分有合，明晰各方职责定位

（四）构建统筹协调平台。以区住宅小区综合治理联席会议为依托，区级层面落实党政双牵头责任，统筹协调指导全区老旧住宅小区物业综合管理工作。整合条线部门、街道、企业集团等各方职能，有效整合行政管理、执法、专业组织等多方力量，强化信息联通、治理联动，分层分级系统推进。

（五）明确各方工作职责。坚持“条线定标准规范、街道重协调推进、企业抓具体实施”的工作思路，各相关部门、街道、企业集团依据自身职责，落实管理职能。

区房管局:细化推进老旧住宅小区物业综合管理工作，形成具体的管理标准、要求。依法落实行业监管与指导责任，明确物业管理的总体服务内容、细化行业标准和规范。

区绿化市容局:明确老旧住宅小区内“保洁”与“保绿”的具体要求与规范，牵头指导住宅小区垃圾分类工作。

区财政局：落实老旧住宅小区物业综合管理工作的资金保障。

各街道：具体实施老旧住宅小区物业综合管理的日常监管，会同企业集团确定管理单元，整合小区内房屋管理、绿化市容、城管执法、社会组织等各方力量，统筹协调推进辖区内老旧住宅小区物业综合管理工作。

企业集团（即：永业集团、南房集团、金外滩集团）：落实老旧住宅小区物业综合管理工作的主体责任，具体实施物业综合管理服务，并落实文明创建、美丽家园建设等具体工作任务。

其他相关职能部门与单位依据自身职责落实对老旧住宅小区的管理工作。

三、统筹布局，合理设置管理单元

（六）规划先行、街道统筹。在城市精细化管理的总体框架下，坚持规划先行，综合考虑城区功能定位，加强城区功能规划和环境设计，优化空间格局。按照“管建并举，重在管理”的要求，各街道统筹辖区内环境综合整治、无违小区创建、老旧房屋修缮等各类实事项目，并叠加实施老旧住宅小区物业综合管理，系统谋划、分步实施，逐区域改善老旧住宅小区面貌。

（七）科学划分、分类施策。管理单元设置应当从有效管理、节约成本的角度出发，兼顾房屋类型以及街坊形态，优化管理单元设置。倡导增设“智慧公安”等技防设施实现组合式管理，探索打破“围墙壁垒”，实现集约化管理。以“新里促提升、旧里保基本、售后房重整合、老大楼管安全”为基本思路，因地制宜叠加不同管理侧重点，逐个小区提出针对性工作方案，实现老旧住宅小区精细化管理。

四、系统思维，协同实施关键制度

（八）统筹管理制度。建立奖惩激励、日常考核、管理标准相互协同的运作体系。按照管理标准的要求实施日常考核，考核结果与奖惩激励相关联，三者有机结合、协同实施，不断促进老旧住宅小区物业综合管理水平提升。

（九）完善标准体系。全区执行统一的老旧住宅小区物业综合管理工作标准，推动实现全区老旧住宅小区物业管理的标准化与规范化。基于老旧住宅小区现有基础情况，分类设置管理标准，包含保障型、整洁型和宜居型小区三大类型，内容涵盖物业管理的基础性要求和特殊性要求等。

（十）多方联动考奖。实施定期考核制度，相关条线部门、各街道、企业集团、居民共同参与，并组织第三方开展满意度专项测评，全面、真实、客观反映物业小区的管理实效。综合各类奖惩制度运用，汰弱留强，优化老旧住宅小区物业管理企业队伍。

（十一）综合经济效益。进一步激励企业参与老旧住宅小区物业综合管理工作。根据小区规模、房屋类型、居住密度、特殊管理事项等具体情况，多措并举，奖惩并施，激励物业企业提升服务品质。

五、探索创新，有效落实工作举措

（十二）完善社区共建共治。将老旧住宅小区物业综合管理工作纳入我区“美丽家园”建设体系。进一步理顺居委会、业委会、物业公司三驾马车关系，积极探索鼓励规划设计、律师团队、专业社会组织等参与老旧住宅小区物业综合管理，提升居民参与物业管理的意识，多维度、多层次推动小区物业综合管理。增强群众自治和社会共治合力，紧紧依靠社区综合治理平台，发挥党组织在基层社会治理中的核心作用，持续培育居民自我管理、自我监督的社区自治共治模式，充分发挥楼组长等自治骨干作用，动员更多居民参与物业综合管理工作，实现老旧住宅小区“协作共管、责任共担、成果共享”的工作格局。

（十三）持续抓好队伍建设。强化监管队伍，整合城管、市场监管、文化、公安等多条线执法队伍，共破管理顽症；做实应急抢险队伍，配强物资、人员，兜住老旧住房安全底部；培育小区经理队伍，抓住老旧住宅小区物业综合管理关键核心，倡导物业企业管理扁平化；引入专业保安、保洁队伍，以专业管理手段促进成本控制。

（十四）探索全新管理方式。在老旧住宅小区物业综合管理中引入集约化、智能化的管理手段，着力推动建设老旧住宅小区物业综合管理智能化平台，全面、及时、动态反映小区基础现状、管理巡查、问题发现与整改，实现设备、立面等安全数据的部门间共享与互推。

（十五）鼓励打造创新亮点。将老旧住宅小区物业综合管理纳入社区综合治理工作平台，更好地发挥小区居委会、业委会以及物业企业的协同作用，积极引导鼓励街道创新，赋予其更大的职权，充分考虑地缘实际，结合群众所需所盼，提供个性化服务，打造管理亮点，提升老旧住宅小区物业综合管理品质。
