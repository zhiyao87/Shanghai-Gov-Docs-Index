# 上海市住房和城乡建设管理委员会关于公布2025年度本市建筑工程领域拖欠农民工工资失信企业和项目名单（第二批）的通报

上海市住房和城乡建设管理委员会关于公布2025年度本市建筑工程领域拖欠农民工工资失信企业和项目名单（第二批）的通报

沪建建管〔2026〕54号

各有关单位：

根据《保障农民工工资支付条例》（国务院令第724号）、《上海市建设工程招标投标管理办法》（沪府令50号）、《关于进一步完善本市建筑工程拖欠农民工工资管理工作的通知》（沪住建规范〔2022〕13号）等文件精神，现对2025年度本市建筑工程领域发生的拖欠农民工工资事件中负有相应责任的失信企业、负责人及项目进行通报（名单详见附件）。

一、自通报公布之日起，被列入名单的企业执行以下惩戒措施：

（一）根据相关规定，提高工资保证金的存储比例；

（二）1个月期限内不得参加本市建设工程的招投标报名；

（三）作为经认定的不良行为信用信息，属于建筑业企业的，扣除企业本年度信用评价分２分。

二、市、区建设管理部门应将被列入通报名单的责任企业及其负责人作为重点监管对象，在开展工地实名制管理、市场承发包行为巡查等监督管理时，覆盖全面检查，提高检查频次，加强违法查处，督促企业落实好本市建筑工人工资支付管理办法，切实保障建筑工人工资权益。

附件：2025年度本市建筑工程领域拖欠农民工工资失信企业和项目名单（第二批）

2026年2月11日
