# 关于取消不符合评审条件企业新增汽车租赁专用额度的公告

根据相关工作要求，市道路运输局对2022年年末评审通过的994家获批新能源租赁汽车专用营运额度企业的参评条件进行了复核，现将发现的不符合条件企业及处理措施公告如下：

根据《关于同意上海江南旅游服务有限公司等994家企业新增新能源汽车租赁车辆专用营运额度的通知》（沪道运客〔2022〕223号）中“2022年新能源租赁汽车车辆专用营运额度评审规则”相关“否决指标”的规定，经复核，994家按专家打分评审通过的企业中，35家拟从事汽车租赁经营的企业存在“否决指标”，不符合通过条件：25家企业曾被列入道路运输行业严重失信主体名单；10家企业参评材料中，注册资本不足50万元（详见附表）。

按照“公开、公平、公正”的评审原则，市道路运输局决定取消上述不符合条件企业获批资格，停止办理相关额度使用手续；对已办理额度启用的，收回相关额度。

特此公告。

上海市道路运输管理局
