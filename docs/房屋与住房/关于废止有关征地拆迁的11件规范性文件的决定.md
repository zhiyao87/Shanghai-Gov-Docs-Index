# 关于废止有关征地拆迁的11件规范性文件的决定

区政府各委、办、局，各街道办事处、五角场镇政府：

根据《上海市人民政府办公厅关于做好有关征地拆迁的规章和规范性文件清理工作的通知》的要求和《上海市行政规范性文件制定和备案规定》的有关规定，区政府对本区有关征地拆迁的规范性文件进行了专项清理。经过清理，区政府决定废止下列11件区政府规范性文件：

1、《上海市杨浦区人民政府印发关于贯彻<上海市城市房屋拆迁管理实施细则>试行意见的通知》（杨府发〔2001〕20号）

2、《上海市杨浦区人民政府关于征用集体所有土地拆迁房屋补偿安置有关标准的通知》（杨府发〔2003〕10号）

3、《上海市杨浦区人民政府关于调整2004年度征用集体所有土地拆迁房屋补偿安置有关标准的通知》（杨府发〔2004〕16号）

4、《上海市杨浦区人民政府关于调整2004年度城市房屋拆迁补偿安置有关标准和规定的通知》（杨府发〔2004〕17号）

5、《上海市杨浦区人民政府关于印发修订后的<上海市杨浦区房屋拆迁行政强制执行暂行规定>的通知》（杨府发〔2005〕5号）

6、《上海市杨浦区人民政府关于进一步加强本区房屋拆迁管理工作的通知》（杨府发〔2005〕11号）

7、《上海市杨浦区人民政府关于印发〈上海市杨浦区政府性投资项目动拆迁资金监督管理办法〉的通知》（杨府发〔2005〕18号）

8、《上海市杨浦区人民政府关于印发<上海市杨浦区政府性投资项目动拆迁房源统筹使用管理办法>的通知》（杨府发〔2005〕19号）

9、《上海市杨浦区人民政府关于调整2005年度征用集体所有土地拆迁房屋补偿安置有关标准的通知》（杨府发〔2005〕26号）

10、《上海市杨浦区人民政府关于调整2005年度城市房屋拆迁补偿安置有关标准和规定的通知》（杨府发〔2005〕27号）

11、《上海市杨浦区人民政府关于公布2006年度城市房屋拆迁补偿安置有关标准和规定以及征用集体所有土地拆迁房屋补偿安置有关标准的通知》（杨府发〔2006〕28号）

本决定自发布之日起生效。

二○一一年十二月八日
