# 关于印发《松江区房票安置实施办法（试行）》的通知

区发展改革委、区国资委、区司法局、区人力资源社会保障局、区民政局、区财政局、区审计局、区规划资源局、区税务局、经开区、各街镇：

现将《松江区房票安置实施办法（试行）》印发给你们，请遵照执行。

松江区住房保障和房屋管理局     松江区规划和自然资源局
2025年11月20日

松江区房票安置实施办法（试行）

为进一步拓宽我区居住房屋被补偿人安置渠道，满足多元化安置需求，保障被补偿人合法权益，加快安置进度，实现集约增效土地利用，根据本市有关规定，制定本办法。

一、适用范围

本办法适用于本行政区域内国有土地、集体土地上居住房屋被依法征收的被补偿人选择房票安置，并在本区购买商品房的相关活动。

二、房票内容

（一）房票定义

本办法所称房票，是指由区房管局、区规划资源局（以下称为“房票核发单位”）作为实施主体将居住房屋征收补偿资金核算后，出具给被补偿人在规定时间、规定区域内用于购置商品住房的结算凭证。房票样式由区房管局统一印发，由房票核发单位按需申领，并做好核销台账。

（二）票面金额

国有土地上可购买房票的金额由被征收居住房屋货币补偿金额（含被征收房屋市场评估价、价格补贴、套型面积补贴、居住困难户补贴、搬迁费和临时安置费、奖励费）和房票使用奖励金额构成。

集体土地上可购买房票的金额是由政府配套商品住房回购金额（政府配套商品住房回购面积乘以政府本区域内配套商品住房回购单价，并扣除购买政府配套商品住房应支付的费用）和被征收房屋及附属物市场评估价、搬家补助费、设备迁移费、临时安置补助费、按时搬迁奖励费、房票使用奖励金额等构成。政府配套商品住房面积由街镇核定，政府配套商品住房回购价格由区相关部门根据相关规定确定。

（三）安置方式

房票安置是货币安置方式的一种补充，以被补偿人自愿为原则，从我区新建商品住房“房源超市”中选择房源，利用房票自行向房地产开发企业购买商品住房的一种安置方式。

被补偿人可选择货币补偿、房票安置、政府建设配套商品住房安置，或多种安置方式相结合，具体由房屋征收部门根据实际情况制定“一基地一方案”。街镇开展的协议置换涉及国有土地上的项目，相关工作方案需向区房管局报备；涉及集体土地上的项目，相关工作方案则需向区规划资源局报备。

三、房票房源

本区房地产开发企业以自愿参与为原则，通过意愿征集、综合评估、平等协商，签订协议后，纳入“房源超市”，相关房源楼盘位置、销售备案价、房源户型、交房日期等基本信息应在征收基地内进行公示，相关楼盘信息应及时更新。纳入“房源超市”中的新建商品住房应是已取得新建住宅交付使用许可证的现房或工程进度已整体达到结构封顶的期房，并均应为已取得商品房预（销）售许可证。

四、使用规则

（一）实名登记

房票实行实名制，核发对象为被补偿人，在使用期限内不得转让、赠与、抵押、质押、套现。被补偿人有多人的，经全体被补偿人协商一致，房票可作为指定的被补偿人使用。经与持有人协商一致，并完成公证的，可为直系亲属（配偶、父母、子女）使用。

（二）房票核发

选择房票安置的，由房票核发单位以户为单位，在补偿协议约定期限内向被补偿人核发房票。房票一式两份，房票核发单位、被补偿人各持一份。房票应带有唯一识别码。房票金额确认后不得更改，不计息。

（三）有效期限

房票有效期限自房票核发之日起算，原则上有效期限为6个月，房票持有人应在房票有效期内使用。需延期使用的，应在有效期届满前１个月提出申请，可延期6个月，延期仅限1次，延期后房票有效期合计时长不超过1年。

（四）支付、兑换

房票持有人购买可购房源时，持房票及补偿协议，与房地产开发企业签订商品住房购房合同。房票应优先全额使用。在购房政策允许范围内，票面金额不足以支付购房款的，可自行支付房款差额，也可按规定办理商品住房贷款。房票核发单位根据有效的房票凭证及购房合同，与房地产开发企业结算房票对应的资金。若支付购房款全额后仍有余额，票面金额使用未达到85%的，房票余额在扣除与该未使用比例相对应的房票使用奖励后，由房票核发单位按照“一基地一方案”及补偿协议进行货币结算；票面金额使用达到85%的，房票余额可兑换成等额货币。

（五）房票继承、挂失

房票持有人亡故的，其继承人凭具有法律效力的公证书、法院生效文书等继承证明材料，向房票核发单位申请办理房票更名手续，使用期限不变。房票持有人应当妥善保管房票，如有遗失，应及时向房票核发单位办理挂失补办手续。因房票遗失引起财产损失等后果的，相关责任由房票持有人自行承担。

（六）房票结算

房票使用过程中，房地产开发企业应与房票持有人及房票核发单位确认房票有效性及使用金额。后续，房票核发单位根据确认金额，并按照“一基地一方案”中明确的时间节点进行房票结算。

（七）房票资金管理

房票安置资金应实行闭环管理，房票核发单位应存入专用账户，专款专用，确保资金安全。房票核发单位与房地产开发企业结算资金纳入商品住房预（销）售资金监管。

（八）退出机制

自核发房票之日起2个月内，被补偿人不得变更已选择的房票安置方式。2个月期满且在房票有效期内，房票持有人放弃房票的，按照征收补偿协议约定明确的其他方式进行补偿，但不再享受房票使用奖励。

房票持有人逾期（原则上有效期限为6个月）未使用房票，或申请延期后到期还未使用房票的，扣除房票使用奖励额度后，按照征收补偿协议约定明确的其他方式进行补偿。

房票核发单位自收到房票持有人申请之日起20个工作日内，按照征收补偿协议约定明确的其他方式进行补偿，房票核发单位收回房票。

五、奖励和优惠政策

（一）房票使用奖励

对选择房票安置方式的，给予房票使用奖励，奖励金额具体以“一基地一方案”为准。

（二）税收优惠政策

税收优惠政策按国家、市相关政策执行。

（三）“房源超市”优惠

“房源超市”内商品住房，在本市相关规定允许范围内，房地产开发企业予以购房者一定比例优惠。

六、责任追究

（一）参与房票安置的房地产开发企业应诚实守信、合法经营，存在弄虚作假、提供不实信息等行为的，终止其参与房票安置资格，造成损失的应依法承担赔偿责任。严禁与被补偿人合谋非法套现房票，并建立信息共享机制，杜绝套现问题发生，否则将依法追究相应法律责任。

（二）房票核发单位及相关单位，要严格执行征收安置相关政策及规定，对弄虚作假，或者擅自突破政策标准、拒不执行相关规定的，依法追究相关单位和人员责任。

七、其他事项

（一）被补偿人指征收国有土地房屋征收补偿的房屋所有人或执行政府规定租金标准的房屋承租人以及集体土地房屋补偿的宅基地使用人或房屋所有人。

（二）国有土地和集体土地上居住房屋协议置换项目可参照执行。

（三）“松江区G60科创走廊优秀人才”人才房票可参照执行。

（四）本《实施办法（试行）》由区房管局、区规划资源局根据各自职责负责解释。

（五）本办法自2025年12月21日起施行，有效期至2027年12月20日。本办法失效后，原发放的房票在本办法规定的房票的有效期限内仍然有效。

（六）凡与上级文件规定不一致的内容，按照上级文件相关规定执行。
