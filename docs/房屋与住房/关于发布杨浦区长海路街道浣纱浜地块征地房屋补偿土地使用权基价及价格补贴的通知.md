# 关于发布杨浦区长海路街道浣纱浜地块征地房屋补偿土地使用权基价及价格补贴的通知

区政府各委、办、局，各街道办事处：

根据上海市人民政府《上海市征收集体土地房屋补偿规定》(沪府规〔2021〕13号)规定，就杨浦区长海路街道浣纱浜地块征地房屋补偿土地使用权基价及价格补贴标准，已经区政府常务会议审议通过，请认真遵照执行。

一、土地使用权基价标准及价格补贴系数

区  域
同区域新建商品住房每平方米建筑面积的土地使用权基价（元/平方米）
价格补贴系数

黄兴路以东，翔殷路以南，军工路以西，虬江以北
55000
30%

二、价格补贴标准

价格补贴=(房屋建安重置结合成新均价+同区域新建商品住房每平方米建筑面积的土地使用权基价)×价格补贴系数。
