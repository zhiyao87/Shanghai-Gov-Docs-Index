# 上海市房屋管理局关于印发《本市建设单位、业主大会选聘物业服务企业的相关示范文本》的通知

各区房屋管理局、建设单位、业主委员会、物业服务企业、招标代理机构，各相关单位：

根据《上海市住宅物业管理规定》《关于进一步规范本市物业管理招投标工作的若干意见》等相关规定，结合本市物业管理实际情况，我局制定了《本市建设单位、业主大会选聘物业服务企业的相关示范文本》，自发文之日起施行。

上海市房屋管理局

2021年6月5日
