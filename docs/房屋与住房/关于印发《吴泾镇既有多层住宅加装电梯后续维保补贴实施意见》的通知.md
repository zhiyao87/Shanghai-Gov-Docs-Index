# 关于印发《吴泾镇既有多层住宅加装电梯后续维保补贴实施意见》的通知

关于印发《吴泾镇既有多层住宅加装电梯
后续维保补贴实施意见》的通知

机关各办（部门），各街区、居、村委，镇属事业单位（公司）：
《吴泾镇既有多层住宅加装电梯后续维保补贴实施意见》经党委、政府审议通过，现印发给你们，请认真组织学习，抓好贯彻落实，确保各项目标任务圆满完成。

闵行区吴泾镇人民政府
2025年3月6日

吴泾镇既有多层住宅加装电梯后续维保
补贴实施意见

为加快推进既有多层住宅加装电梯工作，激励广大居民群众积极参与，经镇政府研究，对镇域内加装电梯的楼道予以后期维保专项补贴。具体办法如下：
一、补贴范围
完成竣工验收的加装电梯楼道，含龙吴路5530弄小区旧房改造期间新增的加梯楼道。
二、补贴条件和金额
签订既有多层住宅加装电梯合同并取得特种设备使用许可证的加装电梯楼道，可申请补贴资格。补贴资金以楼道为单位发放。
1.住宅小区零星代建且独立作项目报建的加装电梯，每台补贴人民币6万元整。
2.龙吴路5530弄小区在旧房改造期间新增加装电梯，即旧改项目预算中已涵盖附属井道且不可独立作项目报建的新增加装电梯，每台补贴人民币3万元整。
三、补贴申请程序
1.申请：符合申报补贴资金的加装电梯楼道，在取得电梯特种设备使用许可证后，由楼组出资业主(代表)向镇加梯办申请，并提供加梯合同和特种设备使用许可证。
2.审核：镇加梯办初审后，报镇加梯领导小组复审。
3.资金发放：在电梯投入使用、出资业主与授权管理单位签订委托管理协议（确定后期使用管理、维保责任、安全职责）后，镇财政所发放补贴资金。
四、资金使用范围
补贴资金须统一使用，仅用于电梯、电梯紧急报警装置以及新增设施设备的日常管理、维护保养、改造、修理、检验、检测、安全评估以及委托他人管理服务或者购买相关保险等方面的支出，不得挪作他用。资金使用时，需经楼道出资业主三分之二及以上同意。
五、资金管理
补贴资金划入出资楼道专用账户，归楼道全体出资业主所有。该项资金按照专用共管账户资金管理程序使用，由镇财政所负责审计、监督。被补贴楼道或其委托管理方须做好与补贴资金使用有关的资料归档工作，如台账、发票、合同等，以便核查。
六、其他
本补贴实施办法有效期至2026年6月30日，未尽事宜由镇加梯办负责解释说明。如在执行期间遇法律、法规、政策、规范性文件有调整的，则以调整后的文件或上级政策为准。
