# 上海市住房和城乡建设管理委员会关于印发《上海市海绵城市建设景观设计导则》的通知

上海市住房和城乡建设管理委员会关于印发《上海市海绵城市建设景观设计导则》的通知

沪建综规〔2025〕540号

各有关单位：

为进一步落实《本市系统化全域推进海绵城市建设的实施意见》（沪府办发〔2024〕3号）要求，统一建设项目景观美学效果和雨洪管理需求，提高海绵设施的景观价值和民众接受度，我委制定了《上海市海绵城市建设景观设计导则》。现予以印发，请各相关单位参照本导则内容做好海绵设施的景观设计和建设。

2025年10月23日
