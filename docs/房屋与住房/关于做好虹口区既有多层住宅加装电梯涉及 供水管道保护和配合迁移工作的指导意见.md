# 关于做好虹口区既有多层住宅加装电梯涉及 供水管道保护和配合迁移工作的指导意见

各街道办事处、加装电梯相关单位、供水企业：

为进一步推进虹口区既有多层住宅加装电梯工程，做好涉及供水管道保护及配合迁移，在加速推进电梯加装的同时有序保障供水管道运行安全，根据《关于转发〈关于做好既有多层住宅加装电梯项目供水配套项目的工作要求〉的通知》（沪供水〔2022〕33号）等文件要求，结合本区实际情况，制定本意见：

一、明确职责

（一）加装电梯所有权人

加装电梯所有权人（或受委托的代建单位）应主动向供水企业进行前期征询，未明确管线情况前，严禁开挖施工。如需对部分供水管线进行迁移，按要求申请办理。

（二）供水企业

对加装电梯所有权人（或受委托的代建单位）提出的征询需求应及时、准确予以答复。做好日常供水管道巡查，对涉及供水管道做好监护。对管道迁移申请应及时组织力量实施，确保加装电梯工作顺利推进。

二、办理流程

（一）前期征询

加装电梯所有权人（或受委托的代建单位）向供水企业提交《既有多层住宅小区加梯工程供水设施配合申请单》（附件1）。

供水企业受理后进行现场踏勘，确定加装电梯影响范围内是否存在需保护的供水管道。满足以下任意一条，供水设施需进行迁移：

1.小区内新建电梯外墙位置距供水管道外壁净距小于1米；

2.电梯建成后不满足供水设施养护要求。

对仅涉及保护的项目，供水企业以《供水设施无需迁移确认单》（附件2）形式予以确认。

对涉及迁移的项目，供水企业以《上水管线交底意见书》（附件3）形式予以确认。

（二）管道配合迁移

供水管道迁移由加装电梯所有权人（或受委托的代建单位）作为合同主体，负责申请办理业务。

1.申请受理

申请方需提交的材料如下：

（1）业委会加装电梯的相关授权证明

（2）加装电梯设计图

（3）加装电梯工程供水管线配合申请单

（4）上水管线交底意见书

供水企业收到资料起1个工作日内完成资料审核，资料缺失申请方应按要求补齐。

2.设计施工

申请受理材料齐全后，供水企业在2个工作日内完成现场勘察（另行约定日期除外），并完成申请受理。现场勘察后3个工作日内制定方案并编制预算，双方确认后签订合同。满足施工条件后，供水企业安排人员进场施工，加装电梯的供水配套施工周期不超过8个工作日。

3.费用计算

供水企业严格按照《上海市城镇给排水工程预算定额》（SHAB-31-2016）、《上海市安装工程预算定额》(SH02-31-2016)、《上海市房屋建筑工程养护维修预算定额》(SH00-41-2016)相关规定编制施工预算。

4.服务评估

施工完成后，供水企业主动进行用户满意度调查回访，发放《客户满意度回访单》（见附件4），及时了解意见和建议，以优质、便捷的服务态度，不断提升用户满意度。

三、工作要求

（一）各街道在报送《联审平台过渡期间开工项目清单》前，应先确认项目已取得《供水设施无需迁移确认单》或《上水管线交底意见书》，并将其作为附件一并报送至区房管局。

（二）供水管理部门将会同供水企业加强对供水设施的巡查和保护，并依据《上海市供水管理条例》等法律法规对影响供水管道设施安全的有关行为实施查处。若电梯加装建设单位未办理相关手续，擅自施工，供水企业将上报信息，由相关执法单位进行处置。

本指导意见自发布之日起施行。
