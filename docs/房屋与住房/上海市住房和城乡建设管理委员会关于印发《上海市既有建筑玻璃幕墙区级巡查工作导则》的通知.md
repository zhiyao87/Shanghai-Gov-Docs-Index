# 上海市住房和城乡建设管理委员会关于印发《上海市既有建筑玻璃幕墙区级巡查工作导则》的通知

上海市住房和城乡建设管理委员会关于印发《上海市既有建筑玻璃幕墙区级巡查工作导则》的通知

沪建质安〔2023〕385号

各区建设行政管理部门、房屋行政管理部门，特定地区管委会，各有关单位：

为进一步落实《上海市建筑玻璃幕墙管理办法》，加强本市既有建筑玻璃幕墙建筑监督管理，降低玻璃幕墙高坠风险，现将《上海市既有建筑玻璃幕墙区级巡查工作导则》印发给你们，请遵照执行。

2023年7月31日
