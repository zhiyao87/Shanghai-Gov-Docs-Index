# 上海市住房和城乡建设管理委员会关于发布《上海市建筑信息模型技术应用指南（2025版）》的通知

上海市住房和城乡建设管理委员会关于发布《上海市建筑信息模型技术应用指南（2025版）》的通知

沪建建管〔2025〕238号

各有关单位：

为进一步提升BIM技术应用，贯彻落实《上海市全面推进建筑信息模型技术深化应用的实施意见》（沪住建规范联〔2023〕14号）中关于“升级完善相关BIM技术应用指南”工作要求，我委结合最新的行业规范和市场需求，组织对《上海市建筑信息模型技术应用指南（2017版）》进行了修订，对应用项和内容进行了全面梳理和提升，编制完成了《上海市建筑信息模型技术应用指南（2025版）》，现予以发布，请遵照执行。
