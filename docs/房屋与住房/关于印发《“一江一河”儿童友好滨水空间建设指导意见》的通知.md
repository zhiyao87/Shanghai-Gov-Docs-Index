# 关于印发《“一江一河”儿童友好滨水空间建设指导意见》的通知

关于印发《“一江一河”儿童友好滨水空间建设指导意见》的通知

沪建浦江联〔2023〕637号

各相关区，各有关部门、单位：

为贯彻落实《上海市推进儿童友好城市建设三年行动方案（2023-2025）》相关工作要求，推动黄浦江、苏州河“一江一河”沿岸地区建成儿童友好、人人友好的滨水空间，形成与世界级滨水区相匹配的儿童友好滨水品牌，市住房城乡建设管理委（市“一江一河”办）、市发展改革委、市妇儿工委办联合制定了《“一江一河”儿童友好滨水空间建设指导意见》，现印发给你们。请各有关区、各有关部门和单位结合年度工作重点，细化任务目标，持续推进落实。

市发展改革委
