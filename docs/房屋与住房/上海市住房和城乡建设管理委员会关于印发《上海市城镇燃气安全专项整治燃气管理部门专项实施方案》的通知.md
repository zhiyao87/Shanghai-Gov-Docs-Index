# 上海市住房和城乡建设管理委员会关于印发《上海市城镇燃气安全专项整治燃气管理部门专项实施方案》的通知

上海市住房和城乡建设管理委员会关于印发《上海市城镇燃气安全专项整治燃气管理部门专项实施方案》的通知

沪建设施〔2023〕478号

各区城镇燃气安全专项整治工作专班、燃气管理部门，市燃气管理事务中心，各相关单位：

为做好本市城镇燃气安全专项整治工作，依据专项整治工作的主要任务和职责分工，我委制定了《上海市城镇燃气安全专项整治燃气管理部门专项实施方案》，现印发给你们，请遵照执行。

2023年9月12日
