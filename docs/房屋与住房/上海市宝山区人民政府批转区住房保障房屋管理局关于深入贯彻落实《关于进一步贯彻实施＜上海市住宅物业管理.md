# 上海市宝山区人民政府批转区住房保障房屋管理局关于深入贯彻落实《关于进一步贯彻实施＜上海市住宅物业管理规定＞的若干意见》的通知

各镇人民政府，各街道办事处，区政府各委、办、局：

区住房保障房屋管理局制订的《关于深入贯彻落实<关于进一步贯彻实施《上海市住宅物业管理规定》的若干意见>的通知》，已经区政府同意，现转发给你们，请认真按照执行。

上海市宝山区人民政府

2017年2月13日

关于深入贯彻落实《关于进一步贯彻实施

<上海市住宅物业管理规定>的若干

意见》的通知

为深入贯彻落实《关于进一步贯彻实施＜上海市住宅物业管理规定＞的若干意见》（沪府发〔2016〕94号）（以下简称《若干意见》），在创新社会治理中，不断提高宝山区住宅物业管理水平，不断提升居民的满意度和获得感，现就有关事项通知如下：

一、充分认识贯彻落实《若干意见》的重要意义

住宅小区是市民群众生活的基本场所、城市管理的基础单元、社会治理的重要领域。加强住宅物业管理、提升住宅小区综合治理水平，是全面落实市委、市政府关于创新社会治理、加强基层建设要求的重要内容，也是提升群众感受度、获得感的必然要求。《若干意见》的出台，为规范物业管理活动、保障业主和物业管理企业合法权益、提升住宅小区综合治理水平提供了政策支撑，对于完善基层社会治理体系、提高基层社会治理能力，具有十分重要的基础意义。

各部门、各单位要把贯彻落实《若干意见》放到“创新社会治理加强基层建设”的大格局中加以把握，作为当前一项重要工作来抓；要认真制定并组织实施《若干意见》的学习、宣传和培训计划，通过举办培训班、召开座谈会、发放宣传材料、组织现场咨询等多种方式，帮助物业服务企业、业主委员会、业主等相关主体深刻了解、领会《若干意见》精神和条文基本含义。

各部门、各单位要全面落实《若干意见》中明确的责任分工。房屋管理、民政、城管执法、市场监管、绿化市容、规划土地、消防、环保等相关职能部门要着重加强对街镇（园区）的服务和统筹协调，做好政策咨询和业务指导，帮助处理紧急事务，协调解决居民反映强烈的突出问题。各街镇（园区）要切实承担起住宅物业管理的属地主体责任，建立健全联席会议机制，落实负责部门，充实人员力量，解决区域住宅物业管理的疑难问题；要积极搭建社区党建的载体平台，优化党组织领导下的社区事务协商制度，把党组织的领导核心作用落到实处，尤其要重视做好业主委员会、物业公司中的党建工作，推动在业主委员会设立党的工作小组，深化物业党建联建等，通过党的工作的加强推进治理架构中各方关系的协调。各居民区要进一步强化指导和监督责任，建立健全以居民区党组织为领导核心，居民委员会为主导，居民为主体，业主委员会、物业公司、驻区单位等共同参与的居民区治理架构，为提高基层治理能力提供重要支撑。

二、切实提高物业行业管理水平

物业服务企业作为社区多元治理主体中的一支重要力量，其服务水平的高低直接影响着居民对居住环境的感受度。《若干意见》对物业服务企业的“委托聘用、合同签订、纠纷处理、委派经理、物业收费、维修基金使用”等从业行为作了规定。区住房保障房屋管理局、各街镇（园区）要切实按照《若干意见》的要求，加强指导、服务和监督，推动和帮助物业服务企业不断提高物业管理水平。

（一）要加强物业服务企业管理。建立健全业务指导和监督管理制度，加强对物业服务企业行业管理，开展对物业企业行业规范服务的动态检查。加大对物业服务企业和项目经理诚信信息的检查力度。加强对物业企业的督察，规范物业服务企业管理行为。

（二）要建立物业服务市场机制。引导业主委员会和物业服务企业按照“按质论价、质价相符”的原则，协商确定物业服务内容和收费标准。建立物业达标考评奖励机制，鼓励物业服务企业做好基本服务。探索推进酬金制。

（三）要做好物业服务托底保障。各街镇（园区）要结合本地区实际，建立和完善物业服务应急机制，对暂无专业单位管理的住宅小区，建立以保障特种设备、消防设施运行安全和应急维修、生活垃圾清运等基本生活服务为重点的应急处置机制，并确定应急物业单位。对物业服务企业或专业服务机构突然撤离、业主大会无法及时选聘物业服务单位的住宅小区，可应业主委员会要求，指定临时托管单位。

三、切实加强对业主委员会的指导和监督

业主委员会的健康发展是推进基层社区治理的基础和前提，它在协调业主与物业之间、业主相互之间利益上有着不可替代的作用。各相关职能部门、各街镇（园区）要切实按照《若干意见》的要求，重视和规范业主大会、业主委员会的组建、换届和日常运作工作，切实提升业主自我管理能力。

（一）要认真做好业主委员会的制度建设和培训工作。进一步提高业委会组建率，重点指导新组建的业主委员会建立业主接待、信息发布、印章管理、档案管理、业务学习、矛盾协调工作会议等制度，督促其加强内部管理。做实居民委员会参加业主委员会等相关会议的工作制度。对所有业主委员会成员进行轮训，提升业主委员会依法办事的能力和水平。

（二）要更加加强对业主大会、业主委员会日常运作的指导和监督。建立对业主委员会运作的评价制度，重点规范日常工作制度、物业服务企业选聘、维修资金及公共收益的使用管理等，提高业主委员会规范运作率。对选聘物业服务企业、实行自我管理、使用专项维修资金等涉及大多数居民群众利益的事项，居民委员会应督促业主委员会依法召开业主大会，广泛征求业主意见并形成决议。

（三）要完善优化业主自我管理机制。根据本市住宅小区《管理规约》、《临时管理规约》、《业主大会议事规则》等示范文本，修订和完善住宅小区相关文本，规范居民居住生活秩序和行为。对尚无条件成立业主大会和业主委员会的，由街镇（园区）牵头、居民委员会加强指导，帮助业主加强自我管理。推进实施《上海市文明居住行为规范》，积极培育和倡导文明居住意识，进一步规范物业使用和文明居住行为。

四、切实推进实事工程建设

实事工程是解决好涉及居民切身利益问题的重要载体，是加强社区建设的重要内容和体现。各相关职能部门、各街镇（园区）要以贯彻《若干意见》为契机，结合“创宜居宝山，建美好家园”创建的深化推进，加快落地旧房改造等实事工程，努力解决居民“急、难、愁、盼”问题，不断提升居民的满意度和获得感。

（一）要加大落地实事工程建设力度。加大对住宅修缮、旧房改造、供电设施、二次供水设施、燃气管道改造、市政排水设施、消防设施、电梯、安防技防设施、电动自行车充电设施、绿化等关系居民切身利益、日常生活实事工程的建设力度，制订计划、落实责任、注重质量、确保资金、统筹推进。

（二）要大力整治难点顽症。加大对住宅小区违法建设和破坏房屋承重结构、“群租”、擅自改变房屋使用性质等影响房屋使用安全行为的整治力度。通过规范停车划线、改造小区机动车停车位，努力缓解住宅小区“停车难”矛盾。研究解决商品住宅专项维修资金缺失等历史遗留问题。

五、切实发挥自治共治作用

以党建为引领，发挥居民自治和社区共治作用，调动居民群众和相关各方的积极性，是破解住宅小区物业管理难题的重要途径。各相关职能部门、各街镇（园区）在贯彻《若干意见》过程中，要进一步健全和完善自治共治机制，构建多元力量参与住宅小区综合治理的良好格局。

（一）要进一步发挥居民委员会在业主自治管理中的作用。强化居民委员会对业主大会、业主委员会组建、换届和日常运作的指导、服务和监督职责。探索在居民委员会设立物业环境专业委员会，在有条件的居民区合法有序推进居民委员会和业主委员会成员交叉任职。完善住宅小区矛盾化解长效机制，实现街镇层面调解工作的全覆盖。

（二）要积极引导专业社会中介组织参与小区管理。通过政府购买服务的形式，建立和完善专业社会中介组织提供公共服务和解决事项的社区治理模式，引导专业社会中介组织为业主大会组建、业主委员会换届改选、物业企业选聘、维修资金续筹和使用、物业矛盾纠纷化解等住宅小区管理事务提供服务，工作全面覆盖。

（三）要着力提高问题解决能力。全面贯彻市委“1+6”文件精神，总结实际工作中的经验做法，不断健全完善自治共治工作制度和长效机制。把推动形成价值认同、运用制度机制解决实际问题作为重要着力点，进一步提高自治共治实效。

各相关职能部门、各街镇（园区）要认真落实责任，加强协调配合，形成工作合力，确保各项工作要求得到有效落实，切实提高宝山区住宅小区综合治理水平。
