# 关于印发《关于加强临港新片区住宅小区通信配套设施建设与管理的实施意见（试行）》的通知

关于印发《关于加强临港新片区住宅小区通信配套设施建设与管理的实施意见（试行）》的通知

沪自贸临管委〔2021〕577号

管委会各部门、各直属单位，临港新片区各镇、各开发公司、各有关单位:

为深入贯彻党中央、国务院关于建设网络强国和制造强国的战略部署，落实上海市城市数字化转型的总体要求，进一步加强临港新片区住宅小区通信配套建设，助力上海市智慧社区建设，临港新片区管委会组织制定《关于加强临港新片区住宅小区通信配套设施建设与管理的实施意见（试行）》，

现印发给你们，请遵照执行。
