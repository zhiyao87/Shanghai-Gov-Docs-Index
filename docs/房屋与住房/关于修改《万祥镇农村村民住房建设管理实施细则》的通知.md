# 关于修改《万祥镇农村村民住房建设管理实施细则》的通知

各村居委、企事业单位、机关各科室：

经研究，现决定对《万祥镇农村村民住房建设管理实施细则》(浦万府规〔2023〕4号)部分内容作如下修改：

一、将第四条中的“规划资源局第六管理所主要负责村民建房的用地管理、宅基地资料审核、资料归档等工作”予以删除。

二、将第十七条中的“土地所”修改为“城建中心”。

本文件自2025年3月17日起实施，有效期至2027年12月31日。

上海市浦东新区万祥镇人民政府
