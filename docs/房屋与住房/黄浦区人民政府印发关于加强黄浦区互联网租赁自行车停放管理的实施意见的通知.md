# 黄浦区人民政府印发关于加强黄浦区互联网租赁自行车停放管理的实施意见的通知

区政府各委、局、办，各街道办事处：

经区政府同意，现将《关于加强黄浦区互联网租赁自行车停放管理的实施意见》印发给你们，请认真按照执行。

特此通知。

上海市黄浦区人民政府

2018年4月3日

关于加强黄浦区互联网租赁自行车停放管理的实施意见

按照“在规范中发展，在发展中规范”的总体要求，围绕黄浦区建设现代化国际大都市中心城区的总体目标，为了更好地鼓励和规范在本区的互联网租赁自行车（以下简称“共享单车”）依法有序健康发展，及时遏制当前共享单车各种乱象的蔓延，提升道路公共资源的合理规范有效利用，努力为市民营造安全便捷文明的出行方式，倡导共同维护黄浦区道路交通秩序以及市容环境面貌，依据《关于鼓励和规范互联网租赁自行车发展的指导意见》、《上海市鼓励和规范互联网租赁自行车发展的指导意见（试行）》、《上海市道路非机动车停放点设置技术导则》、《上海市共享自行车团体标准》以及相关法律、法规，结合本区实际，制定如下实施意见。

一、创新理念，准确定位

共享单车是移动互联网和租赁自行车融合发展的新型服务模式，是分享经济的典型业态，是城市绿色交通系统的组成部分，是方便公众短距离出行和公共交通接驳换乘的交通服务方式。根据牢固树立和贯彻落实创新、协调、绿色、开放、共享的发展理念，黄浦以“积极引导、注重有序、强化安全、加强协同”为原则，以优先满足短距离出行和对接公共交通需求为导向、以合理配置城市公共资源为主导，以规范企业市场经营活动和维护城市秩序为重点，推动共享单车健康规范有序发展。共享单车属分时租赁营运的非机动车，黄浦区不发展互联网租赁电动自行车。

二、科学规划，合理设置

1.根据合理布局慢行交通网络和自行车停车设施，将其纳入城市综合交通体系规则，与城市公共交通规划相衔接；积极推进自行车道建设，提高自行车道的网络化和通达性，优化自行车交通组织，完善道路标志标线的要求，依据《上海市道路非机动车停放点设置技术导则》，由区建管委、区市政办牵头，会同公安分局、区规土局、区城管执法局、各街道办事处、各风景区管理办，结合本区道路现状，优化全区非机动车道、道路非机动车停车点布局，完善慢行交通的组织运行体系；细化道路非机动车停放点设置技术导则，规范停放点设置和划线，提出可供共享单车投停放的站点及投停放标准，建立适宜和不适宜投停放的正面清单和负面清单，统一站点标牌、标识、标线，确保设置规范清晰。

2.进一步加强配套设施建设，区建管委会同公安分局、区城管执法局牵头试点开展道路微改造，对部分非机动车停放需求较大的道路路权进行重新分配，进一步增加慢行交通设施和非机动车停放点的设置，逐步改善本区非机动车停放点资源有限的现状。

3.落实临时停放调蓄点，区建管委牵头，针对共享单车“堰塞湖”现象、“潮汐”现象以及本区各类应急保障活动，在临时疏导点的基础上，加强资源统筹，协调落实临时停放调蓄点。

三、总量控制，规范投放

1.依据《上海市占用城市道路人行道设置设施管理规定》第二条、第五条的相关规定，对占用人行道设置的共享单车实行总量控制。由区市政办牵头会同区建管委、公安分局、区城管执法局，根据黄浦道路状况、城市空间的承载能力、非机动车道路停放资源、公众出行的需求量等，研究制定本区道路非机动车停放总量，提出本区共享单车可投放总量以及各街道的投放量。

2.按照力量下沉，属地管理的原则，各街道办事处、风景区管理办牵头，会同交警中队、城管中队、市容所以及具体负责非机动车停放管理的公司，根据区有关部门明确的各街道集中投放总量，制定合理的集中投放设置点位以及每个点位的投放量。

3.依据《上海市城市道路管理条例》第二十七条以及《上海市鼓励和规范互联网租赁自行车发展的指导意见（试行）》相关要求，对在本区投放运营的共享单车实行统一管理，企业在投放前，通报投放规模和方案计划。由区市政办牵头，会同区建管委（区市政所）、公安分局、区城管执法局等相关部门，对在本区投放运营的共享单车企业提供的投放点位、投放量、投放时间等投放计划，在征求各街道办事处、风景区管理办以及具体负责非机动车停放管理公司意见的基础上，进行统一核实管理。区相关部门、各街道办事处应指导共享单车企业根据黄浦提供的投放点位和投放量，依法依规进行投放，规范投放流程；按照公平共享原则，引导共享单车企业不得恶意竞争投放。

四、明确标准，严格管理

1.为加强共享单车的规范管理，根据“城市管理应该像绣花一样精细”的要求，由区市政办牵头，会同区建管委、公安分局、区法制办等部门，依据相关法律法规，结合黄浦实际制定相应的《共享单车管理标准》。

2.根据“坚持属地管理”的原则，各街道办事处及各重点地区管理办为本区域共享单车管理的责任主体，积极主动牵头协调共享单车的规范停放管理，因地制宜探索符合本区域实际的停放管理和发展模式。同时，加大对共享单车文明骑行、文明停放的宣传和引导，建立公众共同参与的共治共管机制。

3.区、街道网格中心依托网格化平台，加大对共享单车的集中投放点和乱停现象突出的停放点的视频监控频率，发现超量投、停放的共享单车以及未按规定停放的共享单车，及时立案督促限时整改。

4.本区非机动车停放管理实行“政府购买服务、部门监管、企业化运作、社会评估”的管理方式，引进专业管理公司对本区非机动车停放进行专业管理。区城管执法局为道路非机动车投放管理的主管部门，加强对道路非机动车（共享单车）投放管理的监督、检查和管理；监督指导专业管理公司做好投放、停放等日常管理工作，引导其配合相关部门、街道以及共享单车公司，加强文明骑车和文明停车的宣传，营造良好的共管氛围；指导专业管理公司参与共享单车违骑违投违停现象综合治理，并按照非机动车道路停放管理标准加强管理，处理好有关共享单车的各类投诉。

五、健全机制，联合治理

针对共享单车无序管理现状，建立健全共享单车日常管理机制、联勤联动机制、应急响应机制，探索建立对共享单车企业的评价机制、准入机制、退出机制等，各部门联手，开展联合治理。

1.区市政办牵头搭建本区规范共享单车发展的共建共治平台，针对共享单车在本区出现的突出问题，建立多方参与的协商机制，积极主动共商共议，共同规范本区共享单车管理。各街道办事处主动牵头，建立由公安分局、城管队伍、非机动车停放管理公司、共享单车企业、街道市容管理辅助力量共同参与的“五方联动机制”，加大对辖区内乱投乱停共享单车的综合整治和清理。

2.建立区、街道两级应急网络和应急处置机制，针对节假日共享单车短期内在人流密集的重点区域周边、主要道路、主要交通出入口等迅速堆积、影响交通及行人通行等现象，区层面由公安分局统一指挥，区应急办、区城管执法局配合，并引导鼓励区非机动车停放管理公司、共享单车企业落实力量，及时做好共享单车应急处置工作。街道层面，由街道办事处以及各重点地区管理办作为应急处置牵头单位，完善应急管理网络和各方联动的应急处置机制，确保城区安全有序。

3.依据《上海市共享自行车团体标准》，由区市政办牵头，制定细化本区共享单车投停放管理社会评估标准，建立共享单车企业行业评价、管理部门评定、第三方综合测评的社会评估机制，并将评估结果定期向社会公布。

加大对评估结果的运用，对存在乱停乱放问题严重、线下运营服务不力，经提醒仍不采取有效措施，不积极主动配合政府加强管理，社会评估差的共享单车企业，通过优胜劣汰的约束机制、择优招录机制进行市场选择，努力营造公平竞争的市场秩序。

六、宣传引导，强化自律

1.根据谁投放谁管理的原则，区市政办、各街道办事处牵头，积极引导在本区运营的共享单车企业应按照《上海市鼓励和规范互联网租赁自行车发展的指导意见》的有关要求以及自行车行业协会的相关标准，配备相应的专业管理力量，加强对单车运行、投放、停放等日常管理和维护，对乱停乱投乱放单车及时进行清理，及时召回报废、破损以及老旧的单车；定期对营运车辆进行检查并做好清洁维护，对车身张贴的违法小广告等进行及时清除，确保车身安全整洁，单车停放在线内。

2.针对单车用户的乱停乱放乱骑等违规行为，区委宣传部门应通过各种形式加强对文明骑行的宣传，引导共享单车企业积极开展文明公益活动，利用自有平台，加大对用户的提示、告知，开展各类文明共享的主题宣传活动，倡导社会企业、市民共同参与，逐步形成单车文明共享公约，努力营造单车共享共管良好的氛围。

3.区市政办牵头引导在本区投放运营的共享单车企业通过本区信息共享平台，定期向政府部门提供包括投停放量变化、出行热点区域和时段，共享单车停放集中点位、文明骑行指标等，并配合区公安分局提供对违规用户查处的相关信息。

4.各街道办事处、各重点地区管理办充分发挥辅助力量作用，对道路乱停乱放协助管理，做到劝一劝，引一引，搬一搬，同时，各街道办事处、各重点地区管理办发挥属地化的优势，充分利用各种宣传阵地，结合文明城区创建等工作，积极开展各种形式多样的宣传，倡导文明骑行、文明停放、文明使用，并鼓励志愿者共同参与，倡导安全绿色文明出行。

七、监督查处，依法治理

1.依据《中华人民共和国道路交通安全法》第五十九条、《上海市道路交通管理条例》第四十五条、第七十六条以及《上海市非机动车管理办法》第三十三条、第三十九条，《城市道路管理条例》第二十七条、《上海市城市道路管理条例》第二十七条、《上海市占用城市道路人行道设置设施管理规定》第二条、第五条和《上海市市容环境卫生管理条例》第二十五条有关规定，区城管执法局会同公安分局依法加大对违规投停放的共享单车的查处和清理力度。

2.加强行业协会自治管理，充分发挥自行车行业协会自律作用，督促屡屡违规投放、恶意竞争投放且严重影响交通秩序和市容环境，以及对共享单车用户违规行为无任何管理措施的共享单车企业进行整改。

八、积极探索，精细管理

1.切实掌握本区共享单车的投停放规律，提高精细化管理水平，由区网格中心牵头，会同区科委、区建管委、公安分局、区城管执法局和各街道办事处，充分利用区网格化信息平台，及时掌握分析本区共享单车投停放矛盾突出区域、点位和时段，供停放管理部门参考；同时根据国务院办公厅《关于加强信息资源开发利用工作的若干意见》，共同搭建与共享单车企业的信息共享平台，定期互通信息。

2.区市政办牵头，会同区科委、区建管委、区网格中心，协调共享单车企业利用互联网信息技术，建设黄浦共享单车监管平台，通过科技力量，加强对投、停放点以及乱停行为的监管、控制和约束，提升本区共享单车信息化、数字化管理水平；探索在有条件道路试点推进电子围栏停车站点建设，提升规范停车的技术性含量。

3.各职能部门主动加强与市交通委、市路政局、市公安局、市城管执法局、市自行车行业协会等部门、单位的沟通，争取上级部门、社会各方在政策、法规等方面的指导和支持。借助行业协会、社会力量以及互联网技术，探索建立多方参与的举报机制、社会评价机制。区市政办牵头，探索建立政府主导、部门监管、行业自律、市民参与、社会监督的有效的共管模式，促进黄浦共享单车健康发展。

九、加强督办，提升效能

将规范本区共享单车停放管理纳入区政府重点督办工作，区、街道网格化考核重要指标，定期通报管理情况；区城管执法局加强对本区非机动车道路停放管理公司日常管理的监督考核和实效评估，切实提升管理效能。各部门各单位积极履职，强化监管，敢于担当，勇于创新，不断探索适应互联网新经济模式快速发展下的城市管理新模式、新举措。
