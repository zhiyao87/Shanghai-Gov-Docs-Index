# 关于公布上海市“模塑申城”住建行业人工智能优秀案例和创新应用场景名单的通知

关于公布上海市“模塑申城”住建行业人工智能优秀案例和创新应用场景名单的通知

沪建科信联〔2025〕501号

各有关单位：

为落实国务院《关于深入实施“人工智能+”行动的意见》、市政府办公厅《关于人工智能“模塑申城”的实施方案》，推动人工智能赋能“数字住建”建设，上海市住房和城乡建设管理委员会、上海市经济和信息化委员会共同组织开展了上海市住建行业人工智能优秀案例和创新应用场景征集工作。根据各单位自主申报情况，经过材料征集、形式审查、专家评审，确定了上海市“模塑申城”住建行业人工智能优秀案例和创新应用场景名单。其中，遴选“‘云工大模型’建筑AI产品服务平台”等10个案例为住建行业人工智能十佳案例，遴选“基于生成式大模型的CAD图纸矢量化重建与智能解析平台”等10个场景为住建行业人工智能十佳场景。现将上海市“模塑申城”住建行业人工智能优秀案例和创新应用场景名单予以公布（详见附件）。
