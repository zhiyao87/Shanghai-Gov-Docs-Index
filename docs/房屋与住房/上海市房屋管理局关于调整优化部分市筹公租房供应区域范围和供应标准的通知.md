# 上海市房屋管理局关于调整优化部分市筹公租房供应区域范围和供应标准的通知

各区住房保障房屋管理局、相关市筹公租房运营机构：

经研究，现就调整优化部分市筹公租房供应区域范围和供应标准事宜通知如下：

一、2020年4月起，馨宁公寓、馨越公寓、馨逸公寓、耀华滨江公寓、馨古美佳苑、铁路上海南站噪声治理收购房屋、新江湾尚景园、上海晶城晶华坊等8处市筹公租房统一面向全市范围内符合市筹公租房准入条件的对象供应。请新纳入供应区域范围的金山、松江、青浦、奉贤、崇明区住房保障房屋管理局组织本区住房保障机构和公租房受理窗口，按照《市筹公共租赁住房准入资格申请审核实施办法》（沪房规范〔2017〕1号）做好本区符合条件对象的市筹公租房准入资格受理、审核工作。

二、上述市筹公租房中的三居室房源，可以安排4人以上（含4人）家庭单独居住使用，也可以拆套安排使用。

三、请相关市筹公租房运营机构进一步加大力度做好市筹公租房分配供应工作，提高房源使用效率。

特此通知。

上海市房屋管理局

2020年3月11日
