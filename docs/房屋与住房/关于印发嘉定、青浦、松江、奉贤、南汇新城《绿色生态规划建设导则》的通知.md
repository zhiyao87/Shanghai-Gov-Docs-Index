# 关于印发嘉定、青浦、松江、奉贤、南汇新城《绿色生态规划建设导则》的通知

关于印发嘉定、青浦、松江、奉贤、南汇新城《绿色生态规划建设导则》的通知

沪建建材联〔2023〕561号

各有关单位：

为贯彻落实《关于本市“十四五”加快推进新城规划建设工作的实施意见》（沪府规〔2021〕2号）要求，充分发挥绿色生态城区示范溢出效应，我们按照“分新城、分区域、分重点”的方式，分别编制了嘉定、青浦、松江、奉贤、南汇新城《绿色生态规划建设导则》，现予以发布，请遵照执行。

附件：1.嘉定新城绿色生态规划建设导则

2.青浦新城绿色生态规划建设导则

3.松江新城绿色生态规划建设导则

4.奉贤新城绿色生态规划建设导则

5.南汇新城绿色生态规划建设导则

2024年1月2日
