# 黄浦区人民政府关于同意确认123地块旧城区改建项目房屋征收范围的批复

区建设交通委、区住房保障房屋管理局：

你部门《关于申请确认123地块旧城区改建项目房屋征收范围的请示》（黄建交〔2014〕54号）收悉。经研究，批复如下：

一、原则同意123地块列入我区旧城区改建范围。上述地块房屋征收范围：西藏南路310～324号；356弄1～9号；自忠路16～24号、28～36号（包括18弄1～26号）；东台路1～7号、9弄1～15号（包括过街楼11号）、13～29号、29弄1～3号、31～33号、47～81号、85～87号、101～113号；浏河口路7～25号、4弄1～2号、6～8号、10～14号、18～20号、28～34号。

二、在启动改建前，按照《上海市国有土地上房屋征收与补偿实施细则》有关规定，组织开展居民意愿征询和房屋征收补偿方案征询工作，在被征收人、房屋承租人同意旧城区改建和签订附生效条件的补偿协议达到规定比例后，方可实施改建工作。

特此批复，请抓紧组织实施。

上海市黄浦区人民政府

2014年4月22日
