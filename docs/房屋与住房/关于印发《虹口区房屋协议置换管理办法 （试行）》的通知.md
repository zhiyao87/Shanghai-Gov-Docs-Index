# 关于印发《虹口区房屋协议置换管理办法 （试行）》的通知

区政府相关部门、各街道办事处、相关单位：

《虹口区房屋协议置换管理办法（试行）》已经区政府常务会议审议通过，现印发给你们。

特此通知。

虹口区住房保障和房屋管理局

虹口区建设和管理委员会

虹口区规划和自然资源局

2026 年9月10日

虹口区房屋协议置换管理办法（试行）

为规范本区房屋协议置换行为，维护协议置换双方合法权益，根据《关于进一步加强本市房屋协议置换管理的意见》（沪建房管联〔2025〕220号），特制定本办法。

一、开展房屋协议置换的范围

以下项目经区人民政府备案后，可开展房屋协议置换。

（一）有明确交地和开工时间节点，且已取得建设项目规划选址意见书的重大工程项目；

（二）无法实施征收但因安全控制或环保等要求必须搬迁房屋的项目；

（三）其他经区人民政府常务会议讨论决定，确需先行开展房屋协议置换的项目。

二、职责分工

区住房保障房屋管理局负责业务指导检查、对实施主体及其委托单位、工作人员行为监管等工作。区发展改革委、区建设管理委、区规划资源局、区财政局、区文化旅游局、区生态环境局等有关行政管理部门，应当按照各自职责分工，互相配合，保障房屋协议置换工作的顺利进行。

各街道办事处及其他由区人民政府指定的主体为开展房屋协议置换的实施主体，负责组织实施房屋协议置换项目的补偿与安置工作。实施主体可以委托房屋征收事务所具体实施置换房屋工作，对房屋征收事务所行为负责监督，并对其行为后果承担法律责任。

三、开展房屋协议置换的条件

确需开展房屋协议置换的项目，应在项目启动前落实资金和安置房源。

（一）用于货币补偿的资金应当足额到位、专户存储、专款专用。

（二）房屋协议置换的项目安置房源为期房的，一般应当取得建筑工程施工许可证。对于重大工程项目的安置房源，应当确保安置房源所在地块为净地。

居民在外过渡期原则上不得超过三年。原地回搬安置的项目在外过渡期不得超过五年，采取原地回搬安置方式的，应当经区人民政府同意。

四、开展房屋协议置换的程序

（一）项目牵头单位会同区发展改革委、区建设管理委、区规划资源局、区财政局、区住房保障房屋管理局、区文化旅游局、区生态环境局、街道办事处等部门确定房屋协议置换项目，包括置换项目范围及实施主体等，报区人民政府常务会议讨论决定。

（二）实施主体对房屋协议置换项目范围内的房屋土地相关情况进行调查，根据调查结果编制本项目房屋协议置换方案，并按照项目需求筹集资金和房源。

（三）实施主体将确定的房屋协议置换方案报区住房保障房屋管理局备案。备案的方案应包括房屋协议置换项目范围、补偿方式和标准、补偿价格的确定以及协议生效的条件等。

（四）实施主体应当对房屋协议置换项目范围内房屋的权属、区位、用途、建筑面积等情况的调查结果在房屋协议置换项目范围内公布。

（五）实施主体将房屋协议置换方案在房屋协议置换项目范围内公布。

（六）实施主体根据房屋协议置换方案与房屋所有权人、公有房屋承租人签订房屋置换协议。

（七）实施主体应当建立房屋协议置换项目档案，并将补偿结果在房屋协议置换项目范围内通过有效途径公开。

五、法律责任

违反本办法规定的行为，依照相关法律法规处理。有关部门、实施主体及其工作人员应接受纪检监察和审计部门监督。

六、附则

本办法自2026年10月10日起施行，有效期至2029年10月9日（有效期三年）。
