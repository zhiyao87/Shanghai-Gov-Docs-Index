# 上海市奉贤区住房保障和房屋管理局关于进一步加强奉贤区既有多层住宅加装电梯建后管理工作的指导意见

各加装电梯相关单位：

为确保加装电梯安全运行，巩固既有多层住宅加装电梯的工作成效，建立建后管理工作机制，规范、明确加装电梯所有权人、使用管理单位和维护保养单位的权利、责任和义务，根据《物业管理条例》(中华人民共和国国务院令第379号)、《上海市住宅物业管理规定》、《上海市电梯安全管理办法》(沪府令76号)、《关于进一步加强本市既有多层住宅加装电梯全过程管理的若干意见》(沪房更新〔2024〕126号)、《关于落实既有多层住宅加装电梯使用管理责任的指导意见》(沪精细化办〔2024〕1号)等文件精神，制定奉贤区既有多层住宅加装电梯建后管理工作的指导意见如下：

一、建后管理的责任主体

(一)加装电梯所有权人

电梯所在楼幢中，就加装电梯事项进行出资的业主是加装电梯所有权人。房屋产权人发生变更或转移后，自该房屋变更、转移登记之日起，受让人相应变更或转移为新的电梯所有权人，享有原加梯协议约定的权利和履行相关义务。

如原房屋产权人不为电梯所有权人，应在房屋所有权发生变更、转移前，明确告知受让人相关情况。受让人就加装电梯费用及维保费用与其他电梯所有权人协商一致并出资后，可成为电梯所有权人。

加装电梯的房屋为公有住房的，公有住房出租人可以与承租人约定， 由承租人享有相关表决权并享有和承担加装电梯相关的其他权利义务。

(二)加装电梯后的使用管理单位

加装电梯所有权人应当委托物业服务企业作为加装电梯的使用管理单位，履行电梯安全管理义务，对电梯使用安全负责。

加装电梯投入使用后，应配备远程监测装置，并接入智慧电梯平台，鼓励电梯使用管理单位与加装电梯所有权人协商后安装带有智能视频的电梯远程监测装置、购买电梯安全责任险等，以进一步保障电梯安全运行。

(三)加装电梯后的维护保养单位

电梯使用管理单位应当主动与加装电梯所有权人进行协商，通过加装电梯所有权人直接委托或电梯使用管理单位间接委托等方式确定电梯维护保养单位，具体承担电梯维护保养业务，对电梯的安全性能负责。

二、相关责任主体的职责

(一)加装电梯所有权人

1、通过签订合同等方式明确委托物业服务企业作为电梯使用管理单位，约定电梯安全管理方面的权利、义务和责任;

2、开设建后管理资金账户，承担电梯日常管理、维护保养、改造、修理、检验、检测、安全评估、更新等所需费用，并按时足额交纳相关费用;

3、参与电梯管理、修理、改造、更新等事务的协商表决，监督物业服务企业和电梯维护保养单位提供的日常管理和维护保养服务，督促物业服务企业根据业主大会决议和委托合同约定组织落实相关工作;

4、对小区的电梯运行维护费用和电梯专项维修费用的支出情况享有知情权;

5、发现危害电梯安全的违法违规行为，有权向相关行政管理部门进行投诉、举报;

6、遵守小区管理规约、电梯安全使用说明和安全注意事项，文明乘梯、规范用梯，不损坏电梯设备及相关标志。

(二)电梯使用管理单位

1、日常管理职责

(1)接收全过程建设资料并归档，按照规定建立电梯安全技术档案;

(2)在电梯轿厢内或者出入口的显著位置张贴有效的电梯使用登记标志、安全使用说明、安全注意事项、警示标志、本单位应急救援电话号码、电梯安全责任保险的投保信息等;

(3)保管电梯层门钥匙、机房钥匙和安全提示牌;

(4)做好电梯厅窗户、照明、地砖、电梯轿厢以及与房屋本体间的连接结构等部位的日常保洁、维护保养和定期巡视等工作，并做好记录，巡视记录至少保存1年;

(5)做好电梯安全乘用的宣传，劝阻不文明乘梯行为;

(6)根据与加装电梯所有权人的约定，委托制造单位(建议优先选择)或者取得电梯安装、改造、修理资质的单位承担电梯维护保养工作并查验相关资质证书。电梯使用管理单位具备电梯制造、安装、改造、修理资质的，可以接受加装电梯所有权人的委托承担电梯维护保养工作。

2、安全管理职责

(1)设置安全管理机构或者配备专职安全管理人员，落实专业人员定期对电梯及电梯相关围护结构、附属设施设备进行巡视，并如实记录巡视时间、检查人员、隐患发生位置、隐患情况以及处置结果。对存在高空坠物隐患的区域，应当及时设置警戒线，并以书面形式报告加装电梯所有权人和业主委员会，情况严重的应当同时报告属地街镇;

(2)如发现围护结构、附属设施设备存在安全隐患，可能影响电梯正常使用的，应当及时通知加装电梯所有权人和电梯维护保养单位，并根据加装电梯所有权人或者电梯维护保养单位的意见停用电梯;

(3)确保电梯紧急报警装置(对讲系统)有效运行，即时响应乘客被困报警，做好安全指导工作，并在乘客被困报警后5分钟内通知电梯维护保养单位采取措施实施救援;

(4)发现电梯存在故障或者其他影响电梯正常运行的情况时，及时作出停止使用的决定，报告本单位负责人、加装电梯所有权人及小区业主委员会并通知电梯维护保养单位：在需要暂停使用的电梯出入口张贴停用告示、公示停止使用的原因和修复所需时间，并采取避免电梯乘用的安全措施;

(5)电梯发生事故时，组织排险、救援，保护事故现场，并于1小时内报告电梯所在地的区特种设备安全监督管理部门;

(6)配合电梯维护保养单位开展工作，签字确认维护保养记录;在相关单位对电梯进行安装、改造、修理、检验、检测时，做好现场配合工作，协助相关单位落实安全防护措施，监督其履行保证电梯安全性能的职责;

(7)自监督检验合格之日起使用年限超过15年的电梯，需要继续使用的，电梯使用管理单位应当向加装电梯所有权人建议委托检验、检测机构进行安全风险评估，确定电梯是否有继续使用的条件或者对电梯进行修理、改造、更新。电梯经安全风险评估后，电梯使用管理单位将评估结论向全体业主公示，并报告属地街道。

3、其他

(1)根据加装电梯所有权人的委托，将运行维护费用和专项维修费用(如有)单独立账，按委托管理协议约定时间公布电梯运行维护费用和专项维修费用的收支情况，并接受加装电梯所有权人的监督;

(2)其他由加装电梯所有权人和电梯使用管理单位约定的管理职责。

(三)电梯维护保养单位

1、具备电梯制造或者安装、改造、修理许可资质，依法在本市办理市场主体登记;

2、按照电梯安全技术规范、相关标准和使用维护保养说明的要求，制定安全管理制度、维护保养计划并告知电梯使用管理单位，开展电梯维护保养工作;

3、在电梯显著位置，标明本单位的名称、应急救援电话号码和投诉电话号码;

4、指派具有资质的维护保养人员，开展日常维护保养，做好维护保养记录，确保电梯安全性能，维护保养期间应做好现场安全防护措施，保证施工安全;

5、定期对作业人员进行安全教育和技术培训，建立作业人员教育培训记录并至少保存4年，支持作业人员取得职业技能资格;

6、按期开展限速器校验、125%荷载制动试验、日常小修等工作;

7、检查本单位配置的电梯远程监测设备的运行情况;

8、在电梯轿厢内或者出入口公布最近一次电梯维护保养信息，信息至少应当包括维护保养人员、维护保养时间和内容等;

9、更换的电梯零部件应当具有产品质量合格证明，如更换《电梯型式试验产品目录》中的零部件，还应当提供相应的型式试验证明;

10、发现电梯设备存在故障、安全隐患，或者在接到故障通知后，及时排除故障和隐患;对故障和隐患暂时难以排除的，应当及时向电梯使用管理单位通报有关情况、书面提出排除故障和隐患的解决方案、措施或建议，并告知电梯使用管理单位故障排除前不得使用;

11、至少每年对电梯进行1次自行检查，向电梯使用管理单位出具自检报告，并向加装电梯所有权人公示;

12、建立电梯维护保养和故障处置记录，并至少保存5年;

13、制定应急救援预案，确保应急救援电话24小时保持有效应答和应急救援装置完备，接到乘客被困报警后，30分钟内赶到现场完成救援解困，并做好救援记录;

14、对自监督检验合格之日起使用年限超过15年的电梯，电梯维护保养单位应当根据电梯运行实际情况向使用管理单位提出建议，经电梯所有人同意，增加维护保养频次和维护保养项目;

15、其他由电梯使用管理单位和电梯维护保养单位约定的职责。

三、电梯建后管理的资金管理

在意愿征询时加装电梯所有权人，应协商一致确定电梯使用管理单位，明确服务事项、服务内容、服务标准、收费事项和收费标准等具体内容，约定建后管理资金筹集与分摊内容，形成加装电梯后续管理方案。在加装电梯签约后，由加装电梯所有权人委托的代建单位向所属街镇管理部门报备加装电梯后续管理方案。

(—)资金构成

电梯建后管理资金主要分为电梯运行维护费用和电梯专项维修费用(电梯建后管理资金构成详见表1)。电梯运行维护费用主要包括：使用管理费用、维护保养费用、日常运行费用(电费、远程监测费、日常小额维修费用等)以及其他服务费用(运行维护费用测算具体可参考附件1)。电梯专项维修费用主要用于电梯运行维护之外的电梯修理、改造、更新费用，以及其他确需支出的费用，根据电梯维修发生的实际费用结算。

(二)资金筹集

设立电梯建后管理资金账户，加装电梯所有权人应当按照合同签订的电梯运行维护费用及各户分摊比例将电梯运行维护费用及电梯专项维修费用缴纳至建后管理资金账户。

电梯建后管理资金的筹集途径主要包括：

1、加装电梯产权人自筹资金;

2、加装电梯专项账户的余额;

3、在加装电梯内设置广告、商业推广等经营设施而获得的公共收益;

4、购买社会保险;

5、其他出资方式，建议在政府补贴中预留部分资金在专项账户中作为电梯专项维修资金。

(三)资金使用

加装电梯运行维护费用及电梯专项维修费用的管理及使用规则可参照附件2示范文本。

四、档案管理

电梯使用管理单位应对每台电梯建立安全技术档案，妥善保存电梯相关资料。

加装电梯所有权人委托物业服务企业作为加装电梯的使用管理单位，应移交相关资料原件或复印件，包括：上海市特种设备使用登记证、电梯产品出厂合格证明、电梯监督检验报告、建设工程竣工验收报告等其他电梯相关资料。

电梯使用管理单位应向加装电梯所有权人提供相关资料复印件并加盖公章，包括：营业执照、特种设备安装改造维修证、特种设备作业人员证等其他相关资料。

电梯使用管理单位负责运维管理期间，应做好年检合格证、日常维保记录、故障处置记录等的留档。

五、工作要求

在意愿征询阶段， 属地街镇应指导协调加装电梯所有权人与电梯使用管理单位就电梯建后接管达成一致意见，形成后续管理方案，并在签约时与电梯使用管理单位签订书面委托管理协议(可参照附件2示范文本)，确保相关维保监管责任得以落实。

结合物业服务“红黑榜”评价、宜居社区建设工作，将加装电梯建后接管及管理情况纳入项目指标，引导物业企业积极参与既有多层住宅加装电梯建后管理工作。

区住房保障房屋管理局和区市场监管局等相关行业主管部门负责电梯建后管理的指导工作。

本指导意见自发布之日起施行。
