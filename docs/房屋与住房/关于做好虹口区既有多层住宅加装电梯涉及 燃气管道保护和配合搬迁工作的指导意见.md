# 关于做好虹口区既有多层住宅加装电梯涉及 燃气管道保护和配合搬迁工作的指导意见

各街道办事处、加装电梯相关单位、管道燃气经营企业：

为进一步推进虹口区既有多层住宅加装电梯工程，做好涉及燃气管道保护及配合搬迁，在加速推进电梯加装的同时有序保障燃气管道运行安全，根据《上海市住房和城乡建设管理委员会关于做好本市既有多层住宅加装电梯涉及燃气管道保护和配合搬迁工作的通知》（沪建设施〔2022〕97号）等文件要求，结合本区实际情况，制定本意见：

一、明确职责

（一）加装电梯所有权人

加装电梯所有权人（或受委托的代建单位）应主动向管道燃气经营企业(以下简称燃气企业)进行前期征询，在取得燃气企业盖章确认的《前期征询书面答复单》（见附件）前，严禁开挖施工。如需对部分燃气管线进行搬迁，按要求申请办理。

（二）燃气企业

对加装电梯所有权人（或受委托的代建单位）提出的征询需求应及时、准确予以答复。做好日常燃气管道巡查，对涉及燃气管道做好监护。对管道搬迁申请应及时组织力量实施，确保加装电梯工作顺利推进。

二、办理流程

（一）前期征询

加装电梯所有权人（或受委托的代建单位）向燃气企业提交申请单和电梯井位示意图。

燃气企业3个工作日内给予盖章确认的《加梯项目燃气管道前期征询书面答复单》（见附件）。对于仅涉及管线保护的情况，燃气企业应明确相应保护要求。

（二）管道配合搬迁

管道配合搬迁环节为三个环节，即申请受理，方案设计，搬迁施工。燃气管道搬迁由加装电梯所有权人（或受委托的代建单位）作为合同主体，负责申请办理业务。

1.申请受理

申请方需提交的材料如下：

（1）加梯项目燃气管道前期征询书面答复单

（2）路面维修情况说明

（3）电梯基坑平面图

（4）申请方营业执照复印件

（5）经办人身份证复印件

（6）街道或业委会电梯工程委托书

（7）加梯申请书

原则上受理方收到资料起1个工作日内完成资料审核，资料缺失申请方应按要求补齐。

2.方案设计

申请受理材料齐全后，受理方原则上在收到材料后的4个工作日内完成现场勘察及申请受理，并根据现场情况选择标准化设计图，出具施工图设计、预算书和标准化合同等资料交予申请方，双方确认后完成合同签订。若上述工作因故无法在4个工作日内完成的，则以双方另行约定日期为准。

3.搬迁施工

申请方支付合同款后，受理方应根据现场施工情况尽快组织施工并验收通气。原则上涉及地下管道搬迁工程总时限不超过10个工作日完成，涉及地上、地下管道搬迁工程总时限不超过15个工作日（因加梯进度因素影响不计入总时限内)。

三、工作要求

（一）各街道在报送《联审平台过渡期间开工项目清单》前，应先确认项目已取得《燃气管道前期征询书面答复单》，并将其作为附件一并报送至区房管局、区建管委。

（二）区燃气管理部门将会同燃气经营企业加强对燃气管道设施的巡查和保护，并依据《城镇燃气管理条例》、《上海市燃气管理条例》等法规对影响燃气管道设施安全的有关行为实施查处。

本指导意见自发布之日起施行。

注意事项：
1、 本管道前期征询书面答复单请妥善保存，将作为燃气管道搬迁业务受理材料。
2、 严禁盲目开挖破坏燃气管道和盲目加装电梯施工形成燃气占压。
3、 应严格按照施工方案、保护方案要求进行施工，尽到燃气管线保护责任。
4、 燃气管线两侧各1米范围内严禁大型机械开挖。
5、 地下燃气管线应与建筑物基础水平净距大于0.7米；地上燃气管道应与电梯装饰面、助残坡道保持间距，保留维修空间。
6、 地下燃气管线在机动车不可能到达的地方时，最小埋深不得小于0.3米。（路面至管顶）
7、 开挖过程中发现管线现状与管道前期征询不符等异常情况时，应立即通知管线权属单位到场研究管道保护措施或搬迁方案；
8、 一旦发生管线外损事故，应按应急预案暂停施工，做好现场防护，同时通知管线权属单位（拨打962777）和消防应急人员赶赴现场。
9、 需现场踏勘、需采取保护措施、需现场监护开挖申请征询单位应约定时间。经现场踏勘后需增加管道搬迁的，应重新出具管道前期征询书面答复单。
10、附页：管道前期征询申请单、电梯井位示意图、燃气管线示意图。
