# 关于印发《上海市保障性住房（大型居住社区）配套建设管理导则（基地内市政公建配套）（2024年修订版）》的通知

关于印发《上海市保障性住房（大型居住社区）配套建设管理导则（基地内市政公建配套）（2024年修订版）》的通知

沪建房管联〔2024〕243号

各区建设管理（交通）委、住房保障房屋管理局、规划资源局，各相关单位：

为进一步完善本市大型居住社区配套建设管理要求，加快推进与群众利益相关的市政和公建配套设施建设，全面提升大型居住社区居民生活品质，满足居民多层次、多样化配套需求，现将《上海市保障性住房（大型居住社区）配套建设管理导则（基地内市政公建配套）（2024年修订版）》（以下简称导则）印发给你们，请遵照执行。

各单位在本导则执行过程中遇到的有关情况，请及时反馈市住房城乡建设管理委、市房屋管理局。
