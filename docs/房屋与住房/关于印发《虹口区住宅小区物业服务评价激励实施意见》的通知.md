# 关于印发《虹口区住宅小区物业服务评价激励实施意见》的通知

各街道办事处：

为进一步贯彻落实市委、区委关于加强党建引领物业治理工作有关要求，提升我区物业服务行业监管水平及人民群众的居住满意度和获得感，结合工作实际，区房管局制定了《虹口区住宅小区物业服务评价激励实施意见》，经区政府同意，现印发给你们，请按照执行。

虹口区住房保障和房屋管理局

2026年7月23日

虹口区住宅小区物业服务评价激励实施意见

为进一步提升我区物业服务行业监管水平及人民群众的居住满意度，充分调动物业企业、小区业委会管理小区、服务业主积极性，有效提升物业服务总体水平，根据《上海市住宅物业管理规定》《关于推进物业行业提质增效的实施意见》（沪府办发〔2026〕10号）《上海市住宅小区物业服务质量提升行动方案》（沪房物业〔2025〕78号）等，结合我区实际情况，制定本实施意见。

一、工作目标

根据市委、市政府关于强化党建引领、深化物业治理、推进超大城市基层治理现代化的总体要求，以建设安全、整洁、文明、有序小区为目标，通过物业服务评价激励机制，鼓励物业服务企业高质量履约，支持居委会、物业企业、小区业委会（以下简称“三驾马车”）开展“家园微更新”硬件改造、智慧物业改造、环境品质提升、安全隐患消除，解决居民高品质居住需求与物业服务发展不匹配的矛盾。

二、工作原则

（一）依申请参与原则。符合条件的住宅小区，由物业企业和小区业委会共同提出申请（小区业委会无法履职则由居委会代为申请），经审核通过的小区纳入评价范围。

（二）客观公正原则。相关部门、各街道在开展评价激励工作时应坚持客观公正原则，以实地检查、满意度测评、日常运行及工作完成情况等为依据，杜绝人情干扰和形式主义。

（三）注重实效原则。以评价结果为导向，激励物业企业加强管理、小区业委会规范履职，持续改进物业服务、提高居民满意度，以落实激励资金使用为抓手，开展“家园微更新”活动，提高居民参与社区治理积极性，推动形成共建共治共享良好局面。

三、工作职责

（一）区房管局。牵头本区住宅小区物业服务评价激励工作，指导各街道开展评价检查；委托第三方测评机构对全区的住宅小区进行满意度测评；向区财政申请激励资金；根据评价结果向物业企业拨付资金。

（二）街道办事处。负责辖区内住宅小区物业服务评价激励工作，组织社工办、城运中心、居委会等部门共同落实；加强组织领导，成立评价工作组，制定街道评价实施细则，专人负责评价实施；督促物业企业、小区业委会整改提升；按时向区房管局报送评价方案；指导“三驾马车”规范开展“家园微更新”，指导物业企业规范使用资金。各街道应指导业委会签订物业服务合同时，鼓励物业企业积极参与评价激励政策，可以将结果作为履约评价、续聘的参考依据。

四、适用范围

经各街道认定的售后房小区和竣工满15年的早期商品房小区（含保障房小区）。专有面积（具有投票权的建筑面积）大于8万平方米的小区，以8万平方米为最高激励上限。

五、考核办法

（一）提出申请。评价激励每半年开展一次，符合条件的住宅小区，由物业企业和小区业委会共同填写书面申请（附件1），小区所在居委会、街道城运中心初审；各街道审核汇总后书面报送至区房管局。

（二）评价实施。评价工作由各街道负责组织实施，应充分发动住宅小区积极参与，及时收集小区申请，按时完成评价工作，评价材料由街道保存。

（四）特殊激励情形。对以下情形给予物业企业6个月一次性激励，该激励与综合评价等级无关，由企业按规定自主使用，记录在附件2中：

1.小区在前一评价周期内完成“质价双提升”（通过业主大会表决，且调价幅度≥0.2元/平方米·月），给予0.1元/平方米·月额外激励；

2.对专有面积不足1万平方米，物业企业、小区业委会积极开展“质价双提升”并向街道提交计划，给予0.3元/平方米·月额外激励，用于先期提高服务标准，改善小区环境，提升居民满意度；

3.存在《上海市住宅物业管理规定》第七十三条五类安全隐患的住宅小区，企业根据整改通知单或鉴定意见积极行动，排除险情，按要求完成整改抢修的，给予0.2-0.4元/平方米·月的额外激励；

4.住宅小区建成智慧物管安防系统并与上海市物业管理监管与服务平台完成有效对接，经街道核实认定，对该系统合规发生的安装及首年运维费用给予50%补贴；

5.既有多层小区加装电梯竣工后由企业接管的，对该住宅小区加梯楼栋给予0.4元/平方米·月额外激励；

6.通过联合选聘物业方式，以规模效应促进降本增效、服务优化的，给予相应小区0.2元/平方米·月额外激励；

7.物业企业主动承担社会责任，通过“以大带小”等形式，为微型小区提供保洁、急修、保绿等基本服务的，给予小小区0.2元/平方米·月额外激励。

六、资金管理

（一）资金来源。区房管局将评价激励资金纳入部门预算管理，按年度编制资金预算，向区财政申请。预算编制和资金管理遵循注重引导、公正规范、强化绩效的原则。

（二）资金分配。区房管局综合全区整体情况、当批次各街道上报情况及年度预算规模，核定并下达各街道激励资金额度。各街道在各自核定额度内，按评价得分高低排序，确定激励小区名单。

（三）资金使用。各街道指导“三驾马车”按评价等级分类使用激励资金，用于小区“家园微更新”改造（包含智慧物管安防系统运维费用）和提高小区一线员工积极性（包括小区经理、四保人员等），其中A等、B等、C等小区用于微更新的比例分别为50%、60%、70%。

单次激励资金低于2万元的小区，根据街道申请可将“家园微更新”资金暂存不超过2个半年度，到期一次性用于小区微更新。

（四）资金拨付。各街道根据激励资金额度和评价结果制定本街道住宅小区激励方案，报送《住宅小区物业服务评价激励汇总表》（附件2），并于每年10月30日、次年5月30日前提出资金拨付书面申请，区房管局收到申请后，将激励资金拨付至物业企业。

七、评价内容

评价内容包含街道实地核查、物业治理实效测评、满意度测评三方面，另设立负面情形扣分事项和正面情形加分事项。

（一）住宅小区物业治理实效测评（占比40%）

街道对住宅小区物业治理实效情况进行评价，填写《住宅小区物业治理实效测评表》（附件3）。

（二）居民满意度测评（占比20%）

区房管局委托第三方测评机构对申请评价激励的小区居民开展物业服务工作满意度问卷调查。

（三）街道各部门测评（占比20%）

1.街道城运中心牵头将巡查发现问题告知物业企业，对问题处置效率和成效进行评价，填写《街道部门测评表》（附件4）。

2.街道城运中心牵头对物业企业处置962121物业呼叫平台、“12345”市民服务热线工单和信访件的情况作出评价。

（四）居民区党组织、居委会、小区业委会满意度测评（占比20%）

居民区党组织牵头居委会、小区业委会对物业服务质量进行满意度问卷调查（业委会瘫痪由居委会代为评价），填写《住宅小区物业服务满意度征询表》（附件5）。

（五）加分情形

1.物业服务企业依据《上海市住宅物业管理规定》第七十三条，认真开展并及时完成五类安全隐患处置的（消防、高坠、电梯等），完成一项加1分，上限2分；

2.被市、区级以上媒体或相关部门通报表扬的，其中区级加1分，市级加2分，上限2分。

（六）负面情形

若小区存在以下情况，各街道应取消当次物业服务激励资格：

1.因管理失职，造成在市、区级层面通报或媒体曝光的；

2.擅自利用共同部位、共用设施设备进行经营，损害业主共同利益的；

3.对存在重大安全隐患未能及时发现或发现后不及时上报、整改的，因管理失职发生安全事故的；

4.在虹口区生活垃圾分类实效测评中半年内2次及以上列入警示名单的居住小区；

5.未按要求使用激励资金的；

6.小区项目经理被记分9分或物业企业在本区内被记分一次及以上的；

各街道应将上述情形记入附件1，相关小区不得申报当次激励。区房管局可据实取消此类小区当次激励资格。

八、工作监督

（一）物业企业、小区业委会应规范使用激励资金，并接受业主监督；

（二）各街道应妥善保存物业服务评价激励工作的申报材料、评价表格、活动照片等资料台账。

九、附则
