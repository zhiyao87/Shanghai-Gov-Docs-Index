# 上海市徐汇区人民政府关于规范本区征地房屋补偿事务中各类补贴标准的通知

区政府各委、办、局，各街道、华泾镇，各征地房屋补偿工作实施单位:

根据《上海市征收集体土地房屋补偿规定》(沪府规[2021]13号)第十六条第一款“征地房屋补偿，还应当对宅基地使用权人或者居住房屋所有人补偿搬家补助费、设备迁移费、过渡期内的临时安置补助费、奖励费，具体标准由区人民政府制定。”的有关规定，现就本区征收集体土地房屋补偿事务中各类补贴标准规定如下:

一、搬家补助费:以征地房屋每平方米建筑面积35元计算，每户低于1600元按1600元计算。期房调换的搬家补助费标准增加一倍计费，并一次付清。

二、过渡期内的临时安置补助费:安置房屋为期房的，应当支付临时安置补助费或者提供周转用房。临时安置补助费标准以安置房户型作为计费标准，具体标准为:一室户型月补助1500元;二室户型月补助2000元、三室户型月补助2500元，按实际过渡期一次性发放。

三、设备迁移费按以下规定执行:电话移装费，140元/门或按现行有关规定煤气，160元/个或按现行有关规定有线电视移装费，240元/个或按现行有关规定宽带迁移费，90元/户或按现行有关规定。空调，400元/台或按现行有关规定。热水器，300元/台或按现行有关规定。本通知各类补贴标准自2023年7月16日起执行。特此通知。

上海市徐汇区人民政府

2023年6月15日
