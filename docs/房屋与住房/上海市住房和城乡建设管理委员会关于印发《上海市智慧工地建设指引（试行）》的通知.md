# 上海市住房和城乡建设管理委员会关于印发《上海市智慧工地建设指引（试行）》的通知

上海市住房和城乡建设管理委员会关于印发《上海市智慧工地建设指引（试行）》的通知

沪建质安〔2023〕186号

各区建设行政管理部门，各特定地区管委会，各有关单位：

为贯彻落实《住房和城乡建设部“十四五”建筑业发展规划》和《上海市住房和城乡建设管理“十四五”规划》的有关要求，促进智慧场景应用与业务流程再造融合，提升建设工程质量安全全过程管理的数字化和智能化水平，结合本市实际情况，我委牵头编制了《上海市智慧工地建设指引（试行）》，现印发给你们，请遵照执行。

2023年4月10日
