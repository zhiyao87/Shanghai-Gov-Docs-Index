# 上海市住房和城乡建设管理委员会关于批准发布《上海市公路日常养护维修估算指标第二册高速公路（SHC2-42（02）-2025）》的通知

上海市住房和城乡建设管理委员会关于批准发布《上海市公路日常养护维修估算指标 第二册 高速公路（SHC2-42（02）-2025）》的通知

沪建标定〔2025〕414号

各有关单位：

为进一步完善本市建设工程计价依据,满足高速公路养护维修计价需求，根据市住房城乡建设管理委《关于印发2022年度上海市建设工程及城市基础设施养护维修定额编制计划的通知》（沪建标定〔2021〕479号）及《上海市建设工程定额体系表（2020版）》（沪建标定〔2020〕794号），由上海市建筑建材业市场管理总站组织编制的《上海市公路日常养护维修估算指标 第二册 高速公路（SHC2-42（02）-2025）》已完成编写并通过专家评审，现予以批准发布，自2025年12月1日起实施，原《上海市公路工程养护维修估算指标 第二册 高速公路（SHC2-42（02）-2010）》同时废止。

本次发布的定额由市住房城乡建设管理委负责管理，由上海市建筑建材业市场管理总站负责组织实施和解释。

特此通知。

2025年8月22日
