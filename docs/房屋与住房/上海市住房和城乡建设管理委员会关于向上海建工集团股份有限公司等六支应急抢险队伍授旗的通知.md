# 上海市住房和城乡建设管理委员会关于向上海建工集团股份有限公司等六支应急抢险队伍授旗的通知

上海市住房和城乡建设管理委员会关于向上海建工集团股份有限公司等六支应急抢险队伍授旗的通知

沪建应急〔2022〕296号

各有关单位：

为进一步加强和规范本市住建行业应急抢险队伍管理，经综合评估，特向上海建工集团股份有限公司、上海隧道工程有限公司、中国建筑第八工程局有限公司、上海能源建设集团有限公司、上海凌锐建设发展有限公司、顺天（上海）能源技术发展有限公司授予“上海市住房和城乡建设管理委员会应急抢险队”旗帜。今后，我委将根据应急队伍建设及综合评估情况，对授旗单位适时调整。

各应急抢险单位要进一步加强队伍建设，强化演练培训，不断提高应急抢险能力，努力打造“召之即来、来之能战、战之能胜”的行业应急铁军，为维护上海城市安全运行做出新的贡献。

特此通知。

2022年6月30日
