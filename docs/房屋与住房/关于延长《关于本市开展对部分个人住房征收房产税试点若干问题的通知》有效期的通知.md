# 关于延长《关于本市开展对部分个人住房征收房产税试点若干问题的通知》有效期的通知

各区财政局、国家税务总局上海市各区税务局、住房保障房屋管理局，市财政监督局、国家税务总局上海市税务局各税务分局：

经评估，《关于本市开展对部分个人住房征收房产税试点若干问题的通知》（沪财发〔2020〕18号）需继续实施，有效期延长至2031年1月27日。

特此通知。

国家税务总局上海市税务局

上海市房屋管理局
