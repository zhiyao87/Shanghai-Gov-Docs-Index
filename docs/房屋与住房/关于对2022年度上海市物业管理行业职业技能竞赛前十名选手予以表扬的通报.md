# 关于对2022年度上海市物业管理行业职业技能竞赛前十名选手予以表扬的通报

各有关单位：

根据《关于举办2022年度上海市物业管理行业职业技能竞赛的通知》（沪房物业〔2022〕104号）的要求，2022年9月以来，本市物业服务企业和广大从业人员积极响应中共上海市城乡建设和交通工作委员会、上海市住房和城乡建设管理委员会、上海市总工会、上海市房屋管理局的号召，踊跃参与物业管理行业职业技能竞赛活动，进一步提升行业基础服务技能水平，展示本市物业管理行业的专业形象和精神风貌，涌现出一批技能过硬的行业人才。

为表扬先进，鼓励成才，现决定对在物业管理员比赛项目中获得总成绩排名前十名的选手予以表扬（名单详见附件）。其中，获得总成绩前三名的陈亨等3名选手，符合条件的由市物业管理行业协会按照程序授予“上海物业工匠”称号，并优先纳入“上海工匠”评选行业推荐名单；对获得总成绩排名第四名至第十名的刘通等7名选手，由市物业管理行业协会授予“上海市物业管理行业技术能手”称号。

希望以上受到表扬的人员珍惜荣誉、再接再厉，充分发挥示范作用，以更高的标准、更严格的要求，在岗位上再创佳绩。广大物业管理行业从业人员要以受表扬人员为榜样，爱岗敬业、刻苦钻研，不断提升技能水平。各级房管部门党组织要指导各物业服务企业，认真贯彻落实党的二十大精神，践行人才强国战略，切实加强职业培训，为培养素质优良、技艺精湛、作风踏实的行业人才队伍作出努力，为推动物业管理行业高质量发展作出贡献。
