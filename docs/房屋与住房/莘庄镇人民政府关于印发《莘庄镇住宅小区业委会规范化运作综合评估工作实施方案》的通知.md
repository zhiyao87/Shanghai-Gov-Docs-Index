# 莘庄镇人民政府关于印发《莘庄镇住宅小区业委会规范化运作综合评估工作实施方案》的通知

闵莘府发〔2025〕4号
各相关部门、各居民区：
《莘庄镇住宅小区业委会规范化运作综合评估工作实施方案》已经2025年9月5日莘庄镇人民政府2025年第11次镇长办公会议审议通过，现印发给你们，请认真遵照执行。

闵行区莘庄镇人民政府
2025年11月7日

莘庄镇住宅小区业委会规范化运作综合评估
工作实施方案

为进一步指导监督业委会依法依规运作，提升规范化运作水平，保障小区业主的合法权益，根据《中华人民共和国民法典》、《上海市住宅物业管理规定》和《关于开展本市住宅小区业主委员会规范化运作评价工作的指导意见》等相关规定，结合莘庄镇实际情况，就莘庄镇住宅小区业委会规范化运作综合评估工作，制定如下实施方案。
一、评估对象
莘庄镇辖区内依法组建，运作满六个月的住宅小区业主委员会。
二、评估原则
1.自觉接受党的领导，接受莘庄镇人民政府、居委会的指导和监督，接受业主大会和业主的监督。能够积极协助配合开展美丽家园、垃圾分类等小区综合管理相关工作。
2.按照法律、法规及小区各项规约规范运作，资金使用规范，日常工作台账规范健全。
3.有效沟通协调，引导业主自觉履行义务、遵守小区管理规约、文明公约，增强自我教育、自我管理的能力。
4.及时了解业主、物业使用人的意见和建议，依法有序维护业主权益，监督并积极协助物业服务企业履行物业服务合同。
5.业委会成员团结合作，业主认同度、满意度高。
6.创新工作方法，积极主动化解小区各项管理难题和矛盾。
三、评估内容
莘庄镇住宅小区业委会规范化运作综合评估由基本评估和特色评估两部分组成。以两年为一个周期，对镇内所有符合条件的住宅小区业主委员会实施全覆盖评估。第一轮评估截止至2025年底，第二轮评估自2026年起，截止至2027年底，以此类推。评估标准会根据上级部门评估标准的变动及莘庄镇重点工作的部署作相应调整。
（一）基本评估
基本评估主要涵盖日常工作制度规范、专项维修资金和公共收益使用管理规范、物业选聘与监督规范、换届及变更规范四大类，由第三方评估机构进行现场资料检查，占评估总分80%。同时，根据评估过程中发现的情况和评估结果，给每个参评的业主委员会出具意见建议书。
（二）特色评估
特色评估为党建引领执行情况，由居民区党组织评估，占评估总分20%。
四、评估计分规则
综合评估=基本评估得分×80％+特色评估得分×20％
五、评估结果运用
综合评估得分在60分及以上的小区业委会按排名予以星级表彰，60分（含）-79分评为“三星业委会”、80分（含）-89分评为“四星业委会”、90分（含）以上评为“五星业委会”。
六、评估奖励
（一）每个评估周期设立星级业委会奖励和特殊贡献奖。
1.星级业委会奖励：给予每个五星业委会10000元、四星业委会5000元、三星业委会2000元奖励。
2.特殊贡献奖：对获得市级媒体正面报道，或在社会治理工作中作出引领性贡献的业主委员会，给予特殊贡献奖，奖励标准为20000元/例，实行“一案一议”。
（二）奖励拨付至小区业主大会账户，用于业委会办公经费，后续资金使用按照各小区业主大会议事规则执行。

附件：莘庄镇业主委员会规范化运作评估标准

公开属性：主动公开
