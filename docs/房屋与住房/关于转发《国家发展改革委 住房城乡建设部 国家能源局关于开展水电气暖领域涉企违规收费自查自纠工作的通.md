# 关于转发《国家发展改革委 住房城乡建设部 国家能源局关于开展水电气暖领域涉企违规收费自查自纠工作的通知》的通知

各区发展改革委、经（科经、商务）委、建设管理委、水务局，各供水、供电、供气企业：

为贯彻落实国务院决策部署，切实减轻企业不合理负担，现将《国家发展改革委 住房城乡建设部 国家能源局关于开展水电气暖领域涉企违规收费自查自纠工作的通知》（发改价格〔2022〕1116号，以下简称《通知》，详见附件）转发给你们，请遵照执行，并就我市水电气领域涉企违规收费自查自纠有关工作要求通知如下。

一、主要任务

严格按照《通知》明确的重点任务，清理规范建筑区划红线外接入工程收费、建筑区划红线内有关收费、已纳入定价成本的相关收费、非电网直供电环节不合理加价以及其他不合理收费。

二、组织实施

市水务局、市经济信息化委、市住房城乡建设管理委分别负责组织实施供水、供电、供气领域涉企违规收费自查自纠工作。各区相关水务、经济、燃气主管部门要按照市级行业主管部门有关要求，开展本辖区内水电气领域涉企违规收费自查自纠。各区发展改革委要加强对水电气用户的调研走访，发现违规收费问题要及时反馈各区行业主管部门，配合研究制定整改措施。供水、供电、供气企业要做好自查自纠，主动规范整改，并完成数据填报等工作。

自查自纠工作具体分为三个阶段。

1.调查摸排（2022年8月19日前）

供水、供电、供气企业要开展全面自查，梳理本领域内存在的违规收费具体问题和整改情况。各有关单位要深入企业开展调查研究，全面掌握了解本辖区内水电气领域涉企违规收费具体情况和问题，摸排查清投诉举报线索，系统梳理，逐项分析。请市级行业主管部门汇总分析，并填写问题自查自纠情况明细表（详见附表1）、问题自查自纠情况汇总表（详见附表2）。

2.集中整改（2022年8月25日前）

根据调查摸排情况，取消不合理收费项目，涉及市级部门职能的及时向市发展改革委和市级行业主管部门反馈。对于发现的违法违规价格行为，要及时向市、区市场监管部门通报相关线索，并举一反三提出整改措施。

3.工作总结（2022年8月31日前）

各区行业主管部门将自查自纠情况及对建立健全长效监管机制的意见建议形成报告，于8月31日前报送市水务局、市经济信息化委、市住房城乡建设管理委。市发改委将会同有关部门汇总分析自查自纠工作情况，形成本市水电气涉企违规收费自查自纠情况上报。
