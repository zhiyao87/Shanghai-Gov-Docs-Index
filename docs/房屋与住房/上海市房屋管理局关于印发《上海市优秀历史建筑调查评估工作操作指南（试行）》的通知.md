# 上海市房屋管理局关于印发《上海市优秀历史建筑调查评估工作操作指南（试行）》的通知

各区住房保障房屋管理局：

根据市委办公厅、市政府办公厅《关于在城乡建设中加强历史文化保护传承的实施意见》和上海市房屋管理局、上海市财政局、上海市规划和自然资源局《上海市优秀历史建筑调查评估工作实施办法》的相关要求，为扎实推进本市优秀历史建筑保护利用工作，现将《上海市优秀历史建筑调查评估工作操作指南（试行）》印发给你们，请结合实际按照执行。

2022年11月22日
