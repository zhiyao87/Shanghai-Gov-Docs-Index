# 关于印发《中国（上海）自由贸易试验区临港新片区高品质住宅管理大纲（2024）》的通知

关于印发《中国（上海）自由贸易试验区临港新片区高品质住宅管理大纲（2024）》的通知

沪自贸临管委〔2024〕139号

管委会各部门、各直属单位，临港新片区各镇、各开发公司、各有关单位:

为提升临港新片区住宅小区的建设质量，打造符合人民生活要求的高品质住宅产品，真正实现“住有宜居”的住房发展目标，临港新片区管委会根据工作实践和跟踪评估，组织修编了《中国（上海）自由贸易试验区临港新片区高品质住宅管理大纲（试行）》，形成了《中国（上海）自由贸易试验区临港新片区高品质住宅管理大纲（2024）》。现印发给你们，请认真贯彻落实。

中国（上海）自由贸易试验区临港新片区管理委员会

2024年11月15日
