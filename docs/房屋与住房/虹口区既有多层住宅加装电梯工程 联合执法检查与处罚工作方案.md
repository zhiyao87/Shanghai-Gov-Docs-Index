# 虹口区既有多层住宅加装电梯工程 联合执法检查与处罚工作方案

为进一步加强虹口区既有多层住宅加装电梯工程质量安全及文明施工管理，完善对参建方的监督与服务，根据《关于进一步做好本市既有多层住宅加装电梯工作的若干意见》（沪建房管修〔2019〕749号）、《关于进一步做好全市限额以下建设工程安全生产工作的通知》（沪建质安〔2021〕526号）、《关于加强既有多层住宅加装电梯代建单位管理等事项的通知》（沪精细化办〔2021〕17号）、《上海市既有多层住宅加装电梯工程质量安全监督要点（试行）》及有关规定，结合工作实际制定虹口区既有多层住宅加装电梯工程联合执法检查与处罚工作方案。

一、基本原则

按照“全覆盖、全过程、全要素”的检查原则，严格对照建设工程规章制度，开展虹口区加装电梯工程常态化联合执法检查工作，严肃查处违规违法行为，切实消除安全隐患，保障工程建设质量，杜绝施工扰民现象，通过“一次检查、全面体检、综合会诊、集中交办”的联合执法检查模式，大力提升虹口区加装电梯工程管理水平。

二、执法检查主体

联合执法检查主体为区房管局、区建管委、区应急局、区市场监管局、区城管执法局、区消防救援支队及所属街道。

三、执法检查内容

根据加装电梯工程项目特点，联合执法检查内容主要包括：

(一)安全检查内容

1.施工区域(材料堆场区域)与居民住宅、生活区围挡(警示标志)设置的情况；

2.脚手架及人员进出通道设置的情况；

3.吊装作业的情况；

4.施工临时用电管理(电线电路架设及外电防护)的情况；

5.特种作业人员（高空作业、电焊作业等）持证上岗的情况；

6.临时消防设施配备及管理的情况。

（二）质量检查内容

1.基础施工及桩基承载的情况；

2.电梯井道及连廊结构与原建筑结构连接的情况；

3.钢结构构件的选用及安装的情况；

4.混凝土结构外观质量的情况；

5.电梯基础、外墙及屋面的防水施工情况；

6.开展建材和实体质量检测的情况，对材料报审、隐蔽工程验收的审核及对关键部位的施工进行旁站监理情况；

7.电梯施工及完成后的沉降观测情况；

8.结构施工和竣工阶段自查和报验的情况；

9.建设过程中涉及结构、消防等重大设计变更重新论证的情况。

（三）文明施工检查内容

1.建筑垃圾、建筑土方、工程渣土及时清运，密闭式防尘网遮盖的情况；

2.按照规定取得许可，在噪声敏感建筑物集中区域夜间进行产生噪声的建筑施工作业的情况；

3.采取有效的遮蔽光照措施的情况；

4.按照规定取得许可临时使用绿地、迁移树木或者绿化设施的情况；

5.编制建筑垃圾处理方案，及时清运固体废物、建筑垃圾的情况。

四、职责分工

区房管局负责加装电梯工程的全面管理，督促代建单位、监理单位、施工单位等建立质量安全生产责任制、落实质量安全生产主体责任，牵头协调相关部门落实各自监管职责，开展联合执法检查和处罚。

区建管委负责加装电梯工程质量、安全监督管理和指导，做好受监加装电梯项目的日常质量检查，对违反建设工程质量法律法规的行为进行行政处罚。

区应急局强化综合监管，对加装电梯中负有安全生产监督管理职责的部门加强履职检查，对未履职的负有安全生产监督管理职责的部门以安委办名义进行督办，对涉嫌刑行衔接的违法行为移送区公安分局处理。

区市场监管局负责加装电梯工程特种设备监督管理，对违反特种设备相关法律法规的行为进行行政处罚。

区城管执法局加强对属地街道综合行政执法队（城管中队）执法业务指导。属地街道综合行政执法队（城管中队）负责加装电梯工程文明施工监督管理，对违反文明施工法律法规的行为进行行政处罚。

区消防救援支队和属地街道派出所负责加装电梯工程消防安全监督管理，对违反消防法律法规的行为进行行政处罚。

各街道负责属地区域加装电梯项目的安全巡查，对联合检查过程中发现的问题及时督促有关单位进行整改。

五、工作措施

（一）成立联合执法检查小组

各监管单位成立既有多层住宅加装电梯工程联合执法检查小组，组长由区房管局局长担任，副组长由区房管局、区建管委、区应急局、区市场监管局、区城管执法局、区消防救援支队及各街道分管领导担任，成员由相关单位科室负责人担任。

（二）建立联合执法检查机制

各加装电梯工程监管单位确定联合执法检查联络员，由区房管局牵头定期（每月一次）开展联合执法检查工作，检查加装电梯工程的所属街道一同参加。各监管单位根据各自职能，分工协作，对加装电梯工程安全、质量、文明施工等相关工作开展联合执法检查，检查形成问题清单。

（三）问题隐患复查闭环

联合检查完成后，各监管单位针对检查中发现的问题，提出整改意见，并根据问题严重性程度，通过约谈警示、通报批评、责任追究等进行处理。同时，各监管单位根据整改时限进行现场复查，形成闭环。

（四）联合检查结果应用

联合检查及处罚情况同步作为虹口区加装电梯代建单位信用分考评的依据，同时，区房管局定期将各加装电梯工程监管单位的检查与处罚情况进行汇总，以加装电梯工作简报形式通报。
