# 关于加强金山区既有多层住宅加装电梯代建单位管理的通知

区规划资源局、建管委、市场监管局，各街镇（金山工业区）：

为促进金山区既有多层住宅加装电梯（以下简称“加梯”）工作有序推进，规范加梯代建单位行为，提高加梯工作质量，根据《关于进一步做好本市既有多层住宅加装电梯工作的若干意见》《关于进一步明确本市既有多层住宅加装电梯审批管理等要求的通知》《关于加强既有多层住宅加装电梯代建单位管理等事项的通知》等相关文件规定，结合本区实际情况，现就相关工作通知如下。

一、加强加梯代建单位的选择、管理

既有多层住宅加装电梯代建单位（以下简称“加梯代建单位”），是指受本区加梯的既有多层住宅小区楼幢业主委托，按照合同约定，协助业主依法开展征询工作，对加装电梯项目建设实施检测、勘察、设计、施工、监理、电梯安装服务的专业化项目管理单位，承担建设单位安全质量责任。

（一）加梯单位的选择

凡在本区从事加梯工作的代建单位应当具备以下条件：

1.熟悉掌握本市既有多层住宅加梯相关政策，具有相关工作业绩和良好市场信誉。

2.能独立承担相应的责任和义务，并在建设过程中遵守相关法律法规和管理规定。

3.具有与加梯相关的检测、勘察、设计、施工、监理、电梯安装等专业化项目管理力量。

满足上述条件的代建单位，在与小区业主或业委会签订加梯代建合同前，应当携带相关证照资料前往区房管局备案登记，纳入金山区加梯代建单位名录库。按照“公平、公正、公开、择优”的原则，鼓励引导小区业主或业委会选择金山区加梯代建单位名录库中“实力强、经验足、服务优”的单位为其提供加梯代建服务。

（二）代建单位的签约管理

小区业主确定委托加梯代建单位后，双方应当签署《加梯代建合同并签署金山区既有多层住宅加装电梯代建单位承诺书》(详见附件1)。合同应载明加梯工程建设管理的范围和内容，委托人加梯代建单位的权利和义务，明确加梯代建项目的质量要求和工期、代建管理费用、设计变更程序、建成后电梯使用单位、违约责任及各方约定的其他事项等内容。加梯代建单位应当严格合同约定履行义务，不得将项目转包或违法分包，并在项目竣工验收后，协助业主落实建后维保工作和资金补贴申请事宜。

加梯代建合同应当报区房管局和拟加梯小区所在地的城建中心备案。

二、建立加梯代建单位信用评估制度

本区建立以加梯项目为基准的加梯代建单位信用评估制度，区房管局作为既有多层住宅加装电梯牵头单位，每年于一季度制定各街镇（工业区）加梯任务数量指标，各街镇（工业区）根据各自情况落实反馈各自区域内加梯年度推进项目清单，区房管局根据各街镇（工业区）反馈的项目清单制定区级加梯年度计划。原则上列入加梯年度计划的项目在年内应当完成竣工验收。

（一）评估周期

对本区内参与加梯代建工作的单位按自然年进行评估，由区房管局牵头负责，每年12月组织协调相关部门及属地城建中心对本年度应当完成竣工验收项目的加梯代建单位进行检查和评估，并公示通报评估结果。

（二）量化管理

对加梯代建单位的前期服务、全过程参建管理、进度控制、质量控制、安全文明施工、建后运维、诚信记录等要素按一定权重统一进行综合评估打分。评估以项目为单位，按代建单位进行汇总，代建单位有多个项目参与评估的，取各项目的平均分作为最终评估分数。评定等级分为A、B、C、D四个信用等级。评估规则详见《金山区既有多层住宅加梯代建工作评估表》(详见附件2)；

三、强化加梯代建单位评估结果应用

强化评估结果应用，逐步优化加梯代建单位名录库，实现加梯代建单位信用等级差异化管理和动态监管。

（一）等级划分

1.信用分数排名前20%（含）的为A级企业，分数排名前40%（含）至前20%的为B级企业。

2.信用分数排名在前80%（含）至前40%的为C级企业；

3.信用分数排名在后20%的为D级企业。

（二）差异管理

1.A、B级企业实行信用激励机制，在金山区加梯代建单位名录库以绿色标识突出为诚信单位，推荐业主优先选择；

2.C级企业实行信用引导机制，在金山区加梯代建单位名录库以黄色标识突出为一般单位，引导业主谨慎选择；

3.D级企业实行信用惩戒机制，在金山区加梯代建单位名录库以红色标识突出为预警单位，不引导业主选择；对已承接的项目视具体情况予以约谈等方式处理，并加大监管力度。

由区房管局每年更新和制作金山区加梯代建单位考评信用等级名册，并通过官方微信向社会公开。

（三）黑名单制度

出现以下情形的，加梯代建单位将被清退出金山区加梯代建单位名录库，列入黑名单并向社会公开，不得再从事本区加梯工作：

1.发生严重工程质量安全责任事故的且代建单位负主要责任的；

2.造成严重社会不良影响的（如项目建设期间发生严重舆情或重大群体性社会稳定事件的）；

3.以严重低价承接项目或其他恶性竞争行为的；

4.项目竣工验收质量达不到合格标准且拒不整改的；

5.代建单位信用等级评价分数低于40分的；

6.受到行政机关严厉处罚的。
