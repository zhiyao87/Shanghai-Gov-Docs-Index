# 竖新镇关于进一步加强农村集体资产租赁管理工作的通知

各村（居）民委员会、集体经济组织：

为贯彻落实《上海市农村集体资产监督管理条例》和《崇明区加强农村集体资产管理工作的指导意见》（沪崇农规〔2022〕2号）精神，加强我镇农村集体资产租赁管理，保障农村集体经济组织和资产经营者合法权益，我镇形成《竖新镇关于进一步加强农村集体资产租赁管理的工作方案》，请各村（居）民委员会、集体经济组织遵照执行。

附件1

竖新镇关于进一步加强农村集体资产租赁管理的工作方案

为贯彻落实《上海市农村集体资产监督管理条例》《崇明区加强农村集体资产管理工作的指导意见》（沪崇农规〔2022〕2号）和《关于进一步加强崇明区农村集体资产租赁管理的工作方案》（以下简称《工作方案》）的精神，加强我镇农村集体资产租赁管理，保障农村集体经济组织和资产经营者合法权益，为此，结合本镇实际，制定以下工作方案。

一、指导思想

农村集体资产是发展农村经济和实现农民共同富裕的重要物质基础，充分认识加强镇、村、队三级农村集体资产的租赁管理的重要性、紧迫性和必要性，以改革的理念、创新的举措、科学的手段，依据区农委《工作方案》，建立本镇农村集体资产租赁管理工作方案，以健全农村集体资产租赁管理机制，实现农村集体资产租赁管理工作的规范化，切实保护好农村集体资产，维护好农村集体经济组织和资产经营者合法权益。

二、基本原则

（一）坚持依法依规

根据区农委《工作方案》，农村集体资产受法律保护，农村集体资产租赁严格按照《上海市农村集体资产监督管理条例》等法律法规和集体经济组织章程规定，依法依规实施，做到管理规范、运营高效、监管到位、公开公正。

（二）坚持民主公开

根据区农委《工作方案》，充分保障农村集体经济组织成员享有的知情权、表决权、收益权、监督权等权利，农村集体资产租赁应严格履行民主决策程序，将民主和公开贯穿集体资产经营与监管的各个环节。

（三）维护成员权益

根据区农委《工作方案》，农村集体资产属农村集体经济组织全体成员共同所有，切实维护集体经济组织及其成员的合法权益，防止集体资产流失，促进农村集体资产保值增值。农村集体资产租赁管理，既要立足当前集体经济组织现实收益，又要着眼长远的持续稳定，做到统筹兼顾，健康发展。

三、管理范围

本工作方案适用于本镇镇、村、组三级农村集体经济组织及其全资、控股集体企业所属的集体建设用地、集体农用地、房屋等经营性资产的租赁交易。

四、管理责任

镇集体资产监督管理委员会是农村集体资产租赁管理的责任主体，做好本镇农村集体资产租赁及租赁合同履约监管和指导工作。

镇农村集体资产管理部门设在镇经济发展服务中心，具体负责本镇农村集体资产租赁的日常审核和监督管理，确保农村集体资产租赁经营符合所在区域产业规划要求，确保各项制度有效执行。

镇集体经济联合社、村集体经济合作社及其所属全资、控股集体企业是农村集体资产租赁的实施主体，严格按照制度要求开展资产租赁管理、合同履约管理，并自觉接受镇集体资产管理部门的监管。

组级农村集体资产租赁，经本组户代表五分之四以上表决同意后，原则上通过授权或者委托村集体经济合作社代理实施。

五、租赁程序

农村集体资产全部纳入上海农村集体资产经营管理监督平台（以下简称“三资”平台）监管。规范农村产权流转交易行为，坚持“应进必进”“能进则进”原则，农村产权流转交易应当进入上海农村产权交易平台，进行公开透明、公平竞争的自主交易。农村集体资产租赁严格实行民主决策，基本程序如下：

（一）方案预审

村级集体经济组织作为出租方的，由合作社理事会提议、村党组织商议后报镇集体资产监督管理委员会预审；镇级集体经济联合社、集体企业作为出租方的，应由镇资产管理部门报镇集体资产监督管理委员会预审。租赁方案应包括标的物基本信息、租赁用途、租赁价格、租赁期限、交易方式等内容。

（二）民主决议

租赁方案预审通过后，镇集体经济组织提交镇党委会审议后再提交成员代表会议决议；村级集体经济组织提交村党员大会审议后再提交成员代表会议决议。方案经民主决策程序表决通过后，应进行不少于5个工作日的公示。

（三）公开交易

租赁方案公示期满无异议后，出租方通过“三资”平台线上发起交易，根据上海农村产权交易平台的交易规则，规范实施公开交易。

（四）签约公示

根据公开交易结果，出租方以区级合同示范文本与承租方正式签约（如遇一事一议的合同，需经法务审核后方可签约）。租赁标的物面积、租赁价格、租赁周期等签约情况应进行不少于5个工作日的公示并接受本集体经济组织成员监督。

六、租赁价格

农村集体建设用地租赁价格不低于每年1万元/亩。

农村集体农用地租赁价格不低于本区公益性项目流转农用地补偿指导价。

集体房屋租赁价格可根据租赁标的物区域位置、交通条件、租赁用途、房屋成新、使用面积、配套设施等因素，综合研究确定租赁指导价（附件3）；也可在保障集体收入不减少的情况下，探索建立租税联动工作机制，积极推动农村集体资产盘活利用。

对确因历史原因、客观现实等造成新签、续签合同租赁价格低于指导价的，出租方应按照实事求是的原则加强与承租方沟通协商后，通过一事一议的方式，报镇集体资产监督管理委员会审核同意，并经本集体经济组织民主决策后方可实施。集体土地租赁价格低于指导价的，租赁价格应有增长机制，原则上租赁价格在一个租赁周期内逐步提升至指导价水平。

七、租赁期限

农村集体资产一个租赁周期原则上不超过5年。对确因历史原因、客观现实等造成新签、续签合同租赁周期超过5年的，出租方应按照实事求是的原则加强与承租方沟通协商后，通过一事一议的方式，报镇集体资产监督管理委员会审核同意，并经本集体经济组织民主决策后方可实施。

八、合同文本

按照区农业农村委制定《崇明区农村集体资产租赁合同（示范文本）》（以下简称“区级合同示范文本”）。镇、村、组集体经济组织按照“区级合同示范文本”签订租赁合同，也可结合实际情况对“区级合同示范文本”补充完善后签订租赁合同。

九、监督管理

镇集体资产监督管理委员会对农村集体资产租赁全过程监管，严格执行管理制度，加强合同履约管理，严控集体资产租赁风险，全面梳理排摸农村集体资产租赁合同，建立健全管理台账，分层分类有效化解长期租、低价租等历史遗留问题合同，持续强化农村集体资产监管，促进集体经济健康稳定发展。

镇资产管理部门不定期开展农村集体资产租赁管理监督检查，对发现的问题短板和薄弱环节，督促并及时整改，对涉嫌违纪违法的问题线索，移交纪检监察机关处置。

十、其他事项

（一）本方案自2025年1月1日起实施。

（二）本方案如与国家和上海市的有关法律、法规及上级文件精神不一致的，以法律、法规及上级文件精神为准。

（三）本方案由镇集体资产监督管理委员会负责解释。
