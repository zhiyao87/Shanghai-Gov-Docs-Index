# 康复辅具租赁补贴政策申请办理服务指南

（一）补贴对象
符合下列条件之一的本市户籍老年人，租赁《产品目录》中的康复辅助器具且单次租期为 2 个月或者 3 个月的，可以申请租赁服务补贴。
1.75周岁（含）以上人员；
2.60～74周岁（含）经上海市老年照护统一需求评估具有二级
及以上照护等级的人员；
3.60周岁（含）以上低保、低收入人员。
（二）补贴标准
75周岁（含）以上和60～74周岁（含）二级及以上照护等级的老年人，补贴金额为《产品目录》中租赁服务价格的50%；低保、低收入老年人，补贴金额为租赁服务价格的70%；每人每年补贴最高限额3000元。
（三）租赁服务在线申请
1.下载并登陆“随身办市民云”APP。
2.进入【随身办市民云】首页，点击【更多-社会保障-康复辅助器具社区租赁服务申请】进入申请页面。
3.点击选择租赁人【户籍】或【实际居住地】行政区划
核对申请表中自动生成的【姓名】、【证件类型】、【证件号码】、【性别】、【手机号码】。
4.填写【租赁服务申请信息】中的【必选/必填信息】，包含【本人申请/他人申请】、【康复辅具送货地址街镇区划】、【社区辅具租赁点】、【康复辅具送货地址】、【康复辅具产品名称及型号】、【是否符合补贴资格】。
*如果是申请人本人租赁辅具，则选择【本人申请】；如果是他人租赁，则选择【他人申请】。本人租赁，但是由他人代填表的，可补充填写【填表人】、【填表人身份证号】、【填表人手机号码】。申请表中部分信息会在填表过程中自动生成。
5.确认信息无误后，点击【提交】，系统跳转至【提交成功】画面，则说明提交成功。
6.可进入【我的-我的办件】，点击已提交的【康复辅助器具社区租赁服务申请-新办】查看办理进度，等待服务商电话联络。
