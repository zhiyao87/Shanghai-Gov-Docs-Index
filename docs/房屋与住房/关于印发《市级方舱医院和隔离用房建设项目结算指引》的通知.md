# 关于印发《市级方舱医院和隔离用房建设项目结算指引》的通知

关于印发《市级方舱医院和隔离用房建设项目结算指引》的通知

沪建标定联〔2022〕383号

各有关单位：

根据市委、市政府疫情防控统一决策部署，为加快本市市级方舱医院和隔离用房建设项目竣工结算工作,规范指导建设各方有序开展结算工作,现将《市级方舱医院和隔离用房建设项目结算指引》（以下简称《结算指引》）印发给你们，请根据《结算指引》尽快开展完成竣工结算工作。

特此通知。
