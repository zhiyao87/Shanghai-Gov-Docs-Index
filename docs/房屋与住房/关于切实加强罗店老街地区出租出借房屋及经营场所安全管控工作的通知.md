# 关于切实加强罗店老街地区出租出借房屋及经营场所安全管控工作的通知

长江口投控集团、区供销合作总社、粮油购销公司、宝房集团：

根据前段时间的大排查，系统内罗店地区出租出借房屋及经营场所数量多、面积大，仅罗店老街就有257户、10万平方米，该片区域房屋较为破旧，业态低端，安全基础及条件极为薄弱，承租人安全意识差。3月28日，区委常委、副区长苏平在调研罗店老街国资委直管企业出租出借房屋及经营场所业态和安全工作时多次强调在转型调整期间要特别加强安全管控工作。

4月1日，区国资委召开党政班子扩大会，就加强罗店老街安全管控工作进行了专题研究，并就转型调整期间安全管控工作提出如下要求：

一、严格执行负面清单，加强业态管控

根据《宝山区国资委、集资委关于进一步加强监管企业出租出借房屋及经营场所管理的实施意见》，企业出租出借房屋及经营场禁止下列行为：

1.在本市内环线以内的房屋及经营场所和在区政府规定的禁止危险化学品生产的有关区域从事危险化学品生产的行为。

2.从事涉黄、涉赌、生产销售假冒伪劣产品等违法犯罪活动的行为。

3.在设有经营活动、生产车间或者仓库的建筑物内，设置员工集体宿舍的行为。

4.堵塞、封闭、占用疏散通道和安全出口，违法使用特种设备，造成安全隐患的行为。

5.违反有关食品安全法规，违法生产、加工、制造、储存、运输、销售食品的行为。

6.违反操作规程和安全管理规定从事作业的行为。

7.隐瞒事故隐患；对已经发生的事故隐瞒不报的行为。

8.法律、法规禁止的其他行为。

二、加强协议管理，严格报备程序

1.各企业出借房屋签订租赁合同时，必须同时签订安全生产责任书。

2.对依法依规转租的，要在转租过程中签订新的安全生产责任书。

3.安全生产协议在签订后30日内向租赁房屋及经营场所所在地的镇政府、街道办事处报备。

4.出租面积在1000平方米以上，场地单项面积2000平方米以上的出租项目或出租房屋和场地面积合计在2000平方米以上的出租项目在租赁合同签订后15个工作日内向区国资委行政审批科备案。

三、强化隐患排查整改，提高现场管控能力

1.企业各级安全管理部门和管理人员必须严格按照规定履行工作职责，加强对出租出借房屋及场所的日常检查，企业每月全覆盖检查不小于1次，片区管理部门检查每周不少于1次。

2.检查中要对照各行业最新标准从严、从实、从细开展检查，决不能因历史原因而降低检查和整改的标准。要教育引导被检单位和承租单位、承租人端正态度，提高认识，正确对待安全检查。

3.对检查出的问题隐患要列好清单，要逐条逐项落实整改，并做好防控预案。要对检查敷衍、整改不力的当事企业、区域网点负责人及相关人员严肃追责。

4.罗店老街地区木结构较多，原则上除经营性餐饮场所外，其他场所不得使用罐装燃气。

5.各直管企业要加强和属地政府及属地安管所的沟通，积极配合属地政府进行的各项安全检查并认真做好整改工作。

6.各企业要及时做好各项安全会议、检查、整改、管控、维护等记录，严格规范台帐的管理。
