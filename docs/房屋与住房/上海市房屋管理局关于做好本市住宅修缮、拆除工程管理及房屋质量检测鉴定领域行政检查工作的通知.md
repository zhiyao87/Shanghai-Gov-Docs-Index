# 上海市房屋管理局关于做好本市住宅修缮、拆除工程管理及房屋质量检测鉴定领域行政检查工作的通知

临港新片区管委会，各区住房保障房屋管理局，各相关单位：

为加强本市住宅修缮工程、拆除工程、房屋质量检测鉴定活动的监督管理，规范行政检查工作程序，提升行政检查的科学性、公正性与实效性，依据《上海市建设工程质量和安全管理条例》《上海市建设工程检测管理办法》《上海市房屋使用安全管理办法》《上海市人民政府办公厅关于规范本市涉企行政检查的实施意见》《上海市住房和城乡建设管理委员会规范涉企行政检查的实施方案》《上海市住宅修缮工程管理办法》《上海市既有建筑物、构筑物拆除工程管理规定》《上海市房屋检测鉴定单位管理办法（暂行）》等相关法律法规及规范性文件，现就有关事项通知如下：

一、适用范围

市、区房屋管理部门或其委托单位对纳入监督范围的住宅修缮工程、拆除工程、房屋质量检测鉴定活动等进行的行政检查工作适用本通知。

二、行政检查方式

行政检查包括有计划行政检查和触发式行政检查，以现场检查为主。仅实施线上核查、书面函询、数据比对等非现场行政检查的，按照专项工作细则执行。

有计划行政检查是指相关责任主体开展日常检查、专项检查，实行“先计划后检查”制度。

触发式行政检查是指根据投诉举报、舆情反映、转（交）办、其他部门移送等途径发现的违法违规线索，对相关责任主体开展的针对性行政检查。

三、行政检查工作要求

（一）制定行政检查计划

市、区房管部门应科学、合理制定行政检查计划，明确检查对象范围、检查比例、检查频次、检查方式、检查项目、检查必要性等内容，并报同级司法行政部门备案。推进跨部门联合检查，建立健全市、区两级联合检查机制。对涉及多部门职责的行政检查，应强化部门联动，统筹制定联合检查计划。

（二）分级分类行政检查

探索建立“风险+信用”的分级分类涉企行政检查模式，对检查对象进行综合评价。建立健全信用与风险信息动态调整机制，及时更新分级分类结果，实现有差异化的检查。对综合评价等次高的检查对象，合理降低检查频次；对综合评价等次一般的检查对象，保持常规检查频次；对综合评价等次低的检查对象，适当提高检查频次。

（三）规范检查主体

遵循合法合规、客观公正、公开透明的基本原则，由依法取得执法证件并持证的两名及以上人员实施行政检查。根据工作需要，市、区房屋行政管理部门可以邀请检验检测机构、科研院所、行业专家等第三方对行政检查予以协助，提供专业参考意见，第三方不得单独开展行政执法性质的检查。严禁外包给中介机构实施行政检查；严禁未取得执法证件的执法辅助人员、临时工等人员实施行政检查。

（四）全面应用检查码

开展现场行政检查前，行政检查人员应当向执法系统申领“检查码”，未取得“检查码”不得开展行政检查。申请“检查码”前，主动查询企业历史检查记录，避免多头检查和重复检查。到达现场并准备开展检查前，应当主动向检查对象出示“检查码”和行政执法证件。

（五）开展现场检查

行政检查人员应当按照规范的行政检查程序，做好行政检查记录，录入行政检查结果。检查记录包括视音频记录，记录内容包括检查发现的具体问题以及必要的调查问询等场景。行政检查过程中，应当对所有检查对象开展合规指导，针对不同检查结果进行差异化的合规指导。

1.住宅修缮工程、拆除工程检查。依照法定职责，了解、核查工程项目在施工安全、工程质量、材料使用行为及文明施工方面遵守法律法规、规章制度、施工图纸及工程建设有关标准的情况。

2.房屋质量检测鉴定活动检查。通过问询、检查实验室和查看资料等方式，全面检查材料检测机构住宅修缮工程材料检测活动、房屋检测机构房屋质量检测鉴定活动情况。

（六）规范结果处理

行政检查人员应明确建议提升内容和检查发现问题，检查发现问题应出具《行政检查告知单》（工程项目类《行政检查告知单》详见附件1，检测鉴定机构类《行政检查告知单》详见附件2），由检查主体、委托单位、检查对象等分别留存。行政检查过程中发现的违法违规行为，要指导督促责任单位限期整改，并根据现行行业管理要求对相关责任单位及人员进行处置。

（七）评价反馈

检查结束后，行政检查人员应向检查对象出示行政检查反馈信息码。检查对象针对检查工作反馈评价意见，自主完成线上提交，确保评价结果真实客观。

（八）资料保存

行政检查主体要加强对行政检查全过程文字、影像记录等的管理，探索切实有效的信息化记录储存方式，通过技术手段对行政检查记录进行集中存储，任何单位和个人不得擅自毁损、删除、修改记录资料。检查相关文字记录应在项目整改书面闭环工作结束后10个工作日内由检查单位妥善保存，文字记录保存期限不少于5年，影像记录应保存不少于6个月。
