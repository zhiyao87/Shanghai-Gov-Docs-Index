# 上海市住房和城乡建设管理委员会关于公布上海市超低能耗建筑项目第三方测评机构的通知

上海市住房和城乡建设管理委员会关于公布上海市超低能耗建筑项目第三方测评机构的通知

沪建建材〔2023〕199号

各有关单位：

为推进上海城乡建设领域碳达峰，加快新建建筑节能降碳，促进超低能耗建筑高质量发展，按照《上海市建筑节能和绿色建筑示范项目专项扶持办法》（沪住建规范联〔2020〕2号）《上海市超低能耗建筑项目管理规定（暂行）》（沪建建材〔2021〕114号）文件要求，我委通过政府采购公开招标方式确定了7家“上海市超低能耗建筑项目第三方测评机构”，具体名单如下：

国检测试控股集团上海有限公司

上海建科检验有限公司

上海众合检测应用技术研究所有限公司

上海同济检测技术有限公司

上海苏科建筑技术发展有限公司

上海浦公检测技术股份有限公司

上海诚云建设工程质量检测有限公司

（排名先后按中标公告顺序）

自文件印发之日起,以上第三方测评机构服务期限为三年。

尚未通过超低能耗建筑专项技术方案评估的项目，我委根据方案评估通过时间先后，按测评机构中标公告顺序为其匹配测评机构。已通过超低能耗建筑专项技术方案评估的项目，建设单位最晚在开展节能专项验收时向我委提出超低能耗建筑测评申请，并填报《上海市超低能耗建筑项目第三方测评申请表》（附件），签字盖章后寄送至我委。我委根据申请时间先后，按测评机构中标公告顺序为其匹配测评机构。
