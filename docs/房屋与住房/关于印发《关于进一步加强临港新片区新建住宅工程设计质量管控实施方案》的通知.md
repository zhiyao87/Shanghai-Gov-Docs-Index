# 关于印发《关于进一步加强临港新片区新建住宅工程设计质量管控实施方案》的通知

关于印发《关于进一步加强临港新片区新建住宅工程设计质量管控实施方案》的通知

沪自贸临管委〔2024〕106号

管委会各部门、各直属单位，临港新片区各镇、各开发公司、各有关单位:

为贯彻落实好《上海市住房和城乡建设管理委员会关于进一步加强本市新建住宅工程设计质量管控的通知》（沪建质安〔2024〕417号）和《中国（上海）自由贸易试验区临港新片区建设工程高质量发展实施方案（2023-2025年）》（沪自贸临管委〔2023〕103 号）的相关要求，进一步夯实临港新片区产城融合区范围内新建住宅工程建设单位工程质量首要责任和设计单位主体责任，临港新片区管委会组织制定《关于进一步加强临港新片区新建住宅工程设计质量管控实施方案》。现印发给你们，请认真遵照执行。

特此通知。

中国（上海）自由贸易试验区临港新片区管理委员会

2024年9月23日

关于进一步加强临港新片区新建住宅工程设计质量管控实施方案

为贯彻落实好《上海市住房和城乡建设管理委员会关于进一步加强本市新建住宅工程设计质量管控的通知》（沪建质安〔2024〕417号）、《中国（上海）自由贸易试验区临港新片区建设工程高质量发展实施方案（2023-2025年）》（沪自贸临管委〔2023〕103 号）、《关于印发的通知》（沪自贸临管委〔2022〕48 号）等文件的相关要求，进一步夯实建设单位工程质量首要责任和设计、施工等单位的主体主任，加强临港新片区新建住宅工程质量常见问题的源头治理，提升住房品质，特制定本实施方案。

一、实施范围

临港新片区产城融合区范围内新建住宅工程。

二、职责分工

（一）建设和交通管理处。负责区域内新建住宅工程设计质量管控的综合协调，督促建设单位组织编制“住宅工程关键节点设计专篇”（以下简称“设计专篇”）并将其纳入施工图审查要点。

（二）规划和自然资源处。负责区域内新建住宅工程设计质量的规划设计管控，将相关管控要点列为土地出让条件并纳入土地出让合同。

（三）城市建设交通运输事务中心（建设工程质量安全监督站）（以下简称建交中心）。负责区域内新建住宅工程质量的监督管理，并将相关管控要求纳入建设工程质量安全的日常监管范围；负责核查“设计专篇”及相关材料的有效性并对“设计专篇”的落实情况进行监管；在施工过程中对防治设计关键节点的施工质量进行抽查，在综合竣工验收阶段针对相关管控措施的落实情况和有关资料进行核查。

三、主体责任

（一）建设单位。建设单位应落实工程建设首要责任。严格落实《临港新片区工程项目建设单位关键人员配备指南（试行）》（沪自贸临管委〔2023〕71号）等有关文件规定，配备建设单位项目负责人和勘察设计质量主管人员，并明确其质量管理责任和持证上岗等要求。方案设计阶段应落实工程质量潜在缺陷保险（IDI）制度，要求保险公司的风险管理机构（以下简称TIS机构）从方案设计阶段进行源头风险控制；施工图设计阶段应落实专人督促设计单位编制“设计专篇”并报送施工图审查机构进行审查；施工阶段应组织施工单位编制“质量常见问题防治施工方案”（以下简称“施工方案”）；综合竣工验收阶段应要求施工单位在工程竣工报告中说明防治措施落实情况。鼓励支持编制《住宅使用手册》。

（二）设计单位。设计单位应落实设计质量主体责任。在施工图设计阶段，应结合临港实际编制“设计专篇”，提升新建住宅工程关键节点的设计标准与质量；在施工阶段应就“设计专篇”向施工单位作专项交底。涉及观感和使用功能的设计变更，必须征得小业主的同意，确保变更合理合法。

（三）TIS机构。TIS机构应落实质量风险管理责任。在方案设计阶段介入，对“设计专篇”的编制深度及合规性进行核查；在施工阶段应对“设计专篇”技术要求落实情况加强监督与抽查，将管控落实情况编入质量风险最终检查报告。加强日常检查，定期将检查情况报送至建交中心。

（四）施工总包单位及监理单位。施工总包单位应落实施工质量主体责任，在施工中严格按照关键节点设计管控要点编制“施工方案”，紧盯材料检验、工序控制、技术交底等方面工作，强化施工过程管理。监理单位应落实施工过程监理责任，将各项设计管控要点纳入日常监管，确保施工质量问题整改到位。

四、管控要点

各单位应严格落实《上海市住房和城乡建设管理委员会关于进一步加强本市新建住宅工程设计质量管控的通知》（沪建质安〔2024〕417号）和临港新片区新建住宅工程质量的相关要求，在“优化住宅工程关键节点设计管控”的18条具体措施基础上，结合临港实际，重点抓好以下两方面工作：

（一）提升高品质住宅设计质量。针对连廊雨水倒灌、阳台渗水、进户门与楼梯踏步距离过近等突出问题，遵循《中国（上海）自由贸易试验区临港新片区高品质住宅设计导则（试行）》，优化立面控制、户内空间、地下空间等关键节点设计方案，切实提升建筑品质。

（二）加强住宅工程质量常见问题治理。各镇政府应充分发挥社区和网格化管理作用，加强对日常管理中发现的住宅工程质量问题的收集，并将有关信息及时反馈至建交中心。各开发公司应加强对本单位及下属单位承建或代建的新建住宅工程设计质量管控的指导监督，督促相关单位履行企业主体责任，强化质量管控，及时将质量问题整改到位。

建交中心、TIS机构要加强日常检查指导，及时整理并汇总分析检查中发现的问题，督促参建各方及时完成整改。上海市工程建设质量管理协会（临港）要发挥专业组织和专业团队的优势，结合突出问题，编制临港新片区住宅工程质量常见问题管控措施案例，特别是外墙保温材料方面，要研究制定外墙保温一体化系统工程管理导则和维护手册；制定各类问题的正负面清单，鼓励引导企业不断提高工程质量，从源头上防治住宅工程常见质量问题。

五、组织实施

（一）加强创优评先。落实创优考核制度，对于未按规定落实住宅工程关键节点管控措施的责任单位，建交中心应责令整改；造成负面舆情或群体性事件的，应当及时警示，并按照相关规定取消评优资格。

（二）加强宣传培训。管委会定期组织建设单位、设计单位、审图公司开展住宅工程关键节点设计管控宣贯培训，督促各参建单位按要求落实方案。定期梳理住宅项目设计质量通病问题、常见问题以及“关键节点设计专篇”执行过程中的问题，面向勘察设计企业、审图公司组织研讨，通过交流学习，不断优化“关键节点设计专篇”质量，提高勘察设计行业水平。

本实施方案自发布之日起施行。
