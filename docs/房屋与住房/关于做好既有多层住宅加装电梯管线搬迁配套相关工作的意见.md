# 关于做好既有多层住宅加装电梯管线搬迁配套相关工作的意见

各相关单位：

为进一步支持和做好既有多层住宅加装电梯工作，规范加装电梯相关管线搬迁管理，提高办事效率、提升服务效能，保障管线搬迁的工程进度和质量安全，现提出如下意见：

一、进一步完善沟通协调机制

（一）提前对接加梯计划

各区要充分发挥加装电梯牵头推进和统筹协调作用，根据辖区内加装电梯业主签约情况和总体安排，主动牵头对接相关管线配套单位，建立月度计划对接机制，实现实施计划的提前告知。

各街镇要在加装电梯项目开工前，组织相关管线配套单位做好项目管线施工的交底工作。

（二）提前预排加梯事项

相关管线配套单位在提前获取加装电梯项目计划后，要主动跨前服务，积极做好加装电梯项目所涉及的管线搬迁前期踏勘、方案设计、施工安排等事项，实现加装电梯项目计划和管线搬迁计划“并联”推进。

（三）强化加梯施工协同

各街镇是辖区内加装电梯项目的牵头主体，要根据加装电梯项目的实施安排，做好与相关管线配套搬迁的实施衔接，按照“协同前期踏勘设计，统筹现场交底施工”的原则，强化电力、燃气、水务、信息通信等管线搬迁的施工协同，杜绝擅自搬迁现象，努力减少施工扰民影响，消除安全隐患。

（四）加强部门沟通协调

各区、各街镇要加强与水务、电力、燃气、通信管线等管线配套单位的沟通协调，强化管线搬迁施工过程的管线保护、安全生产和文明施工，牵头协调解决加装电梯管线迁移配套中的问题和难点，推动加装电梯项目顺利实施。

二、进一步强化服务支持

（五）简化办事流程、降低工程成本

相关管线配套单位要在已经推出的加装电梯管线搬迁服务要求、办事流程的基础上，按照“能减则减”“能免则免”的原则，进一步优化办事流程、简化收件资料、提高办事效率，科学编制管线搬迁计划，统筹管线搬迁以及相关道路开挖、回填施工等工作，有效降低工程成本，合理收取费用，减少居民负担。

（六）推动加梯申请“一件事”线上办理

各相关部门、街镇和管线配套单位要进一步推进加装电梯申请“一件事”线上办理，积极推动加梯审批及业务办理的“一口受理”“一站式服务”“同步踏勘”等，实现加梯信息互联互通和数据共享。

三、进一步明确工作要求

（七）推动整体方案设计

各区、各街镇要按照集约节约的原则，积极引导小区业主推动整小区、成规模加装电梯，提升代建单位的专业化水平，推动加装电梯方案的整体设计、管线搬迁的统一安排。

（八）整合各类改造计划

各区、各管线配套单位要将加装电梯与旧住房更新改造、美丽家园建设、老旧管网改造、架空线入地、通信管网升级、雨污水分流等改造项目结合，加强统筹安排，避免项目的重复建设和施工。

（九）加强质量安全监管

各区行业监督管理部门、各街镇及相关管线配套单位，要加强加装电梯项目和管线搬迁的质量安全监管，做好相关管线的施工保护，防止破坏管线等事故的发生。

市住房城乡建设管理委、市房屋管理局、市经信委、市水务局、市通管局等部门要加强行业指导，强化服务支撑，对管线迁移过程中遇到的各类突出问题，建立会商机制，及时推动解决。
