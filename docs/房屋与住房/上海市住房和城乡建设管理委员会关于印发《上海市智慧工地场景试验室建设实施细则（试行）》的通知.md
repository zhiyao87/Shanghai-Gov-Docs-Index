# 上海市住房和城乡建设管理委员会关于印发《上海市智慧工地场景试验室建设实施细则（试行）》的通知

上海市住房和城乡建设管理委员会关于印发《上海市智慧工地场景试验室建设实施细则（试行）》的通知

沪建质安〔2023〕701号

各区建设行政管理部门，各特定地区管委会，各有关单位：

为贯彻《上海市智慧工地建设指引（试行）》的要求，配套《上海市智慧工地场景试验室建设管理办法（试行）》执行实施，加快上海市建筑工地安全管理数字化转型，我委牵头编制了《上海市智慧工地场景试验室建设实施细则（试行）》，现印发给你们，请遵照执行。

2023年12月27日
