# 关于印发《虹口区住宅小区物业服务达标奖励实施意见》的通知

各街道办事处：

为进一步提升我区物业服务行业监管水平及人民群众的居住满意度，鼓励物业企业、小区业委会积极参与物业联合招标、质价双提升、小区微更新等工作，有效提升我区住宅小区物业服务总体水平，区房管局对《虹口区住宅小区物业服务达标奖励实施意见》进行了修订,现予以印发，请遵照执行。

特此通知。

虹口区住房保障和房屋管理局

2023年10月7日

虹口区住宅小区物业服务达标奖励实施意见

为进一步提升我区物业服务行业监管水平及人民群众的居住满意度，充分调动物业企业、小区业委会管理小区主动性和积极性，有效提升物业服务总体水平，根据物业管理相关规范要求，结合我区实际情况，制定本实施意见。

一、工作目标

根据市委、市政府关于创新社会治理，加强基层建设工作的总体要求，以建设安全、整洁、文明、有序的小区为目标，通过开展“达标奖励”活动，对达到考核标准的小区给予资金奖励，支持居委会、物业企业、小区业委会开展“家园微更新”硬件改造、环境提升、服务改善行动，促进物业服务水平不断提升，小区环境持续改善，以解决居民日益增长的居住环境需求与物业服务发展滞后的矛盾。

二、考核范围

成立业主大会，房屋竣工满15年，且有业主大会投票权的建筑物总面积（以下简称“考核面积”）小于等于10万平方米，委托物业企业提供物业服务的住宅小区（不包含直管公房一体化管理小区）。

三、工作原则

（一）自愿参与原则。符合条件的住宅小区，需由物业企业和小区业委会共同提出申请（小区业委会无法履职则由居委会代为申请），由所在居委会、街道城建中心初审后报街道办事处核准，汇总后将拟申请奖励资金的小区名单报区房管局。申请参加达标奖励考核的物业企业和小区业委会应自觉接受相关部门的考核与监督。

（二）客观公正原则。相关部门、各街道办事处在开展达标奖励工作时需坚持客观公正原则,杜绝人情因素和形式主义。通过对住宅小区物业服务实地考核检查，以居民、居委会与小区业委会的满意度测评，物业企业、小区业委会实际运行情况及与相关部门工作的配合情况等客观事实为依据，进行考核评分并进行奖励。

（三）注重实效原则。以考核结果为导向，激励物业企业加强管理、小区业委会规范履职，持续改进物业服务、提高居民满意度，以落实奖励资金使用为抓手，开展“家园微更新”活动，提高居民参与社区治理积极性，推动形成共建共治共享良好局面。

四、工作流程

（一）考核申请

“达标奖励”活动每半年开展一次，符合条件的住宅小区，由物业企业和小区业委会共同填写书面申请（附件1）后，交小区所在居委会、街道城建中心初审；街道办事处审核汇总后向区房管局提交本街道参与达标奖励工作的书面申请。

（二）资金预算

区房管局将住宅小区物业服务达标奖励资金纳入部门预算管理，根据申请参与达标奖励工作住宅小区的具体情况向区财政申请资金，预算编制和资金管理遵循注重引导、公正规范、强化绩效的原则。

（三）开展考核

考核工作由各街道负责实施。各街道应及时收集梳理各小区考核申请，并将汇总后的考核结果报区房管局备案。考核工作应坚持公平公正原则，考核评分材料由各街道保存。

2.资金使用

由各街道指导居委会、物业企业、小区业委会，将奖励资金用于小区“家园微更新”硬件改造、环境提升、服务改善活动和提高小区一线物业服务人员工作积极性（包括小区经理、保安、保洁、工程人员等），其中一线人员奖励占比30%。通过党建引领，由居民区党组织发动居委会、物业企业、小区业委会、广大居民共同参与小区建设和管理，重点解决小区安全隐患和环境短板问题，促进物业服务高质量发展，满足居民高品质生活需求。

3.资金拨付

各街道根据区房管局下达的奖励额度和考核结果制定参与达标奖励工作的住宅小区的奖励方案，汇总后将《虹口区住宅小区物业服务达标奖励考核情况汇总表》（附件2）报区房管局。各街道根据各小区获得奖励资金情况，指导居委会、物业企业、小区业委会规范使用资金，核实活动开展和资金使用情况后应在10月30日和次年5月30日前提出奖励资金拨付书面申请，区房管局收到申请后，将奖励资金发放至物业企业。

五、考核办法

本考核办法以小区为单位分别从实地核查（街道各部门）、住宅小区物业治理实效和满意度测评（居民、居委会、小区业委会）三方面对住宅小区物业服务状况进行考核评分，另设立一票否决和加分事项。

（一）街道各部门测评（占比30%）

1.街道城建中心将小区巡查工作发现的问题告知小区物业管理处，以问题解决效率和效果作为测评依据。

2.街道城运中心、城建中心通过962121物业呼叫平台、“12345”市民服务热线等信访工单处置中物业企业的配合情况做出评价。

街道办事处根据以上情况及其他相关部门反馈的物业企业相关工作的配合情况进行综合评分（附件3）。

（二）住宅小区物业治理实效测评（占比30%）

街道按照各住宅小区物业治理实效情况进行打分，将具体结果填入虹口区住宅小区物业治理实效测评表(附件4)。

（三）居民满意度测评（占比20%）

区房管局委托第三方测评机构对参加达标奖励小区居民关于小区物业服务工作进行满意度问卷调查。

（四）居委会、小区业委会满意度测评（占比20%）

街道办事处对参与达标奖励的住宅小区所在居委会、小区业委会进行满意度问卷调查（附件5），对物业企业的服务水平、工作配合情况作出评分。

（五）一票否决的情形

若存在以下情况，街道办事处应取消当次住宅小区物业服务达标奖励资格：

1.因管理失职，造成在市、区级层面通报或媒体曝光的；

2.擅自利用物业共同部位、公用设施设备进行经营，损害业主共同利益的；

3.对存在的安全隐患未能及时发现或发现后不及时上报、整改的，因管理失职发生安全事故的；

4.未及时发现、劝阻、制止、上报，造成小区违法搭建、群租现象严重，且在社会公众中产生恶劣影响的；

5.在各类创建工作中（如创建全国文明城区等）存在问题多，被扣分，导致对创建工作造成负面影响的；

6.按虹口区生活垃圾分类实效测评中半年内2次及以上列入警示名单的居住小区；

7.未按要求使用奖励资金的；

8.未配合相关部门工作并造成较严重后果的；

9.物业服务合同过期超过2年的；

10.对加装电梯征询、建设存在阻挠、扰乱行为，对接管存在畏难、消极行为的；

11.考核期内在市房管局信用记分平台项目经理被记分≥9分或物业企业在本区内被记分一次及以上的；

12.其他造成重大影响的事项。

街道办事处应当将以上具体情况在附件1中记录，不予通过申报达标奖励。区房管局可根据实际情况取消此类小区当次物业服务达标奖励资格。

（六）加分的情形

若存在以下情况，街道办事处可适当予以加分，并由区房管局记入我区物业企业诚信档案良好记录：

1.被市、区级以上媒体或相关部门通报表扬的（加2-5分）；

2.采取联合招标、小小区合并等创新管理方式并取得良好效果的（加2-5分）；

3.积极配合参与协调解决小区内重大矛盾的（加2-5分）；

4.配合相关部门工作且成效明显的（加2-5分）；

5.其他对住宅小区物业管理有明显促进作用的事项（加2分）。

街道办事处应当将上述情况在附件2中记录并上报区房管局备案。

（七）额外奖励的情形

经考核分值达到80分及以上，在考核周期内每出现以下一种情形的，一次性额外增加达标奖励0.1元/m2·月：

1.物业企业主动加大投入，提升小区环境和服务品质，取得业主认可，当次考核期前一年内完成小区“质价双提升”（以通过业主大会表决为依据且调价幅度≥0.2元/m2·月）；

2.既有多层小区加装电梯竣工后由物业企业统一接管的（5台及以下须全部接管，5台以上接管率须达85%以上）；

3.物业企业主动承担社会责任，通过“以大带小、以商带居、邻里互助”等形式,解决袖珍小区、微型小区（10000m2以下）物业管理难题，提供保洁、保修（急修2小时内到场）、保绿等服务。

佐证材料由街道审核并保存，相关情况在附件2中记录并上报区房管局备案。

六、责任分工

（一）区房管局

牵头本区住宅小区物业服务达标奖励工作，指导各街道开展考核检查；委托第三方测评机构对全区的住宅小区进行满意度测评；向区财政申请奖励资金；根据考核结果向物业企业拨付奖励资金。

（二）街道办事处

负责辖区内住宅小区物业服务达标奖励考核工作，组织协调自治办、城运中心、城建中心、居委会等部门共同落实推进；加强组织领导，成立考核工作组，安排专人负责达标奖励考核工作的具体实施；督促物业企业、小区业委会落实问题整改，提升物业水平；负责评估考核以及实施中相关信访、“12345”投诉的处理；按时向区房管局上报奖励方案；指导居委会、物业企业、小区业委会规范开展“家园微更新”，指导物业企业规范使用奖励资金。

七、工作监督

（一）物业企业、小区业委会需及时规范使用达标奖励资金。

（二）物业企业、小区业委会应在知晓获得奖励后提供“家园微更新”活动佐证材料和员工奖励资金发放计划，并由街道汇总提交奖励资金拨付申请，未完成“家园微更新”活动的视作自动放弃奖励资金。

（三）街道办事处应妥善保存住宅小区物业服务达标奖励考核工作的测评表格、照片等台账。

八、附则

本《实施意见》自2023年10月7日起施行,有效期至2028年10月6日止。
