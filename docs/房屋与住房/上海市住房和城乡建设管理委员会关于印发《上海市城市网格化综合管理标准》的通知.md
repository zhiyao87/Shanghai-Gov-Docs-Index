# 上海市住房和城乡建设管理委员会关于印发《上海市城市网格化综合管理标准》的通知

上海市住房和城乡建设管理委员会关于印发《上海市城市网格化综合管理标准》的通知

沪建城管〔2022〕433号

各有关单位：

为贯彻落实市委、市政府关于城市运行“一网统管”和加强城市管理精细化工作的要求，我委结合工作实际,对《上海市城市网格化综合管理标准（试行）》进行了修订。现将修订后的《上海市城市网格化综合管理标准》印发给你们，请按照执行。

特此通知。

2022年8月30日
