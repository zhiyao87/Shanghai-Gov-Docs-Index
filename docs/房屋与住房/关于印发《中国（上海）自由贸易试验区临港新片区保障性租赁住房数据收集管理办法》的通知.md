# 关于印发《中国（上海）自由贸易试验区临港新片区保障性租赁住房数据收集管理办法》的通知

关于印发《中国（上海）自由贸易试验区临港新片区保障性租赁住房数据收集管理办法》的通知

沪自贸临管委〔2024〕43号

管委会各部门、各有关单位:

为进一步规范临港新片区保障性租赁住房数据收集管理机制，根据《关于加快发展本市保障性租赁住房的实施意见》、《中国（上海）自由贸易试验区临港新片区公共数据管理办法》等文件精神，研究制定了《中国（上海）自由贸易试验区临港新片区保障性租赁住房数据收集管理办法》，现印发给你们，请认真贯彻落实。

中国（上海）自由贸易试验区临港新片区管理委员会

2024年5月10日

中国（上海）自由贸易试验区临港新片区保障性租赁住房数据收集管理办法

为进一步规范中国（上海）自由贸易试验区临港新片区（以下简称“临港新片区”）保障性租赁住房（以下简称“保租房”）数据收集管理机制、提升管理水平，根据《关于加快发展本市保障性租赁住房的实施意见》（沪府办〔2021〕12号）、《中国（上海）自由贸易试验区临港新片区公共数据管理办法》（沪自贸临管规范〔2024〕1号）等，制定本办法。

一、责任主体

在临港新片区住房保障工作领导小组（临港新片区保障性租赁住房工作领导小组）及其办公室（简称领导小组办公室）的统一领导下，管委会相关部门和单位协同落实有关工作。

临港新片区管委会建设和交通管理处（以下简称“建交处”）承担领导小组办公室日常工作，统筹协调保租房管理有关工作。

临港新片区管委会数据处（以下简称“数据处”）负责统筹协调临港新片区公共数据资源管理工作，指导监督保租房数据管理工作的开展。

临港新片区住房保障事务中心（以下简称“住保中心”）是保租房的管理部门，负责根据业务管理标准确定保租房数据收集的对象、内容、频率以及数据标准等，负责指导协调临港新片区保租房开发及运营企业提供基础数据，负责与管委会各业务平台数据应用需求的对接，落实保租房数据归集、统筹使用管理及数据赋能申请。

上海市临港新片区大数据中心（以下简称“大数据中心”）负责提供数据收集、存储的技术保障，为存储的保租房数据赋能与安全管理提供技术支撑。

临港新片区各类保租房运营单位、开发单位和相关单位（以下统称“数据供应单位”）负责如实、及时、规范提供相关数据。临港新片区管委会各相关部门和单位协同推进有关工作。

二、数据收集范围

临港新片区产城融合区域内经认定的保障性租赁住房（含公共租赁住房）的相关基础数据。人才公寓、代理经租等由机构或企业整体持有的租赁性住房相关基础数据参照管理。

三、数据收集要求

为实现数据的如实、及时、规范等目标，数据供应单位应确保数据达到以下要求：

1、数据（含房源全景数据）每日实时动态更新，由对应数据供应单位通过专线、公网通道或标准数据接口方式实时传输接入。对于暂时不具备接口对接传输条件的数据供应单位，初期可以按照数据报表形式等约定方式，离线传输至大数据中心数据库，每日动态更新。

2、保租房业务审批基础数据每日动态更新，各审批部门单位可进行一站式审批管理。

出现数据异常的，由住保中心责令相关数据供应单位完成数据治理和整改，整改完成后重新按照约定方式传输至大数据中心数据库。

四、数据安全要求

保租房数据安全管理应满足《中国（上海）自由贸易试验区临港新片区公共数据管理办法》（沪自贸临管规范〔2024〕1号）。相关单位安全管理职责如下：

1、按照“谁持有、谁负责，谁使用、谁负责”的原则，做好本机构数据资源的安全保密工作。

2、大数据中心对归集的数据进行统一管理并保障数据安全，指导相关单位加强在数据收集、治理、共享等过程中的身份鉴别、授权管理和数据安全保障等。

3、被赋能使用数据的单位应当在其履行法定职责的范围内依照法律、行政法规规定的条件和程序进行数据存储、加工处理等，并根据公共数据分类分级要求对敏感数据进行脱敏处理。

五、数据应用要求

保租房数据的共享、开放、授权运营活动根据沪自贸临管规范〔2024〕1号文要求开展。未经允许任何单位或人员不得私自利用保租房数据产生的相关成果申请专利、转让技术成果、申报奖励。

六、监督检查

临港新片区管委会对保租房基础数据资源目录编制、数据汇聚更新维护、共享使用情况等方面进行评估，存在问题的数据资源，责令数据供应单位整改。数据供应单位有下列情形之一的，临港新片区管委会责令其限期改正：

1、无故拒绝、拖延提供数据共享及开放的；

2、故意提供不真实、不准确、不全面的保租房数据的，未按照规定时限发布、更新数据的；

3、对获取的共享数据管理失控，致使出现滥用、非授权使用、未经许可的扩散以及泄漏的；

4、擅自将获取的数据资源用于本单位履职以外用途、擅自转让给第三方或利用共享数据资源开展经营性活动的。

保租房数据采集及使用过程中机构或个人违反法律、法规和本办法有关规定，造成国家、法人、其他机构和个人损失的，依法追究相关机构、直接责任人或主要负责人的法律责任。

七、附则

本办法自发布之日起执行，有效期至2029年3月4日。
