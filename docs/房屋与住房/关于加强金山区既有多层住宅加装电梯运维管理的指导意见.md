# 关于加强金山区既有多层住宅加装电梯运维管理的指导意见

区规划资源局、建管委、市场监管局，各街镇（金山工业区）：

为贯彻落实《关于印发<关于进一步做好本市既有多层住宅加装电梯工作的若干意见>的通知》（沪建房管联〔2019〕749号）、《关于印发<关于加强既有多层住宅加装电梯管理的指导意见>的通知》（沪精细化办联〔2021〕10号）等文件精神，进一步规范金山区既有多层住宅加装电梯运维管理，切实保障加装电梯安全平稳运行，推动加装电梯民心工程高标准、高水平、高品质实施，结合金山实际，特制定本指导意见。

一、指导思想

以习近平新时代中国特色社会主义思想为指导，坚持以人民为中心的发展理念，进一步完善制度机制，推进基层社会治理创新，着力纾解住房民生领域痛点问题，加快推进金山区既有多层住宅加装电梯工作，加强和完善加装电梯运维管理保障机制，不断增强市民群众的获得感、幸福感、安全感。

二、基本原则

（一）坚持条块结合、以块为主。在发挥区相关行业主管部门指导、审批、监管等工作职能的同时，各属地政府坚持和加强对加装电梯工作的领导，突出居委会社区治理牵头统筹作用，积极搭建社区协商平台，组织业主民主协商，分级负责，凝聚各方合力，为提升加装电梯管理水平提供坚强有力的组织保障。

（二）坚持业主主体、共同协商。充分尊重加装电梯业主的意愿，发挥业主的主体地位作用，根据各加装电梯项目的实际情况，科学谋划、民主协商、突出重点、分类施策，促成共识达成，推动加装电梯“共建、共治、共享”。

（三）坚持行业指导、专业管理。充分发挥区规划资源局、区市场监管局、区建管委、区房管局等相关职能部门专业优势，调动物业服务企业、电梯专业维保单位、保险公司等第三方的专业管理能力，为加装电梯管理工作提供安全、可靠、便捷、经济的政策支持、行业指导和专业服务。

（四）坚持因地制宜、循序渐进。科学把握各住宅小区资源禀赋和自然环境条件等，按照“一楼一策”原则制定加梯运维方案，循序渐进推动各方主体参与加装电梯运维管理，持续完善保障机制。

三、管理内容

（一）加装电梯管理相关概念

1.加装电梯所有权人

既有多层住宅加装电梯的所有权人为本门号（即加梯门栋）全体出资业主。若房屋所有权发生变更，变更后的房屋所有权人承继为电梯的所有权人。经加装电梯门号所有业主同意，可由小区业主委会代表有关业主行使加装电梯所有权人的职责。

2.加装电梯管理

既有多层住宅加装电梯的运维管理分为两部分，包括电梯使用管理和因加装电梯新增的围护结构、附属设施设备的管理（以下简称“新增设施设备管理”）。

3.加装电梯管理单位

加装电梯所有权人可以落实电梯使用管理单位和新增设施设备管理单位，代为履行管理责任。

加装电梯出资人前期与代建单位签订代建协议的同时，应在居委会和代建单位的协调指导下，综合考虑后期运维的管理便捷性、服务专业性、合同稳定性和资金安全性等因素，经民主协商后，与相关加装电梯管理单位签订加装电梯委托管理协议，并对服务事项、内容、标准以及收费事项、收费标准等相关内容予以约定。

（二）加装电梯使用管理

1.电梯使用管理单位的确定

加装电梯所有权人所在小区有物业服务企业的，本小区物业服务企业应当主动接受加装电梯所有权人的委托，提供加装电梯使用管理服务；加装电梯所有权人所在小区为自治管理的，可委托有电梯使用管理经验的第三方机构提供服务。电梯使用管理单位确定后，需签订单独的管理协议。

2.电梯使用管理单位的职责

加装电梯使用管理单位应按照国家和本市电梯使用管理相关法律、法规和安全技术规范的规定，积极履行职责，并做好电梯轿厢保洁和电梯轿厢内照明、风扇等设备的维修工作；建立使用管理制度、配备使用管理人员，承诺履行电梯使用管理的相关职责和义务，并签署《金山区加装电梯使用管理单位承诺书》(详见附件)。

（三）新增设施设备管理

1.新增设施设备管理单位的确定

加装电梯所有权人应当委托本小区物业服务企业管理新增设施设备，小区为自治管理的应当委托已确定的电梯管理使用单位代为管理，管理维护费用可另行约定。

2.新增设施设备管理单位的职责

（1）新增设施设备管理单位应当按照相关约定，做好电梯厅窗户、照明、地砖以及与房屋主体间的连接结构等部位的日常保洁、维护保养等工作。

（2）新增设施设备管理单位应落实专业人员定期对电梯相关围护结构、附属设施设备进行定期安全巡视，如实记录巡视时间、检查人员、隐患发生位置、隐患情况和处置结果等。

（3）新增设施设备管理单位发现新增设施设备存在安全隐患的，要及时采取设置警戒线等应急措施，并书面告知加装电梯所有权人和业主委员会，情况严重的应当同时报告属地政府（街道、工业区）。加装电梯所有权人、业主委员会以及属地政府（街道、工业区）接到通知或报告后，按照《上海市房屋使用安全管理办法》等相关规定予以处置。

（四）加装电梯管理经费的筹集和使用

1.管理经费的使用范围和承担主体

（1）使用范围：包括加装电梯日常管理、能耗、维护保养、改造、修理、检验、检测、安全评估以及委托他人管理服务或者购买相关保险等。

（2）承担主体：加装电梯管理经费由加装电梯所有权人承担。加装电梯所有权人应当按照相关协议约定的比例自行筹集加装电梯管理经费。

（3）监督指导：各街镇（金山工业区）需发挥主体监督指导职能，推动加装电梯项目所在社区居委会全程参与到加装电梯管理经费的协调管理工作，建立工作机制，指导加装电梯所有权人及其代表开展相关工作，监督管理单位等合规合法履行工作职责，协调加装电梯管理经费使用、筹集、管理等具体事项，及时处置相关矛盾问题。

2.管理经费账户的开设

（1）协商一致后，加装电梯所有权人可以委托本小区业主委员会或物业服务企业开设加装电梯管理经费账户，并按门号立账实施日常管理。物业服务企业接受委托开设并管理加装电梯管理经费账户的，要与加装电梯所有权人书面约定账户管理费用等相关事项。

（2）加装电梯所有权人也可以自行开设加装电梯管理经费账户并实施日常管理。所有权人自行开设并管理加装电梯管理经费账户的，要书面约定账户管理人，承担具体管理工作。

3.管理经费的筹集

（1）首次筹集。加装电梯所有权人需自行筹集加装电梯管理经费，并在相关协议中明确每次筹集的金额。加装电梯管理经费由所在门号加装电梯所有权人选出的代表（以下简称“加装电梯所有权人代表”）收齐后，统一存入加装电梯管理经费账户。

（2）再次筹集。当账户余额不足时，加装电梯所有权人代表要及时组织加装电梯所有权人按照约定比例进行续筹。属地政府可以协助组织加装电梯所有权人筹集落实资金。

利用在加装电梯内设置广告、商业推广等经营设施所获得的公共收益，可以按照相关约定用于补充加装电梯管理经费。

（3）相关责任。加装电梯所有权人应按照约定比例开展加装电梯管理经费首次筹集和余额不足后的再次筹集。因未按时续筹经费导致电梯无法正常运行等后果，由加装电梯所有权人自行承担。各所有权人不得以房屋出租、长期不居住和使用等原因拒绝承担交纳加装电梯管理经费。

4.管理经费的使用

加装电梯管理经费按照委托管理协议的约定或者加装电梯所有权人的决定使用。发生需使用加装电梯管理经费情形的，由加装电梯所有权人代表按照委托管理协议约定或者加装电梯所有权人的决定，在管理经费账户中提取，并支付给相关单位。

（1）委托管理费用。用于委托相关管理单位的委托管理费用，可按照委托协议的约定直接提取支付。

（2）维修费用。加装电梯所有权人需在相关协议中明确一般维修费用的授权金额。单项维修费用在授权金额以内，由被授权的相应管理单位直接组织实施维修并支取相应费用。超出授权金额的，应经加装电梯所有权人一致同意后，书面通知管理单位进行维修和支取相应费用。

（3）其他费用。加装电梯所有权人可在协议中对包括能耗费、年检费、限速器校验费、荷载实验费、保险费等情况另行约定，相关费用按实结算。

（五）其他方面

1.协议约定。

加装电梯具体方案表决通过后，加装电梯出资人在协商一致的基础上签署加装电梯协议，明确约定加装电梯的所有权归属、使用规则、管理责任和费用分摊等相关事项。加装电梯协议约定的加装电梯所有权人依法享有相关权利义务，并履行相关义务。

2.告知权利义务。

加装电梯所有权人的房屋所有权发生变更时，加装电梯的相关权利和义务由变更后的房屋所有权人承继。其中，加装电梯所有权人通过买卖、赠与等方式转移房屋所有权的，应当书面告知其他加装电梯所有权人，并在房屋买卖合同、赠与合同中明确告知受让人对加装电梯的权利和义务。加装电梯所有权人将房屋出租、出借或通过其他方式转移房屋使用权时，应当书面告知受让人对加装电梯的权利和义务。加装电梯所有权人为公有住房承租人的，公有住房承租人变更后，加装电梯的相关权利和义务由变更后的公有住房承租人承继。其中，通过差价换房等方式变更公有住房承租人的，加装电梯所有权人要书面告知其他加装电梯所有权人，并在公有住房承租权转让合同中明确告知受让人对加装电梯的权利和义务。

3.信息公开。

加装电梯所有权人代表应当按照约定期限公布加装电梯管理经费缴纳情况。账户管理人应当按照确定期限与开户银行核对加装电梯管理经费账目，并向加装电梯所有权人公告。以上所约定的期限原则上不长于半年。

4.档案管理。

加装电梯管理单位应加强对包括上海特种设备使用登记证、电梯产品出厂合格证明、电梯监督检验报告、建设工程竣工验收报告等电梯档案的管理工作，建立健全安全技术档案管理制度，认真落实日常管理记录，妥善保存相关资料。

5.违约责任。

加装电梯所有权人和委托管理单位应按照签订的委托协议履行相应的责任和义务，其中对于加装电梯所有权人未按时履行支付义务，委托管理单位在按照约定履行催告措施后仍未全额支付的，委托协议自然终止，同时委托管理单位应当书面告知业委会和居委会。

四、管理要求

（一）强化居委牵头作用

推动建立健全以居民区党组织为核心，业委会、物业服务企业、加装电梯业主共同参与的加装电梯管理机制。强化居委会在加装电梯具体工作中牵头统筹作用，全程指导参与加装电梯管理的民主协商、管理单位甄选、协议签订、经费管理、责任落实和矛盾处置等工作。按照“共建、共治、共享”的原则，发挥业主主体意愿和主观能动性，积极推动提升加装电梯社区自治共治共管活力和水平。

（二）夯实属地主体责任

各街镇（金山工业区）承担辖区内加装电梯管理的属地管理责任，建立健全加装电梯运维管理机制体制，牵头协调电梯使用单位确定工作，统筹协调日常运维、应急处置和矛盾化解等工作。落实属地城建中心、市场监管和城管执法等部门工作责任，加强指导与监督。街镇城市网格化综合管理中心等部门要将加装电梯纳入“一网统管”，加强加装电梯建成后日常巡查，及时指挥派遣处置相关问题。

（三）明确行业管理职责

加装电梯按照《上海市电梯安全管理办法》相关规定开展日常管理。区市场监管局负责对本区加装电梯安全实施监督管理，区房管局负责加强对代建单位、业主委员会的指导监督，并指导物业企业积极发挥自身优势，全程参与加装电梯；区科委、民政、监管、绿容、城管执法、应急等部门加强行业监督指导，及时响应各类投诉，处置各类违法违规及应急处置工作。水、电、通讯等公共服务单位，应加强加装电梯运维服务保障工作。

（四）推动物业服务企业全程参与

推动物业服务企业积极主动、协同配合、全程参与加装电梯工作。指导督促物业企业积极配合开展加装电梯相关政策法规宣传，协助做好意见征询和方案设计等工作，推动业主达成共识。业主共识达成。配合加梯设计和施工管理，提供房屋原始图纸材料及建筑材料和垃圾的堆放场地，做好业主停车等引导工作等。在公平合理、协商一致的基础上，主动承接加装电梯管理委托，签订和落实委托管理协议，提供加装电梯使用管理服务。

（五）凝聚社会管理力量

推动代建单位、电梯专业维修单位、保险公司等第三方充分发挥自身专业优势，积极参与到加装电梯管理工作当中。坚持为民服务工作理念，提供优质的专业服务，落实电梯使用安全责任保险100%全覆盖，探索实践电梯全生命周期管理，不断提升加装电梯运维管理能力和保障水平。
