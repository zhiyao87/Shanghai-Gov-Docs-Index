# 黄浦区人民政府关于同意确认黄浦区老西门689街坊旧城区改建项目房屋征收范围的批复

区建设管理委、区住房保障房屋管理局：

你部门《关于申请确认黄浦区老西门689街坊旧城区改建项目房屋征收范围的请示》（黄建征收【2018】33号）收悉。经研究，批复如下：

一、原则同意老西门689街坊列入我区旧城区改建范围。上述地块房屋征收范围：

东至梦花街160-162号、文庙，西至老道前街，北至梦花街，南至老道前街47号，详见附图。

二、在启动改建前，按照《上海市国有土地上房屋征收与补偿实施细则》有关规定，组织开展居民意愿征询和房屋征收补偿方案征询工作，在被征收人、房屋承租人同意旧城区改建和签订附生效条件的补偿协议达到规定比例后，方可实施改建工作。

特此批复，请抓紧组织实施。
