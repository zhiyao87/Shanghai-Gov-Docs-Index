# 关于印发《苏州河沿岸街区建筑立面整治设计要求》的通知

各有关单位：

为提升苏州河沿岸街区建筑立面的整治设计，改善苏州河沿岸街区城市风貌，增加滨水区的人文魅力与城市魅力，特编制《苏州河沿岸街区建筑立面整治设计要求》。请各区按照《苏州河沿岸街区建筑立面整治设计要求》开展苏州河沿岸街区建筑立面实施工作。

特此通知。

上海市房屋管理局

上海市“一江一河”工作领导小组办公室

2021年10月20日
