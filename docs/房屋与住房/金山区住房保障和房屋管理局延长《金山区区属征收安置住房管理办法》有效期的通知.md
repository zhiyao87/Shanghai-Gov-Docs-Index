# 金山区住房保障和房屋管理局延长《金山区区属征收安置住房管理办法》有效期的通知

各有关单位：

经评估，《金山区区属征收安置住房管理办法》（金房管规〔2021〕1号）需继续实施，有效期延长至2026年12月31日。

特此通知。

上海市金山区住房保障和房屋管理局
