# 上海市住房和城乡建设管理委员会关于印发《上海市超低能耗建筑项目第三方测评机构管理办法（试行）》的通知

上海市住房和城乡建设管理委员会关于印发《上海市超低能耗建筑项目第三方测评机构管理办法（试行）》的通知

沪建建材〔2023〕197号

各有关单位：

为规范、有序开展超低能耗建筑测评工作，根据《上海市超低能耗建筑项目管理规定（暂行）》（沪建建材〔2021〕114号），我委制定了《上海市超低能耗建筑项目第三方测评机构管理办法（试行）》。现印发给你们，请遵照执行。

2023年4月14日
