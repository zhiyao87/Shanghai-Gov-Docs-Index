# 关于发布《道路人行天桥加装电梯导则（试行）》的通知

各相关单位：

为深化道路人行天桥电梯精细化管理要求，规范道路人行天桥电梯加装工作，根据《无障碍设计规范》《上海市无障碍环境建设与管理办法》等现行规范、标准，特制定《道路人行天桥加装电梯导则（试行）》，现予印发，请遵照执行。

特此通知。

市交通委

市道路运输局

二○二一年七月十五日
