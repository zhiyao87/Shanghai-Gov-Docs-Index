# 浦东新区人民政府关于延长《浦东新区国有土地上非居住房屋按期搬迁奖励费标准》有效期的通知

区政府各委、办、局，各管理局(管委会)，各直属企业，各街道办事处、镇政府：

经评估，2014年5月浦东新区人民政府印发的《浦东新区国有土地上非居住房屋按期搬迁奖励费标准》(浦府〔2014〕90号)需继续实施，有效期延长至2029年5月19日。

特此通知。

2024年5月17日
