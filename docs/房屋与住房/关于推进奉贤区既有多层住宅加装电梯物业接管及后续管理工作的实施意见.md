# 关于推进奉贤区既有多层住宅加装电梯物业接管及后续管理工作的实施意见

各街镇(开发区)、物业服务企业，各相关单位：

为确保奉贤区既有多层住宅加装电梯安全运行，进一步明确物业接管及后续管理相关事项和要求，健全建后管理工作机制，根据《关于加强既有多层住宅加装电梯管理的指导意见》(沪精细化办联〔2021〕10号)、《关于落实既有多层住宅加装电梯使用管理责任的指导意见》(沪精细化办〔2024〕1号)等文件精神，现就推进奉贤区既有多层住宅加装电梯物业接管及后续管理工作制定实施意见如下：

一、工作目标

有序推进奉贤区既有多层住宅加装电梯物业接管工作，有效防范加装电梯“有人建、无人管”的问题，保障加装电梯安全健康运行，形成既有多层住宅加装电梯建后管理的长效机制。

二、工作对象

本意见中既有多层住宅加装电梯(以下简称加装电梯)物业接管及后续管理工作的对象包括：

1、即将推进签约的加装电梯;

2、已完成签约但尚未交付使用的加装电梯;

3、已交付使用但物业服务企业尚未接管的加装电梯;

4、已由物业服务企业接管的加装电梯可参照本意见中的相关条款执行。

三、物业服务企业职责

1、积极配合开展既有多层住宅加装电梯相关政策法规宣传，协助做好资料收集、方案制订、意见征询等工作，并根据小区地形地貌、道路、绿化、停车位配置、管线位置等实际情况，对加装电梯品牌、型号、建筑设计方案等提供专业建议，协助推动业主就加装电梯相关事宜达成共识。

2、积极配合提供房屋原始竣工图纸和建筑材料、建筑垃圾堆放场地。相关场地需占用小区道路或者机动车停车位的，要做好道路交通和机动车停放引导工作。配合施工单位做好现场管理，维护施工现场秩序。

3、主动承接加装电梯所有权人的委托，提供加装电梯使用管理服务，在公平合理、协商一致的基础上与加装电梯所有权人签订书面加装电梯委托管理协议，明确约定服务事项、服务内容、服务标准、收费事项和收费标准等具体内容。

4、物业服务企业要安排专人负责电梯紧急报警装置监控室端接警的托底保障工作，并配合加装电梯所有权人做好相关排险维修工作。加装电梯所有权人委托除物业服务外的维护保养单位或者专业公司等其他市场主体管理电梯的，物业服务企业可以接受相关单位的委托负责电梯紧急报警装置监控室端接警的托底保障工作，并收取相关费用。

四、相关主体职责

1、加装电梯所有权人。在加装电梯前期征询阶段，应就电梯后续管理的经费筹集、管理使用、账户设立等进行充分酝酿，并在后续管理方案中进行约定。鼓励加装电梯所有权人预存部分资金至电梯后续管理资金账户。加装电梯签约同时，加装电梯所有权人应当委托物业服务企业(或其他专业单位)作为加装电梯使用管理单位，履行电梯设备及新增维护结构、附属设施设备的管理责任。

2、属地街镇(开发区)。属地街镇要指导、督促居委会、业委会深入开展群众工作，加大加装电梯后续管理的宣传力度，提高群众加装电梯安全管理和安全使用意识。对尚在免费维保期内以及超过免费维保期的加装电梯项目分类制定物业接管实施方案和具体计划。对于即将推进签约的加梯项目，后续管理方案与加装电梯前期征询同步开展，明确加装电梯使用管理单位，协商相关服务内容、服务标准、收费方式、收费标准、管理经费分摊、筹集及使用管理规则等后续管理事宜。对业主与物业服务企业接管价格无法协商一致的情况，指导物业服务企业首年以基础指导价接管试行。试行一年后，根据管理情况及实际管理成本调整接管费用，首年差额部分可在第二年调整价格时补足或其他适当形式补足，并在委托合同签订时予以明确。

3、区市场监管局。在综合竣工验收环节配合落实对加装电梯使用安全管理的指导，并加强对投入使用后的加装电梯和使用管理的安全监督管理;加强电梯安全宣传教育，增强社会公众的安全意识和自我保护能力。

4、区房管局。将住宅物业服务企业对小区加装电梯的接管情况将纳入红黑榜考核范畴。在加装电梯的住宅小区开展招投标工作中，指导将物业企业接管加装电梯业绩纳入招投标管理评价范围。对于原物业服务企业已接管加装电梯的小区，在更换物业时，会同属地街镇引导业委会在招标文件中注明，投标企业对原有的加装电梯及新增电梯需履行管理职责。中标企业须按招标要求制定接管方案，接管小区加装电梯，加强指导、监督和协调，帮助推进既有多层住宅加装电梯接管工作。

5、代建单位。代建单位在推介宣传加装电梯时，应当将电梯加装完成后的后续管理方案(包括：使用管理主体、使用管理费用、维护、保养、更新、修理方案。)等一并向意向加梯的业主全面充分提示。加装电梯征询时，代建单位要引导居民与物业服务企业商讨加梯后车位、绿化影响情况，并就现场施工、后续管理、隐蔽工程(包括桩基施工、基坑防水、雨污管道迁改等)等方面征求物业服务企业意见建议，优化加梯方案。加装电梯完成综合竣工验收后，代建单位要促成业主和物业服务企业(或其他专业单位)达成接管协议，未达成协议不得投入使用。对于电梯尚未签约的，要在与业主正式签订加装电梯工程代建合同时，将电梯作为特种设备后续管理的主要内容、日常管理和维保可能需要的费用构成、电梯使用管理单位的选择等问题进行书面提示，为加装电梯完工后的后续接管奠定基础。
