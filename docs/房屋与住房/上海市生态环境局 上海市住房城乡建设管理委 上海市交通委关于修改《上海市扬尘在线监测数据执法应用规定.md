# 上海市生态环境局 上海市住房城乡建设管理委 上海市交通委关于修改《上海市扬尘在线监测数据执法应用规定》的通知

各有关单位：

现决定对《上海市扬尘在线监测数据执法应用规定》作如下修改：

1.将第一条、第五条中的“《中华人民共和国大气污染防治法》”修改为“《中华人民共和国生态环境法典》”。

本通知自2026年8月28日起施行，有效期至2029年3月14日。《上海市扬尘在线监测数据执法应用规定》根据本通知作相应文字调整后，重新发布。
