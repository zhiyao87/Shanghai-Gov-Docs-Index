# 上海市住房和城乡建设管理委员会关于批准《太阳能热水系统应用图集》为上海市建筑标准设计的通知

上海市住房和城乡建设管理委员会关于批准《太阳能热水系统应用图集》为上海市建筑标准设计的通知

沪建标定〔2024〕245号

各有关单位：

由华东建筑集团股份有限公司主编的《太阳能热水系统应用图集》，经我委审核，现批准为上海市建筑标准设计，统一编号为DBJT08-110-2024，图集号为2024沪S101，自2024年11月1日起实施，原《太阳能热水系统应用图集》DBJT 08-110-2016同时废止。

本标准设计由上海市住房和城乡建设管理委员会负责管理，华东建筑集团股份有限公司负责解释。

特此通知。

2024年5月21日
