# 上海市房屋管理局关于延长《〈上海市新建住宅交付使用许可规定〉实施细则》有效期的通知

上海市房屋管理局关于延长《〈上海市新建住宅交付使用许可规定〉实施细则》有效期的通知

沪房规范〔2023〕7号

各有关单位：

经评估，2018年10月1日起施行的上海市房屋管理局印发的《〈上海市新建住宅交付使用许可规定〉实施细则》（沪房建管〔2018〕102号）需继续实施，有效期延长至2028年9月30日。

特此通知。

2023年9月28日
