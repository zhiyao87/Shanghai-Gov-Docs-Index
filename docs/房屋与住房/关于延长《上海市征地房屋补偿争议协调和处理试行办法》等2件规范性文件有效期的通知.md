# 关于延长《上海市征地房屋补偿争议协调和处理试行办法》等2件规范性文件有效期的通知

局机关各处室、局属各单位、各区规划资源局、各派出机构:
经评估，《上海市征地房屋补偿争议协调和处理试行办法》（沪规土资规〔2017〕1号）、《关于贯彻实施〈上海市征收集体土地房屋补偿暂行规定〉的若干意见》（沪规土资规〔2017〕2号）需继续实施，有效期延长至2021年9月30日。
上海市规划和自然资源局
2019年9月25日
