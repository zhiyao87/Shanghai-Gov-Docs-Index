# 黄浦区人民政府关于同意确认132街坊北块旧城区改建项目房屋征收范围的批复

区建设交通委、区住房保障房屋管理局：

你部门《关于申请确认132街坊北块旧城区改建项目房屋征收范围的请示》（黄建交〔2014〕55号）收悉。经研究，批复如下：

一、原则同意132街坊北块列入我区旧城区改建范围。上述地块房屋征收范围：西藏南路276～296号（包括292弄1～19号）；寿宁路69弄1～6号、71弄7～13号、73弄过街楼；柳林路109～123号、127～129号。

二、在启动改建前，按照《上海市国有土地上房屋征收与补偿实施细则》有关规定，组织开展居民意愿征询和房屋征收补偿方案征询工作，在被征收人、房屋承租人同意旧城区改建和签订附生效条件的补偿协议达到规定比例后，方可实施改建工作。

特此批复，请抓紧组织实施。

上海市黄浦区人民政府

2014年4月23日
