# 上海市住房和城乡建设管理委员会关于批准《光纤到户工程设计安装图集》为上海市建筑标准设计的通知

上海市住房和城乡建设管理委员会关于批准《光纤到户工程设计安装图集》为上海市建筑标准设计的通知

沪建标定〔2021〕792号

各有关单位：

由上海邮电设计咨询研究院有限公司主编的《光纤到户工程设计安装图集》，经审核，现批准为上海市建筑标准设计，统一编号为DBJT08-134-2021，图集号为2021沪D601，自2022年5月1日起实施。

本标准设计由上海市住房和城乡建设管理委员会负责管理，上海邮电设计咨询研究院有限公司负责解释。

特此通知。

2021年12月2日
