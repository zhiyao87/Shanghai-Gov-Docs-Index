# 关于印发《东明路街道老旧住宅小区物业达标补贴实施办法》的通知

相关物业、居委及相关职能部门：

根据浦东新区建设和交通委员会及浦东新区财政局联合下发的《关于印发<浦东新区老旧住宅小区物业服务补贴达标考核奖励实施意见>的通知》（浦建委物管〔2023〕2号）精神，现结合街道老旧住宅小区实际情况，对街道2020年10月1日施行的《东明路街道老旧住宅小区物业达标补贴实施办法》进行修订。

上海市浦东新区人民政府东明路街道办事处

2023年2月24日

浦东新区人民政府东明路街道党政办公室

2023年3月15日印发

东明路街道老旧住宅小区物业达标补贴实施办法

为深入推进“美丽家园”建设，进一步提高本辖区老旧住宅小区物业服务规范化水平，提升人民群众的居住满意度，加快构建基本保障、应急托底、奖惩激励、优胜劣汰的老旧住宅小区管理格局，根据《上海市住宅物业管理规定》、《关于加强本市住宅小区综合治理工作的意见》和《浦东新区深化建设新时代“美丽家园”三年行动计划 (2021-2023 年)》，结合辖区老旧住宅小区实际情况和管理现状，制定本实施办法。

一、补贴对象

辖区内老旧住宅小区物业服务企业。

二、补贴标准

（一）基本标准

老旧小区物业达标补贴基本标准为0.25元/平方米.月。本辖区实行“差别化”补贴制度，根据考核结果确定考核等级以及各物业服务企业的补贴额度，并按季度拨付。

（二）“差别化”补贴标准

1、考核等级为优秀：考核分值为86分（包含86分）至100分为优秀，按照补贴基本标准的100%拨付。其中分值为86分及以上并在本辖区季度总排名前三的小区（不重复计算），按照补贴基本标准的120%拨付。

2、考核等级为达标：考核分值为71分（包含71分）至86分（不含86分）为达标，按照补贴基本标准的100%拨付。

3、考核等级为基本达标：考核分值为60分（包含60分）至71分（不含71分）为基本达标，按照补贴基本标准的80%拨付。

4、考核等级为不达标：考核分值为60分以下为不达标，不予补贴。

（三）综合评定

1、老旧住宅小区中发生严重安全事故、造成社会严重负面影响、群体性不稳定事件且属物业服务企业处置不当的，实施一票否决制，扣除当季度全部补贴。

2、单一季度内生活垃圾分类工作每月检查分数评定均为不达标等级的住宅小区，扣除当季度全部补贴，由建管中心向物业服务企业发放整改通知书，并予以记分处理。

3、对于符合下列全部条件且经浦东新区物业管理服务中心考核评定为优秀的住宅小区项目，可根据《关于印发<浦东新区老旧住宅小区物业服务补贴达标考核奖励实施意见>》(浦建委物管〔2023〕2号)有关规定，向浦东新区物业管理服务中心申请3万元专项奖励资金。

(1) 在浦东新区老旧住宅小区实效测评和满意度测评中年度排名前100名；

(2) 12345市民热线物业管理类投诉量低于5件；

(3) 专项审计意见无问题。

三、考核标准

以提供保障型的物业管理服务为基本原则，物业服务企业提供的物业管理服务须达到以下标准：

1、履行物业管理服务合同的约定；

2、符合国家和本市规定的相关技术标准、服务规范；

3、及时向业主、使用人告知安全合理使用物业的注意事项；

4、定期听取业主的意见和建议，改进和完善服务；

5、配合居民委员会做好社区管理相关工作；

6、符合《浦东新区老旧住宅小区物业服务达标基本标准》或 《上海市住宅物业管理服务规范》(DB31/T000-2018) 基本规范和一级服务规范。

物业服务达标基本标准按合理、必须、基本的原则。上述标准中，合同约定的部分项目服务标准高于其他规范标准的，按合同约定的标准执行。

四、考核方式

为确保考核工作的公平、公正，并能够全面、客观、真实地反映老旧住宅小区物业管理现状，考核工作实行定量测评，以百分制进行打分。考核由建管中心测评、居民区测评、管理办（分减办）测评、各职能部门测评等组成。测评分值按各单位和部门权重加权形成考核分值，其中建管中心测评占比50%，居民区测评占比15%，管理办（分减办）测评占比10%，文明办、平安办(派出所)、城管中队、城运中心、应急中心相关职能部门测评各占比5%，并据此核定考核等级，作为物业达标补贴拨付依据。

1、建管中心测评

建管中心测评汇总表分为以下四个部分：

（1）根据《东明路街道住宅小区物业考核表》及专项检查的情况，通过明访和暗访的方式相结合，对各住宅小区每季度进行测评，占比15%；

（2）结合各类工单热线（如12345、962121、网格平台等）情况汇总表，根据物业管理类投诉内容对各个住宅小区进行打分，占比15%；

（3）各项重点工作完成情况及其他突发事件处置情况，占比15%；

（4）物业经理每日巡查、物业公司双周查完成情况，占比5%。

2、居民区测评

（1）居民区结合住宅小区综合管理联席会议制度组织两委委员、业委会、业主代表等（人数不少于20人，其中业主代表比例不低于10人）根据居民区测评表对住宅小区物业管理综合情况每季度进行一次测评，测评前组织测评人员召开会议，评议物业管理工作季度情况，占比10%；

（2）由街道工作人员随机在小区内抽取10位居民开展测评，占比5%。

3、管理办（分减办）测评

由管理办（分减办）根据住宅小区环境质量、垃圾分类实效等内容，每季度对各老旧住宅小区市容状况和生活垃圾分类工作进行测评，占比10%。

4、职能部门测评

文明办、平安办(派出所)、综合执法队、城运中心、应急管理中心等相关职能部门根据根据各自职责每季度对老旧住宅小区进行一次测评，测评分值各占比 5%，总占比25%。

五、监督管理

1、由社区管理办会同建管中心组织各居民区、物业服务企业不定期开展培训，提高综合管理和服务能力。

2、结合街道住宅小区综合管理联席会议制度，每季度召开一次老旧住宅小区物业达标补贴工作例会，对上一阶段考核工作进行总结分析，并统筹安排、指导开展具体工作。

3、建立每月一次的监督检查制度，深入各老旧住宅小区和居民区指导监督测评工作，考核情况必须有两人以上签名，确保考核真实性、客观性。

4、各物业服务企业要结合所管理小区实际，突出重点服务管理，做到工作有方案、现场有照片、汇总有依据，做到注重实绩、 各方受益，以“利于生活，便于生活，公平合理”为主旨，全面提升业主对物业管理服务工作的满意度。

六、其他

1、本办法自2023年5月1日起实施，2028年4月30日失效，本办法实施后，原浦东明规〔2020〕1号文失效。

2、2022年7月1日至2023年4月30日前的物业达标补贴，参照本办法执行。
