# 关于印发《中国（上海）自由贸易试验区临港新片区高品质住宅物业服务管控大纲（试行）》的通知

关于印发《中国（上海）自由贸易试验区临港新片区高品质住宅物业服务管控大纲（试行）》的通知

沪自贸临管委〔2022〕22号

管委会各部门、各直属单位，临港新片区各镇、各开发公司、各有关单位:

为贯彻落实“人民城市人民建，人民城市为人民”重要理念，将临港新片区建设成为宜业宜居的独立综合性节点滨海城市，临港新片区管委会组织编制了《中国（上海）自由贸易试验区临港新片区高品质住宅物业服务管控大纲（试行）》，现印发给你们，请认真贯彻落实“运营定管理，管理定建设”工作要求，着力打造符合现代人群生活需求的高品质物业服务。

特此通知。

中国（上海）自由贸易试验区临港新片区管理委员会

2022年1月29日
