# 关于延长《金山区农民平移集中居住用地补偿指导意见》有效期的通知

各镇政府、高新区管委会：

经评估，2019年12月20日印发的《金山区农民平移集中居住用地补偿指导意见》(金农规〔2019〕2号)需继续实施，有效期延长至2029年12月17日。特此通知。

上海市金山区农业农村委员会

2024年12月13日
