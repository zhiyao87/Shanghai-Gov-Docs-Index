# 上海市生态环境局 上海市规划和自然资源局关于成立上海市建设用地土壤污染责任人认定委员会的通知

各有关单位：
根据《上海市生态环境局 上海市规划和自然资源局关于印发〈上海市建设用地土壤污染责任人认定实施办法（试行）〉的通知》（沪环规〔2022〕8号）要求，现成立上海市建设用地土壤污染责任人认定委员会（以下简称“认定委员会”），有关事项通知如下：
一、认定委员会职责
认定委员会负责对上海化工区和跨行政区的建设用地土壤污染责任人认定的有关第三方调查机构或调查组出具的调查报告进行审查，并按规定出具审查意见。认定委员会成员不得与被审查的土壤污染责任人调查工作存在利益关系。
二、组成人员
主 任 委 员：
罗海林  市生态环境局副局长
王训国  市规划资源局副局长
工作组负责人：
任菊萍  市生态环境局土壤处处长
专职工作人员：
何  赟  市生态环境局土壤处副处长
胡  进  市规划资源局用途实施处副处长
赵  方  市生态环境局土壤处
王  胤  市规划资源局用途实施处
专  家  组：
根据地块属性从建设用地土壤环境保护领域专家库选取5名评审专家
认定委员成员如有变动，由现履职人员自行替补，不再另行发文。
