# 上海市崇明区人民政府关于印发崇明区2020年违法用地综合整治行动实施方案的通知

各乡、镇人民政府，区政府有关委、局，区有关直属单位，在崇市属有关部门：

《崇明区2020年违法用地综合整治行动实施方案》已经区政府同意，现印发给你们，请认真按照执行。

2020年4月24日

崇明区2020年违法用地综合整治行动实施方案

为进一步贯彻落实《崇明区违法用地综合整治三年行动工作方案（2018-2020年）》（沪崇府办发〔2018〕18号）以及市规划资源局《关于开展本市2020年违法用地综合整治行动的通知》（沪规划资源执〔2020〕70号）精神，全面推进落实违法用地综合整治目标，严格落实耕地保护和“四线”管控工作要求，结合本区当前土地执法工作实际，制定崇明区2020年违法用地综合整治行动实施方案。

一、总体目标

按照规划资源管理工作“严起来”的要求，在切实做好新型冠状病毒感染肺炎疫情防控工作的同时，认真履行属地化土地管理职责，加大违法违规用地整治力度，严格落实国土空间四线管控和用途管制，实现对耕地特别是永久基本农田的特殊保护，全力推进土地监管制度化、常态化，进一步巩固崇明生态岛规划土地监管工作的严肃性与有序性。

二、整治内容

（一）专项任务

1.设施农业疑似违法项目：第三次全国国土调查发现无备案的设施农业用地疑似违法项目，全区共计1534件、面积2489.71亩。

2.督察违法项目：2019年国家自然资源督察发现违法用地，本区共计4件、面积2422.62亩。

3.卫片违法项目：2019年度自然资源部“季度+年度”卫片执法检查发现违法用地，具体以正式上报部卫片执法数据为准。

4.永久基本农田调整补划涉及违法项目：各乡镇人民政府、各相关部门要将调整补划方案范围内的永久基本农田地块作为监管的重点内容，自行梳理其他区域永久基本农田调整补划涉及违法用地项目，补充上报并列入2020年度整治计划，依法依规及时启动查处，坚决予以整改消除。

（二）综合整治新三年行动结转任务量

1.经营性违法项目：本区新三年行动剩余存量工矿仓储等经营性违法用地，共计13件、面积33.01亩。

2.设施农业违法项目：本区新三年行动尚未整改消除的设施农业用地违法项目，共计1件、面积0.19亩。

3.公益性违法项目：本区新三年行动剩余各类公益性违法用地，剔除农民宅基地项目后共计71件、面积137.44亩。

三、整治要求

（一）设施农业违法项目：按照《自然资源部农业农村部关于设施农业用地管理有关问题的通知》（自然资规〔2019〕4号）以及本市《关于建立常态长效监管机制防止“大棚房”问题反弹的通知》（沪农委〔2019〕343号），由乡镇人民政府拟定整治方案，经区农业农村委、区规划资源局共同核定，于2020年10月30日前依法依规落实分类处置，对符合设施农业用地备案规定的项目抓紧落实备案；不符合备案条件的项目列入拆除计划予以整治。

（二）国家督察、卫片检查违法项目：对国家自然资源督察和卫片执法检查发现违法用地，要严格按照相关规定的标准、时限和要求落实整改。

（三）经营性违法项目：对经营性违法用地项目，应落实行政处罚以及“两告知”和“两责停”相关执法规定，按照“以拆为主”的原则予以打击和拆除。其中，符合国土空间规划、计划补办手续的项目，于2020年6月20日前征询区发展改革委、区经委等部门意见，经认定符合产业结构调整等情况的，加快规划、用地手续办理。

（四）公益性违法项目：各区要加快公益性违法项目的分类处置，对符合国土空间规划的项目，应按照乡村振兴相关政策要求，会同区农业农村委等部门，年内抓紧完成用地手续的补办；对不符合公益项目保留条件的，特别是不符合“四线”管控要求的，要坚决予以拆除，恢复土地原状。

四、保障措施

（一）提高思想认识，抓好统筹协调

2020年是违法用地综合整治行动新三年行动的收官之年，各乡镇人民政府、各相关部门要进一步提高思想认识，周密制定整治计划，及早启动违法用地整治整改工作。在整治过程中，要定期统计工作进展，梳理工作动态，分析整治形势，总结经验做法，查摆存在问题。各属地乡镇、单位于每月20日前报送月度工作统计表，每季度最后一月20日前报送季度工作情况报告。

（二）落实共同责任，合力推进整治

要积极落实土地监管共同责任，综合施策，推进年度整治任务有计划、有步骤落实到位。一是强化部门协同，加强属地乡镇与区规划资源局、区农业农村委、区城管执法局、区生态环境局、区绿化市容局等部门的协调联动，联合做好对违法行为的执法检查、案件移送、征信公开以及对地方政府的责任追究、奖励惩戒等工作。二是加强工作统筹，借助违建别墅问题清查整治专项行动、“大棚房”问题专项清理整治行动等工作形成的高压态势，结合无违建先进村居（乡镇）复评、美丽乡村示范村创建、高尔夫球场常态化监管、国家自然资源督察、部卫片执法检查等工作，压实属地政府土地管理主体责任。

（三）严格检查督办，扎实推进整改

区规划资源局要严格开展督办工作，对整治任务实行“一地一档”销项式管理，定期开展实地核查，确保违法用地整治到位、符合标准；要坚持落实月度统计分析通报、排名制度，及时报告区政府并抄送各乡镇人民政府及各相关部门。

开展违法用地综合整治新三年行动，是切实保护耕地、严格落实《崇明世界级生态岛发展“十三五”规划》，积极推进长江经济带生态发展战略、改善营商环境的重要举措。各乡镇人民政府、各相关部门要切实加强组织领导，筑牢树立底线意识，发扬锲而不舍的“钉子”精神，严格落实城市精细化管理要求，坚决将违法用地综合整治工作落到实处，以更高标准、更扎实举措保障崇明世界级生态岛建设。
