# 关于印发《上海市测绘地理信息、地质矿产、地名、城建档案行政处罚裁量基准实施办法》的通知

各区规划资源局、各有关单位:

《上海市测绘地理信息、地质矿产、地名、城建档案行政处罚裁量基准实施办法》已经2022年1月25日局长办公会议审议通过，现予印发，请遵照执行。

本办法自2022年3月1日起施行，有效期至2027年2月28日。《上海市测绘地理信息行政处罚裁量基准实施办法》（沪规土资测规〔2017〕197号）、《上海市地质矿产行政处罚裁量基准实施办法》（沪规土资矿规〔2017〕181号）、《上海市地名管理行政处罚裁量基准实施办法》（沪地办〔2017〕32号）、《上海市城建档案管理行政处罚裁量基准实施办法》（沪规土资科规〔2017〕176号）同时废止。

上海市规划和自然资源局

2022年2月21日

上海市测绘地理信息、地质矿产、地名、城建档案行政处罚裁量基准实施办法

第一条  为规范本市测绘地理信息、地质矿产、地名、城建档案行政执法行为，确保行政处罚合理、适当，根据《中华人民共和国行政处罚法》《中华人民共和国测绘法》《中华人民共和国矿产资源法》以及《上海市城乡规划条例》《上海市地名管理条例》等法律、法规，制定本办法。

第二条  本办法所称的测绘地理信息、地质矿产、地名、城建档案行政处罚裁量基准，是指本市具有测绘地理信息、地质矿产、地名、城建档案行政处罚权的部门（以下简称各执法部门）依职权对法定处罚事项进行裁量时，依据的量罚标准及其适用规则。

第三条  各执法部门行使测绘地理信息、地质矿产、地名、城建档案行政处罚裁量权，适用本办法。

第四条  测绘地理信息、地质矿产、地名、城建档案行政处罚裁量基准，由本办法及附件《上海市测绘地理信息、地质矿产、地名、城建档案行政处罚裁量基准表》（以下简称《基准表》）予以规定。

第五条  行使行政处罚裁量权，应当按照违法行为的种类及违法情形，对照《基准表》确定相应的量罚标准。

第六条  对违法行为适用从轻处罚的，应当符合《中华人民共和国行政处罚法》规定的从轻处罚情形。

第七条  违法行为有下列情形之一的，应当从重处罚：

（一）危及国家安全、公共安全、公众健康或者生态环境，造成严重后果的；

（二）严重损害群众利益，造成重大社会影响的；

（三）隐匿、销毁、伪造、篡改违法行为证据，虚假陈述的；

（四）对举报人、证人打击报复或者妨碍执法人员查处违法行为的；

（五）法律、法规、规章规定的应当从重处罚的其他情形。

第八条  有下列情形之一的，各执法部门应当按照符合法律目的和过罚相当的原则，通过集体讨论决定量罚标准和具体处罚尺度，经部门负责人批准后实施：

（一）遇有《基准表》未规定的违法情形，足以影响裁量基准适用的；

（二）对未列入《基准表》的其他违法行为实施行政处罚，按照法律、法规、规章的规定需要进行裁量的。

集体讨论应当制作书面记录，说明确定量罚标准和具体处罚尺度的理由，并纳入行政处罚案件卷宗。

第九条  违法行为符合《中华人民共和国行政处罚法》规定的不予行政处罚情形的，依法不予行政处罚。

对当事人的违法行为依法不予行政处罚的，应当对当事人进行教育。

第十条  各执法部门遵守本办法及《基准表》的情况，应当纳入本市规划和自然资源行政处罚案卷评查范围。
