# 关于崇明区三星镇市级土地整治项目（二期）规划设计优化调整的批复

关于崇明区三星镇市级土地整治项目（二期）规划设计优化调整的批复
沪规划资源施〔2023〕416号
上海市建设用地和土地整理事务中心:
你中心《关于崇明区三星镇市级土地整治项目(二期)规划设计优化调整的请示》（沪地整〔2023〕20号）及相关附件收悉。经审核，现将有关事项批复如下：
一、根据《关于上海市崇明区三星镇市级土地整治项目(二期)规划设计和预算的批复》（沪规划资源施〔2020〕461号），该项目总面积405.85公顷，总投资11302.67万元，
二、根据项目区实际情况，你中心对原规划设计和预算进行了调整。经审核，原则同意你中心上报的《崇明区三星镇市级土地整治项目（二期）规划设计优化调整报告》中对原规划设计方案进行的局部优化调整，总投资相应调整为11160.81万元，共核减141.86万元。
三、请你中心按照国家和本市土地整治项目管理有关规定，认真做好项目后续工作。
上海市规划和自然资源局
2023年11月1日
