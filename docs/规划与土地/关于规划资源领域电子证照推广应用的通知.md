# 关于规划资源领域电子证照推广应用的通知

关于规划资源领域电子证照推广应用的通知
沪规划资源信〔2021〕425号
局机关各处室，局属各单位，各区规划资源局，各派出机构，市、区自然资源确权登记事务中心:
电子证照是“一网通办”平台的重要组成，是推进城市数字化转型的基础工具。根据《上海市人民代表大会常务委员会关于进一步促进和保障“一网通办”改革的决定》要求，为推进本市规划资源行业电子证照的推广应用，加快推动本市规划资源行业数字化转型，促进规划资源服务更加便民、便企，现就本市规划资源行业电子证照推广应用有关事项通知如下：
1.启用本市规划资源行业相关电子证照。目前，本市政府核发的规划资源行业电子证照包括建设用地规划土地意见书、建设用地规划许可证、建设工程设计方案批复、不动产权证等26项（见附件），相应电子证照可以通过市大数据中心电子证照库或“一网通办”外网PC端查看使用。
2.在规划资源服务领域普及“不带实体证”。在本市规划资源公共服务领域内，加快推广应用相关电子证照。政务服务“一网通办”过程中，优先通过市电子证照库获取业务办理所需电子证照，电子证照符合办理条件的，用证单位不得要求办事人提供实体证照。具体市级电子证照制发证清单可通过“一网通办”总门户查询（https://zwdt.sh.hov.cn/zwdtSW/certificationList/index.jsp）。
3.强化异议数据反馈。使用电子证照过程中，对证照数据有异议的，应积极向市规划和自然资源局或本级大数据中心反馈，促进有误证照数据及时更正，保障电子证照数据质量不断提升。
4.加大宣传推广力度。充分利用微信公众号、服务窗口等线上线下渠道，加大电子证照应用宣传推广力度。对规划资源行业内已形成的电子证照应用场景加大宣传，营造全民使用电子证照的良好氛围。
