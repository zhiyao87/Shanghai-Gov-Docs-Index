# 关于延长《关于本市耕地占用税有关适用税额标准的通知》有效期的通知

各区财政局、国家税务总局上海市各区税务局，市财政监督局，国家税务总局上海市第三税务分局：

经评估，《关于本市耕地占用税有关适用税额标准的通知》（沪财发〔2019〕5号）需继续实施，有效期延长至2029年8月31日。

特此通知。

上海市财政局
