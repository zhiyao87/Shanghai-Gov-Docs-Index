# 上海市奉贤区农业农村委员会关于进一步规范我区设施农用地管理的通知

各镇人民政府、街道办事处、开发区管委会、头桥集团：

为规范设施农用地管理，2016年市农业农村委会同市规划资源局、市绿林业局联合下发了《关于进一步完善设施农用地管理 支持设施农业健康发展的通知》(沪规土资综规〔2016〕227号)文件(以下简称“227号文”)，进一步完善了设施农用地地办理、用途管理等相关制度。

我区自2013年起，在市级相关设施农用地管理办法出台以来，根据各类文件要求对新增设施农用地、存量设施农用地进行了分类管理，造成目前现状设施农用地存在备案材料标准不统一的情况，为进一步规范我区设施农用地管理，请各街镇严格按照“227号文”对现状设施农用地做好梳理检查工作，同时对新增设施农用地严格对照文件要求进行材料审核。现将有关工作要求通知如下：

1、对现状设施农用地做好项目服务范围梳理。对照《上海市设施农用地用地标准(试行)，对已备案设施农用地的服务范围做好梳理工作，摸清底数，为“十四五”期间设施农业发展做好预留空间;

2、加强对现状设施农用地用途的监管工作。严格按照“227号文”内设施农用地用途管理要求，对现状设施农用地做好用途管理监管，确保农地农用，杜绝用地非农化现象的发生;

3、做好设施农用地台帐管理工作。对照“227号”文件要求，整理现状设施农用地有关台帐，便于后期管理，同时由于“227号文”文件要求，用地备案由镇级属地政府进行备案，请各街镇对照已备案项目，完成备案文件，确保备案材料齐全，用地合法。

4、做好新建设施农用地材料审核工作。对新建设施农用地申报过程中，严格按照文件要求，进行材料审理。对用地标准、服务范围、土地流转合同等相关要素进行严格把关，做到实事求是。特别对土地流转年限不得小于用地办理年限(目前设施农用地备案年限一般为5年)，避免出现备案材料自相矛盾的情况发生。

特此通知。
