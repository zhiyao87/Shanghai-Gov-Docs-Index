# 关于开展“促履约，提绩效”产业用地监管专项行动的通知

关于开展“促履约，提绩效”产业用地监管专项行动的通知
沪规划资源用〔2021〕227号
各相关区政府、各相关管委会:
为加强产业空间高效能治理，强化土地利用全生命周期管理，推动新供产业用地履约，根据《关于上海市推进产业用地高质量利用实施细则（2020版）》和《本市低效产业用地处置工作的实施意见》（沪规划资源用〔2019〕475号）等相关工作要求，市规划资源局、市经济信息化委联合在全市开展“促履约，提绩效”产业用地监管专项行动。具体内容如下：
一、目标任务
截至2021年3月31日，全市2014年以来供地并纳入全生命周期管理的830幅产业用地中，已到约定开工时间项目700个，开工履约率为96%；已到约定竣工时间478个，竣工履约率为70%；已到约定投产时间项目350个，投产履约率为44%；已到约定达产时间项目222个，达产履约率为18%。
本次专项行动的目标，是通过各区的监管、督促和处置，到2021年12月31日，上述830幅产业用地的竣工履约率达到90%、投产履约率达到80%，达产履约率达到60%。
二、工作要求
各相关区政府（各相关管委会）应当依托支持产业发展规划土地工作推进机制，组织区规划资源、产业、市场监管、房管、环保等相关部门和镇（街道）、园区，严格落实全生命周期监管要求，共同推进逾期违约项目的处置工作。
1.及时开展开竣工履约认定。
各区规划资源部门应对照全生命周期管理系统，对已到约定开竣工时间的项目进行开竣工认定。对因企业自身原因导致开竣工时间逾期的，应督促企业尽快开竣工，并依法追究企业违约责任；非企业自身原因导致开竣工时间逾期的，经协商可以延期的，应依法约定合理的开竣工期限，投达产时间相应顺延并最长不超过一年。（牵头部门：规划资源部门）
2.及时开展投达产监管和履约认定。
各区产业部门应按照全生命周期管理系统，对已到约定投达产期限的项目，严格对照合同约定的绩效标准，实事求是核定企业投产和绩效情况，合理考虑疫情影响，开展履约情况认定。经批准重新约定履约时间的，按照新约定履约时间统计，延长时间最长不超过一年；以违约金补足差额税收的，按已履约统计。（牵头部门：产业部门）
3.督促企业履约。
对认定开竣工、投达产未履约的项目，应通过书面督促、当面约谈等方式，督促企业尽快开竣工、投达产。对尚未竣工的项目，应帮助解决其施工过程中的问题，督促其尽快竣工。对项目已竣工，但因行业不景气、市场波动等非企业原因暂时无法履约的项目，经协商后仍有履约可能的，应督促企业并帮助其尽快履约。（牵头部门：产业部门、规划资源部门）
4.严格转让管理。
除出让合同约定允许转让或经出让人同意，产业用地使用权及其地上物业不得转让，产业用地权利人股权结构、出资比例和实际控制人依法不得变更。各区要健全涉地股权转让监管机制，督促各区不动产登记、市场监管部门对产业用地实行清单式管控。（牵头部门：规划资源部门）
5.制定低效处置方案。
经认定逾期未履约投达产的地块，由各区规划资源部门会产业部门启动调查、协商和处置程序，根据地块具体情况，综合运用各种政策路径，“一地一策”制定具体处置方案，报请区政府（功能区管委会）研究决策并组织实施。（牵头部门：规划资源部门、产业部门）
三、处置方式
经调查认定，确属逾期未履约开竣工或投达产、且已无履约可能的，应根据项目具体情况，“一地一策”采用以下方式处置：
1.退出土地由政府收储。
确已无法按出让合同开竣工、投达产要求履约的地块，受让人应按出让合同约定退出土地；由出让人按约定给予相应补偿，收回土地纳入储备。（牵头部门：规划资源部门）
2.园区管理机构（园区平台）协商回购。
受让人应按出让合同约定退出土地的，也可以由园区管理机构（园区平台）与出让人协商，按照出让合同约定予以回购。（牵头部门：产业部门、规划资源部门）
3.节余土地转让。
确因区域产业发展需要，需调整产业项目的，应按照程序，由权利人向区产业部门和规划资源部门申请，经产业准入程序，重新核定规划条件和全生命周期管理要求，报请区政府（功能区管委会）批准后，通过土地市场公开转让或股权转让。受让人应签订新的全生命周期监管出让合同，并按新的履约时间进行监管。（牵头部门：规划资源部门、产业部门）
各区可根据本区域实际情况和资源特点，充分发挥基层能动性，创新处置方式，有关情况可及时与市规划资源局、市经济信息化委沟通。
四、时间节点要求
1.2021年6-7月
：各区应全面梳理排摸本区签订土地全生命周期产业项目情况，并如实填报在土地全生命周期共同监管系统中。
2.2021年8-11月
：各区根据项目时间节点开展履约情况认定工作和违约项目处置工作，更新信息及时填报在土地全生命周期共同监管系统中。
3.2021年12月
：各区报送专项工作情况给市规划资源局和市经济信息化委，两部门联合汇总分析各区项目开竣工和投达产履约率，形成工作专报报市政府。
五、工作口径
1.开工履约率
：已到约定开工时间，且监管系统中为已开工的项目数，与已到约定开工时间项目总数的比值。
2.竣工履约率
：已到约定竣工时间，且监管系统中为已竣工的项目数，与已到约定竣工时间项目总数的比值。
3.投产履约率
：已到约定投产时间，且监管系统中投产为已履约（原标注为“可视为履约”的项目，经产业部门认定，可在系统中填写具体绩效数据和原因后转为“已履约”）的项目数，与已到约定投产时间项目总数的比值。
4.达产履约率
：已到约定达产时间，且监管系统中达产为已履约（原标注为“可视为履约”的项目，经产业部门认定，可在系统中填写具体绩效数据和原因后转为“已履约”）的项目数，与已到约定达产时间项目总数的比值。
5.已到投产或达产时间，且已完成收回、收购，或节余转让的地块，或地块收回、收购、节余转让方案已经区政府集体决策批准的可计入完成量。
