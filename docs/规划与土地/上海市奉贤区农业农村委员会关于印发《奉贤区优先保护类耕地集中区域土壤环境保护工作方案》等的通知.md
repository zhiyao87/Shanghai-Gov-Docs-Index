# 上海市奉贤区农业农村委员会关于印发《奉贤区优先保护类耕地集中区域土壤环境保护工作方案》等的通知

各街镇、开发区、头桥集团：

为贯彻落实《中华人民共和国土壤污染防治法》，根据《国务院关于印发土壤污染防治行动计划的通知》(国发〔2016〕31号)、《上海市人民政府关于印发<上海市土壤污染防治行动计划实施方案>的通知》(沪府发〔2016〕111号)和《关于印发<上海市优先保护类耕地集中区域土壤环境保护工作方案>等的通知》(沪农委〔2019〕473号)的要求，区农业农村委会同区相关部门，结合我区实际，制定了《奉贤区优先保护类耕地集中区域土壤环境保护工作方案》、《奉贤区受污染耕地安全利用工作方案》、《奉贤区受污染耕地严格管控工作方案》。请各街镇按照工作方案，结合实际认真贯彻执行。

附件1

奉贤区优先保护类耕地集中区域土壤环境保护工作方案

为贯彻落实《中国人民共和国土壤污染防治法》、《土壤污染防治行动计划》、《上海市土壤污染防治行动计划实施方案》、《农用地土壤环境管理办法(试行)》要求，加强农用地分类管理，推进本区优先保护类耕地土壤环境保护，制定本方案。

一、总体要求

全面贯彻落实党的十九大以来中央和本市关于生态文明建设和绿色发展系列部署要求，牢固树立创新、协调、绿色、开放、共享的新发展理念，以改善土壤环境质量为核心，以保障农产品质量安全为出发点，将优先保护类耕地划为永久基本农田，并以优先保护类耕地集中区域为重点，坚持预防为主、保护优先、风险管控，形成保护有力、建设有效、管理有序的优先保护类耕地土壤环境保护制度，促进土壤资源永续利用，保障本区都市现代绿色生态农业发展。

二、工作目标

到2020年，本区优先保护类耕地土壤环境质量总体保持稳定，耕地土壤环境安全得到有效保障，土壤环境风险得到有效管控。到2030年，本区优先保护类耕地土壤环境质量稳中向好，耕地土壤环境安全得到全面保障，土壤环境风险得到全面管控。

三、主要任务

(一)建立保护清单。按照国家和本市相关技术规范，以农用地土壤污染状况详查结果为依据，以耕地为重点，划定耕地土壤环境质量类别，建立耕地分类清单，并根据土地利用变更和土壤环境质量变化情况，定期对各类别耕地面积、分布等信息进行更新和上传。在此基础上，以粮食生产功能区、蔬菜生产保护区为重点，明确优先保护类耕地集中区域的范围和面积，建立优先保护类耕地清单。(区农业农村委、区规划资源局、区生态环境局牵头，各街镇、开发区、头桥集团配合实施)

(二)提升耕地质量。落实耕地质量保护措施，推行耕地轮作休耕、有机肥替代化肥、测土配方施肥、绿色防控、耕地保育等绿色生产技术，减少化肥农药使用量，提升耕地质量。加强纳入耕地后备资源的滩涂等未利用地的土壤环境保护和地力提升。(区农业农村委牵头，区规划资源局配合)

(三)加强风险管控。建立本区统一的农资监管平台，实现对农资经营企业采购、库存、销售全流程监管，推进化肥、农药实名制购买。健全种植业生产管理信息系统，实现对种植业生产过程的全程可追溯。严厉查处在饲养过程中非法添加违禁物等违法违规行为。建立农药包装废弃物回收机制。(区农业农村委)

(四)加强污染源监管。依法将符合条件的优先保护类耕地划为永久基本农田，实行严格保护。在永久基本农田集中区域，不得新建可能造成土壤污染的建设项目;已经建成的，应当限期关闭拆除。对优先保护类耕地集中区域的有色金属冶炼、石油加工、化工、焦化、电镀、制革等行业企业的排污行为加强监管，防止对耕地造成污染。对优先保护类耕地集中区域及其周边的非正规垃圾填埋场等污染源进行排查和整治，严格控制污染源头，强化风险管控。进一步巩固农村地区生活垃圾综合整治成果，因地制宜开展农村生活污水治理，完善农村生活污水处理长效管护机制。(区规划资源局、区生态环境局、区农业农村委、区水务局、区绿化市容局按职责分工负责)

(五)加强跟踪监测。完善耕地土壤环境质量监测网络，开展耕地土壤和农产品协同监测。实施农业生产方式对农田生态环境质量影响的监测。加强对农田灌溉用水水质的管理，对农田灌溉用水水质进行监测和监督检查。(区生态环境局、区农业农村委、区水务局按职责分工负责)

(六)建立激励机制。进一步优化完善补贴政策，探索金融保险制度在耕地质量保护上的应用，建立耕地保护绩效与补贴资金挂钩的激励机制，鼓励农业生产主体主动保护耕地土壤环境质量。(区发展改革委、区财政局、区农业农村委)

四、保障措施

(一)明确职责分工。区农业农村、生态环境、规划资源等部门按照各自职责协调、指导、督促本区优先保护类耕地集中区域土壤环境保护工作;涉农镇人民政府、街道办事处是优先保护类耕地集中区域土壤环境保护工作的责任主体，落实优先保护类耕地集中区域土壤环境保护各项任务，确保优先保护类耕地面积不减少、质量不下降。

(二)加强工作考核。按照土壤污染防治行动计划、粮食安全省长责任制等相关考核要求，加强优先保护类耕地集中区域土壤环境保护工作的考核，做好工作台账，不定期开展工作绩效评估，将考核结果与绿色农业发展资金相挂钩。

(三)强化执法监督。将土壤污染防治列入环境执法的重要内容，充分利用环境监管网络等多种途径，加强土壤环境日常监管执法和专项环境执法。

(四)加强宣传培训。结合各类主题宣传活动和新型职业农民培育等工作，大力开展耕地土壤环境保护科学普及和教育培训活动，切实提高经营主体对耕地土壤环境保护重要性和紧迫性的认识，进一步提升社会公众参与的自觉性、主动性和能力水平。

附件2

奉贤区受污染耕地安全利用工作方案

为贯彻落实《中华人民共和国土壤污染防治法》、《土壤污染防治行动计划》、《上海市土壤污染防治行动计划实施方案》和《农用地土壤环境管理办法(试行)》要求,落实农用地分类管理,推进本区受污染耕地安全利用,制定本方案。

一、总体要求

全面贯彻落实党的十九大以来中央和本市关于生态文明建设和绿色发展系列部署要求,牢固树立创新、协调、绿色、开放、共享的新发展理念,以保障农产品质量安全为出发点,坚持以风险管控与综合利用并重的理念,针对轻中度污染耕地安全隐患,依靠科学管理,强化政策引导,落实有效措施,构建并不断完善受污染耕地安全利用长效机制,持续提升受污染耕地安全利用率。

二、工作目标

到2020年,轻中度受污染耕地的安全利用率达到95%以上;到2030年,轻中度受污染耕地安全利用率达到98%以上。

三、主要任务

(一)建立安全利用清单。按照国家和本市相关技术规范,以农用土壤污染状况详查结果为依据,以耕地为重点,划定耕地土壤环境质量类别,建立耕地分类清单,并根据土地利用变更和土壤环境质量变化情况,定期对各类别耕地面积、分布等信息进行数据更新和上传。在此基础上,以污染成因分析结果为依据,明确安全利用类耕地的范围和面积,建立各区安全利用类耕地清单。(区农业农村委、区生态环境局、区规划资源局牵头, 各街镇、开发区、头桥集团配合实施)

(二)编制安全利用技术指南。从农用地分类施策的实际管理需要出发,针对轻中度受污染耕地,以保护农田土壤环境质量和保障农产品安全为原则,编制受污染耕地安全利用技术指南,为本区不同污染类型和程度的受污染耕地安全利用提供指导。(区农业农村委)

(三)制定安全利用方案。本区依据国家和市相关技术要求,根据受污染耕地地块的特征污染物、污染程度和利用现状等具体情况,采用农艺调控措施、替代种植、土壤改良、退耕还林等措施,因地制宜编制安全利用方案。(各街镇、开发区、头桥集团)

(四)加强地下水监督管理。在安全利用类耕地地块中对土壤污染影响或者可能影响地下水、饮用水水源安全的,根据国家统一部署,制定防治污染方案并采取相应措施。(区生态环境局、区农业农村委)

(五)加强跟踪监测评估。对采取退耕还林措施的安全利用类耕地定期开展土壤监测,对采取农艺调控、替代种植、土壤改良等措施的安全利用类耕地定期开展土壤和农产品协同监测,跟踪评估土壤环境质量和农产品质量变化状况。重点关注安全利用措施实施后土壤环境质量和农产品质量安全状况,并据此调整安全利用方案。(区农业农村委)

四、工作计划

2020年,根据本区安全利用类耕地分布和面积，编制并实施受污染耕地安全利用方案,完成本区受污染耕地安全利用任务。

2030年,达到本区受污染耕地安全利用目标,形成安全利用长效机制。

五、保障措施

(一)加强组织领导。区农业农村、生态环境、规划资源等部门按照各自职责协调、指导、督促本区受污染耕地安全利用工作; 各镇人民政府、街道办事处是受污染耕地安全利用工作的责任主体,落实受污染耕地安全利用各项任务,确保受污染耕地安全利用。

(二)加强财政支持力度。统筹安排财政专项资金,切实加大受污染耕地安全利用资金投入,完善多元化投融资机制。完善安全利用技术指南,提高受污染耕地安全利用技术水平

(三)加强工作考核。结合土壤污染防治行动相关考核要求,加强受污染耕地安全利用工作考核,做好工作台账,不定期开展工作绩效评估,将考核结果与绿色农业发展资金相挂钩。

(四)强化执法监督。将土壤污染防治列入环境执法的重要内容,充分利用环境监管网络,加强对受污染耕地安全利用措施的实施监督,保障农产品安全。

(五)加强宣传培训。结合各类主题宣传活动,大力开展耕地土壤环境保护科学普及和教育培训活动。结合新型职业农民培训,对农民、农民专业合作社及其他农业生产经营主体进行技术指导和培训。

附件3

奉贤区受污染耕地严格管控工作方案

为贯彻落实《中华人民共和国土壤污染防治法》、《土壤污染防治行动计划》、《上海市土壤污染防治行动计划实施方案》和《农用地土壤环境管理办法(试行)》要求,落实农用地分类管理,推进本区受污染耕地严格管控工作,制定本方案。

一、总体要求

全面贯彻落实党的十九大以来中央和本市关于生态文明建设和绿色发展系列部署要求,牢固树立创新、协调、绿色、开放、共享的新发展理念,从保障人民群众身体健康角度岀发,重点针对重度污染耕地的土壤环境风险,按照目标可达、经济可行、全过程管控的原则,加强对严格管控类耕地的用途管理,有效遏制重度污染耕地土壤环境进一步恶化,并通过退耕还林等生态修复措施,不断改善重度污染耕地土壤生态环境质量。

二、工作目标

本区严格管控类耕地退耕还林等生态修复措施全面落实;到2030年,本区严格管控类耕地土壤环境质量逐步改善。

三、主要任务

(一)建立严格管控类耕地清单。按照国家和本市相关技术规范,以农用土壤污染状况详查结果为依据,以耕地为重点,划定耕地土壤环境质量类别,建立耕地分类清单,并根据土地利用变更和土壤环境质量变化情况,定期对各类别耕地面积分布等信息进行更新,数据上传至农用地环境信息系统。在此基础上,明确严格管控类耕地的范围和面积,建立本区严格管控类耕地清单。(区农业农村委、区生态环境局、区规划资源局牵头, 各街镇、开发区，头桥集团配合实施)

(二)严格管控耕地用途。编制严格管控类耕地风险管控计划,落实严格管控类耕地杈属、边界及面积,加强对严格管控类耕地用途管理,遏制土壤环境质量进一步恶化,控制现有污染物不向周边农田土壤、河流水体等未污染区域进一步扩散。鼓励将重度污染耕地纳入新一轮退耕还林范围。(区农业农村委牵头,区规划资源局配合)

(三)划定农产品禁止生产区域。将严格管控类耕地依法划定为农产品禁止生产区域,禁止种植食用性农作物,禁止开展食用性畜禽养殖、水产养殖等农业生产活动,从源头上阻控污染物进入食物链,避免对人民群众的身体健康产生潜在风险。(区农业农村委)

(四)落实退耕还林措施。将严格管控类耕地纳入新一轮退耕还林计划实施范围,编制退耕还林实施方案,并通过积极实施生物治理和生态修复措施,有效遏制重度污染耕地土壤环境质量进一步恶化,逐步恢复污染严重土地的功能性。(区农业农村委牵头,区绿化市容局、区规划资源局配合)

(五)加强地下水监督管理。在严格管控类耕地地块中对土壤污染影响或者可能影响地下水、饮用水水源安全的,根据国家统一部署,制定防治污染方案并采取相应措施。(区生态环境局、区农业农村委)

(六)加强跟踪监测评估。在严格管控类耕地地块布设耕地土壤环境质量监测点位,对特征污染物进行长期跟踪监测,建立符合严格管控要求的跟踪监测体系及生态修复效果评估机制,并根据监测评估结果,动态调整风险管控和生态修复措施。(区农业农村委牵头,区生态环境局配合)

四、保障措施

(一)加强组织领导。区农业农村、生态环境、规划资源等部门按照各自职责协调、指导、督促本区严格管控类耕地风险管控工作; 涉农镇人民政府、街道办事处是严格管控类耕地风险管控工作的责任主体,落实严格管控类耕地风险管控各项任务,有效遏制严格管控类耕地土壤环境质量进一步恶化。

(二)加大财政和技术支持。统筹安排财政专项资金,切实加大严格管控类耕地风险管控和生态修复资金投入,完善多元化投融资机制。充分发挥本区科研院校技术优势,聘请相关专家进行实地考察、科学规划和实验论证,取得成果后逐步推广,提高严格管控耕地风险管控水平及生态修复效果。

(三)加强工作考核。按照土壤污染防治行动相关考核要求,加强严格管控类耕地风险管控工作考核,做好工作台账,不定期开展工作绩效评估,将考核结果与绿色农业发展资金相挂钩。

(四)强化执法监督。将土壤污染防治列入环境执法的重要内容,充分利用环境监管网格,加强对严格管控类耕地的用途管理和环境风险管控措施的实施监督,防止污染扩散。

(五)加强宣传培训。结合各类主题宣传活动,大力开展耕地土壤环境保护科学普及和教育培训活动。结合新型职业农民培训,对农民、农民专业合作社及其他农业生产经营主体进行技术指导和培训。
