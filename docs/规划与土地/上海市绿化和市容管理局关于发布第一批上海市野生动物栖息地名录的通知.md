# 上海市绿化和市容管理局关于发布第一批上海市野生动物栖息地名录的通知

各区绿化市容局：

为科学规范野生动物栖息地管理，加强上海生物多样性保护，根据《上海市野生动物保护条例》规定，经对上海市野生动物栖息地建设成效进行评估，浦东新区金海湿地公园野生动物栖息地等17处野生动物栖息地列入第一批上海市野生动物栖息地名录，现予以发布。

特此通知。
