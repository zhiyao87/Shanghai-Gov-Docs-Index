# 关于规范嘉定区工程建设项目临时用地管理的通知（修订）

各镇人民政府、街道办事处，嘉定工业区、菊园新区：

为加强本区临时用地管理，进一步规范临时用地使用行为，严格落实节约集约用地和耕地保护，根据国家和本市相关法律法规，结合本区实际情况，现制定临时用地管理有关规则。

一、临时用地适用范围

临时用地是指建设项目施工、地质勘查等临时使用，不修建永久性建（构）筑物，使用后可恢复的土地（通过复垦整理可恢复原地类或者达到可供利用状态）。使用后难以恢复原状的用地，不得使用临时用地。临时用地的范围包括：

1、建设项目施工过程中建设的直接服务于施工人员的临时建筑及场地，包括临时办公用房、生活用房、工棚等使用的土地；直接服务于工程施工的项目自用辅助工程，包括农用地表土剥离堆放场、材料堆场、施工车辆停放场、制梁场、拌合站、钢筋加工厂、施工便道、运输便道、地上线路架设、地下管线敷设作业，以及能源、交通、水利等基础设施项目的取土场、弃土（渣）场等使用的土地。

2、矿产资源勘查、工程地质勘查、水文地质勘查等，在勘查期间临时生活用房、临时工棚、勘查作业及其辅助工程、施工便道、运输便道等使用的土地。

3、符合法律、法规规定的其他需要临时使用的土地。

二、临时用地建设要求

1、科学合理选址。临时用地应当根据土地权属、地类及规划、建设计划等情况合理选址，尽量利用存量建设用地，少占或不占耕地。临时用地不得影响近期建设规划的实施，不得影响公共卫生、公共安全、公共交通和市容景观。禁止在现状城市公共绿地、市政公用设施用地、教育用地内安排临时用地。临时用地范围应包括进出通道，应与现状道路无缝衔接。临时使用林地、河流水面（含防汛通道）的，须经相关部门同意。

2、加强耕地保护。临时用地一般不得占用永久基本农田和部管储备地块、市管储备地块等耕地保护空间，交通、水利等基础设施工程临时用地选址，经论证确实难以避让的，在不修建永久性建（构）筑物、经复垦能恢复原种植条件的前提下，方可临时占用。直接服务于铁路工程施工的制梁场、拌合站，需临时使用土地的，其土地复垦方案通过论证，业主单位签订承诺书，明确了复垦完成时限和恢复责任，确保能恢复种植条件的，可以占用耕地，不得占用永久基本农田。鼓励通过耕地耕作层表土剥离再利用等工程技术措施，减少对耕作层的破坏，提升优质土壤利用效率。

3、节约集约用地。临时用地使用应遵循节约土地原则，严格控制用地规模。

4、保护生态环境。临时用地使用应严格落实生态环境保护和环境卫生管理等相关要求，避免对周边环境产生影响，确保土壤和地下水不被污染，坚持“谁污染，谁治理”原则。

三、临时用地手续办理

1、编制临时用地方案。临时用地使用人应按要求编制临时用地方案，内容包括用地范围、用地面积、使用必要性、建设内容、功能布局等。临时用地使用人还须编制土地复垦方案、明确土地复垦费用及资金来源，并纳入临时用地方案。临时用地使用人应为建设项目用地单位。

2、签订临时用地合同。临时用地使用人应当与有关土地所有权人或使用权人签订附生效条件的临时用地合同。其中临时使用未确定使用权的国有土地的，由相关镇人民政府、街道办事处、管委会与临时用地使用人签订临时用地合同，并通过集体决策确定租金标准（参考标准详见附件）；临时使用农村集体所有土地的，由临时用地使用人与镇（村）集体经济组织或村民委员会签订临时用地合同；临时使用储备土地的（含因出让带征收回的储备土地），由临时用地使用人与土地储备机构签订临时用地合同。

临时用地合同应约定临时用地的四至范围、用地面积、土地用途、用地期限、临时建筑拆除期限、复垦期时长、恢复标准及土地复垦费预存金、租金费用、违约责任等。用地期限严格按照合同约定执行，如在过程监管中发现超合同期限使用，应追加收取相应租金。土地复垦费预存金（参考标准详见附件）原则上不低于本市耕地开垦费标准及土地复垦费用，由相关街镇、管委会土地管理部门收取，应专款专用，不得挪作他用。

3、临时用地申请和审批。临时用地使用人向区规划资源局提出临时用地申请，申请材料包括书面申请、临时用地方案、临时用地合同、土地复垦承诺书、临时用地勘测定界报告、主体工程项目批准（或核准、备案）文件或主体工程建设用地规划许可证、土地复垦方案和占用永久基本农田可行性、必要性论证方案等。申请材料齐全并符合规定的，区规划资源局应在收到材料之日起6个工作日完成现场踏勘及审批工作。

4、提供土地。临时用地经批准后，由土地所有权人或使用权人会同具备相关资质的土地勘测定界部门实地确定临时用地范围，并埋设界桩，提供临时用地。临时用地使用人应在批准范围内按照批准用途使用土地。临时用地不得转让、出租、抵押。

5、系统备案。区规划资源局应当在临时用地批准后20个工作日内，将临时用地的批准文件、合同以及四至范围、土地利用现状照片影像资料信息等传至自然资源部临时用地信息系统备案。

6、到期拆除。临时用地使用人应在临时用地使用期限届满前，完成人员撤离和设施搬离，并自行拆除建构筑物及相关设施。逾期未拆除的，依据临时用地合同约定的条款进行处置。

7、到期复垦及整理。临时用地使用耕地或其他农用地的，一般要求自临时用地期满之日起三个月内，按照复垦报告要求完成土地平整，最迟九个月内恢复至复垦报告要求地类，其中占用耕地的应当恢复种植条件。对逾期不恢复种植条件、违反土地复垦规定的行为，责令限期整改，并依照法律法规的规定进行处罚。临时用地全部使用建设用地的，应当在临时用地期满之日起三个月内恢复到可利用状态。因气候、灾害等不可抗力因素影响复垦的，经批准可以适当延长复垦期限。

8、使用期限。临时用地使用期限一般不超过两年。建设周期较长的交通、水利、能源、管线等基础设施施工使用的临时用地，期限不超过四年。

全部为国有建设用地的临时用地，需办理《临时建设用地规划许可证》；部分国有、集体建设用地的临时用地，无需办理《临时建设用地规划许可证》。使用临时建设用地的，必须按《临时建设用地规划许可证》批准的内容和要求临时使用土地，临时用地的使用期限应相衔接。临时用地使用期限，从批准之日起算。

9、重新办理。因气候、灾害等不可抗力因素的影响，或经市、区重大办认定的重大项目、重点工程，在临时用地使用期限届满后确需继续使用的，可以申请重新办理临时用地，经批准后可以继续使用临时用地。重办过程中，除临时用地申请书、临时用地协议外，其他申请材料科免于提交。

四、组织验收和交还土地流程

1、临时用地使用人在临时用地恢复土地原状或实施复垦后，委托第三方单位完成土壤和地下水检测。

2、检测通过后，临时用地使用人携带相关材料，最迟于复垦期满前三个月提出验收申请。未在规定期限内进行复垦和申请验收的，由收取土地复垦费预存金的部门代为组织实施，土地复垦费预存金不予退还。

3、区规划资源局会同相关镇人民政府、街道办事处、管委会和土地所有权人或使用权人等，在收到材料之日起5个工作日完成进行现场验收。

4、验收通过的，临时用地使用人支付的土地复垦费预存金全额退还，土地交还原土地所有权人或使用权人。

验收不通过的，责令临时用地使用人限期1个月内进行整改。土地使用人拒绝整改的，或整改两次仍不合格的，没收土地复垦费预存金，并由收取土地复垦费预存金的部门代为组织实施。

五、临时用地日常监管

1、加强使用监管。临时用地出租人和所在政府方应加强临时用地合同的监管。在监管中发现临时用地改变用途、超占面积、改变位置、修建永久性建（构）筑物、到期拒不归还土地、拒不按照合同约定期限拆除建构筑物和其他设施、拒不按照合同约定期限恢复土地原状等违反合同的行为，应立即通知临时用地使用人履约，并及时报告所在镇人民政府、街道办事处、管委会和区规划资源局。

2、严肃执法执纪。对于临时用地违法违规行为，由区规划资源局牵头查处，依规依纪依法移送问题线索，追究责任人的责任。相关镇人民政府、街道办事处、管委会作为属地责任单位应及时制止并督促临时用地使用人按照规定完成整改。

3、禁止未批先用。区规划资源局应对临时用地未经批准使用、边批边用和超占面积使用等未批先用的违法行为责令限期整改。在规定期限内未完成整改的，依照法律法规进行行政处罚，待整改验收合格后方可申请办理临时用地手续。
