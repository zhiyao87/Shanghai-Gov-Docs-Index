# 关于转发《自然资源部办公厅关于依法规范做好国土调查政府信息公开工作的通知》的通知

各区规划资源局:

为便于公民、法人和其他组织依法获取国土调查政府信息，依据《中华人民共和国政府信息公开条例》《土地调查条例》，按照《自然资源领域基层政务公开标准指引》等有关要求，现将《自然资源部办公厅关于依法规范做好国土调查政府信息公开工作的通知》（自然资办发〔2024〕50号）转发给你们，请做好贯彻落实。

上海市规划和自然资源局

2024年11月15日
