# 上海市住房和城乡建设管理委员会关于批准《国土空间综合整治工程技术标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《国土空间综合整治工程技术标准》为上海市工程建设规范的通知

沪建标定〔2025〕200号

各有关单位：

由上海市自然资源调查利用研究院、上海市建设用地和土地整理事务中心主编的《国土空间综合整治工程技术标准》，经我委审核，现批准为上海市工程建设规范，统一编号为DG/TJ08-2079-2025，自2025年10月1日起实施。原《土地开发整理工程建设技术标准》（DG/TJ08-2079-2010）同时废止。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市自然资源调查利用研究院负责解释。

特此通知。

2025年4月8日
