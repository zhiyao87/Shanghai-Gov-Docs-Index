# 上海市静安区人民政府办公室关于转发区发展改革委《关于进一步规范本区土地储备项目审批和成本认定工作的若干意见》的通知

区政府各委、办、局，各街道办事处、彭浦镇政府：

区发展改革委《关于进一步规范本区土地储备项目审批和成本认定工作的若干意见》已经区政府第121次常务会议通过，现转发给你们，请认真按照执行。

关于进一步规范本区土地储备项目审批

和成本认定工作的若干意见

为了进一步完善我区土地储备制度，规范土地储备项目审批，根据《上海市人民政府办公厅转发市发展改革委等四部门关于进一步规范本市土地储备项目审批工作若干意见的通知》（沪府办〔2017〕79号）和《上海市人民政府办公厅转发市发展改革委等三部门关于规范本市国有土地使用权出让收支管理意见等三个文件的通知》（沪府办〔2008〕52号）等有关规定，结合我区实际，现就规范本区土地储备项目审批和成本认定工作提出如下意见：

一、总体要求

土地储备项目要符合土地利用总体规划和城乡总体规划、符合本市土地储备规划和经批准的年度储备计划，与本市和本区国民经济和社会发展规划相衔接。土地储备项目审批应参照政府投资固定资产项目管理要求，结合土地储备的特点，既要程序规范，又要加强衔接，提高效率。

二、适用范围

本办法适用于区土储中心为调控土地市场、促进土地资源合理利用，依法单独取得土地，组织前期开发、储存以备供应的行为。

三、土地储备成本认定机构

成立由区发展改革委牵头，区财政局、区建设管理委、区规划资源局、区房管局组成的静安区土地储备成本认定工作小组，负责项目预算及预算调整的审核和项目决算的核销工作。

区土地储备成本认定工作小组办公室设在区发展改革委，办公室具体组织日常工作。

四、项目审批方式和内容

根据国家和本市有关规定以及储备土地项目的不同性质，分别明确审批方式和内容。

（一）对以收储国有土地、场地平整为主要实施内容的项目，批复项目投资估算。批复内容包括项目投资主体、储备范围、实施内容、投资估算和资金筹措等。

（二）对以收储集体土地、场地平整为主要实施内容的项目，仍批复项目可行性研究报告（代项目建议书）。批复内容包括项目投资主体、储备范围、实施内容、投资估算和资金筹措等。

（三）对收储土地中既有集体土地又有国有土地的项目，按照上述收储集体土地方式予以办理，其中涉及国有土地收储的，应明确按照国家和本市有关规定办理。

（四）在土地储备范围内实施道路、供排水、供电、供气、绿地等基础设施建设的，按照我区固定资产投资的基本建设程序办理。

土地储备项目批复可作为土地出让收入支出预算编制和支出计划安排的参考依据。

五、项目审批要件

（一）区土储中心在报送对以收储国有土地、场地平整为主要实施内容的项目（协议收购单位）投资估算时，应当附送以下材料：

1．事业单位法人证书，组织机构代码证复印件；

2．土地储备计划文件；

3．覆盖储备地块的控制性详细规划或结构规划；

4．区土储中心与原土地使用权人达成的收购储备意向；

5．根据法律法规及相关规定应当提交的其他材料。

（二）区土储中心在报送对以收储国有土地、场地平整为主要实施内容的项目（旧区改造项目）投资估算时，应当附送以下材料：

1．事业单位法人证书，组织机构代码证复印件；

2．土地储备计划文件；

3．覆盖储备地块的控制性详细规划或结构规划；

4．旧城区改建项目房屋征收范围确认文件、征收范围内居民意愿征询通过后的公告文件；

5．根据法律法规及相关规定应当提交的其他材料。

（三）区土储中心在报送对以收储集体土地、场地平整为主要实施内容的项目可行性研究报告（代项目建议书）时，应当附送以下材料：

1．事业单位法人证书，组织机构代码证复印件；

2．土地部门出具的审核意见；

3．规划部门出具的规划意见；

4．根据法律法规及相关规定应当提交的其他材料。

六、项目审批程序

（一）土地储备项目批复的程序

土地储备项目需委托有相应专业和能力的工程咨询估价机构编制土地储备项目报告。区发展改革委受理后，由区发展改革委委托有相应专业和能力的工程咨询估价机构对土地储备项目报告及相关资料进行评审，并出具评审报告。

区发展改革委根据评审报告召集区土地储备成本认定工作小组各成员单位召开项目审核会，由各成员单位盖章确认后，区发展改革委将审核意见报区政府审定。

根据区政府的意见，区发展改革委办理项目投资估算或项目可行性研究报告（代项目建议书）的批复手续。

（二）成本认定的程序

土地储备项目收储完成后，由区土储中心向区土地储备成本认定工作小组提交项目成本认定申请报告。区土地储备成本认定工作小组受理后，委托有资格的审计审价机构对项目成本认定申请报告进行成本认定，并出具成本认定报告，成本认定费用列入项目成本。对区审计局已出具竣工决算审计报告的项目，区土地储备成本认定工作小组要做好与区审计局的衔接工作。

区发展改革委根据成本认定报告召集区土地储备成本认定工作小组各成员单位召开项目成本认定会，由各成员单位盖章确认后，区发展改革委将成本认定结论报区政府审定。

根据区政府的意见，区土地储备成本认定工作小组出具项目成本认定的意见。
