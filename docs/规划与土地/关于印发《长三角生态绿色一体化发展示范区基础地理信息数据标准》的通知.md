# 关于印发《长三角生态绿色一体化发展示范区基础地理信息数据标准》的通知

上海市青浦区规划和自然资源局、江苏省苏州市自然资源和规划局、浙江省嘉兴市自然资源和规划局，江苏省苏州市吴江区自然资源和规划局、浙江省嘉兴市嘉善县自然资源和规划局：

根据《长三角生态绿色一体化发展示范区测绘地理信息保障工作协同方案》（示范区执委会发〔2021〕29号），为充分发挥长三角生态绿色一体化发展示范区（以下简称“示范区”）各类地理信息成果资源作用，规范示范区大比例尺基础地理信息及地理实体数据生产，提高数据规范性，更好推进地理信息资源的跨域共享与应用，上海市、江苏省、浙江省自然资源主管部门和示范区执委会共同制定了示范区基础地理信息数据标准，包括《长三角生态绿色一体化发展示范区基础地理信息数据标准：要素分类与代码》《长三角生态绿色一体化发展示范区基础地理信息数据标准：要素数据字典》《长三角生态绿色一体化发展示范区基础地理信息数据标准：要素转换标准》三部分。现印发给你们，请遵照执行。
