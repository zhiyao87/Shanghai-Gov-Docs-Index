# 关于做好2021年度低效建设用地减量化相关工作的函

关于做好2021年度低效建设用地减量化相关工作的函
沪规划资源施〔2021〕128号
宝山区政府:
2015年以来，各区按照市委、市政府部署，坚决落实本市土地资源高质量利用有关要求，有力有序推进低效建设用地减量化，取得了显著成效。
“十四五”期间，各区仍应依据规划持续推进减量化工作。2021年，全市减量化任务总量不低于15平方公里，按季度应分别累计完成任务总量的20%、50%、75%和100%。截至目前，全市已完成了第一季度的考核目标。
你区2021年减量化任务总量为立项65公顷、验收60公顷。截至目前，立项为0公顷，完成验收0.94公顷，未达到一季度目标，进度位于全市各区末尾。
据了解，你区已将减量化年度任务分解至各街镇，并进行了工作部署。为确保完成年度减量化任务，建议你区进一步加大工作力度，压实各级政府及相关部门工作责任，加快推进相关工作。我局将做好业务指导和服务。如二季度工作推进依旧缓慢，我局将按照“以减定增”落实管控措施并专报市政府。
特此致函。
上海市规划和自然资源局
2021年4月22日
