# 关于奉贤区庄行镇市级土地整治项目（二期）竣工验收和新增耕地确认的批复

关于奉贤区庄行镇市级土地整治项目（二期）竣工验收和新增耕地确认的批复
沪规划资源施〔2024〕79号
上海市建设用地和土地整理事务中心:
你中心《关于奉贤区庄行镇市级土地整治项目（二期）竣工验收的请示》（沪地整〔2023〕28号）收悉。奉贤区规划和自然资源局于2023年11月3日组织并通过了该项目的区级验收，项目竣工验收和试运行情况已通过你中心的检查复核。在此基础上，我局会同市财政局对该项目竣工结算进行了审计，并组织土地、农业、水利、生态、造价等领域专家对该项目进行了竣工验收。现将有关事项批复如下：
一、本项目按照规划设计完成了相关建设任务，项目管理、工程质量符合相关要求。项目实施后经济、社会、生态等综合效益较为显著，同意本项目竣工验收。
二、根据规划设计和预算批复（沪规划资源施〔2020〕462号），本项目建设规模366.53公顷。项目实施后新增耕地面积11.52公顷，新增耕地率3.14%。
三、根据审计单位出具的项目竣工财务决算审计报告，本项目最终决算为8,373.945084万元，项目投资控制在批复的项目预算内。
四、请你中心与庄行镇做好本项目工程交接，并督促其做好项目后期管护，同时做好档案整理归集工作。
上海市规划和自然资源局
2024年3月20日
