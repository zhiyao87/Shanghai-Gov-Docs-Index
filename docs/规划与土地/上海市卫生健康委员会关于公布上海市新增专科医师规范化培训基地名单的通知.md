# 上海市卫生健康委员会关于公布上海市新增专科医师规范化培训基地名单的通知

各区卫生健康委，申康医院发展中心、有关大学，有关医疗机构:

为进一步推进和规范本市专科医师规范化培训工作，扩充培训容量，我委委托上海市医师协会组织开展了新一批专科医师规范化培训基地评审工作。按照培训基地的有关标准，经过申报材料审查、听取汇报及实地考察等程序，经研究决定，认定13家培训医院的47个科室为本市新增专科医师规范化培训基地。

现将新增专科医师规范化培训基地名单（见附件）予以公布。请各有关医院和办医主体按照各专科培训细则、基地标准、培训医院和师资管理办法、培训考核办法等相关要求，严格各项管理工作，保证培训过程的同质化、规范化，确保高质量地完成专科医师规范化培训任务。

特此通知。
