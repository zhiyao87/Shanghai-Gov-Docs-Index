# 上海市嘉定区人民政府关于下达嘉定区2014年度集中建设区外现状低效建设用地减量化任务的通知

各镇人民政府，嘉定新城、嘉定工业区、菊园新区管委会：

为贯彻市委、市府《关于进一步提高本市土地节约集约利用水平的若干意见》的有关精神，深化土地利用制度改革，全面实施“总量锁定、增量递减、存量优化、流量增效、质量提高”的基本策略。根据市规土局2014年下达给我区的集建区外建设用地减量化任务，结合各街镇实际情况及土地整治规划，现将我区2014年度集建区外建设用地减量化任务分解下达，并提出相关工作要求，请认真贯彻执行：

一、充分认识集建区外建设用地减量化的重要性

目前我区建设用地规模至规划期内已严重倒挂，市规土局已对我区实施了建设用地增量与减量挂钩、与经营性用地出让挂钩等措施，我区的各项经济、社会事业发展的用地需求受到严重制约，未来建设用地新增空间必须通过集建区外现状建设用地减量化来获得。因此各街镇要充分认识集建区外建设用地减量化的重要性，只有对集建区外现状建设用地减量化，才能破解我区土地资源约束的困境。

二、加强组织领导，广泛宣传，形成共识

各街镇应加强减量化工作的组织领导，成立集建区外现状低效建设用地减量化工作领导小组，由街镇主要领导担任组长，领导小组下设办公室，具体负责工作的组织协调，加强督查指导，协调解决工作中出现的问题和困难，确保工作能尽快组织实施。减量化工作涉及面广，难度大、任务重。各街镇要广泛宣传，着力破解减量化工作中的难点问题，形成共识，全力推进。

三、加快编制郊野单元规划

各街镇要加快启动郊野单元规划的编制工作，通过郊野单元规划编制，摸清情况，锁定减量化目标与任务。有序推进集建区外建设用地的减量化，为区域发展增加建设用地新增空间，进一步促进集建区外节约集约用地，产业结构调整，空间布局优化，生态文明的提升，实现城乡一体化发展。

四、狠抓落实，确保质量

各街镇要结合郊野单元规划编制，及时对下达的计划落实到具体地块中，对具备条件的，抓紧开展项目立项，工程施工等工作，确保项目及时通过验收，按时完成本年度的建设用地减量化任务。各街镇要严格按照土地整理复垦项目管理的有关规定，严格执行项目法人制、公告制、合同制等制度，确保项目地类无误，面积准确，工程质量优良，资金管理规范。

五、实行考核奖惩制

为确保减量化工作顺利推进，区政府执行奖惩考核制度，考核结果与年度部分新增建设用地计划分解下达挂钩，并建立减量化任务完成情况和经营性用地出让、年度综合考核相挂钩的工作机制。对完成情况较好的街镇予以适当奖励，优先安排新增建设用地计划和占补平衡指标；对不能完成下达任务的街镇，将暂停审批街镇的各类土地供应。
