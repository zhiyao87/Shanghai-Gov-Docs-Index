# 关于印发《上海市测绘、地矿、地名、城建档案违法案件查处工作规程（试行）》的通知

各区规划资源局、各派出机构，浦东新区城管执法局:

为规范测绘、地矿、地名、城建档案执法查处工作，提高规划资源综合执法水平和执法效能，维护行政管理秩序，我局制定了《上海市测绘、地矿、地名、城建档案违法案件查处工作规程（试行）》，现予印发，请遵照执行。

上海市规划和自然资源局

2021年6月7日

上海市测绘、地矿、地名、城建档案违法案件查处工作规程（试行）

第一章  总则

第一条（目的）

为规范测绘、地矿、地名、城建档案执法查处工作，提高规划资源综合执法水平和执法效能，维护行政管理秩序，根据《中华人民共和国行政处罚法》《中华人民共和国测绘法》《中华人民共和国矿产资源法》《中华人民共和国城乡规划法》《地名管理条例》等法律、法规和规章，制定本规程。

第二条（适用范围）

本市规划资源主管部门（包括市、区规划资源主管部门及已授权行使规划资源行政处罚权的各级部门），查处测绘、地矿、地名、城建档案违法案件，适用本规程。法律、法规、规章另有规定的，从其规定。

第三条（定义）

查处测绘、地矿、地名、城建档案违法行为，是指自然人、法人或者其他组织违反测绘、地矿、地名、城建档案法律、法规和规章，应当由规划资源主管部门依法进行调查处理，实施法律制裁的行政执法行为。

第四条（执法裁量）

市规划资源主管部门应当结合相关法律、法规、规章中的规定以及执法的实际情况，制定行政处罚裁量基准。对于重大、疑难和复杂案件应当建立和完善案件集体讨论制度，作为实施行政处罚裁量基准的保障机制。

第二章  管辖

第五条（市级职责）

市规划资源主管部门管辖下列案件：

（一）涉及测绘行为、资质、成果、地图等测绘地理信息违法案件；

（二）涉及地质资料、地面沉降监测、地质灾害相关资质等地质矿产资源违法案件；

（三）本级管理审批的地名违法案件；

（四）应向市城建档案馆报送的城建档案违法案件；

（五）在全市范围有重大影响，市规划资源主管部门认为需要直接查处的违法案件。

前款规定的案件，市规划资源主管部门可以指定区级规划资源主管部门管辖。

市规划资源主管部门对各区级规划资源主管部门的业务开展情况进行指导、监督、考核。评议考核结果作为年度责任目标考核、评优、奖惩和警示约谈的重要参考。

第六条（区级职责）

区规划资源主管部门（含已授权行使规划资源行政处罚权的各级部门）管辖本行政区域内测绘、地矿、地名、城建档案的日常执法。对发现属于市级主管部门查处的违法线索，应当及时上报。

第七条（管辖争议）

区级规划资源主管部门管辖发生争议的，应当共同报请市规划资源主管部门指定管辖；市规划资源主管部门应当在收到申请之日起七日内作出决定。

第三章  违法线索

第八条（违法线索来源）

（一）通过12345市民热线，电话、信件、网络举报等发现的违法线索；

（二）通过报刊、广播电视、网络等媒体发现的违法线索；

（三）上级指派、交办，或者其他部门移送、转办的违法线索；

（四）业务职能机构在行政管理过程中发现的违法线索；

（五）其他违法线索。

第九条（协同配合）

规划资源执法机构要加强与业务职能机构的沟通，建立健全测绘、地矿、地名、城建档案行政执法协同工作机制，开展违法线索的核查处置工作。

规划资源执法机构获得的违法线索，如需业务职能机构协助调查的，应当填写《协助调查单》。业务职能机构应在十个工作日内书面反馈调查情况。

业务职能机构在业务管理中发现的违法线索，应先予核实并依法采取必要的管理措施；认为涉嫌违法的，填写《违法线索移送单》，并附相关证据材料，移送相应规划资源执法机构依法查处。

第十条（违法行为核查）

规划资源执法机构获得违法线索后，应当开展线索核查，核查的主要内容包括：

（一）涉嫌违法当事人的基本情况；

（二）涉嫌违法的基本事实；

（三）违反相关法律法规的情况；

（四）是否属于本机构管辖。

规划资源执法机构应当向违法当事人宣传相关法律法规政策，下达《执法检查告知单》；对正在实施的违法行为，应当下达《责令停止违法行为通知书》。核查过程中，可以采取声音影像采集、询问、复印资料等方式收集相关证据。

核查结束后，核查人员根据核查结果提出核查处置建议报执法机构负责人审核。经核查非本机构管辖的，依照本规程的管辖规定，及时将违法线索填写《违法线索移送单》，连同相关证据材料移送有管辖权的执法机构。

第四章  行政处罚

第十一条（立案）

（一）立案条件

规划资源执法机构发现自然人、法人或者其他组织有涉嫌违反测绘、地矿、地名、城建档案法律、法规、规章的行为，经核查符合下列条件的，应予以立案：

1.有明确的行为人；

2.有违反相关法律法规的事实；

3.依照相关法律法规应当追究法律责任；

4.属于本机构管辖；

5.违法行为没有超过追诉时效。

符合不予立案情形的，不予立案。

（二）立案呈批

规划资源执法机构认为符合立案条件的，应当在十个工作日内予以立案，填写《立案审批表》，报规划资源主管部门负责人审批。

不予立案的，应填写《不予立案审批表》，报规划资源主管部门负责人审批。

（三）确定承办人员

批准立案后，规划资源执法机构应当确定至少2名有执法资格的案件承办人员。

第十二条（调查取证）

（一）执法告知

开展调查时，承办人员应当向当事人及其他被调查人出示执法证件，告知执法事项、执法依据以及被调查人的权利和义务。

（二）调查职权和措施

调查取证时，发现涉嫌违法行为，可以依据相关法律法规采取下列措施：

1.进入涉嫌违法行为的场所实施现场检查；

2.查阅、复制有关合同、票据、账簿、登记台账以及其他有关文件、资料；

3.要求有关单位和人员就调查事项涉及的问题作出解释和说明；

4.查封、扣押涉嫌违法的产品，以及与涉嫌违法行为直接相关的设备、工具、原材料、成果资料等;

5.依法可以采取的其他措施。

被检查的单位和个人应当配合，如实提供有关文件、资料，不得隐瞒、拒绝和阻碍。

依法取得并能证明案件真实情况的书证、物证、视听资料、电子数据、证人证言、当事人陈述、鉴定意见、勘验笔录、现场笔录等均可作为案件查处的证据。

承办人员应当全面、客观、公正地进行调查，收集证据应当符合《中华人民共和国行政处罚法》《中华人民共和国行政诉讼法》等有关法律、法规的规定，不得伪造、隐匿、篡改证据，不得以不正当手段收集证据。

（三）询问调查

办理案件需要询问当事人或者证人的，应当制作陈述、询问笔录。问询当事人或其他知情人，调查了解案件相关情况。陈述、询问笔录应当记载陈述、询问的时间、地点、询问人、记录人、被询问人等基本信息和询问内容，经由被调查人核对无误后签章确认。

（四）现场勘验

进行现场勘验、检查，可以邀请相关业务职能机构共同参加，并制作《现场勘验笔录》。《现场勘验笔录》应当记载当事人、案由、勘验内容、时间、地点、勘验人、基本情况等内容。《现场勘验笔录》应当由承办人员、勘验人员，当事人或见证人签名确认。当事人拒绝签名或者不能签名的，应当注明原因。

第十三条（调查终结）

（一）案情分析与调查报告起草

1.作出证据认定。应当审查证据的真实性、合法性和关联性，并对证据的证明效力进行认定。

2.对违法事实进行认定。对违法责任主体、违法事实等内容进行确认。

3.提出法律适用和处理建议。在证据认定和事实认定的基础上，综合研究提出处理建议。

4.起草调查报告。案件调查结束后，起草《案件调查报告》并报执法机构负责人审批。涉及需要追究党纪、政纪或者刑事责任的，应当提出移送建议。

（二）处理决定

案件经审理通过的，承办人员应当填写《案件处理决定审批表》，附《案件调查报告》和案件审理意见，报规划资源主管部门负责人审查，根据不同情况，分别作出如下处理决定：

1.确有应当予以行政处罚的违法行为的，根据情节轻重及具体情况，作出行政处罚决定；

2.依法可以不予行政处罚的，不予行政处罚；

3.违法事实不成立、违法行为已过行政处罚追诉时效的，予以撤案；

4.依法应追究当事人及有关责任人的责任的，移送相关机关处理。

在作出行政处罚决定前，如需确认违法行为的整改状态，执法机构可以邀请相关业务职能机构共同认定。对于需要内业认定的，可以向业务职能机构发出《违法行为整改情况征询单》；对于需要外业认定的，可以邀请相关业务职能机构共同进行现场核查认定。

第十四条（告知）

经审查认为应当给予行政处罚的，应当制作行政处罚事先告知书、听证告知书，报规划资源主管部门负责人批准后，送达当事人。

（一）处罚告知

《行政处罚事先告知书》应当载明做出行政处罚的实施、理由、依据和处罚内容，并告知当事人依法享有的陈述和申辩的权利。陈述和申辩应当由当事人在收到《行政处罚事先告知书》后五个工作日内提出。口头形式提出的，应制作笔录。执法部门对当事人提出的事实、理由和证据应当进行复核。当事人提出的事实、理由和证据成立的，应当采纳，不得因当事人的申辩而加重处罚。

（二）听证告知

规划资源主管部门拟作出下列行政处罚决定，应当制作《行政处罚听证告知书》，并送达当事人：

1.较大数额罚款；

2.没收较大数额违法所得、没收较大价值非法财物；

3.降低资质等级、吊销许可证件；

4.责令停产停业、责令关闭、限制从业；

5.其他较重的行政处罚；

6.法律、法规、规章规定的其他情形。

上述规定的较大数额，是指对个人处5000元以上罚款（或者没收等值物品价值）、对法人或者其他组织处5万元以上罚款（或者没收等值物品价值）。

《行政处罚听证告知书》应当载明做出行政处罚的事实、理由、依据和处罚内容，并告知当事人有要求举行听证和陈述、申辩的权利。当事人要求听证或陈述、申辩的，应当在行政机关告知后五个工作日内提出。口头形式提出的，应制作笔录。

第十五条（法制审核）

（一）法制审核条件

有下列情形之一，在规划资源主管部门负责人作出行政处罚决定之前，应当进行法制审核；未经法制审核或者审核未通过的，不得作出决定：

1.涉及重大公共利益的；

2.直接关系当事人或者第三人重大权益，经过听证程序的；

3.案件情况疑难复杂、涉及多个法律关系的；

4.法律、法规规定应当进行法制审核的其他情形。

（二）法制审核内容

对重大行政执法决定的管辖权、行政执法主体资格、行政执法人员执法资格、依据、程序（包括听证程序、陈述申辩程序）、理由、事实认定及证据、救济途径告知、行政执法文书、行政处罚种类、履行方式及期限、适用裁量基准、违法行为是否涉嫌犯罪需要移送司法机关等进行审核。

第十六条（处罚决定）

当事人未在规定时间内陈述、申辩、要求听证的，或陈述、申辩、听证中提出的事实、理由或证据不成立的，应当依法作出行政处罚决定。

陈述、申辩、听证中提出的事实、理由或证据成立的，应当调整或重新作出行政处罚决定。

规划资源主管部门应当自行政处罚案件立案之日起九十日内作出行政处罚决定。法律、法规、规章另有规定的，从其规定。

第十七条（案件执行）

（一）当事人履行：当事人收到行政处罚决定后，应当在行政处罚决定规定的期限内自行履行。行政处罚决定生效后，当事人逾期不履行的，应督促其履行。

（二）申请人民法院强制执行：当事人在法定期限内不申请行政复议或者提起行政诉讼，又不履行行政处罚决定的，规划资源主管部门可以自期限届满之日起三个月内，申请人民法院强制执行。

（三）催告履行：规划资源主管部门申请人民法院强制执行前，应当制作《履行行政处罚决定催告书》，催告当事人履行义务。催告书送达十个工作日后当事人仍未履行义务的，规划资源主管部门可以向所在地有管辖权的人民法院申请强制执行。

第十八条（案件移送）

规划资源主管部门在依法查处违法行为过程中，发现需要追究当事人及有关责任人员行政纪律责任，本部门无权处理的，在作出行政处罚决定或行政处理决定后，应依法将有关案件材料移送监察、任免机关。涉及刑事犯罪的，移送公安机关。

第十九条（结案归档）

（一）结案

符合下列条件之一的，可以结案：

1.案件已经移送管辖的；

2.依法终止调查的；

3.决定不予行政处罚或者行政处理的；

4.行政处罚决定或者行政处理决定执行完毕的；

5.行政处罚决定依法终止执行的；

6.已经依法申请人民法院强制执行的。

符合结案条件的，承办人员应当填写《结案呈批表》，报规划资源主管部门负责人批准后结案。

（二）归档

规划资源执法机构应当依法以文字、音像等形式，对行政处罚的启动、调查取证、审核、决定、送达、执行等进行全过程记录，并保存。

结案后，应将办案过程中形成的法律文书、证据及其他材料，编目装订，立卷归档。

第二十条（处罚信息主动公开）

根据《上海市行政处罚案件信息主动公开办法》规定，行政处罚决定作出后，应在七个工作日内在门户网站予以主动公开。情况复杂的，经规划资源主管部门负责人批准后可以延长七个工作日。法律法规规定可以不予公开的情况除外。

公开的行政处罚决定被依法变更、撤销、确认违法或者确认无效的，应当在三个工作日内撤回行政处罚决定信息并公开说明理由。

第二十一条（处罚信息报送）

各区规划资源执法机构在行政处罚作出后应按照“一般案件每月一报、重大案件即时上报”的要求，落实向市规划资源执法机构报送案件查处信息。

案件查处完成后，规划资源执法机构应将案件查处信息及时反馈给业务职能机构。

附件：1.上海市测绘、地矿、地名、城建档案行政处罚事项清单

2.违法行为查处法律文书及业务表单参考格式
