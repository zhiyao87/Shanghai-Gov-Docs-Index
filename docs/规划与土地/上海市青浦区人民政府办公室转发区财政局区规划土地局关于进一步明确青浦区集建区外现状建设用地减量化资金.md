# 上海市青浦区人民政府办公室转发区财政局区规划土地局关于进一步明确青浦区集建区外现状建设用地减量化资金使用管理意见的通知

各镇人民政府、街道办事处，区政府各委、办、局，各有关单位：
区财政局、区规划土地局制订的《关于进一步明确青浦区集建区外现状建设用地减量化资金使用管理的意见》已经区人民政府同意，现转发给你们，请认真按照执行。

上海市青浦区人民政府办公室
2017年4月17日
关于进一步明确青浦区集建区外现状建设用地减量化资金使用管理的意见

为进一步推进青浦区集建区外现状建设用地减量化工作，规范减量化资金使用管理，根据《上海市青浦区人民政府办公室转发区规划土地局区财政局关于青浦区集建区外现状建设用地减量化资金方案的通知》（青府办发〔2016〕83号）等文件规定，结合我区实际情况，现对减量化资金使用管理提出如下意见：
一、明确管理职责
各镇（街道）是减量化工作的责任主体和实施主体，负责区域内减量化资金的规范使用。各镇（街道）应健全资金使用管理制度，加强内部财务管理，实行镇级财政直接支付制度，规范政府采购程序，确保依据相关文件规定规范使用资金，确保减量化工作的推进。
区规土局、区财政局负责协调区级减量化资金政策的制定工作，依职责做好区级指标收购费的审核拨付和监管工作。
二、加强资金管理
（一）指标收购费统筹使用。各镇（街道）收到的区级指标收购费应结合今后年度减量化任务统筹使用。减量化工作一般按先易后难顺序推进，以前年度结余的指标收购费优先用于弥补以后年度减量化项目资金的不足，确保减量化项目的总体资金收支平衡。
（二）村级集体资产补偿费优先保障。各村级集体资产在减量化项目中收到的补偿款，其使用用途由该村社区经济合作社社员代表大会讨论决定后，报镇（街道）农村集体资产监督管理委员会审核，资金用途应优先保障村级集体资产的保值增值。
（三）结余资金提高效益。各镇（街道）按进度完成减量化确保任务后（确保任务是指经区土地领导小组审议通过的各年度各街镇减量化任务分解表中的数量），结余的指标收购费全部留存街镇财政，可以在适用范围内安排项目支出，提高资金使用效益。适用范围包括：土地整理、土地复垦、耕地开发、宜农未利用地的开发、基本农田建设、改善农业生产条件的土地开发、农村及公益性设施建设等。镇（街道）使用新增建设用地指标或占补平衡指标由区级统筹安排的，相应指标使用费也可在结余资金中列支。
三、严格监督检查
各镇（街道）应建立健全责任机制，加大对区域内减量化资金规范使用的监督检查。对未能按进度完成减量化确保任务的街镇，指标收购费一律不得截留、挪用、借用或改变用途使用。对不按规定用途安排使用资金的，区财政局有权停止拨付资金，收回结余的指标收购费，停止拨付土地出让金。同时减量化资金的使用，应接受配合各级相关职能部门的监督和检查。
