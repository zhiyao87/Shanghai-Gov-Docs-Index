# 上海市普陀区人民政府办公室关于印发《普陀区国土空间近期规划（2026-2030年）》的通知

区政府各委、办、局，各街道办事处、镇政府，各相关单位：

《普陀区国土空间近期规划（2026-2030年）》已经2026年7月7日区政府第116次常务会议审议通过，现印发给你们，请认真按照执行。

上海市普陀区人民政府办公室

2026年8月20日

普陀区国土空间近期规划（2026-2030年）

“十五五”时期是普陀服务国家战略和上海发展大局的关键五年，为深入落实区委区政府关于“十五五”规划的工作部署，确保普陀区单元规划确定的目标、指标和任务分阶段有序实施，高站位谋划全区“十五五”空间战略格局，统筹近期城市建设实施计划，制定本规划。

一、总体要求

以习近平新时代中国特色社会主义思想为指导，深入贯彻党的二十大和二十届历次全会精神，坚决贯彻习近平总书记考察上海重要讲话精神和重要指示要求，全面落实中央城市工作会议精神，认真践行人民城市理念，全面贯彻新发展理念，服务构建新发展格局，紧扣上海加快建成“具有世界影响力的社会主义现代化国际大都市”目标要求，坚持“四个放在”，积极融入上海“五个中心”建设，深刻认识和全面把握普陀发展的阶段性特征和在全市发展大局中的地位和作用，持续推动城市总规“一张蓝图”绘到底干到底，进一步优化城市空间和功能布局，强化资源要素配置和保障能力，续写新时代普陀高质量发展新篇章。

到2030年，贯彻落实国家和市级重大战略任务取得显著成效，经济、科创、贸易、金融等核心功能能级明显增强，城区颜值气质实现同步跃升，人民城市建设迈出坚实步伐，确保“协同创新活力区、半马苏河品质区”建设取得决定性进展。

二、空间格局

（一）空间发展战略

1.服务“五个中心”战略

融入上海“五个中心”建设大局，在空间落实上有效响应“五个中心”建设新要求，强化经济、科创、金融、贸易、高端产业等核心功能提质升级和联动发展。

一是以优势地区精准发力承载核心功能建设。应对普陀高能级资源要素分散等问题，强化核心功能板块集聚牵引，推动科创、金融、贸易等核心功能率先向武宁路沿线以及“一带一心一城”承载战略发展机遇的潜力板块集聚，统筹战略优先时序，为服务“五个中心”建设提供充分的空间资源支撑。

二是以空间弹性适应匹配功能融合发展需求。顺应新兴产业和新型消费形态的空间需求，强化多元弹性、融合复合的空间资源配置，促进“五个中心”建设的系统联动和功能融合。重点强化面向新质生产力发展需求的“研发+制造”等复合型产业空间的供给，促进产学研用各环节的衔接耦合，为“十五五”期间普陀发展动力转型开拓新空间资源。

2.跨市区协同联动战略

顺应区域协同发展新态势，关注长三角和市域两个层面的跨界协同和联动。

一是廊带共建，发挥普陀在沿沪宁产业创新带中的先锋引领作用。借鉴英国M4科创走廊、长三角G60科创走廊等发展经验，强化普陀在沿沪宁产业创新带中“引力场、智汇源、孵化器和服务中心”的定位，着力打造区域科创、产业、服务和流量核心，支撑长三角一体化高质量协同发展。

二是门户共筑，积极融入上海中城和西向战略地区。紧抓大虹桥地区打造新时代国际开放门户枢纽综合发展示范区，以及上海“一环四向”新空间格局谋划的机遇，强化桃浦、苏州河滨河区域等全市近期重点发展空间联动发展，推动普陀力争成为大虹桥辐射全球国际开放门户的战略支点，助力中城地带西部象限价值提升。

三是水岸共荣，利用苏州河更新转型窗口机遇，推动苏河两岸协同联动发展。以苏州河滨水空间提升为契机，通过滨水带动腹地发展、激活潜力板块，为高能级资源集聚和新质生产力配置提供更优质载体。聚焦产业、文旅、交通等领域加强跨区域联动统筹，共塑沿苏州河时尚创意、校园风情、亲绿宜居风貌展示长廊，共筑上海“一江一河”滨水区标杆地。

3.高质量城市更新战略

以人民城市重要理念为引领，以品质提升为核心，突出城市更新在城市高质量发展中的战略地位。

一是以“大中小”层级、全类型项目引导全域更新。从“大”处落笔，针对转型、提升、机遇等发展导向，推进“一带一心一城”重点地区转型提质发展。从“中”处入手，聚焦功能定位转变、公共要素稀缺等区域，推动更新片区整体焕新。从“小”处见真章，以零星更新项目为抓手，补齐社区功能短板，盘活零散、低效用地。坚持落实单元规划“一张蓝图”，梳理覆盖商务商业、居住、产业、开放空间等全类型的更新项目。

二是以住房和公共服务改善保障人民群众生活更有品质。面向人民日益增长的多层次多样化需求，加快推进老旧住区更新，顺应人口结构趋势变化，提供与多元人群需求相匹配的精准化公共服务产品，打造多元公共空间，切实提升人民满意度。

三是以锚固生态和智慧韧性框架夯实发展底板。点亮蓝绿空间贯通、城绿融合渗透的生态底色。推动传统基建和数字新基建同步提升，针对市政基础设施亟需完善的地区，补齐安全韧性短板，推进传统基础设施更新和数智化改造，强化绿色低碳转型和新型基础设施对城市核心功能的支撑。

（二）空间格局优化

“十五五”期间，普陀在发挥沿沪宁产业创新带对地区空间牵引及区域辐射链接作用的基础上，优化完善“一带一心一城”空间结构。通过推动高端要素集聚，实施差异化空间策略，实现三大重点地区协同共进、各展所长。

“一带”：强化苏河水岸经济发展带能级提升，聚力打造高品质、有温度的全龄友好体验活动区。一是推动苏河水岸经济发展带从“功能建设”到文商旅体展“功能融合”迭代升级。二是大力提升水岸经济硬核实力，营造高密度、高浓度的创新创业生态，引育一批硬核科技企业。三是深化长寿、长风、长征地区更新，推动更新项目实施落地。

“一心”：推进真如城市副中心强核提质，打造上海西部地区高端商务集聚地、数字化转型示范区、文化商业新地标以及服务长三角的公共活动中心。一是提升服务长三角、联通国际的能力以及面向上海西北地区的综合服务功能和特色功能，推动重大功能项目落地。二是聚焦“海纳小镇”数字化转型，营造具有生命力的数字创新生态。三是焕新真如生态底色和人文底蕴魅力，持续推进真如绿廊建设，推动兰溪路及周边地区城市更新。

“一城”：促进桃浦智创城动能迸发，打造上海中心城区转型升级示范区、上海科技创新中心重要承载区。一是着力完善城区空间布局，明确近期资源投放的重点板块。二是全力推进高品质项目建设，推动TOP中央公园品质提升，加快推进核心区配套设施建设。三是聚力提升经济活力和能级，持续做强做大“数智健康、科技服务”产业，推动创新经济总部集聚。

三、行动任务

（一） 全力服务上海“五个中心”建设行动

1.行动目标

加强普陀在上海“五个中心”建设国家战略中的作用，提升高端资源要素配置效能，加快构建现代化产业体系，高标准推进产业、科创、贸易、金融功能集聚区建设。至2030年，服务上海“五个中心”建设取得突出进展，基本形成“一带多点、三区多簇”的产业科创空间发展格局。

2.行动任务

一是加快建设高端产业功能集聚区，培育经济发展新动能。积极融入全市现代化产业体系布局，分类引导工业园区空间优化和释放，推动新质产业向“一带一心一城”集聚。二是加快创新要素高浓度集聚，打造中心城区科创新动力。突出资源禀赋，引导形成各具特色的创新街区。强化科技创新和产业创新深度融合，统筹形成“一带多点、三区多簇”、产业链与创新链融合发展的产业科创空间格局。三是加快大宗贸易集聚区建设，打造上海国际贸易中心特色承载区。优化商贸布局和载体，沿中山北路打造有色金属生产性互联网服务平台“一核多园”发展布局。四是加快特色金融功能集聚，打造上海国际金融中心的新质金融发展阵地。建设以长风生态商务区为核心的上海科技金融产业集聚区，打造真如、长寿、长征和桃浦等多个功能互补的特色金融节点。

（二） 大力推进沿沪宁产业创新带发展行动

1.行动目标

深化沿沪宁产业创新带产业创新和科技创新跨区域协同，通过武宁路串联整合放大全域科技和产业创新资源，推动“一带一心一城”三大重点地区积极参与沿沪宁产业创新带建设，强化培育科创、产业等区域辐射功能，加强优质资源合作交流，完善全域创新空间组织。至2030年，普陀区沿沪宁产业创新带引力场、智汇源、孵化器和服务中心的核心地位和功能进一步巩固，“一带一心一城”面向长三角的服务能级显著增强，初步建成高端产业集聚、创新活力显著、产创城融合的创新城区。

2.行动任务

一是推动武宁路沿线功能品质提升，开展武宁路门户、西宫+曹杨路TOD等关键板块城市更新，拓展高质量科创空间载体。二是增强重点地区区域辐射功能，推动真如城市副中心塑造“长三角公共活动中心”，苏河水岸经济发展带建设“长三角沿沪宁科技金融创新会客厅”，桃浦智创城打造“沿沪宁协同创新区”。三是建设活力复合的创新友好型城区，全区培育以沿沪宁产业创新带为牵引的三大创新圈，打造产业、创新与城市功能高度融合的创新友好城区。

（三） 加快融入上海战略机遇区建设行动

1.行动目标

立足上海大虹桥、中城地带、“一江一河”等重大机遇，加强桃浦地区和新曹杨、北新泾等战略机遇板块的资源投放和要素保障，推动与市域其他战略机遇区跨界协同。至2030年，全方位融入大虹桥发展版图，智创城与苏河源双驱动下的中城更新样板成效显现，苏河两岸协同联动取得实质性进展。

2.行动任务

一是抢抓大虹桥和中城地带发展机遇，提升重点板块战略功能承载能力。用好桃浦智创城待开发用地，加快北新泾、新曹杨地区更新转型，深化拓展西北物流园商贸物流功能。二是把握上海“一江一河”深入推进机遇，强化半马苏河两岸联动统筹。对接苏州河专项规划建设要求，研究制定近期行动计划，分段分主题推动苏河两岸多维度跨河联动。

（四） 深入实施可持续城市更新行动

1.行动目标

围绕“苏河高品质更新样板区、全域可持续更新践行区”的总体目标，深入贯彻人民城市理念，依托“专项规划-片区策划-项目实施方案”的实施路径，以商务楼宇更新、产业用地盘活和老旧住区更新为重点，分层、分类、分区域，系统化推进城市更新行动。至2030年，商务楼宇功能、产业用地绩效和老旧住区品质提升显著，推出一批显功能、惠民生、强辐射、见示范的更新项目。

2.行动任务

一是有序推进更新实施，建立健全城市更新项目库。统筹推进真如、长寿路商务单元等更新单元，以及北新泾、新曹杨等更新片区整体研究和实施，分类推动更新项目实施方案编制和落地。二是着力推进老旧商务楼宇盘活，有序推动商务区功能集聚和融合发展，分类推动存量楼宇更新。三是积极推进产业用地提质增效，建立产业用地评估和处置的长效机制，推动市属国企“四个一批”存量盘活，以及产业用地分类处置盘活。四是持续推进旧住房更新改造，加快推进旧住宅成套改造，持续实施老旧小区提质改造。

（五） 加强畅达融通的综合交通支撑行动

1.行动目标

充分发挥上海西站优势，以补齐轨道交通和道路系统层次和功能短板，打造完善的慢行系统为重点，有效支撑沿沪宁产业创新带建设发展，做好“一带一心一城”重点区域的交通服务保障。至2030年，初步建成与“中心辐射”功能相匹配，内外畅达、融合高效、人本绿色的综合交通体系，市民出行效率和体验明显升级。

2.行动任务

一是促进轨道-公交-慢行三网融合。研究强化轨道交通对区域的支撑和保障功能，优化完善轨道、中运量站点的公交配套，推动公共交通与慢行融合发展。二是推动骨干路网体系完善和提质达标。配合沪嘉、外环高速抬升等市属重大项目，同步完善周边道路设施，推动道路达标提质以及区区对接道路和重点地区配套道路建设。三是完善跨铁跨河通道缝合南北两侧区域。研究推进苏州河普陀段西段规划跨河通道建设，加快推进真南路-兰溪路跨铁通道落地。研究推动苏州河现有驿站功能提质升级，探索沿苏州河滨河道路开辟“深度慢游”定制公交线路。四是构建点覆盖、线贯通和区友好的慢行系统。微改造打造完善的慢行系统，持续推进苏州河等地区慢行交通精品区域的前期研究，构建苏州河全龄友好特色区域。

（六） 积极提高人民生活品质行动

1.行动目标

以“住有所居、住有优居”为目标，进一步完善“租购并举”住房体系，加大保障性住房供给，积极推进好房子、好小区、好社区、好城区建设。加大高能级、高品质公共服务设施建设，推动“15分钟社区生活圈”建设持续向“提质增效、内涵发展、智慧赋能”三大核心方向稳步迈进。至2030年，全区住房市场更加健康、保障更加完善、绿色化智能化明显提升，基本公共服务优质、均衡发展水平稳步提升，建成一批高等级公共服务设施，不断满足人民对美好生活的向往。

2.行动任务

一是精细化引导商品住宅空间布局和供应，面向需求端，合理确定住宅供应区域和节奏。全面提升住宅品质，建设人民满意的好房子。二是多渠道推动保障性住房建设和供给，加快真如翠谷等地区规划保障性租赁住房实施建设。根据市场情况，探索回购部分住宅、商办作为保障性租赁住房。三是推动高等级公共服务设施向重点地区集聚，加快推进波克艺术中心、市体育宫等重大项目建设。四是持续推进“15分钟生活圈”建设，继续完善社区级文教体卫设施配置，优化“1+N”设施空间布局，推进社区数智化转型，为加快构建共建共治共享的社区治理新格局筑牢坚实基础。

（七） 系统推进蓝网绿脉融城行动

1.行动目标

强化门户绿廊、滨水绿带建设，促进绿化贯通成脉，持续推动公园体系完善和“蓝网”提升，打造高颜值、有内涵的公共空间。至2030年，新增公园绿地面积15万平方米，河湖水面率提升至3.95%，“一带两楔、环廊渗透、水环点亮”的生态空间整体格局基本形成，公共空间品质大幅提高，绘就“蓝绿空间交织、三生有机融合、生态赋能发展”的城区新图景。

2.行动任务

一是完善“一带两楔、环廊渗透、水环点亮”的生态空间结构。加快推动真如绿廊以及桃浦河西侧公园绿地建设，谋划建设真如港-木渎港-西虬江-苏州河景观水环，构建城绿渗透、城水交融的生态基底。二是深入推进公园城市建设，实现公园绿地“量质齐升”。完善公园体系，加快真如翠谷绿地等公园绿地建设，推动TOP中央公园、万里公园等现状公园更新改造。三是推进水网体系建设，建设“美丽幸福河湖”。至2030年，全区河湖水面率不低于3.95%。四是提升城市公共空间品质，打造更富魅力的城市环境。持续完善公共空间网络的连通性，盘活存量用好“边角料”扩充公共空间，推进重点地区公共空间品质提升和魅力彰显。

（八） 强化半马苏河文旅品牌赋能行动

1.行动目标

巩固完善半马苏河文化发展主脉，充分用好用活红色文化、海派文化、江南文化等资源，打造“半马苏河”特色IP。至2030年，半马苏河文化主脉人文内涵更加丰富出彩，文化设施建设和历史文化遗存保护更新协同推进，文化活动能级与品牌效应显著提升。

2.行动任务

一是筑造半马苏河引领的文化空间格局，激活半马苏河文化脉络，打造“苏河之冠”文化创意集聚区;精细化管控沿河建筑风貌，激活滨河街坊第五立面，立体化展现水岸文化魅力。二是持续完善特色文化地标和基层文化设施体系，加强福新面粉厂、上海啤酒厂等工业遗存和红色遗迹的深度挖掘，加快推进沪西工人文化宫等文化新地标建设工作;加速完善基层公共文化服务设施网络，培育新型公共文化空间。三是推动历史风貌地区品质提升和功能活化，持续跟进兰溪路及周边地区城市更新、玉佛禅寺更新等历史风貌魅力重塑更新项目建设，加强历史文物资源分级分类管理，促进优秀历史建筑分类活化利用。

（九） 推动低碳和智慧韧性城区建设行动

1.行动目标

落实普陀区碳达峰实施方案，优化能源供给结构，加快重点领域绿色低碳发展。稳步推进“平急两用”公共基础设施建设，显著提高人居环境应对气候变化、灾害的能力和韧性。把握“数字上海”建设要求，不断提升数字化治理水平。至2030年，全区重点领域绿色转型取得积极进展，如期实现碳达峰目标;城市韧性安全体系基本健全，防灾减灾救灾能力不断提升;基本建成数据要素集聚区、数字长三角先锋引领地和数字创新思想策源地。

2.行动任务

一是持续推动城市节能减碳，加大清洁能源开发和利用，加快推动建筑、交通、园区等关键领域绿色低碳转型，推进建设绿色低碳循环型城区。二是构建安全韧性的市政基础设施体系，提升供应设施可靠性，强化排水防涝体系建设，提高综合防灾救援能力。三是建设协同共享的智慧城市，推动数字基础设施建设，强化数字赋能场景应用。

四、保障措施

健全统筹联动机制，深化市区、跨部门协同，统筹规划编制、项目实施和资源要素保障等重点工作。开展国土空间规划实施动态评估，与市级层面协同完善动态维护的传导机制。创新规划管理政策，顺应城市功能融合需求，鼓励各创新街区、商务区等用地和建筑混合利用及转换。着眼突破当前普陀城市更新工作中面临的裉节难题，分类探索商务楼宇、老旧工业区等不同类型的城市更新政策优化路径。强化土地要素保障，落实“规、储、净、供、用、维”一体的运行模式，强化资源配置向重点地区倾斜。探索产业用地供应新机制，由出让为主向长期租赁、先租后让、弹性年限出让转变，降低企业初期用地成本。形成多方参与体系，依托“三师联创”、社区规划师等制度吸纳社会力量参与，鼓励社会资本参与更新建设。
