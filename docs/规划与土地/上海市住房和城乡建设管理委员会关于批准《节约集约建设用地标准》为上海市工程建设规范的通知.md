# 上海市住房和城乡建设管理委员会关于批准《节约集约建设用地标准》为上海市工程建设规范的通知

上海市住房和城乡建设管理委员会关于批准《节约集约建设用地标准》为上海市工程建设规范的通知

沪建标定〔2023〕115号

各有关单位：

由上海市地质调查研究院主编的《节约集约建设用地标准》，经我委审核，现批准为上海市工程建设规范，统一编号为 DG/TJ08-2422-2023，自2023年8月1日起实施。

本标准由上海市住房和城乡建设管理委员会负责管理，上海市地质调查研究院负责解释。

2023年3月8日
