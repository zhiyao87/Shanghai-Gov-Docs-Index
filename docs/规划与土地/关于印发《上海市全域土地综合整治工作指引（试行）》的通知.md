# 关于印发《上海市全域土地综合整治工作指引（试行）》的通知

各涉农区政府、管委会、规划资源局、镇（乡、街道），各相关规划建筑设计单位:

为全面贯彻《关于实施全域土地综合整治的意见》（沪府办〔2022〕13号），配套落实《上海市全域土地综合整治工作管理办法（试行）》，切实做好全域土地综合整治工作，制订了《上海市全域土地综合整治工作指引（试行）》。现予印发，请认真按照执行。

上海市规划和自然资源局

2022年9月14日
