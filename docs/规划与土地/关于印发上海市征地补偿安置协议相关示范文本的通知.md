# 关于印发上海市征地补偿安置协议相关示范文本的通知

各有关区人民政府:

根据《中华人民共和国土地管理法》、《中华人民共和国土地管理法实施条例》等规定，制定《上海市征地补偿安置协议相关示范文本》，已经市政府同意，现予印发，自2021年10月1日起施行。
