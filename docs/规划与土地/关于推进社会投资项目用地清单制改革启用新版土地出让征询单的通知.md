# 关于推进社会投资项目用地清单制改革启用新版土地出让征询单的通知

各相关单位，各区规划资源局，临港、虹桥、长兴岛、自贸区、化工区管委会:

根据《国务院关于开展营商环境创新试点工作的意见》（国发〔2021〕24号）、《上海市营商环境创新试点实施方案》（沪府发〔2021〕24号）和《上海市营商环境创新试点规划资源实施办法》（沪规划资源建〔2022〕181号），为提升社会投资项目建设便利度，深化投资审批制度改革，在本市推进社会投资项目用地清单制改革。各行业主管部门在土地供应前开展相关评估工作和现状普查，并形成评估结果和普查意见清单，通过土地出让征询反馈规划资源部门，规划资源部门在土地供应时将相关信息一并交付用地单位。

结合现有土地出让征询工作流程，我局会同各市级行业主管部门对土地出让征询单（2018版）进行了修订，建立了相关评估结果和普查意见的征询信息栏目，并完成了各区规划资源部门和派出机构的意见征询，近期正式启用新版土地出让征询单。现将有关工作要求通知如下：

一、启用新版征询单

本次征询单修订，新增了地震、气象部门和地下管线征询单；在现行征询单的基础上，优化完善了水务、绿化市容、民防、文物管理等相关内容；在规划资源征询单的土地版块内增加了地质灾害危险性评估、压覆矿情况、地面沉降监测设施普查等内容；在规划资源征询单的规划版块内增加了测量标志点管理要求，优化了历史保护建筑管理要求。

二、征询方式

对于新增的地震、气象等评估和普查信息，各区出让人按地块开展征询。

对于土地储备范围内地下管线普查事项的征询，由各区出让人在土地出让前委托区土地储备机构通过查询本市三维地下管线地理信息库、征询所属各大管线公司等方式完成地块内的管线普查情况，并将征询单反馈出让人。

本次修订的征询单已纳入“大土地”征询模块，出让人必须通过“行政协助平台”开展线上征询。

三、征询时间

各行业主管部门应在7个工作日内通过线上完成征询意见回复，相关征询意见原则上半年有效，但各行业主管部门另有规定的除外。

四、实施时间

本通知自印发之日起执行。同时，为保障各区历史已征询项目的供地节奏，在本通知印发前已完成征询的项目，可沿用原征询单。相关项目在本年内未完成供地的，需按改革要求重新实施线上征询。

五、其他要求

各区规划资源部门和派出机构在征询系统运行中发现的问题，应及时反馈市规划资源部门；对于征询中相关部门存在反馈困难的，应及时反馈各区审改管理部门。

各单位在运行期间积极收集管理案例，迎接本市营商环境的相关检查，我局将结合市发展改革委《关于开展2022年区营商环境测评工作的函》（沪发改营商〔2022〕6号），对各区落实用地清单制情况开展测评。
