# 关于出让土地项目在建工程转让建设主体变更相关手续办理的通知

各区规划资源局、各相关管委会、各派出机构:

对于出让土地项目在建工程转让建设主体变更相关手续的办理规定如下：

出让土地项目在建工程转让后，转让合同的双方当事人可向登记机构申请房屋建设工程转让的转移登记。受让人可凭已完成登记的不动产权证书等材料向规划资源部门申请建设主体变更。

经审核同意变更的，规划资源部门做出建设主体变更的批复，在建工程转让后的建设主体应在批复中载明。建设主体变更前已核发的《建设用地规划许可证》、建设工程设计方案批复、《建设工程规划许可证》等无需变更。

建设主体变更批复核发后，后续建设工程规划许可证（如涉及分期建设）、竣工规划资源验收、不动产登记等手续，应以变更后的建设主体为行政行为对象。

特此通知。
