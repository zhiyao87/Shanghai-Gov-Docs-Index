# 上海市嘉定区人民政府关于印发《2026年嘉定区违法用地综合整治实施方案》的通知

各镇人民政府，区政府各相关委、办、局、街道办事处，嘉定工业区、菊园新区管委会：

《2026年嘉定区违法用地综合整治实施方案》已经区政府同意，现印发给你们，请认真按照执行。

附件：2026年嘉定区违法用地综合整治实施方案

上海市嘉定区人民政府

2026年2月12日

附件

2026年嘉定区违法用地综合整治实施方案

围绕《关于开展2026年度违法用地综合整治的通知》（沪规划资源执〔2026〕13号）和嘉定区违法用地综合整治三年行动工作方案（2024－2026）的总体目标和要求，为具体安排落实2026年综合整治工作各项目标任务，制定本方案。

一、目标任务

根据嘉定区违法用地综合整治三年行动工作方案（2024－2026），我区三年应累计完成5800亩存量违法用地整治。2024年及2025年我区已累计完成约4180亩整治任务量，2026年应完成剩余1620亩整治任务量（各街镇（管委会）任务详见附件）。

二、工作要求

（一）坚持“应拆尽拆”的原则

各街镇（管委会）围绕以“拆除还地”和“清退没收”方式为主体开展整治。开发边界外不符合总体规划的存量违法用地，可结合低效建设用地减量化等工作，协同推进。各街镇（管委会）以“拆除还地”和“清退没收”方式整治的面积应不低于年度计划任务量的60%。

（二）助力盘活低效产业用地

各街镇（管委会）应结合产业用地综合绩效评估情况，将综合绩效评估为C类（观察整改）、D类（整治退出）的产业类违法用地（以下简称“C类、D类违法用地”）作为整治重点。2026年度各街镇（管委会）要加大对低效产业类违法用地整治力度，对C类、D类违法用地整治面积应基本完成剩余未完成整治任务量，超年度任务量的应尽量满足要求。各街镇（管委会）可结合产业用地综合绩效评估最新成果，对C类、D类违法用地的整治计划进行相应调整。

（三）持续推进重点项目整治

各街镇（管委会）进一步梳理分析剩余存量违法用地类型结构，聚焦规划实施、土地储备、土地整治等重点区域，聚焦低效产业用地等重点地块，有序推进整治。各镇（管委会）应从2026年整治计划中挑选不少于1宗整治难度较大的地块，纳入我区2026年重点整治项目备选清单，通过明确整治责任主体、制定具体整治计划，以“项目化”方式重点推进整治。重点整治项目挑选应优先考虑两方面因素：一是规模，原则上项目面积应不小于5亩；二是整治重要性，项目综合绩效评估为C类、D类，或位于开发边界以外，或位于重点开发区域内。各镇（管委会）2025年度未完成整治的重点整治项目，将结转纳入2026年重点整治项目清单。2026年底，各镇（管委会）应全部完成重点整治项目。

各街镇（管委会）“厂房仓库C、D级隐患情形”涉及违法用地的，原则上需在2026年年底前完成整治。如任务量超过街镇（管委会）违法用地综合整治2026年度任务量较多的，可在2027年底前完成整治。

三、整治计划安排

（一）方案制定阶段（1-2月）

各街镇（管委会）结合实际制定本辖区2026年度实施方案和整治计划，并及时召开动员部署会议，全面提高认识、统一思想，逐地块制定整治计划，明确整治时间及整治方案。

（二）整治推进阶段（11月中旬前）

2026年3月底前完成20％年度任务量，6月底前完成60％年度任务量，9月底前完成80%年度任务量和11月中旬前完成剩余20％的整治任务。

各街镇（管委会）要聚焦任务目标，依法依规、综合施策推进整治工作，并做好建档立卷、总结报告等工作。每月15日前报送当月完成整治的案例、“项目化”重点项目推进进度及整治过程中遇到的堵点、难点问题。

（三）中期通报阶段（7月初）

区规划资源局于7月初前开展中期通报。

（四）年度验收总结和考核阶段（11月底前）

各街镇（管委会）于11月下旬开展预验收和总结，区规划资源局于11月底前开展年度验收考核。

四、保障措施

（一）加强通报督办

区规划资源局视整治情况开展专项督办，采用通报、移送等工作机制，督促各街镇（管委会）落实主体责任。各街镇（管委会）要将各村居推进落实整治情况进行通报，要主动将推进整治进度缓慢的村居予以通报、报告。

（二）严肃开展考核

区规划资源局牵头开展中期通报和年终考核。中期通报紧盯整治进度和整治措施落实，年终考核结果纳入街镇绩效考核。

（三）强化联合查处和做好移送工作

对于违法用地当事人不配合整治的，各相关职能部门应加大联合查处力度，通过增强执法震慑力，有效推动整治。涉及国企的，应及时将有关线索移交市、区两级国资部门，结合对国企的相关考核机制，推动落实违法用地整治。对于涉及党员、干部的，按照有关规定及时移送各级纪检监察部门。

（四）加大媒体宣传

各街镇（管委会）和相关部门要用好各类媒体，形成正确的社会舆论导向，助力整治推进。对违法用地综合整治成效，做积极正向报道，形成社会共识。
