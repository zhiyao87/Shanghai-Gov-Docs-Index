# 关于延长《关于〈上海市土地使用权出让办法〉第三十条适用范围的解释》等2件规范性文件有效期的通知

局机关各处室、局属各单位、各区规划资源局、各派出机构:
经评估，《关于〈上海市土地使用权出让办法〉第三十条适用范围的解释》（沪规土资地规〔2015〕315号）和《关于转让花园住宅和非居住用房补交土地使用权出让金有关问题的通知》（沪规土资法〔2010〕309号）仍需继续适用，延长有效期至2025年4月30日。
上海市规划和自然资源局
2020年4月27日
