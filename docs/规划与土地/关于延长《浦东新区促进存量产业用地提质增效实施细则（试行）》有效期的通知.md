# 关于延长《浦东新区促进存量产业用地提质增效实施细则（试行）》有效期的通知

区政府各委、办、局，各管理局(管委会)，各直属企业，各街道办事处、镇政府：

经评估，2023年11月浦东新区科技和经济委员会印发的《浦东新区促进存量产业用地提质增效实施细则(试行)》(浦科经委规〔2023〕5号)需继续实施，有效期延长至2026年12月3日。

特此通知。

上海市浦东新区科技和经济委员会

上海市浦东新区规划和自然资源局

2024年12月27日
