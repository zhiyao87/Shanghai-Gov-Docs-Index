# 上海市嘉定区人民政府办公室转发关于调整嘉定区动迁安置房基地和宅基地安置基地土地出让价格标准的通知

各镇人民政府，区政府有关委、办、局，各街道办事处，嘉定新城、嘉定工业区、菊园新区管委会：

根据土地管理相关规定，动迁安置基地土地出让价格不得低于基准地价的70%，目前我区已执行的区属动迁安置基地和宅基地置换安置基地的出让价格与该项规定不符。区规土局根据有关标准调整制定了新的出让价格标准，现经区政府研究同意，决定转发给你们，请按照执行。具体如下：

一、调整标准

根据上海市2013年基准地价更新成果，我区住宅用地所处的土地等级为五级-九级，按照设定容积率的基准地价分别为：五级（2.0）1431万元/亩、六级（1.8）984万元/亩、七级（1.8）739万元/亩、八级（1.4）408万元/亩、九级（1.4）262万元/亩。

二、调整后价格

根据不低于基准地价70%的规定，按照容积率1.8和2.0，分别对我区动迁安置基地和宅基地置换安置基地出让价格进行了修正，具体价格见下表：
