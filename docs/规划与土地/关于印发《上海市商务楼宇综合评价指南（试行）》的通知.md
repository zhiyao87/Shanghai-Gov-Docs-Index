# 关于印发《上海市商务楼宇综合评价指南（试行）》的通知

各区人民政府、各管委会，市相关部门:

按照高质量发展和世界眼光、国际标准要求，充分借鉴国内国际经验，结合上海实际，深入推进上海商务楼宇健康、可持续发展，做好评估、监测和规划建设工作，制定《上海市商务楼宇综合评价指南（试行）》。现予印发，请按照执行。

上海市规划和自然资源局

2025年3月12日
