# 上海市绿化委员会办公室关于公布本市首批“互联网+全民义务植树”基地名录的通知

各区绿委办，相关单位：

2017年以来，本市根据全绿委《全民义务植树尽责形式管理办法（试行）》试点开展“互联网+全民义务植树”工作，搭建了在线认建认养平台，提供线上尽责途径。经市、区两级绿委办共同努力，全市已有134座公园（绿地）提供线上认建认养服务，社会反响较好。其中上海植物园、上海滨江森林公园已被授予国家级“互联网+全民义务植树”基地称号。

为进一步做好本市“互联网+全民义务植树”相关工作，现决定对提供在线认建认养服务的公园（绿地）授予上海市“互联网+全民义务植树”基地称号，并形成名录予以公布（详见附件）。

各基地应以此次命名为契机，不断深化全民义务植树的文化内涵，提高社会知晓度、接受度和参与度。按照因地制宜、方便参与的原则，拓展义务植树尽责形式，完善线上线下联动、劳动捐资结合的工作机制，不断推进“互联网+全民义务植树”工作。

上海市绿化委员会办公室

2023年5月29日
