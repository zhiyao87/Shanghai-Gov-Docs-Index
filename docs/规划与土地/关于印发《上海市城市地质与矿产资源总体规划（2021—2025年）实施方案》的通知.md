# 关于印发《上海市城市地质与矿产资源总体规划（2021—2025年）实施方案》的通知

各区人民政府，市政府相关委、办、局:

经市政府审核同意并报自然资源部批准，《上海市城市地质与矿产资源总体规划（2021—2025 年）》已于2022年10月21日正式印发。为推进落实规划中所确定的目标和任务，结合上海地质环境特点和上海经济社会发展的实际，经研究编制了《上海市城市地质与矿产资源总体规划（2021—2025年）实施方案》，现印发给你们，请认真按照执行。

上海市规划和自然资源局

2023年5月16日
