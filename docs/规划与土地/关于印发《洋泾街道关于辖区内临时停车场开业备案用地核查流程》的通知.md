# 关于印发《洋泾街道关于辖区内临时停车场开业备案用地核查流程》的通知

街道各部门、企事业单位、居民区：

经研究决定，现将《洋泾街道关于辖区内临时停车场开业备案用地核查流程》印发给你们，请遵照执行。

特此通知。

上海市浦东新区人民政府洋泾街道办事处

2024年11月20日

（此件公开发布）

洋泾街道关于辖区内临时停车场

开业备案用地核查流程

根据上海市道路运输管理局《关于修订印发<公共停车场（库）经营备案指南（2023版）>的通知》（沪道运审〔2023〕1号）文件要求，临时停车场用地使用权证明材料中，需要属地街镇无明确异议，并在“上海市临时停车场经营条件评估（征询意见座谈会会议记录）”上用印确认或另出具相关证明材料同意临时停车场用地。现结合本街道管理实际，制定辖区内临时停车场用地核查流程如下。

情况一：新办理临时停车场开业备案

（一）资料审查

申请人根据临时停车场开业备案行政审批申请材料目录，提交材料至洋泾街道社区平安办公室（以下简称“平安办”）后，由平安办牵头核查所涉场地权属、是否具有“停车场服务”经营范围的《营业执照》和停车场运营情况，确认授权开展停车场服务的期限不短于临时停车场备案证明有效期限。若无误则进入下一个环节。

（二）现场评审

1.由平安办牵头，联合洋泾街道信访办、综合行政执法队、城运中心、洋泾派出所、交警等部门实地检查临时停车场地，确认有无安全隐患或相关问题。如存在违法搭建、群租、生产仓储经营“三合一”、消防隐患等情形，需要告知申请人立即整改。

2.现场检查临时停车场地后，召开相关部门座谈会，交流评审意见，形成会议纪要。若评审通过，则进入下一环节；若未获通过，则由平安办告知申请人，并留好相关凭证存档留查。

（三）征求意见

广泛征求、听取停车场周边单位、居民的意见：

1.由平安办审核申请人提供的“上海市临时停车场经营条件评估（征询意见座谈会会议记录）”是否已覆盖所有周边相关单位、居民区。

2.申请人在停车场周边居民小区张贴《关于XX临时停车场开业业主意见征询公示》，公示时长7个工作日，由平安办负责收集反馈意见。

3.由平安办牵头信访办、城运中心核查有无该地块信访或12345热线投诉工单，并协调周边居民区核查该地块有无牵涉矛盾纠纷。

以上事项需做好沟通记录，形成台账备查。若无反对意见，或整改后符合周边居民小区、单位预期，则进入下一个环节。若有反对意见，且整改后依然无法通过的，则告知申请人并留好相关凭证存档留查。

（四）出具意见

若以上流程中，申请人整改不通过或拒不整改，则不予审批。若以上流程均通过，则由平安办落实临时停车场开业备案用印审批程序，在“上海市临时停车场经营条件评估（征询意见座谈会会议记录）”中加盖“洋泾街道办事处”公章后，向申请人反馈新办临时停车场开业备案用地核查意见。

情况二：已办理临时停车场开业备案，需办理续期的

（一）资料审查

申请人根据临时停车场开业备案行政审批申请材料目录提交材料，同时提供已临期或已到期原临时停车场备案证明至平安办后，由平安办牵头核查所涉场地权属、是否具有“停车场服务”经营范围的《营业执照》和停车场运营情况，确认授权开展停车场服务的期限不短于临时停车场备案证明有效期限。若无误则进入下一个环节。

（二）征求意见

广泛征求、听取停车场周边单位、居民的意见：

1.由平安办审核申请人提供的“上海市临时停车场经营条件评估（征询意见座谈会会议记录）”是否已覆盖所有周边相关单位、居民区。

2.由平安办牵头信访办、城运中心核查有无该地块信访或12345热线投诉工单，并协调周边居民区核查该地块有无牵涉矛盾纠纷。

3.由平安办牵头派出所核实该地块有无突出警情，牵头交警核实该地块周边违章停车情形是否突出，作为审核的依据。

以上事项需做好沟通记录，形成台账备查。若无反对意见，或整改后符合周边居民小区、单位预期，则进入下一个环节。若有反对意见，且整改后依然无法通过的，则告知申请人并留好相关凭证存档留查。

（三）出具意见

若以上流程中，申请人整改不通过或拒不整改，则不予审批。若以上流程均通过，则由平安办落实临时停车场开业备案用印审批程序，在“上海市临时停车场经营条件评估（征询意见座谈会会议记录）”中加盖“洋泾街道办事处”公章后，向申请人反馈临时停车场开业备案用地续期核查意见。
