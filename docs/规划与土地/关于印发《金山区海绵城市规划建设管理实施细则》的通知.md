# 关于印发《金山区海绵城市规划建设管理实施细则》的通知

各有关单位：

《金山区海绵城市规划建设管理实施细则》已经2025年区政府第85次常务会审议通过，现予印发，请遵照执行。

特此通知。

附件：金山区海绵城市规划建设管理实施细则

上海市金山区建设和管理委员会

2026年1月7日

金山区海绵城市规划建设管理实施细则

第一章 总则

第一条（制定依据）

为深入落实国家及本市海绵城市建设的决策部署，根据《国务院办公厅关于推进海绵城市建设的指导意见》（国办发〔2015〕75号）、《关于印发＜上海市海绵城市规划建设管理办法＞的通知》（沪住建规范联〔2023〕11号）、《上海市人民政府办公厅关于印发<本市系统化全域推进海绵城市建设的实施意见>的通知》（沪府办发〔2024〕3号）和《关于印发＜金山区系统化全域推进海绵城市建设的实施意见＞的通知》（金建发〔2024〕38号）等文件要求，结合本区实际，制定本细则。

第二条（定义）

海绵城市是指通过加强国土空间规划和管理，充分发挥建筑、道路和公园绿地、水系等生态系统对雨水的吸纳、蓄渗和缓释作用，有效控制雨水径流，实现自然积存、自然渗透、自然净化的城市发展方式。

第三条（适用范围）

本细则适用于金山区行政辖区内符合条件的新、改、扩建建设项目和海绵城市规划、设计、建设、运维及管理活动。

第四条（遵循原则）

海绵城市建设坚持“规划引领、生态优先、因地制宜、统筹建设”的原则，在国土空间规划和管理各环节落实海绵城市建设理念，统筹协调建筑小区、公园绿地、道路广场、河湖水系等设施建设，综合采用渗、滞、蓄、净、用、排等措施，提升城市市政基础设施建设的系统性。海绵城市相关设施与主体工程同步规划、同步设计、同步建设、同步运维管理。

第五条（管理体制）

区建管委统筹推进海绵城市建设，负责组织编制本辖区海绵城市建设规划、系统方案和达标自评估报告并上报市住房城乡建设管理委备案；推进本辖区内海绵城市建设，做好各阶段海绵城市建设工程的指导和监管工作。

区机管、教育、水务、文旅、卫健、体育、绿化市容、房管、交通等部门及各街镇（园区）按照各自职责分工，负责落实主管领域内项目的海绵城市建设相关要求。

区发改、财政、规划资源、生态环境等部门在项目立项、资金预算、规划审批、水环境质量等方面，按照各自职责协同实施本细则。

第二章 规划、立项、用地

第六条（总体规划衔接）

在金山区级、各镇级国土空间总体规划编制和修编时，应统筹研究海绵城市专项规划中的相关指标，将《金山区海绵城市建设规划（2018-2035）》（以下简称《区海绵城市建设规划》）中年径流总量控制率等核心控制指标纳入总体规划指标体系；将《区海绵城市建设规划》中提出的自然生态空间格局作为金山区城市总体规划空间开发管制的重要要素。

第七条（控规与专项规划落实）

控制性详细规划、郊野单元村庄规划编制和修编时，应落实海绵城市建设内容和相关要求。

防洪除涝、雨水、污水、绿地、道路交通等相关专项规划，应与海绵城市建设规划充分衔接，细化落实海绵城市建设内容和相关要求。

第八条（系统方案编制）

区建管委组织编制片区海绵城市建设系统方案，聚焦重点建设区域、重大项目及达标区域，坚持问题导向、目标导向、结果导向，分类施策。根据水安全、水生态、水环境和水资源等目标要求，进一步分解落实《区海绵城市建设规划》中年径流总量控制率、年径流污染控制率、径流峰值削减等核心控制指标，因地制宜推进海绵城市建设。系统方案经专家评审后报市住房城乡建设管理委备案，作为金山区海绵城市建设的指导性技术文件。

第九条（项目立项要求）

政府投资项目：在工程可行性研究或核准等阶段贯彻海绵城市理念，明确海绵城市建设目标和管控指标。工可评审专家应对海绵城市建设内容进行专项评审，评审意见作为工程可行性研究报告批复的依据。

企业投资项目：在备案阶段应明确年径流总量控制率等海绵城市建设控制指标、建设内容、投资概算等。

纳入区重大项目年度投资计划中的工程建设项目，原则上按照海绵城市示范项目标准建设。区发改委在项目立项阶段，应充分考虑海绵城市建设实施条件，将相关建设要求及投资概算纳入项目批复。

第十条（土地出让或划拨管理）

出让项目：区规划资源局在土地出让前、招拍挂征询阶段，应征询区建管委、区水务局关于海绵城市、绿色调蓄设施建设方面的意见，并将相关建设内容和指标要求纳入土地出让合同和规划设计方案。区建管委、区水务局负责对建设单位落实海绵城市、绿色调蓄设施的建设情况实施监督。

划拨项目：区规划资源局在建设项目规划设计方案环节、区发改委在工程可行性研究报告审批环节，应征询区建管委、区水务局意见，并在规划审批和工可审批中监督落实。

其他项目：由相关主管部门或建设单位书面征询区建管委、区水务局意见，作为项目建设条件。

既有项目调整：已出让或划拨的建设项目，可依法通过设计变更等方式，落实海绵城市建设相关内容和要求。

区域整体划拨（或出让）：建设单位如对区域内部各地块海绵城市建设指标进行调整，应征询区建管委意见，通过内部平衡达到区域总体建设指标要求。

第三章 项目设计管理

第十一条（设计方案审批）

设计单位在编制项目设计方案文件时，应依据意见征询中提出的海绵城市建设指标和要求，按照方案设计文件编制深度以及现行标准规范，编制海绵城市设计专篇（章）。

区规划资源局在建设项目设计方案审批阶段，应以行政审批协助方式就建设单位报批的设计方案征询区建管委、区水务局意见，将审核意见作为设计方案审批的依据之一。对于确需加快推进实施的重大工程项目，经建设单位书面承诺并经区建管委同意后，海绵城市设计专篇（章）可容缺后补，但建设单位应在承诺期限内提交海绵城市设计专篇（章）进行审查。

第十二条（初步设计审批）

设计单位在编制项目初步设计文件时，应依据区建管委、区水务局提出的海绵城市建设指标和要求，按照初步设计编制深度及现行标准规范，编制海绵城市设计专篇（章）。

区建管委应根据项目审批和海绵城市建设管控需要，选择海绵城市领域专家参与初步设计评审会，对海绵城市建设内容进行专项评审，评审意见作为初步设计批复的依据。

第十三条（施工图审查）

设计单位编制施工图设计文件时，应依据区建管委、区水务局提出的海绵城市建设指标和要求，按照施工图设计编制深度及现行标准规范，编制海绵城市设计专篇（章）。景观深化设计中，不得随意改变海绵城市设计内容。

施工图审查机构应按照国家和本市海绵城市相关技术规范、标准，强化施工图设计文件中海绵城市相关内容审查，并在审图合格证附表中注明是否实施海绵城市建设。审图不合格的，不予颁发审图合格证。区建管委应加强对项目海绵城市设计及审查的技术指导和监督。

审查合格的海绵城市施工图不得擅自修改；确需修改的，变更设计不得低于原设计目标。涉及工程建设强制性标准、海绵城市设计目标指标、主要设施调整等重大变更，以及其他法律、法规必须审查内容的，应重新送原审查机构审查。

第四章 建设、验收、移交管理

第十四条（设计管理）

建设单位应在设计招标文件或合同中明确海绵城市建设的具体内容和标准要求。采用工程总承包的建设工程，建设单位应在招标文件或者承发包合同中一并明确海绵城市建设设计要求。各类项目主管部门应督促项目建设单位充分发挥设计龙头作用，对设计质量负责。设计单位应向施工单位进行海绵城市施工设计文件交底，并在施工过程中提供技术指导。

第十五条（施工监管）

海绵城市设施应按照“先地下、后地上”原则合理统筹施工。建设单位应督促设计、施工、监理等单位全面落实海绵城市建设要求，严格把控海绵设施建设过程质量和验收管理，确保工程质量符合法律法规、强制性标准和合同约定。

建设单位应在施工、监理招标文件或合同中明确海绵城市建设内容和标准要求。采用工程总承包的建设工程，应在招标文件或承发包合同中一并明确施工要求。

设计单位应加强技术交底与指导，向施工和监理单位详细说明审图合格的施工图设计文件；参与对重要工艺设施、材料及施工工艺等关键环节质量确认，确保设计意图的实现；设计变更需履行审批程序，重大变更须经原审批部门重新审查，防止质量风险。

施工单位应编制海绵城市建设专项施工方案，严格按照审查通过的海绵城市施工图和相关技术标准施工，不得擅自修改设计或偷工减料。使用经检验合格的海绵设施建设材料、构配件和设备，做好隐蔽工程的质量检查和记录，完整保存技术档案和管理资料，并在竣工时同步提交海绵设施建设竣工资料。

监理单位应将海绵城市建设内容纳入监理细则，对施工进行全过程的管理和监督；加强对原材料见证取样检测，严格原材料进场检验并留存记录；对隐蔽工程进行验收,对关键工序、部位采取旁站和巡视，确保按图施工；对不符合要求的，应责令限期整改。

工程质量监督机构应将海绵城市建设相关工程施工质量及设施验收纳入日常监督，加大现场巡查力度，监督设施验收工作。

第十六条（综合竣工验收）

项目完工后，建设单位组织参建单位竣工验收时，应将海绵城市建设内容纳入验收范围，审阅工程档案资料并实地查验工程质量，重点检查海绵设施相关内容。竣工验收合格后，建设单位组织编制竣工验收报告时应载明海绵设施建设是否合格的结论等。

建设单位组织竣工验收合格后，应通过上海市工程建设项目审批管理系统申请提交包含海绵城市相关内容的竣工验收报告、设施工程竣工验收记录、竣工图纸、建设达标承诺函等资料。工程质量监督机构应加强对海绵城市工程竣工验收监督，不符合要求的，应按照有关规定责令限期整改，不得出具《建筑工程质量监督报告》。

第十七条（移交维护）

海绵城市设施竣工验收合格后，应随主体工程同步移交。

第五章 运维管理

第十八条（管理责任）

运营维护管理单位应建立健全海绵设施维护管理制度和操作流程，配备专人管理，保障设施完好和正常运行。

市政设施、公园绿地、道路广场等政府投资项目海绵设施，由各项目管理单位或相关行业管理部门负责维护管理；企业投资项目和住宅小区等海绵设施由产权人负责维护管理，产权人可委托物业服务单位实施管理。

第十九条（监测评估）

海绵设施维护管理单位应定期对设施进行维护、监测和评估，确保设施正常运行。鼓励引入第三方机构，利用数字化技术和检测手段开展定期评估。

各项目建设单位或相关行业管理部门应与区建管委互通信息，对区内河湖水系、管网关键节点、重点排口、项目地块及重点海绵设施等开展实时动态监测，提供项目基本信息、建成前后对比数据、监测信息等工程资料，支撑海绵城市建设成效评估。

第六章 其他

第二十条（技术推广）

鼓励和支持海绵城市建设的科学研究和先进适用技术、设备和材料的推广使用。重点关注上海市建设领域重点推广的新技术、新产品、新材料。

第二十一条（宣传引导）

各有关部门、单位应积极开展海绵城市建设宣传引导活动，提升全社会对海绵城市建设的认知度和参与度。

第二十二条（附则）

本细则自2026年2月1日起施行，有效期至2031年1月31日。
