# 关于延长《本市落实土地征收成片开发标准的若干意见（试行）》有效期的通知

局机关各处室、局属各单位、各区规划资源局、各派出机构:
经评估，《本市落实土地征收成片开发标准的若干意见（试行）》（沪规划资源规〔2021〕5号）需继续实施，有效期延长至2025年7月29日。
上海市规划和自然资源局
2023年7月28日
