# 关于印发《“十四五”新城建设用地指标奖励操作办法》的通知

关于印发《“十四五”新城建设用地指标奖励操作办法》的通知
沪新城规建办〔2021〕7号
嘉定区、青浦区、松江区、奉贤区政府:
为激励各区加快“十四五”新城规划建设工作推进，支持新城高质量发展，制定《“十四五”新城建设用地指标奖励操作办法》。现予印发，请遵照执行。
上海市新城规划建设推进协调领导小组办公室
2021年7月26日
“十四五”新城建设用地指标奖励操作办法
为全面实施“上海2035”总体规划，深入贯彻落实市委、市政府关于新城规划建设的战略要求，激励各区工作推进，制定“十四五”新城建设用地指标奖励操作办法。
一、目标原则
新城建设用地指标奖励，是指在运用低效建设用地减量化指标以及存量建设用地盘活等措施，充分保障新城建设各类用地需求的基础上，市级对新城规划建设工作年度考核成效显著的区，给予一定规模的净增建设用地计划奖励。目的是为了调动相关区做好新城规划建设工作的积极性和主动性，形成“比学赶超”加快新
城建设的良好局面。
新城建设用地指标奖励政策坚持规划引领、依法合规、公正公开和差别化原则，自2021年起，根据市政府对各区新城规划建设工作情况的考核结果，对各新城建设中的市政公益项目、产业项目和经营性项目在办理农转用用地审批时，分档确定市级使用净增建设用地指标的比例，其余部分由各区使用减量化用地指标落实。奖励方案在一定范围内公开发布，发挥表彰激励和先进示范作用。
二、奖励方案
根据市政府对嘉定、青浦、松江、奉贤四区上年度推进新城规划建设工作情况的考核结果，对考核结果为“优秀”的区，市级净增建设用地计划奖励支持市政公益项目、产业项目和经营性项目的比例分别为100%、60%和30%；对考核结果为“良好”的区，市级净增建设用地计划奖励支持市政公益项目、产业项目和经营性项目的比例分别为80%、40%和20%。
每年年初，市规划资源局在全市年度建设用地计划安排方案编制中单列“新城建设用地奖励指标”。奖励用地指标由区政府统筹安排，用于新城规划范围各类建设项目，应优先保障重点市政基础设施等民生项目和高新技术产业项目。
各新城应用好奖励用地指标，以增量用地开发带动存量用地盘活，结合批而未供、供而未用和闲置土地处置、城市更新政策等，释放新城存量空间，依据规划计划整区域推进新城高质量建设。
三、跟踪管理
市规划资源局对新城建设用地奖励指标实施专账管理，确保奖励指标及时拨付给相关区，并确保专账专用，动态掌握各区奖励指标的使用情况。
本操作办法有效期至2026年12月31日。
