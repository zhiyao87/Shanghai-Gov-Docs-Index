# 关于做好耕地种植用途管控工作的通知

各区农业农村委，各市属涉农国企：

根据中央农村工作会议和中央一号文件部署要求，为落实《国务院办公厅关于防止耕地“非粮化”稳定粮食生产的意见》等文件精神，严格落实耕地保护责任，加强耕地种植用途管控动态监测、日常监督，建立健全保障永久基本农田用于种植基本农作物管理体系，不断提升永农基本农作物种植比例，统筹推进撂荒耕地复耕复种，逐步绘制完善本市耕地种植用途管控“一张图”，守牢、用好耕地资源，保障粮食和重要农产品有效供给，本市将进一步加强耕地种植用途管控工作。

一、工作内容

开展永农种植基本农作物情况摸底调查，掌握本区永农农作物种植基本情况。根据市农业农村委提供的疑似图斑组织开展永农内未种植基本农作物情况核查,并开展原因和分类处置分析，结合春耕秋种科学提出提升种植基本农作物比例推进目标和计划，同时梳理更新撂荒耕地复耕复种一地一方案表，结合春耕秋种按计划推进永农基本农作物种植比例提升和撂荒耕地复耕复种。

二、主要任务

（一）摸清底数，提出对策。

各区、市属涉农国企通过政务云平台“耕地种植现状核查”模块开展疑似问题图斑实地核查，实地核实图斑现状，在线填报核实情况并拍摄上传至少“一远景一近景”带有经纬度水印的照片，分析问题原因和提升永农基本农作物种植比例存在的难点，制订永农提升种植基本农作物工作方案情况，并建立“一地一策”的工作推进计划。梳理更新撂荒耕地复耕复种一地一方案表。

（二）分类施策，统筹推进。

对于“非粮化”问题，全面分析问题原因，因地制宜逐步引导、调整优化种植种类，提升粮食、蔬菜种植面积；对于“非农化”问题，及时整理信息告知区规划资源局，市农业农村委同步告知市规划资源局；对于过于破碎、无法规模种植的地块，协调区规划资源局逐步调出永农范围，优化永久基本农田质量、格局，市农业农村委同步与市规划资源局开展协商。按计划推进撂荒地复耕复种，到2026年全面完成农业农村部下达的复耕复种任务。

（三）建立机制，长效管控。

市农业农村委定期对永农上基本农作物（粮食、蔬菜）种植情况进行分析和监查，各区、市属涉农国企及时对新的疑似问题图斑开展核查、整治工作，加强耕地种植用途管控，并定期反馈实际需求，共同完善耕地种植用途管控平台，健全保障永久基本农田用于种植基本农作物管理体系，逐步绘制本市耕地种植用途管控“一张图”。同时，建立常态化的跟踪督查机制，以区镇、企业自查为主、市级抽查为辅，充分利用遥感数据比对等信息化手段，结合实地踏勘核查，开展跟踪监测，坚决防止问题反弹、反复，守牢上海市耕地红线。

（四）落实责任，做好保障。

严格落实粮食安全党政责任制，将防止耕地“非粮化”作为粮食安全责任制考核重要内容，压实责任。建立耕地种植用途管控责任制，明确各级责任主体职责，做到责有人负、活有人干、事有人管，确保耕地保护工作落到实处。及时将耕地种植用途管控工作网络人员信息（政务云账号）反馈至市农业农村委，方便开通平台权限。指导网格员做好实地在线核实等工作，确保工作顺利实施。

三、保密要求

“耕地种植现状核查”模块依托政务云平台搭建，各区镇、市属涉农国企要注意“耕地种植现状核查”模块中图斑数据安全，不在公共平台传输相关数据，非必要不共享；要注意政务云平台的数据安全，遵守政务云平台相关保密规定。

上海市农业农村委员会
