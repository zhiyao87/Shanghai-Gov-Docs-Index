# 关于印发《大吴淞地区专项规划》的通知

宝山区人民政府、浦东新区人民政府、各相关单位:

《大吴淞地区专项规划》已经市政府批复同意（沪府〔2024〕35号），现予印发。请各相关区、各相关单位按照规划要求，高标准、高质量推进规划建设实施。

特此通知。

上海市规划和自然资源局
