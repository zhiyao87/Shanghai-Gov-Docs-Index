# 关于印发修订后《徐汇区关于产业用地履约达产协同管理的若干意见》的通知

区各有关委、办、局，各街道、华泾镇，有关单位:

根据区政府要求，现将修订后的《徐汇区关于产业用地履约达产协同管理的若干意见》印发给你们，请认真按照执行。

2024年1月区商务委印发的《徐汇区关于产业用地履约达产协同管理的若干意见》(徐商务规〔2024〕1号)同时废止。

徐汇区新型工业化推进办公室

2025年1月23日

徐汇区关于产业用地履约达产协同管理的若干意见

第一条(目的和依据)

为全面推进土地资源高质量利用，鼓励存量产业用地提容增效，强化产业用地履约达产协同管理，实现土地更集约、更高效、更可持续的高质量利用，根据《关于上海市推进产业用地高质量利用的实施细则(2020版)》(沪规划资源用〔2020〕351号)、《关于加强上海市产业用地出让管理的若干规定》(沪规划资源规〔2021〕6号)、《关于推动“工业上楼”打造“智造空间”的若干措施》(沪府办规〔2023〕21号)等有关政策文件，结合本区实际，制订本意见。

第二条(组织保障)

由区新型工业化办牵头，会同有关部门落实产业用地履约达产协同管理有关要求，对涉及项目准入、绩效评估、土地使用权退出和产权关系变更等重大事项进行研究决策，协调各部门工作开展，完善保障措施，确保政策落实，及时报告产业用地管理协调工作情况。各部门分工及职责如下：

1.区新型工业化办、区科委、区文化旅游局、区投促办、区国资委等产业、招商部门负责组织实施产业用地的项目准入、达产评估等履约达产协同管理等工作。

2.区规划资源局负责项目规划条件核定、土地出让、设计方案审核、用地和工程规划许可、竣工规划资源验收、产业用地房地产权证办理的联动监管及出让合同全过程管理等工作。

3.区发展改革委负责产业项目立项等工作。

4.区生态环境局负责在产业用地出让、转让、收回前等阶段，进行土壤和地下水环境质量调查、污染源排查等工作。

5.区财政局负责土地出让收支管理等工作。

6.区税务局负责土地出让收入征收及项目税收监管等工作。

7.区市场监管局负责对涉产业用地企业申请股权变更登记(含股权转让)开展联动监管等工作。

8.区房管局负责产业用地在建工程转让联合监管和商办用房销售备案办理及监管等工作。

9.区建设管理委负责项目开竣工、施工、装修报建等建设方面监管等工作。

10.区应急局、公安分局等部门按照各自职责，做好项目规划、建设等环节中涉及的有关审批、监管事项。

第三条(园区平台认定)

促进园区平台投资建设运营的园区加快产业转型、提升科技研发和实体产业能级，重点扶持本市“2+(3+6)+(4+5)”现代化产业体系、战略性新兴产业、现代服务业等领域企业和研发机构发展。区新型工业化办会同区发展改革委、区规划资源局、区国资委、区生态环境局等有关部门对申报企业的主体类型、资质条件、经营业绩、运营服务能力、产业招商资源等情况进行集体会审，报区政府集体决策认定。

第四条(推动“工业上楼”打造“智造空间”)

拓展制造业发展空间载体，提高产业用地集约利用水平，促进实体经济高质量发展。支持企业自建自用“工业上楼”项目，满足功能复合、规模扩大、能级提升的需求。支持园区平台公司通过自有物业存量改造、低效物业回购改建等渠道，加大“工业上楼”供应，新建“工业上楼”项目纳入全生命周期合同管理，明确建设、招商、运营、退出等环节监管要求。

第五条(存量产业用地盘活利用)

鼓励存量产业用地提容增效。支持“零增地”提容改造(在原有用地基础上进行新建、改建、扩建)，扩大混合成分比例，提高土地利用效率。按照规划和产业导向，引入产业项目，用于工业制造，所用存量工业和仓储用地需要提高容积率或增加地下空间的，由改造主体申请，经市、区规范程序审批，此轮改造的增量部分可以不增收土地价款。改造后的使用全过程由区新型工业化办牵头开展绩效评估，对于不符合产业要求或未达标的，按有关规定和合同约定追究责任。

支持存量工业用地盘活转型，倡导集中成片的存量工业用地区域整体转型，允许园区平台等专业企业参与原权利人为主导的联合体，通过存量补地价办理用地手续，实施转型开发。改造后的使用全过程由区新型工业化办牵头开展绩效评估，对于不符合产业要求或未达标的，按有关规定和合同约定追究责任。

第六条(履约达产协同管理)

(一)项目准入

项目需符合本市、本区城市规划、产业发展、环境保护、经济效益、社会管理等要求。

(二)项目时间履约保证金

出让人、产业、招商部门负责督促受让人按合同约定按时开工、竣工、投产，根据合同约定，受让人应按时缴纳相应项目时间履约保证金。项目按时开工、竣工、投产后，受让人分别提供相关证明材料报产业和招商部门确认，按照履约完成阶段及相应比例返还履约保证金。申请延期开竣工并获批准的项目，投产时间顺延。受让人有未按时开工、竣工、投产情形的，按合同约定条款以履约保证金支付违约金;情节严重的，按照合同约定，出让人有权解除土地出让合同，收回土地使用权。

(三)土地利用绩效评估

出让人、产业、招商部门负责开展项目达产情况评估，属地街道镇配合，按照出让合同约定，对项目实际履约情况进行认定。

1.评估时间。达产评估：对合同约定达产日下一会计年度的全年业绩进行评估。过程评估：在项目达产评估后，根据出让合同约定进行过程评估，考核期间项目绩效情况。到期评估：在项目土地使用年期到期前1年进行一次到期评估，考核项目达产后整体绩效情况，作为合同到期是否续期的参考依据之一。

2.评估标准。项目在到达约定达产日期时税收总额达到合同约定要求的视作达产。如项目实际达产纳税未达承诺税收，根据合同约定执行，出让人、产业、招商部门应当对未达承诺税收的受让人及时发函提醒。

3.达产评估、过程评估、到期评估工作流程。产业、招商部门在项目约定达产日下一会计年度完成或评估周期到达前的1个月内向企业送达项目达产评估认定通知函，并抄送属地街道镇、出让人。

项目单位须在收到产业、招商部门的认定通知函后1个月内提供项目产出税收方面以及其他项目过程评估所需的相关证明材料。逾期不提交的，视作未按时达产。

属地街道镇配合产业、招商部门开展项目达产评估认定工作，产业、招商部门提出项目达产认定意见及项目后续履约的相关措施要求。受让人未能按合同约定达产的，出让人应按有关规定和合同约定追究受让人责任。

第七条(附则)

本意见自2025年2月22日起执行，有效期至2028年2月21日。本意见内容如与国家、上海市有关规定不一致时，以国家、上海市有关规定为准。2024年1月徐汇区商务委员会印发的《徐汇区关于产业用地履约达产协同管理的若干意见》(徐商务规〔2024〕1号)》同时废止。

徐汇区产业园区平台认定管理实施细则

第一条(目的依据)

为贯彻落实《关于上海市推进产业用地高质量利用的实施细则(2020版)》(沪规划资源用〔2020〕351号)、《关于加强上海市产业用地出让管理的若干规定》(沪规划资源规〔2021〕6号)等文件精神，进一步促进产业用地开发建设和转型升级，强化产业用地出让全生命周期管理，结合徐汇区实际情况，特制定本细则。

第二条(适用范围)

本细则适用于徐汇区范围内符合市、区两级城乡规划和土地利用规划的产业项目类工业用地、标准厂房类工业用地、产业项目类研发用地、通用类研发用地。

本细则所指园区平台，系为承担本区辖区内各类园区投资建设、运营管理的平台型公司及其投资公司。

第三条(园区平台责任)

促进园区平台投资建设运营的园区加快产业转型、提升科技研发和实体产业能级，重点扶持研发中心等研发机构和上海“2+(3+6)+(4+5)”现代化产业体系、战略性新兴产业、现代服务业等领域企业发展，实现土地集约、高效、可持续利用。

第四条(政策应用)

(一)支持园区平台提升产业服务功能。标准厂房类工业用地、通用类研发用地出让给园区平台的，可采用“带产业项目”挂牌方式供应。

(二)支持园区平台收购运营区域范围内企业节余工业用地，用于建设标准厂房、通用类研发物业，收购企业节余土地纳入土地交易市场实施。

(三)支持存量工业用地盘活转型，倡导集中成片的存量工业用地区域整体转型，允许园区平台等专业企业参与原权利人为主导的联合体，实施转型开发。

(四)促进园区平台做好园区的开发建设、运营管理，做好招商引资和企业服务工作。

第五条(认定条件)

凡申报徐汇区园区平台的企业，认定条件包括：

(一)园区平台公司应当在徐汇区注册成立项目公司，负责园区运营管理等工作。

(二)园区平台公司所引入的项目应符合徐汇区产业发展规划，符合徐汇区产业准入要求。

(三)园区平台公司应当具备成片园区开发建设和运营管理经验，建筑开发量原则上不低于20万平方米，建筑持有量原则上不低于10万平方米。

(四)采取合作开发模式的园区平台，主要投资方应当为具有专业园区品牌化运作经验的国内外知名企业，并承诺长期经营(20年以上)。

第六条(认定材料)

申报徐汇区园区平台的企业，认定材料包括：

园区平台申报方案。包括公司基本情况表(见附件一)、营业执照复印件、公司章程、公司成片园区开发的主要项目及业绩、近期拟开发的区块和开发运营方案、项目储备情况、合作协议、相应的资质证明等。材料包括电子版和纸质版。

第七条(认定程序)

认定徐汇区园区平台，包括以下程序：

(一)初审。区新型工业化办对申请徐汇区产业园区平台认定的相关材料进行初审。

(二)会审。区新型工业化办会同区发展改革委、区规划资源局、区国资委等相关部门对产业准入、园区平台认定进行联合会审。

(三)审定。会审结果报区营商服务联席会议审定。

(四)确认。审定意见报区政府同意后，由区政府正式发文确认徐汇区产业园区平台名单。

第八条(转让及退出)

(一)区新型工业化办会同区相关部门负责初审园区平台物业转让，并报区政府集体决策审定。园区平台可将部分物业转让研发中心等研发机构、“2+(3+6)+(4+5)”现代化产业体系、战略性新兴产业、现代服务业等企业以及其他符合区产业导向的企业。

(二)园区平台的标准厂房类工业用地、通用类研发用地上的物业，除生活配套设施以外的物业可转让比例不超过50%。

(三)园区平台可转让物业的，应在土地出让合同中明确必须经区政府审核同意，并明确转让方式、产业准入要求和退出机制。鼓励采用先租后售方式，在物业承租人产出贡献、研发投入、节能低碳等指标达到设定条件后再予以转让。园区平台采用直接转让的比例不得超过可转让物业的60%。

(四)园区平台转让的物业，自转让登记之日起5年内不得再次转让。5年后确需转让的，必须经区政府审核同意，并且区政府有权指定机构按约定价格优先回购;放弃优先回购的，经区政府审核同意后，可转让给符合产业准入要求的企业或研发机构。

上述受让企业和研发机构按照规定退出时，应由园区平台按照约定的价格标准优先回购;不予回购的，需经区政府集体决策同意后，方可转让给符合条件的企业或研发机构。园区平台、受让企业和研发机构退出转让的物业纳入土地交易市场实施，不得通过股权转让的方式退出和转让。上述内容纳入土地出让合同，实施土地全生命周期管理。

第九条(平台监管)

(一)凡发现申报园区平台所报材料弄虚作假、或采取其他不正当手段申报影响认定结果的，一经确认,将取消申报资格;已获得认定的，将予以撤销资格。该公司的失信行为将被列入企业信用报告。

(二)经认定的园区平台实行目录式动态管理。凡发现园区平台用地受让人的出资比例结构、股权结构和实际控制人发生改变而未事先经原出让人同意的情形，可予以撤销园区平台资格。园区平台引入产业和科研项目不符合发展导向，产业用房租售对象、租售方式、临时使用不符合产业和科研等规定要求的，不再享受可转让50%物业的支持政策，并可撤销其园区平台资格。

(三)加强信息共享和协同监管，将各类用地的建设、功能、运营、环境等指标以及土地使用条件、利用绩效等履约情况纳入土地全生命周期管理，按照“谁提出、谁监管”的原则，实施协同监管，提高土地利用综合效益。

第十条(生效时间)

本细则自2025年2月22日起执行，有效期至2028年2月21日止。
