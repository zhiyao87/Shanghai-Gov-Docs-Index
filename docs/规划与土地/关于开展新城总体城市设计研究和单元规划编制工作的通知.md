# 关于开展新城总体城市设计研究和单元规划编制工作的通知

关于开展新城总体城市设计研究和单元规划编制工作的通知
沪规划资源总〔2021〕67号
嘉定区、青浦区、松江区、奉贤区人民政府，临港管委会:
“新城发力”是市委、市政府谋划“十四五”新空间格局的重大战略部署。为贯彻落实《上海市人民政府印发〈关于本市“十四五”加快推进新城规划建设工作实施意见〉的通知》（沪府规〔2021〕2号）以及《关于印发〈上海市新城规划建设导则〉的通知》（沪新城规建办〔2021〕1号）的要求，现就做好5个新城总体城市设计研究和后续单元规划编制工作的相关要求通知如下：
一、工作目标
对照2035年集聚100万左右常住人口，基本建成长三角地区具有辐射带动作用的综合性节点城市的发展目标，在市政府已经批准的相关区总规基础上，通过完成新城总体城市设计研究对新城既有规划进行再审视和再优化，并在后续新城单元规划编制工作中进行落实，为“十四五”新城高质量规划建设夯实基础。
二、工作原则
（一）高点定位，确保规划高水平编制。
深入贯彻习近平总书记关于城市规划建设的重要讲话精神，全面落实上海市委、市政府关于新城规划建设的重要指示，充分体现“全新的发展定位、全新的理念运用、全新的系统设计和对既往城市建设实践的全面超越”，对标国内外最高标准和最好水平，强化系统研究和整体谋划，编制出高水准的规划成果。
（二）近远结合，确保各项工作有序衔接。
既要强化总体城市设计、单元规划对各新城功能空间布局和近期开发建设活动的引领作用，也要统筹兼顾各新城“十四五”规划建设行动方案确定的发展目标、实施策略和推进计划，同步做好重点地区的相关详细规划编制工作，保障近期重点地区和重大项目建设需求，确保新城规划建设的集中度和显示度。
（三）市区联动，保障新城规划建设。
充分发挥新城所在区和管委会的主体责任，集中力量，聚焦重点，加强工作支撑和组织保障，确保新城总体城市设计研究和单元规划按计划完成。市规划资源局主动服务，加强工作对接和技术指导，会同各区和管委会共同明确工作路线图和时间表，高效推进新城规划制定工作。
三、工作任务
嘉定、青浦、松江、奉贤新城在完成总体城市设计研究工作基础上，按需有序推进新城单元规划编制工作。
南汇新城结合《中国（上海）自由贸易试验区临港新片区国土空间总体规划（2020-2035年）》（以下简称临港新片区总规）编制工作已经完成了总体城市设计研究，应抓紧对照沪府规〔2021〕2号和沪新城规建办〔2021〕1号文的要求深化完善新城单元规划初步成果。
（一）关于总体城市设计研究
分为前期研究和成果整合两个阶段推进：第一阶段，奉贤新城已经完成了总体城市设计国际方案征集工作，目前正在进行成果整合汇总。嘉定、青浦、松江新城，由市规划资源局会同各区政府，各邀请熟悉新城规划建设情况的三家设计团队开展为期一个月的总体城市设计工作营，对照新目标、新定位对新城空间格局进行再审视和再优化（具体方案详见附件）。第二阶段，嘉定、青浦、松江新城在总体城市设计工作营三个方案的基础上，充分吸纳市级各部门、相关专家的意见，整合提炼形成各新城的总体城市设计研究成果，为新城单元规划编制打下扎实规划研究基础。奉贤新城不再组织总体城市设计工作营活动，在前期总体城市设计国际方案征集工作基础上，直接开展第二阶段成果整合工作，形成总体城市设计成果。南汇新城不再重复开展总体城市设计研究，直接在临港新片区总规基础上提炼形成总体城市设计成果。
（二）关于单元规划编制
在总体城市设计工作的基础上，各新城开展单元规划编制工作，重点将总体城市设计确定的人口规模、用地规模、建筑面积等指标以及用地结构、高度分区、强度分区等规划要求落实到各城镇单元和乡村单元，并重点明确各单元内公益性、基础性设施的设置要求。
除南汇新城单元规划按照临港新片区总规确定的要求抓紧推进外，其余新城单元规划编制工作的具体要求，待各新城总体城市设计研究成果稳定后，按照新城规划建设的实际需求确定。
四、时间安排
（一）关于总体城市设计
各新城均应按照“一城一意象”要求，形成“一城一方案”。
1.工作营开展阶段（2021年3月3日-4月2日），聚焦嘉定新城、青浦新城和松江新城，邀请同济规划院、中规院上海分院、华建集团以及市规划院等共同参与工作营。计划3月3日正式开营，市规划院根据前期规划梳理成果形成总体城市设计任务书并在开营式上下发，3月中旬召开中期成果专家咨询会，4月初召开最终成果专家咨询会。
2.成果整合阶段（2021年4月3日-4月20日），市规划资源局牵头，各区共同参与，组织市规划院具体承担总体城市设计成果整合工作。4月中下旬，完成嘉定新城、青浦新城和松江新城总体城市设计最终成果。对于奉贤新城、南汇新城，提前在3月底前后编制完成总体城市设计研究成果，并在编制过程中充分听取专家和各相关部门意见。
（二）关于单元规划编制
5月初，各区政府组织规划编制单位全面开展新城单元规划编制工作，可以在新城规划范围内整体编制，也可以结合街镇行政边界划分形成3-5个片区分别编制，其中“十四五”重点地区涉及的片区单元规划可以优先推进。原则上，2021年底前完成各新城单元规划编制工作。
五、组织保障
（一）充分发挥专家的决策支撑作用。
成立核心专家团队，全过程紧密参与，直接指导设计团队开展总体城市设计等工作，对成果质量进行全方位把关。
（二）强化技术统筹。
由市规划院组建新城总体城市设计的技术核心团队，负责统一提供基础资料、组织各设计团队交流以及专家研讨等工作，并做好总体城市设计方案整合、单元规划任务书编制等技术工作。
（三）做好经费保障。
按照事权分工，本轮新城的总体城市设计和单元规划编制经费由各新城所在区和管委会承担。请新城所在区和管委会及时做好相关经费落实工作，并为相关规划研究调研和现场踏勘工作做好支撑和保障。
