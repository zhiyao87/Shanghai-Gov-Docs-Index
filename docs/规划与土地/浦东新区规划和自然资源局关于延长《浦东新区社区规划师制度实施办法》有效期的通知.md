# 浦东新区规划和自然资源局关于延长《浦东新区社区规划师制度实施办法》有效期的通知

各相关委、办、局，各街道办事处、镇人民政府：

根据本市城市更新中社区规划师管理工作要求，经评估，2023年9月印发的《浦东新区社区规划师制度实施办法》(浦规划资源规〔2023〕1号)继续实施，有效期延长至2034年12月31日。

特此通知。
