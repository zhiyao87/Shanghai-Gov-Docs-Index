# 关于印发《上海市乡村社区生活圈规划导则（试行）》的通知

各涉农区政府、管委会、规划资源局、镇（乡、街道），各相关规划建筑设计单位:

现将《上海市乡村社区生活圈规划导则（试行）》印发给你们，自印发之日起试行。在试行过程中如有意见和建议，请及时反馈我局。

上海市规划和自然资源局

2021年12月2日
