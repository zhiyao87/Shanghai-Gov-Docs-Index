# 关于印发《上海市征收集体土地信息公开标准指引》的通知

各区规划资源局、各派出机构、各相关单位:

现将《上海市征收集体土地信息公开标准指引》印发给你们，请认真贯彻落实。《上海市征地信息公开目录》（沪规土资综〔2015〕381号）同时废止。

上海市规划和自然资源局

2024年7月5日

上海市征收集体土地信息公开标准指引

为进一步规范征地信息公开工作，适应新形式下行政审批制度改革要求，完善征地信息公开工作机制，保障被征地农民的知情权、参与权和监督权，维护被征地农民的合法权益，根据《中华人民共和国信息公开条例》《自然资源领域基层政务公开标准指引》（自然资办函〔2022〕576号）等规定，制定本指引。

一、适用范围

本指引适用于本市征收集体土地信息公开领域。适用的主体范围包括各有关区规划资源局以及具有征地补偿公共事务职能的行政机关、事业单位。

二、主要内容

本指引按照法律法规及自然资源部有关要求，梳理了本市征收集体土地工作过程形成的政府信息，形成了征地信息公开标准目录，包括公开内容、公开方式、公开渠道等。

公开内容：此列明确了征地各环节中应公开的要素。

公开方式：此列明确了每项内容对应的公开方式。其中，标*是指该项内容公开后可能损害第三方合法权益，相关部门应当征求第三方意见，经其同意后，方可公开。

公开渠道：此列明确了主动公开内容的公开渠道。其中，标■的为必选项，即该内容必须通过此渠道公开；标□的为可选项，即该内容可根据工作实际选择是否在此渠道公开。

申请的征地信息不在标准目录中的，应当结合申请实质内容引导申请人选择标准目录中相应内容。

三、组织实施

各有关区局、特定区管委会等作为征地前期、征地申请、征地实施信息的制作主体，要按照标准目录要求做好主动公开和依申请公开工作。

征地审批信息向各有关区局、特定区管委会等申请的，各有关区局、特定区管委会应当向申请人便民提供征地审批信息；向市规划资源局申请的，根据《关于进一步深化行政审批制度改革加快推进重大项目建设的若干意见》（沪府规〔2020〕16号）规定，按照权责一致、有利于申请人及时准确获取征地信息的原则，由各有关区局、特定区管委会等直接办理。各有关区局、特定区管委会等收到市规划资源局转办通知，按照规定要求办理后调取市规划资源局信息公开电子章，直接回复申请人。

各有关区局、特定区管委会等要按照指引要求履行公开主体责任，切实抓好指引的贯彻落实工作。市规划资源局将加强宣传，引导征地信息公开申请人依法依规申请，对各区局、特定区管委会等落实情况进行指导监督，不断提升本市集体土地征收领域信息公开标准化规范化水平。
