# 上海市青浦区规划和自然资源局关于印发《关于进一步加强青浦区农村村民建房风貌管理的实施意见》的通知

各镇人民政府、街道办事处：
现将《关于进一步加强青浦区农村村民建房风貌管理的实施意见》印发给你们，请遵照执行。
特此通知。
附件：关于进一步加强青浦区农村村民建房风貌管理的实施意见
青浦区规划和自然资源局         青浦区农业农村委员会
青浦区建设和管理委员会
2023年11月6日
关于进一步加强青浦区农村村民建房风貌管理的实施意见
第一章  总则
第一条（目的依据）
为进一步推进我区农村村民建房建筑风貌的提升，提高农村人居环境整治工作水平，建设宜居宜业和美乡村，根据《上海市农村村民住房建设管理办法》（沪府令16号）、《上海市青浦区农村村民住房建设管理实施细则》（青府规发〔2019〕4号）及相关文件，并结合我区实际，制定本实施意见。
第二条（适用范围）
本实施意见适用于本区行政区域内集体所有土地上的农村村民新建、改建、扩建、翻建及修缮住房的风貌管理。
第三条（概念定义）
农房建筑风貌是指一定区域范围内的农房在外观、形态、色彩、材料、比例、风格等方面所呈现出来的整体形象。农房建筑风貌是乡村文化的重要组成部分，是乡村形象的重要载体。
第四条（总体原则）
农房建筑风貌应在挖掘和体现以江南水乡民居为代表的传统建筑元素的基础上，从布局肌理、材料色彩等空间和视觉要素着眼，在演化中实现延续与创新，建成体现传统意向又满足现代功能与审美要求的青浦乡村民居。
农房建筑空间肌理应体现枕水而居、错落排列、宅院相生、紧凑实用的特点；色彩材质宜为粉墙黛瓦、灰色细部，呈现出质朴天然的黑白灰色调关系，同时应兼顾已建成农房建筑的多样性，合理保留已形成较为明艳色彩且整体风貌协调的农房建筑群；屋面立面应体现出延绵缓起、虚实相间的特点，应采用坡屋顶组合或平坡结合的屋面形式。
应统筹村庄内公共建筑、市政基础设施、活动空间、道路桥梁、河道水系、村民停车、院落围墙、绿化景观等各类设施的设计，引导农房建筑与周边环境相协调，促进乡村整体风貌的提升。
第五条（管理部门）
青浦区建设管理委员会（以下简称“区建设管理委”）是本区村民建房的建筑活动主管部门，负责本辖区内村民建房的建筑活动监督管理和农房建筑风貌的引导。
镇人民政府及街道办事处（以下简称“镇（街道）”）受区建管委委托，落实村民建房风貌管控的各项要求并进行现场指导和监督检查。
青浦区农业农村委员会、青浦区规划和自然资源局等其他部门根据《上海市青浦区农村村民住房建设管理实施细则》（青府规发〔2019〕4号）第四条的规定按照各自职责做好相关工作。
青浦区农村村民建房会审联席会议（以下简称“区联席会议”），下设办公室于区规划资源局，负责审议农房风貌管理的相关议题以及对街镇的专项检查和考核等工作。
第二章  工作机制
第六条（施工图纸）
镇（街道）应在区建设管理委的指导下，根据风貌管控正负面清单，结合辖区实际情况委托具备资质的设计单位编制农房设计推荐图集，明确平面布局、建筑面积、建筑高度、色彩材质以及屋面形式等内容，报区联席会议（办公室）审议通过后供辖区内村民建房使用。建房村民也可以自行委托具备资质的设计单位设计施工图纸，经乡村建筑师确认后由镇（街道）报区联席会议（办公室）审议通过后用于农房建设。
未经联席会议（办公室）审议通过的图纸不得用于农房建设。
第七条（乡村建设规划许可）
村民建房应办理乡村建设规划许可证，乡村建设规划许可证应附总平面图、建筑平立剖面及效果图。建房村民应应严格按照乡村建设规划许可证的的内容及附图进行建设。
镇（街道）应通过在线审批系统办理乡村建设规划许可证。建房村民未取得乡村建设规划许可证的，不得开工建设。
第八条（施工队伍管理）
镇（街道）应加强对村民建房施工队伍的管理。村民建房应当选择具有相应专业能力的施工队伍，可选择具备相应资质的施工单位或者由乡村建设工匠组成的施工队伍承担，并签订建房协议，明确施工方责任。
第九条（施工铭牌制度）
镇（街道）要落实村民建房施工铭牌公示制度。施工队伍负责制作施工铭牌，并在开工前将其设立在工地醒目位置。施工铭牌应如实公示房屋立面效果图、总平面图，建筑面积、层数、高度，设计、施工单位的名称，设计、施工负责人的姓名和联系方式，监督举报电话等信息。
第十条（全过程监管）
农房开工前，镇（街道）要全面落实开工放样、逐层竣工核查到场的要求；同时加强执法监管，依法组织开展动态巡查，在施工阶段应开展定期巡查、拍照记录。巡查中一旦发现不按图施工的，应立即责令停止施工、进行整改。
农房竣工后，应按规定组织验收，通过后方可投入使用。镇（街道）应委托有资质的第三方进行农房竣工测绘，复核是否按图施工。对于不符合验收要求的应要求其整改并予以落实。
农房建成投入使用后，镇（街道）要落实日常巡查制度，发现有违章搭建或风貌负面清单等影响农房风貌行为的，应及时制止并责令其恢复原状。
第十一条（档案管理）
镇（街道）应做好村民建房档案资料的整理及归档工作，形成电子化档案，并在竣工验收后6个月内移交区规划资源局城建档案管理中心。
第三章  保障措施
第十二条（充实监管力量）
镇（街道）应当落实村民建房专管人员对农户建房实施风貌监督，也可以委托符合条件的第三方机构实施监督。同时应充分发挥村级组织自治、村民监督作用，发掘吸纳有一定施工技术常识的村民、乡村建设工匠等作为补充力量开展日常巡查等工作。
第十三条（乡村责任规划师及乡村建筑师）
镇（街道）应委托乡村责任规划师及乡村建筑师下乡开展陪伴式驻村指导，为村庄风貌及村民建房提供设计、咨询、管理等服务。
第十四条（乡村建设工匠）
镇（街道）应健全乡村建设工匠管理机制，加强工匠技能培训和考核，提升乡村建设工匠职业技能和综合素质，建立乡村建设工匠名录，推动乡村建设工匠持证上岗全覆盖。
第十五条（资金保障）
镇（街道）应落实财政预算，为推荐房型图集制作、测绘、委托乡村责任规划师和乡村建筑师及第三方监管等提供资金保障。同时，对严格按图施工并落实风貌较好的农户，鼓励给与一定的资金奖励。
第四章  区级监督与管理
第十六条（季报制度）
每季度首月十日前，镇（街道）应将上季度农房审批及建设情况梳理后上报区联席会议办公室，由办公室整理后以季报的形式报送区联席会议。
第十七条（定期检查）
区联席会议办公室每年组织不少于两次的现场检查，对审批材料、风貌管控、档案管理、违法违规处理等方面开展全方位检查，并将检查情况及时整理后上报联席会议。
第十八条（区镇共管）
区联席会议办公室选取一定区域范围作为农房区镇共管区域，镇（街道）在核发《乡村建设规划许可证》以及竣工验收前应征求联席会议办公室的意见，在取得书面同意后才能核发《乡村建设规划许可证》及竣工验收合格证明。
第六章  法律责任
第十九条（考核机制）
将镇（街道）农房风貌管理落实情况纳入年度考核。若发现一年内有三起及以上风貌管控不力问题的，由农民建房联席会议予以通报，并抄送区组织部门；情况严重的，暂停辖区内村民建房审批工作，并报区常务会议予以通报。
第二十条（责任追究）
镇（街道）工作人员应当严格按照相关规定履行职责，若发现玩忽职守、滥用职权、徇私舞弊等违法行为的，由有关部门依法给予行政处分；构成犯罪的，依法追究刑事责任。
第七章  附则
第二十一条（其他）
本《意见》自印发之日起实施。具体内容由青浦区农村村民建房会审联席会议负责解释。
