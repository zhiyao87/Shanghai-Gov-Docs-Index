# 关于公布上海市林果全程机械化生产基地名单的通知

关于公布上海市林果全程机械化生产基地名单的通知

各区农业农村委，各相关单位：

为贯彻落实市政府《上海市推进农业高质量发展行动方案（2021—2025年）》（沪府〔2020〕84号）和市农业农村委等六部门《关于加快推进农业机械化和农机装备产业转型升级的实施意见》（沪农委〔2020〕60号）相关要求，按照《关于开展上海市林果机械化生产示范基地认定工作的通知》（沪农委〔2025〕50号）部署，2025年我委组织开展了上海市林果全程机械化生产基地认定工作。经区级遴选申报、市级评审认定、社会公示等程序，确定哈玛匠（上海）果蔬专业合作社等我市8家果园为上海市林果全程机械化生产基地，现予以公布（名单见附件）。

各区农业农村委及相关单位要强化服务指导，统筹用好现有各类政策，支持已认定林果全程机械化生产基地加快农机装备迭代升级，发挥示范带动作用，进一步提高林果生产机械化、智能化水平和社会化服务能力，推动我市林果业提质增效和高质量发展。
