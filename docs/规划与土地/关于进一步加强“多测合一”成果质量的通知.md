# 关于进一步加强“多测合一”成果质量的通知

各测绘单位:

2018年9月，七部门联合发布《关于全面推进工程建设项目“多测合一”改革的实施意见》（沪规土资测〔2018〕591号），正式启动“多测合一”改革试点工作以来，“多测合一”在减少重复测绘、减轻企业负担、提高工作效率，进一步提升营商环境方面发挥了显著作用。现就进一步加强“多测合一”成果质量通知如下：

一、进一步规范成果报告内容

按照“一次委托”、“同一测绘成果只提交一次”的目标，承担“多测合一”项目的测绘服务机构应当按照要求提交完整的成果报告，不得单独出具单项报告，确保“多测合一”成果报告数据完整，满足共享互认要求。

二、进一步加强技术能力建设

上海市工程建设规范《建筑工程“多测合一”技术标准》即将发布，同时正在探索推进交通线性工程“多测合一”试点。测绘服务机构要加强对相关标准、规范的学习，进一步提升技术能力，做好基于“多测合一”的实景三维建设能力储备。

三、进一步提升成果质量水平

测绘服务机构应严格按照“多测合一”技术标准出具符合要求的“多测合一”成果，保证其完成的“多测合一”成果数据及报告的真实性和准确性，对测绘成果质量负责，并承担相应法律责任。市规划资源管理部门将进一步加强事中事后监管力度。

（一）启动地形核查机制

当前依托“多测合一”项目为驱动的基础测绘地理信息数据动态更新机制已基本完善，很好地发挥了建设工程测绘成果共享价值，提高了数据现势性和数据更新工作效率。为持续保障“多测合一”项目地形数据成果质量，在总结试点经验的基础上，市规划资源管理部门全面启动“多测合一”事中地形核查机制，严把“多测合一”地形数据成果质量关，更好地保障数字城市、智慧城市建设应用需求。

（二）开展“双随机”监督检查

市规划资源管理部门将联合各相关管理部门，按照“双随机、一公开”监管模式，持续加大“多测合一”成果质量监督检查力度。加快测绘行业信用体系建设，逐步构建守信激励和失信惩戒机制。
