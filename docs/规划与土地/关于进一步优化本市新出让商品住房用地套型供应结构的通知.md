# 关于进一步优化本市新出让商品住房用地套型供应结构的通知

各有关单位：

为更好满足群众刚性和多样化改善性住房需求，促进房地产市场供需适配，进一步优化我市新出让商品住房用地套型供应结构。现就有关事项通知如下：

一、进一步优化新出让商品住房用地中小套型住房建筑面积标准。多层、高层建筑的商品住房中小套型住房建筑面积标准分别调整为120平方米、150平方米。

二、进一步完善新出让商品住房用地套型结构的区域统筹机制。衔接2035城市总规的相关规划目标，由各区综合分析确定具体出让地块的中小套型比例，控制超大户型，一并作为土地出让方案的重要内容，经区政府集体决策后实施。

以上政策自2025年9月10日起执行。

特此通知。

2025年11月20日
