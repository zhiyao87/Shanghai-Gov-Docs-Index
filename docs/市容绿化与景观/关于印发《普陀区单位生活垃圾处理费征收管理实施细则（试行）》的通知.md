# 关于印发《普陀区单位生活垃圾处理费征收管理实施细则（试行）》的通知

各相关单位：

现将《普陀区单位生活垃圾处理费征收管理实施细则（试行）》印发给你们，请结合工作实际，认真贯彻落实。

特此通知。

上海市普陀区绿化和市容管理局

2026年9月1日

普陀区单位生活垃圾处理费征收管理实施细则（试行）

为进一步加强本区单位生活垃圾处理费征收管理，规范收费行为，根据《上海市单位生活垃圾处理费征收管理办法》（沪绿容规〔2026〕1号）等有关文件精神，结合本区实际，制定本办法。

一、征收对象

凡在本区产生生活垃圾的国家机关、企事业单位、社会团体、个体经济组织等，应当缴纳单位生活垃圾处理费，征收对象可委托单位生活垃圾分类投放管理责任人缴费。

二、管理部门

（一）区绿化和市容管理局（以下简称区绿化市容局），负责本区范围内单位生活垃圾处理费征收的组织和管理工作。

（二）区城管执法局，负责对单位未按规定缴纳单位生活垃圾处理费的违法行为责令限期整改，逾期未整改的依法处罚。同时，区城管执法局指导各街镇综合行政执法队对违反生活垃圾分类相关规定的行为进行查处。

（三）区发展改革委、区商务委、区财政局、区审计局、区税务局、区市场监管局、区房管局等部门按照各自职责，协同实施本办法。

（四）各街道（镇）负责所辖区域内单位的生活垃圾分类投放、分类驳运以及相关的分类收集等日常管理工作的具体落实。

三、征收主体

区绿化市容局指定下属事业单位普陀区环境卫生管理服务中心（以下简称征收单位）作为全区唯一合法征收单位，履行主体责任，组织开展征收工作。

四、征收标准

（一）收费性质

单位生活垃圾处理费为经营服务性收费，实行政府指导价管理。

（二）收费标准

标准桶容量为240升，依据《关于普陀区单位生活垃圾处理收费有关事项的通知》（普价管〔2014〕8号）以及《关于优化单位生活垃圾处理费政策的通知》（沪发改价调〔2026〕3号），生活垃圾（干垃圾）36元/桶，生活垃圾（其他厨余垃圾）36元/桶，餐厨垃圾（不含餐厨废弃油脂）54元/桶。若使用非标准桶，按容量体积同比例折算。

（三）收费减免

对特殊教育学校、残疾人集中就业企业、经民政部门备案的非营利性养老机构，免征单位生活垃圾处理费。

其他减免政策，按照市、区最新发布的相关文件规定执行。

（四）正向激励

1.对公园或以公园方式管理的绿地等向社会公众免费开放的非经营性场所，参照《上海市生活垃圾分类情况评估工作方案》，经区级生活垃圾分类现场评估，赋予“绿灯”或“黄灯”的，经区绿化市容局核准后，免征单位生活垃圾处理费。赋予“红灯”的，按照产生量征收。

2.除经民政部门备案的非营利性养老机构外的其他养老机构，参照《上海市生活垃圾分类情况评估工作方案》，经区级生活垃圾分类现场评估，赋予“绿灯”或“黄灯”的，经区绿化市容局核准后，减半征收生活垃圾处理费。赋予“红灯”的，按照产生量征收。

3.对于餐饮熟食和果蔬生鲜两类业态的沿街商铺，参照《上海市生活垃圾分类情况评估工作方案》，经区级生活垃圾分类现场评估，赋予“绿灯”或“黄灯”的，采取正向激励分档标准征收生活垃圾处理费（详见附件1）;赋予“红灯”的，按照产生量征收。同时，根据行业特点，对条件成熟的餐饮企业，探索推行标准桶容器按比例缩小为中、小、小小桶三种形式，按量收取垃圾清运费。

4.除餐饮熟食和果蔬生鲜以外的沿街商铺，严格按照定时定点收运时间、收运方式以及垃圾分类要求交付生活垃圾的，免征单位生活垃圾处理费。如因垃圾分类被城管执法部门立案处罚，或经区级生活垃圾分类现场评估，赋予“红灯”的，按照产生量征收。

五、征收管理

单位生活垃圾处理费征收包括政策告知、申报产生量、核定清运量，签订合同、清运作业、清运量确认、费用支付与结算等环节，全过程均实行信息化管理，确保全过程监管、全透明核量、全链条闭环。

（一）政策告知。各街镇和相关部门应当配合区绿化市容局通过线上线下不同渠道，向辖区内或主管领域的征收对象发放《单位生活垃圾处理费征收告知书》，告知政策依据、征收主体、征收范围、收费标准、收运计量方式、信息化申报查询缴费渠道等。

（二）申报产生量。单位生活垃圾处理费原则上以自然年为核缴周期，实施年度核量。征收对象依据当年度生活垃圾产生量结合清运企业提供的清运量，每年第四季度起，通过“随申办”自行申报下一年度生活垃圾产生量。新办单位，通过“随申办•开店一件事”自行申报当年度生活垃圾产生量。

（三）核定清运量。根据征收对象申报情况，征收单位通过与当年度清运量比对，确定其下一年度生活垃圾清运量，核定征收金额。

（四）签订合同。征收双方根据清运量及征收金额，签订《单位生活垃圾清运收费服务合同》，明确权利和义务。

（五）清运作业。清运企业应当根据合同签订量和清运任务单，开展清运作业服务。清运企业应当每月向征收单位报送实际清运量。

（六）清运量反馈。征收单位将实际清运量通过“随申办”定期推送至征收对象进行动态提醒。如征收对象对实际清运量有异议的，应及时向征收单位提出，双方开展复核确认工作。

（七）费用支付与结算。合同签订后，征收单位按合同约定开具符合规定的票据，征收对象在约定期限内缴费。合同期满后，发送《单位生活垃圾处理费结算确认单》，开展结算工作。

六、缴退费管理

（一）缴费方式。原则上有对公账户的征收对象应通过对公转账缴费，无对公账户的沿街商铺、个体经营者可通过合同附带的缴费二维码扫码支付。确有线上缴费困难的，可至征收单位财务部门线下缴费。

（二）结算方式

1.实际年清运量大于合同签订量的，超出部分签订补充协议，由征收对象补缴相应费用;

2.实际年清运量小于合同签订量的，征收对象可选择以下两种方式之一结算：

（1）仍按合同金额结算，清运量结余部分结转至下一年度使用;（2）按实际年清运量结算，如涉及退费，征收对象应在合同期满后一个季度内提交申请，相关费用按原缴费路径退还。

（三）特殊情况。因停业停产等原因导致垃圾收运服务未正常开展的情况，征收对象可向征收单位提交退费申请，并提供缴费凭证、情况说明等证明材料，征收单位审核同意后办理退费。

七、违法行为处罚

征收对象未按规定申报产生量、未按规定缴纳单位生活垃圾处理费、未落实收运签约等影响征收管理的情形，由征收单位督促整改，对涉嫌违反生活垃圾管理法律、法规、规章规定，属于城市管理执法部门职责范围的，征收单位应当及时移送相关线索，由城市管理执法部门依法查处;征收单位与征收对象已依法签订服务合同的，征收对象未按合同约定支付费用的，合同当事人可以依法通过协商、调解、仲裁或者诉讼等方式解决。

征收单位工作人员应当履职尽责。对玩忽职守、徇私舞弊、滥用职权、占用挪用生活垃圾处理费、违反票据管理规定、未按照规定明码标价、不执行政府指导价以及违规收取保证金、抵押金等违法违规行为，按照有关法律法规依法查处追责;情节严重构成犯罪的，移送司法机关、监察机关依法追究刑事责任。

八、施行日期

本办法自2026年10月1日起施行，有效期至2028年9月30日。实施过程中如遇国家、本市及上级主管部门政策调整，从其规定，并按程序修改本办法。

九、名词解释

依据《上海市生活垃圾管理条例》《上海市餐厨垃圾处理管理办法》及《上海市生活垃圾分类情况评估工作方案（2026年度）》，本办法中下列用语的含义为：

赋予“绿灯”，是指经现场评估为表现良好，给予鼓励肯定。

赋予“黄灯”，是指经现场评估存在少量问题，予以警示提醒。

赋予“红灯”，是指经现场评估问题突出，限期完成整改。

其他厨余垃圾，是指农贸市场、农产品批发市场产生的蔬菜瓜果垃圾、腐肉、肉碎骨、水产品、畜禽内脏等。

餐厨垃圾，是指居民日常生活以外的食品加工、饮食服务、单位供餐等活动中产生的食物残余和食品加工废料。

附件

沿街商铺正向激励分档标准

一、餐饮熟食店生活垃圾处理费按面积收取（如有产证，按照产证面积收取，如没有产证，按照租赁面积收取）：

1.60平方米以下（含60平方米）的，不予收取;

2.60平方米至120平方米（含120平方米）的，餐厨垃圾按照5桶/月计量收取，干垃圾按照5桶/月计量收取;

3.120平方米至180平方米（含180平方米）的，餐厨垃圾按照7桶/月计量收取，干垃圾按照7桶/月计量收取;

4.180平方米以上的，按实际产生量收取。

二、生鲜果蔬店生活垃圾处理费仅针对其他厨余垃圾按面积收取（如有产证，按照产证面积收取，如没有产证，按照租赁面积收取）：

1.30平方米以下（含30平方米）的，不予收取;

2.30平方米至90平方米（含90平方米）的，按3桶/月计量收取;

3.90平方米至150平方米（含150平方米）的，按4桶/月计量收取;

4.150平方米以上的，按实际产生量收取。

按面积分档收费，系基于本区餐饮熟食店、生鲜果蔬店历史垃圾产生量数据的平均估算值。

征收对象也可向征收单位申请按实际产生量收费，不再适用面积分档收费。
