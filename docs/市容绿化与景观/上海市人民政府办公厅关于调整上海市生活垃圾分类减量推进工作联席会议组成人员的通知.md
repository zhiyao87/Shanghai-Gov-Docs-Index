# 上海市人民政府办公厅关于调整上海市生活垃圾分类减量推进工作联席会议组成人员的通知

各区人民政府，市政府有关委、办、局：

经市政府研究，决定调整上海市生活垃圾分类减量推进工作联席会议（以下简称“联席会议”）组成人员，调整后的联席会议组成人员如下：

王　桢　市住房城乡建设管理委副主任、市房屋管理局局长

冯力虎　市邮政管理局局长

联席会议下设办公室（设在市绿化市容局），办公室主任由王为人同志兼任，办公室常务副主任由邓建平同志兼任，办公室副主任由市住房城乡建设管理委副主任金晨、市商务委副主任刘敏、市绿化市容局副局长唐家富担任。

今后，联席会议副召集人、成员和办公室主任、常务副主任、副主任职务如有变动，由其所在单位接任领导自然替补。
