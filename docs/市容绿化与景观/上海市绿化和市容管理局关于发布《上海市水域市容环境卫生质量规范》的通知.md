# 上海市绿化和市容管理局关于发布《上海市水域市容环境卫生质量规范》的通知



为进一步提升上海市的水域市容环境卫生管理水平，提高水面环境卫生的保洁质量，我局编制的《上海市水域市容环境卫生质量规范》经审查批准，现予以发布，编号为LHSR03-2014，请各有关单位在水域市容环境卫生管理和保洁作业中遵照执行。
2014年4月1日
