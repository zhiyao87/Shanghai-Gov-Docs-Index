# 上海市绿化和市容管理局关于发布《上海市环卫电动机具技术要求》的通知



各有关单位：
为推进市容环卫作业机械化发展，确保环卫电动机具作业安全，提高环卫作业服务水平，上海市绿化和市容管理局编制了《上海市环卫电动机具技术要求》（编号：LHSR03-2012），现予以发布，请各有关单位在环卫电动机具的配置中遵照执行。
