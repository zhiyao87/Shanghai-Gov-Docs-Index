# 上海市绿化和市容管理局关于公布第二批上海市森林乡村名单的通知

各涉林区绿化市容局：

为贯彻落实市委、市政府决策部署，抓好《上海市农村 人居环境优化提升行动实施方案》（沪委办〔2022〕17号）落实，根据《上海市森林乡村评价认定办法》（沪绿容〔2023〕49号）和《上海市森林乡村评价认定工作方案》（沪绿容〔2023〕51号），经各区林业主管部门推荐，我局组织评审、公示、审查，现对第二批43个上海市森林乡村名单予以公布（见附件）。

各区要以建设上海市森林乡村为契机，加快乡村绿化美化，促进村容村貌提升，建设美丽宜居乡村，为实施乡村振 兴战略和农村人居环境整治作出积极贡献。

特此通知。
