# 关于印发《普陀区生活垃圾分类提质增效三年行动计划（2026—2028年）》的通知

各相关单位：

现将《普陀区生活垃圾分类提质增效三年行动计划（2026-2028年）》印发给你们，请结合实际认真贯彻落实。

上海市普陀区绿化和市容管理局

2026年9月4日

普陀区生活垃圾分类提质增效三年行动计划

（2026—2028年）

为深入贯彻习近平总书记关于垃圾分类工作重要指示批示精神，根据《上海市生活垃圾分类提质增效三年行动计划（2026—2028年）》要求，推动本区生活垃圾分类提质增效，按照区委、区政府总体部署，结合本区实际，特制定本行动计划。

一、主要目标

到2028年，全区湿垃圾分出占比稳定在35%以上，湿垃圾分出纯净度达到95%;每年“友好化”升级改造小区投放点比例不少于10%，推进重点精细化分类公共场所不少于6个;实现源头物码垃圾交付数字化管理及智慧收运线路建设全覆盖;“公益投放”和“惠民回收”服务广泛覆盖，低价值可回收物占可回收物总量25%以上，新增自助回收箱不少于60个，生活垃圾回收利用率达到48%。

二、主要任务

（一）提升源头管理，持续巩固分类实效

1.升级分类投放环境。因地制宜持续推进老旧投放点“友好化”升级改造，规范临时投放点设置，杜绝露天摆放垃圾桶，配齐洗手、通风、除臭等便民设施，优化投放体验。由“居（村）委会、街镇、区”三级确认改造点位，改造完成后由街镇确定维护管养主体，确保各类投放设施常态完好。（责任单位：区绿化市容局、区房管局，各街镇）

2.强化分类投放管理。健全小区、单位等各类场所垃圾分类管理制度，优化“3+N”管理模式。“3”是各行业主管单位、市级和区级绿化市容部门、各街镇三级联动管理。“N”是根据实际情况，明确“一小区一方案”，细化治理措施;推进以分类实效为导向的弹性投放制度，充分听取居民意见，分类实效较好的小区，可以设置误时投放点;分类实效较差的小区应严格执行定时投放制度，聚焦早晚高峰等重点时段，组织志愿者开展现场宣传引导，有力有序推动小区生活垃圾分类工作。科学优化公共区域废物箱布局，推进重点公共场所精细化分类样板区建设。（责任单位：区绿化市容局、区房管局、区文化旅游局、区商务委、区教育局、区卫生健康委、区机管局，各街镇）

（二）规范收运作业，提高智慧化管理水平

1.推进源头物码全覆盖工作。生活垃圾投放点采取“一点一码”，干垃圾交付压缩站时逐一扫码登记，实时记录干垃圾来源小区、交付时间及交付量等关键指标，有效杜绝来源不清和混装混运情况。小区湿垃圾清运交付时，开展扫码登记，为湿垃圾纯净度管理提供数据支撑。针对企事业单位和沿街商铺，探索“一店一码”收运机制，为企事业单位干湿垃圾交付点构建专属数字编码，准确统计干湿垃圾收运量，为征收费工作提供数据支撑，实现全区生活垃圾“扫码交付—品质监控—异常追溯”收运全过程闭环链条。（责任单位：区绿化市容局、区数据局、区房管局、区城管执法局，各街镇，城投公司、西部集团）

2.深化垃圾清运综合治理。生活垃圾智慧收运全覆盖，全面实现智能监控、路线优化、到站提醒等一体化智慧收运功能。进一步优化小区湿垃圾“内投外运”、干垃圾“直运到站”收运模式，探索推行干垃圾“以桶换桶”等清运方式，规范小区生活垃圾清运作业流程。严格对照《生活垃圾收运车辆技改指引表》，有序推进清运车辆升级改造。（责任单位：区绿化市容局、区房管局，城投公司、西部集团、各街镇）

3.规范中转设施运营。完善湿垃圾中转站品质监控系统，减少误识别、图像阴影等问题，强化问题溯源追踪。推进非环卫权属小型压缩站标准化改造，配齐消毒除臭、噪声管控等配套设施，严格落实环境卫生、监测等管控要求。规范有害垃圾全流程管控，严格落实中转站专人管护、空间封闭、防雨防晒、防渗防漏、分类储存、标识规范等标准化建设与常态化管理要求。（责任单位：区绿化市容局、区生态环境局，各街镇）

4.优化单位生活垃圾征收费体系。制定单位生活垃圾征收费管理实施细则，构建并完善“政策引领—数据融合—平台支撑”的单位生活垃圾征收费管理体系。通过“随申办”应用场景，推动征收对象线上签约和商业综合体物业统一签约，提升征收费覆盖面和清运核算准确性。持续深化“一网通办”“一网统管”建设，完成征收费系统信息化升级改造，安装清运车辆升级版智能设备，落实生活垃圾产生单位年度总量核销、“物码”管理，提升全流程数字化管理能级。（责任单位：区绿化市容局、区数据局，各街镇，城投公司、西部集团）

（三）健全回收体系，提升资源循环利用能级

1.提升低价值可回收物托底保障能力。强化低价值可回收物名录宣传培训，夯实托底回收基础。增设小区垃圾投放点可回收物收集设施，拓展收纳堆放空间。鼓励主体企业与小区保洁员协作，建立低价值可回收物定点回收模式。压缩站工作人员兼任低价值可回收物回收专员，提升低价值可回收物分出效能。（责任单位：区绿化市容局、区房管局，各街镇，城投公司、西部集团）

2.引导和激励居民自主分类可回收物。完成小区公益回收布点，优化完善三种有偿服务模式，即惠民回收、智能回收、流动回收，实现可回收物“公益投放”行为激励与“惠民回收”有偿服务全域覆盖。运用碳普惠机制，激励个人开通碳账户，积累碳积分兑换绿色权益，引导群众主动规范投放可回收物。（责任单位：区绿化市容局、区房管局、区生态环境局，各街镇，西部集团）

3.构建可回收物全链条闭环管理体系。优化主体企业运营监管评议，加强源头回收、中转规范化管理。持续深化生活垃圾分类与再生资源回收“两网融合”，畅通数据互通共享渠道。以市级可回收物公共服务平台为载体，统一计量管理标准。建设低价值可回收物中转站，推动可回收物“点站场”合理布局。（责任单位：区绿化市容局、区规划资源局、区商务委，各街镇）

4.夯实装修垃圾管理体系。优化管理制度，制定装修垃圾管理办法，夯实装修垃圾清运处置体系。强化装修垃圾源头管理，落实每个居住区4处清运企业和价格“双公示”，探索物业企业相关信息、短驳信息等联合公示;推动三种收运“新模式”管理，将临时堆放模式转变为箱式收运模式。扩大“个人直约清运”服务模式覆盖面，实现早送晚收的箱式收运服务模式。优化装修垃圾运输分拣管理，全面推进运输车辆涂装，提升车容车貌;探索以“居民（物业）预约、源头开单、全程路线追踪、末端销单”为核心举措的全链条管理模式;稳步提升装修垃圾中转场所环保设备能级。（责任单位：区绿化市容局、区房管局、区城管执法局，各街镇，城投公司、西部集团）

5.完善大件垃圾清运处置体系。健全管理制度，制定大件垃圾管理办法，优化完善大件垃圾收运处置体系。通过拓展现有场地空间等方式，确保可回收利用的废旧金属、废旧木材等纳入回收体系，其余残渣统一实施无害化处置，稳步提升大件垃圾回收利用率。依托装修垃圾预约平台，探索开通大件垃圾“个人直约清运”服务渠道。采用固定点位投放与专项回收日集中投放相结合的方式，定期开展大件垃圾专项整治行动。有序做好街面大件垃圾清运保障，规范企事业单位大件垃圾管理。（责任单位：区绿化市容局、区房管局、区城管执法局，各街镇，城投公司、西部集团）

（四）加强社会共治，营造全民参与良好氛围

1.做强垃圾分类基层治理机制。深化党建引领，健全完善居村党组织统筹领导、物业服务企业履职尽责、多方协同参与的生活垃圾分类工作机制。切实做好垃圾分类组织发动、宣传引导等工作。督促物业服务企业增强保洁力量，严格落实分类容器配置、日常宣传引导、分类驳运中转等主体责任。推动分类投放“一小区一方案”纳入小区管理规约。持续引导居民养成自主分类、规范投放的良好习惯，降低对保洁人员辅助分类的依赖。（责任单位：区委组织部、区委社会工作部、区房管局、区绿化市容局，各街镇）

2.强化宣传教育动员引导。做优社会宣传矩阵，依托重大赛事、地铁公交、旅游景区、公园绿地、宾馆酒店、商务楼宇电梯等各类宣传阵地，常态化开展垃圾分类主题宣传，广泛推广上海专属垃圾分类IP形象。强化重点群体宣教，持续发挥机关事业单位示范引领作用;聚焦房屋租赁、家政服务、文旅出行等关键环节，精准强化垃圾分类宣传引导。做实科普教育赋能，充分用好垃圾分类主题公园等宣教阵地资源，提升科普体验。常态化开展垃圾分类科普“七进”活动，将垃圾分类知识融入爱心寒暑托班日常教学，全面提升全民分类知晓度与参与度。（责任单位：区委宣传部、区机管局、区卫生健康委、区商务委、区文化旅游局、区体育局、区教育局、区房管局、区绿化市容局、团区委，各街镇）

3.充分发挥志愿服务作用。完善生活垃圾分类志愿者组织体系，充实区级志愿者服务支队和10支街镇服务大队力量，擦亮垃圾分类志愿服务项目“一街镇一品牌”，推动绿色发展。组织志愿服务，做好定点值守、投放指导、入户宣传、关爱帮扶等工作，加大对优秀志愿服务工作者的正面宣传力度。（责任单位：区委宣传部、区委社会工作部、区绿化市容局，各街镇）

4.强化执法检查。加强生活垃圾分类普法宣传，加大重点区域执法检查力度。强化行业监管，严格督促旅游住宿业不主动提供一次性用品、餐饮服务业严控限制类一次性餐具供给。深化管执联动，推广简易执法、快处快办、非现场执法取证等监管模式，加大典型违法案例曝光力度，强化警示震慑效应。（责任单位：区城管执法局、区文化旅游局、区市场监管局，各街镇）

三、保障措施

织密区、街镇、居村三级管理网络，完善部门协作机制，定期开展联合执法和专项检查。各街镇落实属地管理责任，做好日常推进和基础保障，精准施策推进工作落地。充分发挥资金支持引导作用，重点支持垃圾分类实效提升、设施建设和更新、设备升级和维护、低价值可回收物补贴、资源综合利用、宣传教育和志愿服务等工作。
