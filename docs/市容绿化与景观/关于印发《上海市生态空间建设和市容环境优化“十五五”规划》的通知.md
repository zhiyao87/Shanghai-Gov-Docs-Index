# 关于印发《上海市生态空间建设和市容环境优化“十五五”规划》的通知

各区人民政府，市政府各委、办、局，各有关单位：

《上海市生态空间建设和市容环境优化“十五五”规划》已经市政府同意，现印发给你们，请认真按照执行。

特此通知。

上海市绿化和市容管理局

2026年7月30日

上海市生态空间建设和市容环境优化“十五五”规划

为加强生态空间建设、优化市容环境，推动绿化市容行业高质量发展，根据国家战略部署及《上海市国民经济和社会发展第十五个五年规划纲要》要求，立足本市实际与民生发展需要，制定本规划。

一、发展目标

以习近平新时代中国特色社会主义思想为指导，深入贯彻党的二十大和二十届历次全会精神，全面贯彻习近平生态文明思想，牢固树立和践行绿水青山就是金山银山的理念，认真践行人民城市理念，坚持保护优先、城乡统筹，城绿融合、提质增效，精细治理、服务民生，以高品质生态空间和优美市容环境，助力打造人与自然和谐共生的美丽中国上海典范。到2030年，初步建成具有超大城市特点的“自然共生、城园共融、全民共享”的“公园城市”和“整洁美观、精致温馨、流光溢彩”的“洁净城市”。基本形成全域覆盖、布局合理、功能完善、品质优良的城乡公园体系，林廊环绕、林城融合、共生共享的都市森林体系，资源化、智慧化、精细化的环境卫生治理体系，打造高品质绿化和市容环境。

二、深化公园城市建设，绘就绿色生态新画卷

（一）启动新一轮公园建设

结合区域人口空间布局和公园绿地服务盲区，优先匹配差异化功能设施，保障居民就近休闲服务供给。结合重点生态网络空间、“一江一河一带”、虹桥国际中央商务区、大吴淞、东方国际枢纽、中城地带等重点区域，推动吴淞中央公园前期论证研究，建设一批高品质公园。通过插绿建园、存量提升开放等方式推进口袋公园、休闲森林公园建设。高水平推进环城生态公园带建设，编制环城生态公园带实施方案，推动外环绿道主脉贯通工程，推进新城绿环建设贯通，推动三岔港楔形绿地前期论证研究。充分利用城市边角地、灰色基础设施等空间增加绿量，新增立体绿化50万平方米，主城区公园绿地服务半径覆盖率超93%。结合公园绿地建设，落实海绵城市理念，增加疏林草地景观，加强绿地生境营造，构建近自然群落，加大推广应用乡土适生树种和地产草种力度，提升城市生物多样性水平。持续推进上海辰山国家植物园建设工作。

专栏2  新一轮公园建设工程

1. 新建及改造公园建设工程
建设和提升一批具有标杆性的重点绿地项目，开展存量品质提升，进一步完善城乡公园布局。开展市属公园的服务配套设施提升改造工程。结合公园地形营造协同消纳土方，加强绿地生物多样性保护与生境营建。

2. 环城生态公园带建设工程
“环内”结合政策创新，推动三岔港楔形绿地建设前期论证研究。“环上”持续提升功能服务，重点推进外环绿道主脉贯通，打通大型市政道路、铁路和河道断点，打造重要活力节点，协同推进“十字象限”节点建设。全面推进五个新城绿环建设。

3. 上海辰山国家植物园建设工程
编制上海辰山国家植物园建设方案，启动植物迁地保护、植物资源可持续利用等7类建设项目，全面提升保护、科研、科普、园艺和社会服务等功能。联合华东地区植物就地保护机构，构建迁地保护与就地保护“双轨”体系，形成区域植物多样性保护网络，加强濒危机制和繁殖生物学研究，建立“调查—研究—回归—种群重建”的保护体系。打造现代植物利用的多组学研究中心，建立从基础研究、关键技术到转化应用的贯通体系。巩固升级一批科普文化品牌，建设5个高水平特色专类园，形成可复制可推广的专类植物展示区建设与运营范式。

（二）推动城园无界融合

优化公园边界形态，统筹优化慢行空间、城市家具与绿化景观。持续加大单位附属绿地开放共享力度，优化开放共享模式，实施开放附属绿地100处以上。协同推进社区生境花园建设，精准激活闲置绿地资源。高水准举办全民义务植树及认建认养活动。健全古树名木保护体系，加强复壮与保护设施维护，推进新一轮资源普查与“一树一园”建设。加强绿地生态系统调查和监测体系建设。

（三）促进公园提质增效

将公园建设融入城市发展，积极践行“公园+”和“+公园”理念，改善生态景观质量，降低城市碳排放，助力区域碳中和目标实现。加快全龄友好的公园基础设施服务能力提升，倡导公园多功能复合，推进老旧公园设施升级，以公园为基底融入运动健身、文化休闲、科普学习、宠物友好、平急两用等功能，有机嵌入餐饮、休闲等各类便民设施。强化公园特色品牌建设，充分挖掘历史文化内涵，提升人文品质和吸引力，在徐汇西岸推进上海白玉兰文化公园建设，以上海滨江森林公园为基底，打造具有代表性的上海市儿童公园。深化公园绿地精细化管理，实施分级分类差异化管控，健全全生命周期管理机制；加快智慧公园监管平台建设，融合视频监控、大数据、物联网等技术，提升智慧化管理水平；推动公园多元协同治理。全面加强公园安全管理，健全公园安全管理体系。推动家庭园艺服务体系建设，优化市民园艺中心服务功能，加强社区园艺师队伍建设。打造上海国际花卉节品牌，促进文商旅体展联动。

（四）推进公园及公共绿地开放共享

公园24小时开放比例达到90%以上。开放草坪的城市公园比例达到80%以上，新增开放草坪200公顷；通过低干预改造，划定弹性游憩型运动空间，使可供开展足球、橄榄球、飞盘等运动健身的普惠型体育绿地达到300处以上，持续扩充市民可使用的体育绿地空间。依托“一江一河一带”大型滨江绿地、节点绿地建设，连片布局开放式体育绿地，打造西岸自然艺术公园（二期）、闵行前湾公园等20处标志性体育绿地。修订印发公园绿地市民健身体育设施管理及设置导则，支持各区推进体育公园建设。

专栏3 公园提质增效及开放共享工程

研究出台并施行公园提质增效实施方案，对城市核心区、商圈周边、社区腹地的公园实施拆墙透绿，构建连接公园与街区、社区、商圈、交通枢纽之间的绿道系统。打造儿童户外游戏空间120处以上，新增篮球场100个以上，乒乓球台100个，新增或提升标准足球场5个，更新健身设施500台（套），宠物友好公园15座。启动上海动物园（包括南美动物展区改造等）、上海野生动物园提质增效建设项目。

三、强化林湿资源保护，构建生态安全新屏障

（五）促进森林资源规模与质量提升

编制《上海市耕地保护和国土绿化空间专项规划（2026—2035年）》。聚焦生态网络空间和生态复合单元，开展生态复合空间综合整治，多途径增加森林面积，林地保有量达到145.1万亩以上，着力提高森林蓄积量。推广应用乡土和适生树种，在新造林中的应用比例不低于85%。持续推进森林可持续经营，实施森林质量精准提升行动，完成公益林抚育面积20万亩。推进林地综合效能提升试点项目，探索森林林相改造、景观塑造与文化传播、林地地形营造等各类社会公共事业有机融合。推进休闲森林公园建设，提升设施供给与服务能级。推进保障性苗圃建设。

专栏4  高品质造林和森林质量精准提升工程

依托生态复合单元，聚焦海岸带、五个新城绿环以及黄浦江—大治河等重要生态廊道，全面推进高品质项目造林。统筹造林与土方利用，净增林地不少于2万亩。进一步完善抚育技术要求，有序开展全市范围公益林抚育，落实20万亩抚育目标。实施老港生态环保基地等林地综合效能提升试点项目。在市域范围内和域外农场（即苏北农场、皖南农场）推进建设1—2个以乡土适生树种为主，耐水湿、耐盐碱和耐瘠薄等抗性树种及彩化树种为补充的保障性苗圃。

（六）推进湿地、自然保护地与野生动植物保护

强化湿地保护体系建设，推进湿地保护立法，完善湿地管理相关制度，加强湿地保护与利用，落实国家湿地管控要求。推进自然保护地体系建设，提升崇明东滩、九段沙等重点区域湿地生物多样性和生态服务功能，开展崇明北湖湿地生态修复工程及维护。推进野生动物栖息地修复和种群恢复。持续巩固互花米草等外来入侵物种除治成效，统筹推进除治区域生态恢复。加强野生动植物保护体系建设，完善资源管理政策制度，提升监测评估智慧化水平。提升崇明区国际湿地城市和崇明东滩世界自然遗产地国际影响力，塑造“崇明东滩观鸟生活季”生态品牌，加强河口湿地和迁徙物种的科学研究。

专栏5  世界自然遗产地和国际湿地城市建设提升工程

统筹推进崇明东滩世界自然遗产地生态保护与修复，构建世界自然遗产保护长效机制，推动崇明东滩自然遗产地展示馆新建工程，搭建社会参与平台，引导有序开展自然教育、观鸟研学等活动。推进北湖湿地生态修复工程，通过地形营造、水位调控等措施，提高湿地生物多样性，提升湿地生态服务功能。持续巩固崇明区国际湿地城市认证成果，推动湿地保护意识融入城市发展全过程。

（七）加强资源生态综合监测和林政执法

健全完善林长制工作机制，健全绿林湿调查监测体系，优化监测站（点）布局。依托林长制数字化平台，构建林业“一张图”，推动数据互联互通和核心业务场景融合，实现林业等生态资源全生命周期闭环管理。优化绿林有害生物、陆生野生动物疫源疫病等监测预警体系布局，提升数据信息化采集水平。加强林地用途管制，推进林地定额合理分配与调控，落实林地占补平衡管理责任。制定完善林业行政处罚裁量权基准与执法规范，依法查处涉林违法行为；牵头开展保护鸟类和打击非法捕猎贩卖野生鸟类等专项行动，严厉打击破坏野生动植物资源违法犯罪。

四、提升全程管理实效，开创垃圾综合治理新局面

（八）优化提升生活垃圾全程分类体系

健全垃圾分类长效机制。开展分类投放设施友好化改造，优化生活垃圾定时定点投放机制。完善大件垃圾清运处置体系建设。构建生活垃圾信息化管理平台，实现设施布局、物流调配、数据分析、实时监管等数字化管理。因地制宜构建惠民回收、智能回收、流动回收等模式的综合回收体系，实现全市居（村）“公益投放”和“惠民回收”服务全域覆盖。按照实际需求，优化中转站、集散场功能设置。优化提升市级可回收物回收公共服务平台，统一计量管理标准，推动数据准确归集；开发碳普惠应用场景，推动生活源可回收物回收利用碳普惠方法学落地。

（九）强化建筑垃圾全过程监管

构建建筑垃圾产消平衡处置体系，结合土地综合整治、生态复合单元建设、绿林地建设等多渠道拓展土方消纳空间，持续印发土方消纳空间选址规划（图则指引）；加强建筑垃圾消纳场所和处置设施建设，结合南汇东滩、横沙新洲等造林和土地综合整治项目积极开展土方综合利用；完善土方跨区转运消纳补偿机制，加强土方暂存和回填利用；优化水运码头布局，提升土方水路运输能力。强化源头工地减量和监管，压实建设单位、设计单位、施工单位主体责任；强化运输监管，推广专业化车辆和信息化装备；优化上海市建筑垃圾数字化智能监管平台，推行建筑垃圾全过程电子联单管理，建筑垃圾数字化监管覆盖率达到90%以上；严厉打击建筑垃圾违法违规排放、运输、处置等行为。优化装修垃圾收运服务，加强源头投放、清运预约、运输处置规范管理，落实物业服务单位责任。

（十）推进垃圾深度资源化利用

全面落实近零填埋。提升湿垃圾资源化利用水平，推进湿垃圾项目产沼气制绿色燃料试点。持续探索湿垃圾生物转化后产品应用；提升餐厨废弃油脂处置能力和韧性，探索高值化利用。推动生活垃圾焚烧设施优化升级，新增飞灰资源化能力约700吨/日，提升炉渣资源化能力，焚烧残渣资源化利用率达到99%；降低单位生活垃圾处理碳排放强度。推进土方、泥浆资源化利用设施建设，推广建筑垃圾资源化产品应用；推进老港再生建材预处理项目建设，实现装修和拆房垃圾分拣残渣零填埋。推动老港生态环保基地整体功能提升，研究江桥焚烧厂升级改造，实现“一主多点”垃圾处置设施托底保障向综合循环利用示范跨越。

专栏6  环境卫生设施提升工程

推进生活垃圾处置设施提标升级，实施生活垃圾焚烧设施飞灰资源化技术改造工程及烟气提标改造。推进老港生态环保基地能级提升，建设渗滤液污泥干化及协同处置、填埋气综合治理及利用、再生建材预处理等项目，新增再生资源利用项目，提升基地公共配套。推进市区两级建筑垃圾消纳场所、资源化利用设施及配套设施建设。迭代升级数字化智能监管平台，提升全链条监管能级。

五、加强城市精细管理，打造市容景观新标杆

（十一）着力提升市容环境品质

深化“美丽街区”建设和巩固提升。持续推进公共空间休憩座椅优化提升。持续打造市容环境综合管理示范街镇样板，带动面上环境提质增效。强化重大活动市容环境保障。深化户外广告招牌精细管理，持续推进各区户外广告设施设置实施方案修编工作。全面推进户外招牌多样化、个性化和艺术化设置，组织落实“一江一河”滨水公共空间、主要道路和景观区域、历史风貌区等重点区域户外招牌设置导则，提升重点区域户外招牌品质。户外招牌设置审批（备案）率达到90%以上。

专栏7  美丽街区提质工程

统筹道路设施、建筑立面、沿街绿化、路面保洁等，进行全要素、一体化建设提升。打造“美丽街区+文旅”“美丽街区+商业”“美丽街区+生态”的新模式，放大“美丽街区”溢出带动作用。

（十二）建成夜景新地标新秀带

贯彻落实《上海市景观照明规划（2024—2035年）》。深度培育上海国际光影节品牌。推进重点区域景观照明建设与更新，全面建成“一江一河”“申”字型高架沿线景观照明，基本建成城市主中心、重要商圈、“五个新城”中心区已建成区域的景观照明。深化景观照明全生命周期管理，建立数字化智慧照明管控系统，提升黄浦江两岸景观照明智能化监控水平。加强节能低碳管理，景观照明节能灯具使用率达到98%以上。探索减少景观照明光干扰对生物多样性的影响。

（十三）推进市容景观专项治理工作

强化小微空间、背街小巷等薄弱区域市容环境整治，开展农村地区环境容貌专项提升。实施户外设施安全监管行动，健全户外设施全过程监管体系，公益性、商业性（含经营性和自设性）户外广告设施安全检测年抽检率分别达到10%、5%以上，户外招牌安全检测年抽检率达到35%以上。强化设摊综合治理，打造高品质外摆位，遏制无序设摊聚集点回潮。加强城市保洁管理，推动公共厕所开放共享与服务能级提升，结合市民游客需求，进一步优化公共厕所布局，提高公共厕所的可达性和标识度。试点推广24小时开放环卫公厕夜间厕位自动化保洁。市管水域保洁优良率达到95%。

六、深化区域协同共进，科技赋能行业新融合

（十四）加强长三角生态绿色一体化发展

推进生态屏障生态廊道共同保护，加强长江口等河口与湿地保护，提高区域生态廊道连通性。建立长三角林业行政执法协作机制。发挥长三角区域建筑垃圾联防联治机制作用，提升跨区域协同监管效能。深化长三角区域水生植物协同治理，实现跨区域高效打捞处置。

（十五）加强科技赋能与行业资源融合

优化科研项目组织机制和攻关布局，分类分层开展科技攻关和推广应用，推动科技成果高效转化。加强科研平台建设管理与统筹协调，推动平台互联互通与数据共享。整合行业科普资源，提升科普品牌影响力。夯实空间数据底座，构建统一权威、动态更新的行业空间“一张图”。深化AI赋能增效，围绕垃圾全流程监管、林业资源保护与灾害防控、公园绿地智慧服务与管理等重点领域，开展垂类大模型应用的前期研究。

专栏8  科普教育能级提升工程

统筹推进协同联动机制，构建全域科普矩阵，打造“公园+科普”“暗访夜精灵”等特色品牌IP体系，实现科普内容覆盖绿化、林业、环境卫生及市容景观全领域，传播渠道联动线上线下全域场景，公众参与渗透全龄群体，推动行业科普从单向输出向全民共建转型。

七、创新管理运营模式，迸发生态资源新活力

（十六）创新公园运营管理

创新多元市场化经营方式，鼓励社会力量参与公园运营服务。盘活公园房屋资源，创新用地保障政策，活化利用场地空间。创新运管机制，加强公园业态管理，支持文创开发，建立公园定期体检评估制度，激发全域公园活力。推动上海动物园、上海野生动物园等重点综合公园高质量发展。

（十七）提升林地复合功能，促进林下经济高质量发展

推进林地空间复合利用。深化推进林业综合改革，探索都市型林下经济发展模式，持续完善相关保障政策，研究森林生态价值多元转化路径。盘活林地周边存量房屋与设施，植入文化、科普、创意商业等功能，营造新型消费场景。鼓励农村集体经济组织、新型林场等经营主体开展多种形式的适度规模经营，探索林下种植等复合经营模式。鼓励各类企业参与林业投资经营，建立联农带农机制。

（十八）探索绿色生态产品价值实现机制

建立绿林湿生态产品调查和监测管理制度，开展生态产品价值核算研究，推动建立森林生态服务功能价值核算标准、森林与湿地碳储核算标准。探索森林碳汇、林业金融、生物多样性银行等价值转化路径，拓展绿色生态产品价值实现模式。加强行业工程监督管理，推进公园绿地和公益林养护降本增效。探索城市生态空间再野化实践。

专栏9  绿林湿复合生态智慧监测与价值核算体系建设项目

新建绿地生态监测站（点），填补公园、大型绿地等区域监测空白，建立环城绿带生态综合监测体系；增建森林生态监测站（点），重点推进五个新城绿环及大型复合生态单元监测能力提升；补建湿地生态监测站（点），聚焦重要湿地区域，增补湖泊、库塘等类型湿地监测空白，形成“空天地”一体化监测网络。建设全市绿林湿生态数据库，实现数据汇聚、交互和共享。依据国家GEP核算框架，建立本市核算体系，编制发布上海市绿林湿生态系统服务白皮书，持续跟踪绿林湿资源动态变化，科学评价其碳汇能力等生态服务价值。

八、保障措施

坚持和加强党对规划工作的全面领导，树立和践行正确政绩观。健全多部门联动及项目推进协调机制，强化用地、资金等要素保障。推进任务分解落实，实施规划动态评估。加快行业法治建设，完善行业标准体系。探索美丽街区等补贴政策，推动单位垃圾收费改革，研究优化绿化资金渠道，完善资金管理机制。持续优化营商环境。强化科技资源投入，构建科创平台体系，完善成果转化机制，打造科技人才高地。提升社会宣传效能，构筑全媒体传播矩阵。全面深化公众参与，推动行业共治共建共享，凝聚社会各界治理合力。
