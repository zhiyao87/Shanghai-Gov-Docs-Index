# 上海市绿化和市容管理局关于印发《上海市绿化和市容管理局科研项目管理办法》的通知



各相关单位：
为规范科研项目的管理，提高课题研究质量，促进科研成果转化和应用，根据国家及上海相关法规和文件，结合本行业实际，我局制定了《上海市绿化和市容管理局科研项目管理办法》，现印发给你们，请各单位遵照执行。
