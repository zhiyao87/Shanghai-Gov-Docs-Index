# 关于印发《上海市休闲森林公园规划建设导则（试行）》的通知

浦东、宝山、闵行、嘉定、金山、松江、青浦、奉贤、崇明区绿化市容局：

根据《关于实施休闲森林公园支持政策的通知》（沪绿容〔2024〕465 号）要求，本市于2025年启动第一轮休闲森林公园试点项目。为规范有序推进试点项目建设，我局组织编制了《上海市休闲森林公园规划建设导则（试行）》，请遵照执行。

上海市绿化和市容管理局

2025年3月26日
