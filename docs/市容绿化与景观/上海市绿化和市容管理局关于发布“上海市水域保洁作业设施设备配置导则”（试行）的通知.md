# 上海市绿化和市容管理局关于发布“上海市水域保洁作业设施设备配置导则”（试行）的通知



各区（县）绿化市容局、城管执法局，浦东新区环保市容局、市市容环卫水上管理处：
为提高本市水域保洁作业标准化水平，确保水域保洁质量、作业效率和生产安全，特制订“上海市水域保洁作业设施设备配置导则”（试行），现予发布试行，试行期为二年。
试行期间如有意见，请联系市绿化市容局环卫管理处、科技信息处。
联系人：孙鉴、陈立民　　联系方式：52567546、52567168
