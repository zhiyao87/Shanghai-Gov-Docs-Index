# 关于印发《上海市绿化市容行业行政审批管理系统管理要求》的通知

各区绿化市容局、各管委会、机关各处室：

为加强本市绿化市容行业行政审批管理系统的管理，推动政务服务“一网通办”工作，依据《国务院关于在线政务服务的若干规定》文件精神，我局编制了《上海市绿化市容行业行政审批管理系统管理要求》。现印发给你们，请认真按照执行。

上海市绿化和市容管理局办公室

2023年10月25日

上海市绿化市容行业行政审批管理系统管理要求

为加强本市绿化市容行业行政审批管理系统的管理，推动政务服务“一网通办”工作，依据《国务院关于在线政务服务的若干规定》对上海市绿化市容行业行政审批管理系统的管理提出以下工作要求。

一、办事指南管理

市绿化市容局相关业务部门如需对行政审批事项办事指南内容调整的，应向市局行政许可处提出申请，市局行政许可处审核通过后向市政府办公厅提交报备。

各区绿化市容局、受托管委会不得对办事指南内容进行自行调整，但可根据各区、管委会审批改革要求，对“申请材料”和“审批时间”作简化（缩短）调整。

二、审批系统功能管理

市绿化市容局相关业务部门、区绿化市容局、受托管委会如需对审批系统功能新增或调整的，应向市局行政许可处提出申请，市局行政许可处审核后组织实施。

三、审批系统账户管理

市绿化市容局相关业务部门、区绿化市容局、受托管委会及各街镇如需对审批系统使用人账号权限调整的，应向市局行政许可处提出申请，市局行政许可处审核后组织实施。
