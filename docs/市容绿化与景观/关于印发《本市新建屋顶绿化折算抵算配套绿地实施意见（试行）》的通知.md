# 关于印发《本市新建屋顶绿化折算抵算配套绿地实施意见（试行）》的通知



各区县绿化管理部门、规划管理部门及相关单位：
为鼓励社会各方充分利用空间资源，有效增加绿量，改善城市生态环境，市绿化市容局、市规划国土资源局联合制定了《本市新建屋顶绿化折算抵算配套绿地实施意见（试行）》，现印发给你们，请遵照执行。
特此通知。
