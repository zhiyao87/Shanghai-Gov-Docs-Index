# 上海市绿化和市容管理局关于印发《上海市户外招牌设置行政审批告知承诺实施办法》的通知



为进一步优化营商环境，提高本市户外招牌设置准入的便捷性、可操作性，根据《上海市市容环境卫生管理条例》《上海市户外招牌设置管理办法》（市政府令41号公布）、《上海市行政审批告知承诺管理办法》（市政府令4号公布）等规定，制定《上海市户外招牌设置行政审批告知承诺实施办法》，现印发给你们，自2021年3月1日起执行。
附件：上海市户外招牌设置行政审批告知承诺实施办法
上海市绿化和市容
管理局
2021 年2月26日
上海市户外招牌设置行政审批告知承诺实施办法
第一条
（目的和依据）
为贯彻落实《上海市户外招牌设置管理办法》，根据《上海市行政审批告知承诺管理办法》等规定，结合本市实际，制定本办法。
第二条
（定义）
本办法所称的告知承诺，是指本市行政区域内，设置人申请办理户外招牌设置审批时，区绿化市容管理部门一次性告知其审批条件和需要提交的材料，设置人以书面形式承诺其符合审批条件，由区绿化市容管理部门作出审批决定的方式。
第三条
（职责分工）
市绿化市容管理部门是本市户外招牌设置的主管部门，负责户外招牌设置的协调、指导和监督管理工作；
区绿化市容管理部门负责本辖区内户外招牌设置的协调、指导和监督管理工作，并具体承担户外招牌设置行政许可工作。
街道办事处、镇（乡）人民政府在区绿化市容管理部门的指导下，负责本辖区内户外招牌设置的相关具体管理工作。
第四条
（审批依据）
《上海市市容环境卫生管理条例》第二十条第二款规定：户外广告以及非广告的霓虹灯、标语、招牌、标牌、电子显示牌、灯箱、画廊、实物造型等户外设施（以下统称户外设施），应当按照批准的要求设置。
《上海市户外招牌设置管理办法》第十条第一款规定：户外招牌设置应当按照《上海市市容环境卫生管理条例》规定，取得区绿化市容管理部门的批准。
第五条
（适用范围）
区绿化市容管理部门可以采取告知承诺方式实施户外招牌设置审批，但下列情形除外：
（一）在历史文化风貌区或者风貌保护街坊内、风貌保护道路或者风貌保护河道沿线、文物保护单位或者优秀历史建筑上设置；
（二）设置箱体式整体结构户外招牌、大型垂直外墙式户外招牌或者高度大于2.5米的独立式户外招牌；
（三）超过建（构）筑物3层或者在建（构）筑物10米以上部位设置；
（四）市人民政府确定的可能影响公共安全的其他情形。
第六条
（审批条件）
本行政审批事项获得批准应当符合《上海市户外招牌设置技术规范（2021版）》明确的有关户外招牌的设置位置、规格、数量、内容规范，以及设计、制作、施工安装、维护保养、安全检测等要求。
第七条
（申请材料）
申请人应当提交下列材料：
（一）户外招牌设置申请表；
（二）法定代表人（负责人）身份证、委托代理人身份证、委托代理书；营业执照、事业单位（社会团体）法人证书、民办非企业单位登记证书或其他合法主体证书等；涉及建筑物名称的提交地名管理部门批准建筑物名称的相关文件（本市政府部门核发的免于提交）；
（三）设置户外招牌的建（构）筑物、场地的产权证书或使用协议（本市政府部门核发的免于提交）；
（四）户外招牌设置效果图（申请时可以免于提交）。
第八条
（行政审批机关的告知）
对户外招牌设置行政审批告知承诺的事项，区绿化市容管理部门收到申请后，应当通过告知承诺书，向申请人告知下列内容：
（一）行政审批事项所依据的主要法律、法规、规章的名称和相关条款；
（二）准予行政审批应当具备的条件、标准和技术要求；
（三）需要申请人提交材料的名称、方式和期限；
（四）申请人作出承诺的时限和法律效力，以及逾期不作出承诺、作出不实承诺和违反承诺的法律后果；
（五）区绿化市容管理部门认为应当告知的其他内容。
申请人当面递交申请的，区绿化市容管理部门应当当场发给告知承诺书；申请人通过信函、电传、传真、电子数据交换和电子邮件等方式提出申请的，区绿化市容管理部门应当在收到申请后3个工作日内，向申请人提供告知承诺书。
第九条
（申请人的承诺）
申请人收到行政审批告知承诺书后，愿意作出承诺的，应当在被告知的期限内填写申请人基本信息，并对下列内容作出确认和承诺：
（一）所填写的基本信息真实、准确；
（二）已经知晓行政审批机关告知的全部内容；
（三）自身能够满足行政审批机关告知的条件、标准和技术要求；
（四）愿意承担不实承诺、违反承诺的法律责任；
（五）所作承诺是申请人真实意思的表示。
第十条
（审核与决定）
申请人向区绿化市容管理部门提交许可申请，愿意采取告知承诺方式的，在收到告知承诺书之日起3个工作日内作出承诺，并向区绿化市容管理部门提交经申请人签章的告知承诺书，还应同时提交本办法第七条第（一）至第（三）项申请材料。
申请人向区绿化市容管理部门提交的告知承诺书，经区绿化市容管理部门和申请人双方签章后生效，由双方各保存一份。区绿化市容管理部门应该在收到申请人按照本条第一款要求提交的符合要求的材料后，当场作出行政审批决定。
申请人不能提交上述规定的全部材料或者提交的材料不符合要求的，不予受理。
申请人不愿意采取告知承诺方式的，区绿化市容管理部门按照法规、规章规定的程序和条件实施行政审批。
第十一条
（文书和证书的送达）
区绿化市容管理部门应当在作出行政审批决定后依法送达行政许可证件，可当场发放的应当场发放。
第十二条
（后续监管）
在作出准予行政许可的审批决定后2个月内，区绿化市容管理部门对被审批人的承诺内容是否属实，按照本办法第六条规定的审批条件的要求组织核查，发现实际情况与承诺内容不符的，应当要求限期整改；逾期拒不整改或者整改后仍不符合条件的，依法撤销行政审批决定并送达被审批人。
第十三条
（诚信档案）
被审批人在规定期限内未提交材料，或者提交的材料不符合要求的，以及区绿化市容管理部门在审查和后续监管中发现申请人、被审批人作出不实承诺或者违反承诺的，区绿化市容管理部门应当记入申请人、被审批人诚信档案，并对该申请人、被审批人不再适用告知承诺的审批方式。
第十四条
（施行日期）
本办法自2021年3月1日起施行。

附件2
行政审批机关的告知（样张）
按照《上海市行政审批告知承诺管理办法》，本行政审批机关就行政审批事项告知如下：
一、审批依据
《上海市市容环境卫生管理条例》第二十条第二款规定：户外广告以及非广告的霓虹灯、标语、招牌、标牌、电子显示牌、灯箱、画廊、实物造型等户外设施（以下统称户外设施），应当按照批准的要求设置。
《上海市户外招牌设置管理办法》第十条第一款规定：户外招牌设置应当按照《上海市市容环境卫生管理条例》规定，取得区绿化市容管理部门的批准。
二、法定条件
本行政审批事项获得批准应当符合《上海市户外招牌设置技术规范（2021版）》明确的有关户外招牌的设置位置、规格、数量、内容规范，以及设计、制作、施工安装、维护保养、安全检测等要求。
三、应当提交的材料
根据审批依据和法定条件，本行政审批事项获得批准，申请人应当提交下列材料：
（一）户外招牌设置申请表；
（二）法定代表人（负责人）身份证、委托代理人身份证、委托代理书；营业执照、事业单位（社会团体）法人证书、民办非企业单位登记证书或其他合法主体证书等；涉及建筑物名称的提交地名管理部门批准建筑物名称的相关文件（本市政府部门核发的免于提交）；
（三）设置户外招牌的建（构）筑物、场地的产权证书或使用协议（本市政府部门核发的免于提交）；
（四）户外招牌设置效果图（申请时可以免于提交）；
申请人通过告知承诺方式办理的，提交第（一）至第（三）项材料；第（四）项材料申请时可以免于提交。
四、承诺的期限和效力
申请人愿意作出承诺的，在收到本告知承诺书之日起3个工作日内作出承诺。
申请人作出符合上述申请条件的承诺，并提交签章的告知承诺书后，行政审批机关将当场作出行政审批决定。
申请人逾期不作出承诺的，行政审批机关将按照法律、法规和规章的有关规定实施行政审批。
被审批人作出不实承诺的，行政审批机关将依法作出处理，并由被审批人依法承担相应的法律责任。
五、监督和法律责任
本行政审批机关将在作出准予许可的行政审批决定后2个月内对被审批人的承诺内容是否属实进行检查，发现被审批人实际情况与承诺内容不符的，行政审批机关将要求其限期整改；整改后仍不符合条件的，依法撤销行政审批决定。
六、诚信管理
被审批人在规定期限内未提交材料，或者提交的材料不符合要求的，以及行政审批机关在审查和后续监管中发现申请人、被审批人作出不实承诺或者违反承诺的，行政审批机关应当记入申请人、被审批人诚信档案，并对该申请人、被审批人不再适用告知承诺的审批方式。

附件4
上海市户外招牌设置行政审批告知承诺后续监管规程
为加强上海市户外招牌设置行政审批告知承诺后续监管（以下简称“后续监管”）工作，落实检查要求，规范检查行为，根据《上海市行政审批告知承诺管理办法》（2018年市政府第4号令公布）的规定，结合工作实际，制定本规程。
一、定义
本规程所指的后续监管，是指区绿化市容管理部门对通过告知承诺方式申请设置户外招牌获许可审批的单位或个人（以下简称“被审批人”），在行政审批决定作出后的2个月内，就被审批人承诺内容是否属实进行检查的活动。
二、监管主体
区绿化市容管理部门负责辖区内户外招牌设置许可的后续监管工作。
街道办事处、镇（乡）人民政府可以受区绿化市容管理部门委托, 负责辖区内户外招牌设置许可的后续监管工作。
三、时限要求
后续监管应在告知承诺方式行政审批决定作出后2个月内完成。
四、材料移送（信息共享）
区绿化市容管理部门应在作出准予许可的行政审批决定后2个工作日内，将全套审批材料移送（或通过信息系统发送）实施后续监管的街道办事处、镇（乡）人民政府。
五、检查通知
监管主体在行政审批决定作出或收到移送的全套审批材料后的5个工作日内，向被审批人送达《行政审批告知承诺后续监管检查通知书》（附件①，以下简称《检查通知》）。《检查通知》中应明确告知被审批人检查时间，并根据被审批人签订的《告知承诺书》，列明检查内容。
六、检查实施
监管主体进行检查时，应指派1名具有业务专长的人员牵头组织检查。检查人员应当向被审批人出示证件，并对检查进程和检查事项真实性负责。检查人员与被审批人有直接利害关系的，应当回避。
检查人员进行检查的内容应与检查通知中一致，并对核查内容逐项核实，之后当场出具《行政审批告知承诺后续监管检查记录单》（附件②），列明单项内容核查结果和总体核查结论，需整改的，在备注栏写明存在的问题、整改内容等，由检查人员、被审批人签名确认。检查记录单经监管主体负责人签字后，表单信息报行政许可部门备案。
七、问题整改
检查人员发现实际设置情况与承诺内容不符的，应当发放《行政审批告知承诺后续监管整改通知书》（附件③），要求被审批人限期整改，整改时限一般不超过1个月；逾期拒不整改或者整改后仍不符合条件的，报区绿化市容管理部门依法撤销行政许可决定。
八、证件注销
监管主体向区绿化市容管理部门提交拟撤销行政许可的相关材料，区绿化市容管理部门应制作《撤销行政许可决定书》（附件④），经法制审核、分管领导批准，依法撤销行政许可决定，向被审批人送达撤销决定书。被审批人无法联系的，经公告后依法注销其行政许可证件，并向社会公布。
九、诚信管理
被审批人作出不实承诺或者违反承诺的，记入诚信档案，并对被审批人不再适用告知承诺的审批方式。
被审批人的行政处罚信息按照规定同步纳入本市公共信用信息服务平台。
十、其他
后续监管涉及的整套材料纳入许可档案管理。
检查要严格遵守法律法规规章规定和廉洁自律要求，对滥用职权、弄虚作假、玩忽职守、吃拿卡要等行为，应依法依纪严肃处理。
其他未尽要求应符合《行政处罚法》《中华人民共和国行政许可法》《上海市行政审批告知承诺管理办法》（市政府令4号公布）等相关法律法规规章要求。
