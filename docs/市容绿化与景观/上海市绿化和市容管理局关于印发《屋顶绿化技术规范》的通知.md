# 上海市绿化和市容管理局关于印发《屋顶绿化技术规范》的通知



各区县绿化管理部门、行政许可受托实施机构：
为了促进本市绿化事业的发展，改善和保护生态环境，加快发展立体绿化，鼓励建设项目的平屋顶实施绿化，根据修正后新颁布的《上海市绿化条例》的有关规定，研究制定了《屋顶绿化技术规范》，现印发给你们，请遵照执行。
特此通知。
2015年11月4日
