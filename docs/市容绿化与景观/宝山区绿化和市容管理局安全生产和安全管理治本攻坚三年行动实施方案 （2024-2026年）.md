# 宝山区绿化和市容管理局安全生产和安全管理治本攻坚三年行动实施方案 （2024-2026年）

为认真贯彻落实习近平总书记关于安全生产系列重要指示精神和考察上海重要讲话精神，全面落实区委区政府工作要求，进一步夯实宝山绿化市容行业安全生产和安全管理工作基础，按照《宝山区安全生产治本攻坚三年行动实施方案（2024-2026年）》要求，结合局系统安全生产和安全管理工作实际，制定本实施方案。

一、指导思想及工作目标

（一）指导思想

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十大精神，坚持人民至上、生命至上，坚持安全第一、预防为主，坚持标本兼治、重在治本，坚持对标国际国内最高标准、最好水平、最严要求，着力消减重大风险，着力消除由于重大风险管控措施缺失或执行不到位而形成的重大事故隐患。落细落实安全生产十五条硬措施、上海安全生产“78条"具体措施和本区“83条"落实举措，在安全理念、责任、规划、法治、标准、科技、工程、素质等方面补短板、强弱项，切实提高风险隐患排查整改质量、切实提升发现问题和解决问题的强烈意愿和能力水平，推动重大事故隐患动态清零和减存量、控增量，不断提升本质安全水平。

（二）工作目标

通过三年治本攻坚，局和基层党组织统筹行业发展和安全的理念进一步强化，坚守安全底线的意识更加强烈，消减安全风险、消除事故隐患的积极性和主动性显著增强。局机关各科室、基层事业单位齐抓共管，压实全链条排查整治事故隐患的责任体系，安全监管能力显著提升，力争绿化市容行业不发生重大安全生产事故和人员伤亡、不发生重大火灾事故。2024年底前，完成局系统风险隐患点位的全面排查，着力解决安全生产和安全管理突出问题，坚决堵住安全监管漏洞。2025年，着力消除事故隐患，有效防范安全事故。2026年底前，形成重大事故隐患动态清零的常态化机制，为全面推动宝山绿化市容行业高质量发展，助力“四个城区”建设保驾护航。

二、任务分工

（一）局办公室负责制定局安全生产和安全管理治本攻坚三年行动方案，统筹推动局机关各科室、基层事业单位安全生产和安全管理治本攻坚三年行动的组织实施，将治本攻坚三年行动作为年终考核重要内容。

（二）负有行业安全监督管理职责的机关科室，要在制定的子方案中进一步细化安全生产和安全管理治本攻坚的具体措施要求，建立健全事故隐患排查治理体系和督办制度，开展安全生产和安全管理专项整治，并定期会同有关部门开展联合督导检查，聚焦重点环节、重点事项精准实施安全监管，严厉惩处各类违规行为，依法关闭取缔不符合安全条件的企业单位。

（三）各事业单位要结合本方案，制定本单位安全生产和安全管理治本攻坚三年行动实施方案，进一步细化具体措施要求，按时间节点，严格落实确定的主要任务，共同推进本方案各项工作的落地实施。

三、主要任务

（一）开展安全生产责任体系提升行动

1.深入贯彻落实《上海市党政领导干部安全生产责任制实施细则》。局党组和基层党组织要定期研究安全生产和安全管理工作，突出重大事故隐患排查整治等方面内容，专题研判推进安全生产和安全管理重大问题解决。要把安全生产、安全管理纳入各级领导干部应知应会党内法规和法律法规清单，加强经常性教育培训。各事业单位要把安全生产、安全管理内容纳入单位领导班子成员安全职责清单和年度任务清单，强化“一岗双责”，明确治本攻坚责任分工和工作目标，落实单位党政领导干部安全生产和安全管理履职述职、督导督查和考核等制度。

2.进一步落实机关科室行业监管责任。机关科室要厘清安全生产和安全管理清单，严格落实市安委会《关于进一步落实“管行业必须管安全管业务必须管安全管生产经营必须管安全”责任体系的意见》（沪安委会〔2023〕3号）要求，强化行业安全监管。建立健全全链条、跨部门安全监管协同机制，推动多部门联勤联动，提升安全治理能力。

3.进一步压实各事业单位主体责任。坚持把各单位安全生产和安全管理主体责任落实作为抓好安全工作的落脚点，加强对各单位落实安全全员责任的监督检查，推动事业单位事故隐患自查自纠以及安全生产和安全管理风险分级管控、隐患排查治理双重预防机制建设，整体提升各单位安全管理水平。

4.严格落实考核机制。坚持把治本攻坚三年行动相关内容纳入安全工作综合考核，对治本攻坚工作开展情况进行动态评估考核，并加强考核结果运用，严格落实“一票否优”。开展安全生产和安全管理督导检查，进一步加强责任倒查，对推进治本攻坚三年行动中涉嫌不担当不作为、失职渎职的问题线索，加大点名、通报、约谈，严肃追究责任，切实把“安全高于一切”的责任感转化为事事抓落实的责任制和行动力。

（二）深化重点领域专项治理行动

5.深化消防安全专项整治。深入开展消防安全集中除患攻坚大整治行动，进一步加强消防安全教育培训、防火巡查与检查、安全疏散设施管理、火灾隐患整改和易燃易爆危险物品防火防爆安全管理、消防设施器材维护管理，以及消防值班，灭火和应急疏散预案演练。

6.深化园林绿化工程安全专项治理。紧盯园林绿化工程施工领域安全隐患易发多发的重点部位和薄弱环节，开展建设单位安全生产和安全管理首要责任、高处坠落事故预防全员安全管理、施工现场防高坠措施、危大工程不按方案施工及验收、起重机械安全保护装置等五项重点整治，严厉打击违法违规行为，精准消除事故隐患，完善事故报送调查处罚闭环机制，不断健全园林绿化工程安全监管制度。

7.深化公园安全专项治理。统筹各类管理资源，切实加强城市公园特别是24小时开放公园的安全管理工作，扎实做好公园游乐设施安全管理和大客流应对工作。加强城市公园游乐设施安全日常监管，坚持重点检查和专项检查相结合，强化节假日和重大活动前的安全检查。结合实际情况，及时开展大客流风险研判，制定并落实应对措施。健全工作台账，完善风险隐患排查清单，落实整改责任、整改时限和整改措施，实行整改“闭环”管理，全面提升城市公园安全管理水平。

8.深化林业安全专项治理。聚焦林业安全生产和安全管理重要领域、重要时段、关键环节，围绕造林生产安全、野生动物人工繁育和经营利用场所安全、野生动物疫源疫病监测、木竹材加工安全、森林防火、林业有害生物防治、林业危险化学品管控、森林旅游景区景点管理、林区防台防汛、消防安全、外业工作安全防范等方面，认真细致开展重大事故隐患专项排查整治。不断强化对林业经营单位的监督检查，加强业务培训，提高安全监管人员发现问题和解决问题的能力水平。

9.深化建筑垃圾领域安全专项治理。积极配合交警、城管执法部门，开展建筑垃圾领域执法专项行动，强化对渣土运输交通肇事、“无证运输”等违法违规行为的打击力度。加强对辖区渣土运输企业的日常监督管理，不断完善安全管理制度，健全安全管理台账，严格落实“右转必停”等安全管理要求。

10.深化生活垃圾处置设施安全专项治理。健全日常运营管理制度，细化安全检查管理措施，强化业务管理和安全管理的全面融合，严格落实《上海市生活垃圾转运、处置设施运营监管办法》《上海市固废设施运营监管考核办法》，督促运营主体完善安全生产和安全管理机制、安全管控措施、安全教育制度，提升设施安全运营和应急响应水平。结合生活垃圾处置设施运营特点，落实重点时段、重点环节、重点区域的安全管控，强化隐患易发领域安全检查，加强处置设施维修维保，及时关停有问题的处置设施。

11.深化户外设施和景观照明设施安全专项治理。常态化持续推进户外设施安全隐患排查和违规户外设施治理，特别是加大对影响消防安全、易发生高坠风险等户外设施治理力度。落实《户外广告、户外招牌、景观照明设施突发事件处置应急预案》，开展针对性应急演练，提高应急处置能力。深入推进消防安全集中除患攻坚大整治，落实《上海市打通消防“生命通道”推进工作方案》，严格源头把关、加强监管。

（三）开展重大事故隐患动态清零行动

12.完善安全风险评估会商机制。定期组织工程管理、公园绿地、林业、环卫车辆、垃圾处置设施和户外设施、景观照明设施等安全形势分析，强化重大安全风险源头管控。

13.强化自查自纠机制。建立风险隐患自查自改常态化机制，制订自查自纠年度计划，开展风险隐患排查，并建立台账，实施销项式管理。

14.完善事故隐患治理督办制度。按照事故隐患“全部上账、即查即改、全面整改”的要求，加大专业指导力度，确保隐患闭环整改到位。建立事故隐患统计分析机制，对隐患整改进展缓慢的单位及时采取函告、通报、约谈、曝光等措施，督促相关单位落实整改措施，全面加强事故隐患排查治理的监督管理。

（四）开展从业人员安全素质能力提升行动

15.加强教育培训。坚持效果导向，健全教育培训机制，完善相关台账，加强教育培训动态管理，全面提升各类人员安全能力水平。

16.开展安全生产和消防安全宣传。每年多层次多渠道组织开展局系统“安全生产月”“防灾减灾日”“消防宣传月”等活动，持续增强职工安全意识和防灾避险、自救互救能力。

17.抓好应急演练。策划应急预案演练，组织灭火实操演练和人员密集场所疏散演练、防汛防台应急抢险演练和森林防火实战演练，锤炼应急队伍实战水平，提升单位应急处置能力。

三、保障措施

（一）加强组织领导。各部门、各单位主要负责同志要定期组织研究本单位安全生产和安全管理治本攻坚有关工作，听取进展情况汇报，协调解决跨部门安全工作突出问题，全面推动落实本行业领域和业务条线的安全责任，确保行业的安全稳定。

（二）加强安全投入。要强化安全生产和安全管理相关投入，科学合理安排预算，确保事故隐患治理资金，切实做好治本攻坚各项任务措施的支撑保障。聚焦制约安全生产和安全管理的重点难点问题，加强统筹规划，持续推进“人防、技防、工程防、管理防”等治本之策，不断提升本质安全水平。

（三）强化考核巡查。把治本攻坚三年行动作为安全工作考核巡查重点，完善督办交办制度，优化考核巡查方式方法，将“多通报、多发督促函、多暗访”作为长效机制，对事故隐患排查整治不力等突出问题及时约谈、通报、曝光。
