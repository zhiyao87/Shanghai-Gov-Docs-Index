# 关于修订印发《静安区单位生活垃圾处理费征收管理办法》的通知

各相关单位：

为进一步规范静安区单位生活垃圾处理费征收管理，根据《上海市生活垃圾管理条例》《上海市市容环境卫生管理条例》《上海市单位生活垃圾处理费征收管理办法》规定要求，现将新修订的《静安区单位生活垃圾处理费征收管理办法》印发给你们，请认真遵照执行。

特此通知。

静安区绿化和市容管理局

静安区发展改革委员会

静安区财政局

静安区市场监督管理局

2023年5月23日

静安区单位生活垃圾处理费征收管理办法

第一条（目的和依据）

为有效改善城市生态环境，推进生活垃圾处理减量化、资源化、无害化，促进可持续发展，提高生活垃圾处理质量，根据《上海市生活垃圾管理条例》《上海市市容环境卫生管理条例》《国务院办公厅关于转发国家发展改革委住房城乡建设部生活垃圾分类制度实施方案的通知》《上海市单位生活垃圾处理费征收管理办法》等规定，结合本区实际，制订本办法。

第二条（适用范围）

本办法适用于本行政区域内单位生活垃圾处理费的征收及其相关监督管理活动。

第三条（征收对象）

凡在本区范围内产生生活垃圾（餐厨垃圾）的国家机关、企事业单位、社会团体、个体经营者等，均应当缴纳单位生活垃圾处理费。

第四条（征收原则）

向单位征收生活垃圾处理费，遵循以下原则：

（一）有利于宣传倡导节能减排、环境保护理念；

（二）有利于实现生活垃圾全程分类，推进生活垃圾分类达标；

（三）有利于体现“谁产生、谁付费”“多产生、多付费”“少产生、少付费”的原则；

（四）有利于完善征收方式，规范征收行为，方便单位缴费，体现公平、公正、公开。

第五条（收费性质）

单位生活垃圾处理费为经营服务性收费，实行政府指导价管理。

第六条（管理部门）

静安区绿化和市容管理局（以下简称区绿化市容部门）在静安区政府领导下，负责本区范围内单位生活垃圾处理费征收的组织和管理工作。

区市场监管局负责对收费行为进行监管。

区财政、税务等部门按照各自职责，协同实施本办法。

第七条（征收单位）

本区单位生活垃圾处理费由静安区绿化和市容管理局下属区市容环境综合管理中心负责征收。

各街道（镇）城市运行管理中心协助区市容环境综合管理中心办理收费事项。

第八条（单位申报）

生活垃圾（餐厨垃圾）产生单位应当每年度向区绿化市容部门申报本单位生活垃圾（餐厨垃圾）的产生量。

单位自行收集、运输所产生生活垃圾的，应当向区绿化市容部门申报生活垃圾产生量和处置方案，并提供产生单位营业执照（复印件）、运输单位资质文件、生活垃圾末端处置证明文件等。

单位自行收集、运输所产生餐厨垃圾的，应当符合市绿化市容局规定的条件，并在首次收运前向区绿化市容部门备案。

单位委托收集、运输生活垃圾（餐厨垃圾）的，受委托的市容环境卫生作业服务企业应当将收集、运输的各单位生活垃圾数量告知区绿化市容部门。

第九条（基数核定）

单位生活垃圾处理量基数一年核定一次。

区绿化市容部门根据各单位自行申报的不同种类生活垃圾产生量，结合上年度实际收运量，核定当年基数，以适当方式向社会公示，并书面告知相关单位。

对新设立单位的生活垃圾分类处理量基数，由区绿化市容部门参照同行业、同等规模单位的数据确定。

各街道（镇）城市运行管理中心协助做好单位生活垃圾基数核定工作。

第十条（签订合同）

单位委托收集、运输生活垃圾的，应当根据核定的单位生活垃圾处理量基数，由城市运行管理中心协助区市容环境综合管理中心与生活垃圾产生单位签订《静安区单位生活垃圾清运处理服务合同》，明确处理量基数、计量办法、收费项目、收费标准、收费总额及方式、服务承诺等内容。

第十一条（计量方法与收费标准）

单位生活垃圾处理费以按量计费为基础，采取基数内外不同收费标准，并按不同行业实行分类计费。

单位生活垃圾处理费按标准桶（每桶240升）计收，具体标准如下：

（一）对单位和饮食行业产生的餐厨垃圾（不含餐厨废弃油脂），基数内每桶60元，基数外每桶120元。

（二）对国家机关、企事业单位、社会团体、个体经营者等产生的生活垃圾（不含餐厨垃圾），基数内每桶40元，基数外每桶80元。

（三）对四星级以上宾馆、歌厅、舞厅、卡拉OK歌舞厅、夜总会、台球房、高尔夫球场、保龄球馆、游艺厅、桑拿浴室（按摩）、足浴室等企业产生的生活垃圾（不含餐厨垃圾），基数内每桶80元，基数外每桶160元。

生活垃圾产生单位应当设置符合市容环境卫生要求和标准的生活垃圾收集容器，并保持容器整洁完好。

第十二条（费用征收）

单位委托收集、运输生活垃圾的，区市容环境综合管理中心根据《静安区单位生活垃圾清运处理服务合同》，收取单位生活垃圾处理费。

第十三条（收费减免）

对养老院、残疾人企业、特殊教育学校等公益性较强的单位，其生活垃圾分类考核达标的，由产生单位提出减免申请，经区绿化市容部门审核决定后，减免该单位生活垃圾处理费。

第十四条（征收规范）

区市容环境综合管理中心应当依法向主管税务机关办理税务登记。

区市容环境综合管理中心应当按照规定的收费项目和收费标准，收取单位生活垃圾处理费，做到应收尽收，不得重复收费，严禁乱收费。收费人员应当做到持证上岗，收费时应当开具符合规定的票据。

第十五条（收费监管）

区绿化市容部门应当加强对单位生活垃圾处理费征收和使用情况的监督管理，区财政、税务、市场监管等部门应当根据各自职责，加强对单位生活垃圾处理费征收工作的监督检查。

任何部门和单位不得擅自减免、截留和挪用单位生活垃圾处理费。对应收不收、应收少收，占用、挪用生活垃圾处理费，违反票据管理规定等违法违规行为，按照有关法律、法规依法查处。

第十六条（实施时间）

本办法自2023年6月22日起施行，有效期至2028年6月22日。

本办法在实施过程中如遇上级有关政策调整的，按上级政策执行，并作相应调整。
