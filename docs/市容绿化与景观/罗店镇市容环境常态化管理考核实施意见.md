# 罗店镇市容环境常态化管理考核实施意见

罗店镇市容环境常态化管理考核实施意见

为加强市容环境卫生管理,全面提升我镇市容环境管理水平,建立市容环境卫生长效管理机制,努力改善市容环境卫生面貌,积极打造市容整洁、环境优美、文明卫生、秩序井然的市容面貌，特制定实施意见。

一、指导思想

以党的十九大精神为指引，以解决人民群众最关心、最直接、最现实的生活环境问题为突破口，大力开展市容环境卫生整治，全面改善环境卫生状况，实现市容环境卫生管理长效常态，有力保障全国卫生城镇、人居环境整治、整洁村创建等成果。坚持问题导向、需求导向、目标导向，把提升市容环境融入到城市精细化管理，人居环境建设等行动领域。

二、基本原则

（一） 完善机制，明确职责

为持续保持村民生活环境、村容村貌，全镇480名驻村保洁员今后由各村属地化管理，市容办负责业务指导及每月对各村的考核,管理农村保洁督察队和机动队。

（二） 联勤联动，形成合力

成立罗店镇市容环境管理领导小组（附件一）。明确领导小组成员单位职责分工（附件二），形成工作合力，充分发挥各部门在市容环境工作中的职能。

（三）长效考核、完善管理

完善考核机制，镇规保办每月对各村考核一次，考核成绩呈送镇主要领导，作为各村市容环境年终考核的主要因素。同时，镇市容管理领导小组办公室不定期组织成员单位、镇人大代表对各村进行检查考核。

三、工作范围

1、农村环卫设施维护保洁——农村公共厕所、垃圾箱房

2、农村环卫设备维护保洁——240L垃圾桶、垃圾收集车

3、农村村宅及周边环境卫生

4、农村道路保洁

5、农村河道保洁

6、垃圾分类

7、公共区域及三不管地带保洁

四、工作标准

根据罗店镇市容环境卫生工作范围，考核内容主要涵盖各类投诉、环卫设施清洁维护、农村道路保洁、农村河道保洁、公共区域环卫保洁、村容村貌维护及垃圾分类等七个方面的工作（附件三）。

五、工作内容

1、驻村保洁员属地化管理。驻村保洁员今后由各村属地化管理，由村委会负责保洁人员的日常管理、考核招录，工资表和考勤表由各村每月5日前交于镇规保办,镇规保办汇总后统一交于社保中心。

2、市容办负责业务指导及每月对各村的考核（附件三）。

3、市容办负责管理考核督查队员和机动人员。督查队员负责全镇环境日常巡查及各村考核检查，及时处理好群众投诉。机动人员负责罗南、罗店区域日常突发环境整治工作及“三不管”地带环境整治工作。

4、制定保洁员额度制。按照五个标准制定各村保洁员额度：①每30户/1名保洁员；②每个村宅公厕/1名保洁员；③每2.5KM/1名保洁员为标准；④外来人口每超过300人多配置1名保洁员；⑤天平村、北金村湿垃圾处理器额外各配置4名保洁员。今后超过额度村的保洁员退休后，名额将转给保洁人员少的村，经过三年调整使各村保洁人员数量达到相对平衡。

5、驻村保洁员做好属地生活垃圾分类的指导、收集、驳运工作，保持垃圾厢房规范、整洁、垃圾桶摆放规范。

六、考核制度

市容办每月对各村进行年终考核（附件三）。每月考核成绩直接与年终考核挂钩，由镇政府设立专项考核资金，年终对各村进行考核奖励。

附件：1、罗店镇市容环境管理领导小组；

2、罗店镇市容环境管理成员单位职责分工；

3、罗店镇市容环境每月考核表。
