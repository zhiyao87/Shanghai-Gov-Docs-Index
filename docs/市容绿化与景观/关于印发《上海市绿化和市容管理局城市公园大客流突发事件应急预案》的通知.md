# 关于印发《上海市绿化和市容管理局城市公园大客流突发事件应急预案》的通知

各区绿化市容局、临港新片区管委会、局各直属公园：

为建立健全本市绿化市容行业城市公园大客流应急处置体系，有效预防和处置城市公园大客流突发事件，现制定印发《上海市绿化和市容管理局城市公园大客流突发事件应急预案》，请结合工作实际遵照执行。

特此通知。

上海市绿化和市容管理局

2024年11月11日
