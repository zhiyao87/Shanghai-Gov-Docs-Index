# 关于印发《上海市智慧公厕建设导则（试行）》的通知



为进一步贯彻落实《关于做好推进“厕所革命”提升城镇公共厕所服务水平有关工作的通知》（建城〔2018〕11号）相关工作要求，加快构建上海智慧公厕服务管理体系，我局制定了《上海市智慧公厕建设导则（试行）》，现印发给你们，请遵照执行，建议相关委办局参照执行。
