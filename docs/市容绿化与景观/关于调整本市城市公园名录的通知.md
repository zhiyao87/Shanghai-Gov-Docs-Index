# 关于调整本市城市公园名录的通知

各区绿化和市容管理局、临港新片区管理委员会：

近年来，本市不断加大生态环境建设力度，一大批公园绿地建成开放。其中部分公园绿地设施比较完善，服务功能较为完备，符合城市公园入册标准。在各区申报的基础上,经我局现场踏勘和研究讨论后，决定将36座公园纳入城市公园名录管理。同时，经综合评估，决定将虹口区1座在册社区公园调整出城市公园名录，闵行区、徐汇区各1座在册社区公园调整为综合公园进行管理，静安区1座在册社区公园调整为专类公园进行管理。本次调整后，城市公园增加至512座。现将有关要求通知如下：

一、36座公园纳入城市公园名录,其中浦东新区汤巷公园按照专类公园标准进行管理，闵行区春申公园按照综合公园标准进行管理，其余34座公园按照社区公园标准进行管理。

二、虹口区广粤运动公园调出城市公园名录。

三、闵行区闵行文化公园、徐汇区康健园等2座公园从社区公园调整为综合公园，按照综合公园标准进行管理；静安区辅德里公园调整为专类公园，按照专类公园标准进行管理。

四、请各区公园管理部门对照《公园设计规范》以及城市公园分类分级、精细化管理的要求，及时增加公厕、座椅、路灯、监控等配套设施，进一步提升公园服务水平。

五、新入册城市公园应按照不低于市级一级绿地养护标准实施养护，公园厕所参照环卫行业标准落实养护。各区公园管理部门应参照《上海市绿地养护概算定额（2010）》，积极协调相关部门落实公园运营维护费用。

六、新入册城市公园自2025年1月1日起开始统计公园游客量，自2026年1月1日起实施专业测评和社会评价。城市公园原则上应实行全年延长开放，有条件的实行全年24小时开放。

七、新入册城市公园基础资料请于11月30日前上传至上海智慧公园系统（https://zhgy.shanghaihuaxun.com/zhgy/sso/login）。

八、希望各区公园管理部门切实加强新入册城市公园的管理力度，不断提升公园整体面貌和服务水平。

特此通知。
