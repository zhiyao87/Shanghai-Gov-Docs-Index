# 关于印发《上海市居（村）生活垃圾分类行动方案（2026—2028年）》的通知

各区绿化市容局、区委社会工作部：

现将《上海市居（村）生活垃圾分类行动方案（2026—2028年）》印发给你们，请结合工作实际，抓好贯彻落实。

上海市绿化和市容管理局

中共上海市委社会工作部

2026年7月20日

上海市居（村）生活垃圾分类行动方案（2026—2028年）

为深入贯彻落实习近平总书记关于垃圾分类“需要广大城乡居民积极参与、主动作为”的重要指示精神，按照《上海市生活垃圾分类提质增效三年行动计划（2026-2028年）》总体部署，聚焦居民端这一关键环节，着力解决居民分类参与不均衡、实效不稳定、习惯未牢固等突出问题，推动垃圾分类从“新时尚”向“好习惯”转变，进一步夯实垃圾分类的群众基础和社区阵地。通过本方案实施，力争用三年左右时间，实现居民垃圾分类意识普遍增强、自主分类投放准确率明显提升、低价值可回收物回收量显著增加、社区分类共治机制更加健全，居民对垃圾分类工作的满意度和获得感持续提升。

一、加强社区宣传，推动人人知晓垃圾分类新要求

围绕垃圾分类主题，依托小区、楼道的公告栏、电子屏，以及“社区云”平台等线上线下途径，开展广泛宣传。利用“绿色循环”志愿服务主题宣传日等载体，常态化推广低碳研学、废品手工艺展、主题小品创排等科普活动。注重培育垃圾分类专业讲解志愿者队伍，运用楼道微阵地、小区微景观、微信群微宣讲等形式，以群众听得懂、看得见、能接受的方式，把分类知识讲清楚、分类意义讲明白、分类习惯带起来。

二、结合“四百”走访，带动人人养成垃圾分类好习惯

将垃圾分类宣传引导纳入基层干部“四百”走访工作内容，在联系服务群众中同步推动分类知识普及和行为引导。重点关注新迁入家庭以及新型居住社区的住户，及时主动告知本小区分类投放方式、点位设置、回收服务等信息。对境外人员较为集中的社区，入户宣传材料和公共区域提示中适当配备多语种版本，便于理解与配合。各街镇可统一参考市委社会工作部编制的《上海市居（村）委会“四百”走访工作指南（2026年版）》中垃圾分类特定场景，指导居村工作人员在入户走访时了解居民垃圾分类习惯，积极宣传好的垃圾分类方法，引导居民建立良好的垃圾分类习惯。

三、壮大志愿者队伍，实现人人参与的社区新风尚

拓宽多元招募渠道，挖掘在职党员、楼组长、能人达人、热心居民、青少年等社区骨干，吸纳快递员、网约配送员等新就业群体参与，壮大建强社区志愿者队伍，带动千家万户主动参与垃圾分类，汇聚共治共建共享合力。合理设置值守督导、日常巡查、科普宣传、关爱帮扶等岗位，鼓励党员干部、志愿者、社会工作专业人员等开展高峰时段引导规范投放，日常排查分类乱象，为行动不方便的群体提供垃圾代投等志愿服务。结合“美丽楼道”建设，探索社会工作专业人员和志愿者队伍联动服务机制，深化“专业志愿者+社区志愿者”融合联动模式，发挥具有相关行业背景的专业志愿者技术支撑作用，更好指导社区志愿者开展常态服务。开展岗前培训与实操帮带，用好“随申办·一码做志愿”平台，客观准确记录服务时长，坚持精神激励为主的基本原则，科学制定褒奖措施，讲好志愿者故事。

四、推动共商共治，构建人人尽责的社区治理新局面

将垃圾分类要求纳入村规民约或专项制定垃圾投放管理规约，组织居民围绕分类投放点位设置、投放时间调整、回收服务优化等具体事项开展协商讨论，形成符合本社区实际的管理约定。建立联合接待制度听取居民意见，依托“大城小事”等栏目，聚焦垃圾分类中的难点与焦点问题，组织开展专题讨论和人民建议征集，引导居民从“要我分”向“我要分”转变，从关注个体便利转向关心社区整体环境和公共利益。将生活垃圾分类作为社区治理的重要议题，通过“大家的事大家商量着办”，推动居民在分类实践中逐步形成对社区公共事务的关注与担当，培育共建共治共享的社区共同体意识。

居（村）委会要加强对物业服务企业的指导，做好投放点维护、保洁巡查、驳运管理，提升垃圾分类容器、标识、配套设备等相关硬件的配备，为居民便捷投放创造良好条件；利用“社区云”平台将相关诉求纳入“小事快办”流程；加强巡查监督，对于收集、运输中违反分类要求的，及时向街镇报告。要依托党建引领“多格合一”机制有效解决生活垃圾分类中出现的“三跨”问题，统筹指导各网格内小区生活垃圾分类工作，强化底部抬升，依据实际需要组织经验交流和案例研讨，形成可复制推广的机制和典型经验，推动面上工作提质增效；绿化市容部门指导建强“一居（村）一队伍”，对重点居（村）开展针对性培训，整体提升服务水平和分类成效。要在做好面上统筹兼顾和支持保障的同时，指导垃圾分类科普宣传融入社区日常工作，用好现有宣传阵地，推进常态化宣传，推动形成家家户户养成垃圾分类好习惯的良好氛围。
