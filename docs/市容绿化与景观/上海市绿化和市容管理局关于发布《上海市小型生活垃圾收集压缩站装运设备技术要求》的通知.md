# 上海市绿化和市容管理局关于发布《上海市小型生活垃圾收集压缩站装运设备技术要求》的通知



各有关单位：
根据上海城市建设中环卫公共设施的配置需要，为有效减少小型生活垃圾收集站在生活垃圾转运中对市容环境卫生的影响，提高生活垃圾收集运输系统的使用效率，由上海市绿化和市容管理局制定的《上海市小型生活垃圾收集压缩站装运设备技术要求》（编号为LHSR1&mdash;20011）经审查批准，现予以发布。请各有关单位在小型生活垃圾收集压缩站的建设和管理中遵照执行。
