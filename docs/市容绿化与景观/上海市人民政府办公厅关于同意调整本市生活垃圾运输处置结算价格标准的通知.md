# 上海市人民政府办公厅关于同意调整本市生活垃圾运输处置结算价格标准的通知

市绿化市容局：

沪绿容〔2022〕341号文收悉。经市政府研究，同意调整本市生活垃圾运输处置结算价格标准，调整后的标准请自行印发并会同有关部门、单位和区政府自2023年1月1日起实施。

上海市人民政府办公厅

2022年12月29日
