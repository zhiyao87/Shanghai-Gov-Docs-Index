# 关于调整本市口袋公园名录的通知

各区绿化市容局、临港新片区管委会：

为持续完善城乡公园布局，建设公园城市，全市各区积极推进各类公园绿地建设，建成了一大批绿化面貌良好、配套设施完善、服务功能丰富的口袋公园，已具备纳入城乡公园体系的条件。在各区申报的基础上，经我局现场踏勘和研究讨论后，现决定将黄浦区森邻公园等76座口袋公园纳入城乡公园名录。本次调整后，本市纳入名录的口袋公园数量将增加至341座。现将有关要求通知如下：

一、新纳入的口袋公园应按照《园林绿化养护标准》（DG/TJ08-19-2023）等相关技术标准实施一级绿地养护标准，并在园内显要位置公布养护单位和联系方式。

二、做好新入册口袋公园的“一园一档”台账，对照精细化管理要求，落实各项养管措施。

三、希望各区加强新入册口袋公园的管理，维护良好景观面貌，不断提升服务水平，为市民创造优美的城乡公园生态环境。

特此通知。
