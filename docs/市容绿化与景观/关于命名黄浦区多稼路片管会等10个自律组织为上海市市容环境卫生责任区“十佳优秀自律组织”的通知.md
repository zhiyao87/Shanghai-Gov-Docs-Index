# 关于命名黄浦区多稼路片管会等10个自律组织为上海市市容环境卫生责任区“十佳优秀自律组织”的通知

各区绿化市容局，各相关街镇：

根据《关于选树 2022年度“上海市市容环境卫生责任区优秀自律组织”的通知》（沪绿容〔2022〕213号）要求，为全面落实市容环境卫生责任区管理制度，全面推进上海市市容环境卫生责任区“十佳优秀自律组织”评选活动。深入挖掘全市责任区管理工作中涌现出的自律自治先进典型，进一步提升责任人的自律自治水平，经区级选送、市级评选、网络投票、专家评定等程序，现决定命名下列市容环境卫生责任区自律组织为上海市市容环境卫生责任区“十佳优秀自律组织”：黄浦区多稼路片管会、青浦区福贸路市容环境卫生责任区管理自律组织、松江区“治”爱新浜自律联盟、静安区丰盛里—吴江路商圈商户自治委员会、长宁区古北黄金城道步行街共治委员会、徐汇区康健门责管理商家联席会、宝山区牡丹江路门责管理自律组织、普陀区黄陵路市容环境责任区自律组织、杨浦区国济路商家自律组织、奉贤区韩村路市容自管协会。

此外，对入围的其余10个市容环境卫生责任区自律组织命名为上海市市容环境卫生责任区“优胜自律组织”：嘉定区古猗园南路责任区管理自律联盟、金山区红叶居民区开乐街商户自律小组、长宁区程家桥路门责自律小组、松江区同乐广场商户自治协会、浦东新区陈春路社会责任促进会、闵行区永德路虹梅新尚街自律组织、静安区彭浦新村街道闻喜路分会、奉贤区通阳路商圈责任区自律联盟、浦东新区长岛路自律小组、虹口区四川北路“甜爱坊”自律组织。

希望被命名的市容环境卫生责任区“十佳优秀自律组织”继续优化机制、创新管理、精益求精，切实发挥示范引领作用，入围的10个“优胜自律组织”要继续争创“十佳优秀自律组织”。同时希望全市各区、各街道（镇、乡）结合本辖区的实际情况，努力学习“十佳优秀自律组织”的先进做法，开拓思路、深挖细耕，在责任区自律组织的培育方面强化指导服务，进一步完善落实市容环境卫生责任区管理制度，注重“广度”和“深度”，做实，做深、做活，为全面提升市容环境再创新佳绩、再做新贡献。

上海市绿化和市容管理局

2023年1月28日
