# 上海市绿化和市容管理局关于印发《上海市规范公共绿地和行道树养护作业管理暂行办法》（试行）的通知



各区县绿化和市容管理局、浦东新区环保市容局、局各直属公园、各有关单位：
为进一步完善本市绿化养护作业机制，探索形成政府主导、有序竞争的市场格局和科学规范的监管机制,完善管理措施，强化管理部门的监管责任，提升绿化的管理水平和服务能力，形成企业作业自主，市场竞争有序，资金使用高效，监督管理有力的养护作业模式，我局按照市政府《关于进一步深化本市城市养护作业领域市场化改革工作的指导意见》精神要求，结合本市实际情况，制定了《上海市规范公共绿地和行道树养护作业管理暂行办法》（试行），现印发给你们，请遵照执行。
