# 上海市绿化和市容管理局关于进一步加强本市公共厕所管理工作的指导意见

各区绿化和市容管理局：

为深入贯彻落实习近平总书记关于“厕所革命”的重要指示，坚持以人民为中心的发展思想，践行“人民城市人民建，人民城市为人民”重要理念，进一步强化公厕建设、完善设施配置、加强日常管理、提升服务水平，达到国内“最干净、最方便、最美观、最先进”的整体目标。根据《上海市市容环境卫生管理条例》，就进一步加强本市公共厕所管理工作提出以下指导意见。

一、加强公共厕所配套建设

各区绿化市容部门要注重公共厕所布局规划，按照《公共厕所规划和设计标准》的规定配置足够的公共厕所，提升市民群众的如厕便利度。要加强公共厕所配套建设的指导、督促、管理等工作，按照设置标准，落实环卫公厕布点建设，会同交通、商务、文旅等部门做好交通客运场所、轨道交通站点、农贸市场（菜场）、旅游景区（点）等人流密集场所的公共厕所配建工作。在确保公共厕所服务半径达到上限标准的基础上，结合区域特点、人流聚集等情况，对网红地、人口密集地、农村外来人口聚集地等场所适当增加公厕配建数量。

各区绿化市容部门要积极会同规划资源部门，把好公共厕所设计方案和验收环节的“意见征询关”，做好沟通、协调等工作，对公厕建设提出专业建议。

二、提升公共厕所设计标准

各区绿化市容部门要按照《公共厕所规划和设计标准》要求落实、指导好公共厕所建设工作，尤其是交通客运场所、农贸市场（菜场）、轨道交通站点公厕应做到照明通风等各类设施完备，导向标识清晰。新建、改建公共厕所应当设置无障碍厕间，做到基本设施配置到位，空间分布合理。新建、改建环卫公厕应以一、二类为主，新建、改建农村公厕应以二、三类为主，因面积、高度等客观条件无法达到标准的，应当在设施配置、便民服务等方面达到对应最高等级。要不断优化公厕男女厕位比，交通客运场所、商业区、旅游景区（点）等人流密集区域不宜低于1：2或1:1.5等规定比例，并探索设置“可变式厕位”，让部分男厕位可以临时供女性使用，以缓解高峰时段女厕位需求。

全面加强新建、改建公共厕所适老化、适幼化改造及设施配置。按要求落实无障碍坡道、扶手、挂钩等配置，提升公厕内照明、通风、防滑等设计，增加公厕坐便比例，减少公厕内部台阶；落实托婴板、高低洗手台、高低小便池等设施配置，方便老人、儿童使用。新建、改建一类环卫公厕，新建、改建大型商场、文化体育场馆、旅游景区（点）、公园、医院等人流密集场所的公共厕所，必须设置第三卫生间。

要全面提升公厕设计品味和建设水准，尤其是旅游景区（点）公厕整体设计应与周边环境相融合,凸显文化底蕴；要不断提升公共厕所环保节能水平，加强新材料、新能源、新技术的探索和运用，大力推广节能设备、环保材料、光伏发电、雨水利用、一体建造等材料和技术。

三、推进公共厕所全面开放

大型商圈、商业街、夜班通宵车始末站周边公厕、在居民社区中发挥居家厕所功能的公厕、市民需求特别强烈的公厕，应优先实行24小时开放。其它具备以下条件的公厕，也应实行24小时开放：

（一）通过扫码开门等措施，可以实现自助开、关门的；

（二）具有夜间如厕安全保障设备的（主要包括进门光照自动增强、进门安全语音提示、厕间紧急报警、厕间语音应答系统、险情发现和处置系统等）

（三）配置明显的“24小时开放”标识且在夜间能醒目辨认的。

公共厕所24小时开放形式要因地制宜，可采用整座厕所开放、部分厕间（位）开放、夜间临时增设移动厕所等形式，努力实现24小时开放。

要积极鼓励沿街单位开放厕所供公众使用，开放情况可以作为单位履行社会责任内容，纳入责任区管理、行业评优评奖等体系，不断提升公共厕所共建共享水平。

四、提升公共厕所管理服务

要巩固提升公厕行业文明创建水平，深化“文明公厕”创建，提高行业整体服务质量。严格执行《公共厕所保洁质量与作业要求》，做好日常监管工作，规范文明服务，提高作业水平，落实便民措施。

要结合公共厕所管理新要求、新设备使用等，创新优化保洁模式，强化深度保洁作业，对公共厕所墙面、设施设备、缝隙、出风口等定期进行全面保洁和清理，确保整体环境整洁。探索公共厕所“巡回+深度”、自动一体化等保洁新模式，逐步推进由专人驻守保洁向巡回保洁、自动保洁转变。加强公共厕所日常安全管理工作，做好夜间巡查、保障等工作，确保公共厕所24小时开放安全。探索定期发布公厕白皮书，评估公共厕所管理和使用状况。

要协调各行业管理部门，落实农贸市场、轨道交通站点、旅游景点等场所的管理主体责任，提升公厕整洁程度。菜场公厕要加强公厕保洁作业，做到厕内无异味、无污物；轨交公厕要提升精细化作业水平，确保厕内通风良好、地面干燥。加强对重点社会公厕的监督检查，及时通报检查情况，督促落实问题整改。

要持续深化公共厕所便民服务，在落实环卫公厕冬季热水洗手，免费提供厕纸等服务的基础上，积极推进厕纸进厕位、便民服务箱内容拓展、配置搁物板等工作，提升服务能级，重点区域一类环卫公厕应做到厕纸进厕位。公园、市民休闲空间等人流集中区域的公共厕所，应结合市民实际需求，增加便民举措，提升服务品质。

五、加强农村公厕提档升级

要会同、协调行业管理部门、乡镇、行政村，持续推进农村公厕提档升级工作。结合美丽乡村建设等工作，在乡村振兴示范村、集中居住点、旅游景区（点）等区域推进二类及以上公厕建设。充分考虑农村公厕与周边环境的协调和经济适用性，鼓励因地制宜建设农村生态型公厕，优先使用自然环保材料建设或装饰，采用零排放、资源循环利用等技术减少能耗，使公厕与环境相适应、相协调。

要加强农村公厕管理工作，完善“一厕一档”，指导各乡镇、各村形成公厕管理、人员管理、保洁作业等制度规范，健全保洁员队伍，落实保洁员责任制，加强人员理论和实操培训，有效提升作业水平和服务质量。
