# 上海市绿化和市容管理局关于印发《关于加强口袋公园规划建设和养护管理的指导意见》的通知

各区绿化和市容管理局：

为深入贯彻人民城市理念，全面提升本市口袋公园规划建设质量和精细化养护管理水平，我局制定了《关于加强口袋公园规划建设和养护管理的指导意见》，现印发给你们，请结合实际认真贯彻执行。

特此通知。

上海市绿化和市容管理局

2025年8月7日
