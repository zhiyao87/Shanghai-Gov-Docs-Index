# 上海市绿化和市容管理局关于在全市范围内开展保护鸟类活动的通知

各区绿化市容局、市野生动植物保护事务中心、崇明东滩自然保护区管理事务中心、九段沙湿地自然保护区管理事务中心：

根据《国家林业和草原局关于在全国范围内开展保护鸟类活动的通知》（林护发〔2025〕41 号）要求，为全面加强鸟类保护工作，严厉打击非法捕猎、买卖鸟类行为，提升全社会爱鸟护鸟意识，我局编制了《上海市保护鸟类活动工作方案》，决定自即日起在全市范围内开展保护鸟类活动。现将该方案印发给你们，请认真按照执行。
