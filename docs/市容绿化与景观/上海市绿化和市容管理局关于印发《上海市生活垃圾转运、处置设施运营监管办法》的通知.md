# 上海市绿化和市容管理局关于印发《上海市生活垃圾转运、处置设施运营监管办法》的通知

各有关单位：

《上海市生活垃圾转运、处置设施运营监管办法》经2025年11月28日市绿化市容局第13次局长办公会议审议通过，自2026年1月1日起施行，有效期至2030年12月31日。现印发给你们，请按照执行。
