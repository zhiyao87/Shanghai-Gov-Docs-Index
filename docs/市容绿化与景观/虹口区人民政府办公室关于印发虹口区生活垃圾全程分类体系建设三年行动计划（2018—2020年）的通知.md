# 虹口区人民政府办公室关于印发虹口区生活垃圾全程分类体系建设三年行动计划（2018—2020年）的通知

区政府有关部门、各街道办事处、有关单位：

《虹口区生活垃圾全程分类体系建设三年行动计划（2018—2020年）》已经区政府同意，现印发给你们，请按照执行。

虹口区人民政府办公室

2018年6月24日

虹口区生活垃圾全程分类体系建设

三年行动计划（2018—2020年）

为有序推进虹口区生活垃圾全程分类体系建设，按照市委、市政府的总体部署和市政府办公厅《关于建立完善本市生活垃圾全程分类体系的实施方案》（沪府办规〔2018〕8号）、市生活垃圾分类减量推进工作联系会议办公室《上海市生活垃圾全程分类体系建设行动计划》（沪分减联办〔2018〕5号）的精神和要求，结合本区实际，特制定本行动计划。

一、指导思想

以党的十九大精神为引领，全面贯彻习近平新时代中国特色社会主义思想和普遍推行垃圾分类制度的重要指示，按照中央城市工作会议的总体部署，坚持问题导向、需求导向、目标导向，把垃圾分类作为虹口推动城市精细化管理、“美丽家园”建设的重要路径。以强化全程管控为核心，增强处置能力为关键，落实源头分类为基础，围绕“保障无害化、加强资源化、促进减量化”，统筹谋划、补齐短板、综合治理，加快建立健全生活垃圾全程分类体系，为市民创造良好生产生活环境，满足人民群众日益增长的优美生态环境需要，全力打造高水平发展、高标准管理、高品质生活及生态宜居的现代化美丽虹口，为全市生活垃圾全程分类体系建设作出贡献。

二、工作目标

居民区生活垃圾源头分类实效明显提升，机关先行、家校互动、普遍知晓、广泛参与、单位强制，完成垃圾分类制度全覆盖；单位、居住区、公共场所垃圾分类配套基础设施规范统一，分类投放、分类收集、分类运输、分类处理的全程体系建设标准化、运行有序化、管理精细化；全面形成以法治为基础，政府推动、全民参与、因地制宜的垃圾分类制度。

2018年，一是全面实行“四分类”投放，欧阳、凉城、曲阳、广中4个街道率先完成居住区垃圾分类整区域全覆盖，其余街道完成未推行垃圾分类居住区50％的指标；二是欧阳、凉城、曲阳、广中4个街道创建上海市生活垃圾分类达标街道，并争创上海市生活垃圾分类示范街道；三是完成新增垃圾分类绿色账户居住区172个，累计达到682个，覆盖居民24.3万户；四是新建67个“两网融合”服务点位、4个“两网融合”中转站，完成定时定点垃圾箱房“四分类”标识规范及改造314个，67个点位结合智能垃圾桶、互联网、大数据等相关技术运用，构建智能投放新模式，落实定时定点制度；五是全区党政机关、学校、医院、菜场率先完成单位生活垃圾强制分类全覆盖；六是按市有关部门下达指标完成全区各类生活垃圾分类实效指标。

2019年，一是北外滩、川北、嘉兴、江湾镇四个街道完成居住区垃圾分类整区域覆盖，并创建上海市生活垃圾分类达标、示范街道；二是全区新增垃圾分类绿色账户居住区51个，累计达到733个，覆盖居民26.5万户；三是全区新建101个“两网融合”服务点位、2个“两网融合”中转站，累计完成定时定点垃圾箱房“四分类”标识规范及改造628个；四是逐步推进企业和经营性场所单位生活垃圾强制分类，单位生活垃圾强制分类效果进一步提高；五是按市有关部门下达指标完成全区各类生活垃圾分类实效指标。

2020年，一是全区单位生活垃圾强制分类基本实现全覆盖；二是在完成分类达标街道创建的基础上，创建若干分类示范街道；三是居住区垃圾分类普遍纳入住宅小区综合治理，形成持续有效的长效管理机制；四是全区累计完成定时定点垃圾房改造942个；五是全区新建101个“两网融合”服务点位，2个“两网融合”中转站；六是按市有关部门下达指标完成全区各类生活垃圾分类实效指标。

三年内，同步建设适应生活垃圾分类制度实施需求的分类投放、分类收集、分类收运、分类处理全程分类系统。

三、主要任务

（一）强化源头分类投放，实现生活垃圾规范管理。

1.推进居民家庭按照“一严禁、两分类、一鼓励”实行垃圾分类。严禁将有害垃圾混入其他各类生活垃圾。居民家庭产生的油漆罐、废旧荧光灯管等含挥发性物质的有害垃圾，应及时投放至小区内有害垃圾收集容器；居民家庭产生的废充电电池等不含挥发性的有害垃圾，可集中保留至一定量后投放至小区内有害垃圾收集容器。推进居民家庭做好日常干、湿垃圾“两分类”工作。鼓励居民将旧报纸、易拉罐、旧衣服等残值较高的可回收物通过售卖方式纳入再生资源回收利用体系；引导居民将啤酒瓶、酱油瓶等低价值可回收物交投至“两网融合”服务点或可回收物收集容器。

2.规范绿色账户管理和推行“定时定点”投放。在现有510个垃圾分类绿色账户居住区开展湿垃圾定时定点投放的基础上，依托“两网融合”服务点位建设，结合智能垃圾桶、互联网、大数据等相关技术运用，构建智能投放新模式，全面落实分类居住区生活垃圾的“定时、定点、定类、定员”服务制度。落实物业管理企业分类投放主体责任，发挥基层组织作用，提高对居民参与垃圾分类的宣传、指导、服务水平。以定时定点和分类实效为重要指标，对绿色账户居住区垃圾分类进行达标验收。

3.建立责任明确的居住区垃圾分类综合治理机制。落实街道属地主体责任，落实街道对辖区内居民区、单位的垃圾分类工作的组织、指导、监督职责。发挥基层党组织作用，充分调动基层党组织、居委、业主、物业等各方面积极性，落实各方责任，形成“四位一体”的联动机制。将垃圾分类纳入“美丽家园”行动计划，发挥党建引领住宅小区示范点“四位一体”机制在垃圾分类工作中的突出作用。

4.提升党政机关单位生活垃圾强制分类执行力。2018年完成党政机关、事业单位、学校、菜场、医院、公园和大型宾馆（餐饮）单位的强制分类全覆盖目标。一是建立党政机关和事业单位生活垃圾强制分类责任制，强化行业条线主管部门的监督指导作用，落实教育、卫生医疗等行业垃圾分类制度推行工作。二是加强属地管理，由各街道牵头落实日常管理，在强化单位生活垃圾强制分类普遍告知的基础上，加强管理检查，实现强制分类管理工作的常态化。三是严格执行“不分类、不收运”的倒逼机制，持续强化对单位生活垃圾分类容器配置、分类投放实效等执法工作。四是将单位生活垃圾强制分类执行情况纳入文明单位创建重要指标，逐步将垃圾分类行为规范教育作为各单位职工文明教育的重要内容。2020年，完成全区单位生活垃圾强制分类制度基本全覆盖。

（二）完善分类驳运体系，畅通全程分类渠道。

5.落实分类驳运责任。切实落实居住区分类投放管理责任人职责，实现驳运模式和驳运工具的规范化。按照定点以桶换桶、驳运后定点收运、箱房分类直运等模式，由街道办事处与区绿化市容局负责落实生活垃圾分类收运作业单位与区域内居住区物业或业主自治组织分类收集后的对接方式。

6.落实“两网融合”点位和再生资源回收体系建设。完成市有关部门下达的新建资源回收点和中转站任务指标。由区绿化市容局和区商务委统筹落实，跨街道设立满足再生资源分拣中转需求的再生资源中转站。推进再生资源回收体系与生活垃圾分类收运体系的“两网融合”，构建贯穿源头收集、物流运输、外运处置等关键环节的再生资源回收利用体系。落实可回收物全程运营主体企业，建立服务规范、管理有序、稳定可靠的可回收物收集运输体系，确保点、站、场之间的物流畅通。按照规范标准建立点、站、场之间的可回收物专项收运系统，与市城投（集团）公司做好对接，予以托底保障。

（三）加快设施改造升级，实施硬件标准建设。

7.落实场所分类容器设置和定时定点垃圾房改造。加强对公共场所垃圾分类的监管，重点在道路、广场、公园、公共绿地、客运站、轨道交通站点以及旅游、文化、体育、娱乐、商业等公共场所设置“可回收物”及“干垃圾”类别垃圾收集容器，实现全区735个道路废物箱的标识规范到位。落实沿街垃圾桶相关设施责任人。推行垃圾分类制度的居住区应按现行政府规章和地方标准，对分类投放点落实宣传栏、公示栏、容器标识规范化工作。结合“美丽家园”建设，三年内按年度对开展生活垃圾分类达标验收居住区的垃圾箱房进行改造，实现箱房内外容器、标识、宣传、公示、配置“五规范”。到2020年，全区居住区分类投放点的容器与标识全面实现“双规范、双到位”。

8.落实分类收运装备配置。全面落实湿垃圾专车收运和专用色彩喷涂，干垃圾车辆张贴识别性标志。各街道分别配置1辆色彩标识规范的有害垃圾专用运输工具，全区配置1辆色彩标识规范的有害垃圾专用运输机动车。到2020年，全区新增湿垃圾专项收运车40辆（其中载重量1吨的湿垃圾收运车32辆、餐厨垃圾车4辆、后装式压缩车4辆）；按要求将现有80辆四轮八桶电瓶干垃圾驳运车和四轮冲洗电瓶车更换为载重量1吨的汽油车；基本满足全区从投放点到中转站的分类驳运需求。

四、职责分工

（一）组织架构。

以虹口区推进生活垃圾分类减量工作联席会议为平台，落实成员单位职责，各成员单位主要负责同志负总责，强化联络员制度，全面实施全区生活垃圾全程分类体系建设工作。将生活垃圾分类减量工作落实情况纳入区政府对各成员单位年度目标考核内容。

（二）各成员单位职责分工。

1.区绿化市容局（区分减联办）：负责总体牵头协调推进全区生活垃圾分类工作，落实行业指导；按资产权属落实居住区垃圾箱房改造；负责会同区商务委、各街道办事处共同推进落实“两网融合”工作，完成市有关部门下达的再生资源回收点建设目标；加强分类体系建设，控制生活垃圾处理量，完成年度干垃圾末端控制量、餐厨垃圾分类量、“两网融合”分类量等分类实效指标；推进指导单位强制分类，执行单位垃圾“不分类、不收运”制度，落实管理与执法相结合的措施；进一步拓展分类居住区覆盖区域，巩固提高已分类区域成效，指导、配合各街道办事处落实新增分类居住区的推进工作；按照分类居住区达标标准，指导、配合各街道办事处落实居住区达标复核验收的创建工作；加强环卫分类收运作业管理，确保各类生活垃圾实施分类收运，杜绝混装混运，接受社会监督；建立居住区分类、单位强制分类实效检查、通报、公示制度，完善工作机制。

2.区文明办：负责将垃圾分类工作情况纳入文明城区、文明街道、文明单位、文明小区评选标准，加大宣传力度，播放垃圾分类公益广告，将垃圾分类行为规范作为文明教育的重要内容。

3.区地区办：负责指导各街道创新社会治理，利用巡展、巡演、巡讲等方式在社区开展垃圾分类和绿色账户宣传工作，普及生活垃圾分类及低碳环保知识，做好宣传培训及主题实践活动的组织协调工作。

4.区发改委：负责制定本区低价值可回收物补贴政策。

5.区商务委：负责牵头推进全区菜场湿垃圾分拣，完成年度分类实效指标；统计全区废品回收站低价值可回收物的利用量；围绕“两网融合”中转站建设目标，协助区绿化市容局落实再生资源回收主体企业及处置出路。

6.区卫计委：负责本区医院、社区卫生服务中心等医疗机构在2018年完成单位强制分类工作。

7.区财政局：负责落实生活垃圾分类和全程分类体系建设专项经费投入，根据预算情况，确保生活垃圾分类设施设备、人员补贴、购买服务、“两网融合”、宣传活动等项目资金到位。

8.区教育局：负责落实各中小学在2018年完成单位强制分类工作；落实垃圾分类知识进课堂，开展垃圾分类减量和绿色低碳知识培训，每学期在各校开展不少于1次垃圾分类相关教育和主题活动，提高分类减量的知晓率和参与率。

9.区城管执法局：负责生活垃圾分类相关执法工作的组织实施；依据《上海市促进生活垃圾分类减量办法》等法律法规，加强对垃圾分类违法行为的巡查执法；对相关部门移送的违法案件提供执法支持，做到必查严处，结案率达到100％。

10.区房管局：负责落实居住区物业企业按照生活垃圾分类工作要求，切实履行分类投放管理责任人职责；将垃圾分类相关工作纳入居住区《管理规约》《临时规约》，引导居民开展生活垃圾分类投放，杜绝源头混装驳运；在落实“美丽家园”建设过程中，按照分类要求对居住区小压站、垃圾箱房进行改造；落实居住区物业企业推进生活垃圾“四分类”定时定点收运试点；落实物业企业分类责任人制度，制定居住区物业企业开展垃圾分类实效与售后房小区物业达标奖励及商品房小区物业资质评定挂钩的工作方案。

11.区机管局：负责2018年完成本区党政机关、事业单位等公共机构开展生活垃圾强制分类的工作，发挥示范引领作用，强化垃圾分类意识。

12.各街道办事处：负责按照属地管理原则，根据年度目标任务，统筹协调、组织完成本辖区生活垃圾分类减量和绿色账户工作。完成达标小区和达标、示范）街道创建；负责“两网融合”资源回收点选址工作；在有条件的居住区推行定时定点投放，充分调动基层党组织、居委、业主、物业等各方面积极性，落实各方责任；对各类垃圾的分类收运作业进行监督；组建属地化的分类志愿者队伍，加强对志愿者服务的日常考核和质量监管；开展绿色账户积分监管，并做好日常管理工作，落实绿色账户居住区湿垃圾分类达标率；督促辖区内企业和经营性场所落实单位生活垃圾强制分类工作，加强宣传引导；完成居住区湿垃圾分类实效指标；完成其它相关工作。

13.其他各成员单位：负责支持、配合、落实相关工作。

五、工作要求

（一）加强宣传教育，使群众“愿分、会分”。

居委或楼组干部要做到“百分百入户”、定时定点指导监督，反复开展宣传教育，提高居住区分类知晓率。增加公共场所垃圾分类公益广告，营造更为浓厚的宣传氛围，开展更为细致的宣传培训。广泛推行垃圾分类知识“进机关、进校园、进课堂”，深入开展中小学垃圾分类教育，普及分类知识，通过“小手牵大手”，促进全社会习惯养成。整合社会力量，推动房屋中介组织对外来租住人员、家政公司对家政服务人员的垃圾分类知识宣传普及。

（二）健全体制机制，强化部门合作。

区绿化市容局（区分减联办）是本区此项工作带头部门，应加强对生活垃圾综合管理工作的组织和协调，确保完成本区各类生活垃圾分类实效减量达标。联席会议各成员单位应加强定期情况沟通，细化责任分工，强化工作协同，发挥推进合力。坚持管理重心下移，夯实街道对垃圾分类的组织推进工作。

（三）依托现代技术，实现垃圾分类全程监管。

结合社区现有的智能监控装置以及垃圾箱房和定时定点分类投放点改建，通过整合和新增等措施，在具备条件的居住区，开展智能监控装置对垃圾分类投放环节的监督。加快建设生活垃圾全程分类信息管理系统，实现对分类投放、分类收集、分类运输、分类处理的全程监控，做到可追溯、可监督。

（四）强化执法保障，落实监督考核。

建立多部门协同执法的协作机制，按照“条块联动、以块为主”原则，根据日常垃圾分类收运情况，对拒不开展分类及分类长期不到位的单位、居民区物业开展联合执法行动。通过政府购买服务，将定时定点投放、绿色账户积分志愿者规范值守和居住区达标示范创建情况纳入第三方测评体系，制定考核监督办法，定期排名公布。

（五）落实资金支持，确保经费投入。

在落实生活垃圾分类专项经费投入的同时，按照生活垃圾全程分类体系建设的要求，在垃圾分类标识更新，分类投放点、垃圾厢房设施改建；“两网融合”点、站、场建设和分类中转站等方面，加大财政专项资金投入。
