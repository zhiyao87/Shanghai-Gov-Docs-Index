# 黄浦区人民政府办公室关于印发《黄浦区生态空间建设和市容环境优化“十五五”规划》的通知

区政府各委、办、局，各街道办事处：

《黄浦区生态空间建设和市容环境优化“十五五”规划》已经区政府同意，现印发给你们，请认真按照执行。

特此通知。

上海市黄浦区人民政府办公室

2026年8月26日

黄浦区生态空间建设和市容环境优化“十五五”规划

为优化城区绿色生态基底和市容环境品质，根据《上海市生态空间建设和市容环境优化“十五五”规划》和《上海市黄浦区国民经济和社会发展第十五个五年规划纲要》，制定本规划。

一、总体目标

坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻习近平生态文明思想，认真践行人民城市理念，围绕黄浦区“心脏、窗口、名片”总体定位，紧扣“强新质动能、树高质标杆”发展主线，以绿色发展为底色，严守生态底线，注重生物多样性保护与提升；以品质提升为核心，坚持以人为本，丰富公园绿地综合服务功能；以高效治理为支撑，注重破圈跨界，深化与文商旅体展协同联动，全面推进绿色生态空间和市容环境高质量发展。

到2030年，聚焦黄浦区“一带一区三高地”重点功能区域，着力推进生态空间优化、环卫管理增效、市容景观提升，打造绿融生活的森系黄浦，营造洁净有序的市容环境，塑造独具魅力的璀璨夜景，全面实现城区绿化和市容环境治理效能跃升。

二、重点任务

（一）着力构建绿色低碳、多维复合的生态空间发展体系

坚持把城市作为有机生命体系统谋划，围绕公园城市建设“森系黄浦”，构建森系城区、森系街区、森系社区三维生态空间体系，强化生态连接，统筹地面立面空间，推动绿色低碳、集约复合的生态空间建设。

1.打造更生态、更系统，网络协同的森系城区

统筹全域绿色空间布局，发挥生态廊道骨架作用，有机串联口袋公园、街角绿地与立体绿化等资源，织密全域绿色网络，形成“一核引领、两区联动、多廊织网、多点渗透”的森系黄浦生态空间格局。一核引领，是指环人民广场区域以延中绿地为门户景观核心，打造一条森系生态游廊，形成空间连贯、自然共生的生态绿核，提升国际形象与服务能级。两区联动，是指世博地区浦西片区重点以“森系滨江”为理念，打造功能复合、全龄友好的滨江公共空间，重塑黄浦滨江门户形象。环新天地区域对标低碳实践区，启动淮海公园改扩建工程，以公园焕新赋能周边商业街区高品质发展。多廊织网，是指外滩金融集聚带以南浦地块绿色生态空间建设为抓手，连接董家渡地区与黄浦滨江，实现外滩—董家渡—黄浦滨江生态廊道的全线贯通。深度融合历史文化特色，推进复兴中路衡复风貌带、瑞金南路生态景观带、老城厢环城绿带、方浜路—昼锦路蓝绿丝带等森系街区建设。多点渗透，是指完善综合公园、社区公园、口袋公园、立体绿化及单位附属绿地五类生态空间节点。

2.打造更融合、更高效，功能叠合的森系街区

综合运用绿地改造、景观重塑、小微空间活化等微更新手法，构建地面、墙面、屋顶一体化的森系街区。打造开放共享的绿色节点，从增量建设转向存量更新，重点推动封闭、单一的绿地空间向开放、复合转变，推动单位附属绿地开放共享5个，打造以生态为基、景观为形、人文为魂、休憩社交功能完善的口袋公园10个。活化利用街角空地、桥下空间、硬质地面等灰色空间，打造小尺度柔性绿色空间。建设联通共生的绿色脉络，实施“串珠成链”工程，改造行道树连接带，营造近自然群落式花境，形成连续贯通、风貌协调的线性生态空间，丰富街区绿色景观。构建立体复合的绿色界面，持续挖潜垂直空间生态价值，鼓励墙面、阳台、檐口绿化。倡导公共建筑打造空中花园、生态展厅等“类公园”复合空间，沿街围墙、公交站台、市政箱体等设施融入垂直绿化设计，形成地面立面联动、室内室外无界的街区生态网络。

3.打造更开放、更突破，全民共享的森系社区

促进绿色生态融入公共服务，森系元素渗透生活方式，营造市民群众身边可感知、可参与、可共情的绿色生态场景。打造触手可及的生态空间，坚持低维护、乡土化、功能性为原则，推广集生物多样性保护、休闲游憩、生态科普于一体的社区植物园。结合“零距离科普生态圈”建设，增设生物友好型设施与自然观察点，打造沉浸式生态科普空间。营造全龄友好的生态场景，响应多元需求，推进公园绿地适老化、适儿化改造，优化儿童运动空间，完善各类服务设施，丰富自然教育场景，提升儿童友好公园的自然感知度与吸引力。进一步探索开放宠物友好、帐篷友好区域。推动绿意入户的生活风尚，深化“最美窗阳台、社区花园”等倡议，探索“区—街—社区”层级联动、社区协同、公众参与机制，创新“专业指导+居民自治”共管模式，激发社区内生动力，鼓励居民美化窗台、阳台、弄堂等私人空间，打造家里面、家门口的微花园，形成绿意盎然、邻里共护的社区氛围。

（二）着力构建精准施策、活力彰显的绿色发展长效体系

1.深化绿化资源监测与生态保护修复

健全林长制与精细化养护管理体系，以“林长制”促“林长治”，落实公园绿地分类分级管理，实施低扰动施工、低成本维护，加大绿化养护机械化设备投入，科学开展国土绿化养护管理。强化行道树科学修剪与动态维护，实行一路一策、分类施策，兼顾树木健康、果毛控制、安全防护、风貌保护与居民诉求。在衡复风貌区等重要区域推广行道树健康监测技术，在老旧居住区探索建立树木修剪的长效协同机制，全面提升行道树精细化、专业化、人性化管护水平。加强生态提质与生物多样性保护，加大乡土树种应用与高碳汇植物配置，开展生境适宜性改造，增强生物多样性与生态修复能力。扎实开展野生动植物保护，推进野生动物非法交易专项整治，做好野生动物收容救护。推进古树“一树一园”建设，深化古树名木健康监测、数字化保护与科普利用。

2.扩大“公园+”品牌效应与综合服务效能

积极践行“公园+”理念，办好上海国际花卉节黄浦会场、环复兴公园艺术季等活动，与文商旅体展联动融合发展，塑造城市花事IP，实现生态文化品牌影响力叠加与价值辐射，推动生态价值向经济效益、消费流量、产业衍生等转化，全面激活城区活力与生态品质形象。提升公园绿地服务效能，推进“无废公园”建设，加强公园绿地场所应急管理，更新升级安防设施，完善大客流预警与应急处置体系，全面提升开放公园绿地内公厕建设质量与管理服务水平，保障开放空间品质与安全。丰富园艺文化活动载体，依托市民园艺中心，推广园艺文化，升级园艺大讲堂等课程，打造兼顾日常与节假日模式的市民园艺生活场景。

3.推动公园开放共享与融合治理

实施一园一策，扩大草坪、林下空间开放范围，推动有条件的公园实现24小时开放。秉持公园公共属性和环境定位，探索分类运营与复合功能，临时性活动入园与长期运营的分类管理模式，盘活利用公园低效空间，引入符合公园定位的设施业态和服务场景，激发公园多元价值。夯实公园融合管理机制，打破空间壁垒，探索淮海公园、蓬莱公园24小时开放后与周边街区、商圈在空间、功能与治理上的联动管理模式，促进自然生态与城市生活的有机链接。

（三）着力构建流程可控、协同高效的垃圾综合治理体系

1.优化生活垃圾全程分类体系

深化联席联动机制，健全定期研商制度，坚持依法治理，严格落实管行业必须管垃圾分类的要求。巩固提升源头生活垃圾分类实效，强化分类投放管理，坚持“一小区一方案”，深化定时定点等源头分类措施。改善分类投放环境，因地制宜持续推动老旧投放点友好化改造，规范临时投放点设置，落实容器标识、配套设备和宣传公示设施配备要求，实现环境整洁、墙面洁净、地面平整、投放便利。优化分类收运体系，推进环卫新能源车辆更新，进一步规范环卫清运作业，健全“不分类不收运”机制。完善可回收物体系建设，优化可回收物服务网络，升级服务质量与运行效能。推动低碳时尚理念普及，建设垃圾分类精细化样板区域，强化社会动员力度，充分发挥志愿服务作用，凝聚全民参与合力，擦亮城市文明底色。

2.强化建筑垃圾治理

严抓源头核算与闭环核查，强化建设工地工程渣土消纳处置的核量，定期梳理源头产生量、出土量和消纳量。在建设项目竣工验收前，严格开展工程渣土消纳处置差异量核查，发现线索及时移送城管执法部门。强化运输处置流程智慧监管，实现辖区内建设项目施工现场建筑垃圾运输车辆视频监控设备全覆盖，推进全过程电子联单制度。依托上海市建筑垃圾数字化智能监管平台，推进建筑垃圾数字化监管覆盖率达90%以上。优化居民装修垃圾收运体系，推进辖区内居民小区装修垃圾收运新模式覆盖率达100%，开发黄浦区居民区装修垃圾预约收运小程序，优化清运预约机制，落实居民区装修垃圾清运“双公示”制度。加大小程序推广力度和功能优化，督促作业服务企业规范收运，确保物流衔接通畅、服务高效便民。

3.夯实环卫基础保障

建设集约复合型环卫设施，有效推进可回收物中转站（场）的建设实施，优化设施布局，提升土地复合利用效率。全力推进南苏州路环卫大楼建设，推动设施复合化、功能多元化，完善保障覆盖全区的环卫停车网络。提升环卫保洁管理效能，推动道路保洁模式创新与装备更新，巩固已建成高标准保洁区域实效，发挥已建成区域辐射带动作用，不断提高作业效率和作业质量。提升环卫公厕服务能级，持续优化公厕人性化服务，提升24小时开放环卫公厕夜间保洁管理水平。规范开展区管水域环卫保洁作业。

（四）着力构建规范有序、品质宜居的市容环境管理体系

1.推进市容环境品质提升

厚植黄浦区历史文脉和风貌传承，持续推动美丽街区建设和巩固提升，聚焦滨江岸线、环老城厢区域、重要商圈、个性道路等，深化与公园城市建设、一街一路建设等城市更新工作的衔接。坚持生态优先，新增提升7个美丽街区，推动“美丽街区+”溢出效应。优化提升公园绿地休憩座椅的布局与服务功能。加强市容环境常态长效管理，深化全域门责管理机制，依托“多格合一”压实特定区域内责任单位门前环境秩序主体责任，强化宣传培训，明确职责清单，赋能基层治理。固化重大活动保障机制，推进绿化景观、道路保洁、垃圾分类等保障任务，系统提升重要区域的市容环境品质。坚持设摊管理疏堵结合，坚决遏制无序设摊，科学设置设摊区域，规范管理设摊及外摆位活动，完善线上备案与监管机制，兼顾烟火气与秩序感。

2.促进景观照明创新发展

立足黄浦区海派夜景资源禀赋，统筹景观灯光整体布局，坚持弘扬传统文化、彰显区域特色、体现人文情怀，培育常看常新、温暖舒适的灯光景观，助力“世界著名夜游城市”建设。持续办好上海国际光影节黄浦会场，打造一流的夜景文化IP，推动融入演艺大世界，探索建立专业化、市场化、可持续化的长效运营机制，推动景观照明联动共生。坚持片区差异化塑造，以夜景提质赋能区域经济社会发展。外滩金融集聚带将依托外滩第二立面更新、北京东路转型，促进“一江一河”夜景继续向纵深区域延伸；世博地区浦西片区做好各类国际交流、文博庆典和都市科创活动的景观配套服务工作；“三高地”区域联动重大活动和重要节庆，政企联手推动打造丰富多元的夜景风貌和“光影+”夜间消费场景，塑造具有黄浦韵味的城区夜景。推动景观照明绿色低碳发展，实现景观照明节能灯具使用率达到98%以上，重点区域景观照明纳控率达98%。持续完善数字化智慧照明集控系统，推广低碳/零碳照明技术，实现景观照明服务新升级。

3.推动广告招牌规范提质

深化广告招牌专项治理，推动管理和服务水平双提升。健全全流程监管体系，筑牢安全规范底线。依托信息化技术，推动户外广告招牌的设置方、管理方牢固树立规范设置和维护自检的主体责任意识。常态化开展安全抽检，实施户外广告招牌安全监管行动和连体招牌专项治理行动。推动广告招牌个性化创意发展，规范材料工艺，优化广告设施展示与控制布局，促进广告招牌与街区特色风貌融合。探索人工智能技术赋能户外招牌管理与创意升级，构建户外广告招牌视觉模型与用户定制平台，降低中小商户设计与管理成本。优化产业生态环境，以市场需求为导向，修编户外广告设施设置实施方案，支持创意广告点亮新地标，支持重点区域探索新型广告，为内容创作和广告创意提供优质土壤，助力推动产业联动和文化创新。

（五）着力构建优质高效、数字智能的公共服务支撑体系

1.深化便捷精准的政务服务水平

探索人工智能综合应用，推进许可事项办理更高效便民。发挥区政务中心平台作用，深化多部门协作机制。提供线上线下专业审图等帮办服务，拓展前台、中台、后台联动审批，进一步深化全程网办。拓展一件事改革，优化智能客服，以“开店一件事”整合店招、装修、垃圾清运等，实施六个再造与全域联动。推动“一业一证”改革，实现惠企政策免申即享，巩固一站式综合竣工验收等，深化工程建设领域改革。探索审管执信管理闭环，加强审批事中事后与信用监督。

2.提升智能高效的信息化治理能力

夯实平台建设，打造覆盖绿化市容业务的数据共享平台，实现业务流程链条化。优化生活垃圾全程分类平台，完善生活垃圾征收费、生活垃圾全流程智能监管、环卫公厕管理等功能建设。推进智慧园林建设，赋能绿化管理、养护和巡查工作。深化场景应用，整合公厕、中转站等环卫设施基础数据，为设施供给与区域需求优化布局提供数据支撑。持续推动区内可回收物中转站计量数据自动直连市级平台，实现数据接入覆盖率与精准度双提升。拓展管理效能，在人流密集、景观道路等区域优先打造生活垃圾智慧收运路线，实现收运智能实时监控和服务效能提升。推动实现行政审批、综合指挥、设施设备资产管理、跨部门业务流转等功能。

三、重要项目

（一）世博地区浦西片区公共空间提升项目

市区协同，以区为主，重点推进滨水公共空间改造建设，美化提升防汛墙，重塑临江水际线，柔化并活化3.5公里滨江岸线空间，打造全民乐享的“森系滨江”公共空间。推进迎水界面整治，结合周边环境开展防汛墙景观美化。整合贯通空间，梳理完善慢行系统；升级驿站业态与休闲功能，改造中段原五里桥市民驿站，进行立面更新；整合绿地植被并提升品质，营造特色景观场景；整体提升夜间照明，重塑夜游黄浦滨江新场景。

（二）055-4地块暨淮海公园改扩建工程

055-4地块暨淮海公园改扩建工程，通过征地扩容、空间重塑与生态提升，打造兼具传承经典与现代艺术气息的高品质公园。打开公园围墙，实现与沿街绿化自然衔接，与商业街区无界融合。保留公园的生态基底和历史记忆，同步升级景观节点、配套用房及地下空间，塑造淮海新天地高端商务与贸易联动高地的环境基底，为市民游客提供优质的休闲游憩空间，助力新天地区域文商旅体展高质量融合发展。

（三）南苏州路环卫大楼新建工程

南苏州路环卫大楼通过合理规划布局，推进环卫设施集约化建设，建成后集公共绿地、环卫车辆停车及作业等多功能于一体，并增设市民休憩及文化展示空间，提升周边区域公共服务能力。通过地上地下空间复合利用，有效破解环卫设施资源紧张与布局不均难题，提升环卫服务保障能力。

四、保障措施

遵循统筹协调、动态平衡原则，优化土地资源配置，结合城市更新挖掘地下空间潜力，推动绿化建设、环卫设施用地与城市空间有机衔接。深化管执联动、属地协同，夯实行业指导基础，面向不同群体分层开展主题宣教，普及绿色生态、垃圾分类、市容环境等方面的法律法规，提升行业法治化水平与社会参与度。深化与高校、科研机构的合作，从平台共建、资源共享、产学研协同、政策创新等方面，引入前沿理念，提升实践能力，通过局部应用积累经验，探索中心城区生态价值的实现路径，完善技术应用与成果转化机制，为绿化市容提质增效提供支撑。
