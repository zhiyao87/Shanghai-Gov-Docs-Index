# 上海市绿化和市容管理局关于延长《上海市绿化行政许可审核若干规定》有效期的通知



各区县绿化市容管理部门，各相关局处室、直属单位：
市绿化市容局发布的《上海市绿化行政许可审核若干规定》（沪绿容〔2010〕384号）规范性文件，经评估，决定继续实施，其有效期延长至2014年12月31日。
特此通知。
