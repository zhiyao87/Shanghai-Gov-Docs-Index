# 上海市绿化和市容管理局关于发布《上海市国家重点保护陆生野生动物（实验用食蟹猴）人工繁育许可证核发行政审批告知承诺试行办法》的通知

各区绿化和市容管理局：

为进一步优化以科研为目的人工繁育食蟹猴（Macaca fascicularis）的行政审批服务，按照《上海市人民政府办公厅印发〈关于在中国（上海）自由贸易试验区开展“证照分离”改革全覆盖试点的实施方案〉的通知》（沪府办〔2019〕126号）的要求，依据《中华人民共和国野生动物保护法》《上海市行政审批告知承诺管理办法》《国家重点保护野生动物人工繁育许可证管理办法》（林策字〔1991〕6号）《国家林业和草原局公告（2019年第19号）》，我局研究制定的《上海市国家重点保护陆生野生动物（实验用食蟹猴）人工繁育许可证核发行政审批告知承诺试行办法》已经市推进政府职能转变和行政审批制度改革领导小组办公室同意。按照《上海市行政审批告知承诺管理办法》（上海市人民政府令2018年第4号）规定，我局同步制定了《上海市国家重点保护野生动物（实验用食蟹猴）人工繁育许可证核发行政审批告知承诺后续监管规程》。现印发给你们，请认真按照执行。

附件：

1．上海市国家重点保护陆生野生动物（实验用食蟹猴）人工繁育许可证核发行政审批告知承诺试行办法

2．上海市国家重点保护野生动物（实验用食蟹猴）人工繁育许可证核发行政审批告知承诺后续监管规程
