# 关于印发《上海市居住区绿化调整实施办法》的通知



为加强本市居住区绿化管理，规范居住区绿化调整行为，依据《上海市绿化条例》和《上海市住宅物业管理规定》，结合本市实际情况，对《上海市居住区绿化调整实施办法》进行了修订，现印发给你们，请遵照执行。
特此通知。
上海市绿化和市容管理局   上海市住房和城乡建设管理委员会
2017年7月25日
