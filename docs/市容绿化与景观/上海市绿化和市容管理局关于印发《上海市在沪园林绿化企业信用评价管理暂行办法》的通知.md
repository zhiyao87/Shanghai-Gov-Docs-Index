# 上海市绿化和市容管理局关于印发《上海市在沪园林绿化企业信用评价管理暂行办法》的通知



各有关单位：
为进一步规范本市园林绿化市场秩序，建立健全园林绿化企业（施工企业）信用评价体系，营造诚信守法的市场环境，依据《上海市建筑市场管理条例》、《上海市建筑市场信用信息管理暂行办法》等相关规定，我局制定了《上海市在沪园林绿化企业信用评价管理暂行办法》，现印发给你们，请遵照执行。
特此通知。
2015年11月3日
