# 关于进一步完善本市园林绿化工程施工招标评标办法的通知

关于进一步完善本市园林绿化工程施工招标评标办法的通知

沪建建管联〔2021〕828号

各有关单位：

为进一步规范本市园林绿化工程施工招投标活动，维护招投标当事人的合法权益，根据《中华人民共和国招标投标法》、《中华人民共和国招标投标法实施条例》、《上海市建筑市场管理条例》、《上海市建设工程招投标管理办法》（沪府令 50号）、《上海市住房和城乡建设管理委员会关于修订印发＜上海市房屋建筑和市政工程施工招标评标办法＞的通知》(沪建建管〔2019〕792 号)（以下简称《施工招标评标办法》）、《关于进一步优化营商环境加强本市园林绿化建设工程管理的通知》(沪绿容规〔2019〕3 号)等有关规定，结合园林绿化工程的特点，现对本市依法必须进行园林绿化工程施工公开招标评标工作相关事项通知如下：

一、评标办法的种类与适用范围

本市园林绿化工程施工招标评标办法包括经评审的合理低价法、综合评估法（一）、综合评估法（二）、有担保的最低价中标法以及法律、法规允许的其他评标办法。具体适用范围如下：

1.经评审的合理低价法和有担保的最低价中标法适用范围：标段合同估算价在限额以上的小型或中型工程项目。

2.综合评估法（一）适用范围：工程等级为大型(或特大型)或者施工技术复杂的工程项目。

3.综合评估法（二）适用范围：工程等级为大型(或特大型)且施工技术复杂的工程项目。

二、工程等级划分标准

1.特大型工程项目是指：单项合同额≥5000 万元的园林绿化工程。

2.大型工程项目是指：2000 万元≤单项合同额<5000 万元的园林绿化工程。

3.中型工程项目是指：800 万元<单项合同额<2000 万元的园林绿化工程。

4.小型工程项目是指：单项合同额≤800 万元的园林绿化工程。

5.施工技术复杂是指：涉及高程大于 5 米的高堆土项目、高程大于 3 米的假山项目、古树名木保护项目、专类园改造和建设项目、复杂施工环境等。

三、其他

1.园林绿化工程下浮率抽取范围为 3%-8%，在开标时抽取。

2.本通知未尽事宜，参照《施工招标评标办法》执行。

四、施行日期

本通知自 2021年12月23日起施行，有效期五年。原《关于进一步规范本市园林绿化工程施工招标评标办法的通知》（沪建管联〔2015〕701号）同时废止。
