# 上海市绿化和市容管理局关于发布《上海水面清扫船技术要求》的通知



各有关单位：
为规范上海水面清扫船技术要求，优化设备资源配置，提高水域保洁水平，我局编制的《上海水面清扫船技术要求》经审查批准，现予发布，编号为LHSR02—2012，请各有关单位在水面清扫船的配置与建设中遵照执行。
附件：《上海水面清扫船技术要求》（点击下载）
二○一二年四月十三日
