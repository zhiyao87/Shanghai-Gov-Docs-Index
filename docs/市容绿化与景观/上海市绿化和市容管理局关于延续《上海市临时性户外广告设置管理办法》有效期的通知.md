# 上海市绿化和市容管理局关于延续《上海市临时性户外广告设置管理办法》有效期的通知



2013年6月21日上海市绿化和市容管理局制定的《上海市临时性户外广告设置管理办法》（沪绿容〔2013〕202号）经评估需继续实施，有效期延续至2023年6月30日。
特此通知。
