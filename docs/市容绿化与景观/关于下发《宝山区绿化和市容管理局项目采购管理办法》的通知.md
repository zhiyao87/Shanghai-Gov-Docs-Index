# 关于下发《宝山区绿化和市容管理局项目采购管理办法》的通知

各基层单位、机关各科室：

为贯彻落实《上海市政府集中采购目录及标准（2021年版）》、《关于进一步规范本市政府采购信息公开有关事项的通知》、《关于限额以下采购项目信息发布相关工作的通知》、《宝山区政府购买服务实施办法》等文件精神，经局党组研究决定，重新修订本局项目采购管理办法。现下发给你们，请遵照执行。

上海市宝山区绿化和市容管理局

2022年11月24日
