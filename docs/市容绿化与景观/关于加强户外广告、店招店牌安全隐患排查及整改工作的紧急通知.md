# 关于加强户外广告、店招店牌安全隐患排查及整改工作的紧急通知



受今年第18号台风“温比亚”影响，预计16日晚到17日白天，本市将出现50-80毫米、局部地区100-150毫米、个别地区200毫米左右的强降雨。“摩羯”和“温比亚”两次台风暴雨间隔不到一周，受风雨侵蚀，户外广告、店招店牌易发生坠落危险。根据市委市政府领导指示和全市防汛防台工作统一部署，请各区进一步加大力度加强户外广告、店招店牌安全隐患的排查及整治工作，现将有关要求通知如下：
一、全面落实防汛防台各方责任
要依法进一步落实商家、业主和广告公司在户外广告、店招店牌安全隐患排查整改的主体责任；按照防汛防台总体部署，强化街镇属地管理和行业分类管理职责，切实做到跨前一步，主动对接，形成防御台风工作的合力。
二、全面告知无遗漏
多种形式组织力量对辖区商家、业主、广告公司做好户外广告、店招店牌设施安全排查的再次书面告知。再次书面告知要做到全覆盖，无遗漏。告知书除了安全提示外，要增加商家、业主、广告公司作为主体应负法律责任的警示提醒。
三、全面排查无盲区
发动街镇居委对辖区户外广告和店招店牌设施进行地毯式、全覆盖排查，重点是加强人流密集区、重要商圈、建成时间久、体积大、旧改基地、附着在老建筑上以及停业歇业无主的户外广告、店招店牌安全隐患的排查，排查工作确保做到无盲区、无死角。
四、全面排除安全隐患
对业主自查、管理部门排查发现的问题，及时督促商家、业主、广告公司进行整改，自行整改确有困难的，各级政府要帮助整改。对存在安全隐患的，要采取果断措施排除隐患，确保“温比亚”台风来临前不留隐患。对可能存在隐患但来不及处置的，应协调有关部门设置安全隔离设施，确保不发生人员伤亡事故。
上海市绿化和市容管理局办公室
