# 关于印发《上海市绿化和市容管理局标准化管理若干规定（2025年修订）》《上海市绿化和市容管理局定额管理若干规定（2025年修订）》的通知

各直属单位、相关单位：

为进一步加强行业标准化和定额项目规范化管理，增强行业质量发展的标准化和定额基础,助力城市精细化管理水平的提升，经局2025年第15次局长办公会审议通过，现将《上海市绿化和市容管理局标准化管理若干规定（2025年修订）》《上海市绿化和市容管理局定额管理若干规定（2025年修订）》印发给你们，请遵照执行。

上海市绿化和市容管理局

2025年12月29日
