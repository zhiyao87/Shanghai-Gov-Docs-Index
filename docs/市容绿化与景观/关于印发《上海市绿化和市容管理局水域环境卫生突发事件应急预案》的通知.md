# 关于印发《上海市绿化和市容管理局水域环境卫生突发事件应急预案》的通知

各区绿化市容局，市水管处，各相关单位：

为进一步贯彻实施《上海市水域市容环境卫生管理规定》（上海市人民政府令第50号），建立规范、高效的水域环境卫生突发事件应急处置体系，做好在重大活动、水生植物爆发性生长以及漂浮废弃物聚集等情况下的保洁保障和快速处理工作，有效预防和处置水域环境卫生突发事件，依据《上海市绿化和市容管理局突发事件总体应急预案》《上海市绿化和市容管理局水域保洁突发事件应急预案》等相关规定，现制定印发《上海市绿化和市容管理局水域环境卫生突发事件应急预案》，请结合工作实际按照执行。

上海市绿化和市容管理局

2021年12月17日

上海市绿化和市容管理局水域环境卫生突发事件应急预案

1总则

1.1编制目的

依据《上海市水域市容环境卫生管理规定》第十八条关于“市、区绿化市容、水务部门以及镇（乡）人民政府应当编制水域环境卫生突发事件应急预案，做好在重大活动、水生植物爆发性生长以及漂浮废弃物聚集等情况下的保洁保障和快速处理工作”的规定，编制本预案。

1.2编制依据

《上海市水域市容环境卫生管理规定》《上海市绿化和市容管理局突发事件总体应急预案》《上海市绿化和市容管理局水域保洁突发事件应急预案》《上海市水域保洁区域的保洁等级和具体范围》，以及CJJ/T174-2013《城市水域保洁作业及质量标准》等。

1.3适用范围

本预案适用本市绿化市容行业职责范围内的水域环境卫生突发事件的应对工作。

1.4工作原则

防治结合，预防为主。统一领导，分级负责。依法规范，加强管理。快速反应，协同应对。

1.5突发事件分级

水域环境卫生突发事件按照其性质、严重程度、可控性和影响范围等因素，分为四级：Ⅳ级（一般）、Ⅲ级（较大）、Ⅱ级（重大）和Ⅰ级（特大）。

2风险分析

2.1因水面大量漂浮废弃物聚集，影响重大活动区域及周边水域环境质量。

2.2因水生植物爆发性生长，影响本市水域市容环境。

2.3因船舶事故、船废收运作业不规范、责任区履职不到位、台风等极端天气影响以及动物尸体、雨水泵站放江污染等原因，造成漂浮废弃物聚集，严重污染水域。

3组织体系

3.1领导机构

市局应急领导小组是全市绿化市容行业突发事件应急管理工作的领导机构，统一领导本行业水域环境卫生突发事件的应急管理工作。

3.2办事机构

市局应急办是市局应急领导小组的日常办事机构，设在市局办公室。

3.3工作机构

市局环卫管理处在市局应急领导小组的统一领导下，负责领导、组织、协调水域环境卫生突发事件的预防和应急处置工作。市水管处根据市局环卫管理处要求，负责水域环境卫生突发事件应急处置组织、指导、协调的具体工作。

各区绿化市容管理部门负责本辖区水域环境卫生突发事件应急处置的具体工作。

4监测与响应

4.1监测

市、区绿化市容管理部门应当按照各自职责范围，建立完善监测机制，做到早发现、早报告、早处置。有关部门和单位应当将可能发生Ⅱ级以上突发事件的监测信息及时上报市局。

4.2响应分级

根据相关事项的管理要求以及突发事件可能造成的危害性、紧急程度和发展势态、影响范围等因素，将水域环境卫生突发事件的应急响应分为四级：Ⅳ级（一般）、Ⅲ级（较大）、Ⅱ级（重大）和Ⅰ级（特大）。

4.3响应信息的发布

Ⅳ级（一般）应急响应信息由突发事件发生水域的主管绿化市容管理部门分管领导在一定范围内发布；

Ⅲ级（较大）应急响应信息由突发事件发生水域的主管绿化市容管理部门主要领导在一定范围内发布；

Ⅱ级（重大）应急响应信息由市局应急领导小组授权市局环卫管理处在一定范围内发布；

Ⅰ级（特大）应急响应信息由市局应急领导小组授权市局应急领导小组分管副组长宣布，市局环卫管理处在一定范围内发布。

5应急响应

5.1重大活动的保障和快速处置

5.1.1启动条件

Ⅳ级响应启动条件：单一行政区域内举办一般性活动或赛事期间，涉及水域环境卫生保障的。

Ⅲ级响应启动条件：单一行政区域内举办具有较大影响力的活动或赛事期间和跨行政区域举办一般性活动或赛事期间，涉及水域环境卫生保障的。

Ⅱ级响应启动条件：跨行政区域举办具有较大影响力的活动或赛事期间（如苏州河国际龙舟赛等），涉及水域环境卫生保障的。

Ⅰ级响应启动条件：国家级重大活动或赛事（如进博会等具有重大国际影响的国事活动、国际交往活动、国家庆典或赛事）举办期间，涉及水域环境卫生保障的。

5.1.2分级响应

Ⅳ级响应措施：制定专项保障方案，相关水域保洁作业频率增加至日常的1.2倍，保障活动区域内水域整洁，并做好应急值守工作。

Ⅲ级响应措施：制定专项保障方案，启用应急备用船舶及人员，相关水域保洁作业频率增加至日常的1.5倍，保障活动区域内水域整洁，并做好应急值守工作。

Ⅱ级响应措施：制定专项保障方案，启用应急备用船舶及人员，必要时租用社会力量，相关水域保洁作业频率增加至日常的2倍，保障活动区域内水域整洁，并做好应急值守工作。

Ⅰ级响应措施：制定专项保障方案，活动举办前，开展专项整治工作，做好周边及上下游水域污染点排查整治；活动举办期间，启用应急备用船舶及人员，必要时租用社会力量，相关水域保洁作业频率增加至日常的2倍以上，视情况协调海事部门对通航河道实施间歇性交通管制，保障活动区域内水域整洁，并做好应急值守工作。

5.2水生植物爆发性生长的保障和快速处置

5.2.1启动条件

Ⅳ级响应启动条件：三级保洁区域、二级保洁区域①出现水生植物带状污染，以日常水生植物整治力量不能及时清除的。

Ⅲ级响应启动条件：一级保洁区域出现水生植物带状污染，以日常水生植物整治力量不能及时清除的。

Ⅱ级响应启动条件：黄浦江上游米市渡水域、苏州河上游G2高速公路桥水域出现水生植物带状污染，以日常水生植物整治力量不能及时清除的。

Ⅰ级响应启动条件：黄浦江、苏州河市直管水域②出现水生植物带状污染，以日常水生植物整治力量不能及时清除的。

5.2.2分级响应

Ⅳ级响应措施：相关各区根据水生植物污染动态进一步加强打捞作业，及时清除辖区内水生植物污染。

Ⅲ级响应措施：沿线各区根据水生植物污染动态，进一步加强市级河道的打捞作业，及时清除水生植物污染，并在沿线增设临时拦截设施，减轻下游压力，防止对黄浦江、苏州河干流造成污染；同时，各区将水生植物污染及拦捞作业情况及时通报市水管处。必要时，由市属作业单位启用省界拦截库区作业予以增援。

Ⅱ级响应措施：根据水生植物污染动态，全面启用应急备用船舶及人员，启用省界及黄浦江、苏州河市属拦截库区,必要时调用日常保洁作业船舶和人员、增设临时拦截库区，及时清除水生植物污染，防止对黄浦江、苏州河市直管水域造成污染。

Ⅰ级响应措施：根据水生植物污染动态，全面启用应急备用船舶及人员，启用省界及黄浦江、苏州河市属拦截库区,调用日常保洁作业船舶和人员、增设临时拦截库区，必要时租用社会力量，及时清除水生植物污染。同时，适时协调海事部门对部分河道实施间歇性交通管制,开展封航作业。

5.3漂浮废弃物聚集的保障和快速处置

5.3.1启动条件

Ⅳ级响应启动条件：因船舶事故、船废收运作业不规范、责任区履职不到位、台风等极端天气影响以及动物尸体、雨水泵站放江污染等情况，导致出现下列情况之一，以日常保洁力量不能迅速予以控制清除,影响水域环境卫生面貌的，启动Ⅳ级响应。

1.三级保洁区域5000㎡内漂浮物面积累计超过80㎡；

2.二级保洁区域5000㎡内漂浮物面积累计超过60㎡；

3.一级保洁区域5000㎡内漂浮物面积累计超过40㎡；

4.特级保洁区域5000㎡内漂浮物面积累计超过20㎡；

5.长江口水域沿岸1km内聚集垃圾面积超过500㎡。

Ⅲ级响应启动条件：因船舶事故、船废收运作业不规范、责任区履职不到位、台风等极端天气影响以及动物尸体、雨水泵站放江污染等情况，导致出现下列情况之一，以日常保洁力量不能迅速予以控制清除,影响水域环境卫生面貌的，启动Ⅲ级响应。

1.三级保洁区域5000㎡内漂浮物面积累计超过160㎡；

2.二级保洁区域5000㎡内漂浮物面积累计超过120㎡；

3.一级保洁区域5000㎡内漂浮物面积累计超过80㎡；

4.特级保洁区域5000㎡内漂浮物面积累计超过40㎡；

5.长江口水域沿岸1km内聚集垃圾面积超过1000㎡。

Ⅱ级响应启动条件：因船舶事故、船废收运作业不规范、责任区履职不到位、台风等极端天气影响以及动物尸体、雨水泵站放江污染等情况，导致出现下列情况之一，以日常保洁力量不能迅速予以控制清除,影响水域环境卫生面貌的，启动Ⅱ级响应。

1.三级保洁区域5000㎡内漂浮物面积累计超过240㎡；

2.二级保洁区域5000㎡内漂浮物面积累计超过180㎡；

3.一级保洁区域5000㎡内漂浮物面积累计超过120㎡；

4.特级保洁区域5000㎡内漂浮物面积累计超过60㎡；

5.长江口水域沿岸1km内聚集垃圾面积超过1500㎡。

Ⅰ级响应启动条件：因船舶事故、船废收运作业不规范、责任区履职不到位、台风等极端天气影响以及动物尸体、雨水泵站放江污染等情况，导致出现下列情况之一，以日常保洁力量不能迅速予以控制清除,影响水域环境卫生面貌的，启动Ⅰ级响应。

1.三级保洁区域5000㎡内漂浮物面积累计超过320㎡；

2.二级保洁区域5000㎡内漂浮物面积累计超过240㎡；

3.一级保洁区域5000㎡内漂浮物面积累计超过160㎡；

4.特级保洁区域5000㎡内漂浮物面积累计超过80㎡；

5.长江口水域沿岸1km内聚集垃圾面积超过2000㎡。

5.3.2分级响应

Ⅳ级响应措施：根据污染情况，迅速组织力量到场开展水面清扫保洁作业；控制污染范围，防止造成更大范围的水域环境卫生污染；根据现场条件，必要时布设临时性的拦截设施及围油栏。长江口水域沿岸由占用或使用岸线的责任区单位或公用段海塘管理部门及时组织力量，尽快清理污染。

Ⅲ级响应措施：根据污染情况，启用备用作业船舶及人员，迅速到场开展水面清扫保洁作业；控制污染范围，防止造成更大范围的水域环境卫生污染；根据现场条件，必要时布设临时性的拦截设施及围油栏。长江口水域沿岸由占用或使用岸线的责任区单位或公用段海塘管理部门，进一步增加作业力量，尽快清理污染。

Ⅱ级响应措施：根据污染情况，启用备用作业船舶及人员，迅速到场开展水面清扫保洁作业，必要时，向社会租借船舶补充作业力量；控制污染范围，防止造成更大范围的水域环境卫生污染；根据现场条件，必要时布设临时性的拦截设施及围油栏，并协调海事部门为打捞作业提供便利。长江口水域沿岸由占用或使用岸线的责任区单位或公用段海塘管理部门，进一步增加作业力量，必要时发动社会力量共同参与，尽快清理污染；同时，及时通报市级管理部门。

Ⅰ级响应措施：根据污染情况，启用备用作业船舶及人员，迅速到场开展水面清扫保洁作业，必要时，向社会租借船舶补充作业力量；控制污染范围，防止造成更大范围的水域环境卫生污染；根据现场条件，必要时布设临时性的拦截设施及围油栏，并协调海事部门对部分河道实施局部交通管制，开展封航作业。长江口水域沿岸由占用或使用岸线的责任区单位或公用段海塘管理部门，进一步增加作业力量，发动社会力量共同参与，尽快清理污染；同时，及时通报市级管理部门。必要时，在全市范围内发动引导社会力量共同参与。

6应急保障

6.1队伍保障

市水管处、各区绿化市容管理部门应当根据环卫行业的实际情况，建立专职、兼职水域环境卫生突发事件应急处置队伍。

6.2物资及装备保障

市水管处、各区绿化市容管理部门应当建立健全水域环境卫生突发事件应急物资储备及装备保障制度，储备足量的抢险物资、器材，配备充足的船舶、装备。

6.3人员防护

各有关单位应当为涉险人员和应急处置人员提供符合要求的安全防护装备和培训，采取必要的防护措施，严格按照程序开展应急处置工作，确保人员安全。现场作业人员应穿救生衣等防护用品，具备相应的专业技能。

6.4其他保障

市、区绿化市容管理部门在同级财务管理部门、科技信息部门的支持下做好水域环境卫生突发事件应急处置的经费、通讯、科技等保障工作。

7附则

7.1名词解释

7.1.1保洁区域：保洁区域的等级划分和具体范围，根据《上海市水域保洁区域的保洁等级和具体范围》确定。

7.1.2市直管水域：指黄浦江（吴淞口——关港仓库港池南端）、苏州河（东港口——长宁西界<华漕>）、长江口（浏河口市界——大治河口）段水域。
