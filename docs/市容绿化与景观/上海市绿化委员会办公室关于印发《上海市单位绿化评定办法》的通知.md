# 上海市绿化委员会办公室关于印发《上海市单位绿化评定办法》的通知



各区（县）绿化委员会办公室、绿化管理部门、各有关部门（系统）：
单位绿化是城市绿化的重要组成部分，单位绿化评定工作自开展以来，对于上海市整体绿化面貌的提高以及生态文明建设起到了明显的推动作用。近年来，随着绿化建设的发展、社会的提升、新技术的应用，单位绿化评定工作的意义和内涵不断深化，申报主体呈现多元化和复杂性。为进一步规范我市单位绿化评定工作，更有效地为社会单位提供绿化指导和服务，特制订《上海市单位绿化评定办法》，现将该办法印发给你们，请遵照执行。
特此通知。
