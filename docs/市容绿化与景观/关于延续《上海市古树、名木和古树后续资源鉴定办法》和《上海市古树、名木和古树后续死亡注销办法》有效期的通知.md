# 关于延续《上海市古树、名木和古树后续资源鉴定办法》和《上海市古树、名木和古树后续死亡注销办法》有效期的通知



状态
经评估，《上海市古树、名木和古树后续资源鉴定办法》和《上海市古树、名木和古树后续死亡注销办法》（沪绿容规〔2018〕4 号）需继续实施，有效期延长至2028年8月24日。
特此通知。
上海市绿化和市容管理局
2023年6月29日
