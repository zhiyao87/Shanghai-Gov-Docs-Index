# 闵行区人民政府关于印发《闵行区公园城市建设和市容环境优化“十五五”规划》的通知

闵府发〔2026〕20号

各镇人民政府、街道办事处，区政府各委、办、局，各区属公司，有关单位：
《闵行区公园城市建设和市容环境优化“十五五”规划》已经区政府同意，现印发给你们，请认真按照执行。

2026年7月22日

《闵行区公园城市建设和市容环境优化
“十五五”规划》

“十五五”时期，是我国基本实现社会主义现代化夯实基础、全面发力的关键五年，也是上海加快建设“五个中心”、基本建成具有世界影响力的社会主义现代化国际大都市和闵行区全面建成创新开放、生态人文、宜居安居现代化主城区和新质生产力主阵地蓄力而上的关键时期。闵行区将围绕推动高质量发展首要任务和构建新发展格局战略任务，以高品质生态环境支撑高质量发展，更好地满足人民对人与自然和谐共生生态之城的向往。
一、发展目标
坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻党的二十大和二十届历次全会精神，深入学习贯彻习近平总书记考察上海重要讲话精神和对上海工作重要指示要求，牢固树立“两山”理念、积极践行“三绿”并举，认真践行“人民城市”理念，紧扣“美丽上海”建设目标，推动生态建设由大规模增量转向增量结构调整和存量品质提升并重，进一步提升绿容服务水平。
锚定闵行区“南北牵引、东西协同、中部焕新”的空间战略，紧扣“聚新质转动能，优空间提品质”发展主线，自觉将行业发展融入“迈向高质量建设现代化主城区和新质生产力主阵地”进程。聚焦北部虹桥国际中央商务区建设、南部“大零号湾”科技创新策源功能区建设和“一江一河”沿岸地区品质提升，着力提升生态建设品质，巩固提高垃圾分类实效，全面优化市容景观品质，建管并举满足人民对美好绿色生态空间与市容环境的期盼。至“十五五”末，闵行公园城市价值逐步凸显，垃圾全程综合治理深入推进，市容环境综合治理效能进一步强化。

“十五五”主要发展指标
二、重点任务
（一）加快公园城市建设，持续推进生态服务品质提升
1.围绕新一轮公园建设，构建多元复合的城乡公园体系
接续建设生态空间，结合“一江一河一带”、虹桥国际中央商务区、“大零号湾”科技创新策源功能区等重点区域，计划新增各类公园20座，其中城市公园1座、口袋公园14座、开放林地及休闲森林公园5座。注重公园绿地均衡布局，推进主城区公园绿地服务半径提升。稳步扩绿增量，新建各类绿地300公顷，其中公园绿地150公顷。新建立体绿化3万平方米。结合生态建设加大上海市乡土适生树种和地产草种的使用比例。继续完善环城生态公园带闵行段建设，“环上”围绕外环绿道主脉贯通目标，适时逐步打通漕宝路等绿道断点。“环外”配合推进市级吴淞江凤栖湿地规划建设。计划新增绿道25公里，注重设置休憩座椅等服务设施，提升绿道便民服务能级。
2.稳步推进绿地开放共享，助力打造城园融合的城市治理范式
继续推进公园24小时开放，重点推进全区城市公园24小时开放，力争各类公园24小时开放率提高到90%。聚焦居民区周边公园，推行24小时开放无界管理模式，推进公园开放提质增效、老公园服务能级提升。加大推进单位附属绿地开放共享力度，结合城市更新建设等，新增机关、企事业单位附属绿地开放共享5处。注重生态系统多样性提升，协同推进社区生境花园建设。持续推进全民义务植树及认建认养活动。加大家庭园艺服务体系建设，优化市民园艺中心服务功能。
3.着力强化绿地管理和服务能级提升，推动高品质的生态产品体系与文商旅体展融合
持续优化公园绿地服务功能，打造“全龄友好”空间，探索“公园+”场景拓展，实施多元功能叠加和融合，新增休憩座椅、儿童户外游戏空间、运动场地及健身设施等。适当引进公园配套服务项目，包括轻餐饮、文化休闲、自然科普教育、书香空间等，重点聚焦“环上”公园服务体系建设，推进“绿环驿”高质量运营。推进老公园服务设施提升，聚焦适老化、适幼化改造，保障公园服务设施安全运营。积极开展上海国际花卉节闵行展区活动，进一步激发城市新活力，促进文商旅体展融合发展。加强绿化精细化管养水平，聚焦城市重点区域，强化分区分类绿化建管标准。结合闵行城市空间特征及区域发展水平，分类推进绿林养护降本增效。探索试点营建生态留野区，提升城市生物多样性。
（二）夯实森林资源保护，多措并举助推森林开放发展
1.全面推深走实林长制工作，建立“点对点”的责任链条
推动林长制工作实效，依托分级管理、属地负责、条块结合的工作要求，进一步压实保护发展生态资源的主体责任，形成一级抓一级、层层抓落实的工作机制，保障林长制各项任务落细落实，推动森林资源保护与发展的“责任制”高效运行。全面厘清森林资源家底，解决资源权属信息缺失、管理边界模糊等历史遗留问题。加强对本辖区林绿资源监管，督促街镇林长落实监管责任，加强跨行业、跨部门沟通协调，推动解决资源监管中的重难点问题。做好林地资源占补平衡工作，结合减量化腾地区域挖掘和排摸空间潜力，完成森林植被恢复的年度任务，积极巩固并保持现有林地规模。
2.拓展林下经济模式与林地开放休闲，构建“走得进”的森林场景
持续提升林地服务能级，新增开放林地及休闲森林公园5座，营造四季分明的多彩林相，注重生态涵养和休闲游憩功能复合，完善服务配套设施，盘活可利用设施及空间。完成林地抚育不低于5000亩，聚焦“山水工程”生态修复整治等，有效优化林分结构，改善林木生长空间，提升林地质量。探索开展林下经济，拓展资源利用模式。以森林景观利用为主，鼓励林下种植，结合宜居宜业和美乡村示范建设，引导林下休闲、体育、研学等活动有序发展，打造“森林可亲近、经济可持续、文化可体验”的新型林地休闲场景。
3.完善绿色监测体系及野生动植物保护，做好“一张网”资源管理
持续加强生态资源保护，巩固环保督察问题整改成果，用好行刑案件衔接，推进联合执法、联合办案，形成打击破坏森林资源违法行为执法合力。重点关注林地“三乱”、树木倒伏和林业病虫害，压实各级责任链条，形成“巡、改、督”完整闭环，依图依表提升林绿资源管护实效。完善林业有害生物监测预警体系，落实常态化林业病虫害防治。持续发挥自然教育功能，稳固现有3个野生动物栖息地和1个湿地生态修复项目资源监测与保护工作。落实完善野生动物重要栖息地全覆盖检查考核工作。试点推进野生动物栖息地改建项目1处。加大古树名木资源巡查，贯彻落实首部国家级古树名木保护专项法规的相关要求，加强古树名木及古树后续资源巡查工作。提高巡查工作质量，形成共管同治效应。
（三）深化垃圾全程治理，提升环卫工作综合管理成效
1.持续优化源头分类管理，推动垃圾分类提质增效
持续推动源头减量，倡导绿色低碳风尚。深化基层治理，巩固优化居村党组织领导、物业服务企业履责、相关组织及群体共同参与的工作机制；落实“一小区一方案”，因地制宜推动分类投放环境改造，优化分类投放管理制度。健全可回收物回收利用体系，以低价值可回收物回收实效为导向，完善惠民回收、智能回收、流动回收等多服务模式的综合回收体系，不断提升资源利用效能。
2.完善分类收运体系，聚焦智慧精细管理
实施餐厨再生资源中心提标改造，逐步关停镇级就地就近处置设施，强化区级集中设施规范稳定运营。推动闵吴码头改造提升，深化中转设施运营监管与小压站精细管理。推广新能源及新技术应用，实现新能源环卫车辆占比不低于80%，改善噪声、臭气扰民现象。优化推广“固定箱+移动箱”模式，试点智能废物箱、大口径废物箱。推进镇级环卫基地规划选址，加快实施落地，打造用地集约、功能复合、环境友好、运行高效的现代环卫基地。进一步优化镇级环卫停车场布局，针对区域空间不足，形成跨区域统筹规划建设机制。全面构建生活垃圾闭环管理体系，深化智能设备应用和路径优化等场景建设，推进智慧收运全覆盖，全程分类体系联网率达到80%；推动可回收物全流程信息化管理，中转站和集散场计量数据自动直传市级平台，接入率达到85%。建立“属地管理、分级负责、市场参与、政府托底”的大件垃圾投放、清运、处置体系，督促指导物业服务企业履行投放管理责任人义务，做好宣传动员、现场协调及清运信息公示。推进居住区投放（堆放）场所规范设置，依托可回收物中转、拆解和回收体系，优化镇级大件垃圾中转处置场所布局。落实产生者短驳义务，推动前端投放产生者付费或末端收处政府补贴相结合模式，推行“定点投放清运”、“预约上门回收”和“自行运送至指定的大件垃圾中转、拆解场所”方式。
3.深化全过程监管，建立健全消纳处置平衡体系
强化建筑垃圾全程监管，严格建设工程垃圾源头申报备案；强化运输车辆监管；严格消纳场所管理，落实视频监控和车辆车牌识别设备；强化与城管、公安、生态环境等部门管执联动；持续加强建筑垃圾数字化监管，推进落实建筑垃圾全过程电子联单管理，实现建设工程垃圾处置申报、备案“应报尽报”。结合生态复合单元建设、绿林地建设等多渠道拓展土方消纳空间。持续优化装修垃圾收运处理体系，推进装修垃圾线上预约清运,加强装修垃圾源头投放管理，因地制宜推广优化固定厢房、专用回收箱、临时交付点等不同投放模式应用，做好收运衔接，推进装修垃圾全量收集。加强马桥、华漕建筑垃圾资源化利用中心管理，优化补强拆房垃圾、装修垃圾资源化处理能力，研究推进马桥建筑垃圾资源化利用深加工，落实分拣残渣减量，完成零填埋任务。
4.提升清扫保洁水平，稳步提高环境卫生服务质量
巩固“高标准保洁”建设成果，以点成面，辐射周边，提高环卫机械化作业水平和新工艺应用水平，引导鼓励各单位升级保洁模式与装备、优化保洁流程，道路清洁度达到90%以上，贯彻绿色发展理念，探索道路保洁无人化、智能化。落实新建环卫公厕适老化适幼化配套与职工工休间建设改善，推动保洁作业智能化和24小时开放，公共厕所服务优良率达到90%以上。结合乡村振兴及和美乡村建设，持续推进农村公厕提档升级。
（四）推进城市精细管理，巩固优化市容景观建设品质
1.持续推进美丽街区建设，提升市民获得感
按照“一街区一特色”，针对虹桥国际中央商务区、“大零号湾”科技创新策源功能区、莘庄城市副中心等重点区域进行“美丽街区”深耕，依托区域科研底蕴、交通枢纽、商业活力等要素，联动公园绿地建设提升和城市空间焕新，探索打造科创街区、时尚街区、公园街区，不断增强区域文化标识与人居环境魅力，重点推进申长路、科创水岸等 5个“美丽街区”建设。注重公共休憩座椅的配套，将建设成果切实转化为市民可感、可知、可享的获得感与幸福感。
2.着力创造景观照明标杆，彰显闵行区域特色
高质量承办上海国际光影节闵行分会场活动。完成《闵行区景观照明规划实施方案》修编。以前湾地区、“大零号湾”区域、百联南方商城、锦江乐园及周边等重点区域、重要商圈的亮化为牵引，持续推进景观灯光建设与更新，彰显夜间景观独特韵味，激活夜间经济蓬勃功能，不断增强市民游客获得与幸福感。推动区级景观照明集中控制，落实核心区域、重点区域和单体建构（筑）物的景观照明集中控制纳控率达到95%以上，加强节能低碳管理，景观照明节能灯具使用率达到98%以上。
3.持续提升市容环境品质，平衡好“烟火气”与秩序
构建差异化市容治理新格局，针对城镇与乡村、重点区域与一般区域等不同空间，落实分级分类标准体系，因地制宜提升区域功能与风貌水平。推进公共空间“金角银边”建设，完成一批主要门户、居民区周边等街角区域美化任务，打造高品质、有活力的公共节点。强化薄弱区域市容环境整治，动态更新整治清单实施销项管理。坚持疏堵结合，深化设摊综合治理，平衡市容秩序与民生“烟火气”。
4.加强户外广告招牌管理，放大示范引领效应
定期组织《闵行区户外广告设施设置规划》修编，细化空间分类管控，提升商圈户外广告设施品质，优化商业氛围。引导户外广告设施新材料、新工艺、新技术应用，探索新型管理模式。放大已创建特色道路示范效应，支持街镇借鉴成功经验，推进户外招牌多样化、个性化、艺术化。强化源头治理与长效综合治理，户外广告设施和户外招牌审批（备案）率分别达到95%和90%以上，户外招牌纳管率达100%，以高水平治理保障产业高质量发展。
（五）响应新质生产力发展，拓展智慧应用与人才培育
1.整合各类数据资源，统筹绿容平台建设
坚持问题导向，整合绿化市容各业务板块的数据，建设行业主题库与数据资源共享平台；链接融合市级行业既有信息系统，兼容接入区级城市运行数据资源，形成行业综合管理系统；开展数据挖掘分析，利用平台积累数据，加强集成和联动，探索态势全面感知、趋势智能研判、协同高效处置、资源分配优化、决策提供辅助等功能。
2.加快专业队伍建设，保障绿化市容行业健康发展
持续开展群绿宣教与绿化市容养护专题培训，提升街镇管理人员及一线绿化养护骨干业务水平。结合市、区环卫行业劳动技能竞赛，分批次开展岗位培训，实现全员培训、持证上岗，提升规范作业能力。探索试点以国有企业为牵引，推动公园绿地和道路保洁队伍一体化,研究公园绿地养护和环卫作业养护分级分类评估提标。
3.落实审批制度改革，优化营商环境
落实“三减一提”（减材料、减环节、减时限、提效率），依托市“一网通办”平台开发智能审批模块，推动绿容审批从“能办”向“快办”“好办”跃升。深化“一业一证”改革，在机动车清洗备案改革基础上，提前介入指导场地规划、设施配置。聚焦“开店一件事”，配合审改办，推动“串联”向“并联”转变，实现“多事联办，一次办结”，为小微企业提供精准指导，切实降低准入门槛。
三、重大项目
（一）公园绿地建设和提升工程
新增各类公园20座，其中城市公园1座、口袋公园14座、开放林地及休闲森林公园5座。新增各类绿地300公顷，其中公园绿地150公顷。重点推进前湾公园、晓烟湖公园等一批公园绿地建设，推进研究马桥、紫竹大型绿地建设。聚焦“一南一北”与莘庄城市副中心等重点区域，按照公园与城市融合发展目标，积极推进公园围墙打开、老公园服务能级提升，新增休憩座椅、儿童户外游戏空间、乒乓球篮球等运动场地及健身设施等。
（二）环城生态公园带（闵行段）建设工程
围绕闵行文化公园等“环上”公园，适时逐步打通漕宝路、老沪闵路等绿道断点。“环外”配合推进市级吴淞江凤栖湿地规划建设。
（三）开放空间绿道建设工程
新增绿道25公里。依托“一南一北”与莘庄城市副中心及各地区中心等重点区域，挖潜沿路沿河空间开展绿道亮点建设工程。开展环马桥大居绿道建设等，聚焦蓝绿空间融合研究推进黄浦江、北横泾等水岸贯通。
（四）林地抚育和开放建设工程
开展林地抚育不低于5000亩，新增开放林地及休闲森林公园5座，拓展林地公共空间，提升林地景观面貌，让周边居民有更多获得感。
（五）区级环卫设施提升工程
实施闵行区餐厨再生资源中心提标改造，对工艺设备大修更新，推动闵吴生活垃圾码头防汛墙加固和大修改造，进一步提升运行效能和防洪能力。
四、保障措施
一是加强行业服务保障。紧扣闵行实际和行业发展需求，落实好配套发展政策、管理细则及正向激励机制，构建系统完备、科学规范、运行高效的服务保障制度框架。聚焦政策法规、专业技术、智慧应用、美学素养等核心能力建设，打造高素质绿化市容人才队伍。加强对街镇的行业服务指导，整体提升行业管理能力。二是强化规划统筹保障。强化规划刚性约束和空间保障，保持与城市规划、单元规划的高效融合，落实绿化林地空间与环卫设施可实施空间。加强对环卫规划执行情况的行业指导与监督管理，有序推进镇级环卫设施规划建设。三是鼓励技术创新与模式创新。推动公园城市、垃圾分类、市容环境智能信息系统平台开发建设和迭代升级。深化数据资源归集共享和全生命周期治理，推动管理流程系统性再造和治理能力跃升。推广智能装备、无人作业、AI识别等新技术应用，提升行业新质生产力水平。四是加强社会宣传参与。深入践行“全过程人民民主”重大理念，建立健全规划编制、实施、评估全流程公众参与机制。完善舆论引导长效机制，健全区镇联动、部门协同的立体宣传网络。推进绿化市容志愿服务体系建设，向公众提供生态文明宣传教育服务。

主要指标解释

1.人均公园绿地面积：指期末城区内平均每个常住人口拥有的公园绿地面积。其中公园绿地指向公众开放的、以游憩为主要功能，有一定的游憩设施和服务设施，同时兼有健全生态、美化景观、防灾减灾等综合作用的绿化用地，是城市建设用地、城市绿地系统和城市市政公用设施的重要组成部分。计算公式为：人均公园绿地面积=城区公园绿地面积/城区常住人口。
2.森林覆盖率：上海市森林覆盖率统计方法完全接轨国家森林覆盖率统计方法，森林面积统计口径调整为国土“三调”及其变更调查全部林地范围的乔木林和竹林、建设用地范围内的乔木林和竹林、园地范围内的乔木林、森林沼泽范围内的乔木林和国家特别规定灌木林。因本市无国家特别规定的灌木林，原灌木型和人工矮化的鲜果类经济果林不再列入森林面积统计范围，同时将“三调”林地上且符合乔木形态的其他未成林造林直接纳入乔木林统计。计算公式为：森林面积/土地面积×100%。
3.公园数量: 指区域内各类公园的总数量，包括城市公园、口袋公园、开放林地及休闲森林公园等。
4.绿道长度: 指绿道的公里数。
5.生活垃圾回收利用率：指未进入生活垃圾焚烧和填埋设施进行处理的可回收物、易腐垃圾的数量，占生活垃圾总量的比例。计算公式为生活垃圾回收利用率=（可回收物回收量+湿垃圾资源化利用量）/生活垃圾总量×100%。
6.建筑垃圾综合利用率：指建筑垃圾通过平衡利用（直接回用、绿化回填、堆坡造景、土地平整、修基筑路等）和资源化利用量，占建筑垃圾产生量的比例。计算公式为建筑垃圾综合利用率（%）=〔（建筑垃圾平衡利用量+建筑垃圾资源化利用量）÷建筑垃圾产生量〕×100%。
7.“美丽街区”提升和新建数量：新建“美丽街区”和对原有的“美丽街区”进行提升的数量。
8.核心区域、重要区域和重要单体建（构）筑物的景观照明集中控制纳控率：指核心区域、重要区域和重要单体建（构）筑物的景观照明已纳入区景观照明集中控制系统数量占应纳入数量的比例。计算公式为景观照明集中控制纳控率=已纳入集中控制系统的核心区域、重要区域及重要单体建（构）筑物景观照明控制终端数量/应纳入集中控制系统的核心区域、重要区域及重要单体建（构）筑物景观照明控制终端总数量×100%。
