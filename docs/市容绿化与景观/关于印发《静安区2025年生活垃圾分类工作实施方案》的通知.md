# 关于印发《静安区2025年生活垃圾分类工作实施方案》的通知

关于印发《静安区2025年生活垃圾分类工作实施方案》的通知

静安区各相关单位、各街镇：

为深入贯彻落实习近平生态文明思想和习近平总书记对嘉兴路街道垃圾分类志愿者的重要回信精神，深入实施《上海市持续优化生活垃圾全程分类体系工作方案》，坚决打好上海垃圾分类攻坚战和持久战，不断提高人民群众的满意度和获得感，根据《上海市2025年生活垃圾分类工作实施方案》，结合静安实际制定了《静安区2025年生活垃圾分类工作实施方案》，现印发给你们，请认真按照执行。

静安区绿化和市容管理局

2025年6月16日

静安区2025年生活垃圾分类工作实施方案

为深入贯彻落实习近平生态文明思想和习近平总书记对嘉兴路街道垃圾分类志愿者的重要回信精神，全面实施《上海市持续优化生活垃圾全程分类体系工作方案》，根据《上海市2025年生活垃圾分类工作实施方案》、《静安区持续优化生活垃圾全程分类体系工作方案》要求，围绕“资源化、绿色化、精细化、智能化、惠民化”，高质量完成各项工作：分类投放环境优化、便利化程度提升，全区完成18个高标准生活垃圾分类小区（Ⅰ类）、9个可回收物惠民回收服务点；常态化管理效果提升，居住小区和单位生活垃圾分类达标率稳定在95%以上，居民对生活垃圾分类工作满意度达到96%；资源化利用能级提升，生活垃圾回收利用率达到47%。全面展示“新时尚”风貌，确保静安区垃圾分类工作走在全市前列，持续发挥示范引领作用。

一、 重点任务

（一）强化管理，巩固常态长效机制优势

1. 提升基层治理效能。强化党组织领导下的生活垃圾分类多方参与机制，用好《上海市居村委会依法协助事项清单》，以“融网强格”推进“多格合一”，将生活垃圾分类作为基层党建和社区治理工作的标尺，加大基层赋能力度，形成党建引领、部门指导、物业主导、志愿者督导、指导机构辅导的“五导”管理格局。持续落实分类投放管理责任人制度，提升精细化管理水平，构建稳固的垃圾分类基层治理模式。

2. 拓展社会宣传内涵。在习近平总书记重要回信两周年、《上海市生活垃圾管理条例》施行六周年等重要时间节点，组织开展各类主题宣传活动。以全国城市生活垃圾分类宣传周、节能宣传周、全国低碳日为抓手，依托生活垃圾分类科普馆等宣传教育基地，进一步加强生态优先、节约集约、绿色低碳发展、无废城市建设等理念知识的科普宣传。重点针对租住群体、家政服务、装修人员等流动性较强的人群加强“一对一、面对面”式入户宣传引导。

3. 提升执法监管能级。强化对生活垃圾源头不分类违法行为查处，综合运用《生活垃圾分类执法提示告知单》，充分彰显执法的力度和温度。强化绿化市容部门、房管部门、城管执法部门管执联动，研究住宅小区生活垃圾不分类案件物业发现、固定证据、线上移送、城管处置流程，形成发现问题-线上移送-城管查处-线上反馈的处置闭环。

（二）便民利民，夯实全程分类体系基础

1.推动源头设施便利化改造。以推进人居环境与绿色低碳深度融合为目标，加大生活垃圾分类投放点改造力度。按照“定时定点为主、误时投放为补充”的原则，落实“一小区一方案”管理制度，全面增强居民对源头投放环境的满意度和感受度。持续推进居住区289个投放点微更新，159个投放点专项更新，面向居民的惠民回收服务点9个。

2.推进高标准分类小区建设。巩固提升已建成的52个高标准生活垃圾分类小区管理水平，强化源头分类设施设备使用效率。优先对分类实效不佳、居民满意度不高、出现舆情的小区实施投放设施改造，推进全区完成18个高标准生活垃圾分类小区（Ⅰ类）便利化改造，并配合市级完成已评定的高标准生活垃圾分类小区（Ⅰ类）年度复查工作。

3. 打造高标准精细化分类样板。根据市级下发的《精细化分类样板区域建设标准图示手册》相关要求，以已建成的静安寺商圈和大宁商圈精细化分类样板区为引领，持续推动苏河湾商圈建成精细化分类示范样板，对样板区域内人流密集场所的废物箱进行全面升级。按照精细化、精准化、便民化要求，优化废物箱设置布局，探索部分重点区域设置智能化非接触式废物箱。

（三）科技赋能，加强收运智能监管力度

1.精准优化智慧收运线路。以解决垃圾桶游街问题为导向，在三条智慧收运线路运行模式的基础上，利用AI分析建立数据库，通过动态管理、数据合并等开展分类分级管理。持续拓展“公交站牌式精准报时”智慧收运线路范围，根据不同业态实施“一点一策”。试点引入“AGV搬运机器人”实现垃圾桶高精度定位和自动化驳运，减少扰民现象，力争收运流程更加简化、操作更加便利。

2.提升湿垃圾品质监控全流程应用。持续完善湿垃圾品质监控硬件系统建设，夯实品质监控基础。深化智能识别模型训练，构建完善的监控系统智能识别与预警体系，提升杂物识别准确率。规范湿垃圾品质监控系统运行，形成品质监控问题发现、反馈、整改、销项闭环。探索品质监控发现问题溯源路径，与街镇垃圾分类“一网统管”应用场景对接连通，实现上下数据贯通，通过精准溯源促进源头分类实效提升。

3. 推动“沪尚回收”平台功能升级。结合本市可回收物管理对“沪尚回收”公共服务平台的工作要求，以“统一管理，便民惠民”为原则，在6月底前完成区级可回收物回收量在“沪尚回收”平台上的数据源切换，实现可回收物回收量自动采集生成。将分类规范、流向清晰、品质到位、数量精准、设施安全作为监控重点，强化全程信息集成，全面实现点、站、场各类可回收物流量流向数据自动跟踪。

（四）提质增效，提升资源化利用水平

1. 保障可回收物体系稳定。健全完善全区可回收物体系，保障可回收物中转站基本职能，推进站场以市政用地、区绿化市容局产权、纳入循环利用名单等形式稳定用地保障。结合生态环境保护督察发现问题后续整改，定期开展可回收物场站运营管理、消防安全、生产安全等专项整治。进一步整合主体企业服务资源，提升服务质量，建立符合静安南北纵深格局的“点、站、场”回收体系。以主体企业评议制度为抓手，培育建立责任明确、目标量化、场站规范、服务全面的运作模式，提升回收体系稳定性。

2. 扩大精细化分类辐射范围。在全区党政机关、公园绿地、大中小学实现可回收物精细化分类全覆盖的基础上，持续拓展医院、商场等公共场所可回收物精细化分类覆盖领域。做好源头投放引导，结合不同场所特性建立精细化分类容器配套收运制度，规范收运流程。

3. 丰富单品类专项回收利用。扩大现有一次性餐盒、牛奶盒等单品类可回收物专项回收试点范围，拓展重要商圈精细化分类路径，鼓励相关企业在商区、园区和社区等针对产量较大的可回收物品类开展单品类专项回收，在咖啡店密度高的区域专项回收利乐包、咖啡渣，在眼镜集中销售区域专项回收废旧眼镜等。

（五）凝聚共识，弘扬绿色低碳风尚

1.促进餐厨垃圾源头减量。深入开展绿色餐厅和光盘行动示范店创建，持续开展“光盘行动”。加大对菜市场垃圾分类、净菜上市和“减塑”等工作的宣传力度。积极做好区级机关食堂反食品浪费实地抽查督导工作，创新手段响应反食品浪费。

2. 倡导绿色生产生活方式。持续加大餐饮服务提供者主动向消费者提供一次性餐具以及旅馆经营单位主动向消费者提供客房一次性日用品行为的执法力度。禁止或限制部分一次性塑料制品的生产、销售和利用，不主动提供一次性用品，推动办公场所无纸化办公，创造绿色办公环境。

3.深化全民动员机制。加强社会组织培育，发挥生活垃圾分类志愿者作用，以宣传引导、文明实践、志愿服务和公益活动等为主要活动形式，通过大篷车开展垃圾分类“周周进”活动，每月开展生活垃圾分类志愿者宣传主题，创设“全民看分类、全民谈分类、全民爱分类”宣传动员机制。

二、保障措施

（一）强化组织领导与协同。区绿化市容局牵头各相关单位横向协作，优化上下联动机制。强化与城管执法部门、房管部门管执联动，按照各自职能对街镇源头分类体系更新升级、分类投放违法行为执法、分类投放管理责任落实等情况加强检查监督，针对瓶颈性、顽固性、反复性问题，切实发挥相关单位职能，加强督办和协调推进。

（二）深化落实问题整改与反馈。全面梳理中央及市生态环保督察、区委巡察、12345热线反馈、新闻媒体曝光等各类涉及垃圾分类的问题，深入分析成因，制定整改清单落实销项整改，不断加强风险排查，推动风险防控机制建设，促进将解决垃圾分类“一件事”向办好“一类事”转变。

（三）完善考核评估，压紧压实责任。贯彻落实住建部《生活垃圾分类工作评估办法》、《上海市生活垃圾分类情况评估办法》，精准、科学评估全区生活垃圾分类情况，按照因地制宜、城乡统筹、全程分类、全域覆盖、常态无感、多元参与的原则，实施动态性评估，实现评估工作由被动评估转向自主参与、由结果导向转为过程管控、由重在考核转型服务赋能，切实为基层减负增能。

（四）细化资金保障与政策支撑。街镇生活垃圾专项经费参考年度重点工作任务，结合历年生活垃圾分类专项资金使用情况统筹分配。通过制定《生活垃圾专项资金管理办法》完善制度保障，强化资金配套，进一步提升资金使用效能，优化绩效评价应用。健全监管体系，加强过程跟踪，引入专业机构开展独立评价，确保政策执行过程中流程规范、执行有效、监管到位。湿垃圾就地消纳补贴参照生活垃圾处置费标准，每处理一吨给予221元的消纳补贴，有害垃圾收运补贴以车辆为单位，全年每辆车补贴15万元用于人工、车辆维修保养等运营费。
