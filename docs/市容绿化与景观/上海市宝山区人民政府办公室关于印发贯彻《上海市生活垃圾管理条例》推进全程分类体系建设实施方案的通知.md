# 上海市宝山区人民政府办公室关于印发贯彻《上海市生活垃圾管理条例》推进全程分类体系建设实施方案的通知

各镇人民政府，各街道办事处，区政府各委、办、局：

《关于贯彻〈上海市生活垃圾管理条例〉推进全程分类体系建设的实施方案》已经区政府同意，现印发给你们，请认真按照执行。

上海市宝山区人民政府办公室

2019年5月5日

关于贯彻《上海市生活垃圾管理条例》

推进全程分类体系建设的实施方案

为全面贯彻落实《上海市生活垃圾管理条例》（以下简称《条例》），有序推进本区生活垃圾全程分类体系建设，全面展现“生活垃圾分类就是新时尚”，现制订本区贯彻《条例》推进全程分类体系建设的实施方案如下。

一、指导思想

以党的十九大精神为指引，全面贯彻习近平总书记视察上海重要讲话精神和普遍推行垃圾分类制度的重要指示，按照中央城市工作会议、市委、市政府对垃圾分类工作的总体部署，坚持问题导向、需求导向、目标导向，把垃圾分类作为融入城市精细化管理、美丽家园建设行动领域的重要路径。坚持以强化全程管控为核心，落实源头分类为基础，以生活垃圾“减量化、资源化、无害化”为目标，统筹谋划、补齐短板、综合治理，加快建立健全生活垃圾全程分类体系。

二、工作目标

（一）生活垃圾分类全面覆盖格局基本成型。分类及绿色账户累计达到67.4万户。实现居住区、农村、单位、公共场所生活垃圾分类全覆盖，70%以上居住区实现垃圾分类实效达标，创建达标小区518个。推进农村生活垃圾分类全覆盖，2019年创建农村生活垃圾分类达标村104个。

（二）生活垃圾全程分类体系基本建成。建成“两网融合”服务点670个、中转站12座、集散场1个。全区干垃圾日均控制量不高于1610吨，湿垃圾分类量日均高于407吨，其中居民区湿垃圾分类量日均高于276吨（含菜场）、餐厨垃圾分类量日均高于131吨，可回收物回收量日均高于251吨。

（三）《条例》贯彻实施社会氛围基本形成。积极投入市以垃圾分类及《条例》普法为主题的“十、百、千、万”系列宣传活动，宝山区成立15支志愿者队伍，宣传覆盖约500个居（村）委，发放宣传海报及资料覆盖面达到100%，形成人人知晓、普遍参与垃圾分类的社会氛围。

三、全面推进生活垃圾分类全程体系建设

（一）推进全面覆盖

1.深入开展创建，加强源头管理。深入开展生活垃圾分类达标、示范街镇（园区）创建活动，严格居住区、单位、公共场所达标标准和比例，将70%以上的源头实效比例分解到“进居住区、进单位”等具体项目。发挥基层党组织作用，充分调动基层党组织、居（村）委、居（村）民、物业等各方面积极性，落实各方责任，形成“四位一体”的联动机制。一是将垃圾分类纳入“美丽家园”行动计划，进一步加强居住区源头收集分拣和绿色账户的宣传，推进居民家庭按照“一严禁、两分类、一鼓励”实行垃圾分类。二是全面实行农村户投、村收、区运专项收集、运输机制。干湿垃圾由农户自行投放，村专项收集员上门进行收集并转运至干湿垃圾储存点再进行二次分拣。可回收垃圾则由农户投放至指定堆放点或“两网融合”服务点进行回收。三是加强单位生活垃圾分类宣传培训，做到分类责任告知书发放全覆盖。党政机关等公共机构生活垃圾分类推进由区机管局与区绿化市容局落实，其余单位生活垃圾分类推进由街镇（园区）牵头，区绿化市容局配合落实。

2.夯实工作基础，加快设施规范。全面落实居住区分类垃圾箱房和分类投放点改造，推进居住区、公共场所生活垃圾投放容器、标识、短途驳运机具的规范化。一季度实现全区废物箱的标识全部按照最新地方标准更新到位；上半年，在“美丽家园”垃圾箱房标准化改造基础上，实现功能叠加，按照现行的政府规章和地方标准，对全区1918个垃圾箱房（收集点）进行升级改造，落实好宣传栏、公示栏、容器标识的规范化工作；达到箱房内外容器、标识、宣传、公示、配置“五规范”。到三季度全区居住区分类投放点的容器与标识全面实现“双规范、双到位”。配齐农村生活垃圾分类投放、收集设施。要求每户配置1组干湿垃圾投放桶，每村配置1辆专用收集车，设置集中投放的四分类垃圾桶（240升）至少1组，并设置干湿垃圾储存点1处（可利用现有垃圾箱房改建）。

3.落实有效措施，加速实效提升。因地制宜推进垃圾分类定时定点等促进源头分类实效模式，用好在职党员双报到制度，发挥在职党员对社区垃圾分类的示范、志愿者等作用。一是结合“美丽家园”住宅小区建设行动，推行生活垃圾“定时定点”投放。以干湿垃圾分类投放为主要内容，根据不同类型居住小区实际，因地制宜确定定时定点投放的分类投放点设置、投放时间安排及分类投放规范等。二是发挥“黄马夹”试点示范效应。充分发挥垃圾分类“黄马夹”专业化队伍作用，在进行垃圾箱房源头管理的基础上，协调好与物业、社区居委的关系，调动各方积极性，在宝山一些试点小区，实行“1+2+3”理念，即1名“黄马夹”与2名居委干部配合，由3名社区志愿者（或物业管理）协助，共同做好居民定时定点投放的预先告知和宣传引导。其余小区由物业、居委会做好动员和解释工作，并配合定时定点投放日常监管。三是发挥绿色账户激励作用，严格绿色账户积分管理，紧密结合分类积分与居民分类投放行为，禁止“人情分”“乱积分”的行为，加强对绿色积分兑换的支撑，提高绿色账户吸引力。

4.对接创建要求，加大考核比重。积极对接各项创建工作，相应提高垃圾分类工作在各项考核指标体系中的比重。一是将源头生活垃圾分类开展情况纳入区委、区政府各项年度考核评价内容，建立联席会议制度、各成员单位联络员制度、微信工作群，将单位、生活垃圾分类小区名单及开展情况以简报形式，定期向区委、区政府进行报告，并向社会公示。二是充分发挥文明测评作用，将垃圾分类成效纳入文明单位、文明小区评价标准。三是充分发挥联席办综合协调推进作用，形成每月例会制度、通报制度，沟通各项情况，发挥部门合力。

（二）加快体系建设

1.加快推进“两网融合”。一是依据《上海市再生资源回收管理办法》《上海市促进生活垃圾分类减量办法》有关要求，各街镇（园区）完成再生资源回收网络布局、规范回收分拣人员管理，建立考核检查制度，落实属地化管理责任，街镇（园区）落实收集点及回收站场地，落实管理人员明确管理责任，区商务委对接企业做好数据统计。二是加强条块联动，对街镇（园区）“两网融合”试点工作实施情况进行梳理排摸，抓住“两网融合”实事项目机遇，将区域内不规范的回收站进行清理，将符合标准的回收站纳入“两网融合”可回收资源体系。三是采用市场化方式，解决区内可回收物专项收运问题，落实可回收物全程运营主体企业，依托第三方社会组织、辖区内现有主体资源回收企业等，配套适宜的车辆，建立服务规范、管理有序、稳定可靠的可回收物收集运输体系，确保点、站、场之间的物流畅通。四是区财政局、区发展改革委等部门制定低价值可回收物补贴政策，确保“两网融合”和再生资源回收工作取得实质性进展。

2.进一步完善收运体系。按照上海市提出的“大分流、小分类”的生活垃圾管理体系积极推进垃圾减量工作，在原有垃圾收运系统的基础上，不断完善本区装修垃圾、厨余垃圾、菜场垃圾大分流收运处置系统，积极构建固体废弃物“大分流、小分类”的全过程收运处置系统。一是加大分类收运车辆投入，全面落实本区湿垃圾、有害垃圾专车运输，喷涂标识。2019年再新增18辆湿垃圾收运车，进一步提升湿垃圾和有害垃圾分类收运能力。二是规范垃圾分类处置，宝山区装修垃圾收运后进入江杨北路装修垃圾资源利用中心处置利用，厨余垃圾收集后运送至市局统一处置系统，待区级湿垃圾处置设施建成后，将于区内专项处置。集贸市场垃圾经菜皮垃圾粉碎压榨后处置，分拣后进入泰和路环卫码头处理场所，废玻璃、有毒有害垃圾进入市局指定处理场所，其他生活垃圾通过市属虎林路环卫码头和区属泰和路环卫码头水上外运至浦东老港填埋场处置。大件垃圾、枯枝树叶进入江杨北路大件垃圾处置中心处置。

（三）提高处理能力

1.推进垃圾焚烧设施建设。2019年垃圾焚烧设施开工建设：一季度完成设施规划选址、启动立项；二季度完成立项及规划许可；三季度完成工可及环评；四季度完成施工许可、开工。2020年形成处置能力。

2.推进湿垃圾处置设施建设。2019年湿垃圾处置设施开工建设：一季度完成设施规划选址、启动立项；二季度完成立项及规划许可；三季度完成工可及环评；四季度完成施工许可、开工。2020年形成处置能力。

3.落实末端设施严格监管。建立江杨北路装修垃圾分拣场的运营机制，2019年投产运行。北京建工、庆龙公司、宝武集团三个建筑垃圾处置中心进一步增加产能，并根据环保要求，加强对末端处置设施的监管，切实落实“三必须”扬尘防控措施。

四、全面营造垃圾分类全民参与的社会氛围

（一）推动源头减量。一是推动旅馆、餐饮行业限制或减少使用一次性用品，倡导绿色消费，推广使用可循环利用物品，并组织开展联合检查执法。二是加强对在本区经营的快递业指导，提高快递包装物回收利用率。三是加大净菜上市在标准化菜场和生鲜超市、大型超市等场所的推进力度。四是排摸本区农贸市场、标准化菜场现状，落实新建和已建农贸市场、标准化菜场的湿垃圾就地处理设施配套工作。

（二）强化执法监督。一是强化日常监管，实施专车专运、专档管理，落实区自查、市抽查的监管模式，杜绝混装混运，接受社会监督。二是发挥巡查机制、宣传机制、处置机制优势，通过垃圾分类“黄马夹”巡查队伍，进行循环督查，每日一报，一周整改，做到问题及时发现，及时整改，及时处理。三是在小区宣传栏内，公示投放不规范名单，楼长和物业对三次投放不规范的居民上门约谈等方式，从短板中寻求突破，形成居民之间互相监督的良好氛围。四是加强联勤联动，重点针对收集容器配置、单位生活垃圾分类的执行情况进行执法检查，一旦发现有单位未规范实施垃圾分类，由城管执法部门责令立即或限期改正；逾期不改正或拒不改正的，由城管执法部门予以行政处罚。提高监管执法实效。

（三）营造良好氛围。一是组织开展《条例》培训。充分利用宝山“社区通”管理平台发布培训信息，采取分类分级培训，建立《条例》宣讲队，组织全区性的培训，通过集中培训和送教上门相结合的方式，开展区、街镇（园区）以及行业单位培训，发放普法宣传资料，分类宣传海报及资料。二是积极参与《条例》宣传“五个一”工程。根据市树立一批垃圾分类先进典型，推出一套垃圾分类宣传片，开展一系列“垃圾去哪儿”主题教育活动，建设一批垃圾分类科普基地，创建一批垃圾分类示范街镇（园区）的要求，结合宝山特点，开展好各项主题活动，并加强对成功典型案例及基层创新经验的宣传报道，提高市民群众对垃圾分类工作的参与度。三是开展垃圾分类社会动员。组织开展垃圾立法宣传“进社区、进村宅、进学校、进医院、进机关、进企业、进公园”系列活动，通过“社区通”平台、“小手拉大手”活动、精神文明创建、卫生创建、志愿者服务等渠道，普及垃圾分类及立法知识，结合好家风好家训工作，实现垃圾分类进家庭培训。充分利用传统媒体和新媒体的有效阵地，做好垃圾分类公益性宣传。四是发挥城管社区工作室的作用。主动牵头基层党组织、居委、业委会、物业、志愿者形成“五位一体”联动机制，积极落实居住区、企事业单位的分类投放管理责任人职责，努力推动社会各界和市民群众形成人人知晓、人人参与生活垃圾分类的良好社会氛围。

五、全面优化全程分类体系运作组织保障

（一）明确工作责任。各部门、街镇（园区）要高度重视生活垃圾分类减量工作，将其作为推进循环经济、建设生态文明、落实节能减排的工作实践，作为“十三五”城市管理的重点之一，要真正形成共识，切实加强领导，聚集人力、财力、物力，要根据各自职责分工，制定具体工作计划或实施方案，并按时间节点有序推进。强化党建引领，党员干部先行，把基层党组织建设成为垃圾分类工作的坚强战斗堡垒，积极推动基层党组织和党员在实现垃圾综合治理中当好组织者、推动者、先行者。以《条例》颁布为契机，将生活垃圾管理作为生态文明建设和城市精细化管理的重要内容，纳入专项督查和绩效评价指标体系。按照“市级统筹、区级组织、街镇落实”的思路，建立健全“两级政府、三级管理、四级落实”的生活垃圾分类责任体系，落实街镇（园区）、各部门管理职责，完善各级生活垃圾分类工作联席会议制度，加大日常综合协调和监督指导力度，切实推进《条例》贯彻落实。

（二）落实政策支持。完善单位生活垃圾收费制度，建立与分类质量相挂钩的生活垃圾收费机制；制定并实施源头收运能力支持政策，增加专用运输车辆能力配置，促进低端车型逐步升级改造，增强专业收运能力。强化资源利用产业鼓励政策。制定湿垃圾资源化产品的补贴政策，打通湿垃圾资源化利用产品出路。建立低价值可回收物回收补贴政策，引导企业回收利用低价值可回收物。制定有害垃圾集中收集处置专项支持政策，确保有害垃圾规范收运处置，维护环境安全。

（三）加强经费保障。分类小区居民家庭收集容器经费，对实施垃圾分类的家庭发放干湿垃圾对桶，引导居民做好源头分类；分类小区垃圾房改造经费，对居住区财政供给垃圾箱房进行改建改造维修及专门维护；垃圾分类专管员经费，主要负责小区内垃圾箱房保洁、干湿垃圾分拣、绿色账户扫卡、装潢垃圾堆点管理。并保障垃圾分类“黄马夹”专管员的岗位待遇；宣传动员、教育培训经费，制作发放宣传资料物品，开展相关人员培训、举行大型户外“绿色星期六”宣传活动、“绿色账户”宣传激励兑换物品、用于电视台多媒体播放微电影、专栏期刊等；落实以奖代补经费，主要用于各街镇（园区）对志愿者和分拣员工作补贴，以及对居委、物业组织安排、宣传落实、管理监督的考核奖励等。
