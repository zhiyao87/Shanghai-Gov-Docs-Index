# 关于调整本市城乡公园名录的通知

各区绿化市容局、临港新片区管委会:

为持续完善城乡公园布局，建设公园城市，全市各区积极推进各类公园绿地、林地建设，建成了一大批绿化景观面貌良好、基础配套设施较好完善、服务功能较为丰富的公园绿地、休闲林地，已具备纳入城乡公园体系的条件。

在各区申报的基础上，经我局现场踏勘和研究讨论后，现决定将馨园等102座口袋公园、陈家镇裕西村乡村公园等30座乡村公园纳入城乡公园名录管理(城市公园前期已发布)，并予以发布。同时，经综合评估，决定将普陀静宁花园、浦东梅香园、浦东东篱园、宝山小五角花园、宝山郝桥港小游园、闵行锦逸园、松江人乐花园、青浦海盈路月季园、青浦西部绿苑等9座在册口袋公园调出口袋公园名录。

本次调整后，本市城乡各类公园数量将增加至832座，其中城市公园477座、口袋公园265座、乡村公园89座、主题公园1座。

希望各区加强管理，维护良好景观面貌，不断完善服务设施、提升服务水平，为市民创造优美的城乡公园生态环境。

特此通知。
