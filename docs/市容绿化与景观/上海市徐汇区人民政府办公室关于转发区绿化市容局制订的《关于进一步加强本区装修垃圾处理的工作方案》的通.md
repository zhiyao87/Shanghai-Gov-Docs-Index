# 上海市徐汇区人民政府办公室关于转发区绿化市容局制订的《关于进一步加强本区装修垃圾处理的工作方案》的通知

区政府有关委、办、局，各街道、华泾镇：

区绿化市容局制订的《关于进一步加强本区装修垃圾处理的工作方案》已经区政府同意，现转发给你们，请认真按照执行。

上海市徐汇区人民政府办公室

2017年7月14日

关于进一步加强本区装修垃圾处理的工作方案

为进一步加强本区装修垃圾处理工作，做好文明城区创建迎检准备，根据《关于加强本市建筑垃圾消纳处置监管的通知》等文件精神，结合本区实际，提出如下工作方案。

一、总体要求

补齐装修垃圾分类投放的管理短板。堵塞非法处置装修垃圾的渠道，确保本区装修垃圾市内处置，不发生环境污染事件。规范居民区装修垃圾的运输及处置，加快现有存量消纳。

二、重点任务

(一)解决居民区装修垃圾积压现象

自2016年6月起，本市装修垃圾未经分拣，一律不得处置。本区人工分拣，日分拣处置能力300吨/日。目前机械化分拣设备已基本到位，日常分拣处置能力提升至900吨/日，基本满足本区装修垃圾处置需要，有望近阶段解决居民区装修垃圾积压现象。

(二)打击装修垃圾非法倾倒现象

2016年本市建筑垃圾落实属地处理以来，各中心城区装修垃圾处理难的共性问题不断凸显，装修垃圾非法倾倒现象愈演愈烈，跨区县、跨省市的偷乱倒时有发生。尤其是以三轮车为非法承运工具的“游击队伍”显著增多。据统计，本区平均每日非法倾倒的暴露垃圾近200吨，主要是装修垃圾。打击装修垃圾非法倾倒现象，将有效支撑和维护装修垃圾正规的清运市场，减少暴露垃圾造成的环境污染现象。

(三)落实装修垃圾源头分类工作

目前本区装修垃圾中各类垃圾的混同度较高，其中盒饭、瓶罐、塑料、衣物等生活垃圾及油漆罐、灯管等有毒有害垃圾占比近30%，不符合处置要求，集中分拣的压力和难度较大。落实装修垃圾源头分类工作，将降低集中分拣的难度，有助于本区装修垃圾处置能力的进一步提高。

三、职责分工

区绿化市容局负责本区装修垃圾处理的全面管理和指导工作，以及装修垃圾物流运输、集中分拣、中转与末端处置等具体工作。区政府明确华泾镇关港H4-7地块(龙吴路近景联路)为本区装修垃圾集中分拣、中转场所，分拣达标的建筑垃圾运输至奉贤区柘林塘卸点处置;分拣出的残渣运输至浦东新区老港四期废弃物综合处理厂处置(市绿化市容局分配本区的残渣处置计划量为150吨/日)。

区城管执法局依法对违反规定的行为实施行政处罚，包括对装修垃圾非法倾倒、运输与处置的处罚。重点打击非法承运装修垃圾的“游击队伍”，始终保持对装修垃圾违规堆放、非法处理的严打高压态势，同时督促装修垃圾收运单位做好车容车貌管理。

区住房保障房屋管理局指导、协调各街道、镇督促物业服务企业做好装修垃圾投放管理工作，包括落实装修垃圾堆放场所，做好堆放场所的现场管理，保持环境整洁，防止扬尘污染，挂牌公示相关信息，指导投放人做好分类投放等。

各街道、镇作为本辖区内装修垃圾处理工作的责任主体，负责本辖区内装修垃圾处理的日常监管。一要充分发挥社区自治作用，依托物业服务企业、居委会及网格管理平台，建立多层次的管理网络。二要根据“谁污染、谁付费”的原则落实责任，督促装修垃圾产生者承担处理责任，督促装修垃圾投放管理责任人承担管理责任。对装修业主开展入户宣传，做好源头定点投放、分类减量，垃圾不混同堆放。做好对沿街企事业单位装修垃圾堆放的指导工作，减少乱堆放现象。三要与环卫部门建立有效的联系机制，提早排摸辖区内装修情况，预报环卫部门，施行定点、定量清运，避免装修垃圾积压。四要严格监管辖区内居民区装修垃圾清运情况。为遏制非法运输处置行为，居民区装修垃圾原则上由本区环卫企业负责清运。五要做好装修垃圾非法处理现象的排查与整治工作，依托网格化综合管理平台(视频监控系统)等科技手段，追查非法倾倒装修垃圾的来源与责任人，督促责任人及时落实整改，发现重大违法线索及时移交区城管执法局进行处理。加强对背街小巷等监管盲区的巡查，部署专项整治行动，消除成规模的装修垃圾非法倾倒点及堆点。同时对背街小巷内零星绿地、街旁绿化加强管理，落实属地责任。

四、保障措施

(一)培育居民分类习惯

将垃圾分类、绿色账户推进作为小区综合治理工作中的重要内容，2017年本区绿色账户要新增覆盖14.3万户，累计达到30.3万户，实现垃圾分类居住区绿色账户的全覆盖，以此进一步提升居民的分类意识、培育分类习惯。

(二)提高运能及产量

根据居住区实际情况，因地制宜调整运输路线、清运时间，有效提高运能。进一步加大投入，深化分拣设施设备的研发，提升关港装修垃圾集中分拣、中转场所的分拣能力。

(三)加强分类指导和考核

定期组织开展相关培训，重点抓好物业服务企业领导、居住区物业经理、居住区装修垃圾堆放场所管理员三类人群的分类指导。将装修垃圾投放管理责任履行情况纳入物业服务企业的考核评级。
