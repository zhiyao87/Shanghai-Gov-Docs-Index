# 关于废止《上海市智慧公厕建设导则（试行）》的通知



为贯彻落实相关工作精神，综合考虑技术发展迭代因素，经研究决定，废止《上海市智慧公厕建设导则（试行）》（沪绿容〔2019〕373号）。
特此通知。
上海市绿化和市容管理局
