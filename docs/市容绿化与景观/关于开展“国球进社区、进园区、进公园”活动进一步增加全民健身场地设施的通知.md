# 关于开展“国球进社区、进园区、进公园”活动进一步增加全民健身场地设施的通知

关于开展“国球进社区、进园区、进公园”活动进一步增加全民健身场地设施的通知

沪体群〔2023〕185号

各区体育行政部门、建设行政管理部门、绿化市容管理部门、住房保障房屋管理局：

为全面贯彻落实党的二十大精神，深入践行人民城市重要理念，优化全民健身场地设施布局，拓展市民身边的高品质健身空间，满足市民多样化健身需求，根据住房和城乡建设部办公厅、体育总局办公厅印发《关于开展“国球进社区”“国球进公园”活动进一步推动群众身边健身设施建设的通知》以及体育总局办公厅等部门印发《全民健身场地设施提升行动工作方案（2023—2025年）》等文件，结合上海实际，开展“国球进社区、进园区、进公园”活动。现将有关事项通知如下：

一、主要目标

“十四五”期间，结合本市“15分钟社区生活圈”建设、城市更新和老旧小区改造、完整社区建设试点、公园绿地建设和开放共享、健身设施建设补短板、全民健身场地设施提升行动等工作，组织开展“国球进社区、进园区、进公园”活动，在社区、园区、公园等处配建以乒乓球台等为重点的小型健身设施。通过新建、改建（包括扩建原乒乓球场地、增加乒乓球台）等方式，每个项目至少配备2个乒乓球台（具体要求见附件1），2023年全市完成不少于150个项目合计1360个乒乓球台（指导目标见附件2），2024和2025年项目数量以国家实际下达具体研究为准，构建更高水平全民健身公共服务体系。

二、工作任务

（一）科学规划选址。要加强科学选址，坚持因地制宜，功能复合，在不影响原有功能的前提下，鼓励室内室外相结合（以室内为主），有效兼顾和满足儿童、中青年、老年人以及残疾人等群众就近就便的健身需求，保障空间布局合理，方便群众参与。推动全民健身公共服务资源向中心城区、五个新城、重点转型区域、人口相对集中的郊区城镇和居村等区域合理倾斜。

（二）合理建设场地设施。坚持市区协调、部门协同，以区为单位，结合街镇打造“15分钟社区生活圈”，研究制定建设计划，明确项目清单。区体育行政部门要会同相关部门加强对项目选址、设施配置类型、数量等指导。根据社区、园区、公园场地条件和周边群众需求，可因地制宜结合社区党群服务中心、社区文化活动中心、综合为老服务中心、老年活动室、社区市民健身中心、市民健身驿站、体育公园以及园区公共空间、闲置厂房、城市“金角银边”等嵌入布局以乒乓球台为主的小型多样的健身设施。

（三）鼓励群众参与。在场地设施规划建设过程中，要践行群众路线，兼顾各类人群健身需求，充分倾听百姓声音，提高群众健身的获得感和满意度。可以通过问卷调查、座谈研讨等多种方式听取市民群众、企业、专家等社会各界意见。对于有益意见建议，要积极研究采纳。

（四）推进数字化转型。融入城市数字化转型，鼓励在项目建设过程中同步配备智慧化运动器材，将场地设施信息纳入“一网通办”、“来沪动|健身地图”、上海市体育场馆设施数字化管理服务等公共信息平台，满足市民群众信息查询、预订等需求。

（五）加强社区体育服务。各区、街镇要充分利用已建成的“国球进社区、进园区、进公园”项目，积极组织群众身边的乒乓球比赛等体育赛事活动，开展社区健康运动会和全民健身志愿服务，加强科学健身指导，推进社区体育服务配送，打通全民健身公共服务“最后一公里”。

三、保障措施

（一）加强组织领导。各区体育行政部门要会同建设、绿化市容管理部门以及住房保障房屋管理局制定本区实施方案，鼓励将“国球进社区、进园区、进公园”项目纳入民生实事，健全相关部门之间的协同机制、日常联络机制和重要议题会商机制，明确负责人员，每半年总结上报本区工作情况。支持具备条件的社区、园区、公园先行先试、示范引领，调动各方面参与的积极性，逐步扩大覆盖面。

（二）落实资金保障。各区要建立政府部门、有关单位、企业等共同参与的投入机制。各区体育行政部门要加强与建设、绿化市容管理部门以及住房保障房屋管理局、街镇之间的沟通协调，争取多方支持。市体育局利用中央体彩专项转移资金并争取市级资金对各区街镇新建、改建的“国球进社区、进园区、进公园”项目给予资金扶持。具体扶持方式和标准由市体育局另行研究确定。

（三）加强管理维护。各区要加强项目统计，建立工作台账。做好项目日常维护管理，落实公共体育设施免费或低收费公益开放相关规定，定期对设施器材使用情况进行巡查和评估，对于老旧设施器材要及时纳入更新计划，满足群众正常使用需求，杜绝安全隐患。支持社会力量参与健身设施运营。鼓励购买公众责任险以及意外险。

（四）加强宣传引导。市体育局聘请知名运动员、教练员担任“国球进社区、进园区、进公园”活动公益形象代言人。各区要加大优秀项目、典型案例的宣传力度。充分利用报刊、广播、电视、互联网以及微信、微博等媒体资源，广泛宣传动员，突出全民健身对于促进全民健康的积极作用，推广好的经验做法，营造良好的全民健身氛围。
