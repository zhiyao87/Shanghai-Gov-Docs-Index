# 上海市绿化和市容管理局关于印发《上海市苏州河滨水公共空间户外招牌设置导则》的通知

苏州河沿岸相关区绿化市容局：

为推进“一江一河”两岸公共空间品质提升民心工程建设，优化苏州河沿岸户外招牌设置，根据《上海市黄浦江苏州河滨水公共空间条例》《上海市市容环境卫生管理条例》规定，我局编制了《上海市苏州河滨水公共空间户外招牌设置导则》（以下简称《导则》），《导则》于2023年10月1日起实施。现将《导则》印发给你们，请认真按照执行。

特此通知。
