# 关于开展2026年上海绿化市容行业志愿服务工作的通知

各区绿化和市容管理局、各相关直属单位、市志愿服务总队：

为深入学习贯彻习近平总书记致中国志愿服务联合会第三届会员代表大会重要贺信和给上海市虹口区嘉兴路街道垃圾分类志愿者重要回信精神，根据住房城乡建设部《住房城乡建设部等5部门关于推动生活垃圾分类志愿服务发展的意见》（建城〔2024〕34号）以及《关于健全新时代上海志愿服务体系的若干措施》（沪委社发〔2025〕7号）工作要求，推动绿化市容行业志愿服务制度化、常态化、专业化发展，发挥志愿者在基层治理中的独特作用，现就2026年绿化市容行业志愿服务工作通知如下：

一、主要内容

（一）服务国家战略，落实行业发展要求

助力生态文明建设。展“好形象”，围绕上海“十五五”规划建设目标，引导志愿者投身公园城市建设、无废城市建设、垃圾分类等生态惠民工程最前沿。结合2026年为可持续发展志愿者国际年，立足上海国际化大都市资源禀赋和区位优势，各区策划兼具上海特色和国际视野的志愿服务项目，挖掘爱绿护绿、资源回收利用、垃圾分类等领域的实践案例，讲好上海绿化市容志愿服务故事。

引导志愿服务可持续发展。建“好队伍”，完善管理机制，强化市志愿服务总队示范、指导、协调作用；各区、各单位发挥党建优势，健全志愿服务支持保障体系，建设特色志愿服务队伍，鼓励利用网络平台等开展志愿服务，尤其应注重挖掘和引导行业科普达人、自媒体创作者等参与创作传播，展现本行业良好形象。进一步完善垃圾分类志愿服务“三级管理、五级队伍”队伍体系，规范管理和培训。

（二）服务百姓民生，营造良好社会氛围

拓展服务内涵。搭“好平台”，结合“温暖申城”市级志愿服务工作要求，聚焦社区行动困难群众、老龄人口、流动人群等实际需求，加强跨行业、跨领域的志愿服务队伍融合联动，突显城市暖心底色；行业园林绿化、林业等单位，可引导志愿者开展园艺培训、科普讲解等专业志愿服务，满足市民精神文化需求，提升自我价值。选“好点位”，做好志愿服务宣讲，在学校、园区、特色街区、重点公园绿地、重要垃圾分类场馆等场所，讲述绿化市容行业建设的发展历程和成果。传“好内容”，围绕“公园城市”“洁净城市”等理念，聚焦可回收物回收体系建设、公园开放管理、行道树飘絮治理等民生关注进行科普和宣传，大力推广绿色低碳价值观。

建立常态化宣传动员机制。办“好活动”。在交通枢纽、旅游景区、生活社区等人口流动频繁的区域，以及重大赛会、传统节庆等时间节点，全市各区每月集中一天开展“绿色循环”志愿服务主题宣传日活动。落实相关牵头部门，鼓励以体育、文化、艺术等赛会活动为载体，开展宣传和服务，做好垃圾分类IP形象培育。遇重要节点，市绿化市容局在部分区的宣传日活动中同步设立市级会场（活动计划见附件1）。

开展“七进”志愿服务。树“好品牌”。由市垃圾分类志愿服务总队联合新华社和属地各级志愿服务队伍，开展绿化市容主题宣传进社区、进村宅、进学校、进医院、进机关、进企业、进公园等“七进”活动（活动计划见附件2）。

（三）服务社会治理，凝聚基层治理合力

参与社区治理。做“好帮手”，强化精神文明建设对志愿服务工作的赋能作用，进一步做实志愿服务队伍力量；鼓励行业志愿者与所在社区协同联动，积极参与社区绿化养护、垃圾分类、公园管理等治理过程，主动建言献策，为超大城市治理贡献力量。

凝聚志愿文化。立“好项目”，倡导文明新风，培育具有行业特色、区域特色及影响力的志愿服务品牌项目。育“好典型”，加强先进典型的培育和宣传，营造全社会关心、支持、参与志愿服务的氛围，推动行业志愿服务高质量发展。

二、工作要求

请各区、各单位发挥自身资源优势，将志愿者队伍建设、开展主题活动作为推进绿化市容行业志愿服务制度化、常态化、专业化的重要抓手，制定全年计划，认真实施。将集中活动和常态化服务结合起来，聚焦群众真实需求和行业发展目标设计服务项目，不搞运动式、表演式活动。做实“七进”志愿服务品牌，各区落实专人，做好场地保障、秩序维护、宣传发动等，可结合地区已有的宣传安排联动开展，扩大活动影响力。

各区、各单位要着力拓宽社会参与渠道，有效链接更多社会资源，努力培育一批爱绿护绿、资源回收利用、垃圾分类等领域的志愿服务示范项目。各区、各单位特色志愿服务项目建设计划等请于2026年4月1日前报送（见附件3 ）。
