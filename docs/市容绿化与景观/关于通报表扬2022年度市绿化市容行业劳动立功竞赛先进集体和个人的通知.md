# 关于通报表扬2022年度市绿化市容行业劳动立功竞赛先进集体和个人的通知

各区绿化市容局、局各直属单位、行业相关单位：

2022年，本市绿化市容行业各单位以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的二十大和市第十二次党代会精神，紧紧围绕建设“生态之城”目标，聚焦“公园城市、森林城市、无废城市、美丽城市”建设等市委、市政府战略部署和绿化市容行业重点目标任务，以“建功“十四五”、奋进新征程”为主题，广泛深入开展劳动立功竞赛活动，充分发挥了行业职工在生态文明建设、市容环境保障和城市精细化管理中的主力军作用。为弘扬先进，激励斗志，经研究决定通报表扬：

上海徐汇环卫服务有限公司等55家单位为2022年度上海市绿化市容行业劳动立功竞赛先进集体；

姜欣等197名同志为2022年度上海市绿化市容行业劳动立功竞赛先进个人。

2023年是学习贯彻党的二十大精神的开局之年，是实施“十四五”规划承上启下的关键一年，希望受到表扬的先进集体和先进个人要戒骄戒躁，踔厉奋发，勇毅前行，继续发挥好劳模先进的示范引领带头作用，为行业的快速高质量发展奉献智慧和力量。各赛区和行业职工要以先进为榜样，以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的二十大精神，认真践行习近平生态文明思想，扎实推进“人民城市”重要理念，围绕中心、服务大局，争先创优、敢于担当，当好生态文明建设和城市精细化管理的排头兵和主力军，进一步推动绿化市容行业高质量发展、创造高品质生活、实现高效能治理，着力助推提升城市软实力，为加快建设具有世界影响力的社会主义现代化国际大都市而团结奋斗。

上海市绿化和市容管理局

2023年2月10日
