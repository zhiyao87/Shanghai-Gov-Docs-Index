# 上海市绿化和市容管理局关于表扬2021年度市绿化市容行业劳动立功竞赛先进集体先进个人的通报

各区绿化市容局、局各直属单位、行业相关单位：

2021年，本市绿化市容行业各单位认真贯彻习近平总书记考察上海和在浦东开发开放30周年庆祝大会上的重要讲话精神，自觉践行“人民城市”重要理念，紧紧围绕垃圾综合治理、市容环境保障、生态空间建设、城市精细化管理等市委、市政府战略部署和行业重点工作、目标任务，以“奋进新时代、创造新奇迹”为主题，广泛深入开展劳动立功竞赛活动，较好地完成了年度确定的各项工作任务，为推动绿化市容行业高质量发展、创造高品质生活、实现高效能治理做出了新的贡献。为弘扬先进，激励斗志，经研究决定通报表扬：

上海路吉环境工程发展有限公司等55家单位为2021年度上海市绿化市容行业劳动立功竞赛先进集体；

钟俍等200名同志为2021年度上海市绿化市容行业劳动立功竞赛先进个人。

2022年是进入全面建设社会主义现代化国家、向第二个百年奋斗目标进军新征程的重要一年，是党的二十大和市第十二次党代会召开之年,也是“十四五”规划实施承上启下的关键之年，希望受到表扬的先进集体和个人要戒骄戒躁，砥砺奋进，勇毅前行，继续发挥好劳模先进的引领示范作用，大力弘扬劳模精神、劳动精神、工匠精神。各赛区单位和个人要以先进为榜样，以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的十九届六中全会精神和十一届市委十二次全会精神，认真践行“人民城市”重要理念，围绕中心、服务大局，争先创优、敢于担当，当好生态文明建设和城市精细化管理的排头兵和主力军，进一步推动绿化市容行业高质量发展、创造高品质生活、实现高效能治理，着力助推提升城市软实力，建设生态宜居的人民城市，以实际行动迎接党的二十大胜利召开。

特此通报。

上海市绿化和市容管理局

2022年3月1日
