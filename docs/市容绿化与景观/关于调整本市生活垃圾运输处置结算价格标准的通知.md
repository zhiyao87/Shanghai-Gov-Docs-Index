# 关于调整本市生活垃圾运输处置结算价格标准的通知

各区绿化市容部门、城投集团：

根据《上海市人民政府办公厅关于同意调整本市生活垃圾运输处置结算价格标准的通知》（沪府办〔2022〕52号），现将新一轮生活垃圾运输处置结算价格调整事项通知如下：

一、生活垃圾末端处置结算价格

生活垃圾进江桥焚烧厂的末端处置结算价为269元/吨。

生活垃圾通过内河集装化转运系统水运进老港生态环保基地的末端处置结算价为175.95元/吨；生活垃圾通过散装水运进老港生态环保基地的末端处置结算价为188.38元/吨。

生活垃圾通过直运方式进入老港生态环保基地的末端处置结算价为189元/吨。

宝山区以外的生活垃圾通过蕰藻浜码头集装箱转运进入宝山焚烧厂的末端处置结算价为177.29元/吨。

以上费用由相关区与上海城投老港基地管理有限公司（以下简称“城投老港”）结算。

二、生活垃圾水运结算价格

各区生活垃圾委托上海城投环境（集团）有限公司（以下简称“城投环境”）通过内河集装化转运系统水运进老港生态环保基地的，水运结算价为71.07元/吨；生活垃圾通过散装水运进老港生态环保基地的，水运结算价为65.14元/吨。

以上费用由相关区与城投环境结算。

三、蕰藻浜、徐浦码头转运管理结算价格

生活垃圾经蕰藻浜、徐浦集运码头集装化转运的，卸力服务价格为21.98元/吨。

生活垃圾经蕰藻浜、徐浦集运码头压缩转运的，压缩服务价格为59.51元/吨（含源头除臭费1.5元/吨）。

以上费用由相关区与城投环境结算。

四、陆路集装箱转运结算价格

生活垃圾通过蕰藻浜码头转运至宝山焚烧厂的陆运价格为69.73元/吨，蕰藻浜码头卸力服务价格为21.98元/吨。

以上费用由相关区与城投环境结算。

五、其他垃圾结算价格

各区进入市级设施处置的装修垃圾分拣残渣、整治垃圾、湿垃圾残渣、粪便残渣、应急残液及冲洗水等，运输及末端处置结算价格参照生活垃圾结算价格执行。

以上费用由相关区分别与城投环境、城投老港结算。

上述结算标准自2023年1月1日起执行。
