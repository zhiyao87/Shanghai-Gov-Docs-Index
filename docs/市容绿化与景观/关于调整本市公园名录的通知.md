# 关于调整本市公园名录的通知

各区绿化市容局:

为持续完善城乡公园布局,建设公园城市,全市各区积极推进各类公园绿地、林地建设，建设了一批绿化景观面貌良好、基础配套设施比较完善、服务功能较为丰富的公园绿地、休闲林地，已具备纳入城乡公园体系的条件。

在各区申报的基础上，经我局现场踏勘和研究讨论后，现决定将69座口袋公园、30座乡村公园纳入城乡公园名录管理（城市公园前期已发布），并予以发布。本次调整后，本市城乡各类公园数量将增加至670座，其中城市公园438座、口袋公园172座、乡村公园59座、主题公园1座。

希望各区加强管理，维护良好景观面貌，不断提升服务水平，为市民创造优美的城乡公园生态环境。
