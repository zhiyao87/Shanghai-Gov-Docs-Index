# 上海市绿化和市容管理局关于转发《林木种子生产经营许可证管理办法》的通知



闵行区、嘉定区、青浦区绿化市容局、浦东新区环保局，宝山区、奉贤区、松江区、金山区、崇明县农委：
现将国家林业局制定的《林木种子生产经营许可证管理办法》（2016年第40号令）转发至各单位，请遵照执行。
