# 关于印发《上海市绿化和市容管理局城市公园游乐设施突发事件应急预案》的通知

各区绿化市容局、临港新片区管委会、局各直属公园：

为了有效防范和应对本市城市公园内游乐设施突发事件，提高防范、处置游乐设施突发事件的水平和能力，现制定印发《上海市绿化和市容管理局城市公园游乐设施突发事件应急预案》，请结合工作实际遵照执行。

特此通知。

上海市绿化和市容管理局

2024年11月11日
