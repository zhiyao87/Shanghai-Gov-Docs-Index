# 关于印发《上海市绿化和市容管理局关于全面推进“一网通办”的实施意见》的通知



为贯彻落实市委、市政府关于全面推进“一网通办”的总体要求，严格执行《上海市公共数据和“一网通办”管理办法》，继续深化“放管服”改革，积极优化营商环境，结合绿化市容行业实际，制定了《上海市绿化和市容管理局关于全面推进“一网通办”的实施意见》，现印发给你们，请遵照执行。
