# 上海市市场监督管理局 上海市文化和旅游局 上海市绿化和市容管理局 上海市体育局关于印发《大型游乐设施运营使用单位跨部门综合监管“一件事”改革实施方案》的通知

上海市市场监督管理局 上海市文化和旅游局 上海市绿化和市容管理局 上海市体育局关于印发《大型游乐设施运营使用单位跨部门综合监管“一件事”改革实施方案》的通知

各区市场监管局、文化旅游局、绿化市容局、体育局，各有关单位：

现将《大型游乐设施运营使用单位跨部门综合监管“一件事”改革实施方案》印发给你们，请认真贯彻执行

上海市绿化和市容管理局

上海市体育局

2024年4月15日

大型游乐设施运营使用单位跨部门综合监管“一件事”改革实施方案

为贯彻落实《国务院办公厅关于深入推进跨部门综合监管的指导意见》（国办发〔2023〕1号）、《上海市人民政府办公厅关于深入推进跨部门综合监管改革的通知》（沪府办字〔2023〕8号），推进大型游乐设施（含客运索道，下同）运营使用单位跨部门综合监管“一件事”改革，制定本实施方案。

一、工作目标

以“监管对象全覆盖、监管内容全要素、监管流程全闭环、监管执法全协同、监管数据全共享、监管结果全公开”为目标，按照“三管三必须”的原则，统筹整合市场监管、文化旅游、绿化市容、体育等部门监管资源，全面建立大型游乐设施运营使用单位综合监管机制，形成跨部门监管合力，解决多头执法、重复检查问题，营造更优营商环境。积极探索大型游乐设施智慧监管、信用监管模式，加强现代科技应用，提高风险预警能力，强化信息共享互通，实现信用联合奖惩，全面提升事中事后监管效能。

二、工作任务

（一）梳理综合监管清单

梳理本市大型游乐设施及其风险点清单，构建跨部门联合监测预警模型，提高风险隐患发现、处置能力。建立大型游乐设施运营使用单位重点监管名录，并依据风险隐患情况实施动态管理。根据行业分类，标注大型游乐设施运营使用单位的行业类型，明确综合监管范围。

（二）明确监管内容要素

对大型游乐设施运营使用单位相关检查事项进行全面梳理，明确跨部门综合监管的检查项目、检查内容、检查要求、处置措施、依据出处等，大力精简多部门重复检查事项，形成统一的跨部门综合检查单。

（三）出台综合监管规则

制定出台大型游乐设施运营使用单位跨部门综合监管规则，加强部门政策协同，再造执法检查流程，落实监管闭环管理，对于两个以上部门对同一监管对象实施不同行政检查且可以同时开展的，按照“一次检查、联合体检”的原则，实行联合检查。建立综合监管“一业一册”告知制度，制定大型游乐设施运营使用单位一册合规经营指南，一次性告知市场主体合规经营要求。

（四）建立信息共享机制

充分发挥市、区两级特种设备联席会议（特种设备安全专业委员会）的平台作用，建立健全跨部门联动会商、情况通报等工作机制。加快推进各部门业务系统对接，实现监管信息共享互通，着力打通数据壁垒，加强大数据分析挖掘，形成社会多元共治。依托特种设备智慧监管和数字化转型工作，打造大型游乐设施运营使用单位跨部门综合监管应用场景，支撑综合监管“一件事”改革。

（五）创新智慧监管模式

积极应用物联感知、大数据、人工智能等新兴技术，在大型游乐设施领域推广加装传感器和视频监控装置，有效归集设备运行和安全管理相关数据。推出“特种设备码”，通过逐台设备贴码绑定，实现使用管理、维护保养、监督检查等多维度的“一码通识”，打通大型游乐设施数据链条。

（六）探索信用监管模式

通过行政许可、日常监管、检验检测、投诉举报、执法办案等关键环节记录市场主体信用行为，全面归集大型游乐设施运营使用单位各类信用信息，建立大型游乐设施运营使用单位信用评价体系。加强信用联合惩戒，推进信用评价结果应用，探索差异化、精准化的信用监管模式，定期向社会发布信用评价结果，依法实施守信激励和失信惩戒。

三、进度安排

（一）试点探索阶段（2024年）

先行在浦东新区、松江区开展试点，市市场监管局、市文化旅游局、市绿化市容局、市体育局积极指导、推动试点区整合监管资源，严格按照规范要求开展大型游乐设施运营使用单位跨部门综合监管，形成可复制、可推广的工作机制。试点区由区市场监管局牵头，探索制定跨部门综合监管规则，形成统一的综合检查单，出台一册合规经营指南，尝试运用“特种设备码”开展智慧监管，打造辖区大型游乐设施综合监管示范点位，并在2024年12月底前总结试点经验和成果。相关区文化旅游、体育、绿化市容等部门要依照法律法规、“三定”规定和权责清单，梳理相关事项内容，填写《大型游乐设施运营使用单位检查事项清单》（见附件1）和《大型游乐设施运营使用单位合规经营指南清单》（见附件2），在2024年6月底前报送区市场监管局。

（二）全面推广阶段（2025年）

总结浦东新区、松江区试点经验，在全市复制推广，由市市场监管局牵头建立本市大型游乐设施运营使用单位重点监管名录，理顺专业监管和行业监管的职责边界，制定跨部门综合监管规则，形成统一的综合检查单，出台一册合规经营指南，并开发大型游乐设施运营使用单位跨部门综合监管应用场景，全面推广“特种设备码”。市文化旅游局、市绿化市容局、市体育局要积极完成信息化系统数据对接，发挥行业主管部门优势，健全信用奖惩机制，推广一册合规经营指南，鼓励行业企业及相关单位应用新兴技术，提高设备运行水平和安全管理能级。逐步构建本市大型游乐设施运营使用单位跨部门综合监管“一件事”工作机制。
