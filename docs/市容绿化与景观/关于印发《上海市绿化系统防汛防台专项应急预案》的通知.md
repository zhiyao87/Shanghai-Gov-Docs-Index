# 关于印发《上海市绿化系统防汛防台专项应急预案》的通知

各区绿化市容局，临港新片区管委会，局相关直属单位：

为建立健全本市绿化系统防汛防台的组织应对机制，提高绿化防汛防台的应急处置能力，现制定印发《上海市绿化系统防汛防台专项应急预案》，请结合工作实际遵照执行。
